# Current Debug Update Notes

Replace this template before running `:app:publishDebugUpdate`.

Write the current debug update notes in Chinese by default. Include:

- what the user asked for;
- what analysis or diagnosis was performed;
- important files and implementation changes;
- user corrections after earlier attempts, if any;
- how those corrections were addressed;
- verification and publish status when relevant.

Archived notes from the previous Thing Card media geometry debug cycle live in
`docs/features/thing-card-media-target-geometry/debug-updates.md`.

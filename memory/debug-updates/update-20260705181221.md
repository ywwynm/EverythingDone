# 修复首页选择模式旧阴影与单个 Widget 配置顶部渐变断开

## 本次修复

1. 首页沉浸式列表进入选择模式时隐藏旧 actionbar 阴影
   - 场景：在首页向下滑让 home actionbar 隐藏，再上滑让它显示；此时长按记事进入选择模式，contextual toolbar 下滑动画出现前会短暂露出旧 home `actionbar_shadow`。
   - 修复：`ModeManager.showContextualToolbar()` 在 contextual toolbar 设为可见之前立即把旧 home `actionbar_shadow` 置为透明；`ActivityHeader.hideActionbarShadow` 支持立即隐藏，同时保留原 alpha，退出选择模式时仍按原逻辑恢复。

2. 单个记事 Widget 配置页顶部栏连续绘制背景
   - 场景：进入文件夹后，`statusbar` 与 `actionbar` 分别绘制文件夹背景；渐变文件夹下两段明显断开。根目录的 `accent+accent2` 渐变也应按同一规则连续绘制。
   - 修复：`activity_thing_widget_configuration.xml` 新增 `ll_top_chrome` 顶部容器包住 statusbar 与 toolbar；`BaseThingWidgetConfiguration.applyTopChrome()` 改为只给该容器应用根目录 `App.defaultAccentBackground` 或当前文件夹背景，两个子 View 保持透明。标题、返回图标、菜单图标与系统状态栏明暗策略保持不变。

# 修复：单记事 Widget 选记事界面，打开文件夹时根列表的滚动偏移被带入

## 主要改动
- 续上一处修复。根列表只滑动一小段后打开文件夹，文件夹列表会继承同样的小偏移、没有真正停在顶部。原因是 `StaggeredGridLayoutManager.scrollToPosition(0)` 只保证第 0 项可见；当第 0 项仍部分可见时它不重置偏移，于是父列表的滚动距离被带进了刚打开的文件夹。
- 改用 `scrollToPositionWithOffset(0, 0)` 强制把顶部项对齐到偏移 0，确保“打开文件夹”一定从顶部开始。“无滚动记录则回顶部”的回退路径也走同一逻辑。

## 验证重点
1. 在根列表只向下滑动一小段（第一行仍部分可见），点开一个文件夹：文件夹应严格停在顶部，没有任何残留偏移。
2. 根列表滑动较多后打开文件夹：同样应停在顶部。
3. 返回上一级：根列表恢复到打开文件夹前的滑动位置（保留位置行为不变）。
4. 进入文件夹后未滑动就返回、再次进入同一文件夹：进入时仍停在顶部。

# 修复：单记事 Widget 选记事界面，返回文件夹时保留滑动位置

## 主要改动
- 在为桌面单记事 Widget 选择要显示的记事的界面里，滑动记事列表、进入某个文件夹、再返回时，列表不再跳回最顶部，而是恢复到进入文件夹前的滑动位置（与首页的行为一致）。
- 严格区分“打开”和“返回”两种动作：打开（进入子文件夹）时列表滚到顶部；返回（回到上一级文件夹）时恢复该层级此前的滑动位置，若无记录则回顶部。
- 实现上按文件夹层级缓存列表的滚动状态（根目录单独计一档），进入子层级前保存当前层级位置，返回时恢复目标层级位置。

## 验证重点
1. 进入 Widget 选记事界面，向下滑动记事列表，点开一个文件夹：文件夹内列表应停在最顶部。
2. 在文件夹里返回上一级：列表应回到进入该文件夹前的滑动位置，而不是跳回顶部。
3. 多层文件夹逐级进入再逐级返回：每一级返回都应恢复各自此前的滑动位置。
4. 进入文件夹后没有滑动就返回，再次进入同一文件夹：进入时仍应停在顶部。
5. 选中某条记事进入预览、再返回列表：滑动位置保持不变（与本次改动无关，确认未被破坏）。

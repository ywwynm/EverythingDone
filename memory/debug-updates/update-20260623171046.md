# 修复：大文件夹缩略图列数、新记事入场动画先滚到位、设置页渐变 checkbox 对齐

## 主要改动
- 大文件夹（占满整行的缩略图文件夹卡片）里的记事缩略图列数不再固定为 3，改为“首页记事列表列数 + 1”，并随横竖屏切换自适应：手机竖屏 3 列、手机横屏/平板竖屏 4 列、平板横屏 5 列。显示的缩略图数量也随屏幕调整（手机 6 个，平板约铺满 2 行），手机竖屏维持原样。
- 新建记事后，列表会先平滑滚动到能完整看到这条新记事的位置（停在工具栏正下方），再播放入场动画。之前当顶部被置顶的文件夹/记事占据时，新记事的动画会被挡住、要手动下滑、而且看不全；现在无需手动操作即可完整看到。若新记事本来就完整可见则不滚动、原地播放。
- 设置页给 checkbox 加渐变后，checkbox 与左侧文字之间没有间距、且和部分条目右侧的“?”帮助图标不在一条竖线上；现已恢复约 8dp 间距，并让 checkbox 与“?”图标按中心线对齐成列。

## 验证重点
1. 把某个文件夹设为“缩略图 + 全宽”展示，横竖屏切换、平板上查看列数是否为“首页列数 + 1”，缩略图数量是否随屏幕变化且不显得太空；手机竖屏应与之前一致（3 列 6 个）。
2. 在首页置顶几个文件夹/记事占满头部，然后新建一条记事：应自动滚动到新记事完整可见处再播放入场动画，无需手动下滑；揭示动画与 shining 描边两种风格都生效；动画演完停在新记事处。
3. 没有置顶项、新记事本来就可见时：不应发生多余滚动，原地播放动画。
4. 创建时若开着单一类型筛选（如只看提醒）：返回后列表重置为全部类型、整列表刷新（此路径无逐项入场动画，维持现状）。
5. 设置页逐条检查：每个 checkbox 与左侧文字有合适间距，且与右侧“?”图标对齐成一条竖线；点选/取消的渐变勾选动画正常。
6. 详情页、桌面记事列表 Widget 配置页、颜色选择里的勾选控件外观保持不变（未受本次 checkbox 改动影响）。

# Dialog 粒子消散的释放场不含中心项，改用分界线上的速度差

对话框消散的宏观走向由一张标量释放场决定：一条朝顺风侧推进的斜坡，叠加有界的大尺度起伏。
2026-09-02 决定**删除以卡片中心为原点的椭圆"中心推后"项**，改为让分界线的推进速度沿其
长度缓慢变化（一段约三分之一长、由种子决定位置、离两端至少六分之一的慢段，最慢/最快约 0.4）。

为什么这样做：逐帧拟合参考动画时，"中心更晚"的系数确实存在（+0.216），但参考里最后消失的
那一片是一块**沿扫描方向拉长、落在顺风侧偏左的不规则区域**（长宽比 2.3、圆度 0.18），不是圆；
用椭圆基去凑这个系数，等值线天然是同心椭圆，白底对话框上最后必然剩中心一个圆——这正是
2026-08-30 已明令禁止的拓扑。分界线上有一段走得慢，是参考实测的事实（横向 8 条车道推进速度
321–870 px/单位时间），它自然产生带状的最后一片，而且场里从此没有任何径向构造。

未选：把分界线显式参数化成随时间演化的曲线（能突破起伏幅度的结构上限，但要重写释放场、
桌面探针与单测，留作下一步）；把中心项拉成沿扫描方向的椭圆（治标，落点仍绑在卡心）。

2026-09-02 补记："斜坡 + 分界线慢段"的构造已被 `0007`（点源各向异性扩张）取代；"不含中心项"这一条继续有效。

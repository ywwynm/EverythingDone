# Dialog 粒子消散的释放场是点源各向异性扩张，不是朝顺风侧推进的斜坡

取代 `0006`（0006 的"删除中心项"仍然成立，其"斜坡 + 分界线慢段"的构造被本决定取代）。

2026-09-02 决定：释放时间由一个**源点**向外扩张给出——源点在迎风边中点向内 16% 处，
释放时间与到源点的距离成正比，比例系数随方向变化（朝风向右转 90° 的窄瓣快、其余方向慢，
相差约 2.8 倍），源点周围一小块同期起火，顺风侧角落在约三分之一处独立起火。大尺度起伏
只作用在角度方向（分界线的摆动），小尺度由单元抖动给。

为什么这样做：对参考动画的释放时间图按到源点的距离统计，时间是线性的，超过一半卡宽后
进入平台；同一距离上不同方向相差 2.7 倍。一条平行推进的分界线无论怎样加慢段，都给不出
参考同时具备的三个形状特征——右侧又高又亮的羽流、左下独立的第二条羽流、最后一片落在
左侧偏下且不被粒子包裹。点源加各向异性一条法则同时给出这三个特征，而且场里仍然没有任何
以卡片中心为原点的构造（0006 的禁令不变）。

未选：按参考逐像素直接采样释放时间图（只对这一个尺寸、这一个风向成立，换尺寸/风向
无法泛化）；两个独立源点叠加（左下第二条羽流由慢瓣自然给出，不需要第二个源）。

2026-09-02 补记：点源与其后的扇区模型当日即被否决，释放场回到"垂直于风向的前沿沿风向平推"，并进一步改为连续薄片原型（`tmp/particle-dismiss-tuning/sheet/`）。保留本文只为记录否决的理由，见 `docs/features/dialog-particle-dismiss/decisions.md` 当日各条。

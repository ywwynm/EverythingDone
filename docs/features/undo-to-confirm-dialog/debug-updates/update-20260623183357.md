# 移除撤销 snackbar，状态变更改为确认弹窗

这一版把状态变更的「撤销 snackbar」整套机制移除，改为操作前确认：

- 选择模式下批量「完成 / 删除 / 恢复 / 永久删除」记事时，先弹确认弹窗，确认后执行，不再有底部撤销条。
- 单条左滑完成、右滑开始专注、单条习惯完成保持即时生效，不弹窗、也不再出现撤销条。
- 普通模式工具栏「全部完成 / 全部删除」沿用原有确认弹窗。
- 完成与删除本就可逆（已完成列表 / 回收站可恢复），永久删除仍有确认。
- 「标题不能为空」等纯提示型 snackbar 暂时保留。

这是「多选批量动作支持文件夹」前置的交互基础，后续会在此之上放开多文件夹 / 混合选择的批量动作。

验证：`:app:assembleDebug` 已通过。已通过 `:app:publishDebugUpdate` 发布到阿里云，debug update code 为 `202606231034`。

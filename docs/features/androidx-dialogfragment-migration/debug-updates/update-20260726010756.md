# 对话框底层迁到 AndroidX 2026-07-26

> 注意：发布任务只提取本文件的**第一个 `## ` 条目**作为应用内更新日志，因此全部内容必须写在同一节里，不能拆成多节。

## 全部对话框换用官方新版实现（底层改动，界面无变化）

- 全部 27 个对话框的底层实现，从系统在 Android 9 就标记弃用的旧组件换成了官方 AndroidX 版本。界面、文案、动效都没有改动；点对话框外部关闭（含上一版刚修好的「从里面按下滑到外面松手不关闭」）、返回键关闭、各对话框自身的按钮与滑动操作，行为都和之前一致。
- 顺带一个看不见的好处：对话框现在正确接入了系统的返回手势派发，Android 13 之后的返回预览动画不再被绕过。
- 这次替换涉及面较广（46 个文件），编译与静态检查都已通过，但真机只有你能验证。如果遇到某个对话框打不开、关不掉，或者旋转屏幕后状态异常，尤其是「图片裁剪外观」和「附件信息」这两个对话框的关闭，请告诉我。

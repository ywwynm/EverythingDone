视觉检查发现遗漏：拖动从等待状态开始时，悬浮快照缺少可辨认的转圈。正式拖动使用 `sourceView.draw(Canvas(bitmap))` 软件画布，系统转圈使用渲染线程。直接捕获已附着、正在播放的图标只能得到 11×10 像素的初始短弧；“存在非透明像素”的浅层断言不足，改为检查加载圈二维范围后稳定失败。排除生命周期未启动及配色原因。

修复仅在 `CoverGenerationAlignedDrawable` 的软件捕获分支绘制同色、同尺寸的固定圆弧帧。实际屏幕仍使用系统 ProgressBar 动画；悬浮快照保持既有静态策略，不改拖动控制器或粒子交接机制。两机修复后实际悬浮截图已确认圆弧可见；软件断言通过。OPPO 首次直接图标测试的画布太小，视觉居中偏移被夹具裁切，扩大透明画布后通过，实际悬浮截图没有该裁切。

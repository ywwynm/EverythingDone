## 动态封面进度的复杂交互补测与快照修复（2026-10-15）

在动态封面生成进度基础版之后，根据用户补充要求，继续检查生成状态与首页粒子动画、拖动、自然滑动、fling、持续触摸，以及内容、外观、设置和封面来源修改同时发生的情况。

补测发现：等待或准备生成时长按拖动，悬浮卡片上的文字正常，但左侧系统转圈在软件快照里仅留下极短的初始弧线，视觉上几乎消失。根因是系统 ProgressBar 动画在渲染线程更新，而拖动通过软件 Canvas 捕获卡片。`CoverGenerationAlignedDrawable` 现在在软件快照中绘制同色、同尺寸的固定圆弧帧；实际屏幕继续使用系统转圈动画。沿用拖动与粒子的既有快照和交接机制，结束后恢复当前生成状态及封面。

新增仅允许隔离测试包运行的 `CoverGenerationInteractionProbe`，使用真实首页、触摸、拖动与粒子管线，并复用正式 GIF 编码器及 WorkManager 订阅，在实际帧边界控制交付时机。两台指定设备 `3B1629006YC00000`、`R5CW20BLNKL` 各通过 32 项并发检查及 67 项基础回归，覆盖：

- DRAGGING、SETTLING、手指不松开期间进度变化与生成完成；离屏返回。
- 长按持续跨越 36 张卡片，拖动源和背景卡完成；拖动中更新源内容及背景布局，取消后恢复透明度、尺寸、GIF 与数量。
- 手指控制的粒子消散及粒子拼合期间完成；背景内容变化；目标自身交接后恢复最新封面，无姿态锁残留。
- 生成中改色、内容与显示限制、背景布局和比例；动态来源 A→B→静态、动态照片 A→B、视频起始帧 0→500ms、关闭及重开自动播放；旧任务没有覆盖新来源。

1507 项 JVM 测试无失败，1 项既有跳过；构建通过。实机使用同源码隔离包，不写入正常安装包的数据。复核了修复前后的软件图标像素和实际拖动截图。本次发布为正常包名的 debug 更新，详细验证边界记录于 `docs/features/animated-cover-generation-progress/interaction-verification.md`。

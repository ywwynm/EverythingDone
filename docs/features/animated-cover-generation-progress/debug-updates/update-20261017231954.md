## 动态封面：修复完成回调交接，复核后台处理与多语言术语

用户要求全面检查本次动态封面进度、后台恢复及国际化改动，同时确认译文遵循应用术语与通常用语。复核 Worker、生成管理器、同源互斥、卡片绑定、清单、WorkManager 依赖和全部 13 套语言后，发现并修复两个代码问题及一项地区用词问题。

`VideoCoverPreviewManager.enqueueGeneration()` 在缓存已经完成时原先直接返回。若 GIF 在详情附件首次查缓存后、登记完成回调前恰好生成完毕，回调会被遗漏。现在通过既有 `notifyGenerated()` 交付已经登记的回调，保证回调仅触发一次，且不重新生成 GIF。

临时文件创建原先位于生成函数的异常处理之外，输出目录异常时会直接抛给 WorkManager，绕过有限重试。现将临时文件和媒体资源的创建纳入原有失败处理与清理路径，普通创建失败返回可重试结果，任务取消仍单独传播。

逐条复核 104 条生成状态、无障碍重试及通知文案，保留各语言现有封面术语和自然表达。香港繁体 6 处“產生”按应用地区词表改为“生成”，台湾保留“產生”；其他语言没有发现明确术语或语法问题。

两个新增回归用例在修复前均复现失败，修复后 3 项断言通过；状态与并发的 7 项 JVM 测试通过，OPPO 隔离包原有 72 项卡片回归通过，13 套语言的资源完整性检查通过。一次回归启动被系统已有的 16 KB 兼容性提示挡住，确认提示后重跑成功；原始中断记录保留，不算作功能通过。本轮未重复之前三机大视频和长后台矩阵；隔离包已卸载，无残留前台服务，未锁屏或操作正式包数据。

详细问题、修复与逐语言核对依据见 `docs/features/animated-cover-generation-progress/review-2026-10-17.md`。

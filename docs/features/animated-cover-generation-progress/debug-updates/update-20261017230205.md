## 动态封面：补齐生成状态与通知的全部语言文案

用户在大视频进度和后台恢复修复后，要求为相关文案提供全语言支持，并补齐这个功能初版遗漏的翻译。核对设置页语言列表与实际调用后，确认原先仅英文、简体中文、香港繁体和台湾繁体定义了生成流程文案，其余 9 套语言会回退到英文。

本轮在德语、西班牙语、法语、印地语、意大利语、日语、韩语、葡萄牙语和俄语资源目录新增 `strings_cover_generation.xml`，共补充 72 条译文。全部 13 套语言均覆盖等待、准备、生成、编码、失败、重试无障碍操作标签、通知渠道名称和后台处理说明 8 项内容。通知标题复用生成状态文案；翻译沿用各语言既有的封面名词，保留原中文及英文措辞和单行截断规则。

完整本地化资源检查通过：以简体中文 1614 项可翻译资源为基准，13 套语言无缺项、重复、空值或格式结构错误。`:app:assembleDebug` 成功；AAPT 读取 APK 后确认 8 个键、13 套配置共 104 个实际打包值与 XML 原文逐项一致。已核对 Worker 通知使用应用语言上下文。

本轮只补充语言资源，沿用此前大视频和后台恢复实现；没有重复三机性能或后台场景测试，也没有更改设备设置。详细覆盖范围及验证记录位于 `docs/features/animated-cover-generation-progress/localization-verification-2026-10-17.md`。

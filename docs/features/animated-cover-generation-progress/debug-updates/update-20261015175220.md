## 首页动态封面生成状态与进度（2026-10-15）

根据本轮设计确认，首页记事卡片生成视频／动态照片 GIF 封面时，临时替换原“X 张图片，Y 个视频”数量行，不新增一行。所有封面布局统一采用此规则，保持原行高与卡片高度。

等待阶段显示“等待生成动态封面”，准备源媒体时显示“准备动态封面”，左侧使用应用常用的小型转圈 ProgressBar；生成阶段显示“动态封面生成中”和反映实际帧处理进度的饼图，不额外显示数字百分比。成功后恢复附件数量；最终失败保留静态封面和“动态封面生成失败”，点击整行可重试。

`VideoCoverPreviewManager`、`VideoCoverPreviewWorker` 提供可释放的 WorkManager 状态观察与进度更新，最终文件写入成功前不会提前显示完成；失败记录在任务历史清理后仍保留。`MotionPhotoCoverHelper` 覆盖动态照片准备与提取，同源多卡在重试后同步跟进。`CoverGenerationBinding` 沿用原数量行与 42% 不透明度遮罩，配色跟随卡片；更新进度不重绑整张卡片，保持滚动、回收、多选、长按和拖动的既有规则。

用户查看验证截图后先指出图标与文字没有垂直居中，随后指出等待阶段截图没有转圈图标。现按实际字形视觉中心对齐，补全系统动态图标可见性及绘制后的动画启动，修复饼图首次安装被 TextView 重置为零的问题，并用 PixelCopy 实际渲染截图复核。

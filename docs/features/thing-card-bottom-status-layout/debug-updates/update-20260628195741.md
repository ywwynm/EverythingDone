# 修复记事列表 widget 侧栏模式状态块未置底

## 用户反馈

- 记事列表 widget 里，图片在左/右、内容比图片矮时，提醒/目标/习惯没有在内容区置底；
  单一记事 widget 正常。

## 原因

- 列表行布局 `app_widget_item_thing.xml` 的内容列 `ll_thing_text_content_widget`
  原为 `wrap_content` 高度（注释说明故意不同于单一 widget 的 match_parent），不会填满
  行高，底部状态 spacer(weight=1) 没有多余空间可分配，状态块停在内容自然位置。单一
  widget 的内容列是 match_parent，故正常。

## 本次修改

- 把列表行内容列改为 `match_parent` 高度。水平的 `ll_thing_side_media_row` 仍是
  wrap_content（行高 = max(侧图高, 内容高)），但水平 LinearLayout 会按该行高对
  match_parent 子项做 EXACTLY 重测，使内容列填满行高，spacer 即可把状态块置底（与单一
  widget 一致）。行本身仍随内容自适应，集合行高不受影响。

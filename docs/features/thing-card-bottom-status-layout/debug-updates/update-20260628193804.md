# 修复 widget 记事全部无法显示（RemoteViews 不支持 View）

## 用户反馈

- 上一版后所有 widget 里记事都显示不出来了，但文件夹还能正常显示。

## 原因

- 上一版给 widget 内容列加的底部状态 spacer 用了裸 `<View>` 元素。RemoteViews 仅支持
  有限的视图类型（TextView/LinearLayout/ImageView 等），不支持 `<View>`，导致 widget
  渲染记事时 inflate 失败、整条记事渲染不出来；文件夹走的是另一套布局，未受影响。

## 本次修改

- 把 `app_widget_thing.xml` 与 `app_widget_item_thing.xml` 内的
  `view_bottom_status_spacer_widget` 由 `<View>` 改为 `<TextView>`（沿用项目里
  `view_private_helper_*`、`view_thing_padding_bottom` 等 RemoteViews 占位的既有做法）。

## 验证

- 已运行 `:app:assembleDebug`，构建通过。
- 已运行 `:app:publishDebugUpdate -PdebugUpdateNotesFile=docs/features/thing-card-bottom-status-layout/debug-updates/update-20260628193804.md`，发布 debug 更新 `202606281138` 成功。

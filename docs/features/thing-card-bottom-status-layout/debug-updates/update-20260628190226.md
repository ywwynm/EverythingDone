# 记事卡片状态块置底 + 封面比例编辑器（应用内第一版）

## 本次修改

记事带图片/视频附件时，提醒/目标/习惯等状态信息统一移到卡片底部：

- 图片在左右两侧时，若内容比图片矮，状态块（音频、提醒/目标、习惯）会锚定到内容列
  底部并保留底部边距，不再紧跟正文上方、也不再与上方内容重叠。
- 图片作为卡片背景时，底部从上到下依次为：「X张图片，Y段视频」提示 → 音频 →
  提醒/目标 → 习惯（之前提示语固定在最底、会和状态块打架）。
- 调整记事外观时，若记事内容高度已超过所设封面图片/视频比例对应的高度（比例被内容
  撑高、再也调不矮），封面比例滑条会置灰并给出说明；内容变矮、比例可重新生效时
  自动恢复可调。

适用范围：首页列表，以及醒目提醒界面、计时界面（后两者本就以标题 + 底部操作按钮
表达提醒/习惯，不显示完整状态块）。单一记事 widget 与记事列表 widget 的同类调整将在
后续版本加入。

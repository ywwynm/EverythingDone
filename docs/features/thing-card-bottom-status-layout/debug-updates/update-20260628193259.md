# 状态块置底规则接入单一记事 widget 与记事列表 widget

## 本次修改

把"提醒/目标/习惯等状态块置于卡片底部"的规则接入两类 widget（RemoteViews）：

- 侧栏图片模式：内容比图片矮时，状态块（音频、提醒/目标、习惯）锚定到 widget 内容区
  底部。
- 媒体背景模式：「X张图片，Y段视频」提示移到内容列底部置底组最上方，其下依次为音频、
  提醒/目标、习惯（不再用固定在卡片左下角的 overlay 提示）。
- 顶部/底部图片、无媒体模式保持原样。

实现说明：单一记事 widget 高度固定（单元格尺寸），状态块可稳定置底；记事列表 widget
行高随内容，侧栏/媒体背景比内容高时置底生效，否则状态块保持在内容自然位置。
widget 配置界面的候选列表与首页一致，选中后的预览也已同步。

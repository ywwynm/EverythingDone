# 封面比例置灰提示文案与裁切弹窗同步置灰

## 用户反馈

- 提示文案应区分封面是图片还是视频，只写实际类型，不要"图片/视频"并列。
- 文案改为：封面（图片/视频）比例的调整范围受记事卡片高度影响，当前卡片高度较大，

  滑条也要置为 inactive。

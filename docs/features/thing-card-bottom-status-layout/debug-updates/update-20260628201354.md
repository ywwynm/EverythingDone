# 记事列表 widget 状态块置底（Android 12+）

## 用户反馈

- 记事列表 widget 里状态块与媒体背景提示仍未置底；询问列表 widget 到底能否置底。

## 结论与做法

- 列表 widget 每行高度跟随内容，没有固定总高给 weight spacer 占满；而 RemoteViews 直到
  Android 12（API 31）才有 `setViewLayoutHeight` 能显式设布局高度，API 26–30 无此能力。
  故列表 widget 的可靠置底**仅 Android 12+ 支持**，11 及以下退化为状态块跟随内容。
- 经确认按 Android 12+ 实现。

## 本次修改

- 列表行布局 `app_widget_item_thing.xml` 内容列恢复为 `wrap_content`（11- 安全退化）。
- `AppWidgetHelper`：新增 `applyThingsListContentColumnHeight`，在 Android 12+ 用
  `setViewLayoutHeight` 把列表行内容列高度显式设为行高——侧栏模式用侧图槽高度、媒体背景
  模式用媒体背景行高（`WidgetMediaBackground.layoutMinHeight`）。内容列填满行高后，底部
  状态 spacer(weight=1) 即可把内联计数/音频/提醒/习惯顶到内容区底部。
- 单一记事 widget 不受影响（内容列随固定单元格高度填满，原本即可置底）。

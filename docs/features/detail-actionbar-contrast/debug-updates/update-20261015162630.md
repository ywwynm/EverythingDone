## 详情页顶部图标和波纹统一颜色（2026-10-15）

根据试用反馈，顶部按钮各自选择黑白显得杂乱，现改为返回、操作菜单和更多按钮统一使用同一种颜色，触摸波纹同步统一。

经本轮设计确认，综合各按钮下方的图片和背景内容，每个按钮等权，选择整体更清楚的黑色或白色。各按钮的图形样点先归一化，图标大小和采样数量不增加其权重；按钮之间的空白不参与判断。极端明暗分区时，少数按钮的对比度可能明显降低，这是统一颜色的取舍。

`DetailToolbarContrast` 维护整排共同配色，通过 `MediaOverlayContrast.chooseEqualGroups()` 共同评分；菜单重建期间新按钮先使用现有共同颜色，后台结果同时应用至全部图标与波纹，避免短暂混色。继续沿用静态封面、随滚动更新、无媒体时响应记事颜色、轻微切换余量和波纹动画连续性。

35 项 JVM 回归通过；在 `3B1629006YC00000`、`R5CW20BLNKL` 各合并验证横竖屏，共 152 项检查通过，覆盖明暗分区、菜单重建、真实滚动、裁剪与撤销/重做、透明图片及记事改色、GIF/视频真实播放期间的稳定性。已有记事保持不变，40 条临时记事已清理，旋转设置已恢复。

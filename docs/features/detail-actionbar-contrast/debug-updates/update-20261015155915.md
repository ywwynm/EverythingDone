## 详情页顶部按钮随媒体明暗动态换色（2026-10-15）

详情页顶部返回、操作菜单和更多按钮现在会根据各自下方的图片内容，在滚动中独立选择黑色或白色，触摸波纹同步换色。图片离开按钮区域后，继续跟随记事背景颜色变化；透明图片及顶部覆盖层也参与合成判断。

根据本轮设计确认，沿用附件的静态封面：GIF、动态照片和视频播放帧变化不触发换色，页面滚动仍持续更新取样位置。临界区域保留当前颜色，另一种明显更清楚时立即切换，不设置固定延迟，也不等待滚动停止。

新增 `DetailToolbarContrast` 复用 `DetailMediaOverlayColors` 的静态小图和图形样点，后台计算局部对比度；`DetailActivity` 在菜单重建、改色及销毁时更新控制器。裁剪、比例、选帧和媒体加载完成均会刷新。`GradientRippleDrawable` 原位换色，保留正在进行的按压动画。

32 项 JVM 回归通过；在 `3B1629006YC00000`、`R5CW20BLNKL` 完成横竖屏、明暗分区图片、真实滚动、离开媒体、改色、裁剪及撤销/重做、菜单重建、网格和真实播放验证。补充核验黑白图标及波纹显示，已有记事保持不变，临时测试记事已清理。配色主线程准备及应用 P95 为 0.715–1.003 毫秒，此数值不代表整页帧耗时。

OPPO 原有的 16 KB 原生库兼容性提示已单独记录；本次未调整原生库，也不包含系统状态栏图标配色。

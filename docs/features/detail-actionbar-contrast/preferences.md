## 2026-10-15 — 根据按钮下方内容动态选择明暗

- 用户通过 `grill-me` 发起设计讨论，问题逐个确认；代码可以回答的内容先核对代码。
- 首版顶部操作栏图标根据各自下方的图片内容独立选择偏白或偏黑；逐按钮独立配色已被上方最新反馈取代。页面滚动过程中动态更新、不能只在初始化时设置一次的要求仍有效。
- 触摸波纹也要随背景内容调整明暗。
- 按钮下方没有图片内容时，继续根据记事颜色选择明暗，并响应记事颜色变化。
- 可在 `3B1629006YC00000`、`R5CW20BLNKL` 上验证与测试；此授权不延伸至其他设备。
- 用户确认沿用静态封面规则：滚动时持续更新按钮对应的取样位置，GIF、动态照片和视频的播放帧变化不触发配色更新。
- 用户接受轻微的切换余量：两种颜色的可辨认程度接近时保持当前颜色，另一种明显更清楚时立即切换，波纹同步更新；不设置固定等待时间，也不等待滚动结束。

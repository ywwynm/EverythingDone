# 顶部按钮统一颜色修订

状态：实现及本轮回归完成，debug `202610150828` 已发布、校验并安装到两台指定设备，用户已确认提交。

## 反馈与决定

用户试用首版后认为各按钮独立黑白配色显得杂乱，要求整排统一。通过 `grill-me` 确认，综合所有按钮下方的内容、每个按钮等权，选择整体更清楚的黑色或白色；接受少数位置在明暗冲突时有所取舍。

静态封面、随滚动更新、无媒体时跟随记事色、轻微切换余量和波纹同步继续有效。

## 实施要点

- 各按钮图形样点内部归一化后共同评分，图形大小和样点数量不改变按钮权重。
- 整排仅维护一个黑白状态，包括没有媒体覆盖的按钮；有媒体时按各位置实际合成背景评分，全部没有可见媒体时按记事色回退。
- 新菜单按钮先使用现有共同颜色，后台结果同次应用至全部按钮和波纹，避免等待时出现混色。
- 只调整顶部按钮的共同选择，不改变附件标记原有的独立配色算法。

## 验证安排

- JVM 验证按钮等权、样点数量不改变决定、透明无效样点及共同切换余量。
- 更新真机探针，明暗分区场景由“左右不同色”改为“整体选择同色”，检查真实滚动和菜单重建期间的全排一致性，以及记事改色和媒体退场。
- 两台已授权设备各合并横竖屏验证；沿用原有测试数据清理、旋转恢复及截图限制。发布前写本轮独立中文更新日志。

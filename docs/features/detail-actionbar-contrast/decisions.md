# 详情页顶部按钮配色决定

## 2026-10-15 — 所有顶部按钮统一黑白

- 用户反馈首版逐按钮独立配色显得杂乱，要求返回、操作菜单及更多按钮统一使用同一种颜色；波纹同步统一。
- 用户确认综合各按钮下方的内容，每个按钮等权，以整体可辨认程度决定黑白；按钮之间的空白不参与评分。按钮图形的大小、有效样点数不会增加该按钮的总体权重。
- 有部分按钮下方没有媒体时，这些按钮仍按实际合成背景参与共同评分；所有按钮下方均无可见媒体时，统一沿用记事背景明暗规则。
- 切换余量作用于整排按钮的共同结果。新菜单按钮在后台计算期间沿用当前共同颜色，避免菜单重建或图片异步就绪的过程中短暂混色。

## 2026-10-15 — 首版实施参数与背景合成

- 在逐按钮图形样点上合成静态图片、记事底色和现有顶部覆盖层。完全透明媒体或完全被操作栏背景覆盖时，沿用记事背景的前景规则。
- 滚动切换余量采用覆盖率优势 6 个百分点；覆盖率相同则要求对比度几何平均值优势达到 12%。这是已验证的工程参数，后续根据明确问题再调整。
- 图标与波纹同次应用结果；波纹保留现有半径与黑白透明度，通过原位换色保留触摸动画进度。播放画面不进入配色状态比较。

## 2026-10-15 — 滚动换色加入轻微余量

- 用户接受在黑白两种候选的局部可辨认程度接近时保持当前颜色，另一种明显更清楚时立即切换；图标与触摸波纹同步更新。
- 不设置固定等待时间，不等待滚动结束，避免因定时延迟造成配色落后于滚动。
- 用户接受上滑与下滑在临界区域的切换位置略有不同，以减少细碎纹理导致的黑白往返。具体余量通过样图和实机验证确定，不预先承诺未经测量的参数。

## 2026-10-15 — 静态封面随滚动更新

- 用户选择沿用既有附件的静态封面规则。顶部按钮根据当前滚动位置映射至静态封面的局部区域，更新图标与触摸波纹的黑白选择。
- 页面停住后，GIF、动态照片和视频播放帧变化不触发取样或换色；不引入播放期定时检测。
- 静态封面本身、裁剪、显示比例或布局变化仍需要刷新取样依据，不能把“播放期固定”理解成仅在页面初始化时计算一次。

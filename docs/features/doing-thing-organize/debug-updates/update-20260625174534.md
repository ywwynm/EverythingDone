# 回退右滑限制 + DoingActivity 打开时用最新数据渲染

## 主要改动
1. 回退上一版"已有正在做时禁止右滑开始做另一件"：原本"开始做另一件事（可切换）"是预期行为，
   是之前理解有误。已恢复原逻辑并移除新增字符串。
2. 对正在做的记事调整卡片外观后，数据确实已写库，但 DoingActivity（计时界面）此前一直沿用
   Service 在开始计时时持有的旧 Thing 对象，外观 / 内容改动不生效。现在打开 DoingActivity 时
   用数据库最新数据覆盖渲染：
   - 全新打开（`initAfterBindService`）：取到 Service 的 Thing 后，按 id 用数据库最新数据覆盖再渲染。
   - 已存活被重新带到前台（`singleTask` → 新增 `onNewIntent`，点击卡片 / 通知 / 小组件均经此）：
     重新取当前正在做的 Thing（兼容切换到另一件），同样用数据库最新数据覆盖并重渲染卡片。
   计时状态由 Service 维护、与 Thing 对象无关，故只替换渲染用数据，不影响计时与动画。

## 验证重点
1. 已有正在做时，右滑另一件记事：仍能进入"开始做事"（可切换），与之前一致。
2. 对正在做的记事改卡片外观（如换 span / 媒体位置 / 颜色），确定后：
   - 点击该记事卡片进入 DoingActivity，界面用最新外观渲染；
   - 通过正在做通知 / 小组件进入 DoingActivity，同样是最新外观；
   - 若 DoingActivity 已在后台存活，再次进入也应是最新外观（不再是旧样子）。
3. 计时数字、背景动画、底部按钮等不受影响，计时不中断。

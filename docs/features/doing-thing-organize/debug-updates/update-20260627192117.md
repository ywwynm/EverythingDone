# 修复：DoingActivity 里文件夹内置顶记事的置顶标识颜色

## 主要改动

- 在"正在做"界面（DoingActivity），置顶记事右上角的置顶标识颜色现在与首页一致：
  - 文件夹内的置顶记事 → 用**所属父文件夹的颜色**（此前错误地显示成黄色原图）。
  - 根目录下的置顶记事 → 仍是 accent+accent2 渐变（本就如此，未改）。
- 原因：置顶标识着色与首页共用同一段逻辑，但"取父文件夹颜色"那一步需要适配器提供父文件夹背景，
  DoingActivity 的适配器之前没提供，导致文件夹内置顶退化成默认黄色。现已补上。

## 验证重点

1. 把一个**在文件夹里**的记事置顶并开始做：DoingActivity 右上角置顶标识为该文件夹的颜色。
2. 把一个**根目录**的记事置顶并开始做：置顶标识为 accent+accent2 渐变（不回退）。

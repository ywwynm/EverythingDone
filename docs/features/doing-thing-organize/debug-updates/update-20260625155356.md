# 正在做的记事可拖拽 / 移动 / 选中，并修复相关问题

## 主要改动
- 放开"正在做"的记事在首页的组织能力，使它与普通正在进行记事一致：
  - 长按可进入拖拽，重排到不同列表位置；
  - 可拖到别的记事上建夹、拖入已有文件夹，别的记事也可拖到它上面建夹；
  - 可在选择模式被点选 / 全选，并用工具栏"移动到文件夹"移动。
  - 移动 / 重排不会打断计时。
- 保护：完成 / 删除 / 设为私密都不作用于正在做的记事。无论它是被直接选中、还是在
  被选中文件夹（含多层子文件夹）里被递归命中，都会跳过它；完成 / 删除的确认弹窗按
  扣除后的数量显示，并标注"不含正在做的记事"；设为私密会提示"正在做的记事未设为私密"。
- 修复：进入选择模式时正在做的记事卡片有时被撑高（蒙层不再用旧高度设固定尺寸，改为
  跟随卡片最终高度）。
- 修复：此前"全选"能选中正在做的记事而点按不能的不一致（现统一为可选中）。
- 修复：此前选中含正在做记事的文件夹做"完成 / 删除文件夹中所有记事"会真的把它改成
  已完成 / 删除却不停计时；现已跳过。
- 卡片外观对正在做的记事开放编辑：编辑期间临时隐藏"正在做"蒙层以免遮挡预览，关闭后
  按最终外观恢复蒙层。

## 验证重点
1. 长按正在做的记事：能拖拽重排、拖入文件夹、与别的记事互相建夹；全程计时不中断。
2. 选中正在做的记事 → "移动到文件夹"：能移动到目标文件夹，计时不中断。
3. 点按、"全选"都能选中正在做的记事；正常模式点按它仍打开计时界面。
4. 选中含正在做记事的一批（或含它的文件夹）做完成 / 删除：弹窗数量不含它、并写明
   "不含正在做的记事"，确认后它仍在计时、状态未变。
5. 文件夹内"完成 / 删除文件夹中所有记事"、根目录"全部完成"：同样跳过并提示正在做的记事。
6. 选中含正在做记事做"设为私密"：跳过它并提示"正在做的记事未设为私密"。
7. 对正在做的记事打开卡片外观面板：编辑时看得见外观（蒙层让位），确认 / 取消后蒙层
   恢复且卡片高度正常、不被撑高。

# 微调：正在做蒙层未选中淡化别太透 + 窄缩略图蒙层不变形

## 主要改动
1. 选择模式下未选中的正在做记事，蒙层之前直接套用了普通内容的淡化透明度（0.32 / 0.64），
   太透、盖不住下层内容。改为蒙层专用的轻微淡化（0.8），既能区分选中 / 未选中，又仍能盖住
   下层内容。
2. 大文件夹缩略图里的正在做记事，之前"正在做"图标与文字只按卡片高度缩放，当预览卡宽 < 高
   时图标会贴左边、文字被迫换行，不是正常列表样子的缩小版。现在缩放同时受宽度约束：让
   "图标 + 间距 + 文字"在卡片宽度内一行放下、不贴边（取高度缩放与宽度缩放的较小者），并固定
   单行，使其始终是正常样子的等比缩小版。正常列表（宽度充足）行为不变。

## 验证重点
1. 选择模式下，未选中的正在做记事：蒙层仍能盖住下层内容，只是略微变淡；选中后恢复全黑。
2. 大文件夹缩略图里有正在做的记事、且该预览卡较窄（宽 < 高）时：图标不贴左边、文字不换行，
   蒙层是正常列表里样子的等比缩小版。
3. 缩略图里较宽 / 较矮的正在做预览卡，以及正常列表里的正在做记事，蒙层外观不回退。

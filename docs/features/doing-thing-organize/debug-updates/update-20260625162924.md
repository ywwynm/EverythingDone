# 修复：正在做蒙层尺寸不对（上一版回归）

## 主要改动
- 上一版为修"撑高"把蒙层固定尺寸整个去掉、改成完全依赖 match_parent，结果在这个
  RecyclerView 下因 EXACTLY 测量规格使 match_parent 退化成内容大小，导致蒙层在普通
  显示和右滑预览时铺不满卡片（尺寸偏小）。
- 改回"把蒙层钉成与卡片等大的固定尺寸"以保证铺满；同时用正确方式规避原来的撑高：
  - 卡片已稳定布局（`height>0 且无挂起布局`）时，直接按当前高度钉尺寸 + 缩放；
  - 复用 / 内容变更后将重新布局时，先把蒙层恢复成 match_parent（避免复用时残留的旧
    固定高度把卡片撑高），等卡片按真实内容布局后再钉成与卡片等大的固定尺寸。
- 右滑预览路径恢复按当前高度钉尺寸（卡片此时已布局，尺寸正确）。

## 验证重点
1. 普通列表里正在做的记事：蒙层铺满整张卡片，不偏小、不撑高。
2. 右滑其它记事预览"正在做"蒙层：蒙层铺满被滑卡片，大小正确。
3. 进入选择模式：正在做的记事卡片不被撑高，蒙层仍铺满。
4. 不同高度的卡片（短卡 / 长卡 / 带图）滚动复用后，蒙层尺寸与图标/文字缩放都正确。
5. 对正在做的记事编辑卡片外观后关闭：蒙层按新外观铺满、不撑高。

# 修复：缩略图正在做蒙层闪烁 + 已有正在做时禁止右滑开始做另一件

## 主要改动
1. 拖正在做的记事进大文件夹后，缩略图里它的"正在做"蒙层会闪一下：根因是缩略图预览卡不走
   正常列表的测量时机，`updateCardForDoing` 里 `post` 的蒙层图标 / 文字缩放在首帧之后才执行、
   改了一次尺寸。现在创建预览卡时按已知的预览宽度同步测量并立即定好蒙层缩放，使首帧即为最终
   尺寸，不再闪。
2. 全局只能有一个正在做的记事：之前已有正在做时，右滑其它记事仍会打开"开始做事"的对话框
   （可切换）。现改为——已有正在做时，右滑其它记事直接提示"您正在做另一件事"，不打开对话框。
   右滑正在做的那件本身仍提示"您正在做这件事"；没有正在做时右滑才进入开始做事。

## 验证重点
1. 把正在做的记事拖进大文件夹，观察缩略图里它出现时蒙层不再闪烁，图标 / 文字一上来就是
   正常列表样子的等比缩小版。
2. 有正在做的记事时，右滑另一件记事：弹"您正在做另一件事"，不进入开始做事对话框。
3. 没有正在做时，右滑记事仍能正常进入开始做事；右滑正在做的那件仍提示"您正在做这件事"。

## 备注
本次只拦截了"右滑开始做"这条路径。`StartDoingActivity` 经其它入口进入时仍保留"停止当前、
开始这件"的切换确认逻辑（未改动）。若也要禁止该切换，请告知。

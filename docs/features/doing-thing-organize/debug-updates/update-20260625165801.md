# 修复正在做记事的 5 个问题（蒙层铺满 / 淡化 / 菜单 / 外观预览 / 文案括号）

## 主要改动
1. 蒙层尺寸彻底修对：改为在 `InterceptTouchCardView.onMeasure` 里，于卡片尺寸确定后把可见的
   "正在做"蒙层按卡片最终内容区强制重测铺满（此 RecyclerView 下 FrameLayout 的 match_parent
   第二趟测量不一定触发，纯 match_parent 会退化成内容大小）。因为发生在卡片自身测量之后，
   既不会撑高卡片，也不会有"先小后大"的闪烁；进入拖拽生成的 overlay 位图、退出选择模式时的
   重绑都拿到铺满的蒙层。移除了之前 bind / 右滑里手动钉固定 px 的写法。
2. 选择模式下淡化：未选中的正在做记事，其蒙层（含图标、文字）随其它内容一起按未选中透明度
   淡化，使选中 / 未选中可区分。
3. 选择模式下若只选中了一件正在做的记事，工具栏隐藏"完成 / 删除 / 设为私密"（对它本就无效）；
   移动到文件夹、置顶、卡片外观、导出仍可用。其它选中情况照常显示这三项。
4. 调整正在做记事卡片外观时，蒙层不再消失：外观是实时预览、点确定才应用，预览过程中一直保留
   "正在做"蒙层（撤销之前编辑期隐藏蒙层的做法）。
5. 多选批量确认弹窗里，"不含正在做的记事"不再单独再加一对括号：当同时有"包含所有子文件夹中
   的记事"提示时，合并进同一对括号，避免出现连续两个括号。

## 验证重点
1. 普通列表、右滑预览、进入选择模式、长按拖拽（含 overlay）下，正在做蒙层都铺满整张卡片，
   不偏小、不撑高、不闪烁。
2. 选择模式下选中 / 未选中正在做的记事，蒙层明显有淡化差异。
3. 只选中一件正在做的记事：看不到完成 / 删除 / 设为私密；能看到移动到文件夹 / 置顶 / 卡片外观 /
   导出。再加选其它记事后，三项恢复显示。
4. 对正在做的记事调整卡片外观：预览全程都带着正在做蒙层，确定 / 取消后蒙层仍正确铺满。
5. 选中含正在做记事、且命中子文件夹时，确认弹窗为单括号："……（包含所有子文件夹中的记事，
   不含正在做的记事）"。

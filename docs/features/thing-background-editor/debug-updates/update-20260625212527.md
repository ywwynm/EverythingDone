# 颜色编辑器测试反馈修正（tab/title/图标/颜色条/滚动/边距）

这次 debug update 处理上一版 Thing Background 编辑器的 6 点测试反馈：

- **选项卡样式**：纯色/渐变 tab 不再用原生 TabLayout——改为自定义 TextView，触摸是胶囊型
  ripple、无下划线；选中态的 tab 文本用当前实际选中的颜色着色（渐变则用渐变着色）。
- **标题跟随颜色**：详情 BottomSheet 与首页颜色页的"调整颜色"标题文本，会随当前选中颜色实时着色。
- **图标重设计**：随机取色改为骰子图标；从世界取色改为地球(globe)图标，突出"从世界取色"语义。
- **颜色条 handle 不再被裁切**：颜色条两端内缩量加上描边宽度，handle 圆圈（含外圈）移到最右端也完整可见。
- **可滚动**：新增限高滚动容器，详情 BottomSheet 与首页颜色页都用它包裹编辑器；渐变页过高或软键盘
  弹出时内容可滚动，标题、取消/确认等固定元素留在滚动区域之外。
- **详情面板边距与最大宽度**：详情页颜色 BottomSheet 像首页卡片外观面板一样左右留边距、设最大宽度，
  居中显示，适配平板。

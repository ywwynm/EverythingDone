# 颜色面板键盘弹出时固定标题与按钮

## 用户反馈

在首页选择模式进入「调整记事/文件夹外观」后切到「调整颜色」，或在记事详情页点击调整颜色图标后，点 RGB/Hex 输入框弹出键盘时，颜色面板会因为屏幕高度不足而收缩并让中间内容区滚动。但标题区、取消/确定按钮区没有完整保留，滚动分割线位置也会显得异常；顶部的预置色或渐变方向圆形按钮还可能和标题/按钮区域重叠，甚至贴到面板边缘。

## 诊断

问题集中在 `ScrollAwareColumn` 的测量策略：旧实现先用父级给出的受限高度走一次普通 `LinearLayout` 测量，再根据已经被压缩过的结果去缩小中间 `NestedScrollView`。当软键盘触发 `adjustResize` 后，可用高度变小，这条路径无法可靠保证「固定区优先、中间区吃剩余高度」，从而让标题、底部操作区和滚动内容发生布局竞争。

另一个放大因素是滚动区没有显式声明裁剪边界，颜色编辑器顶部的圆形按钮在滚动区高度被压小时更容易产生越界显示。

## 修改

- 修改 `ScrollAwareColumn.kt`：先用不限高度的 spec 测出真实自然高度，再计算标题、分割线、底部按钮等固定区总高，把剩余高度精确分配给第一个可见的 `NestedScrollView`。
- 当没有可滚动子项时，`ScrollAwareColumn` 仍尊重父级给出的最大高度，避免影响普通外观设置页。
- 在 `fragment_thing_background_editor.xml` 和 `panel_thing_card_appearance.xml` 中显式让颜色编辑器的 `NestedScrollView` 裁剪子内容，避免预置色/方向按钮越界绘制到固定区域。

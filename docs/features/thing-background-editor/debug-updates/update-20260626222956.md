# 颜色面板滚动区裁剪与分割线间距修正

## 用户反馈

上一版发布后，颜色面板在键盘弹出时仍有两个问题：

- 标题下方分割线离标题太近，取消/确定按钮上方分割线离按钮也偏近；应参考 License dialog、选择应用语言 dialog 等现有样式。
- 中间滑动区域的内容仍会和标题、取消/确定按钮、上下分割线重叠，说明可滑动内容虽然被测成中间区域，但绘制时仍能显示到整个 panel 区域。

## 对照

- `fragment_license.xml`：标题下方分割线 `layout_marginTop="12dp"`；底部 action 按钮使用 `app_chrome_dialog_divided_action_row_margin_top`（8dp）。
- `fragment_chooser.xml`：选择应用语言使用 `ChooserDialogFragment`，同样是标题到上分割线 12dp、下分割线到 action row 8dp。

## 修改

- 将详情页颜色面板与首页外观颜色页的标题下分割线上间距改为 12dp。
- 将详情页颜色面板与首页外观面板底部 action row 的上间距统一改为 `app_chrome_dialog_divided_action_row_margin_top`。
- 在 `ScrollAwareColumn.drawChild()` 中对 `NestedScrollView` 子项做强制 `clipRect`，即使面板根节点为了其它子项 ripple/负边距保留 `clipChildren=false`，中间滚动内容也只能画在自己的中间区域内，不能再越界覆盖标题、分割线或取消/确定按钮。

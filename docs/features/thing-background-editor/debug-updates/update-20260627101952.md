# 短列表颜色面板下选中卡片顶部对齐修复

## 用户反馈

- 主页记事/文件夹混合列表 item 不多、不需要滑动时，选择一个 item 打开外观 panel，切换到调整颜色并点击 RGB/Hex `EditText`。
- 键盘弹出后，panel 中间区域变为可滑动，但混合列表没有把选中 item 滚动到 contextual actionbar 下方 16dp 处。

## 诊断

- 原有 `ensureThingCardAppearanceSelectedCardVisible()` 只保证选中 holder 完整可见。
- 短列表里选中 holder 通常已经绑定，如果它仍在可见区内，就不会走“贴近顶部”的定位路径。
- 短列表内容高度不足时，仅靠 `panelHeight + spacing` 的底部 padding 可能无法产生足够滚动余量，因此即使想把选中项顶边移到顶部目标位置，也没有可滚动空间。

## 实现

- `ThingsActivity` 将选中卡片的目标位置统一为 `RecyclerView.paddingTop + getThingCardListItemSpacingPx()`，对应 contextual actionbar 下方 16dp。
- panel 打开期间计算 RecyclerView 底部 padding 时，如果短列表内容高度不足，会根据选中项当前顶边到目标顶边的距离、以及已布局内容底部，额外补足底部 padding。
- `ensureThingCardAppearanceSelectedCardVisible()` 不再只做“完整可见”检查，而是始终尝试把选中卡片顶边对齐到目标位置。

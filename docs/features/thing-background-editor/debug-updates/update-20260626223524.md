# 首页颜色面板层级高于选择模式工具栏

## 用户反馈

首页选择模式里也可以打开调整记事/文件夹外观面板。在颜色编辑器的渐变页里，键盘弹出并触发中间区域滚动时，面板标题有时会被 contextual actionbar 挡住。用户判断可能是 panel 层级低于 contextual actionbar，并询问是否需要让 panel 更高。

## 诊断

`activity_things.xml` 原结构中，`panel_thing_card_appearance` 位于 `DrawerLayout` 内部的 `fl_things` 里，而 `include_contextual_toolbar_things` 是 `DrawerLayout` 后面的顶层 sibling。`panel` 自身的 `elevation=12dp` 只能在同一父级内参与 Z 排序，无法稳定压过另一个父级后绘制的 contextual toolbar。

直接抬高整个 `DrawerLayout` 不合适，因为那会把普通 actionbar、列表等也一起压到 contextual toolbar 上方。这个 panel 本身是浮层，更合理的位置是 activity 顶层，与 contextual toolbar 同父级。

## 修改

- 将 `panel_thing_card_appearance` 从 `fl_things` 内移出，放到 `activity_things.xml` 顶层，并排在 `include_contextual_toolbar_things` 之后。
- 面板仍保留原来的底部居中 `FrameLayout.LayoutParams`、宽度限制、底部 inset margin 和显示/隐藏逻辑；现有 `ThingsActivity` 代码无需改动。

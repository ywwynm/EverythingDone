# 主页/详情页颜色面板切换收起键盘与底部动画

## 用户反馈

- 主页颜色编辑器里，键盘打开后切换纯色/渐变 page、外观页/颜色页或切换到另一个记事/文件夹外观 panel 时，键盘不会自动消失。
- 主页“调整记事/文件夹外观”panel 和详情页“调整颜色”panel 的出现/消失都需要从屏幕下方升起、降落到屏幕下方。
- 用户已将主页 panel 为当前卡片保留的轻量可见高度调整为 `36dp`，本次修复保留该设定。

## 实现

- `ThingBackgroundEditor` 在纯色/渐变 tab 切换前调用 `KeyboardUtil.hideKeyboard`，让编辑器内部 page 切换先收起 RGB/Hex 输入键盘。
- `ThingsActivity` 在打开或切换主页记事/文件夹外观 panel、外观页与颜色页互切、隐藏 panel 时统一收起键盘。
- 主页 `panel_thing_card_appearance` 新增底部滑入/滑出动画：显示时从 panel 高度之外上移到原位，隐藏时降落到底部之外；使用 `mThingCardAppearancePanelVisibilityToken` 避免快速切换时旧动画结束回调影响新 panel。
- 主页 panel 隐藏时等滑出动画结束后再设为 `GONE` 并还原 RecyclerView 底部 padding，避免视觉上直接跳掉。
- 详情页 `ThingBackgroundEditorBottomSheet` 挂载新的 `EverythingDoneAnimationBottomPanel` window animation，并新增 `bottom_panel_slide_in.xml` / `bottom_panel_slide_out.xml`，让显示和 dismiss 都使用底部升降动画。

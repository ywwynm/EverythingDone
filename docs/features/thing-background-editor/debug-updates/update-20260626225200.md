# 首页颜色面板改为轻量卡片露出预留

## 用户反馈

上一版限制首页颜色面板最大高度时，思路仍偏向让当前卡片尽量完整可见。用户指出大多数情况下并不需要、也很难完整看到当前卡片；如果强行完整预留，颜色面板自身空间会被压缩得非常小，影响操作。

## 修改

- 继续保留 `panel_thing_card_appearance` 在 `fl_things` 内，避免把面板提升到 contextual toolbar 上方。
- 首页颜色面板最大高度仍由 `ScrollAwareColumn.maxMeasuredHeightPx` 控制，但卡片预留区改为固定轻量 peek：`thing_card_appearance_panel_card_peek_height`（88dp）+ 卡片间距。
- 删除未发布的“按当前 holder 实际高度 / 可用高度 45% 上限”预留逻辑，不再追求完整露出当前卡片。

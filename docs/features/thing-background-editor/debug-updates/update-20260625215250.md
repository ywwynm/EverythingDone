# 颜色面板展开/滚动行为修正 + 从世界取色图标重设计

这次 debug update 处理颜色编辑器的第二轮测试反馈：

- **从世界取色图标重设计**：改为"相机取景框四角 + 中心取色点"，兼具"眼前所见的世界"（取景框）
  与"取色"（中心采样点，且会被当前颜色 tint）双重含义。
- **详情页颜色面板不再是可拖拽的底部表单**：改为靠底部固定的对话框，打开即按内容**全部展开**，
  不需要再从底部上滑；切换 tab 也不会缩回屏幕底部。
- **渐变 tab 默认全展开**：不再默认进入"被裁切、需要上滑"的状态；只有在**软键盘弹出**、空间不足时，
  中间编辑器区域才变为可滚动，标题与取消/确定按钮始终固定，不与滚动内容重叠。
- **详情页补上取消/确定按钮**：取消 = 放弃本次改色、回到打开时的颜色（不记撤销）；确定 = 提交。
- **首页颜色页返回箭头跟随颜色**：返回 icon 现在会随当前选中颜色着色。
- **滚动分割线**：详情对话框与首页颜色页都在标题下方、取消/确定上方各加一条分割线，按滚动情况显隐
  （到顶隐藏顶部线、到底隐藏底部线、不可滚动时都不显示），与选择应用语言、许可证等 dialog 一致。

# 重构改变记事颜色的编辑器（纯色/渐变 + 颜色条 + RGB/Hex）

这次 debug update 把详情页和首页"调整记事卡片外观"面板里改变记事颜色的
ColorPicker 全面重构为新的 Thing Background 编辑器（搜索界面的色相筛选不变）。

- **纯色 / 渐变两个选项卡**：直接对应 Thing 的纯色或渐变背景。切换选项卡会实时预览，
  且会话内分别记住纯色与渐变两套工作态，来回切换不会重新随机。
- **颜色条（难点）**：一条"黑 → 全色相彩虹 → 白"的颜色条，几乎涵盖所有颜色（含黑白）。
  可拖拽 handle 取色，handle 圆点内部实时显示当前真实颜色；任意来源的颜色都会把
  handle 移到最近位置。
- **RGB / Hex 一行输入**：颜色条下方一行并排 R / G / B 与 Hex(`#RRGGBB`) 输入框，
  实时联动——改任一项都会同步其余项、颜色条 handle 和记事背景。
- **随机取色 / 从世界取色**：颜色条右侧两个图标，分别随机取色和用相机从世界取色，
  取到的颜色会实时更新颜色条、输入框，并 tint 这两个图标。渐变页两个色区各自独立。
- **纯色页顶部 10 个预置色**（两行各 5 个圆形按钮，触摸 ripple、选中打对号）；
  **渐变页顶部 8 个渐变方向**（两行各 4 个，实时显示当前两色的小渐变预览、选中打对号），
  下方是分别表示渐变两端的两个色区。
- **承载方式**：详情页用底部 BottomSheet（淡遮罩，背后记事背景实时可见）；
  首页"调整记事卡片外观"面板内**就地切换**为颜色页，左上返回箭头回到外观设置，
  面板底部取消/确认照旧贯穿整个会话，不再额外弹出面板。
- 详情页改色一次会话只记一条撤销；从世界取色确认后回流到编辑器、不再单独记撤销。
- 控件间距尺寸统一在 XML / dimens 设置；同时移除已并入渐变页的独立渐变方向对话框。

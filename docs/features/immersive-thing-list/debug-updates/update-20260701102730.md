# 沉浸式记事列表：状态栏与 actionbar 连体 ＋ 进入选择直接显示 contextual

## 主要改动
- 状态栏占位与 actionbar 改为"连体"：二者同为不透明、同色（surface 色），一起随滚动上移隐藏、下移回落。上滑显示 actionbar 时，其上方状态栏也一并是实心底色，不再透出卡片、不再割裂。注意：完全沉浸时系统状态栏图标会落在裸卡片上、没有遮罩保护——先按"连体"优先，图标可读性若需要后续再单独处理。
- 进入选择模式改为直接显示 contextual toolbar：进入时整体隐藏 home 顶部 chrome（状态栏占位＋actionbar＋标题），contextual toolbar 从顶部滑入过程不再先露出 home actionbar；退出选择时随 contextual 滑出恢复。去掉了之前"进入选择先把隐藏的 actionbar 弹出来"的多余动画。

## 验证重点
1. 沉浸后上滑：actionbar 与其上方状态栏是一整块实心底色一起下移出现，不透卡片、无割裂。
2. 继续下滑：状态栏底色与 actionbar 一起上移隐藏，卡片铺到最顶。
3. 进入选择模式：只有 contextual toolbar（含其状态栏占位）从顶部滑入，不再先闪现 home actionbar。
4. 退出选择：contextual 滑出、home 顶栏恢复为显示。
5. 换文件夹/换状态/搜索进出后，顶栏状态正常。

# 修复多行文件夹标题的折叠间距与文件夹名输入框下划线

## 主要改动
- 打开名字较长（标题占多行）的文件夹后上滑：文件夹标题归位到 actionbar 时，第一张记事/文件夹卡片与 actionbar 的间距现在和单行标题时一致，不再随标题行数增大而越拉越远。折叠滚动距离改为跟随 header 高度（= header spacer 高 − 固定余量），标题归位与卡片贴齐始终对齐；沉浸式（收起 actionbar）也随之在卡片真正贴齐后才触发，不再提前。
- 调整文件夹外观的面板中，修改文件夹名称的输入框：输入很长文本时，下方那条彩色下划线不再跟着文字往左跑，始终贴在输入框可见范围内（同一修复也覆盖其他带此下划线的输入框，如新建/重命名文件夹弹窗、录音命名等）。

## 验证重点
1. 建一个名字很长的文件夹（标题在标题区占 2~4 行），进入后上滑：标题缩小归位到 actionbar 正中时，第一张卡片离 actionbar 的距离应与普通单行标题文件夹一致（不再多出一大段空白）；标题行数越多也应保持一致。
2. 继续上滑进入沉浸态：顶栏应在卡片贴齐 actionbar 之后才开始收起，过程连贯；上滑回落、松手吸附、返回上一级保留沉浸态等行为不受影响。
3. 单行标题的文件夹、以及"全部/已完成/已删除"根列表：折叠与沉浸行为应与之前完全一致（无回归）。
4. 打开某文件夹的"调整外观"面板，在名称输入框里输入超过一行宽度的长文本：光标滚动时，输入框下方的彩色下划线应保持不动、贴合输入框，不再向左偏移。
5. 新建文件夹 / 重命名文件夹弹窗、录音命名等带彩色下划线的输入框，输入长文本时同样应正常。

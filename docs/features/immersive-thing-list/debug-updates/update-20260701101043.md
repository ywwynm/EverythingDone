# 沉浸式记事列表：修复状态栏遮罩过大 ＋ actionbar 透明

## 主要改动
- 修复状态栏保护罩几乎覆盖大半屏、且静止态就显示的问题：根因是 `view_status_bar` 作为 DrawerLayout 的内容子 View 被强制测量成整屏高。已把它移进 `fl_things`，高度回到状态栏高；静止态它罩在同色 surface 上、本就不可见，只有卡片滑到状态栏之下时才起保护作用。
- 修复进入沉浸后上滑让 actionbar 露出时透出卡片的问题：给 actionbar 设了与状态栏/列表同色的不透明背景——显示时是实心栏、隐藏时随之上移滑走，不再透出其下卡片。

## 验证重点
1. 静止态（列表顶部）：状态栏区域干净、无可见遮罩；actionbar 是实心栏。
2. 下滑折叠→继续下滑：actionbar 连续上移隐藏、卡片铺满上下；上滑露出的 actionbar 是实心的、不透卡片。
3. 深色/高饱和卡片滑到状态栏之下：图标可读（scrim 现在只在状态栏高度范围内）。
4. 打开文件夹后同色不透明规则一致；换状态/抽屉切换后顶栏复位为显示。

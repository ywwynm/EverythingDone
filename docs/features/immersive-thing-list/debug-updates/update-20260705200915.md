# 调整首页选择模式入场动画

## 本次修复

- 修正上一版对旧 home actionbar 阴影的处理方式：不再在所有场景下进入选择模式前立即隐藏旧 actionbar / 阴影。
- 当首页沉浸式列表中 home actionbar 已经完全回落、且下方阴影可见时，长按记事进入选择模式会让 contextual toolbar 直接从顶部滑下盖住它；等 contextual toolbar 入场完成后，再隐藏底下的 home chrome 和旧阴影，最终只保留 contextual toolbar 自己的阴影。
- 如果进入选择时 home chrome 仍隐藏或半隐藏，则继续直接隐藏 home chrome，避免它为了选择模式入场先弹出来。

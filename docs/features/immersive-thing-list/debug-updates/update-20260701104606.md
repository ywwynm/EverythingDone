# 沉浸式记事列表：完全沉浸态叠加独立状态栏保护罩

## 主要改动
- 只在完全沉浸态（顶栏完全收起）下，状态栏区域叠加一层独立的保护罩，让系统图标落在裸卡片上时仍可读。实现上用层叠顺序：保护罩固定在列表之上、连体顶栏之下——显示/静止态被不透明的连体状态栏底色盖住、天然不可见，顶栏收起后才露出，所以无需透明度动画。连体顶栏（状态栏底色＋actionbar）行为不变，仍一起隐现。

## 验证重点
1. 列表顶部/显示 actionbar 时：状态栏是干净的连体实心底色，看不到保护罩。
2. 继续下滑到完全沉浸（顶栏全收起）：状态栏区域出现一层淡淡的保护渐变，深色/高饱和卡片下系统图标可读。
3. 沉浸中上滑：顶栏（连体底色＋actionbar）下移出现的同时，保护罩被重新盖住、消失。
4. 进入/退出选择模式：只有 contextual toolbar 一段动画，顶部不闪保护罩、不闪 home actionbar。

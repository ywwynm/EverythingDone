# 统一 actionbar 到第一张卡片的间距为 16dp

## 主要改动
- 统一"actionbar 底部到第一张记事/文件夹卡片"的间距为 16dp（与卡片之间的间距一致）：搜索态停在顶部、以及非搜索折叠态（标题归位到 actionbar 时）都一致。此前搜索态约 14dp、非搜索折叠那一刻约 20dp，二者不一致且后者比卡片间距大。
- 实现：卡片自带 8dp 上边距；非搜索折叠余量 `TITLE_DOCK_RESIDUAL_DP` 由 12dp 改为 8dp（8+8=16dp），搜索态 header spacer 由 6dp 改为 8dp（8+8=16dp）。两处都由同一个 8dp（`thing_card_outer_spacing`）单位推导。多行标题下折叠态间距同样恒为 16dp。

## 验证重点
1. 普通列表下滑，标题缩小归位到 actionbar 的那一刻：第一张卡片到 actionbar 底的间距应≈16dp，和卡片之间的间距看起来一致，不再偏大。
2. 点搜索停在顶部：第一张结果卡片到 actionbar 底的间距应也≈16dp，与非搜索折叠态一致（此前偏小）。
3. 名字多行的文件夹：折叠态该间距同样应≈16dp，不随标题行数变化。
4. 继续上滑进入沉浸态、阴影淡入过程应连贯（淡入区间由 12dp 变 8dp，仍平滑）；沉浸触发时机、松手吸附等不受影响。

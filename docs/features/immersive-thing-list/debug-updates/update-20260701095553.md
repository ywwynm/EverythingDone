# 沉浸式记事列表（Immersive Thing List）首个可测版本

## 主要改动
- 记事列表加入 edge-to-edge：Activity Header 折叠进 actionbar 之后继续下滑，顶部（状态栏底色＋actionbar）一起上移隐藏，卡片从状态栏一直铺到导航栏；上滑即按滚动量回落，松手吸附到全显示 / 全隐藏。仅正常、moving 模式生效，选择、搜索模式不生效；打开文件夹后同样支持。
- 状态栏改为保护性渐变罩：卡片从状态栏之下透出，同时时钟 / 电量 / 信号图标在任意卡片颜色下保持可读。
- 复位策略：切换范围 / 换状态 / 开关文件夹 / 进出选择或搜索都复位为"显示"；原地完成、删除、恢复单项则保留当前沉浸态、顶栏不弹回。卡片外观编辑面板打开时挂起沉浸。

## 验证重点
1. 从顶部下滑：大标题折叠进 actionbar 的时机、幅度与之前一致；静止态与之前一致，无首帧跳变。
2. 折叠后继续下滑：actionbar 连续上移隐藏、卡片铺满上下；上滑一下即回落；松手吸附到全显示 / 全隐藏。
3. 深色 / 高饱和卡片滑到状态栏之下：系统图标是否清晰（scrim 浓淡可反馈再调）。
4. 选择模式、搜索模式下不进入沉浸（顶栏常规显示）。
5. 打开文件夹后的列表同样能沉浸；返回、换状态、抽屉切换后顶栏复位为显示。
6. 滑到深处 swipe 完成 / 删除一项：顶栏保持隐藏、不弹回。
7. 横屏 / 平板下折叠与隐藏几何正常。

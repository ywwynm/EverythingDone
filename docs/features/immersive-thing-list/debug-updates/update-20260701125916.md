# 修复：点击搜索时列表自动滚到底部

## 主要改动
- 记事列表停在顶部（未滑动）时点击搜索按钮，列表会莫名自动滚到底部——已修复。进入搜索现在稳定复位到顶部，与退出搜索的行为一致。
- 根因：进入搜索时用 `scrollBy(0, Int.MIN_VALUE)`（想一次滚到顶），但 `LinearLayoutManager` 内部 `Math.abs(Int.MIN_VALUE)` 会整数溢出仍为负，触发子项天量位移；沉浸式改了列表 padding/布局后就表现为滚到底部。改用 `scrollToPosition(0)`。

## 验证重点
1. 在"全部记事"根列表顶部（不滑动）点击搜索：列表应停在顶部、正常进入搜索输入态，不再跳到底部。
2. 先向下滑动一段再点搜索：进入搜索后同样应复位到顶部显示结果。
3. 进入文件夹后点搜索、以及在搜索结果里返回：滚动位置与搜索进入/退出行为应正常，无跳动。
4. 退出搜索回到普通列表：仍复位到顶部（原有行为不变）。

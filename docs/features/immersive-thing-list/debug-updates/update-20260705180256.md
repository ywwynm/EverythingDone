# 修复文件夹默认页顶部背景分界线

## 本次修复

- 修复打开文件夹后默认状态下，statusbar、actionbar、记事列表之间出现两条分界线的问题。
- 根因是沉浸式首页布局中，文件夹的淡色页面背景分别应用到了 `fl_things`、`view_status_bar`、`actionbar` 三个 View。纯色文件夹不明显，但渐变文件夹会让三段背景各自从自身顶部重新开始绘制，于是交界处出现色差。
- 现在 `fl_things` 仍绘制整屏的淡文件夹 surface；`view_status_bar` 和 `actionbar` 改为绘制这张整屏 surface 在自身位置上的切片。这样顶部三块在默认状态下会像同一张背景，不再有 statusbar/actionbar 与 actionbar/list 的分界线。
- 纯色文件夹仍走原有纯色背景路径；`actionbar_shadow` 的折叠后阴影逻辑没有改变。

## 选择模式不再隐藏 Activity Header

本次更新修正 Immersive Thing List 选择模式入场时的顶部标题显示范围。

用户反馈：长按记事出现 contextual toolbar 时，Activity Header 也会一起消失。检查后确认，上一轮为了避免旧
home actionbar 和旧阴影残留，复用了 `ActivityHeader.setHomeChromeVisible(false)`；但该方法同时隐藏了
`rl_header`，导致展开态或半展开态的 Activity Header 在进入选择模式时突然不可见。

已将该方法收窄并重命名为 `setHomeToolbarChromeVisible()`：进入选择模式时只隐藏
`view_status_bar`、`view_status_bar_scrim` 与 `actionbar`，不再隐藏 Activity Header 本体。若标题已经折叠到
顶部区域，则由 contextual toolbar 的层级自然覆盖；若标题仍处于展开态，则保持可见，不会因长按进入选择而突然消失。

验证：`:app:assembleDebug` 已通过。未使用 adb，需通过 debug 更新在真机上确认长按进入选择模式时 Activity Header 的可见性和 contextual toolbar 入场动画。

## 选择模式 actionbar 阴影统一

本次更新继续调整 Immersive Thing List 下的选择模式入场体验。

用户反馈 contextual actionbar 的阴影看起来比正常 actionbar 更淡。检查后确认二者虽然都使用
`@drawable/actionbar_shadow`，但正常 home actionbar 阴影高度为 `4dp`，运行时完全显示时 alpha 为
`1.0`；而 contextual actionbar 阴影此前高度为 `5dp`，并固定 `alpha=0.6`，因此视觉上更淡、更散。

已将 `app/src/main/res/layout/include_contextual_toolbar_things.xml` 中 contextual actionbar 的阴影改为
与正常 actionbar 一致：高度 `4dp`，不再额外设置 `alpha=0.6`，继续复用同一个
`@drawable/actionbar_shadow`。这样在从已显示且带阴影的 home actionbar 覆盖进入选择模式时，阴影强度不会发生明显跳变。

验证：`:app:assembleDebug` 已通过。未使用 adb，仍需通过 debug 更新在真机上确认选择模式入场动画中的阴影连续性。

# 实现决策

## 2026-10-19：菜单移除方向与无触点弹窗统一

- 用户确认单选／批量完成、删除、恢复、彻底删除导致的卡片退场，每次等概率选择左上 45° 或正上方，覆盖记事、文件夹及混合选择。
- 同一批可见卡片仍合成一份材料，共用一次随机方向；真实左右滑动完成仍沿水平方向。
- 三台指定设备验证必须保护真实记事；虚构列表调用生产移除控制器，真实业务菜单只在独立测试包的测试数据上执行。

## 2026-09-18 顶栏与半透明前景

- 菜单移除、左滑及回聚共用首页遮挡定义：不透明 actionbar 主体参与素材裁切；半透明阴影只作为固定前景，不裁掉其下的材料。
- 扩展已有 FAB 的 Surface 同步交接为 `ParticleForegroundSurface`，按首页既有顺序接管顶栏、标题、模拟阴影与 FAB；静止复用缓冲，原控件继续处理布局、输入和动画。
- 已布局但暂时隐藏的普通顶栏也参与跟踪，卡片主体释放、选择模式退出时跟随原有可见性和旧式平移动画。Texture 分支直接放在列表之后，复用原生前景层序。

## 2026-09-18 用户确认

- 保留 `swipe_complete_animation` 存储键和当前取值，将设置名称扩展为“记事卡片滑动、移除动画风格”；既有滑动行为和本次菜单移除统一受其控制。
- 粒子动画共用现有模型、渲染器和设置；菜单移除先采用向左方向（用户同时接受左上和左下）。
- 操作最终结果决定退场卡片，屏幕可见区域决定粒子素材。所有退场素材按原位合成一个动画会话。
- 主体消散后开始列表平滑补位，尾部粒子继续。确认、鉴权和习惯/目标排除在此前完成。

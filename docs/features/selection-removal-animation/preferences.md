# 功能偏好

## 2026-09-18 顶栏与半透明阴影遮挡

- 菜单移除期间，contextual actionbar 和下方模拟阴影必须持续覆盖卡片及粒子。
- 阴影是半透明渐变，阴影下的卡片部分仍应参与动画并透过阴影显示；不能把整个阴影高度当成不透明顶栏裁掉，留下空白带。
- 同时修正左滑、回弹和回聚的顶栏遮挡，不能在动画接管时露出原本位于顶栏下方的完整卡片。

## 2026-09-18 已确认并进入实现

- 与滑动动画共用现有设置及存储值，显示名称统一为“记事卡片滑动、移除动画风格”。不新增独立开关。
- 菜单移除的粒子方向可以为向左、左上或左下；实现先统一向左。
- 卡片主体消失后，剩余卡片开始平滑补位；尾部粒子可以继续播放。
- 用户接受分析文档中的其余边界，包括按实际移除结果及可见范围选择动画对象、批量合成、保留仍命中的文件夹、前置确认完成后起播。
- 必须沿用最近新增的粒子设置页参数，不另建一套粒子大小、颜色精度或性能设置。
- 本轮授权使用 `392QBFED2226B` 与 `R5CW20BLNKL` 测试。仅构造本轮测试数据或使用虚构测试页面，不影响既有用户记事；保留设备现有设置。

## 2026-09-18 用户提出的需求

- 当前先梳理实现、提出需要确认的产品问题，不急于编写应用代码。
- 首页 contextual menu 中的完成、删除、恢复、彻底删除，需要为操作后离开当前列表的记事卡片补充动画，也考虑连带离开当前列表的文件夹卡片。
- 支持单选、多选和记事与文件夹混合选择；必须判断卡片可见性。
- 多个记事或文件夹作为一组播放粒子动画，不为每项各自启动一套粒子动画。

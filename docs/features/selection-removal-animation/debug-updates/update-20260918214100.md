# 选择菜单批量移除粒子动画

## 2026-09-18

- 首页选择菜单中的完成、删除、恢复、永久删除现在根据实际列表变化播放移除动画，覆盖单个记事、多选、文件夹与记事混合选择，以及结构性永久删除。
- 设置统一更名为“记事卡片滑动、移除动画风格”，继续使用原设置值。粒子大小、流动精细度、颜色精度及性能自动调节均沿用现有粒子设置页。
- 可见且确实离开列表的卡片按原位合成一次向左消散动画；屏幕外条目直接更新，半可见卡片仅采集可见部分。保留项及仍有匹配内容的文件夹不会被误消散。
- 等确认或鉴权界面的主体退出后开始列表退场；卡片主体消失后，剩余列表平滑补位，尾部粒子继续。移空提示同阶段出现。
- `ThingListRemovalAnimator` 负责快照、批量交接和收尾，`ThingListRemovalDiff` 按类型及稳定 ID 比较投影；顶部占位项使用固定差分身份。`ParticleSession` 按实际呈现帧判断主体消失，避免提前补位；补位前释放旧 holder，避免尾部收尾影响复用卡片。
- 统一纯记事和混合选择状态入口，移除旧整表刷新分支，保留原确认、私密鉴权、习惯/目标排除及正在做事保护。补充返回键、页面暂停、无可见源与失败回退的资源归还。
- 验证：构建及 27 项相关单元测试通过。魅族 392QBFED2226B、三星 R5CW20BLNKL 覆盖单选、多选、半可见、屏幕外条目、整屏移空及真实菜单四类操作；魅族补测文件夹混合操作，三星补测返回键中断与 Texture 交接。测试数据已清理，用户粒子设置保持原值。尚未在旧版 Android 系统本身运行验证。

# 实现计划（2026-10-05）

依据：用户十个裁定（decisions.md）、现有引擎结构（README）、桌面实现 `docs/features/dialog-particle-dismiss/tuning-0909-gpt6/harmony_native.py`
与华为源码（`docs/features/dialog-particle-dismiss/original-code-locations-2026-10-04.md` 列出的运动着色器、消蚀着色器、配置结构、`FormParticleConfig`）。

## 1. 架构

- 新增三个类（`views/particledismiss/`）：
  - `ParticleDriftModel`：CPU 侧输入——样式库、格点值、风向与风力、粒子数、合成方式、时间映射。纯算式部分可在 JVM 单测里定死。
  - `ParticleDriftRenderer`：GL 侧。卡片残留（快照 × 消蚀遮罩）一遍、颗粒实例化绘制一遍；每颗粒子的出生、寿命、位置、尺寸都在顶点着色器里
    按索引闭式算出，不用 compute、不用 SSBO（Mali / 麒麟 GPU 顶点阶段读不了 SSBO 的限制碰不到），GLES 3.0 即可。
  - `ParticleDriftSession`：与 `ParticleSession` 同一组对外方法（准备推进、是否要节拍 / 出帧、绘制、提交 / 上屏回调、可见性、取消、释放）。
- 抽接口 `ParticleLayerSession`：`ParticleWindowSurface`、`ParticleDismissOverlay`、`ParticleCardSurfaceHandoff` 改用接口；`ParticleSession` 只加
  `override`，行为逐位不变。
- `ParticleDismissSpec` 加 `style`（FLOW / DRIFT）。`ParticleDismissController` 与各入口按设置填入；碰一碰固定 FLOW。
- `ParticleWindowSurface.advanceOnce` 只在存在 FLOW 会话时才建微片共享资源（累积缓冲、流场等），飘散会话不占这份显存。
- 取像素复用 `ParticleMicroflakePreparation(deferred = true)`：只解像素与圆角遮罩，不建材。
- 新建页的预热（`ParticleCreationPrewarm`）对飘散样式跳过：飘散的任何时刻都能直接算，没有轨迹要预算。

## 2. 模型（逐项对照源码与桌面实现）

- 坐标：快照即发射区（宿主机器码已核对：`emitSize` = 快照尺寸 × 0.5，居中放在工作面上）。源码的工作面是半分辨率，半径、风、湍流都以工作面像素给出，
  移植时统一按 ×2 换算到设备像素；湍流的取样位置按源码含工作面偏移（扩展尺寸取屏幕尺寸，上限 2100 × 2400，与源码一致）。
- 出生：位置 (hash(i+1), hash(i+3)) / 0xFFFFFFFF 乘发射区；消蚀遮罩 n = 0.2 + 0.8 × 平滑插值（格点值），格点间距由 u = 205 / (W·H) + 0.002
  决定（W、H 为快照的设备像素）；遮罩 α = (n − 1.05 × T) / 0.15，α ≤ 0.9 时出生，出生时刻因此可以闭式求出。格点值在 CPU 上给出（样式库或随机），
  不在着色器里用 sin 哈希（各家 GPU 的 sin 精度不同）。
- 粒子属性：寿命 (1 − 出生进度) × U(0.5, 0.8)；随机 alpha U(0.6, 1.0)；半径 U(3, 4)（工作面像素）；颜色取快照（半分辨率纹素中心，源码的 2t+1 取样），
  透明处不出可见颗粒；三通道都低于 0.1961 时抬到 0.1961。
- 运动：出生位置 + 风（½ × 加速度 × t² × (0.7 + 0.6 × 随机)）+ 湍流（两倍频 simplex fbm × 幅度 × t，演化 0.1 × t，取样相位按索引），与源码相同；
  **风向按现有方向规则**（规格里的虚拟触点方向），风力大小取样式的风力。
- 外观：点纹理 dot01（9×9 软点），半宽 0.7 × 尺寸；生长 / 衰减一半进尺寸、一半进不透明度（`radius_alpha`、alpha_power 0.5）；寿命最后 20% 遮挡减弱
  （alpha_extra 1）。卡片本体 = 快照 × 遮罩 α。
- 合成：按颗粒飘行区域的背景亮度在两种之间选——暗：加光（颗粒颜色按已预乘直接累加）；亮：标准 src-over（颜色乘随机 alpha，alpha × 1.15）。
  背景亮度在抓图时顺带取（具体取样方法在阶段 C 定，先用主题 + 场景的估计值）。
- 粒子数：4 万 ×（对象面积 / 4×4 卡片面积），截在 1～5 万，再乘设置里的「粒子数量」倍率。
- 时长：源码时间轴（卡片约 1.1 秒化完、尾巴到 1.5 秒）整体压到现有时长——消散 1.0 秒、出现 0.6 秒（倒放）、左滑松手后按 (1 − 进度) × 0.42 秒补完，
  都乘系统动画缩放。

## 3. 样式库与随机

- 十二段参考逐段估计出的格点值与风向（横风、纵风 40000）整理成资产 `shared/particle-dismiss/drift-styles.json`。
- 每次动画：按本次方向找夹角在阈值内的参考样式，以概率 p 选用（格点值套到本次卡片的格点网格上），否则随机生成格点值与风力大小。
  参考样式的风向都朝上（左上、正上、右上），向下或水平的方向只用随机生成。阈值与 p 在阶段 C 按截图定。
- 左滑：随机格点在手指按下处放一个低值，那里最先化开（对应现有偏好「至少一个消逝起点在手指按下处」）。

## 4. 倒放与手势

- 闭式模型任意时刻都能直接画：出现按时间从末端倒放（卡片在颗粒归位处重新长出来），左滑按手指进度直接画、允许回退，不需要历史缓冲与预算。
- 出现方向按现有规则（弹窗从下方、新建从 FAB、左滑回位从左或右）：正向用指向来源方向的风生成，再倒放。

## 5. 设置

- 偏好文件 `particle_tuning` 增加 `particle_style`（`flow` / `drift`，缺省 `drift`）与 `drift_particle_amount`（倍率，缺省 1.0，范围先定 0.5～1.5）。
- 粒子动画设置页加「粒子样式：流体 / 飘散」；选飘散时隐藏四个旧调节项、显示「粒子数量」；预览卡片与示例对话框播所选样式。各语言文案补齐。

## 6. 分阶段

- A：接口、飘散会话与渲染器、设置开关；在设置页预览（示例对话框消散 / 出现、卡片左滑）上跑通，R5CW20BLNKL 截图。
- B：全部调用点（29 个弹窗、调整外观面板、首页与「正在做」左滑及回位、多选完成 / 删除 / 恢复 / 彻底删除、新建页、新卡片入场）逐个核对与截图。
- C：样式库、按背景亮度选合成方式、方向细节；帧耗时与首帧延迟测量。
- D：文档、截图交付。

## 7. 风险

- 顶点着色器里每颗粒子每帧两次两倍频 simplex 噪声：5 万颗约 20 万次 / 帧，要在真机上量；必要时把湍流改成按格子预算的速度纹理（只在性能不够时）。
- 本次只授权 R5CW20BLNKL（Adreno 740）。Mali / 麒麟 GPU 上的验证要另问用户。
- 浅色背景上的合成方式与背景亮度的取样位置，需要阶段 C 的截图来定阈值。

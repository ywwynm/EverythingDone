# 2026-10-08：飘散粒径、边缘与卷曲可见性诊断

## 范围与证据口径

本轮处理默认 1× 偏小、起点过糊、卷曲亮带不清晰三个关联问题。使用华为镜像提取的更新着色器与宿主反汇编、桌面 `harmony_native.py` / `android_drift.py`、正式 `shared/particle-dismiss/drift-*` 和 Android 渲染器核对。

镜像中的最终粒子绘制后端缺失；`dot01.png` 出自同一镜像，但此前没有找到它被目标消散后端使用的证据。因此软点纹理、0.7 的半宽倍率、生长/退场在尺寸与透明度之间分摊、额外尾段 alpha 衰减均须视为复刻的绘制推断，不能描述为华为源码的确定行为。

本轮设备：三星 SM-S9180，序列号 R5CW20BLNKL，1440×3088，逻辑 densityDpi 600（density 3.75）。仅操作调试场景和本轮自建测试内容。工作区已有其他功能与研究文档改动，保持原样。

## 验证方法

- 固定快照、种子、时间与风，保存真机正式渲染器的无损离屏帧；桌面重放同一输入。
- 先分别检查粒子轮廓、尺寸、生命周期、合成，再作联合候选；不通过增大湍流掩盖亮度与轮廓问题。
- 连续关键帧同时检查原图大小与局部放大，覆盖旧钢铁侠参考、明暗纯色面板、不同密度和首页滑动。
- 改动期间记录已证实结论与失败实验；最终回到真机交互与性能验证。

## 已复现与单变量对照

- 三星正式离屏渲染导出旧钢铁侠、浅色面板、深色面板各 27 帧；并录制复用首页生产手势的虚构卡片左滑／回位。可以看到小软点、消逝起点灰雾与面板本体粒子偏弱。
- 使用生产 GLSL 重放其中 18 帧，与三星每通道平均差 0.0001–0.0283/255，99.9% 分位不超过 1/255。旧桌面通用 `android_drift` 则尚未同步取消黑白灰强调，面板最大逐帧均差达到 5–7/255；不能把旧桌面输出作为当前 Android 的数值基线。
- 单独放大旧软点 1.4 倍会扩大可见主体，但同时扩大柔糊外缘。取消面板全部缩小／淡化会改变整体权重，收益不足以单独解决轮廓问题。更集中的解析圆点能同时提升粒径辨识度与局部对比。
- 实际读取旧钢铁侠原片的连续进度 0.45/0.55/0.65/0.75/0.85，并对照同一原片输入的 `NativeLive`。原运动已形成上沿、右上弯钩和下沿亮带；全局过量放大（新轮廓再乘 1.25）会使亮带饱和范围过大，不采用这项全局倍率。

## 实现

- 新覆盖函数共用于 Android 与桌面 Android 口径，中心半峰值直径为外框 50%，10% 峰值边界约为半峰值直径的 1.17 倍；旧软点对应 37.2% 与 2.0 倍。四个像素内覆盖样本抑制小粒子的取样跳变，不增加工作面分辨率或粒子数。
- 显示尺寸按 `用户倍率 × density / 3.5` 进入正式输入；3.5 是本应用校准基准，不是推断华为原设备密度。普通稳定粒子的连续轮廓半峰值直径约 1.4 dp，面板本体约 1.176 dp；真实半分辨率像素取整、随机半径与年龄仍影响每一颗。
- 面板额外尺寸衰减由 26% 减为 16%，不改原有透明度衰减；保持颜色、寿命、数量、风、湍流、消蚀柔边、合成选择和时间轴。旧参考复刻仍保留原绘制推断，只把新规则同步到 Android 口径。
- 片元测量回归先在旧版失败，改后 0.5/1/2/6 倍的实际输出通过；设备像素下的取样稳定性与真机结果见下文。

## 性能

三星固定输入基准：每场景 36 帧、3 次轮换，中位数；使用同一正式 GPU 管线，原始 `sizeScale=1`，主要隔离轮廓改动开销。实际交互的密度补偿倍率为 1.0714285，另由上面的真实首页流程验证。

| 场景 | 修正前（ms／帧） | 修正后（ms／帧） |
|---|---:|---:|
| 新建页 1440×3088 | 1.748 | 1.546 |
| 多选移除 734×2499 | 1.103 | 1.128 |
| 弹窗 1200×587 | 1.833 | 1.177 |
| 左滑卡片 1300×300 | 1.636 | 0.576 |

未看到明显性能退化，但前后固定开销和其他绘制遍的耗时也有变化，受设备调频与提交抖动影响；不能把表中下降幅度归因于轮廓优化，更不能推论其他 GPU 同样更快。新建转场约 319–343 ms 的首帧延迟主要来自建会话，确认按钮消散的约 394–401 ms 含原有等待，本轮不改这些启动路径。

## 结论边界

- 本轮仅三星为物理设备实测，其他显示密度通过离屏与模型检查；尚无其他设备的新版本实测结论。
- 浅色粒子叠到浅色背景时没有类似暗背景的亮度余量，仍按既定背景规则使用 src-over；通过轮廓与局部密度表现流动，不额外画白色光带。
- 录屏压缩、缩略图与网上拍摄素材不能用于精确反推原机粒径。新增轮廓是有对照证据的产品调校，不宣称等同于镜像中缺失的华为绘制后端。

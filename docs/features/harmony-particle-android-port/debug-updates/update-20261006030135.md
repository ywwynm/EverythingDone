## 飘散样式：朝上更常出现参考样子，可调粒子大小，点击远近影响动画，起播更快

### 新增与改进

- 朝上方向（正上方、上方偏左、上方偏右，即离竖直向上 35° 以内）消散时，参考视频里朝上的几段（参考 1、2、4、5、7 与朝上的钢铁侠）及其变体出现得更频繁：约四分之三的概率选用它们，其中四成是原样、六成是变体。左上方（含按返回键关闭）仍以旧钢铁侠一族为主。所有参考样子现在都会出变体。
- 设置 → 粒子动画设置 → 飘散：「粒子数量」改为 0.2–1.6 倍；新增「粒子大小」0.5–2 倍。两项默认都是 1 倍，即源码里的原始颗粒大小（飘散的颗粒大小是源码定死的，不像流体那样按面积自动推算）。
- 点弹窗外关闭时，点得离弹窗越远，颗粒飘得越快、越远，并略微朝点击处偏转，与流体样式是同一套算法：风力随远近在 0.55–1.45 倍之间变化。按返回键关闭时不受影响。

### 性能

- 主线程上为每次动画准备输入的时间从 23–67 毫秒降到 3 毫秒以内，新建记事页这类整屏内容最明显。
- 弹窗出现的最后一帧原来要多停约 0.2 秒才换成真正的弹窗，现在立即交接（流体样式同样受益）。
- 快照的上传与内容分析改为并行；应用启动后的第一次飘散动画也更快（提前预热了内容分析）。
- 与流体对比（三星 SM-S9180，首帧取中位数）：弹窗出现 85 对 370 毫秒，点弹窗外消散 97 对 113，左滑 127 对 205，卡片回位 91 对 375，多选移除的卡片 81 对 192；出帧数持平或更完整。

### 已知问题

- 新建记事页起播仍比流体慢约 40 毫秒（209 对 165）：飘散要上传整屏截图，流体在首页空闲时已提前算好。出帧更稳（137/137 对 98/124）。
- 弹窗出现的末尾偶尔会丢一两帧。
- 只在三星 SM-S9180 上验证过。

### 验证情况

- 每次动画的输入（含朝上一组、粒子数量与大小、点击远近）由手机生成，与桌面模拟器里同一套规则逐位相同（1404 组）；同一输入下手机与桌面逐帧一致（七组）。桌面模拟器已同步更新。
- 三星上在弹窗正上方近、中、远三处点击（同一段参考）：0.9 秒时颗粒最高处离弹窗上沿 434、614、816 像素。
- 粒子相关 324 条单测通过。

## 2026-10-08：改善飘散粒子的默认大小、清晰度与卷曲可见性

用户反馈默认 1× 的粒子偏小、中后期不清楚，首页滑动的消逝起点过糊，旧钢铁侠式卷曲和局部粒子带不明显。本次同时核对华为镜像中的更新着色器与宿主反汇编、桌面模拟器及 Android，并在三星 R5CW20BLNKL 上保存旧版基线、逐帧对照和实际首页录像。

旧实现按固定设备像素绘制，9×9 软点的可见中心偏小、柔边范围较宽，面板本体还叠加缩小。现在使用共享 drift-coverage.glsl 的解析圆点，收窄柔边，并通过四个像素内覆盖样本减轻小颗粒取样波动；ParticleDriftInputs 按显示密度补偿大小，默认普通粒子的稳定半峰值直径约 1.4 dp；本体额外缩小由 26% 减至 16%。保留原运动、寿命、颜色、粒子数量和背景合成规则，使已有卷曲与局部聚集更容易看清。桌面 Android 口径同步更新。

镜像缺少目标粒子的最终绘制后端，本次轮廓属于经画面对照后的调校，不宣称取得了华为原生粒径；不同设备的像素取整和物理观感仍可能有差异。

验证：66 项 JVM／着色器检查、161 组内容强调与 32 组裁剪检查通过。三星五组共 135 帧与两套桌面实现对照，99.9% 误差分位不超过 1/255。真实首页高文本卡、清单卡、新建、滑动、确认弹窗及移除流程通过，11 次动画帧间隔 P90 均为 8.3 ms；GPU 基准未显示明显退化，不将调频差异视为性能提升。两条自建测试记事已移入回收站，原有记事、动画偏好与旋转设置未改变。未创建 Git 提交。

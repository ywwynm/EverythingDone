## 粒子动画新增「飘散」样式，并设为默认

### 新增与改进

- 「设置 → 粒子动画设置」新增「粒子样式」：流体（原来的效果）/ 飘散（新）。默认是飘散，可以随时切回流体。
- 飘散：内容从一处开始逐渐化开，颗粒随风飘走；出现时颗粒沿反方向汇回来。所有用到粒子动画的地方都会用它：弹窗的出现与消失、首页与「正在做」页的左右滑完成与回位、多选菜单里的完成 / 删除 / 恢复 / 彻底删除、新建记事页的出现、保存后新卡片入场、调整卡片外观的面板。碰一碰传输仍用流体。
- 方向沿用原来的规则：消失时朝触点或滑动方向飘走，新建页从按钮处汇入，弹窗从下方汇入。朝左上、正上、右上消失时，有一半的概率呈现参考录像里的某一种样子，其余时候每次随机。
- 颗粒在深色背景上发光叠加、在浅色背景上正常覆盖，按颗粒飞过区域的背景亮度自动选择（弹窗下面的暗层不算在内）。
- 选飘散时，设置页只保留一项「粒子数量」（0.5×～1.5×）；原来的粒子大小、流动精细度、颜色精度、性能自动调节四项只在选流体时显示。
- 时长与原来一致：消失 1 秒，出现 0.6 秒，左滑松手后按剩下的距离补完。

### 已知问题

- 新建记事页是整屏的内容，飘散时是一大块一大块地化开，观感与流体差别较大，是否调整待定。
- 只在三星 SM-S9180 上验证过；深色主题下的实际效果还没看过。

### 验证情况

三星 SM-S9180 上逐个入口录屏、逐帧看过：设置页的两种预览、真实首页（新建、新卡片入场、左滑完成、多选删除）、弹窗的出现与消失、左右滑后的回位、调整外观面板。四万多颗粒子一起移除时为 61/61 帧，弹窗消失为 61/63 帧。

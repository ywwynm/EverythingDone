## 飘散样式：新建记事页起播更快（截图零拷贝）

### 新增与改进

- 新建记事页的飘散出现动画起播更快：页面截图不再从显存拷回内存、再整张上传回显存，而是直接把截图所在的显存当作粒子的贴图使用；内容分析只在显存里取它要用的那一小部分像素。
- 三星 SM-S9180 上，新建页从开始准备到第一帧上屏：飘散由约 205 毫秒降到约 152 毫秒，流体约 165 毫秒；截图这一步由 29–37 毫秒降到 5–7 毫秒。动画画面与之前完全相同。
- 只在 Android 12 及以上的新建记事页使用；条件不满足或任何一步失败时，自动回到原来的拷贝方式。弹窗和卡片的截图很小，仍按原来的方式处理。

### 已知问题

- 只在三星 SM-S9180（Adreno 740）上验证过，其它 GPU（如 Mali、麒麟）上没有验证；如果不支持，会自动回到原来的方式。

### 验证情况

- 三星上逐字节核对三轮：直接使用的显存贴图与原来拷回内存的那一份完全相同（1440×3088 整张 0 个像素不同），内容分析取的 85,760 个样本也全部相同。
- 内容分析改了实现，结果与之前逐位相同：单元测试对照原实现，并在手机上与桌面模拟器的规则重新核对（1404 组输入 0 条不一致）。
- 飘散的所有场景（弹窗出现与消散、左滑、回位、多选移除、新建页）和流体的所有场景都在三星上重新跑过，起播与出帧正常；新建页录屏两轮，凝聚过程 31 帧、约 0.5 秒，交接到真实页面时没有跳变。
- 粒子相关 326 条单测通过。

## 飘散样式：与桌面模拟器逐帧一致，有颜色的内容更突出

### 新增与改进

- 弹窗里标题、按钮等有颜色的内容，飘散时颗粒更多、更大、更不透明、停留更久；白色或灰黑色的弹窗主体颗粒更细、更通透。照片类内容不受影响。
- 旧钢铁侠等参考样子用在不同大小的弹窗上时，卷曲和翻折的形状与参考一致（此前按弹窗自己的位置取湍流，形状对不上）。
- 与桌面模拟器对齐：粒子数改按屏幕像素面积计算（与桌面相同，高分辨率屏上比之前多），画布高度、逐帧的时间步长、颗粒出生的时刻、点纹理方向、颗粒与卡片残留的像素对齐都改成与桌面一致。同一组输入下，手机与桌面逐帧相同。

### 已知问题

- 新建记事页是整屏的内容，飘散时仍是一大块一大块地化开，是否调整待定。
- 只在三星 SM-S9180 上验证过；深色主题下的实际效果还没看过。

### 验证情况

- 三星 SM-S9180 上用同一组输入离屏出帧，与桌面实现比较 0.05–1.35 秒的 27 帧：五组（旧钢铁侠参考、浅色背景参考、浅色与深色弹窗、旧钢铁侠样式用在弹窗上）每帧 99.9% 的像素相差不超过 2/255。
- 每次动画的输入（样式、格点、风、粒子数等）由手机生成，与桌面模拟器里的同一套规则逐位相同（588 组）。
- 真机上多选移除、左右滑、外观面板、设置页示例弹窗共 19 次飘散动画正常；粒子相关 314 条单测通过。

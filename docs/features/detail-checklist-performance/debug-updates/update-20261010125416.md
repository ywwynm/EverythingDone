## 2026-10-10 — 记事详情长清单性能优化与交互修复

### 需求与实现

用户反馈长清单记事打开慢、展开或折叠后滑动不够流畅，并要求保留详情页所有区域的功能、外观及外观设置行为。结合提交历史、Android 官方资料和真机测量，确认旧布局会把清单按完整高度挂载，无法按可见区域正常回收。最终采用有界 RecyclerView 与 ConcatAdapter 组织整页内容，保留标题、正文、图片/视频、清单、音频、信息区及固定工具栏。

- DetailActivity、DetailContentLayout 与 detail_content_sections.xml 统一滚动和分区位置映射；DetailGridGeometry 保留附件网格列数、间距和横竖屏几何。
- CheckListAdapter 与 ChecklistEditorItems 保留清单逻辑身份、编辑草稿、焦点、选区、组合输入、层级与级联完成、折叠、撤销重做，以及子树拖拽和跨屏自动滚动。
- ImageAttachmentAdapter、AudioAttachmentAdapter 和 DetailAttachmentPlaybackController 适配附件回收、播放身份、GIF 生命周期及视频预览；保留记事颜色、明暗主题、媒体宽度、比例与裁剪等设置行为。
- DetailScreenshotRenderer 与 ScreenshotHelper 独立渲染完整长图，包含离屏清单、媒体、文件夹图标及记事信息。

### 回归发现的修复

- 修复子树拖拽期间离开详情时，自动保存可能遗漏暂时收起的子项。
- 修复 Activity 重建或固定编辑区离屏后，标题/正文文字、焦点及选区丢失。
- 修复 Downloads 非数字文档标识（如 msf:）解析崩溃，以及损坏音频播放器创建失败时的崩溃。
- 修复长图媒体加载或文件写入失败仍返回成功；补齐超时、取消、位图容量检查和资源释放。
- 修复快速取消计时后延迟回调访问已失效服务，以及未授予相机权限时直接启动拍摄的异常。

### 验证与性能

- 三星、魅族和平板完成 96 组旧新静态外观对照，另有 24 组系统主题与聚焦态对照；已检查可见控件几何、文字与颜色、光标/选择柄和按压状态。此处不表示整屏像素完全一致，也不表示所有系统菜单均已覆盖。
- 三机已验证清单编辑与拖拽边界、真实输入法、旋转、真实文件选择、拍照/录像和麦克风录音的保存/取消、主要记事/提醒/习惯状态操作、ZIP 导出及长图正常/失败路径。系统字体比例 1.3 下的编辑、键盘避让与旋转通过。
- 24 项相关单元测试通过；三机原有七张业务表复核无记录修改、丢失或测试行遗留，测试数据已清理。
- 在魅族同一实际长清单、同等编译条件、先启动首页再立即进入详情的探针中，进入至首帧预绘制由 454 ms 降至 160 ms，展开由 465 ms 降至 83 ms；展开滚动的超时帧由 154/170 降至 4/898。这是特定场景测量，不代表所有设备和启动方式均有相同收益。
- 另一组充分预热对照中，折叠时挂载清单行由 57 降至 13，展开时由 151 降至 20。

### 已知问题与待验证范围

- 直接冷启动到详情后的首次折叠态滑动仍有退化样本，后续继续优化；本次不宣称所有滚动问题均已解决。
- 平板首次视频派生预览生成仍受系统低存储约束，尚未完成验收；实际拍照/录像保存已通过，与此生成任务不同。
- 私密内容的完整图案/指纹解锁按用户安排稍后验证。
- 进程恢复后的全部撤销历史、折叠/滚动锚点与组合输入，额外显示密度、分屏/自由窗口、TalkBack、外接键盘和长时间使用等仍待补测；本轮未覆盖系统/混合音源授权、所有闹钟实际触发策略和全部外部分享接收方。

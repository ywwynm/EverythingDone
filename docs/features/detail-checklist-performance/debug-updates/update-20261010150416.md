## 附件外观提前展示，加载进度支持记事渐变色

用户确认图片按钮的触摸反馈已改善，希望弹窗先按正确尺寸打开并播放原有粒子动画，再异步填入图片/视频；随后补充要求：图片加载进度与首页记事卡片一致，使用记事色并支持渐变。本版包含这些调整及此前批准的清单行减负。

- `DetailCropPreviewLoader` 先在独立后台队列读取图片尺寸/方向、视频尺寸/方向/时长，`DetailActivity` 按原规则展示完整窗口，后台继续准备原精度媒体。加载前后尺寸不变，原粒子出现动画保持一致。
- 图片加载环复用首页 `BackgroundUtil.applyProgressBarGradient` 和 28 dp 尺寸，构建时即使用当前记事的完整纯色或渐变；视频保留已有记事渐变加载反馈。加载完成隐藏，有效缓存命中时直接显示媒体。
- 加载期间可取消，编辑与确认暂时禁用；就绪后恢复裁剪、宽度、比例与视频选帧。尺寸随 Fragment 保存，关闭或重建不会迟到重开；正常新窗口恢复异步加载，升级前缺少尺寸参数的旧窗口保留兼容恢复路径。
- `CheckListAdapter` 为四个按钮复用各自 ripple，颜色变化时更新；移除 XML 中首次绑定就会被替换的背景，减少重复样式设置与无效布局请求。保留完整编辑、输入法组合文本、焦点、层级、拖拽、折叠及撤销行为。
- 指定魅族大图两组首开预绘制约 204/269 ms，完整媒体约 1.22/1.97 秒就绪，最终预览像素一致。预绘制不等于动画完成；清单首滑仍有长帧，不标记为已稳定解决。
- 前序三机清单操作、18 组明暗对照、附件功能、加载取消及重建和 32 项 JVM 回归通过。本次补充三机各 4 组纯色/渐变、图片/视频、粒子开关与加载中重建，截图确认图片加载环；原有七张业务表及相关非认证设置复查不变。

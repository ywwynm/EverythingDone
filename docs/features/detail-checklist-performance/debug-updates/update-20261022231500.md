## 恢复记事详情图片／视频附件的换位动画

用户反馈详情内移动图片／视频附件时直接跳到新位置。实际列表回归复现首帧由横坐标 0 跳至 200 px；单变量对照确认，原因是此前统一详情列表时为避免清单编辑闪动，将整个列表的动画器关闭，附件移动动画也随之失效。

新增 DetailAttachmentItemAnimator，只为图片／视频及音频附件保留位移动画，普通编辑区域不增加变化或增删淡入淡出。清单移动模式继续原有收束、展开和被拖代理控制，附件仍可正常换位；退出清单移动模式后恢复附件动画器。继续复用媒体 View 与细粒度移动通知，不改变附件身份、外观与播放逻辑，不恢复预测布局。

7 项专项回归通过，覆盖连续中间帧、清单模式及退出、反向换位、动画中断和普通编辑无动画；全套本地 1775 项测试无失败／错误，3 项既有跳过。本轮未使用 ADB，三机真实长按与通栏换位尚未复验。

## 修复清单回车后列表滚错位置、光标离屏

- 用户反馈：清单编辑时弹出键盘，再按回车，列表会滑到错误位置，完全看不到光标；并要求覆盖顶部图片、底部音频等复杂详情页。
- 真机复现定位到 `CheckListAdapter.onViewAttachedToWindow`：回收行重新附着时仍处于列表布局过程，同步恢复焦点会让 TextView 使用旧坐标请求滚动。即使新行随后正确聚焦，先前的滚动仍会把光标带出屏幕。
- 现将焦点恢复延后到本轮布局结束，执行前核对行仍附着且 Adapter、条目和当前焦点身份一致，避免过期任务抢焦点。保留原有新行聚焦、光标避让、选区及输入法组合区恢复逻辑。
- 新增 `DetailChecklistFocusChecks` 真机回归：实际弹出键盘并发送回车，之后不主动定位或滚动测试目标，直接检查光标可见性、目标行及继续输入。
- 三星、魅族和平板各 16 组回车/继续输入全部通过。覆盖顶部/中部/末尾、折行拆分、连续回车，以及顶部单图/多图、底部三条音频、图片音频混排的长短清单；手机竖屏和平板横屏均通过。
- 三机各 15 组既有清单功能及 3 组边界编辑全部通过，包含回收选区、组合文本、撤销重做、缩进、级联完成、展开折叠、拖拽、颜色重绑和长图导出。19 项清单 JVM 测试与 debug 构建通过。
- 对照本轮测试前的新备份，三机七张业务表与相关偏好保持不变；临时记事和媒体已清理，生产诊断日志已移除。

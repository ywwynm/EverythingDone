# 卓易通显示兼容性诊断包实施

2026-10-11：用户授权将两个局部候选、应用内对照和报告导出放入同一 debug 包并发布阿里云，明确不使用 ADB。

## 当前实施

首轮用户反馈及诊断 ZIP 已分析：内容隐藏的 Dialog 候选获部分场景确认；前景源缓冲有内容，根节点候选仍无效。具体观察、事件／图像证据、缺失项和下一步见 [首轮结果](droitong-results-2026-10-11.md)。

- 候选仅绑定诊断 Activity，普通页面保持原路径。首页前景可选择挂到窗口根节点；卡片交接快照同步使用预留层级，前景继续按顺序排列。
- Dialog 单独提供显示前设置窗口 alpha、同一启动时机额外隐藏 Decor 两个候选；共享原始透明度与幂等恢复。内容候选强制离屏捕获并叠加独立 Surface，尚需目标设备判断其显示兼容性。
- 新增检查入口、虚构首页和真实 BaseDialogFragment 测试、独立 Surface 色块弹窗、固定缓冲挂载对照；捕获图像预览、用户观察标记、报告复制／ZIP 分享与系统文件保存。
- 诊断记录实际后端、应用可见 Build/API/GL、前景捕获及隐藏恢复、窗口与粒子提交时间。报告明确区分源缓冲、提交回调和最终屏幕证据。

## 入口与操作

入口：设置 → 粒子动画设置 → 右上角菜单 → 显示兼容性检查。

1. 默认选“原实现”，先测首页前景、普通 Dialog 和叠层 Dialog；返回后标记实际画面。
2. 改选“只改前景挂载”，重复首页慢拖、回拉、滑动完成；需要区分内容与挂载时，对照固定色块测试。
3. 改选“只改 Dialog”，分别比较“提前设置窗口透明度”和“额外隐藏普通内容”，每种测试首次与连续打开／关闭。
4. 分别确认后选择“两项候选一起验证”，再补底部面板、独立 Surface、动画中切后台及两种样式；每组有效候选可连续操作 12 次。
5. 记录结果，分享／保存最近 12 次测试的 ZIP；系统分享或文件选择器不可用时可复制简报。卓易通版本和宿主设备可手填备注。比较流畅度时关闭关键图像采集。

两种样式沿用粒子设置当前值，诊断页不改持久偏好。卡片使用种子 42017；Dialog 出现使用种子 42017 和固定方向。应用可见 API 低于 34 时，不启动本次卡片 Surface 同步／根节点对照，并明确提示改测 Dialog；不会偷偷改成 TextureView 后报告候选成功。

## 证据与恢复边界

- CPU 样本在复用前复制。硬件输出仅在 acquire fence 已完成时、仍持有 Image 的期间读回，未就绪记录 `image_unavailable`，不把不可读样本算作透明。PNG 缩放与编码在工作线程执行；图像模式有额外成本。
- 每次测试最多保存 48 张关键图像，长边最多 512 像素。帧事件分别保留开头和末尾，生命周期事件独立限额，导出明确记录被丢弃数量；持续帧记录不会挤掉隐藏／恢复证据。
- 帧日志区分缓冲提交、事务 committed、驱动呈现时间、后续帧放行及超时推定；FrameMetrics 仅代表窗口。实际可见性由用户标记，源图像不能证明最终 Z 顺序。
- Dialog 提前隐藏与控制器复用一份原值；正常完成、启动拒绝、准备取消、dismiss、detach、Activity 停止均有恢复路径，恢复幂等。停止测试同时释放活动动画层。
- 报告只绑定测试 Activity；会话不恢复到业务页面。测试页使用虚构内容，不读写记事。进程重建后不继续旧实验配置；已落盘报告仍可导出。
- 独立 Surface 使用固定双色内容验证捕获与显示边界，尚不等同于真实录音场景回归。额外隐藏 Decor 是否能隐藏独立 Surface，必须由设备画面确认。

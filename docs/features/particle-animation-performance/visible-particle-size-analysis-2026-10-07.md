# 粒子大小读数与可见直径的核对

## 问题与范围

用户试用 `202610061727` 后询问：飘散显示的 2.4 dp 是否为默认值，为什么实际单颗粒子明显更小；并明确两种动画都应使用可见粒子的大小，而非材料片、贴图四边形或网格大小。本轮核对当前实现与尺寸含义，仅补充诊断和记录，未改变应用渲染，未使用 ADB、未重新发布。

## 默认值

`ParticleTuning.defaultDriftSizeIndex(density)` 将 `9.8 / density` 取最近档位。9.8 是原实现中成熟、未受内容强调影响、半径取平均值时的贴图外框宽度（设备像素），不是软点可见主体的直径。密度 4 时原值为 2.45 dp，选择 2.4 dp；密度 3 时选择 3.2 dp。因此 2.4 dp 是可能出现的默认档，不是全部设备统一的默认值。本轮未读取用户设备密度，不能据此断言其设备配置。

## 复现与归因

诊断工具：`checks/measure_drift_visible_size.py`，使用 `everythingdone` 环境的 ModernGL 执行正式 `drift-update.comp`、`drift-particle.vert/frag`、`drift-quad.vert` 和 `drift-composite.frag`，软点数组直接从 Android 渲染器读取。结果保存在 `tmp/drift-visible-size-20261007/result.json`。

先在超采样离屏目标中渲染孤立粒子，复现 2.4 dp 外框与较小中心。随后按优先级逐项检查：

1. **软点的透明边缘被算入大小：成立，是主要原因。** 不改几何和着色器，只把贴图改为全实心，测得宽度 2.3984 dp；换回真实软点，中心半峰值直径约 0.8930 dp。两种输入的差异只来自贴图覆盖率。
2. **内容和生命周期另有缩放：成立。** 正式计算着色器在本体色上乘 0.74；有色内容最多乘 1.2，并保留半径随机、生长和消逝缩小。4096 颗同时出生的粒子，在稳定阶段（设备时刻 0.30 秒），无内容强调的外框直径中位数为 2.3985 dp，本体色为 1.7749 dp，比例为 0.74。
3. **dp 换算或半分辨率比例错误：不成立。** 密度 1、1.5、2、3、4、4.5 的超采样中心半峰值直径为 0.8916～0.8930 dp，基本一致；实心对照几何达到标称值。真实半分辨率工作面加最近邻合成会产生取整波动：密度 4、16 个亚像素位置下，同一普通软点的半峰值宽度为 0.5～1.0 dp，但它不是数值整体偏大的来源。

相同 2.4 dp 设置、平均半径、成熟阶段的软点测量：

| 内容条件 | 贴图外框 | 半峰值直径 | 10% 峰值直径 |
|---|---:|---:|---:|
| 无内容强调 | 2.400 dp | 0.893 dp | 1.793 dp |
| 本体色缩小 | 1.776 dp | 0.660 dp | 1.327 dp |
| 内容强调最大值 | 2.880 dp | 1.071 dp | 2.152 dp |

这里以横截面不透明度达到中心峰值 50% 或 10% 的位置为边界；软点没有唯一的肉眼可见边界，结果不代表任意背景下的绝对可见范围。出生、消逝、半径随机、像素取整和相邻点重叠还会影响实际观感。

## 对两种样式的结论

- 飘散已经逐颗绘制软圆点，问题是把软点贴图外框宽度命名为粒子直径，没有扣除透明边缘，不是把一个发射网格称成一颗粒子。
- 流动显式档位目前与数量预算分离，但仍是几何基准。`material.frag` 的圆边从半径 0.40～0.50 过渡，半峰值直径为几何宽度的 0.90；`material.vert` 和绘制记录路径还叠加年龄、内容、随机和少量椭圆变化。默认未显式设置时仍保留自动网格尺寸。本次先通过源码核对；用户随后要求补做实际测量，已确认 2.4 dp 的无缩放圆边约 2.16 dp，并发现默认 0.84 dp 标签与自动尺寸不一致，见 [流体实测](flow-visible-size-analysis-2026-10-07.md)。
- 前一轮测试验证了 dp 到几何尺寸的换算、档位迁移、形状和数量独立性，却没有验证可见软点的直径。它不能支撑“设置数字等于可见粒径”的结论。

## 后续修正要求

大小统一表示正常显示阶段单颗可见粒子的典型直径，生长和消逝阶段允许自然缩放；网格、四边形范围以及软边覆盖应由实现内部换算。两种样式要使用同一可复核的尺寸指标，并补实际片元输出测量，不能仅用几何宽度自乘自除验证。

默认值和旧设置迁移需要以实际外观为依据。直接把当前 2.4 dp 软点放大至中心直径 2.4 dp，会将普通点放大约 2.69 倍、本体色点约 3.64 倍，不能将这种明显的视觉变化当作纯文案修正。建议在实施时保持当前默认观感并校正其数值，显式选择新尺寸则按统一的可见直径执行；本轮尚未实施或裁定迁移方案。

## 已核对的方程

- 占据度大于 0.025 的格点执行 `p = max((右 + 左 + 下 + 上 - 散度) / 4, 0)`；其余格点压力为零。
- 外边界通过格点坐标钳位处理，因此边缘邻居可能是自身。首轮额外把邻域压力乘 0.9，保留上一时刻压力的暖启动贡献；这一步与后续定常方程分开处理。
- 原算法每批把 32×32 格读入工作组，8 次 Jacobi 后只写中央 16×16 格；无占据的 tile 不执行。新的算法同样必须保持全局边界、活动区域与 tile 间传播正确。
- 数学收敛更快不等于更接近原来有限 100 次的结果；最终仍对照粒子位置、速度、画面及真实呈现。

## 按顺序验证的假设

1. 投影红黑 Gauss–Seidel 用新邻居值更新另一颜色，在相近误差下少做算术，压力阶段和整段都可能变快。
2. 温和的投影超松弛能进一步缩短迭代，但可能改变局部压力梯度及长期轨迹；对照多个有限工作量，不能只比较残差。
3. 半步同步、边带或初始化会抵消收敛收益；大弹窗本身的绘制也可能限制收益，因此同时测压力局部成本、整段成本和真实长帧。

## 算法资料

- [Chentanez 与 Müller：带分离边界的多重网格压力求解器](https://matthias-research.github.io/pages/publications/separatingBoundariesSlides.pdf)，其中包含投影红黑 Gauss–Seidel。这里只借鉴约束更新方式，不套用其三维网格加速倍数。
- [Lai 等，2020：带分离边界压力方程的可扩展求解器](https://uwspace.uwaterloo.ca/items/d5b88286-d408-47a0-b8d7-d7dcb2be4adc)，确认应按互补问题处理，不能直接用普通线性 PCG 替换。
- [Cornell CS 5220：定常迭代与红黑排序](https://www.cs.cornell.edu/courses/cs5220/2020fa/lec/2020-10-27-stationary.html)，用于核对同步和邻域依赖。本轮先实现局部投影红黑／超松弛，不立即引入多级网格。

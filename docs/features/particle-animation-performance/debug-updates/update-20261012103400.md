## Doing 粒子起滑交接与卡片亮度恢复

根据卓易通录像继续修正 DoingActivity：起滑时卡片整块消失约 33 毫秒，取消后还会保持偏亮。这次保留 SurfaceView 和共同默认实现，不新增设备兼容模式。

- 透明壁纸窗口改用 SurfaceView 公开位置同步交接，撤掉直接修改框架 SurfaceControl 透明度的实现；准备期间保留真实卡片，不通过固定延时或暂停壁纸掩盖空档。
- 卡片及前景作为完整 GL 组撤除，避免清理顺序造成短暂遮挡。
- 真实卡片继续使用原容器透明度，修正回弹结束后列表被重新写成完全不透明的问题；GL 仍单独合成祖先浓度。
- 保留应用内原实现对照、Doing 虚构场景和诊断 ZIP 导出；补充位置切换与卡片／容器恢复属性记录。首页的动态背景交接和 Dialog 内容隐藏方案保留。
- 三台授权 Android 设备完成 18 个有效场景，包含两种样式的 Doing 取消／完成、快速松手、高卡片前景及连续弹窗。15 项单元测试、6 份 ZIP 完整性检查通过；三星和魅族录屏中未出现整卡空档，取消后颜色恢复。OPPO 只有截图与提交／状态记录。
- 三星同场景首帧回调延迟约 134ms → 132ms、帧率约 118 → 119 FPS；不据此承诺所有设备和场景完全等价。三台原 APK 已恢复，已有记事未修改。

## Doing 整页 GL 对照：修复退出滞留、阻塞与闪屏

用户已确认上一轮在卓易通滑动首尾不再闪烁、顶部色条持续移动；但点击关闭时前景滞留、返回后长时间不能滑动，Android 两种退出方式还会闪屏。本轮针对退出链路继续修正，保留 SurfaceView 和应用内对照、诊断导出。

- Android 基线复现约 8 秒阻塞，线程采样显示窗口退出等待 HardwareRenderer，日志出现缓冲队列超时。按钮涟漪会额外产帧，原消费者依赖主线程归还 Image，造成渲染线程与主线程互等。现在消费者最多持有一张跨线程图像，及时归还额外帧；GPU 读取和本轮交换完成后才处理下一轮。
- 确定退出后停止整页捕获，已显示页面由原窗口转场退出；onDestroy 不再提前提交透明整页，纹理随窗口分离清理。没有关闭系统转场或加入固定等待，滑动时动态捕获继续工作。
- 调试主页历史报告汇总移到后台线程，返回与滑动不再等 JSON 解析。诊断增加退出请求、生产者停止、窗口分离、资源释放、主页焦点和首次触摸／滚动；新增“返回后暂时无法滑动”观察项。
- 三台 Android 设备通过 9 个退出场景（关闭、返回、粒子过程中返回）及 9 个滑动场景（飘散取消、200ms 快速完成、流体取消）；15 项相关单元测试通过。首次测试滚动距退出请求约 239～371ms，包含脚本派发时间，不是精确触摸延迟。退出没有出现采集失败或队列超时。
- 三星、魅族录像未再出现本轮退出异常空帧，取消时未出现整卡空白，前后颜色偏差不超过 1/255，顶部色条持续移动。OPPO 无录屏权限，仅验证状态与截图；卓易通仍需用户屏幕验收，回调不能代替最终画面。
- 371／180／72 条已有记事及其它数据库表均未变化（排除已有 HEADER 初始化）。普通业务 Doing 和其它页面未切换到整页实验。本轮不宣称解决魅族捕获性能问题，也未推广为全局默认。

请继续进入“显示兼容性检查 → Doing 对照：整页 GL 绘制（不计时）”，分别用底部关闭按钮和系统返回退出，再立即滑动调试主页；也检查滑动首尾和顶部色条。记录实际画面后分享或保存诊断 ZIP，不需要 ADB。

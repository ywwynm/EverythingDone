## 2026-10-07：参考轨迹先控制总概率，再选择具体来源

用户反馈华为参考动画出现过于频繁，尤其多个参考覆盖同一方向时概率叠加；要求先决定本次采用参考还是随机，再从参考中选择，并按可用数量确定总概率。此前已发布的大小倍率与播放去重改动已按要求提交为 9dd31bb86，本次概率调整作为独立改动。

- 原先先抽偏爱组、未命中再抽其他参考，左上总概率可能为 75%，部分重叠方向达到 87.5%。ParticleDriftStyles 现在只执行一次总参考概率判断。
- N 为本次方向差不超过 22.5°、排除灭霸及近期重复后剩余的参考来源数；原版和变体计为同一个来源。参考总概率 X = min(12% × N, 36%)，其余概率随机生成。
- N 为 0、1、2、3 条及以上时，参考总概率分别为 0%、12%、24%、36%。选中参考后每条来源均分 X；4 条时每条 9%，6 条时每条 6%，8 条时每条 4.5%。因此随机生成始终至少占 64%。
- 旧钢铁侠和朝上一组不再额外增加一次抽取机会。选定这些来源后，仍按原版 40%、变体 60% 分配，其他参考保持原版；变体不增加总参考概率。
- ParticleDriftSequence 在预热时保存排除集合，开播前历史变化就按当前可用数量重新选择，包含原候选未重复或原本为随机的情况。取消预热、同一会话回退与重画仍不消耗额外记录。
- 验证：52 项飘散相关 JVM 测试通过，无失败或跳过；两个多参考方向各抽样 60,000 次，参考比例分别为 36.02% 和 36.33%，符合 36% 的设计值。过滤、去重、变体份额、概率上限及预热历史变化均已覆盖，调试 APK 构建成功。本轮未连接 ADB。

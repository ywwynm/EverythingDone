## 2026-10-11：卓易通粒子首尾交接与独立 Surface 恢复对照

上一版默认 GL 组合已由用户确认：固定色块可见、弹窗粒子正常，卡片滑动不再隐藏顶栏等前景。但首尾交接时阴影和提示文字短暂变深，独立 Surface 弹窗橙蓝区域短暂露出深灰。本版保留 SurfaceView 和 Dialog 额外隐藏普通内容，分别修正这两类交接问题。

卡片与前景在隐藏的 GL 表面中准备缓冲，再协调真实 View 和 SurfaceView 在同次窗口更新中切换；返回时先协调可见性，再清理隐藏表面的旧内容，避免两份半透明阴影、文字同时显示。新增重绘完成协议、事务与缓冲确认、取消和迟到回调保护，不通过降低阴影透明度掩盖问题。

独立 Surface 恢复时只覆盖其色块区域，等待窗口恢复与新色块缓冲检查通过后撤盖。色块生产者补充 Callback2，保持附着期间的表面生命周期；异常、超时、窗口退出和布局变化都有清理，报告会记录未验证结果。

测试入口：设置 → 粒子动画设置 → 右上角菜单 → 显示兼容性检查。默认“本轮两项修复／额外隐藏普通内容”；可选择“上一版 GL 组合”及两项修复单独对照。候选只在测试页生效。先试卡片慢拖、回拉、完成和独立 Surface 弹窗，记录“正常”“阴影或文字变深”或“Surface 露出灰块”，随后保存或分享诊断 ZIP。补测动画中返回、切后台后恢复；判断流畅度前可关闭关键图像采集。

本地构建及 40 项相关单元测试通过，桌面实际着色器 8 项交接合成检查通过。测试和缓冲回调不能证明卓易通最终显示正确，仍由用户安装验收；本轮不使用 ADB。

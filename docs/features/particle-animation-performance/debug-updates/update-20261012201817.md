## 修正录音计时样式与非目标卡片阴影，提前准备 Surface 恢复帧

用户反馈“添加附件 → 录音”时计时数字变淡、疑似额外描边，粒子结束后文字与水体延迟恢复；随后补充首页其它卡片阴影在粒子首尾突变。本轮在真实录音准备页与多卡片场景复现并分离了原因。

- `ParticleViewCaptureTree` 复制 View 的有效重叠绘制属性，使整体透明度在控件合成之后应用，避免数字内部蒙版再次衰减透明度。未修改计时字体、颜色和原有 0.36 准备态透明度。
- `ParticleWindowLighting` 共用真实窗口的主题光源、透明度和显示尺寸校正，整页／动态背景／普通硬件捕获与原单卡片计算保持一致，修正其它记事卡片阴影的突变。
- `ParticleSurfaceRecovery` 在粒子播放期间提前提交、验证恢复帧；结束时仍等待窗口与 Surface 就绪。表面若重建，旧结果作废，继续等待新缓冲。保留 SurfaceView、动态背景和重叠弹窗转场。
- 应用内卡片对照增加两张静止背景卡片，补充本轮观察项与实际录音准备页测试提示，继续提供诊断 ZIP 导出，无需 ADB。

三台 Android 已执行真实首页、真实录音准备页及 15 项固定色块／重叠转场／Doing 回归。三星、魅族计时区域逐像素一致；OPPO 窗口缓冲对照最大差 1/255，最终屏幕仍有小幅差异，不宣称逐位一致。已测非目标卡片阴影区域首尾无损截图无差异；恢复遮盖由三星配对约 312ms 缩短至 65ms。单测 1448 项、0 失败、1 跳过，原 APK 已恢复，既有记事未改动。

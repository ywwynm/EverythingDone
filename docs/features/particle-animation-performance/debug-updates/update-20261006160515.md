## 流体粒子动画新增数量调节

用户希望「流体」（流动）也像「飘散」一样，可以同时设置粒子数量和大小，并要求 ADB 真机验证、截图确认后发布阿里云。

粒子动画设置页现在为两种样式都显示「粒子数量」，范围为 0.2～1.6 倍，每档 0.1，默认 1 倍。流体和飘散分别保存，切换样式恢复各自的值；恢复默认同时清除两种数量设置。

原流体数量由网格密度、内容面积与粒子大小共同决定。本次由 ParticleMicroflakeModel 按数量倍率调整网格密度和数量预算，并在直接绘制与绘制记录两条着色器路径补偿释放后的尺寸，避免数量调节只是改变粒子大小；默认 1 倍沿用原有材料取值。ParticleMaterialShare 和 ParticleCreationPrewarm 的匹配条件加入数量倍率，避免复用旧设置的材料或轨迹。ParticleTuningActivity 与 activity_particle_tuning.xml 复用既有滑动条和已翻译文案。

90 项相关 JVM 测试通过，调试 APK 构建及三星 SM-S9180（R5CW20BLNKL）覆盖安装成功。对话框预览在默认、0.2 倍、1.6 倍下分别为 100,758、20,119、160,950 颗；数量与大小两项同时显示。两种样式独立保存、重启持久化、恢复默认都已通过；1.6 倍示例卡片的左滑消散与聚回已录屏检查。设置截图、动画截图及日志保存在 tmp/flow-particle-amount-20261006/。

测试结束已还原原有粒子偏好和旋转状态，未操作真实记事；本次测试未发现应用崩溃或粒子 GL 错误。数量可能因整数网格和内容采样有少量取整差异，更多粒子的渲染开销也更高；本轮未测试其它型号的性能。

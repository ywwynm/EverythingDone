## 2026-10-07：粒子大小统一使用倍率

用户核对飘散 2.4 dp 的观感后，确认设置读数实际上对应软点贴图的几何范围；流体圆边更接近读数，但默认仍随内容面积自动计算。随后用户决定两种大小统一为倍率，不再使用绝对值，并要求发布阿里云。

- 飘散和流体共用 0.5～6× 的 31 档，保留此前指定的数值并补上 1.0×。1.0× 表示当前样式的原始默认大小，界面取消 dp／px 显示，各样式独立保存。
- ParticleTuning 以倍率百分位整数持久化并迁移历代设置。旧飘散 dp 按本机密度换回倍率，旧流体显式 dp 按原规则基准换算最近档，未设置保持 1.0×；超出范围取端点。
- ParticleDriftInputs 直接传入大小倍率；ParticleMicroflakeModel 在数量补偿后缩放单颗粒子，大小不再改变发射数量或轨迹输入。ParticleMaterialShare 与 ParticleCreationPrewarm 同时纳入大小倍率，防止沿用旧缓存。
- 流体的自动默认基准仍随内容面积变化；旧显式大小曾影响发射密度，因此迁移后不保证与旧画面逐像素相同。两种样式的 1.0× 各有自己的默认基准。
- 性能自动调节仍默认关闭，启用后改为降低粒子数量与流动精细度，不再通过改变大小减少计算量。设置页及 13 个语言目录同步更新说明。
- 验证：233 项相关 JVM 测试全部通过，无跳过；128 组正式 GLSL 离屏检查通过，调试 APK 构建成功。本轮未连接 ADB、未创建 Git 提交；本日志随阿里云调试版本发布。

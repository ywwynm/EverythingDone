## 修复：弹窗消散动画在魅族上有时整场不播

用户报告详情页的「添加附件」弹窗与「调整颜色」面板关闭时消散粒子**有时不播**，魅族 20
Infinity 上更频繁。本次定位到根因并修掉，两台设备各跑了一轮完整的「弹窗 × 关闭方式」矩阵。

1. **根因不是 GPU 跟不上，是抓图那一步拿不到图。** 消散要先把弹窗当前的画面抓成一张快照，
   有两条路：**离屏硬件抓图**（把弹窗的显示树重录一遍离屏画出来）和**窗口 PixelCopy**
   （从系统合成器里复制窗口当前的缓冲）。此前只有「点按钮关闭」（有涟漪）才走离屏，
   **返回键与点外部一律走窗口 PixelCopy**。而在魅族 20 Infinity（Flyme / Android 15）上，
   「调整颜色」面板用点外部关闭时，窗口 PixelCopy 在整个 700 ms 重试窗口里一直返回
   `ERROR_SOURCE_NO_DATA`，快照为空，弹窗直接以系统默认动画退出——**修前 2/2 复现，
   而且此前一条日志都没有**。同一台设备同一个面板，点「取消」「确定」走离屏抓图，
   11–53 ms 就拿到图、动画照常。
2. **修法**：弹窗里没有可见的独立 Surface 时**一律走离屏硬件抓图**，与点按钮时同一条路径；
   只有确有可见 SurfaceView（录音、播放这类）时才用窗口 PixelCopy——那种情况只有窗口缓冲里
   才有真实的透明洞，各 Surface 的像素才合成得回去。另外加一次**单向兜底**：离屏没拿到图时
   再用窗口 PixelCopy 试一次，而不是直接放弃整场动画；反方向不做，用离屏图去补有 Surface
   的弹窗会在画面上留一块空洞。
3. **魅族修后 12/12 全部开播**：原先 0/2 的「颜色面板 + 点外部」变成 2/2，消散 52 / 47 帧，
   首帧 148.9 / 141.6 ms（修前是白等 703–717 ms 之后什么都没有）。其余各格与修前同档
   （帧数 47–60 对 44–58）。
4. **华为 MatePad Pro 13.2 修后 16/16 开播，帧数与修前同档**（附件弹窗 40–55 帧、颜色面板
   22–34 帧，各格差异都在 ±3 帧以内）。录音弹窗那一格仍然走窗口 PixelCopy 并合成 1 个
   Surface，说明分支判断按预期生效，没有把有 Surface 的弹窗一起改掉。
5. **观感没有改动。** 离屏抓图正是出现动画与「点按钮关闭」一直用的那条路。量化旁证：
   微片数由快照里的非透明像素决定，同一个面板两条路径给出的片数分别是 158 474 / 158 459
   与 158 486 / 158 491，落在同一条路径自己重复两次的波动范围内。
6. **补齐了失败日志**（仅 debug 版，正式版零开销）：每次消散先打一行「消散受理」作锚点，
   随后是「抓图路径」；失败时按具名原因打「消散未受理 / 消散未开播 / 消散降级淡出 /
   消散未接管」，并带上 PixelCopy 状态码、等待时长、`syncAndDraw` 返回值、fence 超时、
   异常类型。此前「不播」在日志里完全没有痕迹，这是这次先补日志才定位到根因的原因。
7. **顺带纠正一条记录**：魅族的动画时长缩放此前记成 0.75，应用里从框架读回来的实际是 1.0
   （消散两台都是 1016.7 ms）。按 0.75 推出的「魅族每帧比三星重 33%」作废。
8. 华为上「调整颜色」面板（15.7 万片）消散只有 22–34 帧、p90 50–83 ms，而同样片数的出现
   动画能到 33–35 帧、p90 16.7 ms。这是另一件事（消散每帧现场积分 + 压力求解），已经定位，
   不在本次改动范围内。
9. 粒子相关单元测试 103 项全部通过，其中 6 项是本次新增、钉住抓图选路的两条规则。

## 粒子动画设置：示例卡片可以两边滑，对话框能选粒子飞向哪一边

按你这一轮提的八条又改了一遍。**默认的动画效果与上一版逐位相同**，魅族与三星两台都核对过。

### 换色图标不再是实黑

浅色模式下这枚图标此前是纯黑的。现在与「音频海浪动画设置」里那枚同款按钮用同一份颜色，
深浅两种模式都跟着走。

### 下方选项的尺寸改回去了

上一版把「颜色精度」的两个选项做小了一圈，这一版改回原来的大小，排布与样式不变。
「性能自动调节」与它下面那行说明之间的间距，也按「音频海浪动画设置」里同类选项收紧。

### 示例记事卡片现在两边都能滑

**向右滑与向左滑完全对称**：滑过一半抬手，卡片会把剩下的动画播完、完整消失，
随后粒子从飞出去的那一侧重新聚成卡片回到原位。下方提示相应改成「滑动以预览动画效果」。

### 示例记事卡片的文字会跟着卡片颜色走

换到浅色的记事颜色时，标题与正文自动变成深色；换到深色时变回浅色。与首页列表里的卡片是同一套规则。

### 示例对话框：水波纹播完才开始消散

点「稍后」或「继续」时，先把按钮的水波纹播完，再让粒子接管——与真实弹窗的顺序一致。

### 示例对话框的投影会跟着粒子一起散开

此前对话框的投影是在粒子接管的一瞬间直接消失的。现在投影被一并算进动画，
与卡片本身一起碎开、也一起聚拢。

### 可以选粒子飞向哪一边

对话框预览下方新增一枚**方向按钮**，点开是一个九宫格，八个方向各一个小箭头，默认左上。
选定之后，这块预览的出现与消散都朝那个方向播；按钮上的箭头就是当前选中的方向。
**这项只影响预览，不会改动你的任何设置。**
切换「记事卡片 / 对话框」时，下方两枚按钮的排布会平滑过渡。

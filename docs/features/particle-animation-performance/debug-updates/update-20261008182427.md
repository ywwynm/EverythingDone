## 2026-10-08：统一两种粒子的默认大小，并按视觉效果降低数量

用户指出流体默认颗粒比飘散更小、数量更多，计算压力明显偏大，要求调整 1× 基准；随后指定两种样式的 1× 都为 1.6 dp，并提醒检查飘散放大后的疏密。

本次用三组固定输入生成旧版、只放大、放大并减量的 189 帧画面对照。只放大会明显增厚、增亮；将飘散默认数量降为原来的约 76.6% 后，单颗更清楚，整体疏密和主要文字、色团更接近原版，消散后段总对比强度变化不到 0.4%。因此采用此减量，并将内容补充颗粒上限一同调整。

ParticleDriftModel 将两种样式的 1× 可见直径统一标定为 1.6 dp，并提供共用的面积预算。ParticleMicroflakeModel 按这个预算生成流体网格，大小不再随控件面积、网格间距或数量档位改变；ParticleMicroflakeRules 保持阴影扩展后的本体密度。两种样式仍保留自己的运动、生命周期、内容强调、颜色精度与独立设置倍率，原有倍率相对新基准生效，设置文案没有增加技术细节。

372 项相关测试、8 组正式片元尺寸校验通过；五组三星同输入基准在七个时刻状态均正常，初始静止快照前后完全一致。默认大场景流体现场渲染耗时下降约 38%～43%，回放下降约 41%～51%；高负载下降约 47%～57%。三星真实附件和颜色弹窗，两种默认及流体 1.6 倍数量／3 倍大小共 12 场均约 120 fps，P90 为 8.34 ms。该结果不代表所有设备、所有场景的保证，也不包含触摸到首帧的全部准备延迟。

测试后原粒子偏好、诊断配置与旋转状态已恢复，没有保存或修改真实记事。完整分析和数据位置见 docs/features/particle-animation-performance/flow-default-alignment-2026-10-08.md。发布完成后，用户确认提交本轮实现与验证记录。

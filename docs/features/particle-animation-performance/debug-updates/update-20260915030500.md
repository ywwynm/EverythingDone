## 粒子动画性能优化 第三批

这一版有两处**外观改动**（只在新建记事的出现动画上），都带开关、可以随时回退；其余是延迟修复。
粒子模型本身仍然一个字没改：材料规则、随机、粒子数量、积分步数、压力迭代、寿命、材质、
着色器数学全部原样保留。两台真机上的 GPU 输出逐位对照（消散 61 帧、出现 37 帧、两个动画在同一
上下文交错播放，以及这一版新加的「跳过尾段之后保留的每一帧」）全部零差异。

**左滑甩动的卡顿修好了。**

上一版为了让左滑更跟手，在按下时就先备好前几档画面。但甩动太快时问题反而更明显：手指在
20–30 毫秒就越过了识别阈值，那时卡片的材料还没建好；等建好，手指已经拖过两成，于是第一帧
必须先把中间十几档补算出来才能画——三星上单档约 7 毫秒，补十几档就是 80 毫秒以上的停顿。

这一版改成：**识别到左滑就立刻出画面，先画已经备好的那一档（画面比手指落后一点），
随后每一拍按手指速度往前追，追上之后完全跟手。** 补算全部挪到出帧之外，第一帧再也不等。

实测「识别左滑之后第一个动起来的画面」：

- OPPO 平板快拖 180 毫秒：**132 → 65 毫秒**
- 三星快拖 180 毫秒：**201 → 122 毫秒**
- 含图片的卡片，快拖：OPPO 156 → 110 毫秒，三星 228 → 160 毫秒
- 慢拖没有退化（OPPO 31 → 32 毫秒），松手回弹、按住跨过原点再拉回、
  「拖到 60% 再退回 20% 再拖到 60%」的画面仍然逐像素完全一致。

追赶过程可以从逐帧进度直接看出来：第一帧是完整卡片，随后每拍前进 2–6 档，第八帧前后跟上手指。

**点新建按钮之后到底在等什么，这一版量清楚了。**

把「抬手 → 首页截图 → 启动创建页 → 首次布局 → 抓图 → 建材 → 预计算 → 首帧上屏」这条链路
分成十段逐段计时，结论是：**确实在等，不是动画已经在播但看不见。** 首帧真正出现在点击后
约 0.60 秒（OPPO）/ 0.89 秒（三星），其中最大的一块是 GPU 预计算——260 毫秒 / 467 毫秒，
占整条链路的 44% 和 53%。其次是等创建页完成首次布局再抓图（71 / 136 毫秒）。
从点击到创建页 `onCreate` 只有 22 / 42 毫秒，创建页自己的初始化只有 24 / 38 毫秒。

预计算是粒子模型本身的开销（240 步积分 × 三十几个采样），不在这一轮的改动范围内。
不过「起始段看不见」这件事也确实存在，只是只值 16–33 毫秒——见下一条。

**外观改动一：出现动画现在真的从右下角的新建按钮那里开始。**（可回退）

以前创建页的出现动画用的是一个固定 315 度、位于屏幕外一倍多对角线处的虚拟触点，粒子近似
平行地从右下方飘过来。现在直接把**新建按钮的中心**当作真实触点：方向按「内容中心 → 按钮」
算（横屏的 OPPO 平板是 328 度，竖屏的三星是 293 度），触点距离和强度也按真实位置算。
按钮落在页面内部，于是粒子的汇聚点落到页面边界上，倒放时就成了**从右下角那一点扇形汇入**，
方向性比原来明显。

**外观改动二：跳掉开头那几帧空画面。**（可回退）

出现动画是把消散倒着播。消散的最后阶段绝大多数微片已经消失，所以倒过来播时，最开始的
一两帧画面上几乎什么都没有——实测**第一帧的存活微片占比恰好是 0.0%**，第二帧也才一成。
这一版按每片的出生时刻与寿命，在 CPU 上算出每个时间点还有多少微片在画面上，从「仍有 5%」
的那一帧开始播，播放时长按保留的比例相应缩短（每帧速度不变），预计算也只算到那一帧。
实测跳掉了 2–3 帧，开头那 16–33 毫秒的空白没有了。

保留下来的每一帧都与不跳过时逐位相同，这一条由新增的设备端散列对照守住，两台真机零差异。

**这两项都可以回退。** 如果看了实机觉得不如原来，告诉我关掉哪一项（或两项都关）即可，
关掉后出现动画会完全回到上一版的样子。需要说明的代价：真实触点让每个采样的预计算贵了
两成左右，抵消掉跳过尾段省下的时间，所以创建页首帧出现的时刻与上一版基本持平——
如果更在意速度而不是方向感，也可以只保留「跳过空白」这一项。

**顺带修的**

- 新建记事时的「快速新建」常驻通知，原来压在创建页启动的主线程上，现在挪到入场动画结束之后
  再做，行为不变。
- 修了一个只影响调试测量的崩溃（性能观察器在左滑场景写诊断文件时会把应用打崩）。

**这一版验证了什么**

两台真机各跑一轮：新建按钮 → 创建页（含完整分段计时）、卡片慢拖与快拖（纯文字与含图片各一次）、
添加附件弹窗的出现与消散、录音行、同一个弹窗连开关 10 次；功能回归包括新建保存的三阶段顺序、
入场动画中按返回、左滑按住跨过原点再拉回、弹窗四条关闭路径、音频播放窗口的画面交接像素检查、
连开关后的内存与线程。990 项单元测试只有一项既有失败（与本次无关）。

## 流体粒子改为近圆轮廓

用户在新增数量设置后发现：数量减少或大小增加时，流体粒子刚消逝的阶段呈现马赛克状。源码分析确认，原实现先保留原图四边形微片，再逐渐圆化；数量减少会扩大初始网格，而尺寸补偿要在释放后才逐渐生效。用户确认改为接近圆形并查看实际效果。

本次在 material.vert、material.frag 与 draw-record.comp 中为 Android 流体启用 ROUND_PARTICLES：从出生起完整裁去四角，按设定尺寸绘制，以来源中心颜色形成近圆颗粒，并将横向压扁限制在约 4% 以内。直接绘制、绘制记录及逐片常量优化路径同步处理；数量不会再放大初始颗粒。

原界面的消失同步调整：新增 surface-clock.comp 在准备期生成释放时间图，surface.vert 与 surface.frag 用完整快照和连续插值逐像素淡出，避免低数量时仍按大格子退出。流体运动、方向和倒放缓存沿用原逻辑，飘散样式不变。

验证：96 组实际 GLSL 离屏轮廓／数量／尺寸／年龄／绘制路径检查通过，并核对释放时间图乱序写回、原表面连续性及起止快照。24 项相关 JVM 测试通过且无跳过，包含 GLES 着色器变体编译；调试 APK 构建通过。

三星 SM-S9180（R5CW20BLNKL）完成小尺寸、低数量、3.2 dp 大尺寸及大尺寸加 0.2 倍数量场景。对话框消散与聚回正常；大尺寸、低数量卡片为 1,458 颗，左滑消散及聚回完成，统计 34 / 34 帧、16.7 ms 间隔。录屏逐帧及局部截图确认移动粒子接近圆形、原表面退出连续。测试后已逐字节还原粒子偏好，旋转设置保持原值，未操作真实记事；本次日志未发现应用崩溃或粒子 GL 错误。未验证其它型号。

## 修正 Doing 波纹首帧、录音准备和粒子设置预览阴影

本次按用户反馈继续处理三星 Doing 原生波纹首帧偏深、魅族录音准备偶发中止，以及粒子设置页模拟卡片在滑动和首尾交接时阴影闪烁。保留 SurfaceView、动态背景、添加附件到录音的重叠转场和原有粒子表现。

- Doing 只在触摸／按键刚改变反馈的帧调整提交次序，让原窗口先初始化原生动画；其它动态帧保持原节拍。结束时补入有界的窗口提交后清理，保留退出和缓冲释放保护。
- 粒子设置页模拟卡片复用真实记事卡片的姿态锁，避免滑动辅助逻辑临时改变 elevation 导致阴影突变。
- 录音准备分开等待布局与捕获，外阴影与内容并行；独立 Surface 用完既有 900 ms 捕获期限。零旋转跳过无意义的本地后端初始化等待，成功即继续，没有新增固定延时。
- 应用内原实现对照、显示兼容性诊断及 ZIP 导出继续保留，新增分段捕获计时，卓易通可直接安装验证。

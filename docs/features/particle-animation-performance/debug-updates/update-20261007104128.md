## 2026-10-07：移除飘散动画中面板周围的硬边界

用户反馈首页和记事详情「改变记事颜色」的飘散动画，在向左上消逝时会被面板上边缘截断，并要求检查所有弹窗与粒子动画入口。上一轮参考轨迹概率调整已按要求提交为 eb5a3b341，本轮独立修复绘制范围。

- 根因是 ParticleDriftRenderer 沿用参考动画的扩展画布尺寸，并让画布围绕面板居中。高面板的画布上缘可能恰好与面板上缘重合，窗口内仍可见的位置被提前裁掉。
- 新增 ParticleDriftCanvas，将模拟坐标与绘制范围分开。实际半分辨率工作面覆盖整个窗口，drift-particle.vert 只平移最终绘制坐标；原发射位置、轨迹、湍流和粒子大小保持原规则。
- 检查了首页页内面板、详情与其他普通／嵌套弹窗、新建记事、滑动完成、批量移除及设置预览，均使用共同飘散渲染器。流动样式与碰一碰路径也已检查，未发现以原面板矩形裁剪飞出粒子的规则。
- 快照自身的圆角、残留面板遮罩与列表原内容的可见区域仍只作用于原内容；飞出粒子可以越过面板边缘，在整个窗口范围内显示。
- 验证：58 项相关 JVM／着色器测试、61 组窗口布局和调试构建通过。32 组生产 GLSL 离屏对照中，旧布局有 16 组存在明显裁剪，修复后为 0 组；同一模拟粒子的位置映射、半分辨率像素网格、小数原点和横屏均已覆盖。本轮未连接 ADB。

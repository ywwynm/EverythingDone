## 粒子动画设置：两项新设置、整页跟着主题色走、卡片沿原路聚回来

按你上一版看完后提的八条，这一版把设置页再改了一轮。**默认的动画效果与上一版逐位相同。**

### 新增两项设置

- **颜色精度**：标准（8 位）与高精度（16 位浮点）两档，**默认高精度，也就是一直以来的取值**。
  高精度的颜色过渡更细腻，标准每帧的开销更低。
- **性能自动调节**：**默认关**。打开之后，连续掉帧时会自动调整粒子大小与流动精细度以减轻负担
  并在页面上给出提示，随时可以改回。

其余候选逐个衡量过：只有一个方向是好的（例如动画起步的空白段）、或者省下的开销远小于画面代价
的，都没有做成设置——那样的开关只会让人多做一次没有意义的选择。

### 流动精细度改成 0 到 100

原来是六个档位，现在是 0–100 的连续取值，默认仍是 100。**取 0 表示完全不做流动求解**：
粒子照常飞散，只是彼此不再互相推挤，这一段的开销整个省掉。你原来选过的档位会自动按取值搬过来。

### 滑动条与整页配色

- 两根滑动条换成与「音频海浪动画设置」里一样的普通滑动条，不再把每一档的数值都标出来，
  只在右上角显示当前值；粒子大小仍然会吸附到档位上并标出本机像素。
- **换色按钮挪到了预览正下方的中间**，本身也是一枚主题色的圆形按钮。
- **换色之后整个页面一起换**：顶栏、选项卡、滑动条、按钮、勾选框与两块预览内容都会跟过去。
- **打开页面时用的是应用的强调色渐变**，按下换色按钮之后才从你自己的记事里随机取色。

### 预览里的卡片会沿原路聚回来

把示例卡片一路滑到最左端、让它彻底散成粒子再松手，粒子会**沿着刚才飞散的轨迹倒放回来**，
重新聚成卡片停在原位；倒放期间暂时不接受新的滑动，播完即可继续。滑到一半松手也一样，
从松手那一刻原路退回。这只影响设置页里的预览，**首页列表左滑完成记事的行为一点没变**。

### 示例内容

示例记事换成《河流的答案》，示例对话框换成《留在此刻》，十三种语言都写好了。

## 2026-10-07：提高魅族附件和详情颜色弹窗的飘散帧率

用户反馈魅族上的飘散动画仍掉帧，要求特别测试添加附件、改变记事颜色等控件更大、粒子更多的场景，并授权本轮 Wi-Fi ADB 调试。

- 真机离屏基准和逐拍记录表明，常见 GPU 帧成本约 0.6～1.7 ms；主要问题是消散阶段系统选择了 60 Hz。添加附件约 3.1 万颗，详情颜色弹窗约 6.2 万颗，已经覆盖实际大控件场景。
- ParticleWindowSurface 在高刷飘散会话期间，通过新增的 ParticleWindowFrameRate 请求同分辨率的高刷窗口模式。多个粒子层共同请求时，最后一个结束才恢复原值；Surface 销毁和页面退出也清理请求。ParticleDisplayModes 负责可测的模式选择与请求合并规则。
- 同一 APK 仅切换调试开关的两轮对照：附件消散 58.5～59.4 → 112.2～115.8 fps；详情颜色消散 58.4～58.5 → 112.6～113.6 fps；呈现间隔 P90 从 16.6 ms 降至 8.3 ms。帧率按驱动真实呈现时间计算，排除了预热空帧和收尾清屏。
- 首页也测了外观面板及展开后的大颜色页，后者约 6 万颗，两轮仍约 86 fps。其后半段受到系统合成器评分降频影响，本次尚未解决；窗口数值帧率、允许模式切换、节能平衡、View 高刷类别和逐帧重绘等无收益尝试均已撤回，没有作为优化保留。
- 78 项相关测试通过；流体、飘散的小弹窗、合成卡片左滑、批量移除与空白新建返回完成真机回归。空闲时窗口模式偏好及粒子层请求正常撤销。测试后偏好、旋转设置恢复，未修改真实记事内容。

本轮仅在授权魅族设备验证。此次发布保留已证实的详情弹窗提升，不声称所有入口已消除掉帧；没有创建 Git 提交。

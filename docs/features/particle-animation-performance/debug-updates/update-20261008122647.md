# 粒子动画快速算法与三星性能验证

## 2026-10-08：减少流体重复计算，筛选近似算法

- 按用户要求，在另一个会话刚优化过飘散粒径和清晰度的版本之上，实施“减少重复工作”和“可量化近似”两组候选，并只在三星 R5CW20BLNKL（SM-S9180／Adreno 740）测试。
- 普通流体将中心采样、颜色转换和动态明暗处理移到逐粒子阶段，避免每个片元重复计算；近圆改为真圆，绘制记录从 64 字节缩至 32 字节。保留原有轨迹、压力、粒径演变和颜色空间规则，只取消最多约 4% 的短轴压扁；碰一碰吸入与颜色交接路径沿用原实现。
- 四组 16.9 万／25.5 万粒子的同包交错离屏基准中，现场消散耗时下降约 11%～16%，已准备轨迹的回放耗时下降约 29%～35%。这些是耗时降幅，不等于屏幕帧率提升；逆向准备阶段没有显著变化。
- 实现并评估飘散静态缓存及三次噪声拟合，完整时间轴实测最大位置误差约 0.56 像素，但三星大粒子场景净收益不足且增加初始化和缓存成本，因此默认关闭，不改变最新飘散视觉效果。72 基数压力网格的轨迹误差较大，也不默认启用，正式保持 96。
- 补查发现正式流体已经通过生成着色器注入寿命后积分早退，撤去重复实现，并修正此前研究文档，不将既有优化计入新增收益。
- 365 项粒子相关测试全部通过；完成桌面 GLSL 数值对照、三星 GPU 对照、缓存失效检查和真实附件／颜色弹窗各两轮出现与消散。数量 1.6 倍、粒径 3 倍下，三星飘散约 118～120 fps；流体附件消散约 60 fps，大颜色弹窗消散仍约 52～54 fps，后续仍需处理压力更新和排队开销。
- 主要文件：ParticleMicroflakeRenderer.kt、ParticleDriftRenderer.kt、ParticleFastOptions.kt，以及 shared/particle-dismiss 下的绘制记录、材料和飘散着色器。对照工具仅调试包可调用；未新增用户设置项。
- 测试只开关空白新建页的弹窗，不保存记事或修改真实内容。测试偏好、采样开关与调试配置已恢复；保留无关工作区修改，未自动创建 Git 提交。详细数据见本功能的 implementation-2026-10-08-fast-approximations.md。

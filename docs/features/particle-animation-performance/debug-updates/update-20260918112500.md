## 粒子动画设置：预览里的卡片会先完整消失再聚回来，选项与按钮重排

按你这一轮提的八条又改了一遍。**默认的动画效果与上一版逐位相同**，魅族与三星两台都核对过。

### 示例卡片改回与首页一致

左滑超过一半再抬手，卡片会像在首页那样**自动把剩下的动画播完、完整消失**；紧接着粒子会
**沿反向轨迹重新聚成卡片**回到原位。没超过一半就抬手，仍然从松手那一刻原路退回。
这两段期间暂时不接受新的滑动，播完即可继续。**首页列表左滑完成记事的行为一点没变。**

### 示例对话框只播一轮

进入对话框预览时自动播放一轮出现与消散，之后停在那里不再循环。想再看一遍，点对话框里的
「稍后」或「继续」即可重播。顺带修掉一个问题：**按其中一个按钮时，两个按钮的水波纹会一起亮**。

### 界面细节

- **顶部的「记事卡片 / 对话框」不再有底色**，选中的那一个用主题色加粗表示，按下仍有胶囊形水波纹。
- **换色按钮去掉了圆形底**，只留图标本身与一圈水波纹；图标改用与页面其它图标相同的颜色，
  浅色模式偏黑、深色模式偏白。
- **颜色精度的两个选项移到了标题同一行的右侧**，选项名改成「标准」与「高」，
  样式与「音频海浪动画设置」里的「导出色彩设置」一致。说明也重写了：标准精度用 8 位表示颜色，
  计算压力更轻；高精度用 16 位，过渡更细腻。
- **性能自动调节整行都可以点**，点标题或说明都能切换；标题与说明之间的间距加大了，
  勾选框的水波纹也不再被裁掉。说明改成「连续掉帧时自动调整粒子大小与流动精细度，以减轻计算压力」。
- 「恢复默认」的文字与上方各行右对齐。

### 示例记事换成《远山》

> 远山不来，
> 我也不去。
> 风把云吹过山脊，
> 两不相欠，各自完整。

十三种语言都写好了。示例对话框的文字没有变。

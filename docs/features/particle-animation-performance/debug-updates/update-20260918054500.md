## 粒子动画：同一套画面，华为平板上每帧少花一成半

这一版只动「同一件事在哪一级算、要不要多做一遍」，**画面与上一版逐位相同**——两台真机上
各比了 61 帧整屏像素，一个像素都没变。

### 改了什么

- **减少一遍遍的等待**：动画每一帧内部要让 GPU 的各个步骤排队好几十次，此前每次都按最严的
  方式等；现在按各步真正的依赖来等，只有真正需要的那一次保持原样。
- **压力计算少占一半的临时空间**，高通平台上因此能同时跑更多线程。
- **按芯片厂商分路**：华为这类 GPU 换用更小的线程分组，高通平台保持原样。
- **每帧的清零只做真正用到的那一块**，不再整张网格重来一遍。
- **每片粒子共用的那几个数只算一次**：此前颜色、透明度、高光里有一批数其实对同一片粒子的
  所有像素都一样，却在每个像素上重算；现在每片每帧算一次。

### 实测

华为 MatePad Pro 13.2（Maleoon 910）离屏成对测量，同一份素材只切开关：

- 消散动画每帧 **−10% ~ −15%**；
- 出现动画每帧 **−19%**；
- 关闭弹窗到第一帧出现：返回键 **113.6 → 99.9 ms**，点外部 **65.2 → 58.3 ms**，
  颜色面板 **714 → 621 ms**（出现）；
- 左滑矮卡从识别到第一个有粒子的画面：慢拖 **100.2 → 76.1 ms**，快拖 **94.7 → 23.1 ms**。

魅族 20 Infinity（Adreno 740）上压力计算那一项收益最大，每帧 **−13.5%**、左滑预读 **−21%**；
整轮十三格没有一格变差，多格的最长停顿变短（弹窗消散的最长间隔：返回键 88.3 → 74.2 ms、
点外部 94.2 → 70.5 ms），关闭弹窗到第一帧 77.3 → 59.8 ms。

**天玑机型没有实机**：按芯片厂商分路的那一项在华为上验证通过，天玑属同族外推，尚未实测；
每一项都留了可以单独关掉的开关。

### 还没解决的

**默认粒子大小下，华为平板的弹窗消散仍然掉帧**（十万片以上时每秒只出十几帧）。
这一版把它抬高了约两成，但离流畅还差得远。在「设置 → 粒子动画设置」里把**粒子大小**
调大一档、**流动精细度**调低一档就能恢复流畅——这台设备上目前就是这么设置的。
后续会给出「自动按实测帧率调低一档」的选项。

### 另外

- 新增一个后台提示：动画线程会把每一帧真实花掉的时间报给系统调度器，按下卡片准备粒子时
  也会提前告诉它「这一下比较重」，让处理器早一点升上来。部分机型的系统不接受这个提示，
  接受与否都不会更差。

## 2026-10-08：飘散新增独立颜色精度设置

按要求提交前序性能优化后，继续核对两种粒子的颜色精度、大粒子绘制、透明叠加与真实长帧。在粒子动画设置中为飘散增加独立的“标准／高”，默认仍为高精度；切换样式分别保存，流体原有设置不变，恢复默认同时重置两种样式。

ParticleTuning 使用独立的 drift_color_precision_standard 偏好；ParticleStyle 与 ParticleFastOptions 将设置固定到每轮飘散渲染，ParticleDriftRenderer 的标准档使用 RGBA8，高档保持 RGBA16F。两种精度都沿用原混合方式。流体继续使用线性 RGBA16F／SRGB8_ALPHA8。

用户询问能否统一颜色格式，以及两种 8 位格式是否影响计算复杂度。已完成统一线性混合的离屏画面对照，加光亮带和暗部有明显变化；用户明确选择保留现有观感，仅统一标准／高设置的操作。未接入线性原型。设置说明也按用户要求保留原文，不增加技术细节。

368 项相关 JVM／着色器测试通过；80 组正式 GLSL 颜色精度对照完成。三星真实 UI 验证默认、独立保存、页面重启和恢复默认，日志确认格式切换生效。标准档在密集纯色区域可出现更明显的浅深颗粒纹理，因此不更改默认档位。

三星三组同输入大场景中，飘散标准档整段单帧耗时约减少 2%～3%。流体标准档同输入现场耗时约减少 3%～8%，但实际高数量／大粒子颜色消散仍约 90～101 fps，不能保证所有场景稳定 120 fps。两项流体绘制候选——直接覆盖输出与圆边快速近似——因净收益不稳定而撤回。测试后恢复偏好与诊断配置，未保存或修改真实记事。

## Doing 长卡片与计时验收：修正候选，暂不升级业务默认

用户确认卓易通退出修正后，要求进一步验证 Android 大卡片内部滚动、渲染性能、顶部计时动画及其它外观和功能，只有无回退才设为正式方案。本轮保留 SurfaceView，整页绘制仍是 debug 对照候选，普通 Doing 没有切换。

- 新增“Doing 候选：长卡片滚动与模拟计时”，使用虚构长记事，可上下滚动、左右滑动并查看真实 Timely 数字变形、无限计时呼吸；不启动真实计时服务，不改已有记事。保留原实现对照、观察记录与诊断 ZIP 导出。
- 回归中发现并修正：弹窗暗层未进入整页画面；弹窗返回后计时显示列表可能停在旧数字；HWUI 的延后出帧状态被误判为失败。保留真实控件阴影、透明度、裁剪和输入树。
- 页面控制器按 Activity 生命周期管理捕获、后台恢复、尺寸变化及退出，替换全局调试工厂；初始化失败恢复原绘制树。普通业务入口继续关闭整页候选，不新增品牌兼容开关。
- 持续更新复用双缓冲纹理；捕获期间维持刷新节拍；GPU 读取完成才归还图像。冷启动采样定位到纯 CPU 预热和首次本地库查找占住 GL 队列，已把 CPU 预热移到后台，并提前加载本地库。没有通过冻结动态背景或修改粒子参数减负。
- 三台 Android 已执行长卡片、真实计时回调及入场、加时、严格模式、取消弹窗、后台恢复、尺寸变化和三种退出场景；20 项相关单元测试通过。三星、魅族有录像，OPPO 受系统录屏权限限制，只核对状态／截图／驱动时间戳。现存媒体记事只读预览。
- 固定种子配对仍未达到正式接入条件：三星流体约 98.4→89.5 FPS；魅族飘散约 118.1→111.3 FPS，识别到首粒子回调约 323.7→357.0ms。其它组合相近或更快，不能抵消这些回退。FPS 为短窗口驱动呈现取样，回调不等于最终屏幕证据。

此包用于继续对照，整页方案未设为正式默认。后续重点是整页捕获、GPU 复制与粒子合成的竞争，以及复杂媒体冷加载；保留所有已有视觉参数和动态内容。

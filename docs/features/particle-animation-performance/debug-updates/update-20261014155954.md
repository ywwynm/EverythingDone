# Doing 滑动性能测量：复杂卡片样本

用户要求在三星 R5CW20BLNKL、OPPO 9018f404、魅族 192.168.100.67:40807 上核对 DoingActivity 的刷新率请求和滑动帧率，并补充图片、视频 GIF 封面、长 checklist 的复杂卡片测试。

本次仅扩展 debug 自动化入口：ParticleDoingProbeActivity 支持内存中的图片、视频和 90 项三级清单样本，ParticlePresentationRegressionProbe 传递卡型参数，并为真实视频封面生成保留测量准备时间。媒体沿用正式加载与 GIF 生成流程，未修改生产页面、计时数字、粒子渲染、刷新率请求或记事数据。

三台完成长文本 6 轮、复杂卡片 18 轮及魅族视频流体定向复核 1 轮，均采用驱动呈现时间戳、不录屏、不抓图。三机已有 120 Hz 请求，OPPO 144 Hz 未被请求且系统当前也限制为 120。纵向滚动三星约 60–64 FPS、OPPO 约 82–96 FPS，魅族图片／视频接近 120、长清单约 88–100 FPS；魅族视频流体首次启动存在额外延迟。具体原因仍需分阶段追踪，本次未实施性能修复。

本地 assembleDebug 已通过；复杂样本实际运行完成。测量方法、原始报告、分析脚本与后续项归档于本功能目录。

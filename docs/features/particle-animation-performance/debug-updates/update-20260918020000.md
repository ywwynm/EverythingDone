## 粒子动画设置：整页改成产品界面，预览跟着你的记事颜色走

上一版新加的那个二级页面是按调试界面的样子做的。这一版把它整页重做：名称、文案、控件样式、
预览内容与档位全部换过，**默认的动画效果与上一版逐位相同**。

### 名称与文案

- 页面与入口都叫**「粒子动画设置」**。
- 「微片尺寸」改叫**「粒子大小」**，「压力求解迭代数」改叫**「流动精细度」**——数值越高，
  粒子之间的推挤越细致，动画开销越大。
- 卡片下方的提示只剩一句「左滑以预览动画效果」。
- 下方读数改成四项：**粒子总数 · 渲染帧数 x / y · 渲染间隔 · 渲染帧率**。渲染间隔与帧率取
  同一份数据，互为倒数；这一轮掉没掉帧看「渲染帧数」那一格。

### 预览

- **示例记事卡最宽 640 dp 并居中**，平板横屏下不再铺满整行。
- 「示例面板」改成**示例对话框**：底色是常规的浅色 / 深色底，圆角、内边距与按钮排布都照应用里
  真正的对话框取值，只有标题与「确定」着色。
- **预览的主题色取自你自己建过的记事**：进页面随机取一条记事的颜色，预览区右上角的调色盘
  按钮可以换一种，方便看不同颜色的卡片消散成粒子是什么样。一条记事都没有时用默认记事色。

### 控件

- 顶部的「记事卡片 / 对话框」与「恢复默认」改成胶囊形，按下时是 accent + accent2 的渐变涟漪。
- 两根滑动条换成应用自己的渐变滑动条，带刻度：每一档都画出来，选中的那一档高亮。
- 二级页的顶栏下方补上了投影，与设置页、帮助页一致。

### 粒子大小的档位

改成十六档：0.64、0.72、0.84、0.96、1.08、1.29、1.5、1.6、1.8、2.0、2.1、2.4、2.56、2.7、
3.0、3.2 dp，当前值旁边标出本机对应的像素，例如「0.96 dp（3 px）」。

**没有选过时用的仍是一直以来的取值**，滑杆停在最接近的那一档（0.84）并标着「默认」，
拖动之后才按选中的 dp 生效。上一版显式选过的档位会自动搬到新档位里最接近的一个。

界面文案同时补齐了全部十三种语言。

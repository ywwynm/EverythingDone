# 粒子高刷与渲染性能优化

## 2026-10-08：继续提高两类粒子动画的实际帧率

用户希望按上一轮建议继续优化，以稳定 120 Hz 为目标；继续在三星 R5CW20BLNKL 测试，重点覆盖添加附件和改变记事颜色的大弹窗。

- 飘散按实际覆盖收紧粒子的绘制方框，细小颗粒保留原几何，保持最新清晰度和完整窗口轨迹；三星高数量、大粒径场景绘制耗时下降约 14%。
- 普通流体启用高刷播放；出现动画利用相邻历史状态连续插值，历史缓存仍保持原密度。
- 三星 Adreno 上合并相邻 240 Hz 积分步骤的提交，并按原顺序压缩当前可见绘制实例；不减少用户设定的粒子、不跳过模拟、不改变透明混合顺序。压力求解采用严格的 GPU 缺陷阈值，并保留用户迭代上限。
- 将当前画面不读取的末步压力计算安排在交换缓冲之后，下一次积分前仍完成同样的计算；状态与画面对照完全一致。
- 粗压力阈值、后半段压力／积分降频因轨迹偏差过大未采用；保留 96 压力网格。
- 三星默认数量、默认大小下，附件和颜色弹窗的出现／消散，两轮实测约 119～120 fps；附件消散仍各有一次双帧间隔。高负载（数量 1.6×、大小 3×）下，飘散约 118～120 fps；流体附件消散约 112～113 fps，颜色消散约 92～103 fps，尚未全部稳定 120 fps。
- 同包离屏组合对照：流体重负载整段耗时下降约 21%～25%，回放约下降 26%～33%。这些比例不等同于实际屏幕帧率涨幅。
- 366 项相关测试通过；完成着色器数值、像素、历史插值、实例顺序与最高 200 次压力迭代检查。测试只开关空白记事弹窗，未保存记事；用户设置已经恢复。

详细过程与误差限制见本功能的 `implementation-2026-10-08-120hz.md`。未测试其他设备，不保证所有机型和所有粒子设置都达到 120 fps。

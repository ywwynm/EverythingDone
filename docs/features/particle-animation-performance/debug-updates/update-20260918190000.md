## 粒子动画设置：切到示例对话框不再先空一下，也不再多播一遍

这一版只改「粒子动画设置」页面里示例对话框的出场方式。

### 切过去就是一个静止的对话框

此前切到「示例对话框」时，画面会先空一下，然后依次播出现、消散、再出现，粒子动画等于白播了
一遍。现在切过去的那一帧上对话框就已经在了，停留约 0.6 秒之后只播一轮消散与出现，回到同一个
静止的样子。离开这一格再切回来、回到页面、换粒子方向、改参数之后重播，走的都是这同一轮。

多出来的那一次「出现」原本是被迫的：动画从看不见开始、又必须停在看得见的状态上，出现的次数
就必然比消散多一次。现在静止的样子既是起点也是终点，这一次就不需要了。

### 直接显示的样子与动画结束时完全一致

两台设备上各取了两张无损截图逐像素比对：切过去那一瞬的对话框，与一轮动画播完之后的对话框，
在含整圈阴影的范围内（82 万与 97 万个像素）没有一个像素不同，位置、圆角与阴影都对得上，
接上动画或从动画接回来都不会跳一下。

粒子层或快照还没准备好时，对话框就那么静止地显示着，等准备好再开始那一轮；万一这一轮起不来，
也只是不播，不会把对话框藏起来。

### 实测

两台设备各录了两段：首次切到这一格、以及切走再切回。逐帧看下来，切换落地的那一帧上对话框
已经在了，切换到消散开始之间没有一帧是空的，对话框的亮度只穿过中点两次（也就是一次消散加
一次出现），单帧之间最多变化 1 到 2 个色阶。

粒子动画本身没有任何改动：两台设备上默认档位的逐帧比对全部零差异，粒子数量、帧数等关键读数
与上一版逐项相同。

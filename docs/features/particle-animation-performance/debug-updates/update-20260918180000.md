## 粒子动画设置：版式对齐系统设置页，阴影交接与方向切换不再闪

这一版把「粒子动画设置」的版式、阴影交接与方向切换三处收尾做干净。

### 版式与「空间照片效果」设置页统一

整个参数区的字号、行高与间距改为与「空间照片效果」设置页完全一致：各行左右留白 16 dp，
带读数的选项行高 56 dp，选项标题 16 dp 字号、右侧读数 14 dp 字号，说明文字统一为浅色小字并
紧跟在控件下方。滑动条改为整行宽度，轨道与标题左缘对齐。「性能自动调节」整行改用与该页
「通过倾斜设备控制视点」相同的样式：行高、字号、勾选框位置、说明文字的字号与间距、整行可点
与涟漪范围逐项相同。两台设备上逐项实测，全部项目与参照页的差值都在 0.3 dp 以内。

### 示例对话框的阴影不再闪一下

示例对话框的阴影此前在粒子动画开始与结束的瞬间会明显加深一下。原因是交接期间阴影被同时画了
两层。现在改为让阴影与真实对话框、与粒子画面分别在同一帧内交接，中间不再有重叠。实测对比：
改动前每一轮动画都会出现两处「比静止时更深」的画面（其中一台深达 22 个灰阶），改动后为零。

### 切换粒子方向变成一次完整过渡

在示例对话框上切换粒子方向时，对话框不再瞬间消失再重新播放，而是直接用新方向消散一次、
再出现一次，一共一轮。若切换时动画正在播放，会等当前这一轮结束后再按新方向播。
切换预览类型时，正在播放的对话框粒子也会一并收起，不再残留在记事卡片上。

### 其他

修正了在动画时长被系统放大的设备上，示例对话框自动播放的下一步可能压在上一步收尾上的问题：
现在每一步都等上一步真正播完之后再排下一步。

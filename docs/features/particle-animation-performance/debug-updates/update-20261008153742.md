## 2026-10-08：流体粒子减少记录生成与筛选的重复工作

用户确认先试压力散度复用、绘制记录生成与筛选合并；更快的带约束压力求解器留到下一步。已在三星 R5CW20BLNKL 上完成同包独立／组合测试、实际大附件与颜色弹窗回归，以及真实材料逐帧交替对照。

- 默认采用 draw-record.comp 与 compact-circles.comp 的记录生成／稳定扫描合并。ParticleMicroflakeRenderer 省去一次全量扫描及逐粒子偏移表，减少无效写入、提前略过屏外颜色计算，保持原粒子顺序、数量、轨迹和颜色精度。约 25.5 万颗粒子时少分配约 0.97 MiB。
- 三星同输入整段现场耗时约降 4%～8%，已准备回放约降 6%～9%；真实弹窗材料逐帧交替测量的完整阶段平均约省 5%。轨迹差为 0，RGBA8 最大通道差 1 灰阶。
- 压力输入复用试过全网格及活动区域加 8 格边带两版，大弹窗现场净收益约 0%～1%，不足以默认采用。保留明确的 debug 对照，release 不启用该程序或分配缓存。
- 默认数量与大小的两轮附件、颜色出现／消散共 8 次均约 120 fps，帧间隔 P90 为 8.34 ms。数量 1.6×、大小 3× 的实际颜色消散仍约 90～106 fps；最差帧未一致改善，尚未达到全部场景稳定 120 fps。
- 366 项 JVM／着色器测试、590 组正式 GLSL 检查通过。测试后原动画偏好、诊断开关与旋转设置均恢复，只开关空白新建页弹窗，未保存或修改真实记事，未创建 Git 提交。

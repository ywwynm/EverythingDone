# 参考轨迹的两阶段概率（2026-10-07）

## 问题与用户要求

用户反馈华为参考动画出现过于频繁，多个参考覆盖同一方向时更明显。要求先以概率 X 选择「参考」或「随机生成」，选中参考后再从可用参考中随机选一条；X 随可用参考数量确定，改完发布阿里云并说明概率。

原实现先尝试偏爱组，未命中再以 50% 尝试其他参考，因此总概率为 `p + (1 - p) × 50%`。有其他候选时，旧钢铁侠方向是 75%，朝上组与其他参考重叠的方向最高 87.5%；正上仅有朝上组时也有 75%。问题来自多阶段机会相加，并非简单的每个文件独立抽签。

## 新的概率分配

1. 仅保留风向与本次方向相差不超过 22.5° 的参考，移除灭霸，以及紧邻上一段和同类上一段的参考来源；原版与变体按同一来源计数，得到 N。
2. 以 `X = min(12% × N, 36%)` 判断本次是否使用参考。未命中即随机生成，不再进入另一组参考的抽取。
3. 命中后，N 个参考来源等概率选择，各占 `X / N`。

| 可用来源 N | 参考总概率 X | 随机生成概率 | 每个参考来源的概率 |
| --- | --- | --- | --- |
| 0 | 0% | 100% | — |
| 1 | 12% | 88% | 12% |
| 2 | 24% | 76% | 12% |
| 3 | 36% | 64% | 12% |
| 4 | 36% | 64% | 9% |
| 5 | 36% | 64% | 7.2% |
| 6 | 36% | 64% | 6% |
| 7 | 36% | 64% | 约 5.14% |
| 8 | 36% | 64% | 4.5% |

12% 与 36% 是本轮采用的可调常量：候选少时减少熟悉轨迹的频率；三条及以上保持多数动画随机生成，新增参考细分同一个总份额。用户没有指定具体百分比。

选中旧钢铁侠或朝上一组后，仍按原版 40%、变体 60% 分配，其他来源保持原版；变体不增加 N 和 X。例如六个候选时，旧钢铁侠合计 6%，其中原版 2.4%、变体 3.6%。旧钢铁侠和朝上一组不再获得额外的一次抽取机会。

当前资产在没有近期排除的情况下：45° 有 1 条、正上 90° 有 4 条、左上 135° 有 6 条、120° 有 8 条。上述概率按每次开播时剩余的 N 计算；去重可能减少 N，长期统计比例不必等于某个固定方向的初始概率。

## 实现与播放记录

- `ParticleDriftStyles.pick` 统一过滤和去重后，只执行一次参考总概率判断、一次来源等概率选择；原版／变体的判断在选定来源之后。
- `ParticleDriftSequence.prepare` 记录预热时的排除集合，实际 `start` 时若集合变化就重新选择，包括原本未重复的参考和随机候选，避免使用过时的 N。
- 同一会话跟手、回退和重复绘制不会重抽；取消预热不消耗历史。调试工具显式固定参考的行为保留。

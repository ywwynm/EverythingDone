# 粒子动画性能优化

跨三个功能的性能专项：弹窗粒子出现/消失（`dialog-particle-dismiss`）、新建记事入场（`thing-creation-animation`）、左滑完成记事（`swipe-complete-animation`）共用同一套粒子管线，性能问题也是同一组结构性原因，所以放在一个目录里处理。此前逐帧性能批次以保持粒子模型、材料、随机、积分与压力迭代次数为约束；2026-10-08 按用户新要求调研并实施允许轻微画面变化的近似方案，以实机净收益决定默认启用项。

## 本目录的工具

- `device_batch11_ui.py`：第十一批的真机取证驱动，三个子模式。`--mode enter` 录**首次**切到
  对话框那一格（先进一次量下 bounds，退出页面再重新进来），`--mode back` 录「切走再切回」，
  两者按同一套判据逐帧分析；`--mode still` 把 `input tap` 与 `screencap` 合并成**一次**
  `adb shell`，落进切过去那 0.6 s 的静止窗口，与一轮播完的静止态**逐像素**比。
  另有两个**不碰设备**的离线开关：`--reanalyse`（按已落盘的逐帧序列重算判据）与
  `--recompute`（按已录下来的那段视频重新逐帧量一遍）。
  **三个坑写在脚本里**：判「卡片还在不在」要取**卡片左侧露出来的那一条**（贴着对话框上缘那一条
  在三星上只有 4 px，判出来的切换时刻晚两秒）；`screenrecord` 只在画面变化时出帧，静止的卡片
  那一格**切换前可能只有一帧**，基准取整段**最大值**而不是前几帧的中位数；「两个画面是不是
  同一个」不能用录屏判（H.264 的本底与信号同量级），必须走无损截图。
- `device_batch10_ui.py`：第十批的真机取证驱动，三个子模式（`--mode all` 依次跑）。
  `--mode gradient` 量「状态栏与顶栏交界处相邻两行的色差」，并用「同一块内部相邻两行的色差」
  作**噪声底**；`--colors N` 连点换色按钮各量一遍，`--need-gradient` 一直点到抽中一条**竖直分量
  大**的记事渐变为止（纯色与横向渐变在交界处本来就没有断不断开可言，脚本用 `vertical_span` 判）。
  `--mode slider` 把滑杆推到 **0 / 中间 / 最大值**：两端量**滑块外缘**、中间量**轨道两端**
  （滑块让开了两端的轨道才露出来），跑前备份 `shared_prefs/particle_tuning.xml`、跑完写回并读回。
  `--mode edges` 量右侧一列四项的「bounds 右缘」与「墨迹右缘」。
  **三个坑写在脚本里**：滑杆的底色要取整条里出现次数最多的颜色（上下内边距是 0，滑块停正中时
  「上沿中点」正好落在圆顶上，整条会被判成墨迹）；右缘要**逐屏**测量（先 dump 再截图再 dump 核对，
  「先收齐 bounds 最后截一张」在需要滚动时必然错位）；写回 prefs 要走 `run-as … sh -c 'cat > 文件'`
  喂原始字节，PowerShell 的 `Get-Content -Raw |` 会带上 BOM。
- `device_batch9_ui.py`：第九批的真机取证驱动，四个子模式。`--mode bounds` 先进
  「空间照片效果」设置页把参照行的 bounds 读出来，再进本页读一遍，全部换算成 dp 做逐项对照
  （**差值超过 1 dp 即不合格**）；`--mode shadow` 录一整轮对话框动画，逐帧量对话框下缘那条
  阴影带的灰度，判据是**「比静止态还深」的帧段**（阴影只会变浅，更深就说明同时画着两份），
  配 `--handoff on|off|clear` 在**同一个包**上做受控 A/B；`--mode direction` 录一次方向切换，
  逐帧量对话框本体亮度，判据是「穿越中点恰好 2 次」+「单帧最大变化 ≈ 1 个灰阶」；
  `--mode shots` 只取静止截图。**两个坑写在脚本里**：参照页的 `row_depth_detail` 只在选中
  MoGe 系模型时可见，设备上量不到，56dp 的行改用「清除全部已生成空间效果」那一行、16sp 的
  字高与左缘改用「推理运行环境」那个 `wrap_content` 标题；`uiautomator` 把 bounds 裁到可见区域
  内，贴住屏幕上下边的节点一律丢掉、滚过去再收。
- `device_batch8_ui.py`：第八批的真机取证驱动。一轮按顺序取：静止一屏（图标取色、参数区、

  尺寸与间距一律按它取值，截图上量墨迹会被字形留白带偏）、`--dir-effect b,lt`

- 第九批的逐项开关（同在 `ParticlePerfTuning.kt`）：`panelShadowAtomicHandoff`（含投影的页内
  面板在粒子起止两端走窗口内原子交接，**默认开**）。关掉就退回第八批那条「含阴影的快照画在
  窗口内的叠加层上 + 交接那一次遍历把真实 `elevation` 置 0」。留它是为了能在**同一个包**上
  取「修前」数据做受控对照，不必为此重建旧版本。
- 第四批的逐项开关（同上）：`dialogAppearanceSkipEmptyTail`（弹窗/面板/新卡片的 2c，默认开）、
  `creationPrewarm` / `creationPrewarmIdleMs`（创建页轨迹提前预算，默认开 / 500 ms）、
  `rippleHighFrameRate`（涟漪期投高帧率票，默认开）、`atrace`（自定义 trace 分段，默认关）、

  建材，末帧散列仍等于真实页面那一帧）。

- `device_batch3_setup.py`：建专用测试记事（含经真实系统选择器加一张图）、切换新建/左滑档位。

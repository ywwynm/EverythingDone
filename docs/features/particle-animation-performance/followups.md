## 三星首轮实施后的优先级建议（2026-10-08）

- 新发现的飘散绘制机会：`drift-particle.vert` 当前仍以 `h + 1` 为外接方框半宽；解析覆盖在归一半径 0.64 以外为零，每个工作像素的四个采样只各偏移四分之一像素。可先按实际覆盖半径加保守抗锯齿余量收紧单粒子方框，保持 `v_q = local / h`，减少完全透明片元的四次覆盖计算。只收紧单粒子几何，完整窗口工作面和可见轨迹保持。大粒子极限下理论方框面积比约为 `0.64² = 0.4096`，不等于 GPU 耗时比例；需验证小粒子、亚像素平移与消失末段的边缘完整性。本轮仅核对源码、分析，未改代码或测量此项。
- 流体优先测当前版本的压力求解占比，再试基于非负投影固定点缺陷的批间提前停止，保留用户迭代上限、既有暖启动与 96 网格。误差检查留在 GPU，并同时量屏幕位置与局部密度；检查成本也算入净收益。压力阶段省 30%、若占整段 50%，整段只省约 15%，不能按迭代降幅宣传整帧收益。
- 第二顺位分别试平稳段压力 60→30 Hz、积分 240→120 Hz；新生和快速变化阶段保留原频率。现场复用旧压力场与离线利用前后场插值分开评估，不能假定现场已知未来状态。
- 两类均可评估稳定压缩存活／可见绘制实例，保留原粒子 ID 和混合顺序；屏外剔除只针对绘制，不跳过未来可能重新进入窗口的模拟。当前已有寿命后积分早退和活动压力区域，不重复计入收益。
- 飘散收紧方框后再考虑覆盖曲线拟合，减少四次 `length` 的成本；暂不进一步降低工作面分辨率，以保护刚改善的细点清晰度。11 抽头→7 抽头模糊属于约 0%～3% 的整段小项；更换求解器、历史压缩排在前述方案之后。
- 此阶段目标随后由用户更新为尽量稳定 120 fps；高刷显示计划与连续回放已实施，历史密度保持独立。仍用实际呈现长间隔和队列等待验证，避免只改善离屏均值。见 [120 Hz 实施记录](implementation-2026-10-08-120hz.md)。

  没有实测过。真挤了的话按奇偶抽稀即可。
- **「粒子总数」仍然只在播完一轮之后才更新**（第四批已记，这一版沿用）：改完档位停在记事卡片
  预览时，读数是上一轮的。
- **上一版的档位迁移只保留一次**：`particle_size_dp_index` 一旦写入，旧键就删了。
  如果以后还要再改梯度，迁移要按同样的方式再写一遍，不能指望旧键还在。

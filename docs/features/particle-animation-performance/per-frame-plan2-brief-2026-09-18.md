## 审阅结论

1. **批 B 的「每项单独 A/B」只在离屏分段基准上做**（每项在华为与魅族各一次，与第一批做法相同），真机 UI 矩阵
   仍然每批每台一轮。两条纪律并不冲突。

   整帧与累积纹理 alpha 直方图；U8、U10 同样出图；**U9（按实测帧率自动降档）实现成开关默认关**（纯逻辑 + JVM
   单测 + 调参页里的「已自动降档」提示），等用户裁定后再打开。
3. **第一步之前先补 G0 基线路径缺的 `GL_VERTEX_ATTRIB_ARRAY_BARRIER_BIT`**（方案 1.2 末尾那一行），补完先在
   魅族跑一次自比较确认对照工具本身仍然稳定。
4. 华为的 `ParticleTrajectoryCheck` 按方案 3.3 **缩小规模**（只比中心 512×512 或 10%/50%/90% 三帧），跑之前定好，
   不再让它拖垮整轮。

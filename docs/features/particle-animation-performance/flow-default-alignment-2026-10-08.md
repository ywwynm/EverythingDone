# 流体 1× 大小与数量对齐飘散

## 要求与基线

用户指出流体默认数量、大小与飘散差距过大，要求重设流体的 1×，降低默认计算压力。随后指定两种样式的 1× 大小均改为 1.6 dp 供试看。数量以当前飘散为参照，保留两种设置独立倍率和两种运动风格。旧有“1× 为各自原始默认值”的约定由本轮新要求取代；既存倍率仍表示相对新基准的倍率，不反向换算成原来的绝对数量和粒径。

在同一纯色快照、三星密度 3.75 下，通过实际 `ParticleMicroflakeModel.build` 复现：

| 尺寸 px | 原流体数量 | 飘散基础数量 | 数量比 | 原流体圆边基准 dp |
|---|---:|---:|---:|---:|
| 630×300 | 17,381 | 10,000 | 1.74 | 0.791 |
| 1050×1047 | 101,442 | 34,000 | 2.98 | 0.790 |
| 1380×2281 | 159,543 | 50,000 | 3.19 | 1.066 |
| 1440×3088 | 159,432 | 50,000 | 3.19 | 1.267 |

有色内容面板同输入为流体 122,562、飘散 41,191。数量差距主要来自默认发射网格；统一减到原来的固定比例无法同时适应小卡片和大面板。三项新验收在旧实现上失败，原始结果保存在 `tmp/flow-default-alignment-20261008/before-model.xml`。

## 实施与待验证项

- 流体默认基础预算使用飘散相同的面积公式、上下界与数量倍率；发射点仍是流体自己的规则网格，按最接近目标数量的行列数取整并铺满表面，差异须小于 3%。飘散新基准数量为此前的 49/64（约 76.6%），内容副本总量上限同步从 75,000 降为 57,422；最高数量档基础数本身超过它时不截掉基础网格。
- 两种样式按圆边半峰值直径统一标定为 1.6 dp。流体几何宽度为 1.6 / 0.9 dp，飘散按普通粒子平均外框宽度与片元 50% 边界补偿；需通过实际着色器及连续画面验证，不能把这一基准说成每颗粒子整个寿命的固定直径。
- 阴影扩展先按本体面积确定预算，再保持原发射密度扩展；可见大小独立控制，不能因阴影或数量倍率改变。
- 显式 dp 调试路径和历史冻结材料保留原网格用于算法对照；正式入口采用新基准。设置文字、档位、默认倍率和颜色精度保持已有定义。
- 先完成模型测试与离屏粒径检查，再在已授权三星上合并执行一轮同输入前后基准、默认／高负载大弹窗及设置预览验证；不以旧随机画面的帧率差值作为收益。

## 飘散数量与视觉判断

用户提醒增大粒径后重新检查默认数量。`checks/check_default_scale.py` 使用已保存的浅色弹窗、深色弹窗、照片参考输入，运行现行正式 GLSL；每组保留快照、风场、出生、寿命和随机输入，比较旧 1.4 dp、新 1.6 dp 原数量、新 1.6 dp 数量乘 49/64。共 189 帧，连续对照保存在 `tmp/flow-default-alignment-20261008/visual/*/compare.gif`，不是新实机帧率采样。

只放大时色块、黑色文字和深色场景的亮粒子明显变厚；面积补偿减量后单颗更清楚，整体形状、主要色团、消散范围仍完整，疏密更接近旧版。以下指标仅取原表面完全消失后的相同时刻；“对比强度”为每像素相对背景的最大通道差求和，覆盖为差值超过 12/255 的像素数，不等于感知评分。

| 固定输入 | 只放大：对比强度变化 | 减量：对比强度变化 | 减量：覆盖面积变化 |
|---|---:|---:|---:|
| 浅色弹窗 | +21.02% | +0.31% | −1.87% |
| 深色弹窗 | +25.46% | +0.17% | −1.29% |
| 照片参考 | +26.14% | −0.26% | −3.81% |

据此采用 49/64 的固定基准减量，不让设置中的大小倍率动态改变数量。两种样式 1× 的正式片元半峰值测量分别为 1.59989 / 1.59995 dp，0.5×、3×、6× 也通过同口径校验。相同形状不代表逐像素一致，较少、更大的颗粒是本轮允许的画面变化。

- 372 项相关 JVM／着色器源检查测试全部通过；完整 debug APK 构建成功。历史冻结材料明确走旧网格作为算法回归，新默认的面积预算、数量／大小独立、跨密度尺寸和有色内容另行验证。

## 当前可成立的结论

- 提前设置窗口透明度未改善已测试的普通 Dialog。额外隐藏普通内容的候选在普通、叠层及固定独立 Surface 场景中获用户确认正常；组合配置下普通和叠层仍正常。此结果支持保留内容隐藏候选，不证明单独的 `Decor.alpha` 是唯一原因：候选同时调整阴影属性，独立 Surface 捕获也换了来源。
- 前景根节点挂载候选在单独启用和组合启用时均未解决卡片前景消失；不能将其推广到正常业务页面。
- 代码在交接时主动把原前景控件的 `transitionAlpha` 设为 0，由自有 SurfaceControl 缓冲接替显示。替代内容未显示时，原控件便在整段动画中消失；结束恢复符合这条生命周期。
- 固定色块不依赖原控件的捕获或隐藏，仍不可见，提示应检查自有缓冲层提交／合成路径、坐标或裁剪等环节。但下述缓冲用途核对发现探针自身存在不严谨之处，当前色块负面结果只能作为线索，不能单凭它排除前景捕获问题或判定卓易通不支持 SurfaceControl。现已补充真实前景源缓冲图像，捕获为空的解释优先级降低。
- 本次简报里的两次色块测试分别为“原实现”和“只改 Dialog”，都使用原父节点；没有单独记录根节点色块测试。根节点的真实前景候选失败已记录，但不能把它写成固定色块的完整父节点配对结果。
- 底部面板尚未判断；FLOW、连续 12 次、真实录音、取消与切后台等结果未提供。API 36 仅为应用看到的接口级别，不等同于宿主实现的全部行为保证。

## 后续证据与方向

- 已完成当前 ZIP 的源图像、提交回调、位置、透明度和生命周期核对，不再等待这份 ZIP，也不要求用户重跑已有失败组合。
- 后续应修正固定色块的缓冲用途契约，并记录实际 usage；同时修正卡片交接快照的同类用法。真实前景已请求 composer overlay，不能承诺只修这两处就能解决控件消失。
- 新一轮前景修复候选优先评估：保留共享 SurfaceView，将已验证有内容的前景图像合入其 GL 输出，绕过当前直接向自有 SurfaceControl 提交前景缓冲的路径。静态卡片交接也应走同一可见输出，避免只改前景而仍依赖有疑点的临时层。复用已有捕获与 FAB 阴影，处理控件更新、颜色、首尾帧和取消恢复；不回退 TextureView、不单纯提高 Z、不仅关闭原控件隐藏。
- 修正后的最小色块对照用于继续定位独立缓冲层兼容性；GL 前景候选则用于验证可行替代路径。两项结论分开记录，不从某条路径可见推导其他路径实现完全正常。
- Dialog 保留额外内容隐藏候选，重点补底部面板、真实独立 Surface、返回／切后台和两种粒子样式；不再把提前窗口透明度作为主要候选。
- 本轮处理用户反馈和附件，只更新分析资料与离线统计脚本，未扩大候选作用范围、修改应用代码或发布新包。继续禁止 ADB。

## 同轮源码／平台契约复核

- `ParticlePresentationMarker` 用 `Bitmap.copy(Bitmap.Config.HARDWARE, false)` 生成色块缓冲，再交给 `SurfaceControl.Transaction.setBuffer`，没有显式保证或记录缓冲 usage。
- [Android 官方 setBuffer 文档](https://developer.android.com/reference/android/view/SurfaceControl.Transaction#setBuffer(android.view.SurfaceControl,android.hardware.HardwareBuffer)) 要求缓冲同时具有 `USAGE_COMPOSER_OVERLAY` 与 `USAGE_GPU_SAMPLED_IMAGE`。[AOSP HardwareBitmapUploader](https://android.googlesource.com/platform/frameworks/base/+/refs/heads/main/libs/hwui/HardwareBitmapUploader.cpp) 的普通硬件 Bitmap 分配只请求 GPU sampled 用途，没有 composer overlay；不能以 `Config.HARDWARE` 保证满足合成器用途。
- 这是当前色块探针的代码契约缺口；目标容器实际返回的 usage 未收集，尚不能判定本机不可见一定由此造成。卡片临时交接层的 `ParticleCardSurfaceHandoff.prepare()` 也使用同类 copy 路径，应一并核查。
- 真正的 `ParticleForegroundSurface` 已给 ImageReader 请求 composer overlay 与 GPU sampled 用途；不能把色块探针的缺口直接当作所有前景消失的已证实根因。

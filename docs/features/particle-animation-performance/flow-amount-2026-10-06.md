# 流动样式的粒子数量设置

## 需求与实现

- 在粒子动画设置页为「流体」增加「粒子数量」，与飘散共用 0.2～1.6 倍、步长 0.1 的滑动条；两种样式独立保存，默认均为 1 倍。
- 流体原有数量由材料网格与内容补充粒子决定。数量倍率调整网格密度与数量预算；释放后的粒子尺寸补偿回原大小，避免数量滑杆只是反向的大小滑杆。释放初段平滑过渡，静态内容仍完整覆盖。
- 1 倍沿用原有网格、材料和大小；实际总数受网格取整与内容采样影响，近似按倍率变化。
- 数量进入材料共享的匹配条件和创建页预计算缓存键，避免沿用旧设置的材料或轨迹。
- 切换样式刷新当前数量，恢复默认清除两种样式的数量设置；改动后沿用现有预览刷新方式。

## 2026-10-07：低数量或大尺寸时的初段方块感分析

本轮按用户要求只分析，依据当前源码与着色公式核对；没有修改应用代码，没有连接设备或重新发布。未对用户本次的具体参数组合做真机逐帧复现。

### 原因与证据

1. **初段可见形状确实来自微片设计。** `material.vert` 用原界面网格的四角构造带局部纹理的四边形，四角另有随机偏移；`material.frag` 的 `shape=mix(1.,cut,shape_out*.92)` 先保留整个四边形，再随释放年龄逐渐引入圆形／椭圆形遮罩。微片属于粒子的一种表现形式，流体运动并不要求粒子呈方块。
2. **本次数量实现放大了已有方块感。** `ParticleMicroflakeModel.kt` 通过扩大网格来减少数量。忽略取整与预算余量，0.2 倍数量对应约 `1/sqrt(.2)=2.24` 倍的初始边长；`material.vert` 与 `draw-record.comp` 的尺寸补偿均受 `smoothstep(.018,.18,age)` 控制，刚出生时尚未补偿。所以上次所说的数量和尺寸分离，仅在释放充分之后成立，初段仍有关联。增大粒子尺寸也会扩大基础网格，使四边形更容易被看见。
3. **现有圆化不能保证始终近圆。** 圆化系数随年龄增加，面板权重较高时更接近上述较慢的释放进度；粒子淡入可以早于圆化完成。即使圆化完成，圆外仍保留 8% 的形状遮罩贡献，还需乘纹理透明度与淡出系数，并非最终像素固定为 8% 不透明。随机不等轴半径、四角扰动和横向压扁也会让轮廓偏离屏幕上的圆。
4. **原表面的退出也受粗网格影响。** 现有渲染已分原表面与移动粒子两遍，但二者使用同一材料网格，原表面每格整体淡出。因此只改移动粒子的遮罩，仍可能保留粗分块的退出边缘。

公式核对例：面板权重取 1、模拟年龄为 0.022 秒时，粒子出生淡入已完成，圆外角部的形状贡献仍约为中心的 96.5%，0.2 倍数量的几何边长仍约为默认的 2.23 倍。这里是模拟时间与形状遮罩比例，不是设备墙钟时间或最终像素透明度。

### 可行方向与验证边界

- 可以让飞出粒子从可见起就接近圆形，无需更换流体运动、方向控制或倒放机制，也无需把 GPU 的四边形载体改成圆形网格。
- 建议在现有两遍绘制基础上，将原表面的消失分辨率与飞出粒子的数量、尺寸分开控制；飞出粒子从出生起使用近圆遮罩和选定尺寸，并限制让轮廓明显偏离圆形的变形。
- 低数量且尺寸不变时，飞出粒子覆盖自然更稀，应由原表面淡出与粒子出生衔接处理。只把圆化系数改为 1 可能产生提前露孔或明显的密度跳变，不能据此认定已完整解决。
- 上轮验证确认了数量设置、持久化、实际数量和高数量动画，但没有覆盖低数量／大尺寸组合下的初段轮廓；该视觉问题没有被识别。后续若实施，应补看这两类组合、默认档位，以及消散和倒放时的逐帧衔接。

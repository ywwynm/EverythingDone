# 流动样式的粒子数量设置

## 需求与实现

- 在粒子动画设置页为「流体」增加「粒子数量」，与飘散共用 0.2～1.6 倍、步长 0.1 的滑动条；两种样式独立保存，默认均为 1 倍。
- 流体原有数量由材料网格与内容补充粒子决定。数量倍率调整网格密度与数量预算；释放后的粒子尺寸补偿回原大小，避免数量滑杆只是反向的大小滑杆。释放初段平滑过渡，静态内容仍完整覆盖。
- 1 倍沿用原有网格、材料和大小；实际总数受网格取整与内容采样影响，近似按倍率变化。
- 数量进入材料共享的匹配条件和创建页预计算缓存键，避免沿用旧设置的材料或轨迹。
- 切换样式刷新当前数量，恢复默认清除两种样式的数量设置；改动后沿用现有预览刷新方式。

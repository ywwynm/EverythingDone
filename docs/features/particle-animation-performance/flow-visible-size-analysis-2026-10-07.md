# 流体设置值与可见粒子直径的核对

## 问题与范围

用户在飘散大小分析后，要求同样核对流体，主观感觉流体较符合读数。本轮补充正式着色器的离屏测量，仅分析，不修改应用，不连接设备，也不重新发布。

## 结论

手动档位已控制单颗粒子的几何基准直径，不会把数量改变后的网格间距直接当成粒径；但数字仍不是每颗粒子在每一帧的最终可见直径。流体的圆边较实，半峰值直径是几何宽度的约 90%，明显接近飘散软点的约 37%。除此之外，流体还叠加内容、年龄、随机、少量椭圆和深度缩放。

默认未设置大小是另一条规则：界面标注 0.84 dp，但实际传给模型的值为 0，沿用自动网格尺寸。它会随内容面积与粒子预算变化，不能解释成固定 0.84 dp 粒子。

## 测量方式

- 工具：`checks/measure_flow_visible_size.py`，使用 `everythingdone` 环境的 ModernGL；复用同目录的着色器加载与横截面测量函数。
- 执行正式 `draw-record.comp`、`material.vert`、`material.frag`，启用与 Android 相同的 `PARTICLE_AMOUNT`、`ROUND_PARTICLES`、`DRAW_RECORDS` 和 `FLAKE_CONSTANTS` 路径。
- 先给实际绘制程序不缩放的单粒子记录，隔离圆边覆盖率；再执行完整绘制记录计算，取同一位置、相同寿命的 4096 个受控随机粒子，区分内容与年龄影响。该受控分布不是某台手机、某个真实动画全部粒子的统计。
- 与飘散采用同一指标：横截面不透明度降至中心峰值 50% 的直径，另测 10% 边界。少量椭圆分布使用由真实绘制矩阵算出的等面积直径；中位数样本再通过实际片元输出检查。
- 结果：`tmp/flow-visible-size-20261007/result.json`。30 个档位、45 组内容／年龄／数量组合及 9 个中位数像素样本全部完成。没有新建应用测试或修改渲染逻辑。

## 数值与含义

仅看粒子轮廓，不叠加内容与生命周期缩放：

| 相同 2.4 dp 几何基准 | 半峰值直径 | 10% 峰值直径 |
|---|---:|---:|
| 流体近圆颗粒 | 2.160 dp | 2.307 dp |
| 飘散软圆点 | 0.893 dp | 1.793 dp |

全部 30 个流体档位均满足半峰值直径约为所选值的 0.90 倍。流体圆形遮罩只有最外侧一小圈变淡，因此用户主观上较接近设置值有实现依据；不能据此忽略后续缩放。

执行流体完整绘制尺寸计算，选定 2.4 dp、数量 1 倍，固定 300×200 dp 内容中部，状态深度为 0、保留 `roll_gain=0.85` 的正常绘制偏转。以下为中位数粒子的实际横截面测量：

| 内容条件 | 出生后 12 ms | 出生后 35 ms | 出生后 75 ms |
|---|---:|---:|---:|
| 无本体色强调 | 1.884 dp | 2.035 dp | 2.187 dp |
| 本体底色 | 2.058 dp | 1.557 dp | 1.501 dp |
| 强调内容 | 2.103 dp | 2.114 dp | 2.434 dp |

更老的粒子继续变小，随机分布也变宽；这是已有的视觉变化。数量分别取 0.1、1.0、1.6 倍后，同条件的尺寸中位数最大差异低于 1.5%（粒子来源网格中心略变会影响局部偏转）。说明当前显式粒径补偿生效，数量档未直接改变粒子大小。

## 默认档的问题

`ParticleTuning.DEFAULT_CELL_INDEX` 取规则下限 `1.65 / 1.875 = 0.88 dp` 的最近档位，故标签为 0.84 dp。未手动选择时，`cellDpFloor(..., false)` 返回 0；模型仍按面积和总量预算求网格，绘制基准沿用数量为 1 倍时的网格大小。

按当前正式模型公式计算，纯色内容、无额外材料预算倍率时：

| 示例内容尺寸 | 默认标签 | 实际几何基准直径 |
|---|---:|---:|
| 300×200 dp | 0.84 dp | 约 0.878 dp |
| 300×600 dp | 0.84 dp | 约 1.064 dp |
| 384×768 dp | 0.84 dp | 约 1.362 dp |

这是代码公式示例，不是实际设备采样；内容补充粒子、阴影预算与尺寸会改变结果。上述数值还需经过圆边和动画缩放，不能直接当成最终可见直径。

## 后续要求

流体需要与飘散统一可见直径的标定方式，但修正幅度不能照搬飘散。流体显式档已经具有可靠的粒径输入，应保留数量与粒径分离；默认标签与自动尺寸的矛盾需同时解决。实施前需明确默认观感和旧值迁移，不应把默认 0.84 dp 的标签当成此前已经固定的真实尺寸。

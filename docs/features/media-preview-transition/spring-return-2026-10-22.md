# 弹簧返回：缩短惯性外移与收回时间

## 依据与实现

用户认可[曲线调研](motion-curve-research-2026-10-22.md)，要求采用弹簧、保留少量惯性并加快收回，继续在已授权三星、一加、魅族上验证。

旧轨迹的真实快甩外移约 605–670 px，约 98–104 ms 才折返。先加入外移不超过 36 dp、300 ms 内完成主要回收的回归，旧实现两项失败，记录在 `tmp/media-spring-red.txt`。

- `MediaPreviewReturnMotion.Spring` 使用临界阻尼解析解，位置和速度从松手状态连续出发。基础自然频率为 24；根据极值与末端误差增加刚度，保留初速度，不直接缩减速度或截断位置。
- 平移在起点与目标区间之外的延伸同时受 36 dp 和对应视口长度 4% 约束。尺寸额外收缩受 36 dp 与两端较小宽度的 6% 约束，保持正尺寸和原内容比例。
- 最长运动时长 360 ms；选择刚度时保证届时位置误差不超过 0.5 dp、速度不超过 12 dp/s，再确定实际停稳时间。正常收尾只在这个误差内交接到准确目标；后台中断沿用立即完成规则。
- 背景与裁剪使用同步的临界阻尼进度；末段补图仍在最后一段交接，原播放器、动图、HDR 与 PhotoView 内容矩阵不变。
- 帧计算使用 `Choreographer` 提供的显示帧时间，避免主线程排队时刻改变相邻帧的运动间隔。设备诊断增加实际采样时间，检查两向快甩、外移峰值、主体回收和运动到位时间。

## 验证结果

- 7 项曲线测试及既有完整手势链测试通过；包含不同方向、零初速度、极端快甩、不同目标距离、屏幕密度和尺寸约束。曲线初速度保持原值，360 ms 时同时符合位置与速度门槛。
- 最终全套本地测试 1768 项，0 失败／错误，3 项既有跳过；APK 构建成功。
- 补充极小目标的实际渲染回归，先复现高速缩小后宽度变成 -19.4 px；尺寸预算改按起点和目标中较小者的 6% 限制，避免极端初速度造成尺寸穿零，不使用逐帧硬截。该边界变更后重新验证最终包。
- 三机首轮合计 1464 项通过。最终尺寸边界修正后，发布包再完成相同的三机合并验证：双向快甩与交互夹具、真实 200MP 图片／4K 大视频／GIF／HDR 动态照片、原生与 PQ 输出，合计 1464 项全部通过。每台包含 280 项夹具、135 项真实原生、73 项真实 PQ 检查。

这里的 99% 按纵向中心距目标的剩余误差计算，要求此后始终在初始距离的 1% 内；不把首次经过目标或缩放完成混为整体结束。向上快甩在本次几何中顺势朝目标移动，未超出起终点区间，不应为了“惯性”额外强制造出反向运动。

45 次返回首个运动回调为 2.73–19.56 ms，平均 10.60 ms；正常运动完成为 361.86–391.61 ms，包含帧调度开销。详情端点遮层释放为 538.31–684.44 ms，包含既有窗口恢复、布局稳定与淡出，不能把约 300 ms 的主体回收描述为全部交互恢复。采样是实际页几何和回调时刻，不等同于硬件呈现时间。原始逐帧报告索引与输入散列见[最终检查摘要](checks/spring-return-2026-10-22.json)。

一加首轮系统录屏复核了短距离延续、连续折返和末端几何，未见随媒体移动的工具栏副本；录屏为 `tmp/media-dismiss-inertia-oneplus-spring1-fixtures/recording.mp4`，抽帧为 `tmp/media-spring-fling.png`。该录屏早于极小目标尺寸边界修正；最终包的三机轨迹与截图另保存在摘要所列目录。

## 修正图片和视频返回时原附件位置的背景颜色

用户指出，原附件位置挖空后不应显示黑色，而应显示记事自身的背景；随后明确返回键也要一起修正。此前 `202610230232` 虽然已消除静止媒体副本，但错误地把黑色空区作为验收标准。本次同时修正手势和返回键两条路径。

新增 MediaPreviewDetailBackground，只复制详情根容器的背景 Drawable，按原尺寸和窗口坐标绘制，纯色和渐变均保持原位置。MediaPreviewDismissGesture 在挖空处先绘制记事背景，再按拖动进度叠加黑色遮罩；MediaPreviewTransition 的返回键动画也在目标空区绘制同一来源的背景，并跟随页面显露进度。完整详情快照保留用于窗口交接，不修改真实媒体透明度；原有弹簧、惯性、取消回弹、图标渐显、配色与触摸反馈清理继续保留。

像素回归先在旧实现复现黑色错误，再通过修复；42 项媒体专项测试全部通过，包含八种渐变方向、原坐标与尺寸、背景副本独立性、透明度恢复、手势回弹和弹簧曲线。独立实机探针补充纯色、对角渐变和垂直渐变，检查上下滑与返回键原附件空区的实际绘制颜色；最终发布包继续在已授权三星、一加、魅族验证。

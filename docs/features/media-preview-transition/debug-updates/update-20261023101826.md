## 统一图片／视频滑动返回中的图标、颜色和触摸反馈

用户反馈上下滑返回时，顶栏和 GIF 等标识被图片遮住，到动画结束才突然出现；下拉展开接收更新入口后，还会看到旧点击波纹和顶栏变色。此次保留原有拖动、惯性及弹簧收回，统一详情图标的渐显与配色交接。

原发布包真实点击回归确认：动画进度 60%、76%、90% 时，顶栏与删除图标仍完全被遮挡；后台背景冻结了点击波纹，顶栏直到详情恢复才从白色变为黑色。上一轮只验证附件主体与坐标，没有覆盖这些问题，本轮补齐真实点击和图标像素检查。

MediaPreviewTransition 在来源详情停止后结束旧触摸反馈，等待 DetailToolbarContrast 完成后台布局的静态取色，再同时保存干净背景和图标。新增 MediaPreviewDetailChrome 按详情原坐标补绘被移动媒体遮住的图标及遮罩；MediaPreviewReturnAnimation 与返回键共用末段渐显比例，按弹簧缓动进度推进，松手阶段不增加异步等待。日常波纹、预览播放和取消回弹规则保持。

39 项媒体专项和全套 1778 项本地测试无失败／错误，3 项既有跳过。三星本地包 27 组／554 项全部通过，覆盖图片、视频、GIF，普通详情、入口展开及接收中后台退出边界，上下滑和返回键。接收舞台按现有设计拦截触摸，因此其边界组直接向附件发送按下／抬起；普通和入口展开组走完整触摸分发。发布包随后在原三星、一加、魅族三台设备验证，测试不接收真实来件。

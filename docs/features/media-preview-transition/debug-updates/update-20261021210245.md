## 缩短真实大图片的展开等待，保持高清与 HDR

用户要求继续优化记事附件打开大图的延迟，特别要求最终清晰度和 HDR 不退化，并在三星、一加、魅族三台指定设备使用真实记事验证。

分阶段计时确认：真实 36 MB、2 亿像素照片在转场小图阶段仍需解码原文件，三机首次等待约 797／607／1731 ms。新增 `MediaPreviewThumbnail`，在来源截图和预览窗口创建期间后台提取合格 JPEG 内嵌预览，处理 EXIF 旋转与镜像，校验尺寸和原图比例；没有合格预览则继续原小图路径。`ImageViewerActivity` 用独立位图承接转场，高清加载仍沿用原分辨率，超时／返回／销毁后的迟到小图不会覆盖高清。正常尺寸完成状态、HDR 兼容层准备条件、HDR 数值公式和内存预算均不降低。

同一真实大图在兼容路径的首次展开等待降至约 322／164／425 ms，再次打开为 185／174／200 ms。该计时为点击到动画开始，不含动画时长；没有清空用户磁盘缓存，也不代表卓易通宿主的直接测量。三机普通及兼容路径的 200MP 最终位图尺寸、色彩空间、Gainmap 和像素散列与旧路径一致；HDR 兼容输出的纹理与增益参数保持，真实 HDR 动态照片播放后恢复完整增益。

## 修复大视频预览切入播放时的起播黑屏

修复打开较大视频时，预览图与播放画面之间短暂全黑的问题。真实 4K 大视频确认：原先在播放器准备完成后固定等待 180 毫秒就显示视频层，实际画面可能还没有到达。

现在保持预览图，直到目标视频纹理真正更新后再切入播放；不再用固定等待时间判断首帧就绪。播放器通知提前或缺失时也能正常交接，停止、取消或退出后不会被迟到通知重新显示。保留视频比例、缩放、原有清晰度、HDR 输出及动态照片底部细边修复。

## 优化无内嵌预览大图的展开，保持高清和 HDR

用户指出并非所有大图都含内嵌预览，上一版针对 EXIF 预览的优化不足以代表通用大图。本轮改为复用详情现有解码结果，在裁剪前保留完整构图的小图；JPEG、PNG、静态 WebP 等图片不再要求自带内嵌预览。默认详情继续居中裁剪，自定义外观沿用原裁剪器，动态照片复用已有静态取色请求，不新增大文件预加载。

`MediaPreviewThumbnail` 按文件路径、长度和修改时间保存最长边 512 的独立副本，缓存上限 8 MiB，内存告警及退后台释放。查看器使用独立占位，缓存淘汰不会影响已显示图；正常尺寸请求完成后才进入高清就绪集合和 PQ 准备，原分辨率、增益参数及内存预算保持。没有有效缓存时仍保留 EXIF／原小图回退，不保证任意状态下零等待。

三星、一加、魅族三机使用真实记事，并将真实 2 亿像素照片复制后仅断开 EXIF IFD1 链作为压力样本，原照片不变。无内嵌预览压力样本首次展开由约 593／599／1105 ms 降至 203／143／277 ms；真实无内嵌 SDR 图由 236／232／250 ms 降至 189／144／168 ms。计时为点击到开始展开，不含动画时长，未清除用户缓存。最终位图的像素 SHA-256、尺寸、色彩空间、Gainmap 及 HDR 参数与旧实现一致，压力副本像素也与真实原图一致。

2936 项相关实机检查通过，覆盖真实大图、4K 大视频、GIF、普通／HDR 动态照片、完整 HDR 恢复、返回顶栏稳定性、裁剪、旋转、翻页删除、缓存清理、EXIF 全方向、超时与迟到回调。新增副本复制平均约 2 ms、实测最大低于 10 ms。JVM 1732 项无失败／错误，3 项既有跳过；669 条原记事与各轮所选原附件摘要不变。

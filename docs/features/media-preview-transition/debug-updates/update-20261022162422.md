## 图片／视频预览支持单指上下滑动返回

用户希望从记事详情打开图片或视频后，单指向上／向下拖动媒体也能返回详情，并让画面随手指移动、缩小及恢复。本轮通过 grill-me 确认：放大状态先平移至边缘再接续返回；外拖缩小并逐渐露出详情，回拖恢复；距离足够或短距离快速甩动可返回，小幅慢拖松手回弹并保留倍率和位置；播放继续遵循原规则，取消不重置进度；空间模式保留原视角操作，退出后启用返回手势。

新增 MediaPreviewDismissGesture 与 MediaPreviewDismissPolicy，在当前媒体页的外层统一变换和裁剪，保留 PhotoView 矩阵、视频 TextureView、动图 Drawable 及 PQ Surface。详情背景复用打开时捕获的画面。接管时只取消原触摸识别，避免把内部取消事件误当成松手停止播放；确认返回先捕获当前画面，再交给原缩回动画。MediaPreviewTransition 和 ImageViewerActivity 的媒体几何现包含父层变换，避免返回起点跳回全屏；旋转、多指和资源替换会恢复交互状态。

新增 24 项 JVM／Robolectric 专项；全套 1756 项，0 失败、3 项既有跳过。用户授权的三星、一加、魅族完成 1125 项真机检查，全部通过，覆盖小幅回弹、边缘接续、快甩、播放状态保持、真实大图与大视频、GIF／WebP、HDR 动态照片及 PQ 兼容路径。系统合成截图核对了媒体缩放、裁剪、详情显露和黑底恢复；正常清晰度检查通过，未改变 HDR 增益或视频内容矩阵。672 条原记事与选中附件校验保持不变，模拟记事已清理。

## 修复图片／视频拖动返回松手后的停顿，并接续惯性

用户反馈上一版在向下拖动或快速甩动确认返回后，画面先停在中途，再启动缩回详情的动画；期望松手后沿原方向继续一点，再连续收回。重新检查三机旧时间线，24 次返回的首个运动帧等待为 115.6–213.2 ms，平均 185.2 ms，来自截图、窗口切换及详情布局准备；手指速度只用于触发判定，没有参与后续轨迹。

本次由 MediaPreviewDismissGesture 保留松手速度，MediaPreviewReturnMotion 生成连续轨迹，MediaPreviewReturnAnimation 直接变换当前窗口中已有的媒体层。松手后立即继续运动，向外快甩时先顺势前进，再收回附件位置。收回完成后才切换窗口，使用端点画面覆盖详情恢复过程。

保持图片等比和原有裁剪，补图只重绘详情中已解码的图片控件，避免把工具栏和删除按钮一起带着移动。确认返回时暂停当前播放帧并保留纹理和 HDR 层，退出后释放；取消返回仍保留播放进度、倍率及位置，空间模式仍使用原视角手势。

新增 7 项专项检查，全套 1763 项 JVM 测试无失败，3 项既有跳过。三星、一加、魅族共 1218 项实机断言通过，42 次返回的首个运动帧为 0.7–19.3 ms，平均 8.4 ms；系统录屏确认向外惯性与收回连续，没有工具栏副本。覆盖真实 200MP 图片、4K 大视频、GIF、HDR 动态照片及 PQ 兼容输出，672 条原记事和所选附件保持。卓易通宿主未直接连接，兼容输出在这三台 Android 设备验证。

## 图片／视频预览返回改为短惯性的弹簧动画

用户反馈上一版松手后的惯性外移偏大、收回偏慢。结合 Android、Apple、Material 官方资料及三机已存轨迹调研，确认固定 432 ms 曲线把快甩速度放大成较长外移；用户确认采用弹簧方案，保留少量惯性并加快收回。

MediaPreviewReturnMotion 改为临界阻尼解析轨迹，保持松手位置与初速度，通过调整刚度限制外移和停稳时间。平移外移不超过 36 dp 或视口的 4%，尺寸按两端较小宽度的 6% 约束；正常运动在约 360 ms 内达到位置与速度的可见误差门槛。MediaPreviewReturnAnimation 同步加快黑底与裁剪变化，按显示帧时间采样，保持等比、原渲染层与末段详情交接。取消返回仍保留放大倍率及播放进度，空间模式沿用视角手势。

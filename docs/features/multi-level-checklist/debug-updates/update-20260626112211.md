# 多级清单项 debug 发布日志

## 2026-06-26 修复缩进对齐与反缩进按钮

针对首版测试反馈修复三处：

1. **缩进过多** —— 详情页状态图标是 36dp 控件、里面的图标实际更小且居中。改为按“图标实际左缘”
   对齐父项文本左缘，而不是按控件左缘；每级步长扣除图标在控件里的左侧留白，缩进量随之减小。
2. **反缩进按钮 + 图标** —— 之前误用了“移动模式”工具栏的图标，且左侧反缩进按钮位置依赖控件相对
   定位、未稳定出现。现在：缩进/反缩进改用清晰的右箭头/左箭头矢量图标；反缩进按钮锚定父起点、运行时
   显式定位到状态图标左侧的缩进空档，二级及以上聚焦该项时必定出现。
3. **图标与首行文字未居中** —— 详情页与首页卡片的状态图标与文字改为垂直居中对齐（二、三级字号变小时
   不再偏上）。

均为对齐/图标层面的修复，数据与完成/拖拽逻辑不变。

# 多级清单项 debug 发布日志

## 2026-06-26 多行文字时轮廓底部加留白

**多行文字时轮廓底紧贴文字、无留白**：根因是多行时 itemView 高度恰好被文字占满、内部没有多余空间，而
轮廓 `bottom` 又被夹到 `itemView 高度内`，于是轮廓底反而切进文字底。直接加大 `bottom` 会超出 itemView
被 overlay 裁掉（看不见）。

改法：移动模式期间让清单 RecyclerView **`clipChildren = false`**（退出时恢复），使被拖项轮廓可在 itemView
下方**溢出一点**而不被裁；轮廓 `bottom` 改为文字底 + 4dp 下留白、coerce 上限放宽到允许这点溢出。这样文字
底与轮廓底之间有了间距，且轮廓底依然完整可见。

重点测：多行文字项拖拽时，轮廓底与文字底之间是否有留白、轮廓底是否完整可见；单行项、右侧覆盖、圆角
是否仍正常。

# 多级清单项 debug 发布日志

## 2026-06-26 多级清单项（首个可测版本）

为记事清单加入最多三级的层级结构，首个可测版本，覆盖以下能力：

**编辑（记事详情页）**
- 点入一个清单项后，右侧出现“向右”缩进按钮、二级及以上时左侧状态图标前出现“向左”反缩进按钮；
  按层级边界自动隐藏（一级无反缩进、三级无缩进）。
- 缩进有防孤儿门控：上方没有可作父级的项时（如清单第一项）不允许缩进。
- 删除入口改为仅退格键（右侧删除图标已让位给缩进）。
- 二级比一级、三级比二级字号更小、颜色更淡（字号与透明度系数均为 0.9，后续可调）。
- 新建项继承当前行层级；底部“添加新项”新建一级项。

**完成 / 取消（按“组”运作）**
- 完成一级项（组根）会自动完成其下整棵子树并整组下沉到底部已完成区；完成二、三级项就地显示为
  已完成、不迁移。
- 取消一级项会级联取消整棵子树并整组回流到顶部；在底部取消某个二、三级项时，整组回流到上方，其余
  原本已完成的项保持已完成显示。
- 首页记事列表、各 widget、通知动作点击完成都遵循同一套规则。

**多级显示**
- 首页列表、单一记事 widget 配置页列表、大文件夹缩略图、DoingActivity、单一记事 widget、记事列表
  widget 均按层级缩进并应用分级字号/淡化。
- 通知与分享/复制的纯文本改用标准 Markdown 任务列表（`- [ ] / - [x]`，每级两个空格缩进），粘到支持
  Markdown 的应用可渲染成复选框。

**拖拽**
- 拖拽只在“同一归属、同层级的兄弟”之间重排，且连同被拖项的整棵子树一起移动，不跨越未完成/已完成
  分隔线。

**已知未完成（后续迭代）**
- 拖拽“收束进组根 + 角标 + 展开还原”的动画尚未实现：当前子树会随组根正确移动，但拖动过程中是直接
  移动、没有收束动画；拖动跨越较大子树时画面会有一次跳变。
- 各界面缩进步长、字号/淡化系数、动画时长等仍是初始值，待真机微调。

**数据迁移**
- 首次启动会自动把旧清单升级为带层级的新格式（全部置一级），无需手动操作。

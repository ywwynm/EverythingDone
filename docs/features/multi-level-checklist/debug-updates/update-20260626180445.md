# 多级清单项 debug 发布日志

## 2026-06-26 拖拽收束/展开动画 + 胶囊轮廓；修边界与目标项横跳

针对三处反馈：

1. **收束没有动画（子项瞬间消失）+ 加胶囊轮廓**
   - 根因：清单 RecyclerView 的 `itemAnimator` 一直被设为 `null`（为编辑输入时不闪动），所以
     `notifyItemRangeRemoved` 没有任何动画、子项直接消失。
   - 现在**仅在移动模式期间**挂一个自定义 ItemAnimator：被收子项做**向上收缩**（从顶部 pivot 的
     scaleY→0 + 渐隐），下方兄弟平滑上滑填补；松手、落点确定后被收子项**向下展开**还原。拖拽过程中的
     重排（onMove）仍是瞬时的、不与跟手冲突。
   - 另给被拖项加一个**胶囊状描边轮廓**（覆盖左侧状态图标与文本，线条用该项文字色），拖拽开始**渐显**
     出现，松手后**渐隐**消失。

2. **二/三级项往下能一直滑出父范围**
   - 根因：原来用"边界项的屏幕位置"判停，而收束后边界项常常就是贴着手指的代理本身、其几何受跟手
     补偿平移影响，判定失效。
   - 改为**按"代理在该方向是否还有同级兄弟可去"判停**（与重排的边界判定同源）：没有兄弟（碰到父子树/
     区域边界）就不再往该方向自动滚动。二/三级项严格限制在父节点范围内，一级项到分割线即停。

3. **拖一级项到别的项处触发移动时，目标项上下反复横跳**
   - 根因：一接触目标兄弟就整段跨越，跨完手指仍落在它身上 → 反向再次触发 → 振荡。
   - 加**滞后**：手指越过目标兄弟"整棵子树"的中线才跨越，跨越后手指自然落在另一侧、不会立即反向，
     横跳消除。

重点测：收束/展开动画是否明显、胶囊轮廓渐显渐隐是否正常；二/三级项上下自动滚动是否都被限制在父范围内；
拖一级项经过其它项时是否还横跳；之前的贴手指、双向滚动、撤销是否未回归。

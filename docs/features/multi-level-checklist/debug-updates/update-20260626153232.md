# 多级清单项 debug 发布日志

## 2026-06-26 禁止层级跳空，彻底消除孤儿项

修复"缩进会产生孤儿/跳空项"的问题（例如 `[1,2,2]` 缩进第一个二级项得到 `[1,3,2]`，那个三级项没有
直接的二级父项）。改为**禁止层级跳空**，两道防线：

1. **缩进门控收紧**：只有当一个清单项存在"同级的上一个兄弟"时，才显示/允许向右缩进（缩进后正好成为
   该兄弟的子项、只深一级）。于是"父项下的第一个子项"不能再缩进，不会跳空。
2. **层级归一化兜底**：反缩进父项、删除中间项、以及历史遗留数据里出现的跳空，会被自动收回到合法层级
   （深层子项随父项一起上移）。覆盖详情页编辑与所有展示界面。

副作用：反缩进一个带子项的项时，它的子树会一起上移一级（这是禁跳空的必然结果）。

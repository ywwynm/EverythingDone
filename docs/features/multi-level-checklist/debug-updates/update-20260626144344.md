## 2026-06-26 缩进按 L2/L3 分别精调

本轮缩进的 L2 与 L3 不再同步，分开调（通过步长 step 与首段偏移 extra 两个量换算）：

- **详情页**：仅 L3 +2dp，L2 不变（step 28→30dp、extra 7→5dp）；T 不变。
- **首页卡片**：L2 +0.5dp、L3 +1dp（step 再 +0.5dp）；T 不变。
- **首页文件夹缩略图**：与卡片同渲染器，自动跟随。
- **记事列表 / 单一记事 widget**：仅 L3 +2dp，L2 不变（step 13→15dp、extra 6→4dp）；T1 +0.5dp
  （图标 2.0→2.5dp），T2/T3 不变。

说明：L_n = (n-1)*step + extra（n≥2）。"仅 L3 +2"= step +2 且 extra −2（L2 保持不变）；"L2+0.5、L3+1"
= step +0.5（L3 是两个 step 所以 +1）。0.5dp 仍按整数像素四舍五入。

# 多级清单项 debug 发布日志

## 2026-06-26 完成态严格不变量：已完成项有未完成下属时自动改回未完成

处理"已完成父项挂着未完成子项"的不一致（例如把一个未完成项缩进到已完成项下、或原位取消已完成项的
某个子项）。采用**严格不变量**「已完成项的所有下属都已完成」：

- 一旦某个已完成项出现未完成的下属，它连同它的**已完成祖先链**都自动改回未完成；
- **旁系**（非祖先）的已完成项不受影响，仍照常显示为已完成。

实现：新增 `normalizeCompletion`（自下而上把"子树里有未完成项"的已完成项改回未完成），接在清单解析、
完成/取消、缩进/反缩进、删除之后，覆盖所有界面。

副作用（合理）：原位取消一个子项，现在会连带把它的已完成父/祖先一起改回未完成（更贴"重开子任务则父
任务也未完成"的直觉）；旁系已完成项不动。

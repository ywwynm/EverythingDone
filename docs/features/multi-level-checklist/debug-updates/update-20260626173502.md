# 多级清单项 debug 发布日志

## 2026-06-26 拖拽：子树收束/展开动画 + 二三级项滚动边界

两项改进：

1. **子树收束动画**：之前拖拽父项时，它的子项还显示着、跟着块移动会跳动，令人困惑。现在改为
   **拖拽开始即把被拖项的子树临时收起**（子项删除动画 + 下方上滑填补，观感是收进父项里），拖拽期间
   列表里只剩父项一行作代理跟手、清爽不跳；**松手时再把子树插回代理落点之后**（插入动画，观感是展开），
   恢复正确结构。整段拖拽合并为一次撤销动作。

2. **二/三级项的移动/滚动边界**：拖拽二、三级项时，它只能在自己父节点的子列表范围内重排，**不会被拖出
   父节点的范围**；对应地，自动滚动也按"父子树范围"裁边——往下滚到父子树底部全部可见即停、往上滚到父项
   头部贴到视口顶即停，不会无谓地滚出父节点范围。一级项仍按未完成/已完成分割线为界。

重点测：拖父项时子项是否平滑收起、松手是否正确展开回原结构；拖二/三级项时是否被限制在父节点范围内、
自动滚动是否到父子树边界就停；一级项跨组重排与分割线边界是否照常。

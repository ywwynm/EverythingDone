# 多级清单项 debug 发布日志

## 2026-06-26 轮廓四边视觉 padding 对称（右/下补足控件留白）

**右侧（文字占满一行时）、下边的 padding 比左/上窄**。根因：左/上的视觉 padding 真实来源是 **ivState 是
36dp 控件、里面的状态 icon 实际更小（scaleType=center，单边各空出约 6dp）**，再加 basePad；而右/下没有这种
控件，只有 basePad，自然偏窄。

改法：取 `ivState.drawable` 的 intrinsic 尺寸算出"控件比 icon 大的单边留白" `insetX/insetY`，令四边到
**内容真实视觉边缘**（icon 扣控件留白、文字扣 EditText 内边距）的 padding 统一为 `basePad + inset`：

- 右 = 文字真实右缘 + (basePad + insetX)
- 下 = 文字/图标真实底 + (basePad + insetY)
- 左/上沿用原值（本就经由控件留白得到同样的视觉 padding）

这样四边视觉对称，且右侧能盖住占满一行的文字、下边与文字底有与上边一致的留白（仍靠 clipChildren=false
让下边溢出可见）。

重点测：文字占满一行时右侧 padding、多行时下边 padding 是否与左/上一致；圆角、轮廓完整性是否正常。

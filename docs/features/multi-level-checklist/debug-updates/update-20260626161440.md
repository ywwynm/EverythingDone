# 多级清单项 debug 发布日志

## 2026-06-26 修复拖拽根节点"脱手"

修复拖拽带子项的根节点时偶发的"脱手"：手指还在屏幕上、根节点却自己跳到新位置。

原因：子树整块移动时用了 `notifyDataSetChanged`，它会回收正在被拖拽的视图，`ItemTouchHelper` 因此
失去对手指的跟踪、拖拽提前结束。

修复：整块移动改为**全程只用 `notifyItemMoved`**（把目标兄弟子树的各项依次移到块的另一侧，等价于整块
移动），不再回收任何视图，拖拽不再脱手。叶子/扁平清单的相邻交换仍是单步平滑移动。

按沟通，收缩动画与数量角标本次不做。

# 多级清单项 debug 发布日志

## 2026-06-26 拖拽自动滚动彻底修复被拖项消失（补偿量双重计数）

上一版（202606260904）修好了双向滚动，但被拖项在滚动后仍会消失。根因不在边缘判定，而在 `onChildDraw`
的**补偿量被重复计算**：

- 旧实现把每帧滚动量**只增不减**地累加进 `mDragAutoScrollAccum`，再 `dY + 累加值`。
- 但 `ItemTouchHelper` 的 `dY` 在**每次手指 MOVE** 时会用"手指相对 RecyclerView 的新坐标"重算，而父容器
  `NestedScrollView` 滚动后该坐标**已包含那段滚动量**。
- 于是手指一动，`dY` 算了一遍全部滚动、累加值又算了一遍，`translation = 手指位移 + 2×滚动量`，被拖项以
  两倍速度往下飞出屏幕，表现为"消失"。

**改法**：补偿量不再累加历史，而取 **"当前 scrollY − 上一次手指事件时的 scrollY"**（在 `dispatchTouchEvent`
里记下每次触摸时的 scrollY 作基准）。其含义是"自上次手指事件以来父容器又多滚了多少"——这段恰好是 `dY`
尚未反映的部分。手指不动纯自动滚动时补偿随之增长、被拖项贴住手指；手指一动的同一帧 `dY` 把全部滚动重算
进去、补偿基准同步刷新回 0，不再双重计数、不跳。

重点测：被拖项滚动后是否还会消失、是否始终贴手指；上下双向自动滚动、到分割线停住、恒定速度这几点是否
仍正常。

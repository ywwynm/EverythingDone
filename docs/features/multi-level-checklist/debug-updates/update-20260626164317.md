# 多级清单项 debug 发布日志

## 2026-06-26 拖拽时支持自动滚动（恒定速度、分割线为界）

清单 RecyclerView 在 NestedScrollView 内、自身不滚动，所以 ItemTouchHelper 自带的自动滚动失效。新增
**自定义自动滚动**：

- 拖拽时清单项靠近视口上/下边缘，**以恒定速度滚动父容器**（不加速）。
- **分割线为界**：拖未完成项往下滚到未完成/已完成分割线即停；拖已完成项往上滚到分割线即停——不越界。
- 滚动时给被拖项补偿一个平移量，使它始终贴在手指处、**不脱手**。

实现：`CheckListTouchCallback` 加 `onSelectedChanged`/`clearView`/`onChildDraw` 三个重写，配合
`startChecklistDragAutoScroll` 逐帧滚动 + `clampChecklistAutoScroll` 边界裁剪。

注：嵌套滚动下的拖拽自动滚动较为微妙，此为首版，重点测：贴边是否匀速滚动、到分割线是否停住、被拖项
是否始终贴手指、滚动中松手落点是否正确。

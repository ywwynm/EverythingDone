# 多级清单项 debug 发布日志

## 2026-06-26 拖拽自动滚动修复（被拖项消失 / 单向滚动）+ 返回 icon 直接退出

1. **被拖项消失 / 只能单向滚动** —— 根因：自动滚动的边缘判定原来用"被拖视图当前屏幕位置"，而该位置
   含了为防脱手加的补偿平移，形成正反馈、补偿量失控，把被拖项推出屏幕（且卡在向下方向）。改为用
   **实时手指屏幕 Y**（`dispatchTouchEvent` 记录）判边缘，与补偿解耦：被拖项始终贴手指、上下两个方向都能
   自动滚动。
2. **左上角返回 icon** —— 改回**始终直接退出详情界面**（即使在清单项移动模式下）；移动模式仍由系统返回键/
   手势返回退出。

恒定速度、分割线为界这两点不变。

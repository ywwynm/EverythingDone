# 多级清单项 debug 发布日志

## 2026-06-26 拖拽轮廓改圆角矩形（修右/下边裁切）+ 落位重叠兜底

四处视觉细节：

1+2. **轮廓下边不完整 / 右侧盖不住文本**：根因是算轮廓范围时直接用了 `et.right`，而 `et` 在内层
   LinearLayout 里、该坐标不是 itemView 坐标系（少算了图标列偏移），且下边 `+padding` 超出 itemView 被裁。
   改为**用屏幕坐标换算到 itemView 坐标系**，并把矩形**夹在 itemView 内、四边留出描边宽度**，下/右描边
   完整、右侧完整覆盖文本。

3. **不用胶囊、改圆角矩形**：圆角由"半高胶囊"改为固定 **10dp**。

4. **移动落位后项停在两行之间、相互重叠**：根因是某个收束/展开/重排的 translation/scale 动画被打断、
   未归零。落位后（动画结束）做一次**变换复位兜底**（仅在拖拽确已结束时），清掉残留、消除重叠。

重点测：轮廓四边是否完整、右侧是否盖住文本、圆角 10dp 是否合适；之前那次"落位重叠"是否不再出现；
收束/展开动画、边界、横跳是否仍正常。

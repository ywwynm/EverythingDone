# Multi-level Checklist Items Plan

## Goal

给记事的清单加入最多三级的层级结构：缩进/反缩进改变清单项层级、分级排版、按“组”运作的完成/取消
迁移、组内同级拖拽，以及在所有展示清单的界面（首页列表、单一记事 widget 配置页列表、两列表中大文件夹
缩略图、DoingActivity、单一记事 widget、列表 widget、通知）上的多级显示与点击完成。

逐条设计决策的权威记录在 `decisions.md`；术语在根 `CONTEXT.md`；存储编码在 `docs/adr/0010`。本文件给出
实现取向与分阶段拆解。

## Confirmed Decisions（摘要，权威见 decisions.md / ADR-0010 / CONTEXT.md）

- 层级逐项显式存储、归属由位置派生；存储为 `SIGNAL + 状态位 + 层级位 + 文本`（方案 B）+ 一次性 DB 迁移。
- 完成模型按“组”整组迁移，组根（⟺ 一级项）的完成态决定整组在顶/底；完成/取消都向下级联子树；组内
  深层项就地完成。禁孤儿（缩进门控）、允许层级跳空。顶/底边界以 `3`/`4` 分隔位为真理来源。
- 完成逻辑收敛到 `CheckListHelper.toggleChecklistItem` 单一真理来源，7 个界面共享；详情页适配器复用它。
- 缩进/反缩进只动单项、可在任意区域操作；拖拽连子树、只在兄弟带内重排，用“组根代理 + 子树收束动画”。
- 分级字号/透明度三常量起步 0.9（独立可调）。单一文本输出改标准 Markdown 任务列表。

## 实现分阶段

1. **存储与迁移层**：清单串解析/序列化纳入层级位（`item[1]`，文本 `substring(2)`，控制标记仍单字符）；
   新增 DB 版本与迁移（扫描 `isCheckListStr` 的 Thing，逐项插入层级位 `1`）；`toContentStr` 跳过层级位。
   排查所有把 `item[0]`/`substring(1)` 当文本起点的旧调用。
2. **完成状态机**：重写 `CheckListHelper.toggleChecklistItem` 为组感知（级联子树 + 按组根整组迁移 + 取消
   回流 + 强制组根取消不横扫兄弟）；顶/底边界改用 `3`/`4` 分隔位判断，替换所有“第一个 `1`”式判定。
3. **详情页编辑交互**：右侧删除图标改缩进按钮、左侧加反缩进槽位与按钮（聚焦门控、按边界隐藏、缩进
   门控防孤儿）；逐级左移约 44dp；新建项层级（回车继承、添加行给一级）；适配器完成切换改为复用
   `CheckListHelper`；撤销记录改内容串 before/after。
4. **分级排版**：三个独立比例常量（字号、未完成透明度、已完成透明度，起步 0.9），应用于详情、卡片、
   widget。
5. **显示界面**：卡片 TextView 渲染（缩进 + 分级字号/透明度）；RemoteViews（`setViewPadding` 缩进 +
   `setTextViewTextSize`）；首页/widget 点击完成走共享状态机；截断维持按项数 + `...`；SIMPLE_FCLI 只折叠
   分隔线以下。
6. **单一文本输出**：`toContentStr` 带标记输出改标准 Markdown 任务列表（`- [ ] / - [x]` + 每级 2 空格），
   空前缀用法保持拍平。
7. **拖拽**：子树块移动、兄弟带约束；收束/展开动画 + 组根角标（后代总数）。

## 待真机微调的参数（起点已定）

- `LEVEL_SIZE_RATIO` / `LEVEL_ALPHA_RATIO_UNFINISHED` / `LEVEL_ALPHA_RATIO_FINISHED`：均 0.9，三个独立常量。
- 密集卡片（≥8 项已 14sp 下限）叠加按级缩放后是否需要最小字号下限。
- RemoteViews 缩进步长近似 dp、通知/分享每级前导空格数（暂定 2）、收束/展开动画时长与缓动。

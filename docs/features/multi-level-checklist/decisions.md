## 2026-06-26 - 完成态不变量：已完成项的所有下属都已完成（已完成项获未完成下属时自动改回）

发现：把一个未完成项缩进到已完成项下、或原位取消已完成项的某个子项，会得到“已完成父项挂着未完成
子项”。该状态早前其实已可达（原位取消子项时父项不变），但与“父完成→子都完成”的直觉冲突。**选择严格
不变量**「已完成项的所有下属都已完成」：一旦某已完成项出现未完成下属，它连同其已完成祖先链都自动改回
未完成；旁系（非祖先）已完成项不受影响（仍满足“已完成的部分照常显示”）。

实现：新增 `CheckListHelper.normalizeCompletion`（自下而上把“子树里有未完成项”的已完成项改回未完成），
接在 `toCheckListItems`、`ChecklistCompletion.toggle`、详情页缩进/反缩进、删除之后。副作用：原位取消一个
子项现在会连带把它的已完成祖先链一起改回未完成（之前父项保持已完成）——这是严格不变量的必然，且更贴
“重开子任务则父任务也未完成”的直觉。组根迁移不受影响（底部已完成组本就全完成，不会被翻转）。

## 2026-06-26 - 改为禁止层级跳空（推翻早前“允许跳空”的选项 A）

实测发现：在 `[1,2,2]` 上缩进第一个二级项会得到 `[1,3,2]`，那个三级项没有直接的二级父项（层级跳空），
用户视之为孤儿/非法结构；反缩进父项、删除中间项也会产生同类跳空。**决定禁止层级跳空**（即早前 grill
里被否的选项 B），推翻“禁孤儿 + 允许跳空”。实现两道防线：

1. **缩进门控收紧为“无跳空”**：`canIndent` 改为——自该项向上扫描，遇到的第一个“层级不深于自身”的真实项
   必须**恰好同级**（即存在同级的上一个兄弟）才允许缩进；若它更浅（自身已是某父项第一个子项）则禁用。
   这样缩进后该项恰好成为兄弟的子项、只深一级，不会跳空。
2. **层级归一化兜底**：新增 `CheckListHelper.normalizeLevels`，自上而下把每项层级钳到“owner 层级 +1”。
   在 `toCheckListItems`（覆盖所有读取/重建：加载旧数据、各界面渲染、完成后重建）以及详情页反缩进、删除
   后调用，自动把反缩进父项、删除中间项、历史遗留数据里的跳空收回到合法层级（深层项随父项上移）。

副作用：单项反缩进父项时，其子树会被归一化“带着上移”一级（等价于子树反缩进），这是禁跳空的必然结果，
与用户预期一致。`CONTEXT.md` 的 owner/level 术语同步改为“owner 恰好浅一级、不允许跳空”。

## 2026-06-26 - 数据模型：层级显式存储，归属由位置派生

层级（1/2/3）是逐项显式存储的属性，用户通过缩进/反缩进直接编辑；归属（owner）不存父
指针，运行时由“上方最近的、层级严格更浅的项”派生，可不存在（孤儿）。代码本就完全基于
位置，派生归属顺着这个纹理走。

## 2026-06-26 - 存储编码：状态位后加独立层级位（方案 B）+ 一次性迁移

清单串每个真实项从 `SIGNAL + <状态位> + <文本>` 改为 `SIGNAL + <状态位> + <层级位> + <文本>`：
`item[0]` 仍是纯状态位（`0/1`），`item[1]` 是层级位（`1/2/3`），文本变成 `substring(2)`；
控制标记 `2/3/4` 保持单字符不变。好处是现有所有 `state == '0'/'1'` 判断零改动，只需把取文本
的 `substring(1)` 改成 `substring(2)`、并在读层级处多读一位；`toContentStr` 导出纯文本时一并
跳过层级位。代价是旧数据需要一次性数据库迁移（新版本号，扫描 `isCheckListStr` 的 Thing，
给每个真实项插入层级位 `1`）。备选方案 E（状态+层级打包进单个数字、零迁移）被否，因为它把
风险摊到每一处状态读取点。**此项将落一篇 ADR。**

## 2026-06-26 - 完成模型：按“组”整组迁移，组内二/三级就地完成

底部已完成区从“逐项迁移”改为“整组迁移”：

- 组 = 组根 + 其逐层归属下的所有项。
- 完成/取消任意一项 → 把该项连同其整棵子树一起置为该状态（**完成、取消都向下级联整棵子树**）。
- 触发整组下沉/上浮的是**组根**的完成态，不是字面“一级”。完成组根 → 子树全完成 + 整组下沉
  到底部已完成区；完成非组根的深层项 → 就地完成、留在原位（删除线 + 对号样式）。
- 取消的“向上”副作用：在底部取消一个深层项时，被点项的子树取消，同时它的组根被**结构性地**
  强制改为未完成（好让整组挪回上方），但这个强制只作用于那一个组根、不横扫它的其它分支，
  因此兄弟里原本完成的项仍就地显示为完成（“已完成的部分该怎么显示就怎么显示”）。
- 一级项无子项时自成单项组，完成即整组下沉——与现有扁平清单行为完全一致。

## 2026-06-26 - 组根概括孤儿项（后被“禁孤儿”取代为：组根 ⟺ 一级项）

“组根 = 无 owner 的项”。归属定义是“上方最近的、层级严格更浅的项”，两个相邻的一级项是
各自独立的组。**注**：见下条“禁止孤儿项”，最终孤儿被缩进门控禁止，组根恒等于一级项。

## 2026-06-26 - 禁止孤儿项（缩进门控）+ 允许层级跳空（“允许跳空”部分已被上方决策推翻）

> 注：本条“允许层级跳空”的部分已被本文件最上方“改为禁止层级跳空”一条推翻，现为禁跳空。其余（禁孤儿、
> 组根 ⟺ 一级项）仍然成立。

禁止出现没有 owner 的二/三级项（孤儿）。收益：组根塌缩为“⟺ 一级项”，所有为孤儿单设的分支
（完成迁移、拖拽、组根判断）消失，已敲定规则原样成立、只是更简单。实现：仅给**缩进按钮**加
门控——“向右”按钮只在该项上方存在更浅的项时才启用（清单第一项永不可缩进；被缩进项的原有
子项事后重算归属，总能落到更上方某个更浅 owner，不会变孤儿）。反缩进无需门控（永不造孤儿），
拖拽只在兄弟带内重排子树块、不改 owner/层级，天然保持无孤儿。

**允许“层级跳空”**（选项 A）：反缩进一个有三级子项的二级项，会得到“一级直接管三级”的断层
结构——这不是孤儿，允许存在，从而反缩进保持单项、无门控。否决了选项 B（连跳空一起禁），因为
那会迫使反缩进“连子树带”或在有子项时禁用，把单项语义搅复杂。owner 因此可以比被管项浅不止一级。

## 2026-06-26 - 底部已完成区的排列

- 已完成区里永远是“整组都已完成”的组（不变量：组根完成→级联全完成；从底部取消任意深层项→
  整组立刻被拽回上方）。
- 整组以一个块迁移，完成时整块插到已完成区**最上方**（最新完成的组在最上），块内保持
  “组根→子项”的原阅读顺序。
- 取消让整组回流时，整块挪到上方未完成区的**最顶端**（沿用现在“取消单项移到索引 0”）。
- 已完成区内照样渲染层级缩进与分级样式，叠加已完成的删除线/变淡。
- “N 项已完成”头部**只统计底部已完成区内的项数**（不含顶部就地完成的项）。

## 2026-06-26 - 缩进/反缩进交互（详情页）

- **删除入口**：右侧删除图标改作缩进按钮后，**退格删除成为唯一删除途径**；删除一个带子项的项
  时**只删单项**、子项保留并按位置重算归属。
- **作用对象**：缩进/反缩进**只动单项**（±1 级，钳制 1~3），子项不跟着动、事后重算归属；
  这与拖拽“连整棵子树”刻意不同。
- **允许越级造孤儿**：哪怕第一项、上方无父级，也允许缩进到三级，只受最深三级钳制，无前置条件。
- **按钮出现时机**：缩进（右）/反缩进（左）只在该项**获得焦点**时显示，失焦隐藏；**层级缩进
  （左边距）始终显示**，不受焦点影响。
- **边界隐藏**：一级只显右侧缩进；二级左右都显；三级只显左侧反缩进。
- **缩进几何**：每加深一级整行左移固定量 = 状态图标宽 + 文本左边距 ≈ 36dp + 8dp ≈ 44dp，使子项
  状态图标左缘对齐父项文本左缘；反缩进按钮摆在这条缩进留出的左侧空档里。

## 2026-06-26 - 分级排版：三个独立的 0.9 常量

- 每深一级，字号与透明度各乘一个系数，**都从 0.9 起步，但写成三个独立常量**便于后续分别微调：
  - `LEVEL_SIZE_RATIO`（字号，所有项通用）
  - `LEVEL_ALPHA_RATIO_UNFINISHED`（未完成项透明度，基于 76%）
  - `LEVEL_ALPHA_RATIO_FINISHED`（已完成项透明度，基于 50%）
- 字号比例对任何基准字号成比例缩放（详情 20sp、卡片动态值、各 widget 基准都适用）。
- 已完成项也按级降透明度（与未完成项各用独立常量），删除线仍是已完成的主要区分信号。

## 2026-06-26 - 顶/底边界的真理来源改为分隔标记

## 2026-06-26 - 拖拽规则与收束动画

- **移动单位 = 被拖项 + 整棵子树**，作为块移动；**可重排范围 = 同一 owner 下的兄弟带**；拖拽**只重排
  顺序、绝不改 owner/层级**（改层级是缩进专属）；**不跨未完成/已完成边界**。拖组根=整组之间重排。
- **实现采用“组根代理 + 收束动画”**（否决真多行跟手）：拖拽开始时被拖项的整棵子树**动画收束进被拖
  行**，只剩该行、右侧角标显示**后代总数**；拖拽中只此行跟手、在兄弟带内重排；松手在目标位置**动画
  展开**还原；叶子项无需收束即单行拖拽。最终数据结果与真整块拖拽一致，复用 `ItemTouchHelper` 单行拖拽。
- 拖拽的撤销记录改为**内容串 before/after**（与缩进、完成等其它操作统一），不再用单一 from/to 下标
  （块移动无法用单一 from/to 表达）。

## 2026-06-26 - 缩进/反缩进在任意区域均允许

详情页已完成项也是可编辑 EditText，聚焦后同样出现缩进/反缩进按钮。决定**顶部未完成区与底部已完成
区都允许缩进/反缩进**，结构按位置重算，不为底部单设门控。改层级不改状态，被改项仍是完成态，不破坏
“底部 = 整组完成”的不变量。

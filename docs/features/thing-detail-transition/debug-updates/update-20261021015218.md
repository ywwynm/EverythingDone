## 修复未修改视频记事返回时的小组件刷新等待

在 OPPO Find X9 Ultra 主设备上复现：已缓存 GIF 的视频记事，点击返回后仍等待约半秒才开始缩小。调用栈确认，未修改的记事也会触发桌面小组件刷新，小组件在主线程重新从原视频取得静态封面，阻塞转场截图回调。

在 `DetailActivity.kt` 中，仅在正常返回且正式判定为没有修改时跳过多余的小组件刷新。实际编辑、创建、后台自动保存、状态改变和外部接收更新仍保留刷新；动画时长、曲线、元素及保存流程不变。

同一原记事、实际返回按钮、各六次且不启用采样，起播等待中位数由 519.6 ms 降到 158.2 ms。停留 12 秒后约 181 ms，系统返回约 162～165 ms；两组末帧与真实首页逐像素一致。JVM 1719 项，0 失败／错误、3 项既有跳过。

按用户要求仅检查指定记事，没有整库备份或创建副本。目标记事及对应提醒的每次摘要均一致；原附件保持不变。此次未修改原记事，也没有将小组件视频渲染改成异步流程。

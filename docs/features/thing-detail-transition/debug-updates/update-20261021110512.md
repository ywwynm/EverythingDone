## 优化首次横屏返回时重复解析外观 JSON 的成本

用户要求继续优化魅族首次横屏返回的列表外观解析，保留现有动画效果，并在一加 15T、三星和魅族回归。已有记事、附件及小组件配置保持原样，不做整库备份；编辑和删除验证只使用专用模拟记事。

新增 `ParsedAppearanceCache.kt`，卡片外观、详情附件外观与背景通过完整 JSON 字符串复用不可变解析结果。每类缓存最多 1024 项、512 Ki 字符，单项超过 64 Ki 字符继续直接解析。嵌套来源及呈现集合不可修改，编辑和导入重写创建新值；并发解析不持有缓存锁，后台小组件读取不阻塞已缓存的界面读取。

保留完整列表重读，不按记事 ID／更新时间猜测外观是否过期，不修改保存、私密、导航或转场绘制。相同 ID 和更新时间下，新的外观 JSON 仍立即生效，其他记事不受影响。

三机同批真实数据的八轮重复解析中位数分别从 18.27／22.57／40.57 ms 降至 5.71／10.91／5.71 ms。魅族整体首次横屏返回仍有运行状态波动，交替版本两轮优化后为 337.8／362.8 ms，初轮曾出现 507.2 ms；不能将解析收益当作整体首次等待的稳定降幅。保留原动画时长及交接效果。

三机基础功能回归 391 项通过，覆盖外观变更、快速返回、完整返回、小组件、保存竞态、导航及模拟私密场景；21 组末帧逐像素一致。JVM 1732 项，0 失败／错误、3 项既有跳过。669 条原有记录的前后摘要一致，原小组件配置未变。另完成定向采样、交替版本性能及原数据语义一致性核验。

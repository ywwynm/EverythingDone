## 减少列表打开详情的首次准备工作

用户反馈魅族首次准备接近 0.7 秒仍然过慢，要求继续分析并优化，同时保留当前动画，并在三台指定设备上回归，保护现有记事。

本轮增加点击、捕获、详情初始化和窗口准备的分段测量。DetailViewPreparation 使用 AndroidX 异步创建一份空详情布局、固定编辑区及快捷提醒选择器；取用时交给真实 DetailActivity，配置不符、未准备好或内存回收时立即走原同步路径。缓存不含任何记事内容或认证状态。

同时取消随后会被应用自绘复选框替换的系统资源；DetailToolbarContrast 在媒体实际进入顶部按钮区域时才生成图标采样；普通提示条按需创建；碰一碰入口延至动画交接完成后初始化。修正准备超时绕过窗口焦点与稳定布局的问题，防止慢设备在首帧可见前消耗动画时长。保留双 Activity、360 ms 时长、原曲线、文字和媒体元素、状态栏交接。

同方法六次短正文测量中，魅族首次初始化从约 271 ms 降至 152 ms，首次整体等待从约 680 ms 降至 632 ms；后续五次为 178～464 ms。首次整体改善约 7%，不能把初始化约 44% 的改善写成总等待改善。普通进程冷启动仍有超过一秒的样本，窗口添加、首帧绘制和焦点准备仍有优化空间，本版没有宣称首次打开已无明显等待。

三台设备重新打开 655 条可访问原有记事，13 条私密／正在计时记录跳过；长短正文、清单、渐变、多种封面、GIF／视频、模拟私密、重复点击、返回／旋转／重建、模拟保存、新建三档及不同裁剪均通过。三机空布局／同步布局像素完全一致，转场末帧与真实详情最大通道差 1／255。28 项相关 JVM 测试通过。

本轮备份与最终回归后的全业务表完整行一致，原有记事内容和全部字段、文件夹、提醒、习惯、计时、桌面组件均未改变，累计数量缓存一致，专用模拟记事已清理。没有尝试真实指纹认证，没有测试卓易通本体，没有创建 Git 提交。发布产物及安装核验完成后另记于功能报告。

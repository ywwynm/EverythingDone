## 列表卡片在应用内展开为记事详情

用户反馈卓易通不播放系统 Activity 转场，希望自行实现从小卡片到完整详情的连续动画，明确保留两个 Activity，并确认现有新建页动画的画面交接可用。本次沿用一次性列表快照承接，新增 ThingDetailTransition，以统一进度控制容器边界、圆角、文字基线与字号、同源封面；布局和裁剪不一致的区域局部渐变。

ThingsActivity 的普通卡片及文件夹缩略预览入口接入新动画，认证完成后重新定位记事。DetailActivity 处理首屏准备、状态栏配色、输入保护、返回／旋转／重建清理，附件自动播放仅在转场期间暂缓。捕获失败、来源失效或外部入口仍可正常打开详情，不改变记事保存逻辑。

实测修正图片上方按钮被遮挡、真实图片透明度干扰顶栏配色、认证窗口尚未恢复焦点时误吞打开，以及状态栏图标提前切换的问题。API 29 及以上整屏快照优先保留硬件位图，减少像素往返；其余情况保留兼容捕获。

## 修复返回动画的卡片与文字残影

用户反馈返回动画有残影。实机中间帧确认两处原因：尚未收回到位就叠入真实列表，导致卡片和文字出现在两个位置；详情正文与卡片摘要换行不同，直接交叉淡化导致同一句重复显示。原有末帧一致检查不能排除这两种运动中问题。

`ThingDetailReturnTransition` 保持 300 ms 总时长和容器收回效果，前 252 ms 完成几何运动，后 48 ms 在同一位置交接真实内容。不同排版的文字和不对应控件先退后进；单行同文仍按字号、基线对齐。同源媒体沿用原有裁剪过渡，保存、排序、刷新与输入释放机制不变。

回归另捕获到 OPPO 模拟认证交接时打开动画的进度倒退，`ThingDetailTransition` 补齐与返回一致的单调进度保护。新增 debug 中间帧像素及正文排版重叠检查，分别记录失败复现和修复后结果。

三台指定设备各 177 项、共 531 项有效检查通过，覆盖长短正文、清单、媒体、渐变、缩略卡、编辑、排序、筛选、保存等待、并发更新、私密模拟、取消、新建兼容及真实触摸返回；每台另含 8 条已有记事的只读打开／返回。45 组末帧与真实内容逐像素一致。JVM 1719 项中 3 项既有跳过，0 失败／错误。

三台全部原业务表及累计数量与独立备份一致，测试记事、文件夹和设备素材目录已清理。没有 Git 提交。卓易通宿主和真实指纹仍需用户在自己的设备上确认。

诊断与验证详见 `docs/features/thing-detail-transition/return-ghosting-2026-10-20.md`。

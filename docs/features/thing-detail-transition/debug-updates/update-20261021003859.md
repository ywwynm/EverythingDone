## 优化缓存视频 GIF 封面的返回等待

用户反馈含视频附件、以其派生 GIF 作为封面的记事，点击返回后停顿一下才开始缩小。用真实返回按钮和已完成生成的约 22 MB GIF 对照四台设备，确认缓存命中正常；额外准备开销包含媒体元素的独立离屏截图和列表窗口恢复。

`ThingDetailReturnTransition.kt` 对普通 GIF 图片控件直接捕获已解码的当前显示帧，保持原裁切、矩阵、分辨率及独立快照；具有背景、前景或自身 outline 的控件保留原路径。布局稳定后的终点捕获与焦点交接并行，真正开始动画仍等待首页焦点。保留连续两帧稳定布局检查，避免把正在清退的文件夹缩略卡片当作落点；保留 300 ms 动画、元素衔接和原保存机制。

四机视频封面／背景返回等待中位数由约 180／182／174／189 ms 降至 164／156／152／156 ms（OPPO 手机／三星／魅族／OPPO 平板）。仍包含两个 Activity 的系统窗口切换时间。

最终 798 项真机检查通过，43 组末帧逐像素一致，24 组 GIF 当前帧与原硬件捕获逐像素一致；返回后继续正常播放。覆盖原有记事、专用模拟记录、保存、重排、目标消失、缩略预览关闭、模拟私密、通知、计时页、嵌套导航及旋转。JVM 1719 项，0 失败／错误、3 项既有跳过。

740 条原记事、其他业务表和累计数量均未改变。测试记录、缓存及设备素材已清理，原方向设置已恢复。详细记录见 `docs/features/thing-detail-transition/video-return-performance-2026-10-21.md`。

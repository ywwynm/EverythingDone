# 动态视频封面：后台生成可靠性修复 P1/P2/P3（debug 发布）

据代码审查修了三处后台可靠性问题：

## P1 — 并发互删临时文件（必修）

迁到 WorkManager 后不同视频的生成任务会并行；旧逻辑"生成开始时删同目录所有 `.gif.tmp`"会删掉别的任务正在写的临时文件，导致大文件夹里多个视频封面同时生成时互相卡住、反复重试。
**修复**：只删当前视频自己的临时文件；遗留的孤儿临时文件改为按年龄（>10 分钟）清理，绝不碰正在写入的。

## P2 — 失败后回调泄漏

生成永久失败（坏视频、视频被删、低存储重试用尽）时，之前登记的"生成好就换成动画"回调不会被清理，会一直持有列表项视图引用。
**修复**：失败时也通知并清理回调，UI 保持静态封面帧；不再泄漏。

## P3 — 低存储兜底

**修复**：生成前也先清一次缓存上限；并给后台任务加"存储不足时延后"约束，低存储时不再反复失败、等空间恢复再生成。

## 说明

VERSION→8，视频封面会按修复后的并发路径**重新生成一次**——方便你验证：打开那个**大文件夹**（多个视频封面同时出现），它们现在应能**各自顺利生成完**（不再互相卡住）。发我 `video-cover-preview.log` 看 `ENQUEUE`/`WORKER run`/`GEN done` 是否每个视频都走到 `done`。

# 动态视频封面：坏 GIF 回退静态帧 + 尾帧不跳变（debug 发布）

修了两处（据代码审查）：

## 坏 GIF 不再让封面消失

派生 GIF 若损坏 / Glide 解不了，之前会**隐藏封面**。现改为：视频派生 GIF 加载失败时，自动**回退显示该视频的静态封面帧**（同样的裁切），封面不再消失；并把这个坏 GIF 删掉一次以便下次自愈式重生成（带防死循环守卫）。真正的 GIF/动态 WebP 附件自身坏了仍按原样隐藏。

## 选末尾附近的帧不再倒跳

之前为了凑满 3 秒，会把 GIF 起点前移，导致"静态帧→动画"切换时画面倒跳。现改为：**从你选定的封面帧开始**截取，第 0 帧恒等于该帧；末尾不足 3 秒就**短循环**（不再硬凑、不前移）。

VERSION→10，视频封面按新逻辑重新生成一次。升级后可重点看：把某条记事的视频封面帧选到**接近视频结尾**，确认静态→动画切换不再跳；其余视频封面正常动、画质正常。

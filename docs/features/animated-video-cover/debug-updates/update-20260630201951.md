# 动态视频封面：定位生成阻塞（逐帧日志 + 改用 getFrameAtTime）（debug 发布）

## 上一版结论

31 帧 / 480px 仍然 `GEN start` 之后无任何输出、目录只剩 `.gif.tmp`——说明卡在前 10 帧之内的某个调用上（不是慢，是阻塞）。最大嫌疑是取帧 API `getScaledFrameAtTime`（部分机型会卡死且不返回 null）。视频在**大文件夹缩略图**里，可能与列表同时为多个子项视频抽静态帧争抢硬件解码器有关。

## 本次改动

1. **逐帧日志**：每帧分别打印 `f<i> decoding` / `f<i> decoded dt=..ms 尺寸` / `f<i> encoded et=..ms`。日志最后一行直接指明卡在"取帧"还是"编码"、第几帧。
2. **改用 `getFrameAtTime`**：弃用嫌疑最大的 `getScaledFrameAtTime`，改用最兼容的 `getFrameAtTime` 自行降采样。若卡死是它引起，本版即修复。
3. VERSION→3、清残留 `.tmp`。

# 动态视频封面自动播放（debug 发布）

## 本次新增

视频封面现在也能在记事列表里自动循环播放——和 GIF 封面一样。原理：为视频封面派生一个高质量 GIF 预览（每帧独立调色板 + Floyd-Steinberg 抖动，长边 720px、约 3 秒、25fps、无限循环），喂进既有动图管线播放，并按你设定的裁切逐帧显示。

## 新增设置

设置 → UI 设置组，新增"自动播放封面动态内容（GIF / 视频）"开关，**默认开**。

- 开：列表卡片上作为封面的 GIF 与视频自动播放。
- 关：视频回到静态封面帧、GIF 回到首帧；返回首页即生效。

## 行为说明

- 视频封面首次显示时先显示静态帧，后台生成预览，好了自动换成动画；之后再进入直接是动画（已缓存，每个封面只生成一次）。
- 以你在卡片外观里选定的"视频封面帧"为循环起点。
- 改裁切不会重新生成、即时生效；改封面帧会重新生成。
- 滚动快滑时暂停可见封面动图（含 GIF）、停下恢复，减轻卡顿。

## 测试关注点

- **画质**（720px / 25fps 的 GIF 观感）与塞满视频封面时的**滚动流畅度**——据此再调帧率/分辨率。
- 各封面位置（顶/底缩略图、侧栏、媒体背景）裁切是否正确。
- 开关切换、升级后存量视频封面是否自动生成预览。

## 已知 v1 边界

- 改帧 / 删附件后旧预览文件暂靠 1GB 缓存上限自动淘汰（非即时删除）。
- 预览生成为单后台线程，多个新视频封面同时首次显示时逐个生成。

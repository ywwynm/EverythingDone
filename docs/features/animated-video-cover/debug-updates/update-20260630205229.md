# 动态视频封面：编码档位升到 STABLE_HIGH_MEMORY（debug 发布）

## 改动

原生编码器档位从 `ENCODING_TYPE_NORMAL_LOW_MEMORY` 升到 **`ENCODING_TYPE_STABLE_HIGH_MEMORY`**（画质/稳定性最好的一档）。VERSION→5，旧缓存按新画质重新生成。

其余不变：480px / 12.5fps / 2.5s ≈ 31 帧。原生编码很快，这档的额外内存对 480px 单帧很有限。

# 动态视频封面：缓存改外部目录 + 诊断日志（debug 发布）

## 本次改动

排查"看不到生成的 GIF"：上一版把派生预览写在**内部缓存** `/data/data/com.ywwynm.everythingdone/cache/`，真机未 root 无法浏览，所以在 `Android/data/` 下看不到，并不代表没生成。本次：

1. **缓存改到外部缓存**：派生 GIF 现在写到 `Android/data/com.ywwynm.everythingdone/cache/video-cover-previews/`，你可以直接用文件管理器查看是否产出。
2. **加诊断日志**：日志写到 `Android/data/com.ywwynm.everythingdone/files/debug_logs/video-cover-preview.log`，记录每个视频封面的判定（是否识别为视频、自动播放是否开、缓存是否命中）与生成过程（时长、起始帧、帧数、成功字节数或失败原因）。

## 怎么帮我定位

打开有视频封面的记事列表后，把这两处发我（或截图）：

- `Android/data/com.ywwynm.everythingdone/cache/video-cover-previews/` 里**有没有 `.gif` 文件**；
- `Android/data/com.ywwynm.everythingdone/files/debug_logs/video-cover-preview.log` 的**内容**。

据此即可判断是"没识别到视频封面 / 自动播放没开 / 生成失败（含原因）/ 已生成但没播放"哪一种。

## 说明

外部缓存仍是缓存语义（卸载即清、可被系统回收）。功能逻辑与上一版一致：视频封面在开启自动播放时派生 GIF 循环播放，首帧为你选定的封面帧，先静态后换动画、每个封面只生成一次。

# 动态视频封面：关闭诊断日志（debug 发布）

把派生预览的诊断日志收到一个总开关 `VideoCoverPreviewManager.DEBUG_LOG` 后**默认关闭**：

- 所有 `DebugFileLogger.log(...)` 调用改走门控的 `debugLog(...)`（Manager 与 Worker 统一走这一处）；`DEBUG_LOG = false` 时不写 `video-cover-preview.log`。
- UI 绑定热路径 `logBindDecision` 在关闭时直接早退，不做任何磁盘 stat，零开销。
- 以后要排查只需把 `DEBUG_LOG` 改 true 重新编译即可恢复全部日志。

功能与参数不变（3s / 25fps / 720px / 原生 `STABLE_HIGH_MEMORY` / WorkManager），无 VERSION 变更，已生成的缓存继续有效。

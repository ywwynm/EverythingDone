# 动态视频封面：生成卡顿修复（降帧 + 分阶段计时）（debug 发布）

## 诊断结论

上一版日志显示：视频封面识别正常、自动播放已开、生成已启动（`GEN start frameCount=75`），但一直没有 `GEN done`，目录里只有 `.gif.tmp`——说明**生成卡在中途/极慢**。根因是 **75 帧 @ 720px 用纯 Java 的 Square 编码器太慢**（逐帧 median-cut 量化 + Floyd-Steinberg 抖动，CPU 密集）。

## 本次改动

1. **降参数让生成能跑完**：480px、12.5fps、2.5s ≈ **31 帧**（约为原来 1/5 的工作量）。
2. **分阶段计时日志**：`video-cover-preview.log` 现在分别记录**取帧耗时（decodeMs）**与**编码耗时（encodeMs）**、每 10 帧进度、总耗时——据此判断瓶颈在取帧还是编码，决定后续是再调参还是换更快的编码路径。
3. **清残留 `.tmp`** + VERSION 升级（旧 v1 缓存 key 失效）。

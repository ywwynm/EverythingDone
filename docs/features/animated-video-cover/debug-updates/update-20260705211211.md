# 2026-07-05 - 添加视频封面 GIF 播放诊断日志

本次 debug update 用于排查一个非常特殊的视频封面问题：在横屏、普通宽度 Thing Card、封面视频位于上方或下方、且封面目标比例为 4:3 时，派生 GIF 文件已经生成，但卡片上仍没有正常播放。

本次没有改变播放策略，只添加诊断日志：

- 打开 `VideoCoverPreviewManager` 的文件日志开关，日志写入应用文件目录下的 `debug_logs/video-cover-preview.log`，统一前缀为 `[DEBUG-video-cover-preview]`。
- 在 `BaseThingsAdapter` 的前景视频封面路径记录绑定分支：是否开启 Cover Autoplay、目标尺寸、卡片宽度类型、列表列数、`loadKey`、当前 `ImageView` tag、派生 GIF 是否 ready、派生 GIF 文件大小和缓存路径。
- 在 ready GIF 命中、后台生成完成回调、静态帧回退、Glide `Drawable` 加载成功/失败、`ImageView.post` 后实际 drawable 状态，以及滚动暂停/恢复动图时记录日志。
- 日志仅针对视频封面、上/下方前景缩略图、非媒体背景卡片，避免普通图片或其它卡片大量刷屏。

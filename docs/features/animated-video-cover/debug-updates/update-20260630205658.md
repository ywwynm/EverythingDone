# 动态视频封面：提分辨率与帧率（debug 发布）

## 改动

原生编码确认通畅后提画质：

- **分辨率**：长边 480px → **720px**；
- **帧率**：12.5fps → **25fps**（40ms/帧 = 4 厘秒，GIF 延迟整除干净）；
- 时长仍 2.5s，故约 **62 帧**；
- 编码档位仍 `ENCODING_TYPE_STABLE_HIGH_MEMORY`；VERSION→6 按新参数重生成。

帧数翻倍后，主要耗时在取帧（~90ms/帧 × 62 ≈ 5–6s）+ 原生编码（快），单个视频约 8–10s，属可接受的后台生成。

## 请测

升级后打开有视频封面的列表（含大文件夹），看：

- 视频封面**画质是否更清晰、动得更顺**；
- `…/cache/video-cover-previews/` 的 `.gif` 大小（720p/62 帧可能数 MB/个，留意累计）；
- 发我 `video-cover-preview.log` 的 `GEN done`（`totalMs / decodeMs / encodeMs`）。

若觉得生成偏久或文件偏大，可回调到 600px 或缩短时长。确认这档满意后，下一步迁 WorkManager（扛进程被杀）。

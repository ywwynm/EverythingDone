# 状态改为分段胶囊，移除独立回收站行

把状态筛选改成一个分段胶囊（自定义 View）：
- 正在进行 / 已完成 / 回收站，固定从左到右。
- 选中的那段展开显示 icon+文字并被填充，另外两段收缩为只显示 icon、停在两侧；切换有展开/收缩动画。
- 整个胶囊有 accent→accent2（文件夹下为文件夹色）渐变描边，描边和选中段的填充用同一条横跨整个胶囊的渐变，融为一体、不分开渲染。
- 各段触摸有 ripple。

下方原来单独的“回收站”行已移除——回收站现在是状态分段的一段。这样：
- 文件夹列表区域始终保持选中项（不会再因为点回收站而失去选中、再点文件夹又进入该文件夹的已删除投影）。
- 点状态分段不再关闭抽屉（方便看到动画、继续组合筛选）；类型按钮也不关；只有点“全部记事/文件夹”这类范围项才关闭抽屉。切换状态仍保留当前范围和类型筛选。

验证重点：① 三段切换的展开/收缩动画与渐变是否连贯；② 描边与选中填充是否是同一条渐变；③ 点回收站后文件夹列表是否仍保持选中；④ 各段 ripple。

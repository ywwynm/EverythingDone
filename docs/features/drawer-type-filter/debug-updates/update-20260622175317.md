# Drawer 胶囊筛选 + 三维正交（Phase A/B）

本次重构把"状态、文件夹范围、记事类型"做成三个正交维度，并重做了 Drawer。

## 新 Drawer 结构
- 顶部"所有记事"作为范围根，下面是文件夹树。
- 中间是筛选区：左侧状态胶囊（正在进行 / 已完成，单选），右侧类型胶囊（全部类型 / 记录·提醒 / 习惯·目标，全部类型排他、其余可多选）。
- 下方独立"回收站"行，再下面是设置 / 帮助 / 关于。

## 行为
- 切换状态保留当前文件夹范围和类型筛选；选择文件夹/所有记事也保留当前状态和类型。
- 状态胶囊点击会关闭抽屉并切换；类型胶囊点击不关闭抽屉，可连续多选。
- 进入回收站里的已删除文件夹后切回正在进行/已完成，会退回"所有记事"。
- 在某类型筛选下创建记事后，类型筛选自动回到"全部类型"，保证新建记事可见。
- 标题只显示状态名或文件夹名，不再附加类型筛选文本。

## 验证重点
- 胶囊选中为实心填充：在所有记事根目录下是 accent 渐变，进入某个文件夹后变成该文件夹的颜色；未选中为透明加轮廓，明暗模式下文字/图标/轮廓颜色自适应。
- 状态胶囊关抽屉、类型胶囊不关；选范围保留状态+类型。
- 回收站行高亮规则：处于回收站时只高亮回收站行。

## 已知待打磨
- "正在进行"状态图标暂时和"全部类型"共用同一个图标，后续会换更贴切的图标。
- 胶囊的列宽、高度、间距为初版数值，可能按真机再微调。

# 偏好

## 2026-08-15 - 音频输入选择的位置、选项与消费方

- “音频输入”选择行放在录音对话框的 `TimelyClockView` 下方。
- 选项固定包含“麦克风”“系统”“麦克风+系统”。
- 用户应能在首次开始录音前，以及点击“重新录音”回到准备态后选择输入。
- 最近一次选择需要跨录音对话框持久记忆，而不是每次打开都恢复为“麦克风”。
- 最终录到的音频既要传给 FableSol 动画实时响应，也要能够正常保存为音频附件。
- 选择器使用下拉 Popup，而不是三个平铺按钮。
- Popup 中每个选项除名称外，还要在名称下方显示提示性文本，把采集内容、权限、系统限制和隐私范围说明清楚。
- 正式录音期间在 Dialog 内隐藏音频输入行，保证 FableSol 动画的观看区域简洁；当前来源改由前台服务通知持续显示。
- 停止录音后继续完全隐藏音频输入行，不显示本次来源，也不能为该行保留纵向空间；只有点击“重新录音”回到准备态后才重新显示并允许选择。

## 2026-08-15 - 音频输入胶囊与 Popup 触摸反馈

- “音频输入”标签本身不属于可点击区域；只有右侧来源胶囊可以展开 Popup。
- 胶囊底色使用记事颜色的淡化版，淡化程度与 FableSol 未录音态一致；来源文字使用未淡化的记事颜色。
- 胶囊最右侧使用下三角图标，不使用旋转箭头图标；整个胶囊显示触摸 ripple。
- Popup 应比当前版本更窄并始终约束在可见屏幕内；每个可用选项都显示真实的触摸 ripple，不能只依赖简单的按下或选中背景。
- 音频输入行的两端必须对齐当前字体下 `TimelyClockView` 的稳定实际着墨边界，不能只对齐 View 的布局外框或固定 24dp 边距；布局结构参考录音完成后的文件名行，但“音频输入”文字之后只保留 8dp，胶囊自身扩展并填满到实际着墨右边界，不能在胶囊外放置弹性空白。胶囊内部的来源文字填充剩余宽度，下三角固定在最右侧。

## 2026-08-17 音频海浪动画方向权限提示定稿

### 背景与实现

- 实机诊断确认：从系统音频授权页返回后，部分系统会暂时不向应用提供设备方向信息；这段时间内 GL 渲染、Surface 和音频处理仍正常。
- 系统音频授权成功返回后，若 1.5 秒内仍没有新的设备方向信息，录音 Dialog 显示一次长 Toast。任意方向信息到达即取消等待；取消授权、普通页面往返或方向信息正常恢复时均不提示。
- 提示状态持久化到 `EverythingDone_preferences`，同一次安装中最多显示一次，App 重启及后续录音会话均不重复。
- 录音 Dialog 会读取设置页的“画面响应设备倾斜”开关；该设置为否时不准备方向传感器、不启动等待，也不显示此提示。

### 文案定稿

- 简体中文正文改为：“因权限设置原因，暂时无法获取设备方向信息，音频海浪动画无法随设备倾斜变化。请前往系统设置，将本应用的‘设备动作与方向’权限设为‘允许’。”
- 文案明确说明权限设置是原因，并以确定语气说明动画当前无法响应倾斜；操作指引由建议式改为直接请用户前往系统设置。
- 用户可见文案采用设置页正式名称“音频海浪动画”，不显示内部名称，也不使用生硬的传感器术语。
- 同步修改全部 13 个 locale：简体中文、繁体中文（香港）、繁体中文（台湾）、英语、日语、韩语、意大利语、西班牙语、俄语、法语、德语、印地语和葡萄牙语；各语言继续沿用对应设置页已有的正式动画名称。
- 本次更新替换阿里云更新码 `202608170939` 中较弱的旧版提示语。

### 验证

- `DirectionSampleDelayHintGate` 的 6 项门控回归测试通过，包含授权取消、倾斜监测关闭、方向信息及时恢复和一次性持久化等路径。
- 此前全量 Debug 单元测试 917 项通过，0 失败、0 错误、1 跳过；9018f404 实机验证首次满足条件时约 1.50 秒后提示，第二次不再提示。
- 最终 13 份本地化资源完整性检查及 `:app:assembleDebug` 构建通过。

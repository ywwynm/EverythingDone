# 2026-08-16 - 录音功能外部审查修复批：深浅色不丢录音、跨记事拦截、停止态跨进程恢复

## 更新内容

- 深浅色切换不再丢录音：此前系统深浅色变化（含日落定时切换）时详情页会关闭录音窗口并按"用户取消"丢弃正在进行的录音且无提示；现改为原地换肤——录音、水面动画、计时全程不断，窗口配色即时跟随新主题（真机验证录音跨两次切换持续未断）。
- 跨记事录音拦截：已有录音会话时从另一条记事（含新建记事页）再开录音，此前会静默接管会话并把录音保存到错误的记事；现在入口直接拦截并提示"正在为另一条记事录音"，附"前往"按钮一键回到原录音窗口。
- 停止态跨进程恢复：通知"停止并保留"后的待处理录音此前只存在内存里，进程被系统回收后录音文件会变成无人认领的孤儿；现在停止即持久化（文件、所属记事、时长、来源），进程重启后点通知或打开该记事都能恢复停止态窗口继续保存/丢弃（真机以"杀进程+通知全清"的最恶劣场景验证通过）。
- 长录音保护：逼近 WAV 单文件 4GiB 上限（立体声约 6 小时）时自动"停止并保留"并提示，不再可能产出损坏的录音文件；录音封装完成立即清理中间文件，磁盘占用峰值大幅缩短。
- 授权页期间进程被回收后，返回的系统授权结果不再被错误地按"麦克风"处理。
- 来源选择弹窗对读屏（TalkBack）正确播报当前选中项；录音临时文件与调参工具的目录隔离，互不干扰。
- 全量 Debug JVM 单测 905 例通过；OPD2515（Android 16）统一真机回归通过。

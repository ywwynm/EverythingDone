## 2026-08-17 系统授权返回后的音频海浪动画倾斜提示

### 用户反馈与诊断

- 在录音 Dialog 中切换到“系统”或“麦克风+系统”，从系统授权页返回后，音频海浪动画可能暂时无法随设备倾斜变化；重新录音并再次授权时也可能出现。
- 9018f404 实机诊断确认：这段时间内 GL 渲染、Surface 和音频重配均正常，真正缺失的是系统暂时未向应用提供设备方向信息；静音提示文本出现只可能碰巧伴随恢复，并不是根因。
- 该行为可能出现在不同系统上，因此产品提示不绑定任何厂商或系统品牌。

### 本次改动

- 仅在系统音频授权成功返回后监测设备方向信息；若返回 1.5 秒后仍没有新的方向信息，显示一次长 Toast。
- 任意方向信息到达后立即取消等待。取消授权、普通页面往返、关闭实时倾斜或方向信息正常恢复时均不提示。
- 新增线程安全的 `DirectionSampleDelayHintGate`，把授权、暂停、返回、恢复和超时的时序收敛为可测试状态；`AudioRecordDialogFragment` 只负责生命周期接入和 Toast 展示。
- Toast 展示前即将状态持久化到 `EverythingDone_preferences`，同一次安装中只提示一次，之后的录音会话和 App 重启均不重复。
- 简体中文正文为：“暂时无法获取设备方向信息，音频海浪动画可能不会随设备倾斜变化。建议前往系统设置，将本应用的‘设备动作与方向’权限设为‘允许’。”
- 用户可见文案统一采用设置页的正式动画名称，不显示内部名称，也不使用生硬的传感器术语。
- 核对 App 语言选择器后，将提示补齐为全部 13 个 locale 版本：简体中文、繁体中文（香港）、繁体中文（台湾）、英语、日语、韩语、意大利语、西班牙语、俄语、法语、德语、印地语和葡萄牙语。

### 验证

- 新增 6 项状态门控回归测试；全量 Debug 单元测试 917 项通过，0 失败、0 错误、1 跳过。
- 9018f404 实机验证：第一次满足条件时约 1.50 秒后提示，第二次同样条件下不再提示；测试后已恢复设备原有偏好，未消耗用户真实的首次提示机会。
- 文案修正及 13 个 locale 资源补齐后，`:app:assembleDebug` 构建通过。

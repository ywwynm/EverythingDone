# 2026-08-16 - 录音后台化后可从桌面图标与通知回到录音窗口

用户报告：录音中回到桌面后，点应用图标或通知栏的录音通知都无法回到录音窗口所在的详情页。已按用户选定的方案实现并真机验收。

## 更新内容

- 点桌面图标直达录音：主列表页（singleTask）收到桌面启动且录音会话进行中时，自动跳回录音所在详情页并恢复录音窗口——此前 singleTask 会把详情页连同录音窗口一起清掉、落在列表页。想去列表按一次返回即可。
- 录音通知可点击返回：Android 16 会把普通进行中通知折进自动聚合组，聚合组行的点击只展开分组、不触发跳转（先试的"提高重要度+显式分组"被系统强制覆盖，实测无效）。改为彩色进行中通知（满足系统 promotable 条件：进行中 + 标题 + colorized + 默认样式）后通知独立成卡，点击正确回到详情页并恢复录音窗口。通知渠道换新（静音、不振动），旧渠道自动删除。
- 恢复后的状态正确：录音时长接续显示、FableSol 水面动画实时响应，均由前台服务的单一会话驱动，真机截图验证（后台录音约 2 分钟后从通知返回，时钟从 00:02:00 接续）。
- 落点加固：录音会话记录所属记事；若返回时复用了正在展示其他记事的详情页实例，会按会话的原入口重启，避免录音附件保存到错误的记事（新建记事跳过该校验，防止重启循环）。录音窗口关闭收尾逻辑与"宿主被系统清栈"解耦，后台续录不再依赖内部执行顺序。
- OPD2515（Android 16）真机验收：图标接力与通知点击两条路径均端到端通过（SystemUI 确认点击真正触发跳转）；全量 Debug JVM 单测 901 例通过。

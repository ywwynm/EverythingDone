# 2026-08-16 - 修复录音来源在系统授权后锁死、采不到系统声音与不记忆

用户报告：准备阶段选择"系统"或"麦克风+系统"弹出系统授权画面后，无论允许还是取消都无法再更改输入来源；重新录音后同样无法更改；怀疑授权后并未真正采到系统播放的声音；关闭录音窗口重开后总是回到"麦克风"。OPPO 平板与手机均复现。

## 更新内容

- 定位到真正根因：详情页 `onActivityResult` 覆写后未调用 `super`，androidx ActivityResult 的分发链被掐断，系统授权结果（允许与取消都）被静默丢弃。授权请求标志因此永久挂起并锁死来源胶囊，录音会话从未切到系统采集（实际一直录麦克风），系统类来源的记忆也从未写入——三个现象同出一源。
- 详情页补上 `super.onActivityResult` 调用，并把旧式附件返回逻辑限定到拍照/摄像/选媒体文件的请求码，避免授权允许返回的 `RESULT_OK` 误触发一次附件添加；主列表页与设置页的同类覆写一并补上 `super`。
- 消除停止预览与切换来源路径上固定约 0.6 秒的线程收尾空等（引擎锁与采集线程退出互斥导致 join 必然等满超时），来源切换与停止响应更快。
- 授权结果、系统模式准备、回退麦克风三处保留 Debug 构建下的诊断日志，便于日后一轮定位同类链路断裂。
- OPD2515（Android 16）真机回归：允许授权后建立立体声 48kHz 系统采集、胶囊保持可改；音乐播放中录 12 秒录得约 -17.8dB 均值的真实内容（对照无播放时为数字静音）；关闭重开记住"系统"并自动请求授权；取消授权回退麦克风并提示、偏好按设计回退；录音中切走由前台服务续录、重开直接连上会话；系统预览运行中切回麦克风即时生效。全量 Debug JVM 单测 142 套件 901 例通过。

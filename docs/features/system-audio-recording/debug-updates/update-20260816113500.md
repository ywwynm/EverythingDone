# 2026-08-16 - 录音通知用记事颜色、修复通知返回后的全局卡顿与倾斜空窗

用户验收后反馈：通知希望用记事颜色而非应用主题色；从通知返回录音界面后时钟、水面动画和按钮全部严重卡顿（点图标返回则不卡，但刚返回时不响应设备倾斜）。

## 更新内容

- 修复通知返回后的全局卡顿（根因级）：水面 GLES 渲染此前把一次 `eglSwapBuffers` 失败一律当成设备级故障、永久降级为主线程 Canvas 软件渲染——而窗口 surface 销毁（回桌面、任务切换）与渲染线程在途帧存在竞争，恰好撞上就触发一次瞬态 `EGL_BAD_SURFACE`。降级后水面模拟与绘制全部压在主线程（实测帧时间中位 150ms、100% 卡帧、主线程满载），并且随复用的录音窗口一直存在；点图标返回不卡只是因为那条路径新建了渲染视图。现改为：交换失败按 EGL 错误码分级，surface 瞬态失效只暂停帧循环、等待新 surface 自动恢复，只有真实 GL 故障才降级。修复后同场景 0% 卡帧、帧时间中位 5ms，水面恢复 GLES 大波浪渲染，停止态的"保存并导出视频"按钮也随之回归。
- 录音通知底色改用所属记事的颜色（渐变记事取代表色），不再固定使用应用主题色；渐变记事另配一枚圆形渐变徽章展示真实渐变（系统的彩色进行中通知底色只支持单色，且自定义视图会破坏"可点击直达"的条件，徽章是渐变的唯一安全载体）。真机确认绿色记事的录音通知即为记事绿。
- 消除刚返回录音界面时不响应设备倾斜的空窗：录音会话现在记住最后一次姿态，重新打开或重建录音窗口时水面立即摆到当前姿态，不再等待重力传感器数百毫秒的预热。
- 保留 Debug 构建下的 surface 生命周期诊断日志，同类问题可一轮定位。
- OPD2515（Android 16）真机复现-修复-回归全链路；全量 Debug JVM 单测 901 例通过。

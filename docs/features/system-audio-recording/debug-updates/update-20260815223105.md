# 2026-08-15 - 录音 Dialog 系统音频输入与授权恢复

本次 Debug 更新为录音 Dialog 加入完整的多来源音频录制能力，并包含测试设备反馈后的交互与授权恢复修正。

## 更新内容

### 功能与交互

- 在录音准备态加入“音频输入”，支持“麦克风”“系统”“麦克风+系统”；选择结果跨 Dialog 记忆。
- 来源使用项目现有 `PopupPicker` 体系实现双行说明 Popup，没有使用 Android 原生下拉控件。右侧胶囊带记事色淡化底、完整记事色文字、下三角和 touch ripple；Popup 选项同样提供 ripple。
- 来源行按当前 `TimelyClockView` 字体的实际着墨边界动态对齐，而不是按固定宽度或 View 外框对齐。标签与胶囊间距固定为 8dp，胶囊吸收剩余宽度。
- 正式录音时隐藏来源行；停止后在音频名称下方只读显示；重新录音回到准备态后再次允许选择。

### 采集、后台与保存

- 新增 `AudioRecordingService` 和 `AudioCaptureEngine`。正式录音由前台服务持有，切换到其他 App 后继续采集；通知显示来源、计时及“停止并保留”，点击可返回录音 Dialog。
- 系统音频通过 `MediaProjection` 与 `AudioPlaybackCaptureConfiguration` 捕获。Android 14+ 请求整个屏幕范围，但应用只消费音频，不读取、编码或保存画面；来源 App 仍可禁止自身音频被捕获。
- 麦克风保存单声道 WAV；系统及混合模式保存立体声 WAV。混合模式把麦克风居中加入系统左右声道并做软限幅，设备支持时尝试启用平台 AEC。
- FableSol 消费与最终 WAV 相同的混音总线。录音切到后台时不绘制、不积压动画帧；返回 Dialog 后从当前实时音频继续响应。
- 正式录音期间投影撤销或必需输入硬故障时停止并保留已有录音；准备态失败则回退麦克风并显示原因。

### 授权锁死修复

- 修复系统类来源在授权和配置成功前就写入偏好的问题。现在只有投影、`AudioRecord` 和当前所需预览成功后才记忆系统类来源。
- 来源偏好新增成功确认标记。旧版已经写入、但无法证明配置成功的“系统”或“麦克风+系统”会在升级后首次读取时一次性迁移回麦克风，修复测试设备异常默认值。
- 开始按钮与来源胶囊使用独立可用性策略：开始录音仍需等待完整配置；`IDLE`、未配置 `PREPARED` 和 `ERROR` 状态保留来源选择恢复入口。
- 补齐前台服务启动、投影创建、回调注册和音频引擎配置的异常收尾，并增加 8 秒准备超时，避免界面永久停在无提示的 `busy=true`。

### 验证

- `:app:testDebugUnitTest` 全量通过，包含新增的来源控件状态、偏好提交/旧值迁移、PCM 混音、WAV 头和 FableSol 隐藏期队列测试。

# 2026-08-16 - 录音失败提示的文案纠偏与窗口宽度恒定

用户核对失败信息清单时发现三处文案与场景不符，另修复失败提示把录音窗口撑宽的问题。

## 更新内容

- 修复三处"已保留此前录音"出现在从未录音场景的文案错位：录音开始前系统音频授权被撤销时，现提示"系统音频授权已结束，音频输入已恢复为'麦克风'"（原文案错误宣称保留了录音）；录音开始前系统音频流中断时，现自动回落麦克风并给出对应提示（原先直接报错卡死且文案错位）；点击开始录音失败时（例如存储不可用），现提示"无法开始录音"。
- 修复显示失败提示时录音窗口变宽的问题：窗口宽度由计时器决定并保持恒定，较长的提示文本在现有宽度内自动换行居中显示，不再把窗口撑宽。
- 以上文案均覆盖简体、繁體（台/港）、英文四语言。
- OPD2515（Android 16）真机注入验证：失败停止态与正常停止态窗口宽度完全一致，提示换行正常，正常录音保存路径不受影响；全量 Debug JVM 单测 906 例通过。

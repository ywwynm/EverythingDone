## 修复 HDR 动态照片播放时的底部细边

修复播放 HDR 动态照片时，图像底部透出不均匀静图细边的问题。真实记事中的两张图片确认：静图与内嵌视频宽高比略有差异，按宽度对齐后，视频底边没有完全覆盖静图。

现在视频开始显示时同步遮住底层静图，停止后同步恢复。保留原视频比例、缩放和平移、完整尺寸位图及已准备的 HDR 输出层，避免拉伸、额外裁剪、重新解码或重建输出层；最终清晰度、增益图及 HDR 参数保持。

指定三星、一加、魅族三台设备完成 2063 项相关检查，覆盖两张真实附件的原生／PQ、普通倍率／放大平移、自动／长按播放和返回。48 组边缘像素对照均无底图泄露，24 组播放中捕获对照通过；真实大图、大视频、GIF 和其他动态照片也已回归。672 条原记事及所选附件摘要保持，完整位图与 HDR 参数和上一版一致。JVM 1732 项无失败／错误，3 项既有跳过。

兼容输出通过三机强制 PQ 路径验证；卓易通宿主本身未直接连接，截图不用于量化物理 HDR 高光。详细诊断和验证记录：`docs/features/hdr-media-display/motion-edge-2026-10-22.md`。

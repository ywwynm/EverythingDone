## 优化卓易通图片 HDR 的打开速度与切换过渡（2026-10-16）

用户确认上一版在卓易通已有 HDR 效果，但首次打开会先显示 SDR，随后短暂黑屏并突然变亮；点击 HDR 徽标也可能闪烁。本次同时检查图片像素数量与启动开销。

- HDR／SDR 开关复用同一 PQ Surface，改为 180 毫秒增益过渡；快速反向从当前强度继续，不重复解码或重建 EGL。首次显示补上系统重绘同步，以 SDR 基图开始平滑增加增益。
- 提前准备当前页，优先复用已解码图片的独立副本；减少逐像素复制。常见 sRGB／Display P3 基图上传量减半，保持原有色域转换和最终 HDR 公式，其它格式保留原来的 FP16 路径。
- 修正小图被提前放大的开销：960×640 测试图由原来被放大至 3960×2640，恢复为原像素尺寸。大图继续原有采样清晰度；兼容静图直接读取原附件，保留内存缓存，避免复用旧的重编码磁盘缓存。
- 2500 万像素对照样本仍按原有屏幕尺寸解码约 523 万像素，HDR 额外数据准备由约 121–145 毫秒降至 23–25 毫秒，基图上传由约 42 MB 降为 21 MB。这不包括首次读图、EGL 与卓易通屏幕实际响应；APP5 首次打开仍可能比暖启动慢。
- 在指定 OPPO 上通过 22 项查看器回归、24 次正常切换与 36 次快速反向切换；31 项 JVM 测试和 27 项 GPU 数值校验通过。覆盖缩放平移、动态照片、GIF、视频、旋转、前后台与失败回退。录屏中心图片区域未检出全黑帧。
- 仅已知卓易通兼容路径启用，普通 Android 的图片请求与系统 HDR 路径保持原逻辑。保留 HDR 对照页及日志文件导出，增加位图尺寸、分段准备耗时、首帧同步及增益过渡事件；请在卓易通重点复测初次打开和开关的实际观感。

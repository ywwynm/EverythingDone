## 修复视频附件点击闪退（根因：FileProvider 路径未覆盖）

上一版点击视频仍会闪退。崩溃日志定位到真正原因：崩溃发生在生成视频分享地址那一步（`FileProvider.getUriForFile`），而不是调起播放器那一步，所以之前的兜底没拦住。

原因：部分视频附件记录的是相册原始路径（如 `DCIM/Camera/VID....mp4`），不在应用此前配置的可分享目录内，导致生成地址时直接抛异常闪退。

本次修复：

- 扩展应用的文件分享配置，覆盖整个外部存储，相册等公共目录下的视频也能正常生成分享地址、调起外部播放器。
- 同时给整个调起流程加了兜底：万一路径仍无法处理（如某些 U 盘/SD 卡）或手机上没有可播放视频的应用，会提示“没有可播放该视频的应用”，不再闪退。

验证：点击之前会闪退的那个视频，确认能正常调起播放器播放；再随便点几个不同来源的视频确认都不闪退。

（HDR 全屏显示在上一版已验证正常，本版未改动 HDR 相关代码。）

## 卓易通 HDR 对照测试与日志导出（2026-10-16）

针对同一原图在华为系统图库有 HDR 高光、在卓易通里的完事儿切换 HDR 没有差异的问题，增加仅 debug 包可见的诊断页。本次提供对照和证据采集，尚未确认卓易通的 HDR 输出修复方案。

入口为“设置 → 高级设置 → HDR 对照测试与日志”，也可在全屏看图时长按 HDR 标识，直接带入当前原图。支持内置已知增益测试图及系统选图；内置图三行 SDR 基图相同，增益分别为 1、2、4 倍。图片只用于本机测试，不随日志导出。

提供七种方式：ImageView SDR 基图、运行时请求 HDR 的 ImageView、与现有查看器相同的 Glide + PhotoView 加载方式、创建窗口时请求 HDR，以及独立 Surface 的 scRGB FP16、BT.2020 PQ 10 位和 SDR 8 位输出。支持自动或请求 2／4／8 倍亮度余量；独立 Surface 的“自动”按 4 倍重建增益，PQ 参考白固定为 203 nit，均明确记为探针假设。缺少扩展、配置不符或不支持的 gainmap 格式会记录失败，不静默改成 SDR。

每次切换记录系统与显示能力、HDR／SDR 比例是否可用、窗口请求、硬件加速、亮度及电源状态、图片 SHA-256 与 gainmap 元数据、实际 EGL 通道位数和色彩空间、错误堆栈。可点“明显提亮／没有变化／异常或黑屏”并填写卓易通版本等备注。日志持续落盘，退出后重新进入仍可导出。

直接提供“分享日志文件”“保存到下载”“另存为”三种 TXT 导出方式；下载目录为 Download/EverythingDone/HDR。日志不含原图及记事内容。HDR 能力、窗口请求或 EGL 提交成功均不等于屏幕已经提亮，最终需要记录肉眼观感。

实现位于 debug 专用的 HdrDiagnosticsActivity、HdrProbeImage、HdrProbeSurface 与 HdrDiagnosticJournal；正式版只有入口空实现。现有查看器的 HDR 显示策略保持不变。

本地 assembleDebug 与 7 项专项 JVM 测试通过，实际探针 GLSL 的 5 组桌面离屏 GPU 数值检查通过。发布使用独立工作树，不混入主工作区其他未提交功能；基线文件树与当前主工作区已提交的 17c5567c4 相同。未使用 ADB、未安装设备、未提交 Git；卓易通及文件分享界面的实际表现由用户测试。

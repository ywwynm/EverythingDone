## 修复卓易通 HDR 动态照片收尾和返回闪烁（2026-10-16）

用户反馈上一版仍有 SDR 到 HDR 等待，动态照片结束可能先提亮、黑屏再重新过渡，返回时也有黑屏和亮度变化。本次结合用户录屏与指定设备的真实查看器流程修正。

- 动态照片播放期间保留同一 PQ 输出层，并在视频下方准备好 SDR 静图；播放结束或长按松手后直接在该层恢复 HDR，减少撤层、重建和重复过渡。播放中切换 HDR、自动播放接管为长按及强制 SDR 收尾均已覆盖。
- 返回和暂停时保留最后一帧，等窗口停止显示后再释放 PQ Surface，避免退出动画尚未结束就撤层。旧播放器的迟到回调只处理对应实例。
- 180 毫秒增益过渡改由 EGL 渲染线程推进，首帧同步后不再等待主线程动画启动；保持现有 PQ 编码、亮度与 APP5 重建曲线。指定设备样本的 PQ 就绪至首个增益帧为 10—50 毫秒，这不包括图片读取与物理屏幕响应。
- 保留 HDR 对照页和日志文件导出，增加数据准备、主线程排队、首个／完整增益帧、动态播放交接及窗口冻结事件，便于继续分析卓易通的剩余等待。
- 指定 OPPO 设备通过 22 项查看器回归、10 项生命周期检查、主线程忙碌回归、24 次普通及 36 次快速反向切换；31 项 HDR JVM 测试通过。约 15.5 秒的回归录屏共 630 帧，中心图片区域未检出全黑帧。普通 Android 仍走原 HDR 路径，缩放、平移、GIF、视频及原图保持原逻辑；卓易通实际观感请继续复测。

## HDR 图片显示（全屏预览）+ 视频播放闪退修复

新增：在全屏图片预览里支持显示 HDR 图片。

- 打开带 gain map 的 HDR 照片时，自动以 HDR 提亮显示（需 Android 14 及以上、且屏幕支持 HDR；旧系统或普通屏幕会正常显示标准动态范围的画面，不受影响）。
- HDR 图片右上角会出现一个 “HDR” 徽标：实心白底表示正在以 HDR 显示，点一下可临时切回标准动态范围（变成描边样式），再点一下切回 HDR。翻到下一张或退出后恢复默认。
- 多张图片左右滑动时，HDR 只在当前这张 HDR 图上生效，翻到普通图片会自动取消提亮，避免界面其余部分变暗。

修复：点击视频附件调用外部播放器时可能闪退的问题。

- 统一用通用的视频类型调起播放器，避免某些格式（如 .mov）拼出非法类型导致找不到应用。
- 找不到可播放的应用时，改为提示“没有可播放该视频的应用”，不再闪退。

说明：记事列表、文件夹缩略图、详情页内嵌的小图、裁切界面、桌面小组件均保持标准动态范围显示，本次不改动；这是平台与设计上的取舍。

验证重点：找一张 HDR 照片（手机相机拍的 UltraHDR、或相册里标了 HDR 的图）导入记事，进入全屏预览，确认画面提亮、徽标出现且点击可切换；再点一个视频确认能正常调起播放器、不闪退。

## 修复 PQ HDR 大图与动态照片交接时的明暗闪烁

用户反馈卓易通在动态照片结束、大图加载完成时闪烁后显示 HDR，要求检查固定延时；随后澄清零增益静图逐步恢复 HDR 本身正常，要解决的是明暗反复或动静切换闪烁。

检查确认现有 180 ms 是同层增益动画，8 ms 是后续帧调度，5 秒是失败回退，不是到时强制揭示。Android 真实 200MP 大图及慢 PQ 准备的“重庆”动态照片复现了完整原图先显示、切至 PQ 零增益帧突然变暗、再恢复的交接；系统录屏确认该亮暗反复。正常播放结束的单调增益恢复继续保留，没有把它作为故障。

HdrViewerController 的首帧保护不再依赖进度条是否仍可见。ImageViewerActivity 在完整图替换小预览前保留独立副本，等待实际 PQ 画面就绪后平滑交接；没有新增到时强制揭示。视频准备期间保持静图亮度，真实视频画面显示后才降低下层增益。正常动态收尾及手动 HDR 开关继续原有 180 ms 渐变。临时预览覆盖回退、超时、关闭以及冻结后恢复的释放路径。

三台指定设备共 2317 项有效检查通过，使用真实 200MP 大图和“重庆”两张 HDR 动态照片，覆盖正常／慢准备、播放结束、长按、开关、缩放、返回、大视频起播、GIF、动态 WebP、超时与 SDR 回退；24 组边缘像素对照、12 组播放快照对照通过。JVM 1732 项无失败／错误、3 项既有跳过。

原有 672 条记事和真实附件保持。完整位图像素、尺寸、色彩空间、Gainmap 和 HDR 重建参数一致；PQ 纹理沿用原有可用内存预算，尺寸可能随运行状态变化，实际显示清晰度要求全部通过。没有修改 HDR 公式、203 nit 参考白或纹理预算。Android 回归确认应用侧交接，卓易通宿主的物理亮度观感仍需现场确认。

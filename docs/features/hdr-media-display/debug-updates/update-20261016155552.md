## APP5 附加图接入 HDR 对照页，发布实验重建版本（2026-10-16）

用户确认现有 PQ Surface 对内置图及 Android 能识别的 HDR 照片颜色正确且提亮，扫描优化后速度明显改善。本次按要求继续处理前两张华为 Pura 70 Ultra 的 APP5 照片，仅在 HDR 对照测试页提供实验适配，保留诊断日志导出，正式查看器策略不变。

两张文件的 APP5 同时包含 ITUT35 标识、附加 JPEG 偏移和 32 字节参数块。新增 HdrApp5.kt 校验已确认的双图布局、相对／绝对偏移、JPEG 结束边界、参数长度与尺寸关系；不再因为 Android hasGainmap=false 就阻断这类照片的独立 Surface。未知布局、损坏数据及不匹配的几何关系仍明确拒绝，保留 SDR 图片和原因日志。新拍的 APP8＋ISO 21496-1 照片继续优先使用原生 Gainmap 路径。

新增 HdrApp5Preview.kt，在内存中提取并缩小解码真实附加图，排除 ICC／EXIF 对增强数值的误处理，使用单通道灰度并按主图方向对齐。HdrProbeImage 将该纹理送入原有色彩转换、GLSL 与 PQ Surface，不修改原图，不给原生 Bitmap 伪造 Gainmap。模式 1—4 保持原生解码对照，模式 7 只显示 SDR 基图。

重要边界：目前没有取得可核验的完整 APP5 厂商重建曲线。本版是明确标注的实验重建，采用“线性主图 × 所选参考余量^(灰度/255)”；余量可选 2／4／8 倍，自动按原测试页的 4 倍。八个私有参数字只记录、不当作已确认的增益参数使用。提亮成功不代表已经精确还原华为图库，高光、颜色、暗部一致性仍需对照，不能将本版视为完成了全部 HDR Vivid 支持。

新增日志 IMAGE_APP5_ADAPTER，以及容器偏移、图像尺寸、参数字、解码耗时、灰度范围／直方图、所选余量、公式和未校准状态；原有 EGL 调用与提交日志仍在，分享 TXT、保存到下载、另存为均保留。日志不包含原图、完整 EXIF、GPS 或完整 URI。

验证：assembleDebug 和 26 项 JVM 测试通过，包括两张原图实际回放与去元数据后的独立摘要交叉核对、第三张标准 ISO 容器排除、损坏及未知版本拒绝、偏移迁移、旋转映射和扫描回归。15 组实际着色器离屏 GPU 数值检查通过，只验证实现的参考公式，不替代卓易通显示实测。没有连接或操作设备。

建议测试：分别选择前两张原图，在模式 6（PQ）先用 2 倍，再比较 4／8 倍，与模式 7 和华为图库对照高光、颜色、暗部；记录观感后直接导出 TXT。最后用新拍的成功 HDR 照片确认标准路径仍正常。

# Motion Photo 播放 · 全屏交互精修（徽标 / 触感 / 缩放）

## 本次更新

全屏预览按你的反馈精修三处：

- **"实况"徽标改到顶部**：移到左上角、与 HDR 按钮**同一高度**，并**整体放大**（图标 + 字号都更大），不再是角落里的两个小字。
- **长按有触感**：按住开始播放实况时，会有一次**振动反馈**（跟随系统触感设置）。
- **保留缩放、消除拉伸闪烁**：放大照片后按住播放，**不再有拉伸/闪烁的瞬间**；播放时视频就在放大后的位置播放；**松手后照片保持你放大的状态**，不再缩回原始大小。

## 请重点测试（OPPO + 三星）

1. 打开一张动态照片全屏 → 徽标是否在**左上角、和 HDR 徽标同排**、是否够大。
2. **放大**照片 → 按住播放：起播是否**没有拉伸/闪烁**；视频是否在放大位置播放；**松手后是否仍保持放大**。
3. 按住起播的一瞬间是否有**振动**。
4. 播放中捏合是否还有"背后另一层图"（应已无）。
5. 点一下切换沉浸模式时，徽标是否随 HDR 徽标一起隐藏/显示。
6. 封面 / 详情动效、上一版详情崩溃修复仍正常。

## 技术记录

- 缩放丢失/闪烁根因：上一版用 `photoView.isZoomable = false` 锁定缩放，但 PhotoView 的 `setZoomable(false)` 会 `update()` **把显示矩阵重置回适配大小**——导致起播拉伸、松手后缩放丢失。
- 修复：不再改 `isZoomable`；播放时把下层 PhotoView 设为 `INVISIBLE`（矩阵不变→缩放保留、且消除双层），停止时恢复 `VISIBLE`；`tab_image_attachment` 根 `FrameLayout` 加黑底承接 letterbox。
- 消除视频层拉伸：`onPrepared` 里先按 `player.videoWidth/Height` 套好 `setTransform`（映射到起播时捕获的 `displayRect`），**再**把 TextureView `alpha` 置 1，避免"先铺满再吸附"。
- 徽标改为活动级 `tv_live_badge`（`activity_image_viewer.xml`，`top|start` + `applyTopInsetAsMargin`，与 HDR 同排），按当前页 + 播放态 + 系统 UI 可见性统一在 `updateLiveBadge()` 刷新；图标 `ic_live_badge` 放大到 18dp、字号 14sp。
- 触感：长按识别即 `mVpImage.performHapticFeedback(HapticFeedbackConstants.LONG_PRESS)`。

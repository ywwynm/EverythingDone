# Motion Photo 播放 · 实况徽标图标与胶囊微调

## 本次更新

只调整全屏"实况"徽标的外观：

- **图标改版**：最外面一圈改成**虚线圈**（更接近常见的"实况"标识），内部保留中心实心点 + 中间实心环。
- **胶囊排布**：图标贴在胶囊最左侧，**图标的左、上、下间距一致**；文字右侧间距与图标左侧间距相同；文字与胶囊都按内容自适应宽度。

行为不变（打开自动播一遍、长按循环、无缝起播、播放时徽标保持显示等）。

## 请看一下

- 图标外圈是否为虚线、整体是否清晰。
- 胶囊里图标四周留白是否均匀、文字右侧与图标左侧留白是否一致。

## 技术记录

- `ic_live_badge.xml`：外圈虚线用 12 段短弧（每段 18°、间隔 12°，半径 8.3，`strokeLineCap=round`）近似 `stroke-dasharray`（VectorDrawable 不支持原生虚线）；中间实心环半径 5、中心点半径 2.3。
- `activity_image_viewer.xml` 的 `ll_live_badge`：四边 `padding` 统一为 5dp（icon 左=上=下=5dp、文字右=icon 左=5dp），icon 20dp，文字与 icon 间距 5dp，均 `wrap_content`。

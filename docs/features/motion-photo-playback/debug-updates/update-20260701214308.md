# Motion Photo 播放 · 全屏顶部两徽标 y 方向居中对齐

## 本次更新

- **全屏顶部 HDR 与 实况 徽标 y 方向居中对齐**：之前两者顶边对齐，但高度不同（实况胶囊比 HDR 卡片高约 6dp），视觉上没有垂直居中。现在改为在同一水平线上垂直居中对齐，与各自高度无关。

## 请重点测试（OPPO + 三星）

1. 打开一张既是 HDR 又是实况的照片，全屏顶部左（HDR）、右（实况）两个徽标是否在 y 方向居中对齐（水平中线一致）。
2. 只有其中一个存在时（仅 HDR 或仅实况），位置是否仍正常（左上 / 右上、与顶栏间距不变）。

## 技术记录

- 根因：两徽标 `layout_marginTop` 同为 64dp、`layout_gravity` 为 `top|start`/`top|end`，是顶边对齐；实况胶囊(padding 5dp + 16dp 图标 ≈26dp) 高于 HDR 卡片(padding 3dp + 文字 ≈20dp)，顶边对齐必然导致垂直中心差约 3dp。
- 改法：把两者包进同一横条容器 `fl_top_badges`（`match_parent`×`wrap_content`，`layout_gravity=top`），HDR 用 `start|center_vertical`、实况用 `end|center_vertical`，以容器高度(取较高者)为参照各自垂直居中。原左右 `marginStart/End 16dp` 改为容器 `paddingStart/End`；`marginTop 64dp` 与顶部 inset 统一加到容器（`applyTopInsetAsMargin` 由分别作用两个徽标改为对容器一次）。

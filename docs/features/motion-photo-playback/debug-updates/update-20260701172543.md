# Motion Photo 播放 · 第 2 版（封面/详情动起来 + 全屏三处修复）

在第 1 版（全屏按住播放）基础上，修掉你反馈的三处全屏问题，并把**卡片封面**与**详情附件列表**接上派生 GIF、真正动起来。

## 全屏三处修复（据 OPPO 反馈）

1. **徽标改良**：从"两个裸字"改成**同心圆图标 + 半透明药丸**（更接近大厂实况标识）。
2. **保留缩放**：放大照片后按住播放，视频现在会**在放大后的同一位置/同一缩放**下播放，不再缩回原大小。
3. **消除双层**：播放期间锁定下层静图缩放，修复"播放中再捏合会看到背后另一层图在缩放"的问题。

## 封面 + 详情（新）

- **卡片封面**：动态照片在**开启封面自动播放（Cover Autoplay）**时，封面会循环播放由内嵌视频派生的 GIF（复用视频封面那套管线）；关闭自动播放则停在静态主图。缩略图与"媒体背景"两种封面模式都支持。
- **详情附件列表**：进入记事详情，动态照片缩略图**无条件自动播放**（先显示静图、派生就绪后换成动图），定制裁切下也会逐帧套用裁切。
- 首次显示需要后台"检测→抠出内嵌视频→生成 GIF"，所以**第一次会先看到静图、过一会儿才动**；生成一次后缓存，之后直接动。

## 请重点测试（OPPO + 三星）

1. **全屏**：徽标是否好看了；放大后按住播放是否跟着放大；播放中捏合是否还有双层。
2. **封面**：把动态照片设为记事封面，开启封面自动播放 → 首页卡片是否会动；关闭自动播放 → 是否停在静图。
3. **详情**：进详情，动态照片缩略图是否自动播放；有裁切时裁切是否正确。
4. **性能**：塞若干动态照片的列表滚动是否顺畅（派生首次有后台开销）。
5. 普通照片、GIF、视频封面、HDR 全屏是否一切照旧。

## 已知边界

- 封面/详情**首次**需后台生成 GIF，会先静后动；派生 GIF 为 256 色，画质弱于全屏真播放（设计如此）。
- 封面/详情暂未加"实况"小徽标（动画本身即示意）；如需可加。
- VIVO 仍按静态图；API 26/27 无法解码 HEIC。
- 抠出的内嵌视频有 512MB 缓存上限，超出按最久未用清理。

# Motion Photo 播放 · 自动播放不被触摸打断 + HDR 徽标 ripple/镂空

## 本次更新

- **自动播放不再被触摸打断**：打开或翻到实况照片时的自动播放（自动演示一遍），现在点击屏幕、缩放松手等任何触摸都不会打断它，会自然播完。只有**长按按住播放**时才是"松手即停、回到静图"。
- **全屏 HDR 徽标加点按 ripple + 选中态镂空**：
  - 点按 HDR 徽标切换 HDR/SDR 时有水波纹反馈。
  - **未选中（强制 SDR）**：半透明深色底 + 白描边 + 白字，ripple 偏白。
  - **选中（HDR 生效）**：白底 + **透明镂空文字**（"HDR"处透出背后照片），ripple 偏黑。

## 请重点测试（OPPO + 三星）

1. 打开实况照片自动播放时，点一下屏幕、或用两指缩放后松手——自动播放是否**继续播完不中断**。
2. 长按按住播放时，松手是否仍立即停止、回到静图（并保留缩放）。
3. 点按全屏左上角 HDR 徽标：是否有 ripple；未选中时 ripple 偏白、选中时 ripple 偏黑；选中态是否为白底 + 镂空透明文字（能透出照片）。

## 技术记录

- 停止契约（decisions.md D9）：`startMotionPlayback` 记 `mMotionHoldToPlay = loop`（长按=true、自动=false）；`dispatchTouchEvent` 仅在 `mMotionHoldToPlay` 为真时对 `ACTION_UP/CANCEL` 调 `stopMotionPlayback`，自动播放由 `OnCompletionListener` 收尾。
- HDR 徽标：新增 `views.HdrBadgeView`（`Canvas.saveLayer` + `PorterDuff.CLEAR` 镂空，保留硬件加速使 ripple 走 RenderThread 顺滑）。选中态白底镂空、未选中态深底白字白描边；ripple 由 `foreground` 承载、随选中态切换（`ripple_hdr_badge_on/off.xml`，带圆角 mask 裁到药丸形状）。`ImageViewerActivity.updateHdrBadge` 改调 `setBoostOn`，`tv_hdr_badge` 由 `TextView` 换成 `HdrBadgeView`。

# Motion Photo 播放 · 全屏体验再打磨（自动播放 / 无缝起播 / 徽标）

## 本次更新

全屏预览按你的反馈继续打磨：

- **打开即自动播一遍**：全屏打开一张动态照片（或翻页翻到）时，**自动播放一遍实况**（带振动），播完自动回到静态。
- **无缝起播，消除拉伸/闪烁**：改为**等视频首帧真正渲染出来的一刻**才从照片切到实况，不再有起播时的闪烁或上下拉伸；放大后播放、以及"缩回原始比例再播放"也不再出现瞬间拉伸。
- **"实况"徽标重做**：
  - 加了**胶囊描边**（半透明黑底 + 细白边框）。
  - **图标更大**、图标与文字**垂直居中**（不再偏下）。
  - 高度与右侧 HDR 徽标一致、位于左上角同排。
- **播放时徽标不再隐藏**：播放实况过程中，左上角"实况"徽标保持显示。
- 长按播放仍在（循环播放、松手回静态，带振动）。

## 请重点测试（OPPO + 三星）

1. **打开/翻页**：进到动态照片是否**自动播一遍**、有振动、播完回静态。
2. **无缝起播**：长按播放、以及放大后播放，起播是否**不再闪烁/拉伸**；"停止→缩回原比例→再长按播放"是否也不再拉伸。
3. **徽标**：胶囊描边是否好看；图标是否够大且与文字垂直居中；高度是否与 HDR 徽标齐平；播放中是否仍显示。
4. 放大后播放：视频是否在放大位置、松手是否保持放大。
5. 封面 / 详情动效、之前的详情崩溃修复仍正常。

## 技术记录

- 起播闪烁/拉伸根因：此前在 `onPrepared`（首帧尚未渲染）就把 TextureView `alpha` 置 1，导致显示到"无帧/未套变换"的一瞬。改为：`onPrepared` 里先 `setDefaultBufferSize` + `applyTextureAspect` + `start()` 但**不揭示**；在 `OnInfoListener` 收到 `MEDIA_INFO_VIDEO_RENDERING_START`（首帧已渲染）时才 `revealMotionSurface()`（置 `alpha=1` + 静图 `INVISIBLE`）；另加 180ms `postDelayed` 兜底防个别机型不发该事件。
- 自动播放：`startMotionPlayback` 加 `loop` 参数；自动播放 `loop=false` + `OnCompletionListener → stopMotionPlayback`；长按 `loop=true`。触感移入 `startMotionPlayback`（两条路径都给）。`maybeAutoplayCurrentMotionPage()` 在检测完成（当前页）与翻页时触发。
- 徽标：`activity_image_viewer.xml` 的 `tv_live_badge`（TextView+compound drawable，文字偏下）改为 `ll_live_badge`（LinearLayout：ImageView 20dp + TextView，`gravity=center_vertical`、`includeFontPadding=false`），`bg_live_badge` 加 `stroke`。`updateLiveBadge()` 去掉"播放时隐藏"。

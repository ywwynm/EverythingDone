# Motion Photo 播放 · 播放实况时支持缩放、视频跟随

## 本次更新

全屏预览播放实况照片时：

- **播放中也能缩放了**：无论是打开自动播放、还是长按播放，播放过程中都可以双指缩放/平移，视频会**跟着一起缩放/平移**。
- **缩放结果会保留**：播放结束后，照片保持你在播放中缩放/平移到的状态，不再出现"播完原图被莫名缩放/放大"的问题。

## 请重点测试（OPPO + 三星）

1. 打开一张实况照片（自动播放时）双指缩放 → 视频是否跟着缩放；播完是否停在你缩放后的状态。
2. 长按播放时，另一只手缩放 → 视频是否跟着缩放；松手后是否保留该缩放。
3. 放大后再长按播放 → 是否从当前放大状态无缝开始播放。

## 技术记录

- 之前播放时把下层 PhotoView 设为 `INVISIBLE`，导致：自动播放时触摸不到 PhotoView（不能缩放）、长按时缩放作用在隐藏的静图且视频不跟随（播完静图被改）。
- 改为：**播放期间保持 PhotoView 可见可触**（不再 `INVISIBLE`），并 `setOnMatrixChangeListener` 监听其显示矩阵，实时把视频 `setTransform` 到当前 `displayRect`（`applyTextureAspect`）。视频层在 PhotoView 之上、但 TextureView 不消费触摸，缩放手势落到下层 PhotoView，再经监听驱动视频跟随。停止时移除该监听；PhotoView 矩阵由用户缩放决定、我们不再重置，故缩放结果自然保留。

# Motion Photo 播放 · 详情网格 HDR/GIF 标识调小

## 本次更新

- **详情附件网格里 HDR / GIF 标识调小**：之前它们比同排的"实况"标识偏大，现在字号从 10sp 调到 8.5sp，整体高度降到约 16dp，与"实况" icon 齐平，宽度也随之收窄，一排三个标识更协调。

## 技术记录

- `KnockoutTextBadge`（详情网格 HDR/GIF 用）文字大小硬编码由 10sp 改为 8.5sp；配合原垂直 padding 3dp，测得高度 ≈16dp，与同排 `iv_badge_live`（16dp icon）齐平。全屏 HDR 徽标用的是另一个类 `HdrBadgeView`，不受影响。

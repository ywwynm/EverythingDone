# Motion Photo 播放 · 修起播拉伸 + 网格标识换序换样式

## 本次更新

- **修复打开时画面瞬间上下拉伸**：全屏打开实况照片自动播放时，偶尔那一下拉伸没有了。
- **详情网格媒体标识换序换样式**：
  - 顺序从左到右改为 **HDR、GIF、实况**。
  - HDR、GIF 改成**偏白的半透明底 + 镂空透明文字**（文字处透出背后照片），不再是深底白字。
  - 实况仍是半透明的图标。

## 请看一下

- 打开实况照片时是否还有起播的瞬间拉伸。
- 网格标识顺序是否为 HDR / GIF / 实况；HDR、GIF 的白底镂空字观感是否符合预期（文字能透出照片）。

## 技术记录

- 起播拉伸：之前"基准变换"在揭示（首帧）时才 `setTransform`，与 `alpha=1` 未必同帧生效，导致一帧显示未变换（铺满=拉伸）的画面。改为在 `onPrepared`（首帧之前、`alpha` 仍 0）就 `setupMotionBaseTransform` 套好基准变换，揭示时只置 `alpha=1`。
- 镂空标识：新增自定义 `views.KnockoutTextBadge`（软件层 + `PorterDuff.CLEAR` 把文字掏成透明，露出照片；偏白半透明圆角底，`android:text` 取文案）。`attachment_image.xml` 三个标识重排为 HDR/GIF/实况，HDR、GIF 用该自定义 View；`ImageAttachmentAdapter` 的 `tvBadgeHdr`/`tvBadgeGif` 引用类型改为 `View?`。

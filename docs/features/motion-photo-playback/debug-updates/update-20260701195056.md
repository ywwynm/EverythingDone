# Motion Photo 播放 · 详情附件网格加实况/HDR/GIF 标识 + 按钮留边

## 本次更新

记事详情的图片/视频附件网格：

- **左下角新增媒体标识**：动态照片显示"实况"图标、HDR 图片显示"HDR"、GIF 显示"GIF"；同时满足多个就一起显示（例如又是实况又是 HDR）。
- **右下角两个按钮（调整外观、删除）留出间距**：之前按钮触摸区正好贴着图片的下边和右边，现在向内留了一点点间距。
- **左下角标识与右下角两个按钮在垂直方向居中对齐**。

## 请看一下

- 各类图片的标识是否正确出现（实况 / HDR / GIF，可叠加）。
- 右下角按钮是否与图片边缘留出间距；左下角标识是否与右下角按钮上下居中对齐。
- HDR 标识：只在 Android 14+（API 34+）设备上、且图片确实带增益图时显示。

## 技术记录

- 新增 `HdrImageDetector`：API 34+ 时降采样解码（目标长边 384）取 `Bitmap.hasGainmap()`，按文件签名缓存；更低版本一律非 HDR。
- `ImageAttachmentAdapter`：`ImageViewHolder` 加 `ll_media_badges` 容器 + `iv_badge_live`/`tv_badge_hdr`/`tv_badge_gif`；`updateMediaBadges()` 中 GIF 同步（扩展名）、实况用 `MotionPhotoDetector`、HDR 用 `HdrImageDetector`，后台检测经 `postBadgeUpdate` 守卫回收后回填；容器按是否有任一标识显隐。
- `attachment_image.xml`：徽标容器 `bottom|start` 高 40dp、`center_vertical`、`marginStart/marginBottom=3dp`，与 `iv_delete`/`iv_edit_appearance`（新增 `marginEnd/marginBottom=3dp`）同高对齐。

# Motion Photo 播放 · 封面/详情动效 + 全屏改进 + 崩溃修复

## 本次更新

动态照片（Motion Photo / 实况照片）支持大幅推进 —— 现在这些地方都能动，并修掉了一处闪退：

**能动的地方（新）**
- **卡片封面**：开启"封面自动播放"时，动态照片封面循环播放（缩略图、媒体背景两种模式都支持）；关闭则停在静态主图。
- **详情附件列表**：进入记事详情，动态照片缩略图自动播放；有裁切时逐帧套用裁切。
- **全屏预览**：按住画面播放内嵌视频，松手回到静图（第 1 版已有）。
- 说明：封面/详情**首次**需后台"检测→抠出内嵌视频→生成 GIF"，会**先看到静图、过一会儿才动**；生成一次后缓存，之后直接动。

**全屏三处改进（据上一版 OPPO 反馈）**
- "实况"徽标从两个裸字改为**同心圆图标 + 半透明药丸**，更像大厂样式。
- **放大照片后按住播放**，视频会跟着放大、在原位置播放，不再缩回原大小。
- 修复**播放中再捏合缩放会出现"背后另一层图"**的问题。

**崩溃修复**
- 修复：在详情页动态照片的动图**生成完成时、如果已经退出该页面**，可能触发的闪退（`You cannot start a load for a destroyed activity`）。

## 请重点测试（OPPO + 三星）

1. **详情崩溃复现**：进一个含动态照片的记事详情，**在缩略图还没开始动时立刻退出**，反复几次，确认不再闪退。
2. **封面**：把动态照片设为封面，开"封面自动播放" → 首页卡片会动否；关闭 → 停静图否。
3. **详情**：动态照片缩略图自动播放否；裁切对否。
4. **全屏**：徽标是否好看；放大后按住是否跟着放大；播放中捏合是否还有双层。
5. **性能**：塞多张动态照片的列表滚动是否顺畅（首次有后台生成开销）。
6. 普通照片 / GIF / 视频封面 / HDR 全屏是否一切照旧。

## 已知边界

- 封面/详情**首次**先静后动（后台生成）；派生 GIF 为 256 色，画质弱于全屏真播放（设计如此）。
- 封面/详情暂未加"实况"小徽标（动画本身即示意）。
- VIVO 仍按静态图导入；API 26/27 无法解码 HEIC。
- 抠出的内嵌视频有 512MB 缓存上限。

## 技术记录

- 崩溃根因：`ImageAttachmentAdapter.loadDetailMotionGif` 的异步回调在 Activity 销毁后仍 `Glide.with(context)`。修复：新增 `isImageViewUsable`（检查 `isAttachedToWindow` + Activity 未 destroyed/finishing），回调前与方法入口双重守卫。封面路径用预取的 `mImageRequestManager`（lifecycle 安全），无此问题。
- 封面/详情动效：新增 `MotionPhotoCoverHelper`——内嵌视频抠到确定性缓存文件（mtime=源图 mtime，稳定 GIF 缓存 key；512MB LRU），喂现有 `VideoCoverPreviewManager` 派生 GIF；`BaseThingsAdapter` 两条封面路径 + `ImageAttachmentAdapter` 详情各加分支。
- 发布日志格式提醒：`publishDebugUpdate` 只嵌入文件**第一个 `## ` 段**，故完整用户可见改动须全部写在第一段（本次已改正）。

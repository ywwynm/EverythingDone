# Motion Photo 播放 · 第 1 版（全屏按住播放）

本次为 Motion Photo（动态照片 / 实况照片）支持的**第一条竖切**，目的是先在真机上验证最核心、风险最高的两件事：**能否检测出你的照片是动态照片**、**能否正确播放其内嵌视频**。范围只覆盖全屏预览，卡片封面与详情列表下一版再做。

## 这版有什么

- 新增 Motion Photo 检测器：扫描文件内嵌 MP4 的 `ftyp` 头并用系统解码器校验，厂商无关（面向 OPPO / 三星，JPEG 与 HEIC）。
- 导入保真：图片按裸字节拷贝、不重新编码，内嵌视频不被破坏；HEIC 现在保留 `.heic/.heif` 扩展名。
- **全屏预览按住播放**：全屏打开一张动态照片时，左下角显示"实况"徽标；**按住画面即播放**内嵌视频（循环、带声音），松手回到静态图。若该照片是 HDR，静态态照常按 HDR 显示。

## 请重点测试

1. 用 OPPO、三星各拍几张动态照片，导入记事，进入**全屏预览**。
2. 看是否出现"实况"徽标（出现＝检测成功）。
3. **按住画面**是否开始播放、松手是否停下并回到静图。
4. HEIC 动态照片（若三星开了高效格式）是否也能识别与播放。
5. 普通照片是否一切照旧（无徽标、无异常）。

## 已知边界（本版）

- 卡片封面、详情列表**暂不会动**（下一版接入"视频→GIF"派生管线）。
- VIVO 动态照片按静态图导入，不支持动态（设计如此）。
- API 26/27 设备无法解码 HEIC（系统限制）。
- 全屏 TextureView 表面在极少数机型上可能需要照片完全加载后才可用；若首次按住没反应，请松开再按一次并反馈。

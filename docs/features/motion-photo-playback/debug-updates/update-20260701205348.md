## 技术记录

- 双图根因：视频“基准区域”取自静图 `displayRect`，而自动播放触发早，可能在静图尚未加载好时取到空/错的 rect → 视频铺到错误位置、与随后加载的静图错位成两张。
- 修法：**基准区域改为“视频在整个 TextureView 内 fit-center”**（仅依赖视频尺寸与视图尺寸，不依赖 `displayRect`，无时序问题）；`setTransform` 在 `onPrepared`（首帧前）套好；再用 View 属性（`trackMotionZoom`）把该基准同步/跟随到静图当前 `displayRect`（矩阵监听驱动，含首帧后的立即同步）。移除了旧的 `applyMotionBaseTransform`。
- 徽标对调：`activity_image_viewer.xml` 中 `tv_hdr_badge` 改 `top|start`+`marginStart`，`ll_live_badge` 改 `top|end`+`marginEnd`。

# Motion Photo 播放 · 播放中缩放跟随优化为顺滑

## 本次更新

- **播放实况照片时的缩放/平移更顺滑了**：修掉了之前"自动播放时缩放卡卡的"（长按播放时同理，只是不易察觉）。缩放跟随的原理不变（视频仍跟着照片缩放/平移，播完保留缩放），只是实现更省。

## 请重点测试（OPPO + 三星）

1. 自动播放实况时双指缩放/平移，是否明显更顺滑、无卡顿。
2. 长按播放时缩放/平移，是否顺滑；视频与画面是否始终同步、无错位/漂移。
3. 播完后照片是否仍停在缩放后的状态。

## 技术记录

- 之前在 PhotoView 每次矩阵变化（一次捏合几十上百次）都 `new Matrix()` + `TextureView.setTransform()`——后者较重、且高频调用与视频解码争抢，导致卡顿。
- 改为：**基准变换只 setTransform 一次**（首帧 `revealMotionSurface` 时，把视频铺到当时的静图显示区域 `mMotionBaseRect`）；之后 PhotoView 矩阵变化只调 `trackMotionZoom`，用 TextureView 的 **View 属性**（`pivotX/Y`、`scaleX/scaleY`、`translationX/Y`，走 RenderThread、零分配）把基准区域精确映射到当前显示区域。视频尺寸变化时才重设一次基准（`applyMotionBaseTransform`）。停止时复位这些 View 属性并 `setTransform` 恢复。
- 数学：以 `base.left/top` 为 pivot、`s = rect.w/base.w` 缩放、平移 `rect.left-base.left`，等价于把 `base` 映射到 `rect`（与原逐帧 setTransform 结果一致）。

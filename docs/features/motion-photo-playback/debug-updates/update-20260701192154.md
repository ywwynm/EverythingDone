## 技术记录

- `ic_live_badge.xml`：外圈虚线 24 段短弧（每段 8°、间隔 7°，共 15°×24=360°），半径 11.4（配 1.1 描边 + 圆角端，外缘 ~11.95 < 12 不裁切），使内容铺满 24×24 viewport、`drawable` 自身无内边距；中间实心环半径 6、中心点半径 2.8。
- 胶囊 `ll_live_badge` 保持四边 5dp 统一 padding；图标 `ImageView` 20dp，因图形已铺满 viewport，其可见左缘≈贴 paddingStart，故与文字右侧 5dp 对齐。

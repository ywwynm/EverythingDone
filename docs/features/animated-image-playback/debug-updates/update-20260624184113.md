# 动图播放:GIF / 动态 WebP 在更多界面自动播放

让动图(GIF、动态 WebP)在更多界面真正逐帧播放,不再只有详情页默认模式会动。

## 本次改动

- **全屏预览**:打开 GIF / 动态 WebP 现在自动循环播放(普通 JPEG/HEIC 的 HDR 行为不变)。
- **详情页定制裁切的 GIF**:既按你设的裁切显示,也会播放(此前设了裁切就变静止)。
- **首页 / 文件夹 / 正在做 / 提醒卡片**:GIF 封面(缩略图、侧栏、卡片背景)按设定裁切并播放。
- **裁切弹窗**:保持显示第一帧(选裁切框用,不播放)。
- **记事 widget 配置页预览**:保持静态——因为放到桌面的真实 widget 本身无法播放动画,预览与之保持一致。
- 视频缩略图不变,仍是静态取帧。

## 测试重点

- 全屏预览 GIF 是否流畅播放;切页、缩放是否正常。
- 带 GIF 封面的卡片:裁切是否正确、是否播放。
- 滚动一个塞满 GIF 封面的列表,留意流畅度(如有明显掉帧请反馈,会再加滚动时暂停)。
- widget 配置页预览里的 GIF 应为静止。

# 决策记录 / 空间视频效果

## D1：建模为应用内动态呈现能力（2026-07-31）

用户确认未来的“空间视频”不是新的媒体文件，而是动态媒体在 EverythingDone 内获得的一项呈现能力，
领域术语为 **Spatial Video Effect**。

- 支持对象预期包含 Animated Image、Motion Photo，普通视频是否同批纳入后续确认；
- 原文件、附件类型和时间线保持不变；
- 播放过程中用户可以通过设备姿态或触摸改变视点；
- 深度和遮挡必须跨帧稳定，不能逐帧独立生成互不相关的空间照片效果；
- 不包含 Apple Spatial Video 或其它空间媒体导出。

该能力尚未进入实现，不创建 ADR。

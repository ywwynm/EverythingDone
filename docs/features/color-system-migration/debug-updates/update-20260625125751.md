## 修复根目录上下文操作栏在 accent 渐变下前景仍为黑

- 上一版漏改了 refreshContextualToolbarForeground：长按选中后菜单项变化会触发它，而它在根目录（无文件夹背景、用 accent+accent2 渐变）时把前景硬编码成黑色，覆盖了原本正确的白色前景。
- 现在它与上下文操作栏其它前景逻辑统一：根目录用 accent 渐变并按深色背景处理，标题、关闭 / 溢出 / 菜单图标统一走白色。

测试重点：
- 在根目录长按一条记事进入选择模式：上方操作栏的标题、关闭按钮、各操作图标应为白色（之前是黑色）。
- 进入某个有自定义背景的文件夹后再长按：操作栏前景仍按该文件夹背景自适应，与之前一致。

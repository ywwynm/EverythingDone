# accent 渐变背景统一配白色前景

## accent 渐变背景统一配白色前景

- 当记事/文件夹/强调元素的背景是 App 默认强调渐变（accent + accent2）时，之前因为它的代表色（两端取平均）亮度恰好略高于阈值，会被判成浅色背景而配深色前景；现在统一识别这个渐变，直接配白色前景。
- 覆盖首页卡片、文件夹卡片、抽屉与筛选条选中态、上下文操作栏、详情页、记事卡片外观弹窗，以及桌面 widget 等所有"根据背景自适应前景明暗"的地方。
- 仅影响 accent + accent2 这一个渐变；其它纯色/渐变背景的前景明暗判断不变。

测试重点：
- 把某条记事/文件夹背景设成默认强调渐变（accent 橙红 → accent2 橙黄），确认其上标题、内容、图标、状态等前景变成白色、清晰可读。
- 选中态（首页状态条、类型筛选）、长按后的上下文操作栏在强调渐变下前景为白。
- 详情页若记事背景是强调渐变，标题、菜单图标、状态栏图标为白。
- 其它颜色背景（纯色、非 accent 渐变）的前景明暗与之前一致，没有变化。

## 点音频附件卡片，进入带水波动画的播放界面

- 详情页点音频附件**卡片本身**，现在会打开一个新的播放对话框：录音界面那套 FableSol 水体铺满全屏，上方是文件名、计时器和进度滑杆，下方是「上一曲 / 播放暂停 / 下一曲」。
- 拖动滑杆可以跳到音频的任意位置；当前这条播完，会按附件的排列顺序自动接着播下一条，播到最后一条为止。
- 水波用的是和录音时**完全相同的实时分析**，只是声音来自正在播放的文件而不是麦克风；喂给分析器的采样点按已经播出的位置对齐，画面和声音是同一个时钟。
- 卡片**右侧的播放/暂停按钮**行为不变，仍是原来的就地播放。两者不会同时出声：打开对话框会先停掉就地播放。
- 对话框离开前台会自动暂停，回来后由你决定是否继续。

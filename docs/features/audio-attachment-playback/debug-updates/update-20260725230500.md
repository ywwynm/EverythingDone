## 音频播放对话框：修掉两个播放卡住的问题，配色调淡

- 修复：在**快播完的时候暂停、再点播放**，有时会播不完、播放/暂停键一直停在「暂停」图标，得反复点才能继续。原因是收尾时死等音频硬件报告"全部放完"，而末尾不足一个缓冲的残帧未必会被计入。
- 修复：**拖进度条到结尾再点播放**只闪一下就回到播放图标，要再点一次才从头播。现在已经在结尾时按播放键就直接从头重放当前这条。
- 底部三个按钮的**触摸涟漪**不再用记事颜色，改为按记事颜色的明暗自适应为偏黑或偏白，压在水面上更清楚。
- **进度条未播的那段**调淡了，之前压在水体上偏深。其它界面的滑杆不受影响。

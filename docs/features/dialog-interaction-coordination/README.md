## 本轮范围与设计约束

- 按先分析、后实施的顺序完成；原因是输入分发与界面切换缺少共同约束，涟漪只负责绘制。
- 优先寻找公共入口的统一控制方式，避免只为详情页两个按钮各加一份限制。
- 区分重复打开、同层不同弹窗竞争与正常的父子弹窗／弹窗切换。

实现统一普通控件的多指分发策略，并按 Activity／窗口来源同步受理界面切换；弹窗、页面跳转、菜单和页内面板的开启过渡共用规则。弹窗真实窗口透明或提前关闭时，保护持续到粒子动画完成。保留正常多指手势、父子界面和顺序切换，不设置固定点击冷却时间。

入口约定与边界见 [decisions.md](decisions.md)，原始设备结果见 `validation/`。

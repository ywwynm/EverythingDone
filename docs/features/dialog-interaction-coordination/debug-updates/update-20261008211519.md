# Debug 更新日志

## 2026-10-08：统一处理连续点击与多指触摸引发的重复窗口

- 修复记事详情页在 dialog 粒子动画开启时连续点击“添加附件”可能叠加多个弹窗的问题。
- 修复同时触摸“添加附件”和“改变颜色”、或设置页“计时数字风格”和“粒子动画设置”时，同时打开多个界面的情况。
- 在公共输入分发、弹窗、菜单和页面跳转入口统一处理竞争请求；首页外观面板的开启过渡也接入控制。没有给每个按钮单独设置时间冷却，保留现有涟漪效果。
- 弹窗出现透明期和消散动画尾段继续保护下层输入；正常父子弹窗、关闭后打开下一窗口、弹窗内跳转及图片双指缩放继续可用。
- 修正颜色编辑器重复请求时覆盖会话字段、外部结果早于 onResume、配置重建复用 DecorView 时无障碍状态未还原等边界。
- 核心实现位于 UiTransitionState、UiInteractions、UiInteractionActivity、BaseDialogFragment 与 PopupPicker；新增 debug 合并回归及状态单元测试。

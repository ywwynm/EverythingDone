# 调研：有没有比 Big-LaMa 更好、又能上手机的补全模型（2026-08-12）

前提是 D195 的结论：**我们这条管线里补全的成败由"带离真实像素有多远"决定**，
实测中位 10.8–16.8px。这是**小掩膜、上下文基本唯一确定**的工况，不是论文榜单常用的
20–60% 大掩膜工况。所以选型必须看**小掩膜那一档**的数，看总榜会选错。

## 一、小掩膜这一档，LaMa 已经很接近天花板

[SEM-Net](https://arxiv.org/abs/2411.06318)（WACV 2025）是目前公开对比里在小掩膜档
明确胜过 LaMa 的一个，Places2 256²：

| 掩膜比例 | SEM-Net PSNR / FID / LPIPS | LaMa PSNR / FID / LPIPS |
|---|---|---|
| **0.01–20%（我们这一档）** | **33.01 / 14.52 / 0.0328** | 32.47 / 14.73 / 0.0354 |
| 20–40% | 25.42 / 22.78 / 0.1054 | 25.09 / 22.94 / 0.1079 |
| 40–60% | 20.83 / 25.70 / 0.2120 | 20.68 / 25.94 / 0.2124 |

**小掩膜档只领先 0.54 dB PSNR、FID 0.21。** 代价：163M 参数、256² 推理 **240ms**，
而 LaMa 是 25ms（论文自报）——**慢 10×，换 0.5 dB**。且论文不声称可上移动端。

> 这条数直接回答了问题的前半：**换更新的模型，在我们这一档买到的提升是零点几 dB 量级。**
> 与 D195 一致——瓶颈不在模型强弱。

## 二、移动端这条线：MI-GAN 与 RETHINED

| | 参数量 | 分辨率与延迟 | 质量（RETHINED 论文同表） | 权重/许可 |
|---|---|---|---|---|
| Big-LaMa（现用） | ~51M（fp32 ONNX 208MB） | 512² 分块，桌面 CPU | 基线 | 已在管线里 |
| [MI-GAN](https://github.com/Picsart-AI-Research/MI-GAN)（ICCV 2023，Picsart） | RETHINED 称其为自身的 8× | Snapdragon 888 实测 **686ms**（另有 3905ms@2048² 的报数） | LPIPS 0.056 / FID 21.93 @2048² | **官方给了 ONNX 导出**；许可未核实 |
| [RETHINED](https://arxiv.org/abs/2503.14757)（WACV 2025 Oral） | **4.3M** | iPad Pro M2：**17.6ms@1024² / 34.3ms@2048² / 39.4ms@4096²**；另测 iPhone XS、Snapdragon 888、Jetson Nano | **LPIPS 0.031 / FID 12.5 @2048²** | **未核实**：项目页无仓库链接，论文写"接收后发布" |

RETHINED 的结构值得单独说：**轻量 CNN 出结构 + NeuralPatchMatch 做分辨率无关的块替换
+ 注意力上采样补高频**。这与本项目自己摸出来的方向撞上了——D189 的相干传输（结构延续）
与 D191 的真实块搬运，正是"CNN 出结构 + 块替换出纹理"这套组合。**一个独立团队从移动端
延迟约束出发，得到了和我们从条带成因出发一样的架构。**

## 三、看过但不适合的

- [CAML](https://github.com/zhenglab/CAML)：2026 年那篇[综述](https://www.mdpi.com/2073-8994/18/1/94)
  称它在中/大掩膜档总体最好，但那不是我们的工况；参数量与许可未核实。
- **PixelHacker**：扩散式，质量高但与移动端无关。
- **TransCNN-HAE**：3M 参数 / 20 GFLOPs，综述里点名的参数效率标杆，值得单独查。
- **Moebius**（现在管线里的激进档）：0.22B，[arXiv 2606.19195](https://arxiv.org/abs/2606.19195)，
  桌面质量强，但本日实测在**窄掩膜**工况下输给 Big-LaMa（00 场景缝 10.3 vs 7.3），
  与 D195 一致；且 0.22B 扩散不可能上端。

## 四、结论与建议

1. **不要为了质量换模型。** 我们这一档的天花板离 LaMa 只有零点几 dB，而实测的杠杆
   （掩膜怎么开）能改变 45%（00 场景缝 13.4 → 7.3）。
2. **要换模型的真实理由是端上部署，不是质量。** Big-LaMa 的 fp32 ONNX 208MB、
   512² 分块，端上不现实；RETHINED 那一档是 4.3M / 数十毫秒。
3. **RETHINED 是首选目标，但有一个必须先查的阻断项**：权重与代码是否真的发布、
   什么许可。项目页没有仓库链接，本轮没查到。**在这条查清之前不要排期。**
4. **MI-GAN 是今天唯一确定拿得到 ONNX 的移动端候选**，但质量低于 LaMa
   （FID 21.93 vs RETHINED 12.5 @2048²），只适合当"端上兜底"，不适合当质量档。
5. 若 RETHINED 拿不到，**自建同构方案**是可行的：本项目已经有相干传输（D189）与
   真实块搬运（D191）两块，缺的是把它们做成一个轻量网络——而按 D195，
   在窄掩膜工况下这套非学习的组合本来就与回归模型同量级。

## 五、本轮没有核实的（不得当成结论）

- RETHINED 的权重/代码/许可；论文里未给与 **LaMa** 的直接对比（只与 CoordFill、MI-GAN 比）。
- MI-GAN 仓库的 LICENSE 原文（GitHub 本轮取不到）。
- CAML、TransCNN-HAE 的参数量与许可。

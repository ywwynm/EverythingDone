# 空间照片效果

状态：端侧生成、按需模型／Runtime、签名 catalog、持久派生、查看器交互和设置管理均已实现。
当前主路径为 schema 13 的 vNext11 自适应多尺度连续深度运动场：分割、matting 与补图只承担
拓扑、边缘和隐藏背景职责，不再把语义实例直接变成运动纸片；默认目标约 `36 px@720`，最大目标
约 `48 px@720`，困难场景由逐图几何门禁自然限幅。2026-08-07 已在 Galaxy S23 Ultra 上完成
单人、双人、室内、办公、交通、插画六类素材的默认／最大强度共 12 段连续真机轨迹复核。

早期 P0/P1、LDI-lite、MPI、ownership 刚性分层和局部相似 chart 等路线仍保留在历史决策、测试与
兼容读取代码中，但已由真机动态门禁证伪或退出当前生成主路径。当前版本获得用户“至少回到了有空间
效果的版本”的阶段性确认；这不是最终画质验收，单目大视差下的局部形变与隐藏内容生成仍受信息上限
约束。Spatial Video Effect 仅完成领域与后续方案记录，尚未实现。

## 目标

让用户把一个普通图片附件转换为 EverythingDone 内可交互的 **空间照片效果（Spatial Photo Effect）**：
应用在手机本地估计图片的相对深度，并在查看时根据触摸或设备姿态移动虚拟视点，呈现有限幅度的
2.5D 视差。

原图片仍是原来的图片附件，不被重编码、替换或改造成新的媒体类型。

## 已确认边界

- 图片内容的分析、深度估计与渲染全部在手机上完成，不上传图片。
- 目标是应用内视觉与交互效果，不要求导出 Apple Spatial Photo、双目 HEIC、SBS 图片或其它空间媒体文件。
- 这不是 Motion Photo：前者从静态图派生深度视差，后者播放图片文件内已有的短视频成分。
- 单张图片只能推断相对深度，因此结果是 2.5D 视觉效果，不宣称恢复了真实三维场景。
- 用户生成一次后，在本机持久保存可重建的派生深度与参数，后续查看无需重新推理；派生数据不替换原图，也不参与同步。
- 效果只在全屏图片查看器中由用户主动进入；详情附件网格与普通全屏查看默认仍显示原图。
- 空间模式同时支持设备姿态与单指拖动：进入后锁定当前附件，拖动时由手指接管视点；退出后恢复普通查看手势。没有姿态传感器时仍可只靠触摸使用。
- 设置提供默认开启的全局“设备倾斜控制”；关闭后不注册姿态传感器，只保留单指拖动，不影响任何
  已生成结果。
- v1 只支持普通静态图片；Animated Image 与 Motion Photo 暂不生成空间照片效果。
- HDR 静态图片可以生成，但 v1 的空间模式显示 SDR 基础画面；退出后原图恢复既有 HDR 显示。
- ONNX Runtime 不进入基础 APK；首次需要推理时只下载当前设备 ABI 的裁剪组件。ZipDepth 与
  Depth Anything V2 Small 作为两个可独立下载的深度模型，MI-GAN 与 AOT-GAN 作为两个可独立
  下载的隐藏背景模型；设置可以分别保留并选择当前组合。
- 双模型支持是 v1 发布验收条件；任一模型在转换、许可、Android 运行或安全资源门槛上失败时，必须
  暂停并带证据重新决策，不静默缩减为单模型。
- 首次无模型时显示选择界面，默认推荐 ZipDepth 但不静默下载；两个模型由 EverythingDone 的阿里云
  服务器分发，不让 App 直接依赖外部模型站点。
- 模型 catalog 独立于 APK 的 debug/release 渠道；两种构建默认使用同一稳定 catalog，debug 仅在
  显式配置时切换到 staging。
- stable/staging catalog 分别由独立 Ed25519 密钥签名；release 只信任 stable 公钥。App 先验证
  catalog 签名，再信任其中的模型 URL、大小、SHA-256 与兼容性声明。
- 模型兼容性按本机、按模型判断；一个不可用时仍可使用另一个，两个都不可用时明确提示。功能不以
  云端计算或可能导致崩溃、长时间卡顿的强制 CPU 路径回退。
- 图片生成是全屏查看器内的前台可取消任务；离开即取消并清理临时文件，成功后才原子保存并自动进入
  空间模式。
- 模型下载可在后台继续、跨网络中断或 App 重启恢复，并可从设置或通知取消；离开查看器后下载完成
  只标记模型就绪，不在后台处理附件图片。
- 模型可通过移动网络下载，但计费网络或流量节省模式下必须再次显示准确大小并取得确认，绝不静默
  使用移动流量。
- 模型更新只提示并由用户主动下载；新版本校验成功后原子替换旧包，不重新生成已有空间效果。
- 完整生成物是本机持久的 Spatial Photo Derivative，不受普通缓存 LRU 淘汰；每张源图片最多一份，
  可按图片移除或在设置中全部清除。
- v1 空间模式固定适应屏幕，不缩放、不平移、不翻页；退出后普通查看态继续提供原有高分辨率缩放。
- 空间模式中第一次系统返回只退出效果并回到同一图片的普通全屏状态；再次返回才离开查看器。
- 已有 Spatial Photo Derivative 的图片在详情附件网格显示纯图形 Spatial Effect Badge；不显示文字，
  不改变缩略图仍先进入普通全屏查看的行为。
- 普通全屏查看器的透明顶部工具栏提供独立空间效果图标：未生成时进入准备/生成流程，已生成时进入
  空间模式；图标随现有查看器 chrome 一起显隐，不放入更多菜单。
- 空间模式中该图标呈激活态，再次点击即可回到普通全屏查看；左上角导航箭头仍直接返回 Thing 详情，
  系统返回则先退出空间模式。
- v1 不提供深度画笔、蒙版或局部修正编辑器；不满意时可调节空间强度、即时切换 P0 单层/P1 双层、
  换深度或隐藏背景模型重新生成，或移除效果。
- v1 不因截图、文字、镜面或复杂边缘等软质量判断禁止生成；风险较高时降低默认强度，只有确定的技术
  失败才中止。
- 切换或删除模型包不改变已有空间效果；只有新生成或用户主动“重新生成”时才使用当前模型，并为
  每张图片原子替换其唯一一份派生结果。
- 每张图片拥有独立保存的 Spatial Effect Strength：生成时给出保守默认值，用户可在安全范围内实时
  调整，不重新运行深度模型。
- 空间模式的强度控件是与查看器 chrome 同步显隐的底部紧凑滑杆；拖动时实时预览，松手保存，且不
  与画面上的单指视点拖动争抢触摸。
- schema v2 同时保存 P0 所需原始深度和 P1 LDI-lite 数据；P0/P1 切换保持同一视点和强度、按图片
  持久化，不重新推理。两条路径都限制连续表面形变，P1 的预算忽略显式断边以保留遮挡视差。
- AOT-GAN 提供 512/768/1024 三档工作长边，默认 768；选择不静默降档。更高分辨率不保证每张图
  都比 MI-GAN 更好，因此两种补图模型按不同结果先验呈现，不标成绝对质量等级。
- 用户不倾斜或拖动时画面保持静止；首次进入仅显示一次操作提示，不自动循环移动虚拟相机。

## 当前实现与实测

- stable catalog 已使用离线 Ed25519 私钥签名并发布到 EverythingDone 的阿里云模型目录；模型与
  Runtime 使用版本化不可变路径，ZipDepth、DAV2 Small、MI-GAN、AOT-GAN 及 ORT 的许可文件随
  对象保存。catalog `20260731103557` 已完成公网逐字节回读、验签与新对象哈希复核。
- 两台授权设备均已通过 App 设置页、签名 catalog、HTTP Range 下载、字节数/SHA-256 校验、完整
  ONNX 初始化自检，并同时保留两个可切换模型。
- OnePlus 已用 ZipDepth 与 DAV2 Small 分别完成真实照片生成；Samsung 已用 DAV2 Small 完成真实
  照片生成。派生结果在重新安装 debug APK 后仍可直接打开，不重复推理。
- 已验证前台取消不会发布正式或 `.pending` 派生文件，系统返回只退出空间模式，强度调整会按图片
  持久化，单指拖动可改变视点。
- 折叠屏大屏任务栏与直板机手势导航均通过底部 system-bar inset 验证，强度条不会被系统导航控件
  遮挡。
- 阿里云 debug 更新 `202607311044` 的远端 `latest.json` 与本地元数据逐字节一致；公网回下载
  APK 为 20,995,401 字节，SHA-256 为
  `eb79991da1daa518ba346b9929620ee84f35163ec8b34823a38d24542fe1fb96`。APK v2 签名有效，且不含
  深度模型、补图模型或 ONNX Runtime 原生库。本轮按用户安排不连接设备；此前双机纵向链路实测
  结论仍保留，新加入的 AOT-GAN 与 P0/P1 切换由用户继续真机验证。

用户希望后续把动态内容扩展为逐帧、跨帧一致的 **Spatial Video Effect**；该方向是独立后续能力，
只在应用内交互呈现，不导出空间视频文件。见
[空间视频效果](../spatial-video-effect/README.md)。

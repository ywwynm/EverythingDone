# 路线审视：空间照片方案全面复盘（2026-08-04）

触发：用户判定"形变仍显著；改进与新问题并存；机制叠加过多"，要求从头审视，
不排除重写。本文档 = 我的第一性分析；三份 Opus 网络调研（工业实现/学术原理/
端侧工程）完成后合成最终路线建议。

## 一、现状全景：一条路线上叠了多少互相制衡的机制

生成期（每次生成顺序执行）：
深度模型(518) → percentile 归一化(2%/98% 拉满 [0,1]) → 锐边闭运算 → 600 网格
上采样 → 引导滤波(糊边模型)/跳过(锐边模型 D53) → 边缘吸附(D47) → P3 组引导
中位数修正 → 深度比 1.2 + 实例归组的断边双门控(D56/P2) → 小岛愈合 → D76
实例残差软限幅(膝 0.09/斜 0.24) → 正则化(逐边应变 ≤0.18) → 背景深度扩展 +
带端渐坡(D51) → 窄带补全足迹(D70/D74) → MI-GAN → ownership alpha 羽化(D54)。

渲染期：连续网格 + 断边 splat + 背景层；UV 平移 shift=amp×(d−0.5)；恒定取景
边距(P1)；形变预算钳制(0.36)；relief 明暗；实例标签已退出渲染(P2)。

交互：陀螺仪 → tanh 软饱和(28°) → 单位圆视点。

**制衡关系直陈**：percentile 归一化把物体内部深度差拉大（形变源头）→ D55 曾
全局压回(0.72) → 退役后靠 D76 实例限幅压 → 预算钳制再兜底 → 正则化又限逐边
应变。四层机制在同一根轴上互相拉扯，每次调整幅度都要重新平衡全部四层——
这就是"太多的事情"的结构性原因。

## 二（修订）、第一性假设的桌面反证（2026-08-04 实测）

原假设"percentile 归一化破坏比例"被测量推翻：归一化是仿射映射，差值比例
完全保真（test1 上 主体内部差/主体-墙间隔 = raw 1.77 vs 归一化 1.75）。
结论修正：
- **形变的真实来源** = ①单目相对深度在近景物体内部的层次夸大（模型属性，
  换信号域治不了）+ ②纯横向平移路径把深度差直接线性兑换成长度变化；
- D76 只限实例组；**场景组（桌面/地面/墙）未限幅**，其 ~11% 延展极可能就是
  用户仍看到的"显著形变"主体；
- 候选 A（raw 逆深度仿射）**作废**——数学上与现状等价。

由此路线问题聚焦为两个正交轴：**深度信号的物体内保真度**（模型/后处理）与
**相机路径的形变感知**（横移剪切 vs 推拉缩放 vs 真透视）。

## 二（原文存档）、形变的第一性归因

真实相机平移下，物体两端的视差差 = 基线 × (1/z₁ − 1/z₂)。真实世界里人体
前后跨度相对观看距离很小（2m 外的人，前后 0.3m → 1/z 差 ≈ 0.065 m⁻¹），而
人-墙的 1/z 差大（≈ 0.3 m⁻¹）——**物体形状天然稳定、层间视差天然大，二者
本来不冲突**。

我们的管线在第一步就破坏了这个比例：percentile 归一化把整个场景的逆深度
非线性拉满 [0,1]，物体内部的微小 1/z 差被放大成归一化域的大跨度（DA3 上
人脸内部梯度是 DAV2 的 2.6 倍、主体-背景间隔 0.87——这些"分布形态问题"
全是拉满归一化的产物）。此后的 D55/D76/预算/正则化都是在给这个被破坏的
比例打补丁。

**候选根治 A（信号修正）**：位移信号直接用 raw 逆深度的仿射映射（robust
去离群但不逐场景拉满；amplitude 语义 = 虚拟基线）。比例保真 → 形状稳定与
层间大视差同时成立，理论上可退役 D76、预算大部、D55 残留语义。前提：模型
的相对深度在场景内近似仿射正确（DA3 这类模型的训练目标即如此）。已有
rawInverse 全链传递，改动集中在"渲染幅度消费哪个场"。

**候选根治 B（投影模型升级）**：深度反投影 → 真 3D 网格 + 透视虚拟相机。
小平移下与 A 的一阶近似等价；额外收益是支持推拉/环绕等相机路径（工业界
掩盖形变的另一手段）与几何正确的透视缩短。工程量大于 A。

**候选 C（表示升级/重写）**：预渲染多视角 bake、或生成期前馈 3DGS + 端侧
泼溅渲染——是否值得重写，取决于调研结论（质量上限、端侧成熟度）。

## 三、已被验证有效、应保留的资产（无论路线怎么变）

- 深度比遮挡判据（尺度不变，D56）与实例先验（P2 归组、P3 边界修正）
- 生成期窄带补全 + 可信隔离（D70/D74）；黑缝/白伪影清零即其功劳
- 剪影 alpha 羽化（D54）；恒定取景 + 软饱和交互（P1）
- 模型资产与分发链（深度/分割/matting/补全 + r6 运行时 + 签名 catalog）

## 四、待调研合成的关键问题

1. 工业界的视差幅度量级与相机路径设计（掩盖 vs 根治）
2. 真 3D 投影 vs 屏幕空间平移的感知差异证据
3. 分层刚性（少量层）vs 连续网格的取舍
4. 端侧 3DGS/bake 的成熟度与包体成本

# 合成：路线建议（三份 Opus 调研 + 本地审视，2026-08-04）

三路调研（research-2026-08-04/ 下三份报告）与本地分析高度收敛：

## 五条收敛结论

1. **幅度纪律**：工业界横向视差硬预算 = 画宽 2-4%（ISU 1/30；阿凡达 ±1%；
   转制 50-80px/2K；Meta 越界淡出）。我们当前 12%，超限 3-4 倍——形变显著的
   第一原因。工业界不进入这个区间，"范围感"靠推拉路径与逐图优化，不靠大横移。
2. **我们的限幅栈本身是形变源**（学术报告数学证明）：应变上界/全局预算/实例
   残差限幅让位移不再是视差的同一全局仿射函数 = 画面各部分各配一台不同基线
   的相机 → 物体跨视角改变长度/相对大小。P/S 比与幅度无关 = 旋钮全是折中的
   定量原因。
3. **结构解 = 实例内视差低阶化**：把实例内视差投影到平面/二次面（λ 自适应
   收缩）——低阶场必然对应刚性表面，形变必然是合法透视前缩。删限幅 + 低阶化
   同时成立。验收用 (P, NR) 指标（层间行程 vs 相似变换对齐残差）。
4. **纯平移下真 3D ≡ 屏幕空间**（数学等价）；真 3D 的价值只在解锁推拉/旋转。
   推拉几乎不产生显露区且对深度误差宽容——"空间感"的第二维度，径向项
   (u−c_x)·g·ρ 屏幕空间即可先行。
5. **表示终点 = 2-4 层软分层**（SLIDE 软可见度 A=exp(−β‖∇ρ‖²) 替代硬断边，
   兼救发丝）；烘层不烘视角；补全先改条件（层坐标系内、排除前景上下文）再
   考虑 LaMa；端侧 3DGS 渲染已证明但前馈未就绪（SHARP 许可待核）。

## 分阶段建议

**阶段一「做减法」（保守，1-2 周）**——不改表示：
- 删：全局形变预算钳制、D76 实例残差限幅、D55 字段残留（regularize 保留为
  断边漏检兜底，评估后定去留）；
- 增：实例内视差低阶化（平面→二次面，λ 按残差方差自适应）、SLIDE 软可见度、
  推拉径向分量（倾斜映射 = 横移 + 推拉混合）；
- 改：幅度回锚 ~3% 画宽（约 0.03-0.04），补全余量与幅度绑定；
- 验收：(P,NR) 曲线 + 五图交叉 + 真机驻留画圆。
预期：形变根治（合法化）、"范围感"由推拉与层间行程共同提供、机制净数量减少。

**阶段二（中等，4-8 周）**：2-4 层软分层 LDI + 真透视相机 + 运动包络烘焙 +
补全条件改造（可选 LaMa）+ 越界淡出。性价比最高的终点形态（Meta OSP 同构）。

**不建议现在做**：端侧前馈 3DGS（先零成本验证：SHARP 许可核查 + 桌面产
splat 用 WebView 看观感）。

**要不要从头重写？** 不需要整体重写：渲染内核（网格+断边+背景层+生成期烘焙
补全）与工业界已验证形态同构，模型资产/分发链全部复用。需要"重写"的是形变
治理哲学——从"限幅补偿"换成"低阶几何 + 软分层 + 路径设计"，净代码量下降。

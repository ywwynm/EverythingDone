## Big-LaMa（NPU 版）下载时会显示进度了

之前这一行在下载过程中只显示「下载中…」，不像其它模型那样报百分比。任务本身一直在
发送已下载的字节数，只是这一行没有去读。现在与其它模型行一致：

`等待下载` → `下载中 N%` → `正在校验…` → `正在安装空间计算组件…` → `已安装`

顺带修掉两处相关的问题：

- **校验和解包期间会一直停在「下载中 100%」**。这两步在 104 MB 的产物上各要两三秒，
  之前被一律当成下载阶段上报，看着像卡住了。现在分别显示「正在校验」「正在安装」。
- **原地升级时整个下载过程显示「已安装」**。这一行与其它模型行不同——预编译产物会在
  模型不升版的情况下被换掉，升级时旧的还在，按其它行的判断顺序会一路显示已安装。
  现在下载中优先。

### 说明

只改了设置界面这一行的状态显示，模型和 catalog 都没动。上一版下载过的不用重下。

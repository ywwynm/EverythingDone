## Big-LaMa（NPU 版）那一行的三处修补

紧接上一版（`202608150837`）。这一版只改设置页里 NPU 那两行的显示与交互，
NPU 功能本身、模型分发、判定逻辑都没有动。

### 未下载时，圆圈不再发淡

Big-LaMa（NPU 版）没下载的时候，左边那个圆圈比旁边 MI-GAN、AOT-GAN 明显浅一档。
这是上一轮统一「置灰只表达真的不可用」时漏改的一行——"还没下载"由右侧的状态文字和
下载按钮说清楚就够了，圆圈再淡一次是同一件事说三遍。现在它和其它未下载的模型同色。

顺带把这两行的圆圈也改成了纯显示（点击交给整行处理），跟本页其它所有模型行一致。
之前直接点圆圈会先自己勾上、再被刷回去，闪一下。

### 下载中的取消图标不再发淡

点了下载之后，右边的图标会变成取消的叉。但那个叉是淡灰色的——判断"这个按钮可不可用"
时把"正在下载"当成了不可用，于是正在进行的操作反而看着像被禁用了。现在与本页其它行
一致：下载中的取消图标是正常颜色。

### 取消按钮真的能取消了

更实的一个：那个取消叉**按下去没有任何反应**。这一行的按钮只写了"下载"这一支，
按下去是把同一个任务再排一次队，而任务是唯一的，等于什么都没发生。现在补上了取消
分支，按一下会真的停掉下载并回到"未下载"。

### 为什么连着几版都在修这一行

这三处都不是新写出来的问题，而是前几轮统一设置页显示规矩时，只改了 CPU 那几组模型，
NPU 这两行漏下了；之后每次又只按报上来的那一个点修。这次改成把整页所有同类控件
列出来逐个比对，NPU 这一行在四项上都是唯一的例外，已经全部对齐。

### 这次要试的

1. 在 Big-LaMa（NPU 版）**未下载**的状态下，看左边圆圈和 MI-GAN、AOT-GAN 是不是同色。
2. 点下载，看右边的取消叉颜色正常；再按一下取消，应当真的停下并回到"未下载"。
3. 再点下载让它装完，圆圈应当可以点选，选中后 Big-LaMa（CPU 版）自动取消选中。

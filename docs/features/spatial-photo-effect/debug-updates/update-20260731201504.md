## 空间照片效果：修复 AOT-GAN 无法安装与生成被锁死，统一界面风格

修复了隐藏背景模型 AOT-GAN 下载后提示「下载失败：…FusedConv…」且无法再生成空间效果的问题。根因是按需下载的裁剪计算组件缺少推理会话在高优化级别下动态生成的算子内核，四个模型都可能受影响；本版把所有模型推理改为不依赖该行为的安全级别，已在 OnePlus 真机完成四个模型（ZipDepth、Depth Anything V2 Small、MI-GAN、AOT-GAN）的下载自检与完整生成验证。同时不再因为补图模型不可用而完全禁止生成：此时会弹出选择对话框，可以立即「仅生成单层」（P0）效果，待补图模型就绪后重新生成即可升级为双层（P1）；重新生成会明示双层结果将被替换的情形。模型下载的「自检未通过」与真正的「下载失败」现在分开提示，不再混为一谈。空间效果相关的全部界面改为与应用一致的风格：确认与选择对话框使用应用的强调色对话框组件，生成失败改为对话框展示完整原因，空间照片设置页重做为与主设置页一致的卡片分组布局（渐变顶栏、分组图标、强调色按钮与选择控件），全屏查看器内的强度条按钮与取消按钮同步调整。

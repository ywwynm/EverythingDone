## 生成时会告诉你哪一步真的在用 NPU

### 不再靠耗时猜测

之前开了「骁龙 NPU 加速」，生成过程里只会显示「正在进行深度估计」，到底走没走 NPU 看不出来。
现在走了 NPU 的那一步会直接写明，例如「正在进行深度估计（NPU 加速中）」。

这个标注来自建立推理会话的那一刻，不是读设置项。也就是说：如果某个模型因为没装 NPU 版、
或者运行组件没就位而回落到 CPU，那一步就不会有这个后缀——它反映的是实际发生的事，
不是设置里勾了什么。

### 设置页里的估计值全部删掉

「约 45MB」「约 20-50 秒」「九场景实测」这类数字都去掉了。它们是在某台机器、某几张图上
测出来的，却被写成了普适说明，换台设备就对不上。留下的是与设备无关的描述，比如
Big-LaMa 写「构建连续性最好，同时也是体积最大的模型」，DAV2 写「推理更慢，内存占用明显更高」。

「深度细节」下方的说明也重写了：它设定的是 MoGe-2 的内部推理分辨率，决定深度不连续处的
边界锐度与可分辨的几何细节上限，档位越高推理耗时随之上升。

### 其它语言的文案补齐了

空间照片相关的文案此前只有简体中文和英文是全的。这一版补齐了全部 12 个语言：
繁体中文（香港、台湾）按各自惯用词转写，德语、西班牙语、法语、印地语、意大利语、
日语、韩语、葡萄牙语、俄语逐条翻译。型号名（MoGe-2、Big-LaMa、RF-DETR 等）保持原文。

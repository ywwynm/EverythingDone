# 空间照片 vNext 深度几何基线

## 本轮目标与更新内容

用户要求重新从根因审视空间照片路线，不能继续依靠曲面畸变、语义纸片或降低视差来掩盖
人物、文字和细结构形变；新方案还必须保留清晰的前后景相对视差、遮挡显露和连续二维
环绕效果。

**主要变更**

- 冻结旧 `ldi-lite-v19-segmentation-prior` 核心，新增 schema v3 与 renderer
  `surface-charts-vnext1`；旧 v19 派生仍可读取，不会在打开附件时静默迁移。
- 新增 `SpatialVNextGeometryBuilder`：几何只由深度证据建立，使用旋转／转置等变去噪、
  遮挡断边、宽过渡单 ridge 和 connected chart；RF-DETR、EdgeTAM、实例分组与
  ownership 不再改写深度或控制运动拓扑。
- 每个 chart 保留平均深度与低频立体变化，同时把最大视点下的局部 Jacobian 扰动限制为
  4%；chart 之间的深度差不压缩，最高仍可保留 0.12 视差预算。合成回归同时要求硬台阶
  前后景相对视差不低于 0.08，防止通过压平画面换取稳定。
- 新增持久化 16 方向 `SpatialViewEnvelope` 契约；运行时连续插值安全幅度，不再消费 v19
  的全图 `0.36` warp budget。
- vNext 参考视点使用零 cover margin，不再固定裁掉约 15% 取景；背景网格延伸到照片画框
  外，中心视点关闭 matting 显露，避免补图或 alpha 软化参考图。
- MODNet 只细化深度几何已经确认的遮挡边。matting 窄带由固定 4 格改为按网格长边缩放：
  v19 的 600 长边仍为 4 格，vNext 的 256 长边为 2 格，避免边缘软化宽度放大约 2.3 倍。
- 传感器低通改为根据事件时间戳和 65 ms 时间常数计算，统一不同采样率设备的响应；二维
  视点不包含 z/dolly 缩放。
- 设置页将 RF-DETR 与 EdgeTAM 标为 vNext 不再使用的旧组件，不再允许新下载或选择；
  已安装文件仍可删除，进行中的旧下载仍可取消，不会自动删除用户数据。

**验证**

- `:app:testDebugUnitTest`：通过。
- `:app:assembleDebug`：通过。
- 永久测试覆盖硬深度台阶、连续斜坡、宽过渡、孤立尖峰、转置等变、4% 局部形变门槛、
  空间感下限、视点包络插值、时间常数滤波和 v2/v3 renderer/schema 隔离。
- 本轮未连接、安装或操作物理设备；视觉质量需用户在真机上验证。

**测试提示与当前边界**

- 已有附件若保存了 v19 派生，会继续显示旧效果。请在图片查看器中执行“重新生成空间效果”
  后再测试 vNext；同一附件重新生成会原子覆盖旧派生。
- 当前是 vNext 第一阶段基线，仍复用 connected surface + boundary splat 光栅器；adaptive
  textured surfel/2D Gaussian、真正的画框外生成式补全、逐方向隐藏区质量搜索和大规模
  held-out corpus 尚未完成，不能视为最终 Apple 级方案。

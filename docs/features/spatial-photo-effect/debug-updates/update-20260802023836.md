# 关系约束 ownership 与 EdgeTAM 可选轮廓细化

本次继续从空间表示和对象边界的根因提升质量，不增加全屏曲面形变，也不让生成模型重绘
原画主体。RF-DETR 继续确定实例身份；新增物理关系解析与 EdgeTAM 可选边界细化，目标是
同时减少同一装配体错层、人物内部扭曲、脸部孔洞和轮廓锯齿。

## 主要变化

- 修正 RF-DETR 分类 ABI：slot 0 是 COCO 稀疏类别保留位，slot 1..90 都是有效前景，
  没有独立 no-object logit。后处理不再误丢 slot 90，并有回归测试固定契约。
- 新增 attachment relation resolver。人与人始终保持独立；只有明确的穿戴、手持、身体部件
  或骑乘类别，同时满足接触、相对面积、深度邻近和空间布局证据时，才并入对应人物父层。
  仅在二维轮廓上偶然相接的前景物体继续独立，避免以单张测试图阈值过拟合。
- 增加 EdgeTAM 可选边界细化器。它不发现实例，也不替代 RF-DETR，而是让 RF-DETR 每个
  box 触发一次 decoder；image encoder 每张图只运行一次。
- EdgeTAM 只能在 RF 轮廓四个 mask cell 的窄带内调整。质量门要求 predicted IoU 至少
  0.65、RF/Edge IoU 至少 0.50、面积比在 0.55..1.65；可信 RF 内部强制保留，新造内部孔洞
  会恢复，脱离原实例的扩张小岛会删除，多实例重叠按置信覆盖率互斥竞争。任一门槛失败都
  逐实例精确回退 RF，不会把脸、衣服或文字交给 prompt mask 任意改写。
- 空间照片设置新增独立 EdgeTAM 下载、启用、关闭、取消和删除入口。模型要求设备总内存
  至少 8 GiB、生成前可用内存至少 2 GiB；安装、自检、内存或推理失败时保留原 RF 结果，
  不阻断空间效果生成。
- 派生 manifest 记录可选边界细化模型 ID/版本；模型包、运行库和已有派生数据仍彼此独立，
  删除模型不影响已生成内容。

## 质量证据与验证

- 12 张跨场景图片、71 个 RF 实例的真实权重桌面 PoC 中，62 个实例通过安全门，59 个实例
  的边界 RGB 梯度对齐提升，中位提升比 1.296；原始 EdgeTAM 会产生的人脸/衣物内部孔洞在
  受约束融合中被禁止。完整桌面进程峰值 RSS 约 758 MiB，不能替代 Android 真机数据。
- 12 张图片分别结合 ZipDepth、DAV2、DA3 复算 attachment 关系，只合并了真实手持杯，
  并拒绝了仅贴近人物轮廓的前景杯。
- 完整 `:app:testDebugUnitTest :app:assembleDebug` 通过。Debug APK 为 24,124,077 字节，
  SHA-256 `dbd6fcc4bcaec17096c4351f8ef48ff029405121e8a76fb19ef6d2ca780a3b06`；拆包未发现
  ONNX 权重、EdgeTAM/RF-DETR 包或 `libonnxruntime*.so`，APK 体积边界保持不变。
- 本次没有使用 ADB。EdgeTAM 的 Android 冷启动、逐实例耗时、峰值 PSS、温升与真实倾斜
  观感仍需用户安装本更新后终验；未验证前不默认启用。

## 背景补全的 NPU 加速快了一倍

### 结果

在骁龙 8 Gen 2（三星 SM-S9180）上实测，1080×1440 的照片、12 个分块：

| | CPU | 之前的 NPU | 这一版 |
|---|---|---|---|
| 整个补全步骤 | 56.1 秒 | 26.3 秒 | **12.6 秒** |
| 单块 512² | 4863 毫秒 | 2083 毫秒 | **1110 毫秒** |
| 首次载入模型 | — | 4478 毫秒 | **761 毫秒** |
| 需要下载的体积 | — | 155 MB | **100 MB** |

对 CPU 从 2.1 倍提到 **4.5 倍**。补全结果与之前逐像素一致，画质没有任何变化。

### 慢在哪

Big-LaMa 的傅里叶分支占整个模型 2.3% 的计算量，却吃掉了 NPU 上 70% 的时间。原因是
它被导出成了一种骁龙的矩阵引擎接不下的形状——同样的乘加，卷积那边跑到 3600 次/周期，
这里只有 1.2 次/周期，差了近三千倍。

这一版把那段改写成矩阵引擎能吃下的形状，算的还是同一件事，结果一个字节都没变，
但那部分快了 7.8 倍。模型文件也从 318 MB 缩到 132 MB，所以首次载入和下载都快了。

### 已经装过 NPU 版的需要重新下载一次

模型本身没有升版，所以设置页里那一行会先退回「未下载」，点一下重新下即可。
装着的旧版会被自动清掉，不会占着空间。

### 说明

只在骁龙 8 Gen 2 上做了完整实测，8 Gen 3、8 Elite 两代是同样的改法编出来的，
但没有对应机器可验。用起来有异常请告诉我。

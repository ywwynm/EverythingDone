# 空间照片：渲染改用断边三角网格，并加上超采样与窄缝闭合

## 空间照片：渲染改用断边三角网格，并加上超采样与窄缝闭合

上一版把运动构造换成了真透视视差，但渲染仍沿用点元 splat：每个采样点画成一个方点，
点的大小按**未形变**的网格间距算。视差放大到物理量级后，深度断崖处相邻点元被拉开的距离
远超点的大小，剪影上就露出棋盘状缺口——底板从主体身上透出来，也就是反复出现的
"轮廓周围的透明条带"。

### 渲染改用断边三角网格

三角形天然铺满顶点之间，只有**显式断边**才留洞，而那正是真实的显露区，由第二层承接。
这一档同时拿回两样点元路径没有的东西：**逐轴独立的运动系数**（点元每个采样只有一个标量，
两轴只能取几何平均）与**前景软边缘**（点元的着色器把不透明度写死，根本不采样抠像结果）。

### 超采样与窄缝闭合

前景表面先画进一张超采样的离屏画布，再降采样叠回屏幕；同一遍里闭合窄缝——某个采样点
没被覆盖时，沿两个方向各探一段，**只有两侧都被覆盖才判定为缝**并借用邻居的颜色，单侧有
覆盖说明那是真正的边界，保持原样，否则前景会向外糊出一圈假边。

超采样倍数按显存与设备纹理上限自适应降档，实在不够就退回原来的直接绘制，不会因此黑屏
或崩溃。

### 分辨率统一到深度网格

此前深度、网格、颜色是三档各走各的（378×518 / 384×512 / 1080×1440）。现在**网格直接建在
深度网格上**，并把深度输入长边从 518 提到 720。

720 这个数是量出来的：深度模型的几何细节由内部的 token 数决定，不由输入分辨率决定——
把输入长边从 518 抬到 1440，深度场的有效带宽（0.00238 / 0.00229 / 0.00237 / 0.00229）
**四档完全持平**，喂更大的图只是把同一份结果插值上去。而模型的内在分辨率约合 588×602，
所以 518 是欠采样、720 刚好匹配、再高纯浪费。颜色与软边缘层仍是 1440——那是纹理，
采样几乎不花钱。

顺带修掉了缩放对齐引入的各向异性：此前两边各自向下取整，540×720 会被压成 378×518
（长宽比误差 2.7%），现在在候选格点里挑长宽比误差最小的一组，同一张图变成 532×714
（误差 0.65%）。恢复出来的焦距与桌面端同分辨率的差因此从 1.4% 降到 **0.04%**。

### 实测

同一视点同一位置，剪影处的边缘粗糙度从 105.7 降到 53.0（−50%），点状能量从 0.460 降到
0.372；条带从"一片弥散的棋盘"变成"柔和的渐变边"。左右满偏移对开时的竖直串扰为 **0.0 px**
（真透视的交叉项本应严格为零，点元路径因为两轴共用一个标量做不到）。

单张生成耗时从约 55 秒增加到约 79 秒，主要来自更高的深度分辨率与更密的网格。

### 已知问题

剪影上仍能看到一条柔和的暗边。它不是缺口——那里的像素是有内容的，来源是第二层在主体
区域保留的暗像素在显露时被看到。超采样只能把它摊柔和，摊不掉，需要在第二层的内容生成上
继续处理。

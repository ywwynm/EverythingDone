## 2026-07-31 - GIF 闪退修复与空间画面低扭曲优化

- 修复详情页移动图片附件、逐一播放 GIF 时可能出现的闪退。恢复 Glide 标准
  `ImageViewTarget` 生命周期，holder 回收时完整清理 target，不再让已释放的 GIF decoder 在
  Activity 恢复时被重新启动。
- 同一附件在静态代表帧与动态图之间切换时，改用独立安全快照维持画面连续；加载中请求与已就绪
  资源分别记录，失败后可正常重试，也不会因播放调度刷新而重复重启同一请求。
- 图片附件拖拽改为细粒度移动通知，只重算当前 attached holder 的播放状态，避免整个附件网格反复
  回收、重绑和解码。
- 空间渲染新增基于 GPU 实际 8-bit 深度纹理的 Jacobian 形变预算。平坦和平缓画面保留完整视差；
  高梯度素材只在危险视点同比例限制相对视差，保持移动方向不变。
- 把交互运动拆为“受限相对视差 + 不产生局部形变的刚性取景移动”，避免降低危险视差后手感明显
  变弱；原始深度明暗 relief 的上限从 ±4% 降到 ±1.8%，减轻人脸、文字和轮廓的不真实起伏。
- 发布前静态复核发现刚性移动必须同时作用于颜色与深度采样；现已统一使用同一 `cameraUv`，并增加
  着色器源码回归，避免内容移动后与深度场错位。
- 真实 OnePlus 人物素材离线回归中，左右极端视点继续保持 0 个 UV 折返点，局部采样步长由约
  0.586～1.414 收敛到 0.8245～1.1755。
- 完整 Debug JVM 测试共 87 个套件、606 例，0 失败、0 错误、1 项既有跳过；
  `:app:assembleDebug` 通过。APK 为 27,708,077 字节，拆包确认仍不包含 ORT 原生库。

## 空间照片效果：修复「立体」模式的黑色碎块，进一步收敛发虚轮廓

「立体」模式在较大视差下，人物或物体轮廓旁出现的锯齿状黑色碎块已修复：显露区域边缘处背景层的网格此前会因深度跳变留下未覆盖的空洞，露出黑色底色；现在背景层始终完整连续，任何视点下都不会露黑。该修复即时生效，已有的空间效果无需重新生成。同时，紧贴轮廓、随前景移动的发虚色边从生成阶段治理：轮廓内侧一圈携带前后景混合颜色的像素会从前景层剥离并交给背景补全模型覆盖，重新生成后轮廓更干净。另外新增一个仅在体验版可见的实验渲染模式 MPI（在「稳定/立体」按钮上继续点按切换）：把同一份生成数据软切为多层半透明平面做合成，头发等柔性轮廓完全无锯齿，当前画面整体清晰度尚未调优，仅供尝鲜与反馈，默认模式与已有效果不受影响。

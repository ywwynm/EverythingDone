## 空间照片效果：修复「立体」模式高强度下的画面扭曲

「立体」（双层）模式在高强度下容易出现的画面拉伸扭曲已修复。原因是物体轮廓两侧一些本应断开的深度过渡带被当作连续表面保留在网格里，视差拉大时这些位置被硬拉成斜坡，表现为人物或物体边缘的橡皮式变形。本版把这类过陡的连续边直接升格为层间断开：轮廓处的深度跳变改由背景层自然显露，连续表面则保留原始深度、不再被磨平，任何强度下画面主体都保持刚性、不变形。该处理在查看时实时生效，已生成的空间效果无需重新生成。真机（OnePlus）以最大强度、极限视点验证：人物与直线结构不再扭曲，视差幅度与上一版一致；轮廓处的细碎显露边属于既有的软边界课题，将在后续版本继续优化。

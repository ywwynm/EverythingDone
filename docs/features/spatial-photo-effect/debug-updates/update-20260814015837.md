## 空间照片：骁龙 NPU 加速可用了，另加深度细节档位与几处设置修复

### 骁龙 NPU 加速（新增，默认关闭）

设置页的「运行环境」多了一个**骁龙 NPU 加速**开关。骁龙机型上打开它，支持的模型会跑在
NPU 上；不是骁龙、或型号不受支持时，这个开关不会出现。

打开后需要另下一套运行组件（约 46 MB，解压后 128 MB）。它与原来的运行组件是**二选一**
的关系，所以切换开关时旧的会被清掉、下次生成时重新下载——切换后请重启一次应用。

每个模型首次在 NPU 上使用时，要在本机把计算图编译一遍，约 20–50 秒；编译结果会缓存，
之后每次复用只要不到半秒。

目前真正走 NPU 的是**人物连续性模型（RF-DETR）**，在它下面还有一个单独的 NPU 复选框，
可以只给它开或关。深度估计与背景补全这次仍走 CPU：前者在 NPU 上要求固定输入分辨率，
会牺牲掉下面新加的深度细节档位；后者的计算图在端上编译不过去。

关闭开关随时可以回到 CPU，行为与此前完全一致。

### 深度细节三档可选

MoGe-2 系模型新增「深度细节」设置，三档：

- **快速**（1200）——中位耗时约 0.69 秒
- **标准**（1800）——约 1.14 秒，与此前行为一致
- **精细**（2700）——约 1.85 秒

这个数决定模型内部的推理分辨率，直接影响深度断崖的锐利程度。九场景实测：精细档相对
标准档，深度断崖锐度 +18%；快速档则是 −14%。想要更硬的轮廓分界就调到精细，想更快出图
就调到快速。默认仍是标准档。

### 设置页三处修复

- **MoGe-2 Small 与 Base 的删除按钮显示出来了。** 此前那两行的删除图标没有画出来——
  控件在、点得到，但完全看不见，只能靠盲点。
- **发丝边缘细化（MODNet）现在可以关闭。** 此前装了就一直用，不想用只能删模型。
- **人物连续性模型（RF-DETR）可以取消选中。** 此前选上之后点不掉。

  不同的名字，应用只认了其中一个）。

  这一项对所有设备、所有档位都生效。

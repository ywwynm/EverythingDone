# 空间照片效果：第三深度模型 DA3 与运行组件 r3

## 新增 Depth Anything 3 Small 深度模型，运行组件升级 r3

- 空间照片效果新增第三个深度估计模型 Depth Anything 3 Small（约 100 MB，
  Apache-2.0）：发丝级边缘质量显著优于现有两个模型，弱光人像的发缘碎屑与
  粘连晕明显减少。在「设置 → 空间照片效果」中下载并选用；内存门槛为总内存
  6 GB、生成时可用内存 1.5 GB。
- 针对锐利深度边缘的渲染适配：发丝间隙自动并入前景（闭运算），并跳过对锐边
  模型有害的引导滤波——立体与稳定两种模式在满强度下均无块状碎屑与发际缺口。
- 空间计算组件升级到 1.28.0-r3（含全部五个模型的算子并集）：首次使用会提示
  下载新版组件（约 4.15 MB），旧版组件自动清理；推理会话恢复 EXTENDED 图优化，
  生成速度提升（本机实测 Depth Anything V2 全链路生成约 5 秒）。
- 既有 ZipDepth / Depth Anything V2 模型与已生成的空间效果不受影响。

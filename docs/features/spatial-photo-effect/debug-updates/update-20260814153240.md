## 设置页：NPU 运行环境改成独立一项，状态措辞全部统一

### 两套运行环境现在各自独立

之前的做法是错的：CPU 版和 NPU 版共用一个位置，启用 NPU 会先把原来的删掉再下载，
所以你会看到「骁龙 NPU 加速」的下载进度出现在上面「推理运行环境」那一行，来回切换开关
还要反复重下一百多 MB。

真正的限制只有一条：**同一时刻只能用其中一份**（NPU 支持是编译在运行库里的，一个进程
装不下两份）。但两份完全可以**同时存在于手机上**——现在就是这样了：

- 「推理运行环境」是 CPU 版，约 4.5 MB
- 「骁龙 NPU 加速」是 NPU 版，约 47.5 MB，**有自己的下载按钮、自己的删除按钮、自己的体积**
- 勾选框只决定生成时用哪一份，不会再删掉另一份
- 来回切换不再重新下载

多占的只是 CPU 版那几 MB。

### 状态措辞统一

所有涉及下载的项目现在都用同一套说法：**未下载 · XXX MB** / **已安装 · XXX MB**。
NPU 运行环境会额外标注**使用中**或**未使用**。

Big-LaMa（NPU 版）装好后显示「已安装 · XXX MB」，不再是含糊的「可用」。

### 上一版三个问题

- **RF-DETR（NPU 版）那一行错位**：它被放进了「EdgeTAM 边界细化」那一行内部，
  所以左边出现两个选择框、高度占满整屏。现已回到 RF-DETR Seg Nano 正下方。
- **下载按钮点不动**：其实是条件不满足时被整个藏了起来，而且没有接下载进度。
  现在按钮始终显示、不能点时置灰，旁边文字说明原因，下载时有进度。
- **CPU 版与 NPU 版同时被选中**：两者分属不同的行，系统不会自动互斥，现已显式处理。

### 状态提示分档

「请先启用骁龙 NPU 加速」此前同时用于「开关没开」和「开关开了但组件还没装好」，
而每次切换开关都会重新下载，所以重新打开后会一直显示它。现在分成：
请先启用 / 等待运行组件就绪 / 需先安装 CPU 版 / 正在下载 / 已安装。

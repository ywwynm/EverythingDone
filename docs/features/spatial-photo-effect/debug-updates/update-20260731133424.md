## 2026-07-31 - LDI-lite 双层空间照片与按需背景补全

本次把空间照片从单纹理连续变形升级为真正保存遮挡关系的 LDI-lite 双层表示，以增强视差并减少
人物、文字和直线随视点移动产生的拉伸。

- 新生成的 Spatial Photo Derivative 使用 schema v2，保存 RGB 引导的断边拓扑、表面与背景深度、
  隐藏区域、补全后的背景颜色及逐文件 SHA-256；写入完成并复核后才原子替换旧结果。
- 空间模式改用 GLES2 前向网格渲染：先绘制隐藏背景，再绘制按遮挡边界切开的可见表面，并通过深度
  测试合成。600px 长边网格按重叠行块使用 `uint16` 索引，避免 GLES2 索引和单次缓冲区上限。
- P1 保留完整请求视差，不再受 P0 单纹理全局形变预算限制。现有 schema v1 结果仍可直接查看并
  继续走低扭曲 P0；只有用户重新生成成功后才升级到 P1。
- 规则背景传播在真实人物素材上会产生明显肩部、头发和车体色带，因此正式生成链路使用 MI-GAN
  只补最大视差可能显露的隐藏背景窄带；模型不会逐帧运行，交互阶段只读取已缓存的派生数据。
- MI-GAN 作为第三个独立按需组件加入设置页，可下载、删除和重新下载。模型为 28,079,181 字节，
  不进入 APK；缺失时仅阻止生成或重新生成 v2，不影响原图和已有空间效果。
- MI-GAN、MIT 许可文件及其 ABI 已发布到现有 Ed25519 签名 stable catalog。公网回下载模型的
  字节数与 SHA-256
  `6f1f3530a1a2324b19752018ce756088b07973cda8d7d890034ace5c8a48c40b`
  均与发布清单一致。

  `:app:assembleDebug` 通过。APK 为 27,712,553 字节，拆包确认没有 MI-GAN、深度模型或
  ONNX Runtime 原生库。

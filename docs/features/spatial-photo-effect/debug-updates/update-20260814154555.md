## 骁龙 NPU 加速的下载终于走自己的通道了

### 上一版为什么还是错的

上一版把两套运行环境在**存储上**拆开了，但**下载通道没拆**：勾选「骁龙 NPU 加速」时
发起的仍然是原来那个下载任务，只是任务内部再判断该装哪一份。而下载进度是挂在任务上的，
一个任务只有一份进度，那份进度只有「推理运行环境」那一行在显示——所以无论从哪一行触发，
进度都跑到上面那行去了。

现在两条通道完全分开：各自的下载任务、各自的进度、各自的状态文字。勾选 NPU 的进度只会
出现在 NPU 那一行。

### 顺带修好的三处

- **「推理运行环境」显示的体积**：拆分之后它把两份加在了一起，两个都装会显示成 130 MB。
  现在只报自己那一份。
- **NPU 行装好后显示的体积**：之前显示的是压缩包大小（47.5 MB），不是实际占用。
  现在装好后报实际占用。
- **NPU 行的下载按钮在下载中再点会重复触发**，现在与其它行一致：进行中点击即取消。

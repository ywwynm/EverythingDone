# 空间照片设置页全面重整

## 空间照片：设置页状态机重整与生成入口改进

- 人物连续性改为复选框：它在生成中是可选组件，允许一个都不勾；修复了从 NPU 版切回 CPU 版时两行全部失选的问题，也修复了取消选择的判定。
- 推理运行环境定位为整个功能的基础：未安装时页面其余选项全部置灰（正在进行的下载仍可取消、已装文件仍可删除），其下载按钮在任何情况下都可点击；修复了开启 NPU 加速时删除后重新下载毫无反应的问题。
- 状态文案全页统一为「已启用 · 大小」与「已下载安装 · 大小」，骁龙 NPU 加速与人物连续性、发丝细化不再使用各自的独有句式。
- 未下载的模型不再显示左侧选择控件，行文字与分组图标左缘对齐；下载完成后控件出现，必选类型（深度、背景补全）只要有已安装模型就必有一个被选中。
- 单选钮与复选框在未选中时轮廓也使用强调色渐变，与设置首页的选项观感一致。
- 所有删除入口统一弹出确认框，并逐类说明该组件的作用与删除后果（骁龙 NPU 运行组件与 Big-LaMa（NPU）预编译产物此前不经确认直接删除）；发丝细化的启用状态不再在取消删除时被误关。
- 点击生成空间照片时，缺失的必需组件（运行环境、深度模型、背景补全模型）一次性列全并可直接前往设置页下载，不再逐项提示。
- 修复若干隐藏问题：选中 CPU 版补全模型时不再误关 MI-GAN／AOT-GAN 的透明 NPU 加速；Big-LaMa（NPU）与发丝细化的下载补上计费网络确认；删除模型不再在磁盘上残留空目录；三个漏着色的选择控件补上强调色。

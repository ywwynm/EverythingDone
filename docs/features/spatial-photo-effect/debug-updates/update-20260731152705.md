# 空间照片低扭曲双模式与可选高质量补图

本次根据 P1 双层画面在部分内容上形变较强、MI-GAN 在大视差显露区域补全有限的反馈，完成了
补图、diffusion 与 Flow Matching 路线复核，并把可稳定落地的方案实现为完全端侧、按需下载的
可选能力。

- 每张空间照片可在 P0 单层低扭曲与 P1 LDI-lite 双层之间即时切换并记住选择；切换不重新推理，
  也不重置当前观察视点。
- P1 不再按全图最坏深度边缘压低视差：形变预算只约束仍保持网格连接的连续表面，显式遮挡断边
  交给补全背景层承接，在保留遮挡视差的同时限制物体内部拉伸。
- 背景补图模型改为 MI-GAN 与 AOT-GAN 两种独立按需下载、删除和选择。MI-GAN 保留快速、人物
  轮廓相对稳健的特性；AOT-GAN 作为 Places2 场景先验不同的替代选项，不宣称对所有图片更优。
- AOT-GAN 提供 512、768、1024 三档工作分辨率；不静默降级。下载前和生成前均检查总内存与
  当前可用内存，最高档不足时明确提示用户选择较低档。
- AOT-GAN 仅处理最大视差会显露的背景区域，并采用保守 mask 缩放，避免细窄隐藏像素在降采样
  时丢失；合成阶段严格保持 mask 外原图像素不变。
- 新生成的派生记录补图模型、版本、工作分辨率与 P0/P1 选择，便于复现、比较和后续逐帧空间视频
  处理。
- 自定义 ONNX Runtime 升级为 `1.28.0-r2`，仍保持 Runtime API 1 以兼容已发布客户端；算子集
  覆盖 ZipDepth、Depth Anything V2 Small、MI-GAN 与 AOT-GAN 四个模型，并继续从签名阿里云
  catalog 按 ABI 下载，不进入 APK。
- Runtime r2 已从同一份上游 AAR 构建并拆分为 `arm64-v8a`、`armeabi-v7a`、`x86`、`x86_64`
  四个不可变包；每包只含 `libonnxruntime.so` 与 `libonnxruntime4j_jni.so`。四包压缩大小分别为
  4,077,237、3,657,027、4,301,201、4,331,376 字节，包级与解包后双库 SHA-256 均已校验。
- AOT-GAN 放入签名 catalog 的向前兼容扩展字段，旧版客户端会忽略它但仍能读取 MI-GAN 和
  Runtime r2，不会因未知模型拒绝整个可信目录。
- stable catalog `20260731103557` 已原子发布并从公网独立回读；远端文件与本地签名副本逐字节
  一致，Ed25519 验签通过。公网重新下载 AOT-GAN 和四个 Runtime 包后，实际字节数与 SHA-256
  全部匹配 catalog。
- 桌面真实显露带与官方样例对比表明，没有一个通用补图模型在所有内容上稳定占优。Big-LaMa
  ONNX 约 208 MB 且未稳定胜过现有两种模型，未进入 stable catalog；目前也没有同时满足通用
  遮罩补图、合法再分发、Android 端侧可运行与可接受体积的 diffusion／Flow Matching 权重，
  因此未提供误导性的同名选项。
- 额外复核了更接近新视角合成的 Apple SHARP 与 2026 年 7 月 MetaView：SHARP 官方 checkpoint
  约 2.81 GB，模型许可明确排除 product development；MetaView 依赖 20B 参数 Qwen-Image-Edit
  和非商业许可的 1.15B 参数 Depth Anything 3 GIANT。两者作为未来任务专用 student 的架构或
  teacher 参考，不进入 App 或阿里云稳定目录。
- 全量重跑 91 个 Debug JVM 测试套件、623 例，0 失败、0 错误、1 项既有跳过；
  `:app:assembleDebug` 通过。干净重打包 APK 为 20,995,393 字节，拆包确认不含深度模型、
  补图模型或 ONNX Runtime 原生库。
- 逐一解析四个正式 ONNX 模型及其嵌套子图，确认其 opset 17/18 的所有标准 `ai.onnx` 算子都已
  被 Runtime r2 裁剪设置覆盖。
- 首次增量发布候选因 `resources.arsc` 更新留下约 3.04 MB 的 ZIP 对齐空洞，没有作为最终
  `latest.json` 保留。改用 `:app:clean :app:publishDebugUpdate` 干净重发后，最终 Debug 更新为
  `202607311044`；公网 APK 为 20,995,401 字节，SHA-256 为
  `eb79991da1daa518ba346b9929620ee84f35163ec8b34823a38d24542fe1fb96`。
- 远端 `latest.json` 与本地发布元数据逐字节一致，公网 APK 与本地版本化副本的大小、SHA-256
  一致；APK Signature Scheme v2 验证通过，拆包仍为 0 个空间模型和 0 个 ONNX Runtime 原生库。

本次未连接物理设备。Android 端不同 SoC、GLES 驱动上的耗时、峰值内存、P0/P1 观感，以及
MI-GAN/AOT-GAN 三档分辨率的真实图片偏好，由用户安装本次 debug 更新后继续验证。

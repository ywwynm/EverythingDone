# 空间照片效果：倾斜体验修复（取景呼吸与跳变）

## 修复倾斜时的画面呼吸、跳变与硬截断

- 取景改为恒定边距：倾斜过程中画面不再随倾斜幅度放大缩小（此前满偏移会整帧
  放大约 13%，产生"照片前后移动"的观感），回正瞬间的缩放突跳一并消除。代价是
  空间模式下静止画面比之前略微收紧一点，全程保持不变。
- 倾斜量程放宽：此前手机倾斜约 9° 视差就打满并硬性停住（继续倾斜出现撞墙、
  斜向折角的跳变感）；现在约 28° 才接近满偏移，且满偏移处为平滑渐进，无硬停点。
- 视点范围改为圆形：斜向倾斜与轴向倾斜的最大视差一致，方向手感均匀。
- 本次仅改渲染取景与倾斜映射，所有模型、已生成的空间效果均不受影响，无需重新
  生成。这是「分割作为先验」改造的第一期；主体立体感的恢复（第二期）随后发布。

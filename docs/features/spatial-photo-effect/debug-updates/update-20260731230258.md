## 空间照片效果：轮廓显露处的深色碎屑明显减少

「立体」模式在大视差下，人物或物体轮廓旁显露出的背景带里容易出现深色碎屑与散点噪声，本版从生成阶段治理了两个来源。其一，深度放大与平滑会把真实的遮挡边缘摊成宽过渡带，导致边缘判定漏检、轮廓两侧被拉成大范围缓坡；现在生成时会先把这类短而陡的过渡带吸附回锐利边缘，遮挡轮廓按真实位置断开、显露区域交给背景补全模型处理。其二，背景板在轮廓两侧一两个像素内是前景与背景的混合像素，此前的补全范围没有覆盖这圈暗环；现在补全区域向外多覆盖一圈，显露的背景更干净。真机（OnePlus）以最大强度、极限视点对比验证：肩部与身体轮廓旁的碎屑散点基本消失，显露内容连贯；头发等柔性边缘的锯齿仍是后续软边界工作的目标。本项改动在重新生成空间效果时生效，已有结果可通过「重新生成」获得改善。

## 修设置页四个问题

### 骁龙 NPU 那两个图标没有按压反馈

下载和取消图标缺少按压效果。原因是这些图标此前靠一份**手写的清单**来上色和加效果，
新增的三个（NPU 运行组件、Big-LaMa NPU 版、RF-DETR NPU 版）没被加进去。

这个问题在这个页面上已经反复出现过——MoGe-2 两行的删除图标、Big-LaMa 的删除图标，
都是同一个原因。现在改成**按控件命名自动套用**，以后新增按钮只要沿用同样的命名就自动
生效，不会再漏。

### 点取消之后勾选框还勾着

取消下载意味着组件没装上，勾选框现在会跟着取消。

### 点「推理运行环境」的删除图标，弹出的是流量下载提示

那一行判断"装没装"时问错了对象——启用 NPU 之后它问的是 NPU 那一份，于是明明装着 CPU 版
却走进了下载流程。现在按各自的那一份判断，删除也只删自己那一份，不影响另一个。

### 骁龙 NPU 组件下载不询问流量

其它下载项在移动网络下都会先问一句，只有这一项直接就下了。现在与其它项一致。

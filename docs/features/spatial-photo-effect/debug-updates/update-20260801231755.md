# 空间照片：2026 模型栈纠错与显式对象层

用户指出此前深度、分割、matting 与补图选型混入明显过时的模型和设备基准，并反馈当前
高强度效果仍像连续曲面、会扭曲人物和画面内容。本次先按截至 2026-08-01 的官方资料重审
完整模型栈，再实施不依赖新权重的表示层修复。

## 本次变化

- Depth Anything 3 Small 的产品契约纠正为“相对 depth 型输出”，不再误称 metric；
  ZipDepth 继续作为 2026 年新近、轻量、许可宽松的默认深度候选。
- MODNet 明确降级为旧人像 ownership/软边界 provider；MI-GAN 与 AOT-GAN 保留为兼容
  隐藏背景后端，不再代表当前生成质量前沿。本次没有把非商用或 GB 级新模型塞进 App。
- 删除主体外 12%～36% 画面尺度的宽深度羽化。人物/对象现在从 base 连续网格中明确
  剥离，以一个代表深度整体移动；脸、文字和对象内部不再因逐像素深度产生非刚性拉伸。
- 新派生保存 provider-neutral 的 `ownership alpha`。对象移开时，base 层让位给已经补全的
  隐藏背景；对象轮廓继续使用软 alpha、预乘合成和背景污染去除。
- 隐藏背景生成范围覆盖完整对象足迹，减少大视差时露出原对象残影。参考视点继续直接显示
  全分辨率原图。
- 派生 renderer 升级为 `ldi-lite-v5-object-layer`；旧空间派生需要重新生成才能使用新表示。
  模型与 ONNX Runtime 仍在需要时按需下载，未进入基础 APK。

## 验证

- 新增对象层内部同位移、mask 外深度不变、软 alpha、base 网格排除 ownership，以及 DA3
  非 metric 契约回归。

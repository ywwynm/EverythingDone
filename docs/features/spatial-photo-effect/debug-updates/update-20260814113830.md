## 空间照片：背景补全也能上 NPU 了，快 2.7 倍

### 背景补全走 NPU（骁龙机型，需打开 NPU 开关）

打开「骁龙 NPU 加速」后，**背景补全模型（Big-LaMa）现在也能跑在 NPU 上**。同一张 512
分块，本机实测从 5.6 秒降到 2.1 秒，**快 2.7 倍**。一张图通常要补好几块，省下的时间成倍。

这一档不需要在手机上编译计算图——用的是预先编好的产物，随模型一起下载（按你的芯片
下发一份，约 155 MB）。此前 Big-LaMa 的计算图在手机上根本编不出来，所以它一直只能用
CPU；现在这条路通了。

打开 NPU 开关后，如果背景补全模型已经装好，重新进入设置页时会自动补下这份产物。

### 运行组件升级

NPU 运行组件从 46 MB 升到 47.5 MB（内部的 Qualcomm 计算库从 2.42 升到 2.48）。
**已经装过 NPU 组件的需要重新下载一次**——预编译产物与计算库版本严格绑定，版本对不上
就用不了。升级后此前在手机上编译过的计算图缓存会自动重建，属正常现象。

### 生成过程的提示更准确了

- 首次让某个模型上 NPU 时，会明确显示**「正在为 NPU 编译模型（仅首次，约 20–50 秒）…」**，
  不再让人对着一条不相干的旧提示干等。
- 抠像、人物连续性、边界细化这三步此前没有任何提示，界面一直停在「正在处理深度…」——
  而深度早就算完了。现在显示**「正在分析主体与遮挡…」**。这一条与 NPU 无关，关着开关
  也生效。

### 已知未验证

背景补全的 NPU 产物下载与实际使用，本次**只在开发机上用探针验过推理速度**，完整的
「下载 → 安装 → 生成」链路尚未在真机上端到端跑过。如果遇到问题，关掉 NPU 开关即可
回到 CPU，行为与此前完全一致。

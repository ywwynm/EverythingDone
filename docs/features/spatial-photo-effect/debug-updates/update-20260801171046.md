# 空间照片效果：倾斜下的头身分离根因修复

## 修复倾斜设备时的人物头身分离与主体内部撕裂

- 根因修复：此前判定"哪里是遮挡边界"依据的是归一化后的相对深度差，这个信号
  在不同模型与场景下没有稳定含义——Depth Anything 3 的锐利深度会把颈部、
  手与衣袖这类连在一起的身体结构也误判成遮挡，倾斜设备持续偏移时就表现为
  头身分离、手部被剪出并撕裂。现在改用真实的深度比例判定（远侧比近侧远 20%
  以上才是分离物体），与场景内容和拍摄距离无关。
- 修复后实测：手与衣袖、下巴与颈部连成整体运动，剪出式撕裂与深色阶梯边消失；
  双人合影中两人贴近处的亮缝同步消失；人物对背景的立体剪影完全保留。
- 仅影响 Depth Anything 3 Small 新生成的效果，重新生成一次即可获得；其余模型
  与已生成效果不受影响。建议配合「发丝边缘细化」组件一起使用。

# 空间照片效果：主体立体感回归

## 恢复主体内部立体感，分割只作边界先验

- 这是「分割作为先验」改造的第二期（核心期）：人物等主体不再是整块平移的
  刚性贴片，而回归连续深度形变——脸、鼻、耳恢复各自的远近层次，明暗随视点
  变化，空间感明显增强。
- 分割模型的职责改为边界先验：同一实体（含手持物等装配关系）内部绝不切开，
  倾斜时不再出现头身分离、手与衣袖被剪开的撕裂；实体之间与背景的遮挡边界
  仍由深度比例判定。
- 发丝等剪影边缘继续由高分辨率 alpha 羽化；已下载的分割/细化模型继续使用。
- 更新后旧的空间效果会自动重建一次（首次打开该照片时生成）。若倾斜手感
  仍有问题请反馈，第三期将处理边界带深度残留与显露区画质。

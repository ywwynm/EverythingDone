## NPU 版模型不再强制启用，也不再跟着自动下载

### 装过 NPU 版的请先点一下 CPU 版那一行

上一版把「（NPU 版）」的默认值设成了开启，这个值已经写进了偏好里，**不会因为这一版改了
默认值就消失**。装上后 Big-LaMa 可能仍显示选中 NPU 版——在设置页点一下「Big-LaMa」
那一行就切回 CPU 版了，之后一切正常。RF-DETR 同理。

### 修了什么

**不再强制使用 NPU 版。** 逐模型的 NPU 开关此前默认全开，于是打开「骁龙 NPU 加速」
总开关的一瞬间，Big-LaMa 和 RF-DETR 就被判定成「用户选了 NPU 版」，CPU 版怎么点都勾
不上。现在有独立「（NPU 版）」选项的模型默认走 CPU 版，要用 NPU 版得自己选；
而 MoGe-2、MODNet 这些没有单独选项、NPU 是透明加速的模型不受影响。

**不再跟着 CPU 版一起下载。** 之前只要总开关开着，下完 CPU 版的 Big-LaMa 就会顺手把
一百多 MB 的 NPU 预编译产物也拉下来，那一行随即显示「已下载」——用户根本没点过。
NPU 版是独立选项，现在只能从它自己的下载按钮下载。

**下载完成后各行的状态会同步更新。** 之前每个下载任务只刷新自己那一行，而
「（NPU 版）」那一行的状态取决于 CPU 版装没装。于是 CPU 版下完之后，NPU 那行还写着
「需要先安装 CPU 版」，同时 CPU 那行又取消了勾选，看上去一个模型都没选中；退出设置再
进去才恢复正常。现在任一下载状态变化都会整页刷新。

**选中 CPU 版会自动取消同一模型的 NPU 版。** 此前只有反方向做了，两个都装着时会同时亮。

### 说明

只改设置界面与下载逻辑，模型和 catalog 都没动。界面未经真机目检。

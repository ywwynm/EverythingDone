## 空间照片：新增 MoGe-2 Base 深度档与细节档位，端侧推理提速

### 新增 MoGe-2 Base（ViT-B）深度模型

设置页的深度模型多了一档 **MoGe-2 Base**，400 MB，需要 8 GB 以上运行内存。它与原有的
MoGe-2 Small 出自同一套官方导出，输出契约完全一致——只是换了更大的权重，所以深度质量
的提升不带来任何算法风险。深度是整条空间照片链路的上游，它准了，分层、补全、重投影
才谈得上准。

原有的 MoGe-2 Small 保留不动，两档可以随时切换对比。内存不够 8 GB 的设备不会看到
Base 这一档。

### 深度细节三档可选

新增「深度细节」设置，三档：

- **快速**（1200 tokens）——中位耗时约 0.69 秒
- **标准**（1800 tokens）——约 1.14 秒，与此前行为一致
- **精细**（2700 tokens）——约 1.85 秒

这个数决定 MoGe 内部的推理分辨率，直接影响深度断崖的锐利程度。九场景实测：精细档相对
标准档，深度断崖锐度 +18.4%、有效带宽 +10.5%；快速档则是锐度 −14.1%、带宽 −7.0%。
换句话说，精细档能让物体轮廓的前后分界更干脆，快速档会让它稍微糊一点。

默认仍是标准档。想要更硬的边缘就调到精细，想更快出图就调到快速。

### 派生数据保存快了 16 倍

保存空间照片派生数据的耗时从 **32.95 秒降到 2.06 秒**。原因是压缩流上少了一层缓冲，
导致每写一个字节都要过一次 JNI 往返。整条生成链路因此从 77.9 秒降到 41.3 秒。

### 骁龙 NPU 加速（部分模型）

在骁龙机型上，遮挡物分割与边界细化两个模型现在会走 NPU：

- 遮挡物检测 **10 倍**
- 边界细化 **18 倍**

首次使用某个模型时需要在设备上编译一次计算图（20–50 秒），编译结果会缓存，之后每次
复用只要 0.4 秒。非骁龙机型、或 NPU 不可用时自动回落到原有路径，不影响使用。

深度模型与补全模型这次仍走 CPU：前者在 NPU 上要求固定输入分辨率，会牺牲掉刚加的细节
档位；后者在 NPU 上跑不通。

### 其它

- 修正了骁龙芯片型号到 NPU 架构的映射表，按高通官方设备属性逐条核对过。
- 端侧推理加了分段计时，默认关闭，只在排查性能问题时开启。

# 空间照片 vNext4：严格刚性主体与双 mask 背景补全

## 本轮目标与更新内容

用户连续真机复核后指出：此前“稳定”模式会产生更明显的形变，“立体”模式又因可视范围
过小而几乎没有空间效果；提高视差后，单人图的脸部仍出现清晰可见的水平拉伸。用户要求
不能只做模拟或针对两张附件调参，必须在真实设备上检查大视角质量，并从可见表面表示的
根因解决主体形变，同时保留明确的空间视差。

**主要变更**

- vNext2 将低频仿射视差与非仿射残差分开约束，“稳定／立体”统一使用分层几何，不再让
  稳定模式退回会直接扭曲内容的旧逐像素路径；两种模式只保留边缘合成差异。
- vNext3 增加 1.5% 总形变上限，并使用深度门控的 motion-group 先验闭合已有深度证据支持、
  但轮廓不完整的主体边界。它不允许分割模型改写深度或凭语义自行创建运动层，空间感由
  主体／背景 chart 间的相对运动承担。
- 背景补全改为双 mask 契约：模型输入使用“实际显露带 + 完整、深度验证过的遮挡主体”
  作为 conditioning mask；持久背景只写最大视角真正可能显露的 write mask，mask 外严格
  保留原图。MI-GAN 与 AOT-GAN 共用该契约。
- 真机量化确认 vNext3 所谓“刚性 chart”仍会积累约 0.5% 主应变与约 0.75% 水平剪切。
  vNext4 因此把主要由深度门控主体占据的**整个最终 chart**设为单一代表深度，包括连通图
  修补进去的小孔、细缝和边缘像素；主体顶点只做整层二维位移，不再发生局部缩放、剪切
  或拉伸。
- renderer 升级为 `surface-charts-vnext4-rigid-subjects`，派生格式升级为 schema v6；旧
  派生仍可读取，只有用户主动“重新生成空间效果”才会生成 vNext4 结果。
- 最大请求视差继续保持约 0.12，没有通过降低空间强度换取主体稳定；未通过深度门控的
  普通场景 chart 仍使用有界的连续几何。

### 验证

- 完整 `:app:testDebugUnitTest`：通过。
- `:app:assembleDebug`：通过。
- 集成回归加入主体内部 matte 小孔，要求 cleaner 处理后的整个主体 chart 深度严格常量，
  同时要求主体／背景相对视差不低于 0.065，防止通过压平画面通过测试。
- 指定真机 `3B1629006YC00000`、记事“测试空间效果”第一张附件：3 个 chart，最大强度
  `0.11999662`；主体 chart 的 9,870 个像素深度范围严格为 0。中心／左右极限截图中，
  面部局部仿射主轴差降至 0.035%—0.069%，而主体／背景左右总相对视差约 130 px。
- 同一记事第二张双人附件独立重新生成：9 个 chart，最大强度 `0.119998455`；两张脸在
  左右极限下均以约 28 px 整块移动，局部仿射主轴差为 0.029%—0.188%，没有复现此前
  明显的水平拉伸。

### 测试提示与当前边界

- 请对已有图片执行一次“重新生成空间效果”，确认派生已升级为 vNext4 后再比较脸型和
  空间范围；仅安装新版 APK 不会静默替换历史派生。
- 本轮解决的是可见主体几何形变。极限视角下的背景补全仍可能出现涂抹、人物／家具残影
  和结构断裂，尤其是人物遮挡面积很大的室内照片；不能把该部分视为已经达到 Apple 级质量。
- 同输入对比中 Big-LaMa 的边界不连续度为 12.76，未优于 AOT-GAN 1024 的 12.02，且仍有
  明显人物残影，因此没有把 Big-LaMa 盲目加入模型下载列表。

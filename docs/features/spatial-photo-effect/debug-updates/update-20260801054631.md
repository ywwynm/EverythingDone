## 空间照片效果：MPI 实验模式大幅提质，全屏渲染开启抗锯齿，设置细节打磨

实验渲染模式 MPI 完成第一轮调优：羽化只作用于层边缘、不再软化画面内部，逐像素的跨层重影随窄带深度羽化消除，平面分辨率同步提高——整体清晰度较上一版大幅提升，头发等柔性轮廓继续保持无锯齿的自然过渡；深色平缓区域在大视差下仍可能看到轻微层界条纹，属该表示的已知特性，后续继续优化。空间模式的渲染现在默认申请 4 倍多重采样抗锯齿，物体轮廓处网格边缘的像素锯齿在支持的设备上明显平滑。设置页按反馈打磨：删除操作换用垃圾桶图标；「推理运行环境」、各模型行、倾斜控制行等可点击整行统一使用强调色渐变触摸波纹；AOT-GAN 工作分辨率改为点击后弹出与应用语言选择一致的选择对话框，仅在选中 AOT-GAN 时显示；「清除全部已生成空间效果」改为与其它条目左对齐的整行操作，触摸波纹覆盖整行。

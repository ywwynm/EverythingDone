# 空间照片效果：DA3 视差对比度修复

## 修复 Depth Anything 3 Small 的画面扭曲与边界破碎

- 修复 Depth Anything 3 Small 生成的空间效果在人像照片上的观感回归：此前主体
  位移过大、近处物体拉伸、耳饰等细小物件被吞掉、发际与人物边界出现块状撕裂。
  根因是该模型的深度经归一化后前后景对比度过高，本次为其加入视差对比度整形
  （压缩到 0.72 倍，对齐既有模型的分布形态）。
- 修复后实测：细小物件（耳坠）完整保留，边界撕裂与阶梯感基本消退，主体位移
  幅度与 Depth Anything V2 一致；双人合影的发际撕裂同步修复。
- 仅影响 Depth Anything 3 Small 新生成的效果；ZipDepth 与 Depth Anything V2
  以及已生成的空间效果不受影响。选用 DA3 的记事重新生成一次即可获得修复。

## 设置页：状态文案分清"装了"和"在用"，取消图标不再显得淡

### 现在能看出哪个模型正在用

之前模型只要下载过就一律显示「已安装」，正在使用的那个和只是装着的那些看起来一模一样。
现在分三档：

- **已启用 · 大小** —— 下载过，并且当前正在用
- **已下载安装 · 大小** —— 下载过，但没在用
- **未下载 · 大小**

发丝边缘细化、人物连续性这两组本来就是这么分的，现在深度模型、背景补全模型、
Big-LaMa（NPU 版）也统一了。「已安装」这个说法一并改成「已下载安装」，十二种语言都改了。

### 未下载的模型，左边的圈不再变淡

之前模型没下载时，左侧那个圆圈会被调淡。但"没下载"这件事，右边的状态文字和下载按钮
已经说清楚了，圆圈再淡一次是同一件事说三遍；而且已经装好的模型（比如 MI-GAN）圆圈是
正常颜色，两者摆在一起看着不统一。

现在只有**设备内存不达标**时才会变淡——那是真的用不了。没下载的模型圆圈保持正常颜色，
点了不会选中（右边会提示需要先下载）。发丝边缘细化那个勾选框同样处理。

「（NPU 版）」两行在没有 NPU 计算环境时仍然整行置灰，这个没变。

### 取消按钮的图标不再显得淡

下载中那个叉号，之前看起来比下载、删除的图标浅一些。两者的着色其实完全相同，差的是
笔画粗细——叉号的填充面积只有下载箭头的三分之二，同样的颜色下就是淡一截。现在把叉号
加粗到与下载箭头相当。

### 说明

只改设置界面，模型和 catalog 都没动。界面未经真机目检。

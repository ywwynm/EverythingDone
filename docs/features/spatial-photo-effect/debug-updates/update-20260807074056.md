# 空间照片 vNext9：回归全局连续多视角，移除纸片主体路线

## 空间照片 vNext9：全局连续多视角与纸片化修复

用户在多轮真机复核后明确指出：以分割、matting 或实例归属直接驱动主体运动，会让人物上身、
脸部或整块前景退化为二维纸片平移；主体与其他区域的交界还会出现运动断裂。此前为了压制形变
而不断压低主体内部视差，也使空间效果接近消失。用户要求回到功能早期正确方向：从单张图像生成
范围有限但清晰可感的全局多视角效果，分割结果不得作为空间运动的主要依据，并以约 36 px 为
探索上限、优先保证 20–28 px 范围可用。

### 主要变更

- 主生成路径回归全局连续单目深度场。分割、matting、ownership、刚性主体 chart 不再参与运动
  构造，不会再把人物或其他语义主体整块平移。
- 新增 `SpatialContinuousMotion` 双尺度连续运动表示：以 `sigma=40` 的低频全局结构承载稳定的
  大范围视差，再按输入质量自适应叠加最多 20% 的 `sigma=16` 中频残差，使人物内部、五官、
  衣物与场景结构保留可感知但受控的深度变化。
- 视差 envelope 会根据运动场梯度自动降低中频残差；它不再通过剪掉全局深度范围来换取稳定。
  因此普通输入可达到约 28 px 极限视差，复杂输入会小幅自适应降档，而不是退回纸片平移。
- renderer 改用 motion-basis texture 与 fixed-point inverse warp，从目标视点反查连续源坐标，减少
  forward splat 在大角度下容易出现的裂缝、白边、三角破口和局部过度拉伸。
- 派生 schema 升级为 v11，renderer 标识升级为
  `surface-depth-vnext9-multiscale-inverse-28px`。旧 vNext8 派生会自动重建，并保留用户设置的
  空间强度。
- 模型继续采用运行时按需下载；本次没有把深度、matting 或补图模型打进 APK，也没有修改模型
  下载地址。

### 验证

- 完整 `:app:testDebugUnitTest`：通过。
- `:app:assembleDebug`：通过。
- 指定真机 `3B1629006YC00000`、记事“测试空间效果”两张附件分别重新生成并录制多方向圆周视点：
  单人图极限视差约 28 px，中频残差权重 0.20；双人图约 27.38–27.65 px，权重 0.15。
- 额外覆盖办公室、道路及高难度插画输入：默认强度约 20.7–21.4 px，极限约 27.3–28 px；高难度
  输入会把中频权重自动降到 0.025，验证策略按几何风险自适应，而非针对两张测试图调参。
- 真机 GPU 录屏与关键帧检查中，未再观察到旧路线的整块纸片平移、明显主体交界断裂、黑色漏洞、
  白色显露缝或三角破口；最终的真实陀螺仪手感仍由用户安装本次 debug 更新后确认。

### 测试提示

- 首次打开旧空间派生时会自动升级并重新生成，请等待生成完成后再比较。
- 本版默认目标是约 20–21 px、极限约 28 px 的有限视角，不以单目输入强行覆盖完整 36 px；后续
  是否继续扩展到 36 px，应以用户真实倾斜时的形变与空间感共同决定。
- 本次发布的是 debug APK；空间模型仍在首次使用相应能力时按需下载。

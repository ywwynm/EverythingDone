## 空间照片效果：大强度下的拖影与鬼影治理（发丝伪影待深度模型升级）

针对高强度、多方向视差下的观感问题做了两处机制性修复。「立体」模式：显露区域边缘此前存在一格宽的深度硬跳变，大视差下会把边缘颜色拉成整条拖影；现在生成时把这一过渡摊成多格渐坡，拖影明显减弱（已有效果点「重新生成」后生效）。实验模式 MPI：修正了层间合成的两处缺陷——上一版底图会产生成片的位移鬼影，向后合成的首版实现存在双重计入导致的提亮薄膜；现在每层颜色按严格归一的遮挡合成携带身后内容、底图改为仅随刚性平移的静止原图，大强度多方向验证下无黑缝、无薄膜、无位移鬼影。已知残留：发丝等细碎轮廓周围仍可能出现错位的彩色碎屑与色块——根源是深度图在发丝尺度上的指派误差，属于渲染无法修正的上游问题，将由下一阶段的深度模型升级与 matting 模型引入解决；玻璃杯等透明物体的深度错误同属模型能力边界。

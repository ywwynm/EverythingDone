# 可选 RF-DETR 实例分层与多实例刚性 ownership

用户反馈显式人物层仍不自然，并希望增加职责明确的新模型继续提升质量。本次没有继续扩大
深度形变或叠加全屏生成，而是修复“多个对象共用一个运动层”这一表示根因，并加入当前代
RF-DETR Seg Nano 作为可选的端侧实例 ownership provider。

## 主要变化

- ownership 从单一 union mask 升级为互斥多实例图。不同人物和物体各自使用深度中位数
  建立独立刚性层，实例内部不再逐像素拉伸；删除新路径中的固定 `+0.16` 前移偏置，避免
  人为放大贴片感。旧 MODNet 二值 mask 也会按连通实例拆分。
- 接入 RF-DETR Seg Nano：312×312 一次前向输出实例 mask，0.45 置信度、最多 12 个实例；
  人物、车辆和动物优先，大型餐桌/床/沙发及超大普通区域回退连续表面，避免整片室内或
  桌面刚性移动。未识别对象仍走深度几何。
- RF-DETR 只负责实例身份；MODNet 只扩展人物发丝/身体软边缘，并按最近人物 label 分配，
  不吞并非人物对象。几何构建保留原始深度层序，不再先把相邻人物 union 压成同一深度。
- 新增设置项“场景实例分层”：RF-DETR 权重约 117.14 MiB，只有用户主动下载后才启用；
  可随时关闭、重新启用或删除。下载、模型自检、内存门槛或推理失败时安全退回原链路，
  不阻断生成，也不影响已有派生效果。
- 派生数据新增互斥 `ownership-labels.u8z` 及分割模型版本信息；旧派生继续兼容。设置页存储
  统计改为包含深度、matting 和实例分层模型。
- ORT Runtime 升级为 `1.28.0-r5`，由七个实际 ONNX 图的 BASIC+EXTENDED 算子并集裁剪。
  四 ABI 包分别为 4,222,645、3,809,480、4,493,231、4,492,912 字节，每台设备仍只在需要
  时下载当前 ABI；模型和 Runtime 均未进入 APK。

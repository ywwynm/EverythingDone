# 空间照片效果：发丝边缘细化（MODNet）

## 新增发丝边缘细化组件与运行组件 r4

- 「设置 → 空间照片效果」新增「发丝边缘细化」卡片：可选下载 MODNet 人像
  matting 模型（约 25.9 MB，Apache-2.0）。安装后，新生成的人像空间效果会在
  深度断边附近用 alpha 通道细化发丝边缘——立体模式下发缘的硬质阶梯感减弱、
  碎发过渡更自然。已有效果需重新生成才会应用。
- 细化只作用于发丝等边缘窄带，人物主体与背景仍由深度主导；暗色衣物等
  matting 不可靠的区域会自动回退为原有渲染，不会出现缺块。
- 空间计算组件升级到 1.28.0-r4（约 4.16 MB，新增 MODNet 所需算子），首次使用
  会提示下载，旧组件自动清理；全部既有模型不受影响。
- 说明：本次改进针对发丝边缘质量；倾斜设备时个别照片仍可能出现的头身分离、
  边界伪影等问题属深度层几何问题，正在单独排查中。

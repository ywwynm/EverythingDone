## 修上一版设置页的三个问题

### RF-DETR（NPU 版）那一行错位

上一版里这一行被放进了「EdgeTAM 边界细化」那一行的内部，所以它左边出现两个选择框、
高度占掉整屏。现在它回到了正确位置——紧跟在 RF-DETR Seg Nano 下面。

Big-LaMa（NPU 版）也从「AOT-GAN 工作分辨率」下面挪到了 Big-LaMa 紧后面。

### 下载按钮点不动、两个选项同时选中

**下载按钮**：条件不满足时上一版直接把按钮藏了，所以你看到的其实是「没有按钮」。
现在按钮始终显示，不能点时置灰，旁边的状态文字会说明原因。同时补上了下载进度提示——
之前完全没接进度，点了确实不会有任何反馈。

**两个同时选中**：CPU 版和 NPU 版虽然在同一组里，但分属不同的行，系统不会自动互斥。
现在选中 NPU 版会自动取消 CPU 版，反之亦然。Big-LaMa 与 RF-DETR 都已修正。

### 关掉再打开 NPU 后仍提示「请先启用」

上一版把「开关没开」和「开关开了但组件还没装好」写成了同一句话，而每次切换开关都会
重新下载组件，所以重新打开后会一直显示「请先启用」。现在分成四种状态：

- 请先启用骁龙 NPU 加速
- 等待 NPU 运行组件就绪…
- 需先安装 CPU 版
- 正在下载…

### 说明

本版仍**只改设置界面**，生成链路与模型没有变动。界面依旧未经真机目检，
如果还有排版或状态不对的地方，截图给我。

## 空间照片设置页整理：下载按钮改成图标，NPU 版模型独立成选项

### 下载按钮换成图标

所有「下载」文字按钮都换成了图标按钮，与旁边的删除图标同一规格——同样的尺寸、同样的
按压反馈、同样跟随深色模式。下载进行中时图标变成取消。

顺带修好了两处一直看不见的按钮：**Big-LaMa 装完之后右侧的删除图标不显示**（其实控件在，
点得到，只是没画出来），MoGe-2 两行的下载按钮也缺少按压反馈。

### 骁龙 NPU 加速这一行重做

- 勾选框移到**左侧**，与下面模型列表的选择框对齐
- 勾选后**自动开始下载**所需组件，不用再去别处找入口
- 装好后右侧出现删除图标；**删除完成会自动取消勾选**，因为组件已经没有了
- 再次勾选会重新下载
- 手动取消勾选时，下方的 NPU 版模型选项会**置灰**，效果自动回到 CPU 版本
- 这一行下面新增说明：**部分模型的 NPU 版本需要单独下载和选择**

### NPU 版模型改成独立选项

此前 NPU 是挂在模型行上的一个小勾选框，不好发现也不好管理。现在各自独立成一行：

**Big-LaMa（NPU 版）** 在背景补全模型里单独一行，自己下载、自己选择、自己删除。
打开上面的 NPU 总开关**不会**自动下载它——要不要用由你决定。只有选中这一行，
生成时才会真的用 NPU 版补全。

**RF-DETR Seg Nano（NPU 版）** 在人物连续性模型里单独一行。它与 Big-LaMa 有一处不同：
**不需要额外下载**，首次使用时在本机编译一次即可（约 14 秒，之后缓存复用）。

两行在总开关关闭时都会置灰，并提示需要先启用 NPU 加速。

### 发丝边缘细化

- MODNet 的勾选框与文字之间的间距，之前比上面几行窄，现在对齐了
- 删除模型后会**自动取消勾选**

### 说明

本版**只改了设置界面**，生成链路与模型本身没有变动。界面改动较多且未经真机目检，
如果有排版或状态显示不对的地方，请告诉我。

# 修复环形倾斜时的整帧缩放呼吸

## 用户可见变化

- 连续倾斜手机画小圆时，安全取景不再随方向周期性改变，画面不会再以整帧放大、缩小为主。
- 保留原有空间视差幅度、固定参考框和黑边保护；没有通过削弱纵向响应降低空间感。
- 稳定、立体和 MPI 三种模式共用修复，已有空间照片无需重新生成。

## 实现与验证

- 将取景边距从方向相关的 `max(abs(x), abs(y))` 改为基于视点与视差欧氏长度的旋转不变计算。
- 保留等比缩放、参考位直通、source lock、采样保护与最大边距上限。
- 新增半径 `0.2`、`0.6`、`1.0`，每档 72 个方向的环形回归。
- 目标单元测试、完整 `:app:testDebugUnitTest --rerun-tasks` 和 `:app:assembleDebug` 均通过。
- 本轮未使用 ADB；真实陀螺仪下的小圆轨迹、端点驻留和回中由用户更新后终验。

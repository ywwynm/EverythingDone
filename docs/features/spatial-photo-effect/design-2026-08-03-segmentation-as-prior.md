# 设计：分割作为先验，深度作为几何（2026-08-03）

## 背景与问题

用户引入分割模型的意图是**提升**空间照片效果。当前 v18 实现却把分割变成了**替代**
深度的主结构：实例 = 整块刚性平面（内部零形变、零浮雕），连续深度形变只剩下背景
基底。结果是撕裂消失的同时空间感也消失——主体像被平移的贴片，加上动态取景缩放的
前后呼吸与 9° 即饱和的传感器标度，整体退化为「挪照片」（用户 2026-08-03 反馈）。

诊断结论（代码证据见会话记录）：
- 贴片感：D63/D64 对象刚性平面 + 全帧 RIGID_PAN + 对象无 relief；
- 前后感：SpatialSourceLock 取景边距随视点半径连续变化，满偏移整帧放大约 13%；
- 跳变/硬截断：SENSOR_FULL_SCALE_RADIANS=0.16（≈9° 打满硬钳）、对角满偏移边距
  顶到 MAX_COVER_MARGIN 后靠 clamp-to-edge 兜底、预算逐轴钳制方向相关。

## 设计原则

**深度出几何，分割出语义。** 空间感唯一可靠的来源是连续深度场的逐像素形变；
分割的正确职责是回答四个深度模型答不好的问题：哪里允许断、哪里必须连、
显露时该补哪里、剪影边界精确在哪。实例永远不成为独立刚性运动层。

## 五个结合点（全部复用已发布资产）

1. **断边双门控**：断边 ⟺ 「跨实例边界」∧「深度比 ≥ OCCLUSION_DEPTH_RATIO(1.2)」
   （D56 判据保留）。实例内部无条件禁断——颈颚、手袖类内部撕裂机制性消失，而内部
   浮雕保留。无实例覆盖的区域（家具、场景）沿用纯深度比判据。D66/D69 的装配与
   共动关系继续生效：同装配体（人+手持杯）的实例间边界视同内部，禁断。
2. **边界带深度重指派**：实例边界 ± 窄带内，像素深度按 mask 归属重指派到所属侧的
   代表深度分布（只动带内、只动错位像素）。治深度-图像错位的 halo/渗色（发缘彩色
   碎屑根源），依据比亮度引导滤波更强。
3. **实例内深度净化**：实例区域内做保边抑噪（单表面先验成立才敢平滑），压制 DA3
   面内高频梯度。随后评估 D55 全局对比度压缩降档/退役——用语义净化换回更多层次。
4. **补图足迹与窄带**：保留 D70——ownership 足迹 + 最大视差窄带决定隐藏背景补全
   范围与可信隔离；对象深处保留源像素。
5. **剪影羽化**：保留 D54/ownership 高分辨率 alpha，仅做断边处的亚网格羽化
   （coverage），不承担实例身份，不参与运动。

**渲染端回归单一连续网格 + 断边 + 背景层**：删除「base 排除对象 + 对象平面」双路径；
budget/stabilizer/relief 恢复全帧生效。RF-DETR/EdgeTAM/关系推理/r6 运行时全部保留。

## 交互层三项独立小修（可先行）

1. 取景改恒定 overscan（静止轻微裁切换取零呼吸），废除「幅度→缩放」耦合；
2. 传感器 full-scale 0.16→约 0.5 rad（≈28°），±1 处 tanh 软饱和替代硬钳；
3. 形变预算钳制改旋转不变（欧氏范数），消除环绕路径的半径抖动。

## 分期与验收

- **P1 交互层三小修**（独立可发，先行止血「前后感/跳变/硬截断」）；
- **P2 核心**：断边双门控 + 实例内禁断 + 渲染回归连续网格（治「贴片感」）；
- **P3**：边界带重指派 + 实例内净化（治 halo/碎屑，评估 D55 降档）；
- **P4**：刚性平面路径退役与回归清理。

验收纪律（全局记忆已固化）：五张测试图交叉验证；真机持续偏移驻留（按住画圆/
驻留四角）；颈、手、发缘、人-人贴近处窗口放大对比；对比组 = 当前 v18。

# 当前管线：每一步的输入、输出、模型、目的（2026-08-11）

用户要求"总结一下目前的处理流程"。以下是**资产生成期**（离线跑一次，烘焙成文件）
与**渲染期**（实时）的完整链路。

**模型一共四个**：BiRefNet_lite（主体剪影）、MoGe-2（几何）、SAM 3（分割身份）、
Big-LaMa + Moebius（补全，两档各一）。BiRefNet_lite 出两张图：`matte.png` 是**二值
区域标签**（并进遮挡物身份，查看器只经 `occluders.png` 间接读它），`matte_soft.png`
是**连续覆盖率**（2026-08-11 起，供软边界用，查看器有 `matteSoft` 诊断档）。

## 渲染期（查看器 / 端上）

| # | 步骤 | 目的 |
|---|---|---|
| 1 | 第一层前向投影 | 逐像素一个点，按 `u' = fx·P'.x/P'.z + cx + fx·tx/Z0` 绕支点转 |
| 2 | 第二层前向投影 | 只画带内像素，用 `hidden_z` 参与 z 竞争 |
| 3 | 剪影去污 k=2 | 断边近侧的前景×背景混合像素逐层向内取色（D161） |
| 4 | 层间 alpha 混合 | 由 `α = (C−B)·(F−B)/|F−B|²` 反解覆盖率（D164）。**只覆盖全图 0.99%**——要求 |F−B|>17 级 |
| 5 | 窄缝闭合 r=8 | 断边处两个三角形都被丢弃留下的 1px 缝（D170） |
| 6 | 2× 超采样 + FXAA | 几何量化（D161/D163） |

视差硬钳到 `meta.hiddenLayer.maxSpanPx720`（资产预算），基线上限 4.5cm（对齐 iOS 实测 3.97cm，D169）。

## 这条链路的结构性弱点

**第 2 步把剪影切成了二值的硬边。** 后面所有工作——挑掩膜、挑模型、Poisson——
都在回答"带里填什么颜色"，没有一步在回答"边界本身该是什么形状"。
第 4 步是唯一在做软边界的，但它只能覆盖 0.99% 的像素。

用户反复看到的"半透明的玻璃条带 / 物体轮廓复制了一份"，形态上就是
**一条沿着剪影的、与前景同形的软带**——这正是硬二值层界在软边界（发丝、玻璃、
毛绒边缘）处的必然产物，不是补全内容不够好。

# Opus 调研 2/3：几何表示与形变治理的技术原理（2026-08-04）

## 颠覆性结论（全部有数学推导/文献支撑）

1. **纯平移下，屏幕空间 UV 平移 ≡ 真 3D 反投影+透视重投影**（差全局平移）。
   升级真 3D 的唯一实质理由是解锁推拉/旋转，不是"画得更准"。
2. **相对深度的仿射不定性在小运动下只贡献全局 pan+zoom，无害**——换 metric
   深度模型不解决小视差形变（与本地桌面反证一致）。
3. **形变三源**：(a) 模型在物体内部给出错误深度梯度（渲染忠实画出错误几何）；
   (b) 断边拉伸（已治）；(c) **我们自己的限幅机制**（逐边应变上界/全局预算/
   实例残差限幅）让 shift 不再是视差的同一全局仿射函数——"图像不同部分前面
   各有一台基线不同的相机"，物体跨视角改变长度/相对大小。**治理手段本身就是
   形变源。**
4. **形变预算方程**：层间行程 P 与实例内剪切 S 之比 = Δρ_inter/δ_intra，与
   amplitude 无关——这就是所有旋钮"都只是折中"的定量原因。唯一出路：压
   δ_intra（几何低阶化/分层）或提 Δρ_inter（视差重映射）。
5. **合法形变判据**：把实例内视差投影到低阶基（常数/平面/二次面）→ 低阶视差
   场必然对应某个刚性表面 → 形变必然是合法透视前缩。应变上界无法区分合法/
   非法形变，低阶化可以。
6. **推拉（dolly）几乎不产生显露区**（近景外扩遮挡更多背景），且径向项
   (u-c_x)·g·ρ 仍是屏幕空间可算——不必上真 3D 就能加推拉。
7. 幅度双上界：显露/舒适 ≈2-3% 画宽；噪声上界 A·σ_ρ ≲1-2px 通常更紧——
   低阶化后噪声上界解除，幅度上限改由显露区决定。
8. 层数趋势：深度图质量足够时收敛到 **2-4 层软分层**（SLIDE 2 层/Flash3D K=2/
   Tiled MPI 4 层），靠软 alpha 解决薄结构；32-64 层 MPI 不划算。
9. 端侧 3DGS：渲染已解决（Mobile-GS：SD8G3 1600×1063@116FPS、4.8MB），
   前馈预测远未就绪（Flash3D 256×384@10fps 数据中心 GPU）；2026 内不做端侧
   单图前馈 3DGS。最近的端侧先例是 CheapNVS（Tab S9+ >30FPS 窄基线）。
10. 补全时机：生成期烘焙是压倒性主流（3D Ken Burns 只在路径两极值视角补全）。

## (P, NR) 验收指标

- NR 非刚性度：实例在两视点间最佳相似变换对齐后的顶点残差 RMS，<1px 不可见。
- P 层间行程：前景实例中位位移 − 背景中位位移。
- 预测：现有三种限幅的所有档位落在同一 (P,NR) 曲线上；实例低阶化把曲线整体抬起。

## 三条演进路线（原文）

- **保守（1-2 周）**：删三层限幅 → 实例内视差低阶化（平面/二次面拟合 + 按
  残差方差自适应收缩 λ）→ SLIDE 软可见度替代硬断边 → 加推拉径向分量 →
  (P,NR) 验收。预期：拉伸根治（形变必然合法），幅度上限改由显露区决定
  （~2-3% 画宽），轻微纸板化用二次面+λ<1 缓解。
- **中等（4-8 周）**：2-4 层软分层 LDI（RGBA+低阶视差图/层）→ 真透视相机
  （解锁推拉+小幅旋转）→ 生成期按运动包络烘焙显露区并集 → 限幅+边界淡出。
  性价比最高的终点。
- **激进（3-6 月，不建议主线）**：度量点图（MoGe/Depth Pro）+ 每实例刚体 +
  端侧高斯渲染 + 扩散补全。收益只在真要大视角时兑现。

## 一句话建议（原文）

先做保守路线第 1、2 步（删限幅 + 实例内视差低阶化）并用 (P,NR) 量化验收——
一周内可证伪/证实核心论断，不改任何表示；成立后推进中等路线。真 3D 的价值
在解锁推拉，不在把平移画得更准。

# 实施工单：`_base` 基线上的条带治理（2026-08-12，接 D194/D195）

## 基线定案与总原则

D194 已回退到 8/11 上午的窄掩膜 Big-LaMa 线（`_base`：`--backend lama_tiled
--exclude-fg 12 --use-matte --matte-mode union`，配现在的 SAM 3 分割），00/315° 渲染侧
缝中位 7.3，优于其后所有版本。D195 的定律是本工单一切取舍的依据：

> 补全质量由「带离真实像素有多远」决定，不由模型强弱决定。
> 掩膜设计（洞开多大、开在哪）比换模型重要一个量级。

**用户裁定（2026-08-12）**：候选模型必须端侧可行（≤0.5B / ≤350MB 量级、可转 ONNX、
可商用）。桌面级大模型路线取消——OSOR-SDXL 对照实验不再跟进，Qwen-Image-Edit 类
20B 模型不进任何环节。

纪律（D194 教训，硬性）：**任何全局换档，验收表必须并列全部九场景同一判据**，
不得只报被治的场景；指标变化必须配 zoom 目标帧目检（D186/D189/D193 三次教训）。

## 任务一：`_base` 全矩阵基线固化

九场景 × 24 角度出帧 + 渲染侧缝判据（D191 修对的版本：按前景深度投影剔除主体侧，
只量第二层对真实背景的缝）+ 台阶/散点/空洞/抄袭度全套 + zoom_matrix 整圈目检。
把这套数字作为后续一切改动的对照基线，落盘 `qa/base-matrix/`。
重点：00/315°、00/328°、05 的脏背景位、08（洞占比最大的场景）。

## 任务二：05 脏背景的逐带段治理（不换全局后端、不扩全局掩膜）

05 是当年放弃这条线的原因，现在必须在不破坏其它八景的前提下单独治：

1. 用 D177/D178 的实例归属判定选出「显露的是别的物体」的带段（05 盘沿对玫瑰类），
   只对这些段做段级处理；自遮挡段与其它八景一个像素不动。
2. 段级处理的候选（按 D195 排序）：
   a. 段级重补：只对该段构造局部掩膜重跑 LaMa，来源窗口用 D189 的逐段实现
      （`band_source.py`，含「来源必须比该段遮挡物更远」判据）；
   b. 段级另源：确需生成自由度的段，从**单独的整幅背景板图**取内容（D195 规则：
      给生成模型开大洞必须另开一张图，不得让默认带从大洞图里取），交界按覆盖率羽化；
   c. 都不行的段：按任务四收紧该方向包络。
3. 验收：05 脏背景位目检 + 抄袭度（同场景 A/B）+ 全九场景缝判据无回退。

## 任务三：多视角顺序补全（D193）叠加到 `_base`

D193 是 D195 定律下最对症的机制（目标视角下洞被真实像素包围），但它此前建在退化
基底上（`_mix`→`_dz`），必须在 `_base` 上重估：

1. 配置沿用 D193 补充的定案：16 角、权重渐变（smoothstep 4–16px + 先验权重 0.5）、
   **Big-LaMa 后端**（多视角档上下文完整，回归式赢，8.9 vs 12.2）。
2. 待办继承：覆盖率从 21.8% 提上去（更多角度/多半径），注意每加一档先量收益再定型。
2a. **前景侧屏蔽（调研新增）**：目标视角的「四面包围」上下文里有一面是遮挡物本身，
   经典 DIBR 规则是补 disocclusion 只许用背景侧像素——补全窗口内把前景投影区标为
   不可参考（LaMa 可并入掩膜），做一次单变量消融验证必要性。
2b. **往返残差门禁（调研新增，GenWarp 教训）**：补完→反投影回第二层→再前投到该
   视角，把往返残差作为一致性指标纳入门禁，防重采样误差叠加。
3. 端侧成本核算：多视角 = 多跑若干次 LaMa 窄带 tile。按 LaMa-Dilated 512² 实测
   （NPU 55ms、CPU 秒级）估 16 角 × 每角数 tile 在 CPU 上约 1–2 分钟，贴生成期预算
   上限；先在桌面定质量收益，端侧档位（角数）另行取舍。
4. 验收：九场景缝判据 + 目检；预期这是 `_base` 之上的主要收益项。

## 任务四：四道修法在 `_base` 上逐一重估

D189（结构延续 `_str`）、D190（跨缝色阶 `_seam`）、D191（纹理镜像 `_tex`）、
D192（带深度 `_dz`）都是在 `_mix` 基底上量的收益，逐一在 `_base` 上重跑：

- 预期：D190/D192 独立于基底（缝的 Dirichlet 修正、深度接回背景），大概率仍有效；
  D189 的去块状化与 D191 的高频搬运在窄带上收益可能变小——量了才算。
- 谁有效留谁，无效的降为可选档；组合顺序固定为 base → (段级治理) → mv → 有效修法。

## 任务五：逐图/逐带自适应视差收紧（原任务三，保证性杠杆）

D187 的空洞率-基线曲线（4.5cm 6.1–6.4% → 1cm 2.4–2.6%）与 D191/D192 的结论一致：
在补全「看不出是猜的」之前，唯一保证消除条带的手段是少显露。实现按带段置信度局部
收紧（复用任务二/三的段级信号），全局上限仍由用户裁定；四项并列硬门禁不得用全图
变保守凑数。

## 任务六（调研已返回，配方定案）：带体制微调与公平对照

依据见 [research-2026-08-12-narrow-band-inpainting.md](research-2026-08-12-narrow-band-inpainting.md)。
**用户裁定（2026-08-12）：第 2 项 crop-zoom 公平对照最先做**（先于微调与工单其余任务，
仅任务一的基线固化语义并入其评测准备）；微调在对照结论出来后排期。

1. **主项：GRT 式 LaMa 微调**（arXiv 2607.05354 配方，同架构同开销 +3.77dB 的实测
   先例）：渲染器 dump 精确显露带掩膜 + 原图 GT + 混入随机笔画掩膜；**语料用
   Open Images / COCO / 自有照片，禁用 Places2/ImageNet（non-commercial 条款）**；
   256² / batch 32 / 20–40 epochs，单 5090 约 1–3 天；带真值台验收（带内 PSNR/
   LPIPS/边缘梯度 + 渲染侧缝落差）；ONNX 走 Carve 的 FourierUnitJIT 先例。窄带专用
   与通用 checkpoint 并存，按带宽选用。
2. **crop-zoom 公平对照**（协议 23 步已在调研报告中，摘要在依据文档第 2 节）：
   整图/仅裁/裁+放大 三档 × 单视角/目标视角 两档 × LaMa/Moebius；同一裁窗生成器、
   同一 zoom、像素域贴回；**裁窗做前景侧屏蔽**；扩散固定 5 种子取中位；指标限定
   带 + 2px 环。目的：修正 D160 适用范围 + 产出「带宽 vs latent 像素」失效曲线。
   若扩散档反超，必须补 N 窗 × 20 步端侧耗时与 ONNX 可行性评估才算数。
3. **观察项（不与 1 并行启动）**：DecFormer 7.7M 头（修 Moebius latent 合成，仅在
   Moebius 保留档位时复现）；MI-GAN（5.95M/MIT/官方 ONNX）底座 + 深度/结构引导
   通道的从零小网络——等第 1 项 baseline 出来再议。

## 边界

- 只改桌面资产生成器与网页查看器；不连接设备、不发布阿里云。
- 模型准入：可商用、权重实发、端侧尺寸（≤0.5B）；FLUX 系与一切 NC 权重禁用。
- 随做随更新 decisions/followups/sessions；新中间产物必须同时落盘未裁剪原始版。

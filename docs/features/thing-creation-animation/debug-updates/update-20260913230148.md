## 新建与左滑动画实机修正（20260913230148）

用户要求把弹窗出现／消散粒子分别用于新建记事和首页左滑完成，并在上一轮发布后明确要求到 `9018f404` 实机调试。本版保留“新建记事动画”的涟漪、边框光效、粒子三档，以及“左滑完成记事动画”的滑动、粒子两档；全部 13 组语言同步，旧边框勾选偏好兼容保留。

OPD2515 / Android 16 首轮实测连续两次复现新建粒子结束崩溃：ParticleDismissOverlay 在 detach 中同步回调，ThingCreationTransition 随即移除同一 DecorView 内的背景和触摸层，破坏尚未完成的父容器移除顺序。现改为主动移除返回后通知，外部 detach 在下一次主线程消息通知，一次性语义不变。

新建页继续使用原 DetailActivity，一次性首页快照承接零时长系统跳转。实机发现键盘会提前覆盖首页快照，现保持输入法隐藏，页面入场完成后再展开；提前返回或配置变化时正常清理。新建入口的边框光效也统一从右下开始。Activity 初始化和粒子准备仍有成本，本版没有将详情改成 View 或 Fragment。

左滑实测发现卡片按压缩放改变了 getLocationOnScreen 的原点，误触几何保护，粒子刚准备就被取消。ParticleSwipeAnimator 改用父容器屏幕坐标加卡片布局位置，排除自身缩放与手势平移。消散进度按卡片自身宽度计算，解决平板多列时按整屏计算反应过弱的问题；原完成阈值、隐私认证和业务处理保留。粒子固定向左，支持停住、回拖和成功松手后的剩余播放。

验证：横屏三种新建选择、打开和保存，竖屏边框与粒子打开保存通过。三轮在创建页刚恢复前台约 130–144 ms 后按返回键均正常回首页，随后仍可新建。横竖屏左滑暂停前后像素完全一致；回拖归零恢复卡片，系统取消后与原图像素完全一致；快速甩动和 1.4 秒慢滑均正确完成测试记事。28 项相关 JVM 测试通过且无跳过，临时定位日志已清除。

设备系统录屏不可用，视觉证据采用连续系统截图与粒子日志；低频截图不作为帧率证明。测试卡片粒子首帧仍约需 0.3 秒准备。仅操作已授权设备和明确命名的测试记事，详细过程见两个功能目录的 device-validation-2026-09-13.md。

# 调试更新日志

## 新建记事动画：光带改为右下角起步，播完后内容放大；涟漪圆心回到新建按钮

边框光效档的全屏光带不再从左下角起步。现在从右下角出发，沿底边向左、沿左边向上、沿顶边向右、沿右边向下，回到右下角。实现方式是给边框视图加了起点角选项并新写了一条从右下角开始的顺时针路径，不再依赖此前那次没有生效的水平翻转。光带时长仍为 1290 毫秒，颜色、描边宽度和粒子参数都没有改。

光带走完、暗段余光退完之后，编辑页内容以右下角为轴从 0.84 倍放大到原始大小，时长 216 毫秒，减速插值。内容从放大的第一帧起就是完全不透明的，没有淡入；放大期间首页画面仍然在底层，放大结束才撤掉首页画面并弹出键盘。页面退出、配置变化、布局尺寸变化等任何中断路径都会把缩放和透明度复位，不会留下缩小或半透明的页面。

保存记事后新卡片上的光带也改成从卡片右下角起步，走向与全屏一致。这里同时修掉一个此前就存在的缺陷：边框视图在本次布局后的第一次播放会用自身边界重新计算路径，把卡片矩形覆盖成整屏，于是应用启动后的第一次保存看到的是整屏光带而不是卡片光带，第二次之后才正常。现在显式指定矩形之后不会再被覆盖。卡片光带的 1600 毫秒时长、末尾 220 毫秒淡入以及中断保护都没有改动。

涟漪档的揭示圆圆心从内容右下角改回新建按钮中心，终止半径按圆心到最远屏幕角的距离取，时长仍为 600 毫秒。粒子档没有任何改动。

在 OPPO OPD2515（Android 16，横屏）与三星 SM-S9180 两台设备上用真实的设置菜单、真实的新建按钮和真实的保存返回做了验收：三星逐帧实测光带 1267–1285 毫秒、内容放大 207–210 毫秒，从光带出现到内容完全落位约 1486–1501 毫秒；放大全程与最终页面按同一缩放对齐后逐像素一致，确认没有淡入。涟漪圆心与新建按钮中心的偏差为 0.0–1.0 像素。光带期间首页画面始终完整，没有黑帧或空白帧。光带播到一半按系统返回可以正常回到首页，进程存活，随后仍能正常新建。

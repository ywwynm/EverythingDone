## 2026-09-14 卡片级涟漪在长滚动后失效（修复记录在首页新卡片入场目录）

- 用户反馈涟漪档保存后卡片级涟漪缺失。根因是揭示动画在“脱离窗口时绑定、重新挂上后从未绘制”的卡片 RenderNode 上立即结束，加上平滑滚动超过 1200 ms 时旧兜底会直接放弃。修复、复现数据与证据路径见 [首页新卡片入场](../home-new-item-animation/sessions.md)。

### `scaleX = -1` 为何无效：未查明

代码层面没有找到重置该属性的地方（`DetailActivity` 唯一的 `scaleX = 1f` 作用于清单项 RecyclerView 子项，与 DecorView 子 View 无关），也没有别的代码遍历 DecorView 子节点清变换。但可以确定翻转**本来就不该用**：水平镜像会把顺时针变成逆时针，镜像后的走向是右下起步 → 右边向上 → 顶边向左 → 左边向下，与目标相反。另外光带头部在前 15% 时长内就跑完约 60% 周长，起点角本身极难目视分辨，用户当时看到的更可能是慢速段（原路径为沿右边向下再沿底边向左收到左下角）。真正的根因未查明，代码已删除该翻转，不再追查。

# 功能偏好

## 2026-09-14 边框光效与涟漪的窗口承接（用户裁定）

- 边框光效档保持“以边框光效为主”：先完整播放 1290 ms 的全屏光带，播完后再做一个快速的内容放大动画，内容以右下角为轴从小放大到满屏。不采用扇形揭示、交叉淡入或收口涟漪。
- 放大动画**不带透明度变化**：内容从放大一开始就是完全不透明的，用户明确表示加入透明度变化“感觉怪怪的”。
- 全屏光带的走向改为：从右下角出发，沿底边向左、沿左边向上、沿顶边向右、沿右边向下，回到右下角。用户在真机上看到当前实现仍是左下角起步（原路径），`scaleX = -1` 的翻转没有达到预期，不再依赖翻转。
- 保存记事后首页的卡片级边框光效同样改为从卡片右下角起步、走向同上；该动画的其余部分（时长、末尾卡片淡入、几何保护）不改。
- 涟漪档的圆心改回 FAB 中心，不再用内容右下角。
- 全屏边框时长保持 1290 ms。

## 2026-09-14 动画选项名称

- 设置标题改为“新建记事动画风格”，同步全部支持语言。

## 2026-09-14 首帧等待

- 用户明确要求继续优化点击新建到粒子开始之间的可感知等待；上一轮约 0.4 秒准备不能作为最终状态。保持 Activity 架构及既有保存三阶段顺序。

## 2026-09-14 性能测试操作方式

- 性能验收必须模拟用户实际按按钮、输入、返回和拖动；不能通过 ADB 的 Intent、广播或内部入口直接调用业务作为真实操作的替代。观察探针只采样，不驱动业务。

## 2026-09-13 保存后卡片入场顺序

- 用户明确要求：先在列表中腾出新卡片的位置，再播放粒子出现动画，粒子播放完成后才显示完整真实记事。不能在粒子尚未播放完时提前露出完整卡片。

## 2026-09-13

- 将原边框光效勾选项改为“新建记事动画”选择弹窗，选项为“涟漪”“边框光效”“粒子”，同步全部支持语言。
- 同一选项控制点击新建按钮和保存成功后的动画，粒子出现从右下方进入。
- 创建页与入场动画需要连贯，避免动画全部结束后才开始创建 Activity。
- 用户补充：Activity 启动本身较重且有系统过渡，可以接受尽量优化动画前置的衔接；明确不考虑把详情页重构为 View 或 Fragment。若有保持 Activity 的更好做法，可以尝试。

# 修复设置页渐变 checkbox 选中态比未选中态小一圈

## 主要改动
- 设置页渐变 checkbox 选中后整体比未选中时小一圈的问题已修复：未选中态的方框轮廓是描边、外缘略大，选中态只填充到内圈所以偏小；现在选中态的填充会铺到与未选中轮廓相同的外缘，选中/未选中大小一致，勾选过程也不再有尺寸跳变。
- 顺带修正了上一版引入的选中态渐变方向轻微偏移的问题（外廓加大后渐变没跟着方框对齐）。

## 验证重点
1. 设置页逐个 checkbox：选中与未选中状态的方框外径应一致，点选/取消时方框大小不跳变。
2. 选中态方框为强调色渐变填充，渐变方向（左下→右上）正常、无明显偏移或被截断。
3. 未选中态轮廓颜色与粗细保持原样不变。
4. 详情页、桌面记事列表 Widget 配置页、颜色选择里的勾选控件外观仍不受影响。

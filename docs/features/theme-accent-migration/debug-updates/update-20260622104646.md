# 渐变文本与 compound drawable 范围修复

本次修复全局渐变文本在固定宽度 TextView 中的采样范围问题，并补齐 compound drawable 与文字一起 tint 的两种模式。

用户观察到：RadioChooser 里短文本和长文本的渐变效果不一致，短文本像是只采样到一小段渐变，长文本才更容易呈现完整渐变。重新确认后，原因不是“短文本在自身宽度内吃满渐变”，而是旧实现混用了 TextView 外层 view 坐标和 TextView 绘制文字时的 Layout 内部坐标；在固定宽度 TextView、compound drawable 和 RecyclerView 重绑场景下，表现会接近按整块 TextView 或错误偏移后的区域采样。

修复内容：
- `BackgroundUtil.applyTextBackground()` 改为等待 pre-draw 后，基于最终 text/layout/compound drawable 状态计算 shader。
- 文字 shader 使用 `Layout.getLineLeft/Right/Top/Bottom` 的内部坐标，不再叠加 `totalPaddingLeft/Top`。
- 新增 `CompoundDrawableGradientMode.NONE / SEPARATE / COMBINED`。
- 默认 `SEPARATE`：compound drawable 与文字分别按自身范围应用渐变。
- 支持 `COMBINED`：compound drawable 与文字作为整体区域共享同一段渐变。
- `GradientCheckboxDrawable` 和 `GradientRadioDrawable` 标记为已自行处理渐变，避免动画 drawable 被全局 compound drawable 逻辑转成静态 bitmap。
- `RadioChooserAdapter` 先设置 radio drawable，再应用文字渐变，确保文本 shader 使用最终布局状态。

验证：
- `git diff --check` 通过。
- 调试日志残留检查通过。
- `./gradlew.bat :app:assembleDebug --console=plain` 通过。

# 主题强调色渐变第四轮修复

这次继续收敛 `accent -> accent2` 渐变迁移中的遗漏和回归：

- 设置页更换 Drawer 头图的 `TwoOptionsDialogFragment` 不再强制使用 accent 渐变，避免这个二选一对话框被错误染色。
- 记事详情页左下角快速提醒 checkbox 在未选中时改为跟右侧提醒文字同色，随记事背景自动切换明暗；只有选中状态才显示 app accent 渐变。
- 修复 loading / progress bar 在新的 tint 方案下不可见的问题：ProgressBar 的渐变包装器现在会转发原 drawable 的 bounds、state、level 和动画 callback，并同时处理 indeterminate/progress drawable。
- debug 更新下载进度条、检查更新 loading、相关更新弹窗标题/按钮改为默认 app accent 渐变，移除 `app_pink` 单色残留。
- 统计页分享 FAB、关于页支持 FAB 改为默认 app accent 渐变，内部 icon 和 ripple 会根据背景亮度自适应黑白前景。

验证：`./gradlew.bat :app:assembleDebug` 已通过。已通过 `:app:publishDebugUpdate` 发布到阿里云，debug update code 为 `202606211407`。

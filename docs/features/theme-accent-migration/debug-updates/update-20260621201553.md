## 2026-06-21 主题强调色渐变修复

本次 debug 更新继续修复 `accent -> accent2` 渐变迁移中的残留问题。用户明确要求：凡是能通过 shader、自绘 Drawable、RemoteViews bitmap 或包装 Drawable 呈现渐变的控件，不再使用代表色作为可见 fallback。

主要变化：

- 设置页所有 panel 标题文字和标题 icon 改为默认 accent 渐变；提醒可靠性标题 icon 做了视觉左移，开始做事标题 icon 缩小到 18dp，避免上下裁切。
- 设置页打开的 Chooser、Alert、Loading、PatternLock、TwoOptions dialog 改为传递 `App.defaultAccentBackground`，标题、确认按钮、RadioButton、ProgressBar 等沿渐变路径渲染。
- `BackgroundUtil.applyCheckboxAccent()` 改为自绘 checked-state，设置页、详情页快速提醒、记事列表 widget 配置页的 Checkbox 选中态都支持真实渐变。
- 详情页右下角开始做事按钮改用 oval 渐变背景，修复渐变后变成方形的问题。
- 记事列表 widget 的置顶/进行中标记改为 RemoteViews bitmap 渐变渲染；根范围使用 app accent 渐变，文件夹范围使用目标文件夹背景；置顶文件夹也新增标记。
- Drawer、移动到文件夹 dialog、记事列表 widget 配置页的文件夹列表改用 sticky-aware 排序，置顶文件夹在对应层级排在最前。
- 清理可见 UI 中对旧 `blue_deep` 和 `app_accent_representative` 的引用；系统单色边界改用 accent 起始色。
- 导出流程的 Loading/Alert dialog 也改为接收 `ThingBackground`，避免继续随机或单色 accent。

验证：

- `./gradlew.bat :app:compileDebugKotlin` 通过。
- `git diff --check` 无空白错误，仅有 Git 的 CRLF 提示。

# 主题强调色渐变第五轮修复

这次修复上一版调试包中的三个视觉回归：

- ProgressBar 改为使用视频封面裁切加载层同类的自绘方案：indeterminate loading 使用旋转圆弧和 `SweepGradient`，horizontal progress 使用自绘轨道和渐变进度条，避免系统 drawable tint/mask 导致加载条不可见。
- Checkbox 继续保留真正的 `accent -> accent2` 渐变绘制，同时恢复勾选和取消勾选的过渡动画；记事详情快速提醒和设置页 checkbox 都走同一实现。
- Chooser dialog 中的单选项不是系统 `RadioButton`，而是 TextView 左侧 compound drawable；已改为自绘渐变 radio drawable，并在选中切换时加入动画。
- 首页新建记事 FAB、统计页 FAB、关于页 FAB 增加 foreground ripple，修复渐变背景覆盖 Material background ripple 后触摸反馈不可见的问题。

验证：`./gradlew.bat :app:assembleDebug` 已通过。已通过 `:app:publishDebugUpdate` 发布到阿里云，debug update code 为 `202606211432`。

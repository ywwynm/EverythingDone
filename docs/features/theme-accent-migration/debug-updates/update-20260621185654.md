## Debug 更新 2026-06-21

### 主题强调色迁移：app_accent → accent/accent2 渐变

将 APP 主题强调色从纯黄色 (`#FFEB3B`) 替换为 Everything-Android 的 accent+accent2 渐变色方案。

**颜色变更：**
- `app_accent`：`#FFEB3B` → `#F66048`（暖红）
- 新增 `app_accent2`：`#FFAE36`（暖橙）
- 新增 `app_accent_representative`：`#FF8040`（系统限制场景降级单色）

**渐变方向：** 左下 accent → 右上 accent2

**支持渐变的控件：**
- FAB（首页创建按钮、DetailActivity 假 FAB）
- 选中模式状态栏 + 工具栏
- Settings / Help / Widget 配置页面的状态栏 + 工具栏
- CheckBox 选中态（DetailActivity + Settings 全部）
- ProgressBar 加载指示器
- 渐变文本（关于页、抽屉头部完成率、Snackbar 撤销按钮）
- SeekBar 进度条
- 图标 tint（粘性图标、文件夹图标）
- AppWidget 头部

**例外（系统 API 只接受单 int，降级为代表色）：**
- 光标颜色
- 文本选择手柄
- 边缘效果（EdgeEffect）

**暗色模式：** 使用与亮色相同的 accent/accent2 颜色。

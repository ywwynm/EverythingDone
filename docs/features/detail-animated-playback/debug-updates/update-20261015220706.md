## 详情动态媒体滑动返回及重载闪烁修复（2026-10-15）

根据用户反馈，在 OPPO `3B1629006YC00000`、三星 `R5CW20BLNKL`、魅族 `192.168.100.67:40807` 检查默认循环下视频、动态照片派生 GIF 的闪烁。用户补充闪烁接近短暂露出记事底色。核对发现首页提交 `45bc4cd5b`、`10f009c3d` 确实包含类似修复，但详情使用独立加载路径，未被覆盖。

三机复现两类异常：部分离屏时切回静态图，返回后再切 GIF；holder 回收重载时出现透明空帧。`DetailAttachmentPlaybackController` 现在将动态资源选择与是否播放分开，循环档离屏只暂停 GIF。`ImageAttachmentAdapter` 用有界的独立位图缓存补足重载占位，键包含文件身份、尺寸、裁切和视频选帧，保留标准 Glide 清理。

补测继续发现：已播放的内存缓存可能没有首帧，此时改用当前画面的独立副本；高分辨率通栏超过原快照上限时改为按比例缩小，占位缓存仍最多 8 MiB，单图最多 1,048,576 像素，不持有 GIF decoder。

最终三机网格与通栏检查合计 21,717 条媒体绘制记录，已复现场景中的空白和静态主图闪回均消除；四档播放、后台恢复、正式回收及重排检查通过。原应用数据库与设置校验和一致，测试在独立包内进行。完整 JVM 测试 1507 项，0 失败、0 错误、1 项既有跳过，正常 debug APK 构建通过。

合成媒体和三份设备现有 GIF 的连续循环均跨越多个边界，尚未单独捕获“循环结束露出底色”，不能认定所有循环闪烁均属同一原因。记录包含初版失败、内存缓存及高分辨率补测，详见 `docs/features/detail-animated-playback/flicker-investigation-2026-10-15.md`。本次发布正常包名，不包含测试媒体及探针入口。

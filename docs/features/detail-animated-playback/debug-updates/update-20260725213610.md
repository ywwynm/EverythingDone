## 繁體中文全面改用台港慣用詞

- 兩個繁體語系的文案此前是從簡體輕度轉換而來，留著大量大陸用詞。這次全面校正，共 236 處。
- 常見的例如：視頻→影片、音頻→音訊、屏幕→螢幕、文件→檔案、文件夾→資料夾、數據→資料、信息→資訊、默認→預設、設置→設定、設備→裝置、創建→建立、添加→新增、保存→儲存、應用→應用程式、用戶→使用者、菜單→選單、圖標→圖示、對話框→對話方塊、剪貼板→剪貼簿、縮略圖→縮圖、撤銷→復原。
- 台港有分歧的詞按各自習慣處理：台灣用「硬體、網路、智慧」，香港保留「硬件、網絡、智能」。
- 一詞多義的沒有一刀切：「支持開發者」保留原義，只有技術義改成「支援」；「未通過驗證」保留，只有「透過某種方式」改成「透過」。
- 順帶修掉兩個錯字：「標凖」→「標準」、「恢複」→「恢復」。

## 记事详情与全屏预览都能自动播放动态内容了

**详情页**

- **详情页的视频终于会动了。** 此前视频附件在记事卡片上会播放派生的动图预览，点进详情却永远停在一帧。现在详情附件网格里的视频也播放同一份预览，与卡片看到的是同一段内容。
- **新增设置「在记事详情中自动播放动态内容」**（设置 → 界面，紧挨着记事列表那一项），四选一：关闭自动播放、逐一播放、同时播放一次、同时循环播放。它统一管控详情附件里的 GIF、实况照片与视频，**默认「同时循环播放」**——与之前的表现完全一致，不必调整也不会有任何变化。
- 逐一播放：可见的附件按从左上到右下的顺序依次各播一轮，轮完安静下来。同时播放一次：可见的附件同时各播一轮后停下。
- 四档都只对**当前看得见的**附件生效，滚出屏幕即暂停，滚回来重新播一次。
- **不播的时候显示哪一帧**：GIF 回到第一帧，视频回到你选定的封面帧，实况照片回到画质最好的静态主图——与「关闭自动播放」档看到的完全一致。
- **长按可以手动播一遍**（关闭 / 逐一 / 同时播放一次三档下有效）。长按一下即可松手，它会自己播完一轮再停。附件多于一个时长按同时也会拿起附件用于排序，这是刻意保留的，松手即结束、不会挪动位置。
- 分享截图时所有动态附件都会冻结到静止帧，截出来的图不会抓到随机一帧。

**全屏预览**

- **翻到视频页，停稳后自动播放 3 秒真视频**（从你选定的封面帧开始，带震动反馈），播完回到静止帧。快速左右连续翻页不会起播，不会发出一串声音碎片。
- **长按继续看正片**：第一次长按从视频开头播起，松手回到静止帧并记住播到哪儿，再长按从那里接着播。想看完整视频仍然可以点中间的播放按钮交给外部播放器。
- 播放期间中间的播放按钮会让开，播完再出现。
- **补上了音频焦点**：视频与实况照片播放时会让正在放的音乐轻轻避让，而不是硬盖上去；播完音乐恢复。这一条对之前就有的实况照片播放同样生效。
- 全屏预览里视频显示的静止帧改为你在详情里选定的封面帧，与详情网格看到的一致。

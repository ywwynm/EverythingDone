## 2026-10-09 — 长清单解析性能优化

针对首页首次滑入长清单卡片时的停顿，完成三设备诊断后，按用户要求先优化首页与记事详情等界面共用的清单解析。

- `CheckListHelper.normalizeLevels` 改为单次顺序扫描，消除逐项反复查找父项导致的二次增长；一级项查找父项直接返回。
- 解析完成区起点时直接判断已归一化的一级完成项，避免大量已完成子项造成重复扫描。
- 保留层级、孤儿项修正、完成状态、控制行、组迁移及文本转换行为，详情编辑与组件仍使用完整且独立的可变解析结果。分隔符字符及存储格式不变。
- 将固定格式分隔符从 Android 资源移为代码常量，让共用解析可直接进行 JVM 回归，不依赖应用初始化。
- 17 项回归及 debug 构建通过，包含 8,000 组新旧算法对照。148 项诊断结构中，层级归一化的列表读取由 18,865 次降至 148 次。
- 本次未调整流体、飘散的粒子预热。访问次数下降不能直接换算为掉帧改善比例；新包的手机滚动表现仍需更新后验证，卡片行创建与布局成本也尚未优化。

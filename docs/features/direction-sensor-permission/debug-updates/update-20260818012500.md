## 画面不随设备倾斜时，四处都会给出提示

部分系统在应用回到前台后的数秒内会在系统侧过滤设备方向数据，此时画面无法响应倾斜。此前只有
录音对话框在系统音频授权返回后提示过一次，现在四处全部覆盖，且判断方式与"用什么动作回到前台"
无关：注册方向传感器成功后 1.5 秒内一个数据都没收到，即视为当前不可用。

- 录音对话框：提示出现在对话框内的提示区，排在所有录音故障提示之后；数据恢复即自行消失。
- 音频附件播放对话框：新增同款界内提示区。
- 音频海浪动画设置：「画面响应设备倾斜」下方出现说明；上方预览恢复响应后说明自行消失。
- 空间照片：提示为一次性提醒，同一次安装最多出现一次。
- 空间照片效果设置：「倾斜控制视点」下方出现说明；从系统设置改完权限返回即消失。

两个设置页的说明里，「系统设置」四个字可以直接点击前往系统权限页面，并按当前强调色着色
（海浪动画设置跟随记事颜色，空间照片设置为主题渐变）。相应选项不会被置灰——权限处于"仅开屏时
不允许"这一档时，功能在稍等之后仍然可用。提示文案统一为一条，覆盖 13 个语言地区，不出现任何
厂商名称。

**录音的倾斜轨迹不再用假数据填充开头。** 录音开始时若尚未取到任何真实方向数据，此前会把开头
记为"竖直"并永久写入音频文件，导出的视频开头因此是错的。现在改为不写入假数据，开头按第一个
真实姿态回填。

**其他。** 移除旧的一次性提示状态；音频与空间照片的提醒状态分开保存，一处看过不再影响另一处。
音频附件对话框的提示不会再把对话框撑宽。新增 10 项门控单元测试，全量 921 项 Debug 单元测试
通过；OPD2515 上按"允许 / 仅开屏时不允许 / 禁止"三档权限逐一实机验证，含提示出现、自动消失
与零误报。

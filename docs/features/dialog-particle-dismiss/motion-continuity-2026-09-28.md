# 连续粒子运动诊断与修正（2026-09-28）

## 问题与原因

用户指出向上钢铁侠、内部起点等序列中，内部材料反复左右摆动、挤压后弹出，多个区域换向时刻接近。固定材料编号的 GPU 读回证实：基础积分并没有这种程度的回摆，后置的时变位置映射显著增加了往返。每一帧保持正空间雅可比，只能限制局部翻转，不能保证材料沿时间连续流动。

## 本轮采用

保持一份全序列共用的输运网络，离线校准同时考虑华为原片和真实 GPU 材料路径。对路径上的修正加速度、逆风速度和多余横向往返加约束；密度函数保持精确一致。运行时仍读取普通共同权重，不读取材料轨迹、参考帧或逐素材输出。

进一步检查发现：只限制加速度，仍允许缓慢而平滑的回摆。现直接削减后置映射相对于基础积分新增的横向总路程减去净位移，不要求把基础积分中的卷曲压成直线。仅限制“不比当前更多”的候选形状收益很小，未采用；当前采用实际往返目标更低、且另相位复核通过的共同候选。

用于校准的路径由同一材料年龄差恢复内部时钟，避免把页面进度误作求解时间。未采用整体压低卷曲、仅随机错开摆动时刻、或简单把原场投影成低阶时间函数。后两类直接平滑会损伤形状，尤其是旧钢铁侠。

母片中心不能覆盖所有细分颗粒的运动，因此另对旧钢铁侠、向上和内部起点抽取固定母片及九份子片，读回细分后的实际中心。三段本次抽样的相邻高速向量反向事件分别为 0、0、4 次，前一连续运动版本分别为 1、0、6 次；短区间内的往返总体减少，例如向上参考进度 0.35～0.60 的 90% 分位由短边的 2.403% 降至 1.322%。这三段的逆风采样比例均有小幅增加，不能把补充检查称为所有颗粒全面改善。完整 0.30～0.70 区间的始终可见子片样本很少，故不依据它给出总体结论。

十二段实际 GPU 回归中，基础状态、密度函数、首尾帧与随机访问回放均保持一致；原始图像仍只作离线参照。

## 结果边界

内部侧摆明显收敛，但向上钢铁侠的亮弧、灰细颗粒、部分表面交接仍有差异。固定密度的运动修正使部分静态误差略升；完整导出报告必须保留这些退步，不宣称各项一致性都提高。继续优化材质时，也需要检查同一材料沿途的明暗变化，防止出现只在静态误差上更好、连续播放却更机械的结果。

十二段连续路径约束的最终导出包含 68 个视频、34 对速度，指纹为 `75f4d950e6798277466e7c1925533b4556755f64beab5798bcb1ae86f1661c56`。十段可靠背景、733 个独立帧的等权平均 σ4 增加 1.47%，十段均略升；σ1 增加 0.83%，颗粒能量差增加 1.55%。这轮改善的是连续运动，不是静态图像匹配。两段背景不完整的参考不计全背景误差。文件身份、速度、帧数、HTTP 访问及三段完整解码通过；已从编码成片再次抽取内部起点、向上、旧钢铁侠和科比的整幅手机画面复看。五段连续约束的中间版指纹 `0936695376c333e573d7d0e791dc113d7144742de00f438dbf59142b21db9bc4` 已被取代，不再作为当前预览。

## 扩充连续路径检查

五段参与连续路径校准的材料检查不能代表全部十二段。补查其余七段后，中间候选的科比和新 6 多余横向往返中位数仍分别为短边的 2.935% 和 2.750%。因此保持同一共同函数和完整图像目标，把十二段实际路径全部纳入连续约束。当前 `all-material-return` 已经过实际十二段路径、七段另五相位原片对照、十二段运行及数值检查，替代中间候选；数据见上表。仍保留旧蜘蛛侠逆风比例上升和少量反向事件的记录。

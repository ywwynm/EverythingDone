# 逐帧外观与输运误差优化

以已发布的前沿衔接版为本轮冻结基线。先建立完整相位序列的像素误差、低频覆盖误差及表面退出测量，分开定位释放时序、速度场与颗粒显色的贡献。诊断使用参考视频，正式模型仍只接受几何、触点、种子和材料输入。

前一轮八个相位的整帧低频误差仅从 7.406 降至 7.387，不足以说明整体接近一致。本轮不能继续用单个局部测量代替完整画面与连续播放。

初次 61 相位诊断确认，稳定背景的原始 RGB 平均误差约 1.6/255；主要误差集中于动画区域。保留原始帧和直接差异，没有通过改变参考配准、相位或裁去问题区域改善结果。系统时钟、外部水印变化显示于原始差异，但不进入动画区域的量化统计。

高频源纹理相关性测量显示，各位置的退出时序偏差方向不同。直接把这一代理量反写为出生时刻，会使右上粒群提前突出，完整外观反而下降，不能把代理误差降低等同于动画改善。增加全局反光同样没有改善完整过程，已排除。

已对共同输运、寿命、细化与交接参数做有限范围消融；较慢的中后段细化及更完整的颗粒寿命有助于覆盖。下一步使用共同归一化场上的 25 个宽尺度形状系数校准释放布局，不加入人物名称、源图内容判定或逐帧遮罩；修改还需用未参加参数选择的相位、素材和方向验证。

重新估计运动使用 [OpenCV DIS 文档](https://docs.opencv.org/4.13.0/de/d4f/classcv_1_1DISOpticalFlow.html) 所述的密集匹配，并增加前后跟踪一致性检查。替换整个观测场的额外收益较小，目前未采用；光流也不能证明压缩录屏中的单粒子对应关系。

最终候选保留原有场，在同一归一化空间叠加宽尺度、连续的释放与速度修正；时间方向只有平滑包络及一次斜率，没有逐帧轮廓表。寿命增量与较弱的额外剥离共同改善中后段覆盖；细粒间距、反光与基础明暗通过局部对比度再校准，降低过亮密点，而不是新增亮线。各方向、触点距离与随机起点继续通过同一坐标和时钟变换作用于这份共同场。

在 0.20～0.80 的 37 个相位、固定动画区域中，正式量化前的最终候选原始 RGB MAE 从 14.869 降至 14.409，σ=2、6、12 的结构误差分别从 8.130、6.431、5.485 降至 6.844、4.944、3.977。不能把这些误差下降换算成视觉相似度，更不能声称单粒子已像素一致。模型输出仍需在半精度共享资源量化后重新核验。

共同资源和着色器已写入桌面及 Android，正在进行正式导出、双设备独立建材与渲染、真实关闭及发布检查。生成依据保存在轻量的 `tuning-0909-gpt6/analysis/common-shape-calibration.json`，参考帧、差异图、消融结果和原始缓存位于忽略区。

跨端校验先拦截了校准场外侧的少量负释放时间。保留 Android 对合法时刻的检查，在生成共同资源时将释放时刻约束到有效范围；没有放宽验证条件。重新导出后 14 项 JVM 检查、两台设备 12 组独立建材与 GPU 对照均通过。

对量化后的正式模型再次核验全部 61 相位，并扩大到包含顶部粒群、设备边缘及下方拖尾的完整动画区域。未参与参数选择的相位中，原始 RGB MAE 从 10.436 降至 10.282；σ=6 的结构 MAE 从 4.560 降至 3.680，约下降 19.3%。完整区域的改善小于局部校准区域，按完整区域报告，不能掩盖仍然存在的颗粒位置差异。原始像素误差的下降幅度仍小，尚未达到单粒子像素级一致。

18 个实际近、中、远输入的速度和位移递增通过；234 组已有边界问题输入的状态复核通过，没有新增停滞窗口或主方向反弹。没有重新渲染 226 组标注视频。两台指定设备均已完成真实近、远、返回关闭与层清理，回到主列表；正式发布前继续完成视频及 APK 身份核验。

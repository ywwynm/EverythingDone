# 2026-09-09：保留 r29 轨迹，优化彩色材料

用户确认 r29 钢铁侠的改善不错，要求继续优化。已归档 r29 的代码、参数、三主序列无损渲染帧和视频清单。所有试验图、缓存与代码继续位于 `docs/features/dialog-particle-dismiss/tuning-0909-gpt6/`。

## 本轮试验和取舍

- 按早、中、晚三段释放时间拟合少量侧向速度、顺风速度和寿命系数，科比局部误差下降，但灭霸在另选时刻反而略退步，形态收益也不够明确。没有将这些校准参数写入运行素材。
- 将材料单元从 2.35 px 减到 2.0／1.8 px，没有稳定改善整体表现，增加的粒子数量也不是本轮剩余差异的主要原因，保留原粒数。
- 彩色材料在细化后失去辨识度，是科比黄色／蓝色粒群较弱的一个因素。适度保留这部分微片的面积和寿命，并减轻材质照明中的白色混入，比整体加亮或延长全部粒子的寿命更稳定。

## r30 候选

- 完全沿用 r29 的释放场、速度积分、风向与随机运动；源色只参与可见性和材质，不参与力或轨迹。
- 以源像素通道最大值与最小值之差作为色度权重，0.30～0.72 平滑过渡；高色度材料的寿命最多增加 30%，仍受原来的统一结束时刻限制。
- 高色度材料仅在释放后的短时间内保留更多面积，线性尺寸最多增加 20%，随后回到原有细化过程。白色本体不增加面积。
- 运动材质按颜色差异减轻白色混入，保留来源色彩；不改变未释放内容，不增加光晕。

此方案不能单独解决科比中段的整个卷束形态。复核后保留这组材质参数：彩色粒子的可见性有所增强，白色本体没有被整体增厚，几何面积与寿命的变化仍随同一释放过程发生。

## 已完成的复核

- 七场景共 3,478,594 个完整材料状态与 r29 逐值一致；释放时间、初速相关随机数、阻力和速度积分均不变。无色度权重材料的寿命逐值一致。
- 七场景各十个方向、120 Hz 的实际材料中心检查通过：147,720,443 对处于相邻生命期的样本，没有逆向主向步长，最小步长 0.17871 px。
- 初始内部像素、未释放内容位置、最终背景、回退重算和不同采样方式检查通过；七场景总览已检查，桌面预览程序已离屏运行。
- 钢铁侠仅约 0.91% 的材料具有非零源色色度权重，平均寿命比为 1.00007；科比约 69.22%，平均寿命增加约 9.92%。因此本轮主要差异应在科比和有色控件中判断，不能把钢铁侠微小的颜色误差变化称为明显形态改善。
- 新旧版本和参考在同一 120 Hz 时刻比较，消除了归档取整时刻与实时采样之间的偏差。六个时刻的低通颜色误差为：钢铁侠 3.086 → 3.077，灭霸 3.264 → 3.213，科比 4.564 → 4.335。仅为诊断；科比约 0.72／0.88 的分布误差仍略有增加，尾部位置仍需继续改进。

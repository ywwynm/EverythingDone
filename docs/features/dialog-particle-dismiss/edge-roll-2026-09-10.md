# 局部卷动与非周期细缕

**最新反馈：用户认可“观测运动控制组”的形状已接近参考，要求以此继续优化并推广到其他消逝位置。下面此前“未通过、退回稳定版”的结论记录助手当时的判断，不能覆盖本次用户认可。强涡、整体翻折及周边提前释放仍属已否决试验。**

## 本轮问题

用户认为统一模型仍缺少钢铁侠参考及此前拟合版本的卷曲感；现有细缕形状相似、平行且等距。先对照三个阶段的可见运动，核实湍流卷吸、惯性颗粒浓集及影视体积特效的控制方式，再修改统一模型。用户关于边缘成缕的判断作为研究问题，不预设为物理定律。

代码初查发现当前流管由单一横向周期相位驱动，即使对相位作少量扭曲，吸引线仍继承重复拓扑。该汇聚横跨整个粒群，未区分边缘与中心；它还会把原流场的侧向速度较强地混合到共同流管方向，可能削弱局部卷动。需结合实际帧和对照实验确认贡献。

保留上一发布版的原始帧和源码用于审阅；本轮继续共用规则，保持内容色份额与返回左上，桌面确认后同步 Android 并按已有授权验证两台设备。大型材料与证据均放在本功能实验目录的忽略区域。

## 重点观察与当前假设

用户进一步指出钢铁侠 0.35～0.65 的左下弧形粒群边缘由上凸转为下凸，并有相伴亮边。本轮将其设为核心视觉标准。已逐 0.05 保存原片该段和局部裁切；画面中的地球对角亮弧属于背景，不能计入粒子亮边。

已观察到轮廓翻转及较亮、较密的窄带一起变化。尚不能仅凭二维参考证明亮带始终由相同粒子组成，也不能判断华为的实际算法。工作假设是连续释放的材料受相关速度场输运，形成卷折或追赶压缩；投影覆盖增加使已有源色形成亮边。渲染不应直接画亮曲线代替材料运动。

对照实验确认：只加大随机涡旋会产生细尖喷出，不能补上大尺度弧边；统一版部分左下区域比原片估计释放时刻晚约 0.10～0.22，而参考估计本身不是精确粒子出生真值。三份参考释放场直接求均值也会过早破坏面部，应弃用该候选。参数试验仅保存在实验脚本，尚未同步 Android 或发布。

## 本轮补充研究

下列为实际阅读的原始论文或官方说明。物理解释与界面特效的设计选择分别记录；不把“边缘成缕”写成普遍定律。

| 来源 | 有价值的结论及本轮用途 |
| --- | --- |
| [Bridson 等：Curl-Noise for Procedural Fluid Flow](https://www.cs.ubc.ca/~rbridson/docs/bridson-siggraph2007-curlnoise.pdf) | 对连续势函数求旋度能避免任意噪声速度的汇点问题；空间调制应在势函数上进行。用于去掉统一周期流管。 |
| [Barnat、Pollard：Smoke Sheets](https://www.cs.cmu.edu/afs/cs/user/abarnat/www/smoke_sheets.pdf) | 相关材料薄层能保留薄片及卷边；面积变化和视线与面法线夹角影响投影吸收。启发卷动与密度表现耦合，不能据此认定参考是烟雾仿真。 |
| [Wavelet Turbulence 作者项目](https://www.cs.cornell.edu/~tedkim/WTURB/) | 大尺度运动与小尺度细节应分开控制，并保持细节随流运动的时间连续性。 |
| [SideFX：Pyro Solver](https://www.sidefx.com/docs/houdini/nodes/dop/pyrosolver.html) | 大尺度翻卷、小尺度扰动、切碎及涡度保持用途不同；不宜靠增大同一个噪声参数解决全部问题。 |
| [SideFX：Gas Shred](https://www.sidefx.com/docs/houdini/nodes/dop/gasshred.html) | 梯度与控制场可以局部化拉伸。用于让细结构更多出现在实际粒群边界。 |
| [SideFX：Gas Disturbance](https://www.sidefx.com/docs/houdini/nodes/dop/gasdisturb-.html) | 局部速度扰动用于打散过于规则的表面，不承担整体运动造型。 |
| [SideFX：Pyro Disturbance](https://www.sidefx.com/docs/houdini/nodes/cop/pyro_disturbance.html) | 连续噪声、分块噪声及旋转速度有不同结果；控制域可避开空区域。 |
| [SideFX：Gas Vortex Confinement](https://www.sidefx.com/docs/houdini/nodes/dop/gasvortexconfinement.html) | 增强已有涡度，补偿耗散；并不意味着应人为放置等距细缕。 |
| [SideFX：POP Axis Force](https://www.sidefx.com/docs/houdini/nodes/dop/popaxisforce.html) | 旋转、轴向输运、吸引与阻力需要分别控制；本轮保留整体前进约束。 |
| [SideFX：POP Advect by Volumes](https://www.sidefx.com/docs/houdini/nodes/dop/popadvectbyvolumes.html) | 直接位置推进、目标速度和力不能重复计算；固定积分频率与阻力影响轨迹稳定性。 |
| [Cencini 等：Heavy inertial particles](https://arxiv.org/abs/nlin/0601027) | 惯性重颗粒可能避开强涡丝而优先浓集，不能用“所有颗粒都吸入涡心”解释细缕。 |
| [Holzner 等：Turbulent/non-turbulent interface](https://arxiv.org/abs/0705.0675) | 界面的应变与涡度结构有差异；边界附近采用不同尺度的运动有依据，但仍须看具体材料。 |
| [Episodic entrainment in a turbulent jet](https://arxiv.org/abs/1907.05421) | 卷吸具有局部性和间歇性，不会沿整个界面等距、同步发生。 |

当前桌面候选增加 128×128 的可见运动材料密度场，排除尚未释放的面板和颜色表现副片。实际密度梯度用于区分边缘与中心；宏观翻卷仍在验证，不能把“已消除平行条纹”当作本轮完成标准。

## 用户红线澄清后的纠正

用户提供两张红线标注，指出需要重现的是密集粒子边界的变化，并认为可能来自粒子涌入、输运及外力或场随时间变化。此前把“上凸转下凸”过早解释成整片材料旋转或翻折，导致试验形态偏离，用户明确认为越来越怪。该解释没有得到参考证据支持，应撤回。

已将这一轮密度场、薄层旋转和大涡试验归档为失败实验，正式桌面 `renderer.py` 与共享规则恢复到上一稳定发布版。后续先配准两张用户截图，读取红线坐标和对应视频时刻，测量边界不同位置的位移及可靠光流，区分旧粒子输运与新粒子补入。不得再用孤立的凸凹翻转证明整体卷折，也不把两张轮廓当作单个粒子的轨迹。

## 红线实测

脚本 `tuning-0909-gpt6/analysis/measure_reference_rim.py`；截图副本、配准图、坐标、前后跟踪和误差保存在忽略区 `analysis/edge-roll/redline-measurement/`。

- 两图配准到原片约 4.867 s、6.133 s，即当前画廊归一化进度约 0.311、0.554。与用户给出的 0.35～0.65 一致地覆盖关注段，后续按实际截图匹配，避免错用时间刻度。
- 以 720 px 宽原片坐标计算，中段对端点连线的偏移从约 −55.8 px 变为 +23.8 px，确认弧向变化；这不是颗粒对应关系。
- 早期红线 47 个样点沿相邻视频帧光流推进，每步前后误差均小于 0.8 px；到晚期红线的单向中位距离约 2.4 px，但反向覆盖距离中位 12.8 px、90 分位 65.7 px。旧边界只覆盖后来边界的一部分，原左下竖段仍拖在下方，**并没有整体翻转成新红线**。
- 反向推进晚期红线的 80 个样点，78 个通过同一误差筛选，其中 46 个回到早期图像中与源纹理较接近的位置（RGB 均方根差 <20/255）。与可见的后续释放相符；压缩录屏与光流不能证明单个粒子身份，不能把 46/78 写成精确新生粒子比例。
- 更有依据的模型是：旧粒子向左上输运，后续材料不断补入密集带；各位置释放速度、颗粒年龄和局部流速不同，共同改变可见边界。仅凭轮廓不能证明外力必须随时间反向或突变。

[Fedkiw 等《Visual Simulation of Smoke》](https://graphics.stanford.edu/papers/smoke/smoke.pdf)分别处理速度、密度输运与外力，并指出随意加入旋转细节可能产生不自然的自发运动。本轮只借用分开控制输运与密度的思路，不宣称实现完整烟雾求解器。

## 完整区域约束优先

用户指出后续试验在 `t=0.43` 提前粒子化大量左边缘、上边缘，而原片这些位置除左上角外基本完整。沿周边加快释放、按到面板边缘距离整体提前释放，都没有本段参考证据支持，已否决；这些候选仅在诊断进程中使用，未进入共享资源或 Android。

下一步应先以源纹理仍然完整的区域为硬约束，对齐右下侧局部粒子化的范围和节奏，再评估粒子输运。红线不能作为反向驱使任何区域提前释放的形状目标。正式桌面及 Android 继续保持上一稳定发布版，不发布这些候选。

### 完整区域实测与防回退检查

新增 `analysis/check_source_regions.py`，分别保存参考画面、源纹理保留代理和正式释放场，覆盖 0.31、0.43、0.55、0.65。测量使用局部源图与背景的对比度，剔除低对比区域；不能把纹理差直接叫作精确释放真值。

- 钢铁侠在 0.43 时，左侧中段有效纹理窗口中约 78% 仍接近源图，上侧中段约 87%；右下区域该比例不足 1%。左侧窗口仅约 55% 有足够前景背景对比，故上述比例不代表整条边缘的真实粒子数。
- 恢复后的连续释放场在相同左、上窗口分别保留约 79%、94%，没有采用失败试验中沿整个周边加速释放的规则。脚本另检查真正建材后的随机出生时刻，防止随机展宽重新大幅提前破坏这些区域。
- 科比原片的源区域变化与钢铁侠不同。这项具体时刻检查只验证钢铁侠输入，不能扩写成所有素材在相同方向下必须保留同样的面板边缘。

### 固定释放源的控制实验

`reference_transport_control.py` 与 `observed_transport_reconstruction.py` 仅隔离“参考释放近似 + 不同输运”的影响；其中读取参考专用拟合或逐时刻光流的部分属于观测控制组，**不得包装成通用模型、纳入 Android 或发布**。

检查结果尚不足以重现目标亮边。按释放梯度直接计算年轻材料速度的试验在右侧产生空洞，已否决；沿周边提早释放、强涡、整片翻折的试验同样不再采用。参考速度采样筛掉慢速材料、释放近似与可见解体之间的时间差，仍是待验证因素，不能据此认定唯一的物理原因。后续必须保持完整区域约束，分开核对释放量、输运及粒子可见覆盖。

本轮没有新的视觉达标结论，没有移植、操作设备、发布或提交。

# 弧边曲率、沿边流动与可见的近远差异

用户在上一轮发布后再次指出横向弧边弯曲及粒子流动不足，近中远仍不明显。原截图沿用更早页面的标题，不能据此推断用户只是看了旧缓存，也不能否定反馈。本轮同时核对实际页面和最终文件，在最新模型上继续诊断。

固定初版钢铁侠 122°、种子 909602，观察 0.4～0.65 的弧边与拖尾；近远保持同种子、实际屏幕内触点及相同比例。先验证速度平滑对弧边相对流动的影响，再隔离新生材料覆盖与整体输运，最后检查六格缩小后的辨认能力。数值只能帮助定位，不能替代同速播放。

## 隔离结果与设计选择

加快阻力响应、降低最低顺风速度、加强现有流场的横向速度，均只产生小幅变化；移除叠加风也没有恢复足够的弧度。因此不采用这些调整。原有流场及释放场继续保留。

局部解除边界的法向速度会明显改变结果：材料先向已经解除的一侧展开，继而随共同流场输运，在连续新材料汇入时，横向边缘逐渐弯出，下方较早释放的拖尾仍保留。该速度仅在出生后生效并随年龄衰减，不提前解除左边及上边尚完整的区域；也不按钢铁侠的坐标或名称添加局部力。

这里借鉴的是通用粒子制作方法，不声称还原了华为源码。Houdini 的[发射方向文档](https://www.sidefx.com/docs/houdini/vellum/fluiddirection.html)展示了以源法线控制初速度；[POP Drag 文档](https://www.sidefx.com/docs/houdini/nodes/dop/popdrag.html)说明目标风速和阻力决定粒子向流动速度靠拢的过程。本实现把解除边界法线用于短时展开，随后交还已有共同流场。

近远对照还暴露出原先直接乘局部场速度的问题：不同速度使粒子进入不同场位置，稠密边缘会被局部流动重新压到相近位置，数值不同并没有稳定转化为可见轮廓变化。尝试额外共同顺风位移后，较老粒子虽移动更多，新生的亮边仍接近，且容易改变默认参考的弧度，未采用。

当前候选改用相对各自出生位置的运动幅度：共同流动在材料坐标中积分，再以真实触点的背景距离比例同时换算实际位移和实际速度。默认输入系数为 1，近点约 0.6～0.7、远点约 1.4；释放、寿命和时长不变。实际状态保存换算后的坐标和速度，测试直接读这些状态。每片仍走自身连续曲线，不向目标点收敛；近中远画面中的角度、随机输入、大小、相位相同。

证据保存在 `tuning-0909-gpt6/analysis/rim-flow/`。最终选择的展开系数为 1.5，按颗粒随机值变化 ±12%，约 0.16 秒衰减；距离幅度为 `0.55 + 0.90 × 触点相对背景距离`。出生、寿命、释放场及共同速度表均未改变。

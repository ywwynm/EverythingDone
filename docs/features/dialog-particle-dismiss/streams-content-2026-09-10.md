# 共用模型的卷曲、成缕与内容色

## 反馈和实现边界

用户试用后希望看到钢铁侠式卷曲聚散、灭霸式细缕粒子流，并提高自有弹窗中非面板色的粒子份额；返回键改为左上消逝。继续使用素材无关的统一模型，保留真实触点方向、未释放表面的完整性与主方向不倒退约束。

原模型的随机分离较强，而综合引导场会平均不同参考的局部流向；高饱和度加权也不能识别灰字、深色面板上的浅字。当前改进分为连续运动组织和材质分配两部分：沿共用弯曲流线产生汇聚与受控卷动，末段再解耦；从源快照估计占主导的面板色，仅对与其不同的内容生成额外微片，初帧仍由原始密铺表面构成。

运动设计参考 [SideFX POP Curve Force](https://www.sidefx.com/docs/houdini/nodes/dop/popcurveforce.html) 对沿线、向线、绕线三种力及阻力衔接的区分；本项目使用程序化连续场，不读取人物专用轨迹。返回路径核对 [Android 预测性返回文档](https://developer.android.com/guide/navigation/custom-back/predictive-back-gesture)，沿用 ComponentDialog 的返回分发与可取消语义。

## 已确定的实现

- 共用弯曲流场加入横向汇聚与绕轴速度，深度也通过速度积分产生；释放后短时保持邻域相干，约 0.18～0.34 秒解除汇聚。第一轮过细的条纹尾段已放松，主向速度下限继续保留。
- 从不透明快照的主色簇估计面板，颜色通道置换不影响分类。内容色按与面板的色距连续加权；每格最多两片副片，副片跟随父片释放后逐渐显现，不在静止表面叠加。总材料数限制为 16 万。
- 返回键及完成的返回手势通过 ComponentDialog 的返回分发获得左上 45° 虚拟触点，先清除最近抬手记录；随后仍调用既有 fallback，保留不可取消及取消回调行为。按钮和外部真实触点保持原方向，无触点的其他代码关闭不在本次方向变更范围内。
- 初次冻结后新增咖啡照片、有色面板两个输入，旧六个留出素材在本轮作回归；不将它们重复计作全新素材。随后语言开发场景暴露低透明度直通颜色量化差异，内容权重改为乘实际覆盖率，并重新冻结为 `fec0aedeff5385b16ae0c414729138ff99931099a36b61e6a04f17a73fbf3d09`；未根据两个新素材调参，初次冻结记录独立保留。
- 15 场景的名称／专用配置独立性、颜色通道置换、起止帧及重播确定性通过。Android 与 Python 的边界尺寸除法曾因 Float 转 Double 多出一列，已改为按同一十进制网格尺寸计算；跨语言材料测试与编译通过。
- 双设备分别从 PNG 独立生成 15 组材料，30 组 GPU 对照通过。新内容权重不再放大低透明度颜色量化；总材料数及全部材料身份、随机值保持两端一致。逐帧轨迹覆盖每个输入的十个方向。

# 2026-09-09：在 r28 基础上继续优化

用户评价 r28「这一版好多了」，要求继续优化。已保存 r28 的三主序列原始渲染帧、代码、释放／速度参数与视频清单，作为本轮对照基线。归档和所有试验产物均在 `docs/features/dialog-particle-dismiss/tuning-0909-gpt6/`，本文只记录结论。

## 试验中确认的限制

- 均匀降低随机分离、提高旋度，不能单独形成参考中的弯曲密集边缘。
- 整体增大粒径、增加白色照明或延长寿命，会让钢铁侠和灭霸中段变厚。科比的局部改善不能抵消这两个场景的退步，未采用这些方案。
- 周期性的侧向汇聚能产生真实位置密度差，但会出现过于规则的平行条纹，未采用。
- 大幅反转分界线法向输运也没有获得可信的形态改善，未采用。
- 提前科比左侧释放并延长早期寿命，仍未解决其参考中段的完整卷束；没有把该局部时间修补写入交付参数。

## 当前收敛方向

1. 仅削弱与主风高度同向的分离冲量，避免钢铁侠左上粒群过早扩张；保留横向展开。
2. 减小过强的随机分离和后续风速增益，维持 r28 的连续前进。
3. 微片先保持局部姿态关联，再逐渐独立转动；较老的颗粒进一步细化，改善尾部颗粒残留。

除明确标记的释放时间／寿命试验外，均采用相同素材、释放场和随机种子。低通颜色误差只作为分布与残留诊断，不当作主观相似度。

## r29 的具体改动

| 项目 | r28 | r29 |
| --- | --- | --- |
| 释放后的主风增益 | 最高增加 42% | 最高增加 24% |
| 短时随机分离速度系数 | 0.60 | 0.48 |
| 局部侧向转动速度系数 | 0.65 | 0.32 |
| 高度顺风的分离冲量 | 全量叠加 | 按法线与风向夹角平滑削弱，最多削弱 75% |
| 独立转动渐入 | 粒龄 0.024～0.22 | 粒龄 0.08～0.28，前段保留局部法线姿态 |
| 老化后的尺寸减少 | 最多 22% | 最多 36% |

时间均为 1 秒模型中的归一化粒龄；调节以释放后的材料为对象。未释放内容的几何和纹理不变，没有加入会衰减归零的位置平移。

## 验证与仍有的差异

- 七场景初始内部像素与来源一致，末帧与背景一致，误差均为 0；回退重算、不同采样方式逐像素一致，未释放材料位移为 0。
- 七场景各十个方向、120 Hz 的材料中心检查通过：145,431,178 个相邻生命期样本，无逆向步长；最小主向步长为 0.17871 px。钢铁侠固定左上材料群的中途最大回退为 0。
- 六个另选检查时刻的低通颜色误差：钢铁侠 3.375 → 3.090，灭霸 3.342 → 3.275，科比 4.659 → 4.576。不是主观相似度，也不是独立数据集盲测；科比 0.24 时刻略退步，未掩盖这一点。
- 形态上的改善以钢铁侠过早扩张收敛最明显；科比 0.48～0.64 的黄色卷束仍不足，灭霸局部密集区和尾部色群比例仍与参考不同。没有以整体误差下降声称已接近完全匹配。
- 桌面预览程序已离屏运行通过；三个主序列阶段图、七场景总览、三个八方向同屏封面均已目视检查。

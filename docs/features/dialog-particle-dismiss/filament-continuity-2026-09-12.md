# 孤立尘缕回归与共同模型连续性

用户指出逐帧校准版在钢铁侠约 0.67 的主体右侧出现细长、孤立的粒子尘，真机不同方向也可见，而前一发布版本没有。先固定当前种子与相位复现，比较逐项恢复寿命、释放布局、流场修正和剥离力的结果，再定位产生细缕的源材料与流动过程。

整体像素误差下降不能抵消新增的显眼结构瑕疵。本轮需单独记录孤立分支的产生与存续，并联合检查完整画面和既有卷边；诊断区域只用于测量，不进入运行端规则。

固定相位回溯到 570 个可见材料样本，主要来自原控件右侧较早释放的区域，出生中位时刻约 0.21、年龄约 0.457、寿命约 0.585。寿命使用的随机量同时进入速度增益与局部卷动采样，导致长寿命材料偏向较慢且相近的运动。该群体随机量中位数约 0.081，明显低于全部可见材料的约 0.352。

分别恢复旧寿命、流场、释放、剥离、输运强度和采样密度后，确认寿命延长会显著放大该问题。仅解除寿命与输运随机量的关联，标记区域多余覆盖约减半；联合调整早期材料的寿命分布后，约减为原来的四分之一。未按屏幕或素材区域删除粒子，原共同场和卷边保留。接下来以完整画面、颗粒对比度及该反例共同约束参数，避免仅降低平均结构误差。

候选已选定：输运使用独立整数哈希随机量；寿命增益由出生时刻连续从约 0.667 过渡到 0.967；在原宽尺度共同场上小幅调整释放与速度系数，原始屏幕边界不参与运动截断。早期片不再长期滞留在慢速流线，后续片仍有足够时间维持卷边。粒径改用温和的对数正态分布，保持平均平方尺度接近原值，增加细粒和少量较大片的层次；没有追加亮边或提高整体反光。增强调亮的实验没有稳定改善，弃用。

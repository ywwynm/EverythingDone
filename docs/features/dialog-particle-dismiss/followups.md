## 2026-08-30 复测后仍存在的二阶差异（未拟合）

以下两项在同口径对照中仍与参考有距离。它们不影响主要观感不变量，本轮
刻意没有继续拟合，避免重新堆叠专用机制：

- **最后残留区域的位置**。参考 `corr(释放时刻, 到最近边缘距离) = +0.244`，
  最后消失的是内部偏左的一块；当前模型为 `−0.495`，最后消失的是离主核最远的
  那个角，形态上更像一条贴边的窄条。要改需要让释放场的最大值落在内部，而
  自归一化构造（主核到最远角定义相位 1）依赖最大值在角点。若要做，可在
  相位上叠加一层"边缘提前"并按解析已知的最大值点重新归一化，代价是新增
  两个常量和一处推导。
- **释放场的空间频率**。参考 50% 方差在 ≥0.98 卡宽的尺度，模型为 0.58；
  线性斜坡 R² 参考 0.258、模型 0.437。即模型比参考更"定向"、更接近单向扫描。
  减小主核偏移可以缓解，但会削弱方向跟随触点的观感。

另外，`make_reference_comparison.py` 依赖微信临时目录里的参考原片；该目录
会被清理。若需要重建参考列，须先把原片另存到仓库外的稳定位置并更新
`REFERENCE` 常量。

- **早期密度亏空**（2026-08-30）：浓区占比在 n=0.30 上 0.090 vs 参考 0.182。对应释放
  进度偏慢（迎风累计 0.11/0.34/0.59 vs 0.17/0.48/0.68）。需要加快释放场早段的推进，

## 前沿起伏的幅度仍比参考低 34%（2026-09-02）

逐帧实测：参考的相干起伏 sd 是 0.1197，我们是 0.0786。已排除的原因：直方图均衡
（减弱反而更差）、幅度不够（加大会饱和）、量程余量（缩小会让十分位崩到 0.025）。

这是「一条斜坡 + 有界噪声」这个形式的结构性上限：噪声要同时满足不折叠（沿飞行轴
的变化率小于斜坡斜率）与不越界，两条约束一起把幅度锁死。要再提高，得换一种前沿
表示——例如把前沿显式参数化成一条随时间演化的曲线，而不是从标量场取等值线。

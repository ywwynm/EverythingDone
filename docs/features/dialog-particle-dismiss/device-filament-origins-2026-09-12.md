# 真机早期孤立细缕的重新诊断

用户提供三段添加附件弹窗录像。细缕在面板大部分仍完整时即出现，呈细长斜线或弯月形，之后仍可延续到后段。因此上一轮钢铁侠 0.667 相位的窄区域检查不能证明问题全面解决，寿命修正只处理了一个后段反例。

已保存原始视频和发布模型，提取完整画面及逐帧检查图。原录像随机种子无法从指定设备现存日志恢复；离线使用相同面板与背景，搜索接近录像释放布局的固定种子，明确作为同类结构复现，不声称逐粒子重放。

三个独立消融结果：关闭局部剥离力，细缕消失；仅平滑共同流场或移除主要引导流速，细缕仍然存在；调整表面交接同样不能消除。接下来追踪局部法向、出生年龄与速度响应的关系，修正剥离过程，不通过固定屏幕区域删除或遮挡粒子。

单纯减半剥离力使完整钢铁侠结构误差变大。保持平均剥离力不变、将每片响应系数从共用出生随机量的 0.88～1.12 改为独立随机量的 0.15～1.85 后，相近布局的斜线和弯月形窄峰明显减弱，原弧边保留。改变阻力衰减和增加剥离侧向偏转的试验没有更好，未采用。

回归检查使用运动粒子层、固定测试走廊及沿整段一致的横向偏移，允许细线平移，不能靠挪开位置通过。最初较宽的滤波会把正常宽密度坡面也记作细缕，已依据放大图将检测尺度收窄到 3 像素，并取消逐截面各自取最大值形成的假线。修复前的弯月反例为 4.232，阈值 2.5；仅采用独立剥离分布后为 1.315。该数值是已知反例的检查，不是所有方向都无瑕疵的证明，仍需连续播放和其它种子验证。

首次重新校准虽降低整体图像损失，却使旧钢铁侠 0.667 区域的覆盖增加到约 19738，超过旧阈值 9531。该候选已弃用。优化从已通过旧反例的独立剥离版本重新开始，同时约束早期窄线与旧后段残留。后续不能再将单个局部或平均误差用作独立的通过依据。

两台设备实际渲染三份用户录像提取的弹窗素材，早期弯月结构明显减弱。独立建材和输运位置一致，但旧钢铁侠局部光度的跨端相对检查失败，不能直接改阈值宣布通过。对照实际 GLES 材质、排除三角形拓扑变化后，进一步导出设备计算的网格随机偏移。原 `sin` 散列在不同 GPU 上产生最大约 0.6 个网格单元的偏差；换入三星实测偏移和位置后，钢铁侠 RGB 误差从 1.904 降到 0.012，改变颜色从 5.346 降到 0.030。另一台设备也明显下降，但计算着色器与顶点着色器的三角函数近似仍不完全相同。正在验证整数散列替换，保留原位移幅度及共同运动规则。

最终采用整数散列，并把独立剥离响应略扩为 0.10～1.90，平均值仍为 1。新网格下的更宽响应候选重新产生早期细线，未采用。三个反例中，早期细线对比度分别为 2.066 和 1.736（上限 2.5），后段局部集中度为 1.783（上限 1.9）；旧钢铁侠后段区域为 9049.827（上限 9531.268）。这些是固定反例的检查，不代表已证明任意输入都不存在瑕疵。

两台设备各九组输入的独立建材与实际 GPU 画面对照通过，覆盖早、中、后段。网格最大误差约 3×10⁻⁸ 个单元；六组标准素材的整帧 RGB 误差均低于 0.075/255。钢铁侠第 40 帧从约 1.90/255 降到 0.009～0.012/255。旧局部光度检查原阈值通过，新增所有采样帧颜色、透明度误差小于 0.25/255 的要求；不能只凭位置相同通过。真实语言弹窗近、远和返回关闭均已验证，并返回记事列表。

对华为参考的完整动画留出相位，结构误差（σ=6）从 3.7295 降到 3.6583，约改善 1.91%；原始 RGB 误差从 10.0379 到 10.0626，约上升 0.25%。原始颗粒位置、局部覆盖与退出时序仍有可见差异，不能称为近像素级一致。跨端高度一致与对华为参考的相似度是两个独立结论。

最终验证通过：18 场景、30 方向、234 组既有轨迹、18 个真实近远输入及 14 项 JVM 测试；170 个当前视频（128 个主要视频、36 个补充视频、6 个真机素材复现视频）均重新导出并核对模型与文件身份。没有重渲染 226 组历史标注视频。浏览器核看真实弹窗的完整过程、钢铁侠完整原速及关键相位、改变颜色八方向。

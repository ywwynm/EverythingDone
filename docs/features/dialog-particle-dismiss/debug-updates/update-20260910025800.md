# 2026-09-10 dialog 消失动画桌面收敛与 Android 移植

## r33 微片消散与双设备验证

根据本轮反馈，继续保留钢铁侠已认可的运动改善，细化灭霸、科比的局部聚散，并减弱添加附件、调整颜色和语言选择等白底弹窗的粒子化硬边。结合既有 107 个来源研究、九段参考和多组候选比较，选择 r33 为本轮迁移基准；华为局部细束仍有差异，不宣称逐像素复刻。

Android 仅替换 dialog 消失路径：新增 ParticleMicroflakeModel 与 ParticleMicroflakeRenderer，使用同一释放场、240 Hz 连续速度积分、微片几何、有限深度提示和源色材质。三个参考的综合流场同时用于自有弹窗，触点决定任意消逝方向，保留原有出现动画。

保留真实 PixelCopy 截图、圆角和圆形色块；优化无效绘制与位图批量上传，按屏幕密度保持粒径，大弹窗材料数限制为 160000。渲染提交上限 60 Hz，背景暗层从首帧同步淡出，修正系统动画倍率重复相乘。含实时 SurfaceView／TextureView 的特殊弹窗沿用原退出方式，图形能力不足时保留淡出降级。

验证：七场景共 54 个桌面视频，含 1 倍、0.5 倍、版本／华为对照和指定八方向；模型、端点、连续轨迹及视频检查通过。9 个粒子相关单元测试通过。9018f404 与 R5CW20BLNKL 已安装本轮 APK，完成实际语言、颜色、添加附件、八方向触摸、每台 10 次快速开关及输入法取消检查；三星额外完成 0／0.5／1／2 倍系统动画设置检查。两台实际 GLES 固定输入的可见材料中心与桌面最大差异小于 0.13 个逻辑像素，上传优化前后 84 张同设备图像逐像素一致。

三星保存了系统录屏；OPD2515 的 screenrecord 输出被系统拒绝，保存真实阶段截图和 GPU 对照，不以离屏视频代替录屏。临时调整的应用跟随系统深色设置及系统动画倍率均恢复。此次发布不创建 Git 提交，保留工作区原有变更。

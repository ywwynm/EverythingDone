## 2026-08-30 - 开场顺风自由边持续粒子化与单一弯曲帷幔

**用户反馈**

左上方向消失时，左上角、上边缘和左边缘此前只象征性起粒，随后变化极轻且近似停住；
Dialog 留存区域没有同步损失，左上拉伸也不足。用户要求重新逐帧核对参考动画，并确保
桌面端、Android 端和真机表现一致。

**诊断与实现**

- 旧的表层预脱落只提前少量粒子，完整层仍等待主体相位；早发纤维的有效飞行年龄在短
  窗口后近似封顶，因此会表现为“起一下后冻结”。
- `ParticleDismissReleaseField.kt` 将顺风角和相邻上、左自由边以有限边界层的平滑并集
  纳入同一连续到达场。完整层和粒子层读取相同相位，边缘向内部平滑衰减，宏观仍只有
  一个主剥离前沿。
- `ParticleDismissRenderer.kt` 让早发纤维在 `t>0.20` 后继续保持正输运斜率，并始终
  进入统一主风；新增切向单峰弓形，使唯一剥离接缝形成连续曲线，不复制第二条粒子带。
- 细孔只在同一释放相位的高张力过渡区生成，孔洞、外边缘和未粒子化表面的连接保持软化。
  帷幔亮度继续来自更多同尺寸真实粒子；彩色内容仅增加同轨迹数量表示，当前为 `4.49×`，
  不使用独立释放、速度、寿命、深度或粒径。

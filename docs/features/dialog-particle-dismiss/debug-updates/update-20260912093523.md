## 去除粒子消散中的孤立尘缕，细化共同流动和颗粒层次

你指出上一版钢铁侠约 0.67 进度、主体右侧多出一缕突兀的粒子尘，真机多个方向也会出现；此前版本没有。此次先固定相位和种子复现，逐项对比寿命、释放、流场和剥离力，并追踪形成尘缕的材料。

根因是早期材料寿命延长后，寿命和运动共用随机量，使长寿命粒子偏向相近的慢速轨迹。现将输运随机量独立，按照出生时刻连续调整寿命：早期材料正常散去，后续材料仍保留卷边所需的流动时间。共同释放场和速度场也作了小幅校正，未加入按图片名称、屏幕区域或截图轮廓删除粒子的规则。

粒径采用温和的对数正态分布，在平均覆盖接近不变的前提下增加细粒与少量较大片的层次。保留原色、已有卷曲与触点远近响应，没有再添加生硬亮带。按返回键关闭仍朝左上消散。

桌面与 Android 的 `ParticleMicroflakeModel`、共享规则和着色器已同步。固定细缕反例由修复前失败转为通过；标记区域亮度覆盖由约 38811 降为 6734，参考约为 5957。完整动画区留出帧 RGB 误差下降约 2.4%，低频结构误差小幅上升约 1.4%，因此本版不宣称所有形状指标都改善，也没有达到近像素级一致。

已通过 14 项跨语言单测、234 组既有状态回归和 18 个屏幕内近中远输入检查。9018f404、R5CW20BLNKL 两台设备各六个素材独立建材与 GPU 渲染通过，额外包含问题对应的 0.667 进度；真实弹窗近触点、远触点、返回关闭和动画层清理通过。桌面视频按既有原速、半速、八方向和双方向三距离配置重新导出，并保留完整画面对照和像素差异视频。

发布后继续核对阿里云、本地及设备安装包身份，再复测真实返回关闭。局部覆盖、相位和明暗差异仍需以完整视频审阅，不能把跨端数值对齐等同于华为效果完全一致。

# dialog-particle-dismiss debug 发布日志

## 2026-08-26 粒子消散第十三版：修复真机噪声退化 + 放开云宽

- **重要修复：真机与桌面预览不一致的根因**。噪声函数底层的哈希此前用正弦实现，其输入达到上千弧度量级——桌面显卡的正弦有精确的参数缩减，而手机 GPU 的正弦是多项式近似、大参数下严重失真，导致溶解锋线扭曲、边缘羽化、大小疏密等所有"去规整"手段在真机上大打折扣（这就是前几轮调整后真机仍显规整的原因）。现已全部换成整数哈希，跨平台逐位一致，之前多轮累积的噪声效果在真机上首次完整呈现。
- 放开消散云宽度：新增外扩羽流——约一半区段（由大尺度噪声决定）的边缘粒子向外推出，可超过弹窗原本的宽度约 90dp；这些区段的漏斗收拢同时减弱。观感为"主体被吸向触点、边缘流苏向外逸散"，云宽不再被收拢锁死。
- 桌面蓝本与真机从本版起应表现一致，若仍有肉眼差异请反馈。

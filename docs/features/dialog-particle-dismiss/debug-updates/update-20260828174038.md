# Dialog 粒子消失：连续布面 A 迁移 Android

本版将桌面端已确认的 A 方案约束迁移到 Android 生产 Shader：

- 开场未脱附的 Dialog 主体保持原位，边缘局部解除与粒子化同步开始；
- 静止表面和粒子共用连续释放场，交界不再由两套时序硬切；
- 局部起点在中段合并为一条连续弯曲折叠脊，不再各自保留独立高密粒子条带；
- 末段改为材料相干、有界的横向流，顺风加速保持主导，去掉向四周爆散的累积随机位移；
- 彩色与中性色完全共用释放、运动、寿命、粒径和材质，彩色只通过真实采样数增加来强调；
- 删除高开销 curl 有限差分，抽稀普通尾流的前后层，折叠脊仍保留三层和明显密度差。

已通过 canonical Android GLSL 离屏编译、内容色/密度/伪深度回归和多像素密度一致性检查。
本次不通过 ADB 操作设备；请安装后手动检查连续动画的帷幔可读性和帧率。

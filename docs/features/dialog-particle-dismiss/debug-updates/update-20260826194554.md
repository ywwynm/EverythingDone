# dialog-particle-dismiss debug 发布日志

## 2026-08-26 出现动画快照也升级为硬件保真

- 出现（凝聚）动画的快照升级为加固后的硬件离屏渲染：圆形按钮等依赖硬件裁剪的组件在凝实末帧不再变形，与消失动画的保真水平一致；同时补上高程阴影的光源配置。加固要点来自对系统源码与官方实现的调研：渲染结果码校验、GPU 完成栅栏等待、正确的资源释放顺序——此前缺失这些正是消失动画快照在部分设备返回空图的原因。任何一步失败自动回退到旧方式，不影响动画播放。
- 消失动画的逐像素拷贝补充了精确的源区域参数，避免窗口与面板尺寸不一致时的潜在缩放。
- 三星真机复核：开关全程逐帧亮度分析零突变，动画平滑。

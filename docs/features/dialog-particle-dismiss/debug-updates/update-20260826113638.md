## 2026-08-26 粒子消散动画第二版：烟云化运动模型

- 重写粒子运动模型：从"每个粒子独立随机方向"（整体像均匀上升的一块）改为空间连贯的旋涡流场——相邻粒子被同一股气流带动，消散时成团成缕、浓淡不均，向烟云的观感靠拢。
- 粒子改为"前慢后快"地加速离场，在仍然运动时逐渐透明消失，不再减速悬停后淡出，整体更轻盈。
- 烟缕有明暗浓淡（不再是均匀密度的一片），弹窗轮廓失形更快，"半实体半烟云"的过渡阶段更长。
- 每次消散的主飘散方向会随机轻微倾斜，配合流场演化，每一次看起来都不完全相同。
- 溶解边缘新增从触点向外的轻微吹散推力，消散与你按下的位置更有因果感。
- 本轮参数先经桌面序列帧蓝本逐帧验证后再上真机，欢迎对比第一版感受差异。

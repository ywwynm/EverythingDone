# dialog-particle-dismiss debug 发布日志

## 2026-08-26 粒子消散第十九版：修复变暗层交接的闪烁

- 修复上一版关闭弹窗瞬间背景仍会闪一下的问题。根因：接力变暗层在应用窗口里、要等下一次绘制才真正显示，而清除弹窗自身变暗与移除窗口是即时系统调用，可能早一帧生效——中间出现一帧"系统变暗已消失、接力层还没画出来"的空窗，背景亮一下再变暗。
- 修复方式：真实关闭动作推迟到接力层确实上屏之后（约一到两帧、约 30 毫秒，无感知；附 100 毫秒兜底保证弹窗必定关闭）。新时序下每一刻画面上都恰好有一层等浓度的变暗——接力层先在弹窗底下就位（被挡住、画面无变化）、再清弹窗自身变暗（底下暗层以相同浓度顶上）、最后移除窗口（已无变暗可过渡），任何一步跨帧都不会闪。
- 变暗层随粒子动画等时长恢复亮度的行为不变。

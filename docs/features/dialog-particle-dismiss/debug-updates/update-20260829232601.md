## 2026-08-29 连续薄面多边缘预脱落与严格一秒时间轴

- 根据逐帧对照反馈，继续修正 Dialog 消失时的整体运动与粒子化关系：未粒子化表面、折叠高密区和已脱离粒子现在共用同一套连续薄面状态，不再把多个圆形波纹或独立粒子条带拼在一起。宏观释放仍主要从消逝方向的反向侧推进，同时允许顺风角和两侧边缘从动画开始就以不同强度发生表层预脱落。
- 左上消逝场景中，左上角从 `t=0` 起便可看到粒子化和轻微顺风牵伸；右上、左下等边缘也有更弱的同步释放。预脱落粒子从同一 PBD 薄面提前脱离并继承局部速度、法线和颜色，不移动仍贴附的 Dialog，也不改变完整表面的单值宏观释放时钟。
- 修复粒子化与未粒子化区域容易出现尖角、狭长残留半岛和截断式边缘的问题：完整层使用连续、单调的方向相位场以及材料尺度平滑；多个局部开场起点只影响表层粒子，不再切割残留 Dialog。预脱落粒子的自由输运受到有界约束，避免中段形成游离条带或把整体轮廓重新拉成僵硬矩形。
- 折叠／帷幔区域继续通过曲率、压缩和投影密度增加更多同尺寸真实细粒子，不通过放大点径伪造高密；彩色内容只提高同轨迹采样数量，释放、运动、寿命、深度和粒径仍与中性色完全统一。
- 统一 Android、桌面模拟器和离线对比视频的逻辑时钟为严格 `1.000 s`。桌面视频现在恰好编码 60 个 60 FPS 帧，并把首末帧映射到归一化 `t=0/1`；删除网页原先按参考视频 `4700 ms` 播放模型的错误。`t=1` 时静止层和全部粒子均为零，不再出现一秒后仍有残留动画。
- 桌面回归覆盖开场多边缘可见性、单一连通粒群、柔和残留边界、方向拓扑、彩色粒子表示和末帧清空。左上场景 `t=0.10` 已能稳定检测到左上主预脱落粒群，以及右上、左下较弱的同步边缘粒子；颜色粒子 alpha 表示约为中性色的 `3.32×`，彩色 cell 直接表示约为源图的 `4.40×`。
- Android 单元测试、Shader 真实编译测试与 `:app:assembleDebug` 已通过。已在 `R5CW20BLNKL` 真机完整录制“添加附件”Dialog 的左上触摸关闭：有效动画区间为 `1.000 s`，约 `119.5 FPS`，帧间隔 P95 为 `9.52 ms`、最大值为 `12.79 ms`；末帧无 Dialog 或粒子残留，应用错误级日志为空。

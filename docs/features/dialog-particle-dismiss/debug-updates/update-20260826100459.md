# dialog-particle-dismiss debug 发布日志

## 2026-08-26 弹窗粒子消散动画（试点）

- 新增弹窗关闭动画：弹窗在关闭时化为数万个细小粒子，从你按下的位置开始向外飘散消失，粒子颜色取自弹窗内容本身。
- 试点范围：仅确认/提示类弹窗（删除确认、设置项确认等）。其他弹窗保持原有关闭方式，观感验收后再逐步铺开。
- 点按钮、按返回键、点击弹窗外部三种关闭方式都会触发；无触点的路径（返回键）从面板按钮区开始消散。
- 系统关闭了动画（开发者选项动画时长缩放为 0 等）时自动退回普通关闭，不受影响。
- 已知取舍：本次试点弹窗阴影会随窗口即时消失（在背景变暗层淡出的掩护下基本不可察觉）。

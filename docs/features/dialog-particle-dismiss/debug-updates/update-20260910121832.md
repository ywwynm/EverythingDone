# 统一人物素材与自有弹窗的粒子消散规则

## 本次调试更新

用户要求钢铁侠、灭霸、科比与自有弹窗使用同一套参数规则，并用未参与调参的素材验收，覆盖桌面模拟器和 Android。

此前桌面人物样本分别选择释放场、投影流场和区域寿命，而 Android 使用通用模型；人物视频的相似度不能直接代表实机能力。本次移除桌面正式路径的照片专用分支，新增共享 rules.properties，两端使用同一综合引导场和确定性随机算法。模型只由尺寸、触点方向、源图材质与种子产生差异，白底的错时过渡仍由整体白色占比连续调节。

Android 的 ParticleMicroflakeModel、ParticleMicroflakeRenderer 与预热路径均读取同一打包规则；调试探针从实际 PNG 独立构建材料，不再只回放桌面预生成数组。仅调整弹窗消失模型，沿用既有出现动画与设备降级条件。

七个开发场景统一调参后冻结代码和参数，再验证五个全新素材：独立自然照片、深色文字面板、宽白面板、窄长列表、透明渐变镂空；另复核一个本轮未用于调参的真实长通知。综合引导场来自既有参考学习，但所有素材只使用这一份固定参数，没有追加人物补偿。通知的隐藏背景仅为重建估计，不能作为真实背景证据。

验证：10 项相关 JVM 测试通过；13 场景起止与确定性检查通过；130 组方向、约 2.26 亿次相邻材料位置检查无沿消逝方向的反向步进；78 个双速度及对照视频完成编码和解码检查。9018f404、R5CW20BLNKL 均完成 13 个素材的独立建材与 GPU 对照、真实语言／附件／渐变颜色弹窗、八方向触点和各 10 次连续开关检查，结束后未残留粒子层或暗层。

不透明材料两端数值一致；半透明 PNG 的预乘量化造成最多约 6.3 毫秒寿命差，低于一个 120 Hz 样本。局部侵蚀形态与华为仍有差异，未宣称完全复刻。OPD2515 继续使用真实阶段截图，三星提供系统录屏；离屏渲染计时不代表系统实际显示帧率。

# dialog-particle-dismiss debug 发布日志

## 2026-08-26 粒子动画四项修复：凝聚重做、闪烁、凝固、组件保真

- 出现动画（凝聚）重做：不再从四周向中心收拢（旧方式中心区域最后成形、常显一个空洞且过于规律）。新凝聚以"一缕缕烟云凝实"的方式随机浮现——各区域按噪声决定的顺序斑块状凝实、粒子就近轻盈飘入，起点是一缕稀薄轻烟，末段各处随机补全成形。
- 修复出现动画播完后的闪烁：根因是弹窗窗口的系统进入动画（淡入+缩放）被挂起到首次显示、在凝聚结束切换真实面板的瞬间才播放，面板以透明起步渐入造成闪烁。凝聚接管时即禁用窗口动画，切换帧完全无缝（真机录屏 688 帧逐帧亮度分析零突变）。
- 修复"消散动画后弹窗凝固在屏幕上"（如检查更新的加载框快速完成时）：凝聚动画尚未收尾就关闭弹窗时，收尾探测与兜底定时器都随窗口移除失效，动画层带着末帧永久残留。现在兜底定时器挂全局、必定执行，且关闭时会先强制释放未完成的凝聚层。
- 修复自定义组件在动画中变形（如背景编辑面板的圆形渐变方向按钮显示为方形）：消散快照改用系统级逐像素拷贝（PixelCopy），圆形裁剪、阴影等所有硬件绘制特性完全保真。出现动画的快照暂保留旧方式（其瑕疵仅在凝实末帧的约 0.1 秒内可见），后续统一。

## 2026-08-31 - 侵蚀式变暗、错开的角块、有边缘的粒子云

本轮针对对话框消散动画的四类观感问题逐条改进，全部先在参考动画上量化、再落到实现。

**释放前先变暗。** 参考在一块区域被粒子化之前会先被压暗：以硬释放时刻回看，未释放
像素的亮度比中位数从提前 0.20 的 1.00 一路降到提前 0.015 的 0.77。静止层现在按同样
的曲线压暗，新生粒子也从被侵蚀的暗度起步再恢复，不再一变暗就弹回更亮。

**左上角不再是一坨凸起。** 原实现给顺风角一整片统一的提前量，还专门抑制角内的分形
以"保住同时释放"。同龄同速的整片材料在屏幕上就是一块凸起。现在角内分形全额展开、
释放时刻按噪声错开，同时把提前量按错开系数重新定标，左上角仍从 t=0.02 起就开始
粒子化，t=0.10 时角块已释放 57%。

**粒子不再过早越出控件边界。** 折叠的正弦位移是双向的，一半的相位会把边缘材料往逆风
方向推出轮廓，实测在动画进行到 20% 时已有 9.4% 的粒子落到卡片下方，而参考在全程的
右侧与下侧越界粒子恒为零。折叠幅度现在在轮廓处收敛到零，右／下越界归零；风的爬升
提前、峰值下调，改掉了"前期不动、后期猛冲"。

**粒子更少、更有层次。** 稀疏区里的粒子数原本是参考的 3–4 倍，且全部同径。网格列数
从 512 降到 256，并新增逐粒子的粒径倍率（多数偏小、少量明显更大），单颗直径的
P90/P10 从 2.0 升到 3.6，接近参考的 2.8。粒径仍不随年龄或寿命变化，浓淡只由存活
数量产生。

**运动模型的一处纠正。** 此前有一个正比于离轴距离的横向发散项，依据是"参考的沿风／
横风伸展比在下降，说明横向增长快于纵向"。把比值拆成分量后发现这个依据是错的：参考
的横向标准差基本不变（斜率 −0.036），是沿轴方向在大幅收缩。该项已删除，粒群从"从
中心炸开"改为整体被搬走，膨胀与平移之比从 0.24 降到 0.10，平移速率从 0.678 升到
0.919（参考 0.895）。

桌面模拟器与真机两端共用同一段 GLSL 与同一组常量。11 个 particledismiss 单测通过
（含 glslangValidator 真实编译，skipped=0），`:app:assembleDebug` 成功。授权设备
`R5CW20BLNKL` 上以真实外部触点关闭"添加附件"对话框：124 帧、卡顿 1.61%、90 分位
14 ms。三列对照视频（参考／桌面蓝本／真机）与关键帧对比图均已更新。

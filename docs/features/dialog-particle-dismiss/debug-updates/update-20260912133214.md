# 弹窗消散：修复孤立细缕并统一颗粒渲染

本次针对三段真机录像中反复出现的斜线、弯月形孤立细缕继续修复，并保持所有素材、方向、触点位置使用同一模型。

- 逐帧复现后分别关闭剥离力、引导流动和表面交接，定位到同步剥离造成的窄密度峰。每片剥离响应改用独立随机量，范围为 0.10～1.90，平均力度不变；保留既有卷曲和触点远近响应。
- 排查出基于 sin 的网格随机函数在不同 GPU 上会产生不同的颗粒形状。改用整数散列后，桌面和两台设备的颗粒覆盖与颜色也保持一致。没有放宽旧回归阈值，新增网格偏移、透明度和颜色检查。
- 继续小幅细化共同释放与速度场。钢铁侠完整动画留出帧结构误差约下降 1.91%；原始 RGB 误差约上升 0.25%，尚未达到对华为近像素一致。运行端没有按照片名称或诊断区域删除粒子。
- 重新导出 170 个视频，包含三份真实弹窗素材的六个修复前后视频，全部平铺在同一目录。原录像种子未知，新增复现明确使用相近释放布局，不冒称逐粒子重放。
- 发布前通过 18 场景、30 个方向、234 组既有状态、18 个屏幕内近远输入、14 项 JVM 测试；9018f404 和 R5CW20BLNKL 各九组素材独立建材与实际 GPU 对照通过，真实弹窗近、远、返回关闭及动画层清理通过。

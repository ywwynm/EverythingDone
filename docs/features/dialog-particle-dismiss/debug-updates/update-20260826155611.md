## 2026-08-26 粒子消散第十版：不规则溶解锋线 + 边缘即刻起沙

- 漏斗收拢强度按要求调至 0.96。
- 对照华为原效果细节优化"未消散部分显得规整"的问题，两处：
  1. 溶解锋线不再是从触点扩散的光滑圆弧：叠加大尺度的空间扭曲，边界呈弯曲参差的不规则线（类似纸张烧蚀的火线），残留实体的轮廓是"咬缺状"而非规则弧形。
  2. 消除锋线后"已变成粒子但还没动"的滞留带：粒子被激活的瞬间即获得一个小的起飞冲量并立即开始透明度衰减、立即软化为圆点——实体边缘直接起沙散开，不再出现一块点阵化却原地不动的"假弹窗"。
- 桌面序列帧蓝本确认：残留实体边界不规则、碎化区直接是离位散沙、文字清晰区不受影响。

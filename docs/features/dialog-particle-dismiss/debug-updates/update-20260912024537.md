# 修正弹窗消散前沿衔接与局部流动

继续处理钢铁侠完整画面对照中的三处反馈：前沿与角部衔接偏迟，右上角颗粒过于扩散，左侧弯曲及拖尾宽度不够接近参考，而且中心原纹理过早破碎。

本次在共同模型中小幅修正释放时序，减弱自由边界朝外的额外剥离力，收窄边缘外扩，并保留内部原有的卷曲与随机输运。内部较晚释放的原表面略延长连贯交接；白底面板相应收减延迟，避免大片白色保留过久。保持此前的细化颗粒覆盖，不添加额外亮线，也没有按钢铁侠、人脸坐标或场景名称选择参数。

桌面与 Android 使用相同规则。修正 Android 释放场插值的精度转换，消除新增梯度对微小数值差异的放大；原有随机起点、任意方向、屏幕内近中远运动差异及返回键向左上消散保持有效。

已完成 162 个正式视频、18 素材与 30 方向检查、234 组既有轨迹状态、18 组真实屏幕范围内的近远输入、14 项 JVM 测试。9018f404 和 R5CW20BLNKL 共 12 组独立建材及 GPU 对照通过，最大可见位置差约 0.003 像素；真实近远点击、返回关闭与动画层清理已通过。此次发布后继续复核安装包身份和实际关闭。

本轮依据完整播放与对应相位检查局部改善；数值验证不代表已逐帧复刻华为参考。视频目录提供原速、半速和调整前后对照。

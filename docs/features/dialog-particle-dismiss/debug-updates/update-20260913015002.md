## 出现动画改为当前消散动画的逆过程

用户否定四个新出现设计，选择直接倒放当前已认可的消散模型。本版删除早期出现模型，使用共同微片模型的完整一秒轨迹，按原采样倒序恢复颗粒的位置、速度与材质；默认倒放向左上的消散，每次仍使用新随机种子。保留上版修复的标题、确定按钮等最终配色抓取时序。

当前消散带有压力迭代和阻尼，不能通过简单反向积分得到同样轨迹。新增可见寿命内的 GPU 状态缓存，并在逆向预计算中合并压力迭代调度，保持原公式、迭代数和结果。共同消散资源与正向运动模型不变。

9018f404 上钢铁侠、添加附件、调整颜色三个素材的 183 个对应帧，倒播与正放 RGBA 散列完全相等。两台设备的十二组真实 Chooser / Alert 配色检查均为整图零差异，并从日志确认 GPU 逆向完整播放。20 项 JVM 检查通过；9018f404 四条关闭路径首帧约 97–112 毫秒，出现时立即返回约 90 毫秒，清理正常。

已知限制：严格倒放需要先顺向解算，9018f404 普通弹窗出现首帧仍约需 0.45–0.59 秒，三星约 0.67–0.85 秒；本版没有把这段准备等待包装成已解决。较高弹窗临时 GPU 轨迹缓存约 120 MB，结束或取消后释放。发布后继续核对远端完整包、两台设备安装身份及真实关闭行为。

# 对话框粒子动画：薄纱质感与多点起碎

## 粒子动画的薄纱质感升级

对照鸿蒙动画逐帧分析后的四项质感升级：一、溶解顺序改由噪声主导（触点只保留整体先后趋势）——锋线从"以触点为圆心的弧"变为大振幅波浪，对话框上多处同时起碎，与鸿蒙的侵蚀式消散同构；二、粒子细密化约三分之一（网格 1.5dp 改 1.1dp、粒径同步收缩），沙粒感变薄纱感；三、锋线辉光——粒子起碎瞬间显示为自身颜色的发光版本（深色内容变亮色、白色保持纯白，不是固定银色），并带柔和光晕，随飘散渐渐恢复真实色，碎化带因此呈现为一条发亮的纱；四、浓度梯度——白底纱带跟随锋线快速转净（扫过即净），内容色余缕仍飘完全程。朝按压点飞散的整体方向、动画总时长、每次随机、内容色增强全部保持不变。出现动画自动继承全部升级：凝实前沿闪光、彩色烟缕在发亮纱雾中聚拢。已在三星与 OPPO 真机逐帧验证，动画期满帧率无卡顿。

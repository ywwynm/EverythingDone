# dialog-particle-dismiss debug 发布日志

## 2026-08-26 粒子消散第二十版：背景暗层全程由应用接管

- 按提议重构背景暗层：不再使用系统的窗口变暗（部分系统对其值变化与窗口移除自带不受控的过渡动画，与应用侧暗层跨窗口交接必然存在闪烁窗口），弹窗从出现起就由应用自己的暗层负责——出现时约 220 毫秒淡入，关闭时按路径淡出：粒子消散路径与动画等长（前慢后快，粒子浓密期背景保持暗，衬托浅色弹窗的粒子）、无动画路径约 220 毫秒短淡出。
- 全生命周期单一图层、单一窗口、无交接，关闭瞬间的闪烁被结构性排除。
- 弹窗出现时的背景变暗从系统的瞬时出现变为平滑淡入，观感也更柔和。

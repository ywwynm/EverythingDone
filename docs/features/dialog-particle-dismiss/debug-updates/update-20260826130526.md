# dialog-particle-dismiss debug 发布日志

## 2026-08-26 粒子消散第三版：修复闪黑、触点方向、宽度截断感

- 修复动画开始时屏幕先变黑一瞬的问题：系统移除弹窗时对背景变暗层自带淡出过渡，此前我们又叠了一层补偿变暗，两层相乘导致闪黑。已移除补偿层，背景亮度过渡完全交给系统。
- 触摸弹窗外部关闭时，粒子现在沿"触点指向弹窗"的方向飞散：点下方粒子向上飞、点上方向下飞、点侧面向对侧飞，消散方向与你的触摸位置真正对应；波前也会从靠近触点的一侧边缘先开始咬入。按钮点击与返回键行为不变（默认向上）。
- 修复消散云宽度被弹窗宽度"截断"的生硬感：气流项改为比主位移更早生效，粒子刚激活就被拂散，弹窗的矩形直边立刻开始失形；同时加强旋涡强度与激活时刻抖动，云的宽度在消散早期就明显超出弹窗。
- 以上三项均先在桌面序列帧蓝本验证（含点击下方、点击上方两个触点场景）后再上真机。

# Dialog 粒子消散：增强相干回卷、运动视差与动态空间层次

本轮根据真机反馈继续增强消散动画的 3D 感。上一版虽然已有后/主/前三层、连续伪深度和
触点光照，但三层二维轨迹仍高度重合，连续播放时主要表现为平面的粒子擦除。

## 需求、分析与实现

- 用户指出 HarmonyOS 7 的空间感更可能来自粒子群持续变化的曲折轨迹、形状、密度和
  z 轴移动共同作用，而不只是透明通知卡或固定尺度差，并要求把 3D 感强度调高。
- 重新逐帧检查参考视频约 6.44–7.40 秒：最强空间线索是多条高密度带形成拱形、半环形和
  斜向回卷；同一条带的外缘、内侧与尾部具有不同速度、密度和覆盖关系。透明材质提供
  背景层级，但不能单独解释粒子阶段的立体感。
- 华为官方资料把沉浸光感定义为光学行为、空间属性和交互响应的统一；kinetic depth、
  motion parallax 与 dynamic occlusion 原始研究进一步支持连续形变、层间相对位移及
  覆盖/显露是单目 3D 感的主要来源。华为未公开通知消散 Shader，本实现不声称复原内部
  算法，只依据参考视频和公开视觉原理改进。

### 实现

- `curtainActivationField()` 新增每个粒子所属种子段的局部锋线法向。粒子不再全部围绕
  全局横轴摆动：每条帷幔按自身锋线先向已揭开的区域回卷，再由本次触点方向的全局风场
  带走，底边、侧边和少量顺向种子因而能形成不同朝向的拱形片层。
- 把局部年龄映射为连续回卷截面：屏幕位移使用 `1-cos`、伪 z 使用 `sin`，两者保持约
  四分之一周期相差；前后层厚度沿截面法线旋转，在正视时主要表现为深度间距，接近侧视
  时转成屏幕间距，避免三层继续平行移动。
- 伪深度对粒径和速度的调制提高到约 ±24% 与 ±20%；z 投影视差、层法向位移、前后层
  清晰度和透明度同步增强。所有变化仍来自连续曲面，不使用逐粒子随机 z，也不让粒子
  朝观察者爆散。
- 触点柔光源继续根据连续曲面法线计算，但加强明暗响应；光照只乘在快照原色上，不增加
  白色染色。彩色控件、图标和文字粒子继续比面板本体色更大、更实。
- 完整采样的高密度帷幔窗口扩大为约 0–150ms，至 260ms 平滑过渡为稀疏尾流，使回卷
  截面具有足够宽度；三层仍共享逐 cell 抽稀掩码，末段继续沿触点主方向消散。
- 新增 `ParticleDismissShaderCompileTest`，从 Kotlin 源码展开共享 GLSL，并用 Android SDK
  自带的 `glslangValidator` 编译消散粒子、静止层的四个 GLES 3.00 Shader。
- canonical 桌面蓝本重新生成 12 个随机种子、上/下/左/右上四种方向、空间诊断图，以及
  与原 HarmonyOS 7 视频的 60fps 并排对照。

### 验证

- 内容色强调 2.07×，门槛为 2.0×；没有因增强空间层次重新变成白色粒子动画。
- back/main=0.425，front/main=0.869；三层联合支持区为主体层的 2.51×。
- 帷幔阶段前后层平均质心视差 14.81px；深度方差 0.0296，尾段降至 0.0173。
- 帷幔/尾流真实覆盖率 4.08×；相反触点光源的平均 RGB 差由上一版约 1.97 提高到 14.27。
- canonical GLSL 桌面编译与原生 GLES 3.00 编译通过；12 个随机种子和四种方向未出现
  主方向反转。
- `:app:testDebugUnitTest` 与 `:app:assembleDebug` 通过；按要求未使用 ADB。

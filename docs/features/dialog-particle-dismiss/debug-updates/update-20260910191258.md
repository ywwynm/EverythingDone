## 弹窗消散每次从不同区域开始

保留已认可的卷曲、聚散、细缕及颗粒质感，让相同弹窗连续关闭时也有不同轮廓。用户反馈此前小幅形变仍相似，本次直接调整粒子化开始的位置、范围和先后顺序。

桌面与 Android 共用新的实例变化规则。源区域提前或延后释放时，其后续速度采样阶段一并调整；保留非面板颜色的颗粒份额、轻微分离和主向前进约束。触点决定总体方向，返回键仍固定左上。

实现集中在 ParticleMicroflakeVariation、材料生成、共享积分着色器与对应桌面模型；没有按人物或弹窗名称分配专用参数。桌面增加每轮随机与固定效果选项，七个主素材新增六次同向消散对比。

17 素材、234 组轨迹、256 种子变换检查、14 项单元测试、34 组双设备独立材料和 GPU 对照、110 个桌面视频已通过。9018f404 与 R5CW20BLNKL 的真实弹窗、各八方向及连续开关通过；每台额外同弹窗同方向关闭六次，确认种子和起始区域不同。

随机化之前的认可版本已先提交，新改动暂未提交。调试包发布后继续核对远端身份并在两台设备安装复测。

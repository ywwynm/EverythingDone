# 弹窗消散调试更新

## 修正粒子群内部孤立细缕，保留正常边缘卷动

用户连续指出：随机打散和静态压缩收减都未解决内部孤立细缕，向下会出现交叉窄流，向上有独立小弧，向右还有斜线和分叉。要求这些错误结构不再出现，同时钢铁侠须直接与华为原片比较，不能用旧版作为正确标准。

本轮逐项消融发现，源区域的剥离方向会在粒子移动后产生实际汇聚；只检查出生位置或某一批材料宽度会漏检。共同模型改为根据当前位置累计质量与剥离动量，用单侧压力约束内部压缩，再把修正速度加回原粒子。保留每片原速度、主群边缘卷动、随机起点和触点响应，没有通过删粒子、缩短寿命或透明度遮盖处理。共同旋流的微调直接对照华为原片，运行时没有照片专用分支。

桌面新增 `pressure_grid.py`，Android 的 `ParticleMicroflakeRenderer.kt` 使用相同的三段计算着色器与共享资源。首帧只初始化零修正，避免空的压力迭代；桌面重播统一清理压力状态，修复同一种子重复播放不一致的问题。

三个确定反例的独立窄线在当前完整过程对照中不再形成，并复核图片背景、长弹窗、横向弹窗、其他方向和种子，共 12 组。钢铁侠的横弧与下垂分支保留，完整区域的留出帧结构误差略降，但不宣称与华为达到像素级一致。所有标准与专项视频已重新生成或逐帧证明画面完全相同后复用，原速、半速共 150 个视频通过编码及身份检查。

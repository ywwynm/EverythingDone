# Dialog 粒子消散：夸张密度、内容色强化与非线性卷流

## 用户要求

用户要求停止小幅调整，将帷幔/尾流的真实粒子密度比直接提高到 4.2×，将彩色区域的
真实粒子数量表示提高到 4.5×；同时修正粒子近似匀速、所有轨迹沿同一消逝方向直线移动
的问题。左上对比场景的下边缘，尤其左下帷幔，应在归一化约 0.5 时先出现向左侧流动，
再顺势向上被揭开。

## 分析与修正

- 用 `analyze_reference_motion.py` 对不透明参考视频重新测量。参考早/中/后段中位速度约为
  18.21/125.25/193.73 px/s；下边缘向左/向上的速度比从 0.83 降至 0.62，确认同时存在
  明显加速和先侧流、后上卷。
- `ParticleDismissRenderer.kt` 的主输运改用全局 `t^3.85` 风势，并扣除粒子出生时的风势，
  保证出生位置连续且整体先慢后快。固定同一批长寿命 cell 的诊断得到中段/早段 5.77×、
  后段/中段 3.01×。
- 每条局部锋线按自身边缘切向累计侧流，再按连续锋线坐标释放成弯曲扇面；不使用逐粒子
  随机方向制造轨迹。左上下边缘的向左/向上比从 1.03 降至 0.76。
- 高密帷幔继续接近满采样；内容色构成完成后，所有尾流统一乘以 0.60 的保留率。彩色粒子
  仍与面板粒子共享速度、寿命、尺寸、透明度、光照和深度，只通过真实 cell 数量强化。
- 2.5D 稳定层距与动态曲面起伏分开，避免提高立体感时覆盖局部转向。前后层质心距离为
  15.61px。
- 桌面回归不再把“高密点占全部点的比例”误作帷幔宽度，改为直接约束几何支撑面积。
  当前高密带只占整帧 2.8%、占联合粒群 19.1%，同时真实帷幔/尾流占地密度达到 4.47×，
  内容色数量表示达到 4.61×。

## 验证

- 颜色、真实点密度、空间层次回归通过。
- 区域激活、柔和孔洞边缘、0.70 前完整表面清空与纯粒子帷幔回归通过。
- 固定粒子队列加速与下边缘转向回归通过。
- `:app:testDebugUnitTest` 与 `:app:assembleDebug` 通过，四种展开后的 GLES 3.00 Shader
  均完成编译验证。
- 未使用 ADB，也未自动安装到设备；请手动安装后检查窄亮带是否过亮、约 0.5 的侧流是否
  清楚、末段加速是否过猛以及真实设备帧率。

# 弹窗消散的柔和颗粒过渡与开放边缘

根据钢铁侠参考动画的六处反馈，继续调整颗粒明暗、左上角行程、拖尾外缘及原面板与颗粒之间的交接。撤回中途过强的亮线方案，以完整画面的自然过渡和原图颜色为准。

- 取消窄时间窗统一加白；通过更细的独立材料、较柔和的转动明暗和小幅覆盖变化改善颗粒层次，避免连续白线及灰色块状残留。
- 减少初段法向速度与消逝主方向的重复叠加，减轻迎风角落过度拉伸。
- 原边缘最后释放的一侧采用更多渐隐、颗粒分散和较低的颗粒份额；内侧仍保留供料与卷动，减少两侧都很清楚的封闭轮廓。
- 桌面与 Android 继续使用同一模型和材质规则，支持其它素材、方向和真实触点；近中远规则与随机起始区域保留，返回关闭仍向左上方消散。

验证：18 个桌面素材、30 组方向、234 组既有轨迹输入、18 组近中远输入及 13 项 JVM 测试通过。162 个原速、半速及组合视频完成导出与编码核验，新增完整画面和左上角对照。9018f404 与 R5CW20BLNKL 均完成六个素材的独立建材及 GPU 对照，并验证真实弹窗的近处、远处点击和返回关闭、动画图层清理。

与华为参考的局部密度、形态和时间节奏仍有差异；本次没有恢复按人物设置的独立参数。实现和验证记录保存在 docs/features/dialog-particle-dismiss/surface-transfer-2026-09-11.md。

## Dialog 粒子消散：连续 61 帧帷幔形态与中后段保持

### 用户反馈

用户要求重新逐帧对照不透明参考，不能只在少数关键帧上调整形似。本轮必须同时检查：
边缘附近是否存在明显高于普通尾流的真实粒子密度；高密区域能否形成符合揭开动作的连续
曲线；Dialog 完整表面与粒子群之间是否为柔和、多孔的曲线交接；归一化 0.54 后粒子是否
过快散空，以及 0.70 时能否继续保持高密粒子带和可辨的曲面形状。

### 根因与修正

- 旧验收只覆盖少数关键帧与局部比值，无法识别不同区域的密度分布和曲线是否连续。新增
  61 帧归一化形态回归，把参考与模型映射到同一 Dialog 坐标，并逐帧测量 4×4 区域中的
  普通/高密粒子质量、最大连通脊线、右下局部曲率、表面边界和交接孔隙。
- 旧高密 band 只在每颗粒子出生后的短窗口存在，且点径与高密权重在 0.54 后同时释放；
  晚出生粒子还会按局部年龄追赶全局风程，造成高密结构一边缩小、一边突然加速散开。
  现改为三个错开的持久等到达时间队列，并以低权重桥接片层连接队列；高密状态延后到
  局部年龄约 0.66–0.88 才释放，普通尾流仍保持稀疏。
- 静止层改为按真实片元位置采样细尺度连续噪声，粒子层按 cell 中心采样同一传播场；
  交接期加入约 75–220ms 的多孔粒子桥，避免整格内容被二值切除后形成硬边。
- 帷幔弧形位移只在曲面建立阶段进入，随后成为冻结的几何形状，不再持续制造横向速度。
  主风改为对 smoothstep 速度曲线做解析积分，晚出生粒子只累计出生后的风程，不会瞬间
  追赶全局进度。左下固定粒子队列先沿边向左展开，再转入左上抬升。
- 后/主/前三层继续共享同一曲面、占用掩码和触点光源，只以法线层距、视差和点径形成
  2.5D 层次。彩色区域只在统一占用概率中生成更多真实 cell；颜色不再拥有单独的位移、
  速度、寿命、点径、透明度、光照、材质或深度规则。

### 逐帧与分层结果

- 0.32–0.72 的普通粒子区域分布相似度中位数为 0.788，高密分布为 0.669；0.47 两项为
  0.816/0.716，0.54 为 0.814/0.741。模型密度对比为 13.77，最大高密脊线质量占比为
  39.31%；参考分别为 26.03 和 52.07%，因此本轮记录为明显改善，不宣称逐像素复刻。
- 0.54→0.70 的模型粒子总质量保持率由约 0.586 提高到 0.660，高密质量由约 0.658
  提高到 0.736；0.70 时完整 Dialog 表面已经清空，但高密曲面仍保持可见。
- 0.32–0.72 的边界孔隙率中位数为 3.43%，表面/粒子重叠为 16.11%，硬边比例为 6.07%。
  0.47 的纯粒子帷幔峰位于完整表面外约 22px，对贴边粒雾和外层尾流的局部密度比均约
  3.1×，不会把未粒子化白边误认成帷幔。
- 参考早/中/后段速度约为 18.21/125.25/193.73px/s，模型为
  32.26/169.11/200.29px/s。固定左下队列先以 dx/dy=-26.37/-25.05px/s 侧流，再以
  -117.36/-170.77px/s 转入左上抬升；回归同时检查方向符号。
- 彩色区域的真实粒子数量表示为 1.84×，但所有颜色共享同一动力学。帷幔/尾流阶段伪
  深度方差为 0.0273/0.0105，前后层质心分离 28.66px。
- 桌面默认密度与 Android 等效密度的平均 alpha、强像素占比和局部密度保持一致；61 帧
  形态、运动、激活、颜色、栅格、边缘和 Python 编译回归全部通过。

# 对话框粒子动画：真正的多点起碎

## 消散从多个互不连通的区域同时开始

上一版的"多点起碎"实际仍聚集在一处：锋线噪声的波长（192dp）在对话框尺度内只有一两个低谷，起碎自然集中。本次把锋线噪声改为双尺度叠加——低频项保留锋线的大波浪形态，新增的中频项（约 66dp 波长）在面板内制造多个独立低谷，并做谷形整形（大部分区域抬平、低谷保留突出）：多数区域较晚碎化，而分散的低谷显著提前冒出。效果是消散从对话框的五六处互不连通的区域同时开花、各自扩张再合并成波浪锋线，与鸿蒙"从控件不同区域同时开始"的形态一致；出现动画对称地呈现多区域同时凝实。溶解总时长与其余观感不变。已在三星与 OPPO 真机逐帧确认多点起碎形态。

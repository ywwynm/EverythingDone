# 调试版本更新说明

## 2026-10-19：默认消散方向随机选择左上或正上

用户先要求只读检查默认消散方向，随后确认修改指定场景，并在三台设备上验证，不能影响真实记事。方向规则确认为每次等概率选择左上 45°（135°）或正上（90°），同一次批量移除共用一个方向。

- 弹窗系统返回、首页“调整记事外观／调整文件夹外观”面板系统返回，以及没有有效触点、异步或中心触点关闭，统一接入 `ParticleDismissDirection`。`BaseDialogFragment` 与 `ParticlePanelAnimator` 的返回路径交由共用控制器选向，不沿用旧触点。
- 粒子设置页的对话框预览每次消散随机选向，随后出现沿该次方向倒放；手动选择后固定到所选方向，即使手动选中当前随机方向也会锁定。重新进入页面恢复随机。
- `ThingListRemovalAnimator` 为单选／批量完成、删除、恢复、彻底删除后的可见卡片合成材料抽取一次方向；原来的真实触点方向、左右滑动、手动八方向、粒子开关与模型保持原行为。
- 137 项相关单元测试通过。`3B1629006YC00000`、`R5CW20BLNKL`、`192.168.100.67:40807` 上两种样式共通过 259 次方向动画、60 项真实菜单用例，并检查代表性过程与结束截图。
- 所有记事操作都在独立测试包及虚构数据上进行。三台测试包已清理，正式应用数据库的 SHA-256 均与首次测试前一致。

实现、验证范围与复现脚本见 `docs/features/dialog-particle-dismiss/default-directions-2026-10-19.md`。

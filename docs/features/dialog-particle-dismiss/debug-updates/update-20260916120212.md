# 弹窗粒子动画调试更新

## 修正上一版的黑屏，弹窗叠弹窗的粒子层级现已在整屏画面上确认

上一版 202609160339 有严重问题：详情页点「从世界取色」整屏直接黑屏，按返回才能看到取色弹窗的消散粒子。实测整屏近黑像素高达百分之九十九点三。原因是两处叠在一起，都是上一版引入的。

其一，新加的全屏承载窗口是不透明的。系统主题里的「窗口半透明」标志并不会替对话框设置窗口的像素格式，默认就是不透明，于是这块全屏画布把整个屏幕涂成了黑色。本版显式给窗口设置半透明格式，并把根视图背景显式设成透明。

其二，上一版为了防止「承载窗口刚显示、根视图还没附着」而加的那道回退，实际上把出现动画这条路整个抵消了：承载窗口是刚显示出来的，根视图必然还没附着，于是每次都回退到原来的表面，抬升等于没做；而窗口已经显示、又被「叠加状态还在就不撤」的规则保留着，就成了一块没人使用的不透明全屏画布盖住整个屏幕。实际上出现这条路本来就是异步取宿主的，真正用到承载窗口是在捕获回调里，那时它早已附着，因此同步的附着检查只应该留给消散那一路。本版把出现这一路的同步检查去掉。

本版在整屏画面上重新确认了效果，不再只看裁剪图与日志。出现动画开始后四百毫秒与八百毫秒两帧，整屏近黑均为零，粒子明确盖在改变颜色面板之上，面板的色点、滑条与按钮都被粒子覆盖；两秒八与五秒八两帧取色弹窗正常显示在面板之上；消散三百毫秒与七百毫秒两帧粒子同样盖在面板之上，三秒七之后干净回到面板。其余路径同样逐帧确认没有黑屏也没有多出窗口：单个弹窗的出现与消散、新建记事入场，画面与改动前一致。

需要说明上一版为什么没测出来。第一版的截图整屏近黑只有百分之零到五，画面确实是对的；但那之后我又改了代码——保留承载窗口、未附着回退、调试日志——而后续的验证只核对了闸门日志与帧数，没有再看一次画面。改完代码只看日志、不重新看图，是这次漏检的直接原因，已记进决策文档。

共同粒子模型、着色器、时长、密度与任何已认可的视觉参数均未改动。构建通过，本地检查 1036 项，唯一失败是既有的 FableSol 曲线那一项。

仍未在设备上单独复现的：提醒或习惯记事详情页里点开始做事弹出的选择做事时长（本项目第二处弹窗叠弹窗，走同一入口同一闸门）；首页调整外观面板里的从世界取色（那个面板是页内视图，闸门必然不启用）；以及三星那台未连接。另外请实际点几下确认承载窗口没有挡住任何点击——它设成了不可触摸不可聚焦。

平板首页仍为原有的两个文件夹十五条记事，三项动画档位与开始时一致，设备上的临时文件已清理，用户现有记事一条没动。本轮未提交 Git。

## 加强弹窗消散的弧边流动与触点远近差异

用户再次指出钢铁侠横向弧边的弯曲和粒子流动仍不足，近、中、远触点的动画也难以区分。本次在原有共同模型上继续调整，保留释放场、随机起始区域、粒子颜色与寿命规则，不按人物或弹窗名称设置独立参数。

- 加强粒子刚脱离控件时沿局部解除边界向外展开的运动，随后平滑进入共同流动；让横向弧边逐渐弯出，并保留下方较早释放的拖尾。展开幅度含小幅随机变化，避免形成过于整齐的边线。
- 触点距离同时改变每颗粒子相对出生位置的实际位移与实际速度。不同距离继续保留原来的卷动路径和相同动画时长，不把所有粒子吸入触点。按返回键关闭仍向左上消散。
- 桌面和 Android 共用 `shared/particle-dismiss/step.comp`。实际状态包含最终坐标和速度，模拟器渲染、移动端渲染与轨迹检查使用相同结果。
- 新增弧边局部三栏对照、钢铁侠／添加附件／调整颜色的双方向近中远单行视频；审阅页可以在相同位置、相同进度切换近、中、远。原有双速度、八方向和四参考视频全部更新，产物共 158 个，仍保存在同一视频目录。

发布前已通过 18 场景、30 方向、234 组旧问题状态、13 项 JVM 单测、9018f404 的 13 组独立建材及 GPU 对照，以及真实背景近远、返回关闭和连续随机关闭检查。没有重导 226 组历史标注视频。

R5CW20BLNKL 仍未获得 USB 调试授权，本轮未在该设备验证。参考的局部释放时序及细缕分布仍有差异，本次重点改善弧边展开和可辨认的近远运动。

# 弹窗消逝：逐帧校准释放与粒子流动

继续处理钢铁侠对照中前沿入口偏移、右上粒群过度散开、左侧曲率和拖尾宽度不符、中心纹理过早破碎，以及颗粒密度与明暗不同的问题。改动继续放在所有素材、消逝方向、触点位置共用的模型中。

- 对参考和桌面动画逐帧建立原始像素差、多个空间尺度的结构差与颗粒对比度测量，同时检查完整画面和连续播放；不通过改变参考相位、扭曲画面或裁掉问题区域降低误差。
- 在共同归一化释放场和速度场上校准宽尺度的空间与时间变化，并联合调整寿命、额外剥离力和微片明暗。保留卷边、分支流动、随机起始区域、实际触点远近响应及内容色强调，没有按钢铁侠或人脸区域增加专属运行参数。
- 桌面和 Android 使用相同的共同资源与着色器。发布前的跨端测试拦截并修正了资源边缘的少量非法释放时间，保留原校验条件；未引入新的硬位置边界。
- 完成 18 个素材、30 组方向检查、234 组已有轨迹状态、18 个屏幕内近中远输入和 14 项 JVM 测试。两台指定设备各完成六组独立建材与 GPU 对照，以及实际近远触摸、返回关闭和动画层清理；返回键仍固定向左上消逝。
- 导出 164 个视频，保留 1 倍、0.5 倍、八方向及距离组合；新增原始像素差与结构差四栏对照。视频和大文件保留在功能目录的本地忽略区。

完整动画区域的留出相位中，结构误差约下降 19.3%，原始 RGB 误差仅小幅下降。中段局部覆盖、颗粒位置与明暗仍有差异，本版尚未达到近像素级一致。额外测试的颗粒加大、强反光与明暗变化未改善整体效果，未纳入发布。

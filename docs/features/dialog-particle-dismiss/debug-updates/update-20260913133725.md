## 补齐弹窗、调整外观面板和音频海浪的粒子动画

用户指出开始做事、更显著的通知、首页调整外观，以及录音、音频播放和 FableSol 参数弹窗尚未接入，要求同时检查其它遗漏。本版统一使用已认可的粒子模型，出现仍从下方随机进入并播放 0.6 秒，消失仍为一秒，不修改钢铁侠等序列的运动效果。

定位到三类问题：透明宿主尚未附着时跳过出现；独立 SurfaceView／TextureView 被一律排除；透明 Activity 关闭过早，动画层甚至还未建立就被销毁。ParticleDismissController 现在等待有效布局和已启动的捕获／动画结束，ParticleDialogHostActivity 管理透明宿主；通知与列表小组件的原内容交由 ActivityContentDialogFragment 承载，首页面板通过 ParticlePanelAnimator 接入。原宽度、取消／确认回调及动画设置继续保留，同时修复浮动页面背景被重复变暗。

ParticleSnapshot 合成普通窗口和独立海浪缓冲，保留海浪上方文字。FableSol 在捕获与交接期间临时冻结，结束后继续运行，不覆盖播放、暂停或导出状态。隐藏 Surface 不参与；TextureView 不再阻止整张面板的动画。普通弹窗继续使用原捕获方式，避免重新出现文字变色与尺寸跳变。冷启动的海浪仍可能等待首帧，未宣称零准备延迟。

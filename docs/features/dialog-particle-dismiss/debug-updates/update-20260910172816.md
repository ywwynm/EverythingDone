# 弹窗消散：从认可的观测运动提炼共同模型

用户指出此前增强卷动的尝试偏离参考，钢铁侠在进度 0.43 时左侧、上侧不应大量提前粒子化；随后明确认可“观测运动控制组”的轮廓，要求沿该结果继续优化并推广到其他消逝位置。

本次将认可控制组冻结，离线平滑并压缩出共同释放场和速度场。两者使用相同的矩形坐标及方向变换，保留局部释放、持续输运与亮弧形成的关系，移除额外整片分离、强旋转和周期流管。所有人物、照片和自有弹窗使用同一份 804 KiB 资源，运行时不读取人物配置、参考视频或原始光流。它是从参考学习的共同形态规则，不声称复原了华为内部物理实现。

桌面 renderer.py、unified_model.py 与 Android ParticleMicroflakeModel、ParticleMicroflakeRenderer 同步。面板色微片在释放后进一步细化，文字、图标和其他非面板色保留实际副片配额；返回键保持固定左上，触点关闭跟随实际方向。只替换弹窗消失路径。

模型冻结后加入灰度照片和横向浅暖弹窗，未根据新素材结果回调参数。17 场景、170 组方向轨迹、两台设备 34 组独立建材和 GPU 对照、12 个相关单元测试及 96 视频检查通过。关键进度的钢铁侠左侧、上侧中段未释放比例均约 89%。真实语言、颜色、添加附件弹窗、各八方向与各 10 次连续开关通过，关闭后无粒子层或暗层残留。

桌面对比增加“华为参考／认可控制组／共同模型”，保留此前发布版对照，视频仍在同一目录。两台指定设备的真实录屏或阶段截图另行留档。不同参考的局部侵蚀时序仍有差异；输入法恢复可能遮挡动画尾段。发布任务完成后继续核对远端 APK 与资源身份，并在 9018f404、R5CW20BLNKL 上安装发布包复测。

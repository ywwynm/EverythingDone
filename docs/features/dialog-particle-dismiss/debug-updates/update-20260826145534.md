## 2026-08-26 粒子消散第六版：收敛混沌感，整团朝向更明确

- 收敛上一版"粒子四面八方乱卷"的混沌感：气流场从驱动力降为扰动（强度下调近半），且不再抢在主方向之前生效——粒子激活初期整齐地朝触点方向启动，缕状摆动在中后期才逐渐加入。
- 对气流做方向整形：剔除逆着主方向的分量，不再有粒子"往回跑"；垂直方向的横摆保留（烟缕与云的宽度来自它），顺向的快慢差减弱。整团烟保持朝触点的一致流动，同时边缘仍有羽化和卷须、浓淡仍不均匀，不回到最初那种整块均匀移动的呆板样子。
- 已在桌面序列帧蓝本验证按钮点击与点击左上方外部两个场景：整团流向清晰一致，方向随粒子位置渐变的特性保留。

# 对话框粒子动画：局部帷幔、破碎轮廓、碎化即飞散

## 轮廓不再方正，浓带是局部掀起的帷幔

这一轮针对三处反馈重做：一、**碎化与消逝同步**——此前粒子碎化后要等揭开线扫到才起飞，中间有一段整卡静止的分割感；现在每颗粒子在自己的时刻碎化并立即飞散，"一开始就露出对话框底下的界面"由被抽稀的白底格子提前消失承担，两个过程重叠进行，没有分段。二、**轮廓破碎**——边缘不再豁免抽稀，四周边缘同时向内侵蚀（侵蚀边界受噪声摆动、强度沿边起伏），对话框的方正轮廓在动画早期就碎成参差的曲线，不再从头到尾保持一个规整的矩形。三、**局部帷幔浓带**——浓带不再由整条边构成，而是沿揭开起始边随机选出**一段**（约占边长三分之一），该段全部保留并三倍增密、粒子更大更亮，且段中心先掀、两端拖后，形成一道下垂的帷幔弧；同时整条揭开线本身也带一道夸张的大弧（往上飞是波峰、往下飞是波谷），弧心每次随机。总时长与出现动画均不变。三星真机逐帧验证：起碎为局部一块不规则区域、整卡随即稀疏透出底下界面、帷幔粒子聚成明亮浓带飘起。

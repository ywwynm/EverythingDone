# 对话框粒子动画：量化对照鸿蒙重做揭开与浓带

## 揭开与浓带按鸿蒙截图逐项重做

对照鸿蒙截图逐帧量化后的一揽子重做：一、揭开线改为**大振幅弧线**（横跨对话框一两个起伏），起始只从边缘的一段掀起（弧线先头），不再整条边同时开始；其他边缘的局部（噪声谷段）也会同步开始粒子化，与鸿蒙"上缘左侧同时掀起"一致。二、**浓带**这次是纯粒子构成的：所有粒子在刚被掀起的阶段（前 30% 寿命）会额外激活两颗副本——粒子数量真实三倍、聚在揭开线附近形成一条密亮的带，随飘散淡出还回单颗；配合辉光、尺寸增强与更慢的起飞节奏，浓带随揭开线移动、一头密一头稀。三、上一版的"整卡颗粒态"删除——未掀开区域保持逐像素清晰的内容。量化验收：真机帧上浓带（暗背景纯粒子带）亮点密度是已飘散区的 5.9 倍，落在鸿蒙实测的 4–8 区间；桌面蓝本带内/已飘散粒子数量比 6–29。触点方向、总时长、每次随机、内容色增强与出现动画均不变。三星与 OPPO 双真机逐帧验证。

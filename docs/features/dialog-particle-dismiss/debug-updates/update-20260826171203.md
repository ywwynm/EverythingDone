# dialog-particle-dismiss debug 发布日志

## 2026-08-26 粒子消散第十五版：先散后聚，宽弹窗不再勒窄

- 运动改为两段式：部分粒子在被激活的初期会先向两侧逸散一段（前 30% 寿命内完成，散多散少逐粒子随机——有的跑得远、有的几乎原地，弹窗中部的粒子做小幅乱散），随后才被主流带向触点方向；散开的宽度不会被后续收拢收回。不再是所有粒子从一开始就直奔最终方向。
- 修复宽弹窗（日期时间、底部面板等）上宽度受限更明显的问题：漏斗收拢按比例作用于横向位置，弹窗越宽、边缘被拉向中轴的绝对距离越大。现对收拢位移设绝对上限（约 240dp），宽弹窗的云保持蓬松肩部，漏斗收束仍在但不再勒死。
- 桌面蓝本新增 560dp 宽面板场景验证：碎化区两侧粒子先行散开、云宽超出弹窗轮廓、蓬松下沉，标准宽度弹窗无过散退化。

## 2026-08-30 - 连续薄面释放拓扑与平滑帷幔外包络

**用户反馈**

用户在逐帧对照参考动画后指出，旧版仍有四周向中心侵蚀、局部粒子群彼此割裂、未粒子化
区域出现尖角、粒子／本体连接生硬等问题。后续真机截图还显示，中段右下高密粒群的下凸
包像多段曲线拼接，转折磕绊且过度突出。用户要求从运动、布面受风和粒子化规律出发解决，
保持桌面 canonical、Android 和真机表现一致，同时不得丢失帷幔增密和彩色内容强调。

**诊断与实现**

- 新增 `ParticleDismissReleaseField.kt`，以统一主风压力、连续材料阻力、内部附着脊和有限
  应力区驱动同一张释放相位，不再使用到四条外边缘的最近距离或多个圆形波纹取最小值，
  因此最后留存区域会随主风迁移，不再固定收缩到 Dialog 几何中心。
- `ParticleDismissClothModel.kt` 与 `ParticleDismissRenderer.kt` 使用同一张连续 PBD 薄面：
  未粒子化表面、剥离接缝、高密折叠脊和已脱离尾流共享材料坐标及释放时序。边缘细孔受
  同一连续相位和局部张力约束，避免两圆未交融产生尖角或在 Dialog 边缘形成截断边界。
- 针对本轮下凸包问题，确认旧 Shader 在已经连续的 PBD 曲线上额外叠加了有限区间
  `frontArc` 抛物线；其区间端点斜率不连续，再与过长的脱离粒子队列叠加，形成多个拼接
  鼓包。现完全删除该横向弓形，高密前沿整体沿主方向平行离面 `0.030w`，直接继承释放
  相位和布面的连续曲率；脱离队列缩为 `0.100→0.065 s`，capture 脉冲降为 `2.85`。
- 帷幔亮带继续由更多同尺寸真实细粒形成，不通过增大粒径伪造密度。彩色内容只增加同一
  轨迹的粒子数量，不改变速度、寿命、深度或方向；动画全程仍严格为 `1.000 s`。

**验证**

- 新增下边缘包络回归，在 `t=0.40/0.47/0.54` 检查突出深度、低频粗糙度、曲率步进和
  曲率总变差。`t=0.47` 下凸深度由 `0.1355w` 降至 `0.1092w`，粗糙度由 `0.0191w`
  降至 `0.0157w`，曲率总变差由 `0.8533` 降至 `0.7959`；独立高密帷幔相对贴边粒雾
  的真实密度仍为 `1.43×`。
- 释放拓扑、形态、柔边、激活、连贯性、非线性运动、早期多边缘、方向、跨分辨率、内容
  色和真实 Shader 编译回归全部通过。Android 945 项测试执行完成，`:app:assembleDebug`
  成功；桌面 canonical 和三列归一化对比视频均严格为 `1.000 s`。
- 在授权三星 SM-S9180 `R5CW20BLNKL` 安装当前 APK，打开真实“添加附件”Dialog，并以
  左上外部触点 `(60,700)` 关闭。逐帧放大显示桌面与真机的下边缘均已成为一条连续、克制
  的曲线。真机有效一秒包含 120 帧，帧间隔中位数 `8.289 ms`、P95 `9.967 ms`、最大
  `12.589 ms`；gfxinfo jank 为 `1.61%`，应用日志没有渲染异常。

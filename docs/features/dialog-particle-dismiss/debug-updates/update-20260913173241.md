# 修复弹窗交接闪烁与旧面板快照，继续改善动画流畅度

本版针对 ripple 尾段卡顿、背景先变暗、音频窗口消失闪一帧、海浪与连续弹窗掉帧、外观面板混入上一个记事的页面，以及首次创建和出现准备耗时继续优化。

共同入口等待 ripple 最后一帧实际提交后再交接；排除 TextureView 建链的空缓冲，粒子有效首帧才启动暗层。粒子末帧被窗口取走后再恢复真实内容和释放 EGL，避免准备或结束时闪烁、冻结和突然变色。出现暗层与 0.6 秒粒子动画同步开始和结束。

首页外观面板复用时，旧 LayoutTransition 仍绘制已隐藏页面。ParticleSnapshot 现在结束旧过渡及其延后启动的布局监听，再捕获当前完整页面；A 外观→A 颜色→关闭→B 外观的快照与最终 B 面板逐像素相同。

ParticlePlaybackClock 使用显示节拍；GL 线程先完成本帧再交给窗口，源消散从准备阶段就持有 GPU 优先级，补齐 ripple 结束至粒子首帧之间的限流空档。正向播放复用已校验的压力批处理，保持粒子数量、240 Hz 积分、全部压力迭代、材质和已认可的共同轨迹。

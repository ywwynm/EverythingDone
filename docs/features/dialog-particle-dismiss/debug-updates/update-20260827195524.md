# Dialog 粒子消散：方向性揭开、柔和孔洞与高密窄帷幔

本轮以新的不透明控件粒子化视频为主要参考，继续优化 Dialog 消失动画。用户要求研究
粒子解体效果本身的运动规律，不再搜索华为或鸿蒙具体实现；桌面对比中的模型统一向左上
消散，以便直接观察差异。经过桌面 canonical 模型确认后，用户同意放到 Android 实机查看。

### 分析与修正

- 逐帧与光流分析确认该效果属于流场输运式粒子化解体：表面传播与粒子运动是两个阶段，
  粒子先在局部锋线附近脱离，随后被主风捕获、加速并向左上收束。
- 修正目标角停留：顺向侧起点原先落在上边中部，改到几何角后又处于圆角透明像素；现在
  沿角平分线内移到可靠的不透明内容，左上角在动画前段即可产生并向外输运粒子。
- 激活场加入沿运动轴的稳定传播梯度。向左上消失时，右下区域明显更快粒子化，左上更慢；
  侧边和顺向侧仍可近同步局部起碎，不退化成单一扫描线。
- 静止表面改为按真实片元位置采样连续细尺度 delay，并与原位细粒通过约 133ms 的局部
  交接包络转换。孔洞边缘形成数像素宽的细碎过渡，不再沿整 cell 二值切出锐边。
- 完整传播场等比收进动画生命周期；0.96 秒时顺向侧剩余表面约 1.6%，避免 Overlay 结束
  时仍有完整区域整块跳失。

### 高密帷幔与稀疏尾流

- 旧高密窗口持续 200–380ms，导致测量帧约 71.9% 的可见点都属于“高密阶段”，连续观看
  仍是一大片近似等密粒云。旧覆盖率指标又受粒径、alpha 和三层重叠影响，无法识别该问题。
- 新回归把主体层每个存活 cell 固定为 1px，只统计真实点中心，并约束高密点占比。高密
  窗口缩为约 68–175ms，高密点占比降至 34.7%。
- 揭开锋线保留约 88%–100% 的粒子；面板色尾流保留约 20%–32%，彩色内容尾流保留约
  62%–74%。当前高密带真实局部点密度约为尾流的 2.30 倍，形成贴着孔洞边缘的窄帷幔，
  其后是更宽、更稀的原色粒群。
- 伪深度更早建立，并随高密帷幔结束而衰减；触点柔光、连续卷曲和前后层运动视差继续
  保留。粒子仍逐位继承快照颜色，没有统一染白。

### 验证

- canonical 桌面 Shader、12 个随机种子、上/下/左/右上方向矩阵及不透明参考归一化并排
  视频均已重新生成。
- 区域回归通过：0.16 秒右下/左上剩余表面约 0.42/0.96；0.16 秒已有左上越界粒子；
  0.24 秒孔洞过渡宽度约 6px；0.96 秒静止表面低于 3%。
- 内容色强调 3.47 倍；back/main=0.402、front/main=0.899；帷幔/尾流深度方差
  0.0319/0.0240；真实点密度比 2.30 倍，高密点占比 34.7%。
- `:app:testDebugUnitTest` 与 `:app:assembleDebug` 通过，包含原生 GLES 3.00 四组 Shader
  编译测试。按项目规则未使用 ADB 操作物理设备或模拟器。

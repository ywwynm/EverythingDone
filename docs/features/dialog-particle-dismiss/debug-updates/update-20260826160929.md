## 2026-08-26 粒子消散第十一版：消除两侧"刀切"直边

- 修复漏斗收拢导致的两侧边缘平直问题：此前收拢是均匀的线性横向缩放，弹窗左右边缘的粒子收缩后仍整齐排在一条线上，云的侧边像刀切的斜线。现在对每个粒子的收拢量做双层调制——大尺度噪声让不同区段收得多、收得少（侧边呈波浪起伏），叠加逐粒子随机形成毛糙羽化边。
- 平均收拢幅度保持不变（漏斗力度仍是 0.96 档），只是边缘粒子不再共线；单粒子收拢量封顶，不会过冲穿过中轴。
- 桌面序列帧蓝本确认（点击下方场景）：云的左右轮廓起伏不对称、有隆起有凹陷、外缘飘出稀疏粒子羽，不再有平整斜线。

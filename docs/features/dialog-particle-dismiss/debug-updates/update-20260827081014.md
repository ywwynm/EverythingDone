# 对话框粒子动画：白底抽稀，浓稀对比内生

## 浓带与稀疏的对比这次是结构性的

采纳你的分析与提议：量化证实鸿蒙通知卡的毛玻璃底不透明度只有约 0.26——粒子化时透明底区的粒子淡到近乎不可见，可见粒子天然集中在内容与边缘，浓稀对比是内容透明度分布的直接映射。对我们这种不透明面板做等效改造：本体色（白底）格子只保留约三成转化为粒子，其余格子在被揭开的瞬间直接消失、露出背景；几何边缘带与有颜色的格子全部保留并叠加副本增密。效果是揭开边缘沿线卷着一条密集的碎屑带、内容色碎成饱满彩色团，而已掀开区域只有零星白粒稀疏飘散——浓与稀的对比从结构上产生（蓝本量化带内/已飘散粒子数量比约 20 倍），不再依赖参数硬调。出现动画不抽稀（凝实成完整面板），总时长与其余观感不变。三星真机逐帧验证：起碎从边缘一段开始、揭开线弧线推进、密集碎屑带与稀疏区分明。

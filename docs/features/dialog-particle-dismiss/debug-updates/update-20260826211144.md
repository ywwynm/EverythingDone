# 对话框粒子动画：修复出现动画结束后的闪烁

## 出现动画结束后面板不再消失一瞬

改变记事颜色的底部面板上，出现（凝聚）动画结束后面板会消失一瞬再出现。根因：凝聚期间面板以"窗口不可见"方式隐藏，系统把窗口的进入动画（底部面板 190ms 滑入）挂起到凝聚结束恢复可见的瞬间才播——动画层撤走时面板还在屏外滑入途中。本次把隐藏方式改为全透明：窗口全程正常显示，进入动画在透明期内照常播完，凝聚结束的恢复只是一帧普通重绘，交接无缝。顺带修复"仅出现时"档位下窗口退出动画被吃掉的问题。已在三星与 OPPO 真机验证：改颜色面板与普通对话框的出现动画逐帧无跳变、收尾面板全程在位，消失动画不受影响。

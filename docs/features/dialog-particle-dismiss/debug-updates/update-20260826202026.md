# dialog-particle-dismiss debug 发布日志

## 2026-08-26 修复出现动画失效与按钮关闭无动画的回归

- 修复上一版两处回归（真机探针定位）：
  1. 出现（凝聚）动画完全不播：硬件快照产出的位图被标记为不可修改，圆角遮罩绘制时抛异常导致快照整体失败、动画被兜底跳过。已改为可修改位图。
  2. 点击弹窗内按钮（确认/取消等）关闭时无消散动画，部分设备上弹窗甚至卡住不关：弹窗关闭链路会两次触发关闭调用，粒子流程接管期间第二次调用抢先移除了窗口，异步抓图回调时窗口已不在、动画被放弃。已加流程进行中的重入保护；同时给异步抓图加 500 毫秒超时兜底，任何设备上弹窗都必定正常关闭。
- 双真机复核：OPPO 平板凝聚快照与消散全链路探针全绿；三星按钮关闭恢复粒子动画（从按下的按钮处起碎）、弹窗正常关闭。

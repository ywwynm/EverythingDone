## 修复弹窗出现时的文字配色跳变

用户反馈很多弹窗在出现动画结束之后，标题、确定按钮等元素才变为正确颜色。本轮先提供四种新出现动效的设计示意；应用包更新的是已有出现动画的配色交接，新动效待用户选择。

使用真实 Chooser / Alert 弹窗直接取出动画 Bitmap，与出现完成后的真实界面逐像素比较。修复前，Chooser 的标题、确认按钮与选中项文字仍是临时纯色，交接时有 14,956 个像素发生明显变化。原因是 `ParticleDismissController.startCondense` 在首次 pre-draw 回调中抓图，早于子 TextView 的渐变初始化回调。

现在把捕获安排到本次绘制准备回调全部完成之后，无固定毫秒等待；增加窗口显示与附着检查，捕获完成即移除多余的恢复任务。出现轨迹和已认可的共同消散模型继续沿用。

9018f404 上两类弹窗、正向渐变／反向渐变／纯色六组检查，动画原图与最终画面整图最大通道差全部为 0。四种真实关闭方式与两次快速返回检查通过，四条关闭路径首帧为 90–108 毫秒，未重现上轮已优化的长等待。R5CW20BLNKL 当前离线，待补测。

新增 debug 专用真实弹窗配色探针及像素验证脚本，输入均为虚构测试内容，不修改用户记事。发布后继续核对远端完整 APK、本地发布包、已安装包及最终包行为。

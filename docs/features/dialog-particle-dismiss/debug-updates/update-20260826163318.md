# dialog-particle-dismiss debug 发布日志

## 2026-08-26 粒子消散第十二版：大小疏密不均，全面加大随机

- 粒子大小不再统一：不同区域有整体的粗细差，叠加逐粒子随机（多数偏小、偶有大颗粒），消散云呈现尘埃般的颗粒混杂感。
- 粒子寿命不再统一：有的区域粒子早早消散变得稀疏、有的坚持到最后形成余缕——云的疏密分布随时间演化不均，更接近华为效果的灵动轻盈。
- 烟缕明暗对比加强（浓处更浓、淡处更透）。
- 全面加大噪声与随机：湍流幅度近乎翻倍且逐粒子随机化、旋涡强度回调一档（方向整形仍保证不回流、不混沌）、弯曲弧线幅度加大、溶解锋线更不规则、逐粒子速度差扩大。
- 动画尾段因长寿命余缕略有延长（约 0.15 秒），整体节奏不变。
- 桌面序列帧蓝本确认：起沙区颗粒大小混杂、云体浓淡斑驳、边缘破碎不规则。

# 对话框粒子动画：内容色粒子增强

## 粒子动画不再单调：内容颜色成为主角

此前粒子动画里绝大部分粒子都是对话框本体的白色（暗色模式下的灰黑色），内容与彩色占比小，观感单调。本次为每颗粒子计算"与面板本体色的差异"权重（本体色由快照自动统计，适配任意背景与暗色模式）：文字等深色内容获得中档权重、彩色内容（按钮、图标、色钮）最高档。高权重粒子更大（最多 +70%）、坚持到最后（白底先散尽，收尾余缕以内容色为主角）；彩色格子还会真实多发两颗副本粒子（起飞时重叠、飞散后成簇）；白底粒子飞散途中更早变稀薄。粒子颜色本身逐位不变（仍真实来自对话框内容），动画总时长不变，出现与消失动画同时生效。已在三星与 OPPO 真机验证：改颜色面板消散时色相条化作彩虹粒子带、色钮碎成饱满彩色团，出现时彩色烟缕先声浮现；普通对话框文字骨架与彩色点缀层次自然。

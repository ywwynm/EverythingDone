# dialog-particle-dismiss debug 发布日志

## 2026-08-26 粒子消散第二十一版：凝聚出现动画 + 修复出现期偏黑

- 弹窗出现现在有了与消散呼应的凝聚动画：面板以"起沙的逆过程"在约 320 毫秒内成形——粒子从散开约 40dp 的近距离落回原位、面板区域逐格显现，末帧与真实面板逐像素一致后无缝切换。时长与普通入场动画相当，不拖交互节奏；重建恢复（如旋转）不重播；含实时画面的弹窗与系统关闭动画时自动跳过。
- 修复弹窗显示期间背景比消散动画开始时更黑的问题：个别情况下系统变暗未被主题声明完全禁用、与接管暗层叠加。现运行时再清一次系统变暗标志，全程统一为 Android 默认浓度的单一暗层。

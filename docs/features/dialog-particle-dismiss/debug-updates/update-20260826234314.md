# 对话框粒子动画：锋线浓带与稀疏尾的强对比

## 掀起的纱带真正变厚了

上一版把"厚"做在固定的起点区域、且靠透明度渐变区分浓稀，对比只有两倍左右，观感上处处一样。对照鸿蒙截图重新解构：浓的是**跟随锋线移动的弧线带**——刚碎化的粒子组成浓密亮带，锋线扫过之后粒子迅速稀疏，浓稀对比来自**数量**而非透明度。本次改为寿命两极分化：约三分之二的粒子短寿命，只活在锋线带里（组成浓带后迅速消失），其余长寿命粒子稀疏地飘完全程（内容色的长寿概率更高，余缕仍以彩色为主）；配合平台式透明度（前半寿命满亮、之后快速谢幕），锋线带内满密满亮、带后数量骤降。效果是一条浓亮的纱带随锋线掀过对话框，身后留下稀疏残缕——数量对比约三比一，叠加透明度后浓稀分明。出现动画对称地呈现"稀纱渐浓、凝实前沿最亮"的递进。总时长与其余观感不变。已在三星与 OPPO 真机逐帧验证浓带与稀疏尾的对比。

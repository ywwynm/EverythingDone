# Dialog 粒子消失：Android 与桌面 A 共用连续布面轨迹

用户在上一版实机中确认 Android 与桌面模拟器仍有明显差异，并进一步澄清：关闭操作来自
左上方的真实触摸 dismiss，而不是返回键。本版不再继续调整旧的逐粒子解析近似，而是把
桌面 A 已确认的连续布面模型直接移入 Android 生产路径。

- 新增 `ParticleDismissClothModel`：使用与桌面 A 一致的 `24×15` PBD 网格、结构/剪切/
  弱弯曲约束、渐进贴附、法向与切向风、下边缘侧流和后段姿态约束；开场未脱附主体保持
  原位，边缘局部受风并同步粒子化。
- 渲染初始化时生成 241 帧 `(x,y,z,released)` 连续布面状态，并以 `RGBA16F`
  `sampler2DArray` 上传。粒子从同一曲面取得当前位置、脱离位置、速度、法线、曲率和投影
  压缩，随后进入有界弹道；不再用多个彼此断开的粒子条带模拟帷幔。
- 静止表面和粒子层使用同一释放时序；修复非正方形 Dialog 中按像素宽高计算释放投影、
  导致它与归一化 PBD 材料坐标错位的问题。孔洞边界、布面折曲和粒子脱离现在连续衔接。
- 彩色内容只增加同一轨迹上的真实采样数，不再具有独立速度、寿命或尺寸路径；触点柔光
  只沿原始 RGB 调整亮度。折叠高密区由真实曲率和投影压缩产生，不创建独立 emitter。
- 左上触摸关闭时，只在当前 `MotionEvent` 分发栈内传递真实触点，同时用于主方向和光源；
  返回键、异步完成及代码关闭不会复用历史触点，继续走无触点右上回退。
- Android 消失材料统一为约 144 列、最多 3 个同轨迹采样。真机夹具中的最坏顶点调用从
  约 191,250 降至 61,344；按相同真机素材和显示尺度把软粒子点径校准为 `0.66×cell`，
  在不增加顶点数的前提下匹配桌面 A 的有效覆盖率。

已通过 2 项连续布面数值测试、3 项 canonical Shader 结构及真实 `glslangValidator` 编译
测试，`:app:assembleDebug` 完整成功。使用同一真机背景、Dialog、左上 `-128°` 方向和
归一化时间逐帧复核了 `t=0.32/0.47/0.65/0.70`，Android 与桌面 A 的开场局部脱附、
连续折叠区和尾段离场保持同一整体形态，浏览器控制台无错误。

本次未使用 ADB；发布后仍需在真实手机上手动检查连续播放帧率。

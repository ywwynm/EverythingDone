# dialog-particle-dismiss debug 发布日志

## 2026-08-26 粒子消散第七版：文字保持清晰 + 弧线飞行轨迹

- 修复动画开始瞬间弹窗内容变模糊：此前"尚未消散的区域"由粒子点阵拼回原图，本质是按粒子网格的重采样，文字笔画会糊。现在未被消散波前扫到的区域直接以逐像素原图显示（新增静止图层，与粒子共用同一套波前公式逐格擦除），动画全程中尚未消散的文字保持完全清晰，与真实弹窗无差别。
- 打破上一版"整团像做了线性拉伸变形、两侧斜边过于一致"的规整感：新增低频弯曲场——不同区域的粒子获得不同的转向角（左右弯向不同），且转角随时间平滑增大，起飞时仍朝触点方向、随后逐渐弯出弧线，飞行轨迹呈曲线而非直线，云的边缘不再平行对称。
- 弯曲是大尺度、空间连贯的（相邻粒子弯向一致），保留上一版的整体方向感，不回到混沌。
- 两项均已在桌面序列帧蓝本验证（按钮点击与点击左上方外部两个场景）。

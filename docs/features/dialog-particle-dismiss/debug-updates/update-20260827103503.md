# 对话框粒子动画：悬浮粒子场与弯曲断续的浓带

## 整卡先化为悬浮粒子场，浓带弯曲断续各边不同

按最新三轮反馈的完整重做：一、动画开始约 0.15 秒内整卡零星碎化为**悬浮粒子场**——白底大部分格子直接消失、露出对话框**底下的界面**，仅少量白粒原位缓慢漂浮（抽稀率随空间起伏、稀疏场浓淡不均）；边缘与有颜色的区域保留密集粒子（轮廓可辨），随后揭开线扫过把悬浮的粒子掀起飞散。二、**浓带 = 边缘与内容色转换出的密集粒子群**（纯粒子构成，配三倍副本、辉光与尺寸增强）——且不再是笔直描边：边界线位置受噪声摆动呈**波浪弯曲**，沿边强度低频变化（同一条边有的段浓、有的段稀、有的段断开），四条边对噪声采样不同、彼此表现各异（有的边先掀、有的边后现）。量化：真机帧上浓带亮点密度 0.33–0.38、稀疏悬浮场 0.04，比值 8–9（鸿蒙实测 4–8 区间上沿）。出现动画不受影响，总时长不变。三星真机逐帧验证弯曲、断续与各边差异。

# Dialog 粒子消散：2.5D 卷曲片层、触点光照与帷幔密度层次

本轮继续对照 HarmonyOS 7 参考视频，解决现有消散效果空间层次偏平、不同区域粒子密度
近乎一致的问题。

## 需求与分析

- 用户选择“有厚度的半透明粒子片层发生空间卷曲”，不采用粒子随机向屏幕内外飞散。
- 半透明材质只作用于已被局部帷幔激活的区域；未触及区域保持完整、清晰。
- 首版采用固定中等强度，不新增 2.5D 开关、调节入口或参数面板。
- 真实触点同时作为光源平面位置；所有无直接因果触点的关闭统一使用右上虚拟触点，方向
  从正上向右偏约 30°。任何可归一化的真实触点仍严格决定运动方向。
- 用户在实现过程中进一步指出：参考效果的揭开帷幔明显比其他区域粒子更密，而当前
  Shader 实际只做了很小的 alpha 起伏，cell 占用率基本一致。该判断经代码和桌面输出确认。

### 实现

- `GestureAnchoredDialog` 只在当前 `dispatchTouchEvent()` 调用栈内传递直接导致关闭的触点，
  不再复用历史 `lastTouch`；返回、异步完成和代码关闭稳定走右上虚拟锚点。
- `ParticleDismissSpec` 增加虚拟柔光源坐标。Shader 将触点 XY 与固定屏幕前方伪深度组合，
  以连续片层法线计算原色明暗，避免屏幕平面点光源的亮斑奇点。
- 复用既有三个消散顶点副本，在单次 draw 内按后层、主体层、前层排序；三层共享连续
  折叠深度，以约 ±12% 调制速度、粒径、透明度和小幅投影视差，顶点总数不增加。
- 空间层次在局部激活后快速建立，于高密度帷幔阶段达到峰值；粒子中后段解耦时，深度与
  光照同步衰减，尾段只保留轻微层次。
- 增加真实粒子数量差：揭开后 0–120ms 完整采样，120–220ms 过渡；尾流面板色保留
  22%–30%，内容色保留 52%–60%。三层共享同一个逐 cell PCG 抽稀结果，既保持片层厚度，
  又让内容色持续可辨。
- canonical 桌面模拟器新增后/主/前三层、连续伪深度、帷幔/尾流密度阶段和相反光源位置
  A/B 输出；多方向矩阵中的无触点右上场景改为 -60°。

### 验证

- 内容色强调：2.48×，门槛为 2.0×。
- 三层 alpha：back/main=0.502，front/main=0.761。
- 深度方差：帷幔阶段 0.0324，尾段降至 0.0171。
- 帷幔/尾流视觉覆盖率：3.34×；改变光源位置产生可测 RGB 明暗差 1.966。
- canonical GLSL 3.30 与原生 GLSL ES 3.00 均编译通过。
- `:app:testDebugUnitTest` 与 `:app:assembleDebug` 通过；未使用 ADB。

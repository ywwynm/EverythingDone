## 2026-08-26 粒子消散第八版：漏斗形收拢（Genie 效果）

- 消散云新增沿触点方向的漏斗形收拢，类似 macOS 窗口收进 Dock 的动画：每个粒子相对"过触点的主轴"的横向偏移会随飞行进度逐渐收回。配合波前时序（靠近触点的一侧先激活、飞得久、收得多；远侧后激活、仍保持全宽），整团云呈现明显的一端宽、一端窄的锥形——点弹窗下方时上宽下窄、底部收成窄流；点斜角方向时锥形沿斜向倾斜。
- 弯曲弧线、烟缕摆动、浓淡不均等既有特性全部保留，收拢与它们叠加。
- 已在桌面序列帧蓝本验证点击下方（上宽下窄漏斗 + 中央收束尾）与点击左上（斜向锥形、先导流收成窄尖）两个场景。

# 增强弹窗消散的卷曲流束与内容色

## 本次调试更新

根据上一版的实际反馈，继续增强钢铁侠参考中的卷曲、聚散感，以及灭霸参考中的细缕粒子流。桌面与 Android 仍使用同一套规则，人物照片和应用弹窗都不选择专用参数。

运动从邻近微片的连续卷动开始，短时向弯曲流线聚合，随后解除汇聚并散开。减弱初段独立随机分离，保留主方向持续前进的限制；第一轮过细、过整齐的尾段已经放松，避免出现规则条纹或整群回弹。

新增 ParticleMicroflakeContent，从快照主色识别面板，对文字、图标和其他非面板颜色提高实际微片份额。每个内容格最多增加两片原色副片，释放之后再逐渐显现；不改静止弹窗的外观，也不把全部粒子统一染色。浅色、深色和有色面板都用相同识别规则，总材料量不超过 16 万。低透明度边缘按实际覆盖降低权重，避免颜色解码量化被放大。

返回键关闭弹窗现在固定向左上 45° 消逝，并清除此前触点的影响。取消按钮和点击弹窗外部仍严格跟随实际触点。返回分发继续保留 ComponentDialog 的可取消与回调行为。

验证包括 12 项相关 JVM 测试、15 场景起止与重播、150 组方向的连续轨迹、两台指定设备共 30 组独立建材及 GPU 对照。七个开发素材以外复核六个既有素材，并新增咖啡照片和有色面板作为未参与调参的输入。9018f404、R5CW20BLNKL 均通过真实语言、附件、渐变颜色关闭、八方向触点及各 10 次连续开关；刚点击标题后立即返回仍为左上方向。

桌面已导出 86 个双速度及对照视频，三星另保留真实系统录屏；OPD2515 使用真实阶段截图。输入法恢复仍可能遮挡部分动画尾段，人物的局部侵蚀形状也仍与华为不同，本版改善的是所有素材共同使用的运动和内容色表现。

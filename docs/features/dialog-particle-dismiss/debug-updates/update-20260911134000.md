## 弹窗消散：恢复弧边与拖尾分离，增强近远移动差异

用户指出，初版钢铁侠左中部的一条弧边随后形成横向轮廓和下方拖尾，当前实现仍缺少这一变化；近、中、远的动画也仍难辨认。本次继续使用共同运动与粒子规则，不用新增参考替换此前所有轨迹。

- 逐项对照发现，减弱叠加风速和最低速度不能恢复分支，固定随机坐标与释放时序变换则可恢复。现在根据共同随机输入中的局部起点独立程度调节变换幅度，避免连贯卷边的供料区域被过度错开；仍保留镜像和较大起始布局变化，没有人物专属规则，也没有额外描绘亮曲线。
- 真实触点的远近改为按该方向可用的屏幕背景范围解释，以有界增益调节实际速度和位移。窄背景也有可见差异；三素材六组输入的远近中位速度和位移约相差 47%～66%。粒子继续随场运动，不被触点吸成一点，也不在屏幕或原控件轮廓处停靠。返回键仍固定左上、默认强度。
- 桌面新增钢铁侠“参考／调整前／当前”的整体及局部三栏视频，重点检查 0.43～0.65 的分离过程。18 个场景共 144 个正常速度／半速视频，保留四参考、随机形态、自有弹窗八方向和屏幕内近中远对照；历史标注视频没有整套重新渲染。

Python 与 Android 的 ParticleMicroflakeVariation 同步随机幅度，ParticleFlowGeometry 同步屏幕内远近换算，ParticleDismissController 传入实际窗口可见范围，ParticleMicroflakeRenderer 使用同一共享着色器。共同速度场、释放基底和置信度资源未更换。

234 组运动状态、18 场景渲染性质、30 组方向和 13 项 JVM 测试通过。9018f404 完成 13 组独立建材／GPU 对照，以及真实弹窗近远背景点击、返回左上和动画层清理；R5CW20BLNKL 仍未授权 USB 调试，本次不能计作该设备已测试。

本次恢复了目标分支观感，但弧边亮度、局部形成时刻，以及向上参考和灭霸的释放、细缕密度仍有差异，不宣称与华为逐帧一致。发布包随后核对资源、安装包和阿里云文件散列。

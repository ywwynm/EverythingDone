# dialog-particle-dismiss 偏好记录

## 2026-08-27 掀起点分布

- 首批局部掀起点应**主要**位于飞行方向的反向一侧，但绝不能把“主要”实现成“全部”。
- 侧边以及少量飞行顺向一侧也要允许出现起点，使多个局部帷幔近同时出现，避免形成单侧
  扫描或整齐波前。

## 2026-08-27 重复播放的变化

- 允许每次消失动画的掀起点位置、帷幔弧度和横向摆动有所不同。
- 随机必须受结构约束，不能改变主方向、起点分布原则、近同时启动或早期片层相干。

## 2026-08-27 揭开前的完整性

- 未被局部帷幔触及的 Dialog 区域应保持完整、清晰，不接受动画开场整卡全局打孔。
- 底层内容只随着各条帷幔的局部推进逐步显露。

## 2026-08-27 内容色强调

- 粒子必须逐位继承 Dialog 快照的真实颜色，不能统一染成白色或固定强调色。
- Dialog 本体背景色面积通常占绝对多数，因此仅仅“保留原色”仍不够；应继续对与本体色
  距离较大、尤其高饱和的内容色粒子提高视觉权重，使彩色控件、图标和标题形成清楚的
  彩色粒子团与尾流。
- 颜色增强不能破坏本轮确定的多起点、局部完整性和早期片层相干结构。

## 2026-08-27 空间层次

- 用户认为 HarmonyOS 7 参考效果具有明显的 3D/空间感，而当前实现仍显得平；后续迭代
  需要把空间层次作为独立目标，不能只继续调粒子密度、颜色或二维轨迹。
- 需要先分清透明材质、片层卷曲、前后遮挡、尺度/亮度差与屏摄光晕各自的贡献，再决定
  实现范围；不能把“3D 感”简单替换成全局模糊、阴影或随机改变粒径。
- 用户选择连续卷曲的半透明 2.5D 片层，不选择粒子明显向屏幕内外飞散；空间层次应来自
  连续曲面、稳定前后层和受控光照，而不是逐粒子的随机纵深。
- 半透明只从各局部片层被激活后开始；未触及区域保持原始外观。面板本体色粒子可更通透，
  真正的内容色粒子仍需更实、更鲜明。
- 首版空间层次采用中等强度；用户希望先看真机效果，再决定是否增强，不能在首版直接使用
  强透视或夸张的前后尺度差。
- 不需要为 2.5D 空间层次保留独立开关、调节入口或运行时参数面板；中等强度直接成为
  消失效果的一部分。后续如需根据真机观感增减强度，可以修改实现并重新验证。
- 用户倾向把本次触点作为粒子片层的光源位置，使明暗响应与交互位置相关。实现上应使用
  位于屏幕前方、范围柔和的虚拟光源，避免把贴在屏幕平面的数学点光源直接套入 Shader，
  否则触点附近容易产生高亮奇点和明暗骤变。

## 2026-08-27 返回方向

- 系统返回操作关闭 Dialog 时，粒子应向右上方消逝，不再默认正上方。
- 所有无直接因果触点的关闭路径均使用同一个右上虚拟触点，不只限于系统返回；虚拟触点
  同时承担运动目标和光源位置。只有直接触发本次关闭的真实触点可以覆盖它。
- 右上方向从正上向右偏约 30°，以上行为主，不采用 45°。
- 不为接近 Dialog 中心的真实触点设置宽阈值或方向混合；除无法归一化的数值零向量外，
  真实触点始终严格决定运动方向。
- 2.5D 深度与触点光照应在局部高密度帷幔阶段最明显，随粒子中后段解耦同步衰减；末段
  只保留轻微空间层次。
- 揭开锋线附近必须具有明显高于其他已消散区域的真实粒子密度；不能让所有区域维持相同
  网格占用率后只靠 alpha 起伏表现浓淡。内容色尾粒子仍应比面板本体色保留更多。
- 用户真机反馈第四十三轮的 3D 感仍不够强，希望增强空间感。后续不能只继续放大三层的
  静态尺度差；需要重点检查粒子群轨迹的曲率、形状演变、交叉遮挡、密度锋线与 z 轴视差
  是否共同形成可感知的空间运动。

## 2026-08-27 不透明控件参考与桌面对比方向

- 新视频 `93292e5c744d4770c4f7ecb686f3dd60.mp4` 展示了不透明图块从完整表面逐步粒子化并
  消散的过程，后续把它作为运动结构、断裂锋线、粒群密度和空间层次的主要视觉参考；
  旧视频只保留为历史对照。
- 本轮网络调研不再搜索华为或鸿蒙的具体做法，而是研究粒子化消融、尘化解体、流场输运、
  连续侵蚀锋线等效果名称及其运动规律和视觉组织方式。
- 桌面并排对比中的模型消散方向改为左上，以便与新参考直接观察差异；这只影响研究用
  对比视频，不改变应用内“真实触点严格决定方向、无触点默认右上”的正式行为。

## 2026-08-27 左上消散的区域时序与孔洞边缘

- 左上消散不能等价为全 Dialog 各区域以近似相同速度消融后整体平移。宏观进度应清楚地
  从运动反向侧的右下向左上推进：右下区域更快，其他区域仍可同步产生局部消融。
- 飞行顺向侧的左上角也应在动画早期出现少量已经脱离、向左上移动的粒子，不能因其属于
  下游侧而让完整角部明显停留；该早期局部起碎不应反过来抹平右下到左上的总体速度梯度。
- 消融孔洞与尚未消融表面的接触边缘应具有柔和、细碎的过渡区，避免完整表面沿锐利的
  二值轮廓直接消失。柔化应由局部表面到粒子的渐变交接和前缘细粒共同完成，不做全局模糊。
- 高密度帷幔与已揭开区域的稀疏粒群必须在连续播放中直接可辨；仅让离屏覆盖率指标通过，
  但肉眼仍感到各区域近似等密，不视为完成。应先在桌面 canonical 对照中收敛，再发布到
  Android 真机版本。

## 2026-08-27 归一化阶段必须直接匹配参考

- 约 `t=0.32` 时，飞行顺向的左上角与反向侧右下区域都必须能直接辨认粒子群，不能只
  看到低对比灰雾。
- 约 `t=0.47` 时，右下揭开锋线应形成明显更亮、更密的帷幔条带，而不是只在密度诊断
  数值里高于尾流。
- 约 `t=0.70` 时，Dialog 完整内容应已基本全部粒子化，进入整体受风输运阶段；到
  `t=0.90` 不得仍有可辨认的完整表面。
- 除内容颜色、控件纵横比和拍摄背景差异外，后续优先让每个归一化阶段的表面占比、粒群
  可见性、浓带位置和输运轮廓贴近参考，而不是只让抽象指标达标。
- 彩色控件、文字和图标粒子不得因单独的寿命、运动时钟、粒径或透明度规则而游离在主体
  粒群之外。所有颜色统一服从同一帷幔与尾流运动；彩色内容的存在感主要通过保留更多
  真实粒子数量来强化，使其在同一粒群内更密，而不是更大、更慢或更长寿。
- 帷幔条带必须在未经诊断着色或人工圈选的普通合成帧中立即可辨认：沿消融锋线形成连续、
  狭窄、由清楚粒子核心构成的高密高亮带，并与残余完整表面的白边和普通模糊过渡明确区分。
  仅有更高的区域 alpha、局部光学密度数值，或需要说明“条带在哪里”才能看见，均不算完成。
- 在已经能与未粒子化表面分离的前提下，帷幔浓带还应继续提高真实粒子密度；彩色控件区域
  也应产生更多粒子，使蓝、橙、绿、紫等原始颜色在同一帷幔和尾流中更突出。两者都优先
  调整真实 cell 数量及空间汇聚，不为彩色粒子新增独立速度、寿命、尺寸或材质规则。

## 2026-08-27 夸张密度与非线性卷流

- 下一版不再做小幅加密：固定 1px 点中心回归中的帷幔/尾流真实粒子密度比目标为
  `4.2×`，彩色区域真实粒子数量表示目标为 `4.5×`。
- 粒子输运必须具有清楚的非线性速度变化，整体观感先慢后快；不能让位置近似随时间线性
  增长，也不能只用末段淡出掩盖匀速轨迹。
- 不同局部帷幔可以先沿自身边缘发生相干侧向卷流，再逐步并入主消逝方向。左上对比场景中，
  下边缘尤其左下侧的帷幔从归一化约 `t=0.5` 起应能看到向左的切向流动，随后顺势向上
  被揭开；不能让全部粒子始终沿同一个左上向量直线平移。
- 方向变化必须由局部帷幔位置、边缘切向和生命周期连续决定，同一邻域保持相干；不使用
  逐粒子的随机方向散射或高频抖动制造“丰富度”。

## 2026-08-27 Android 一致性与逐帧边缘约束

- Android 真机与桌面模拟器必须在相同归一化分辨率下得到接近的粒子覆盖率、点尺寸和
  帷幔亮度；桌面端经过缩小采样后显得正常、真机却变成过密白带，不视为同一实现。
- 彩色元素与面板粒子必须共享完全相同的激活、速度、轨迹、寿命、尺寸、透明度和深度
  运动。颜色存在感可以继续来自更多真实 cell，但不得因数量掩码形成看似独立移动、独立
  成片或更持久的彩色结构。
- 左上消散在归一化约 0.47 时不得出现从左下贯穿到右上的细长对角脊线，局部帷幔端点也
  不得以尖锐形态明显越过 Dialog 上边界；左上边缘必须保留与参考相近的宽、散粒子群。
- 后续视觉验收按归一化时间逐帧比较四条边缘的粒子起点、外扩距离、密度宽度和端点形态，
  不再只比较全局密度比、质心速度或某一张关键帧。

## 2026-08-27 真机密度反馈覆盖旧倍率目标

- 用户确认 Android 上的帷幔明显比桌面模拟器过密，因此此前基于错误桌面点大小得出的
  `4.2×` 帷幔/尾流和 `4.5×` 彩色数量倍率不再是验收目标；后续以修正后的同尺度栅格
  和逐帧普通合成观感为准，不能为了保留旧数字再次把真机堆成白色实带。
- 彩色元素只允许在同一占用率公式中适度增加真实 cell，运动、激活、寿命、点径、材质、
  深度和淡出必须与中性色完全一致。灰色文字、阴影和暗色背景不得因为偏离面板主色就被
  当作彩色内容加密。
- 约 `t=0.47` 的帷幔应是有厚度、能辨认单粒子的局部粒云，不能是从左下贯穿右上的
  等时斜线，也不能在右上端形成尖锐越界；约 `t=0.32` 的左上起始粒群必须直接可见。

## 2026-08-28 连续逐帧形态匹配

- 后续不能只在少数关键帧检查全局数值；应把参考动画的完整有效时段按归一化时间逐帧
  对齐，分别检查全局、四条边缘、四个角部和局部揭开锋线，并同时保留普通合成画面、
  放大局部画面与密度/边界诊断图供目视复核。
- 帷幔必须由可测的局部粒子密度峰形成。需要从参考逐帧提取二维密度场、高密脊线的
  位置、宽度、连续性和相对尾流的密度差，再让模型借鉴这一随时间变化的分布；不能只
  依赖一个固定倍率或某个时刻的全局分位数。
- 高密脊线的边缘应形成与局部“掀开”范围一致的连续曲线，尤其要检查右下等角部的曲率、
  端点和局部法向，避免直线截断、断裂短段、尖角或与实际消融边界无关的悬浮条带。
- 未粒子化表面与粒子群之间的交界必须是有宽度的连续曲线过渡。参考中的表面保真度、
  中间覆盖率和边界梯度应成为独立回归目标，不能以二值阈值直接切断 Dialog，也不能用
  全局模糊掩盖硬边。
- `t=0.54` 以后不能过早把相干片层抽稀和淡出。约 `t=0.70` 时即使完整表面已经消失，
  仍应保留可辨认的高密粒子带、连通曲线和整体粒群形状；后半程先由相干片层随风输运，
  再在接近结束时逐渐散开和淡出。

## 2026-08-28 单一整体卷流与真机性能

- 同一时刻不应出现多条彼此分离、各自保持完整轮廓的粒子条带或粒子岛；Dialog 必须始终
  被感知为一个整体，在一个连续揭开前缘后方共同卷入主消逝方向。
- 向左上消逝时，中段已经应呈现明确的整体左上输运；右下区域只能保留少量连接到主粒群
  的稀疏尾流，不能继续形成独立高密粒块。
- 高密帷幔可以包含局部起伏和多个密度峰，但这些峰必须属于同一连续曲面或主粒群，不能
  通过多个持久 cohort 分别维持。
- 视觉增强不得以明显增加真机卡顿为代价；需要同时约束存活点覆盖、三层过绘和 Shader
  计算量，并优先删除不能直接贡献最终观感的并行结构。

## 2026-08-28 先验证连续布面运动

- 后续调优先暂停粒子密度、粒径和独立尾流参数，先把 Dialog 视作一张拓扑不撕裂的连续
  薄面，单独验证它从原平面逐步解除约束、被风掀起、折叠、拉伸并飞向终点的整体运动。
- 尚未粒子化的区域应近似停留在原始 `z=0` 平面；已经粒子化的区域对应同一薄面中已被
  掀起的部分。两者共享同一释放边界和位移场，交界必须无缝，不能成为两套独立动画。
- 高密粒子条带优先解释为连续薄面折叠、屏幕投影压缩或前后层重叠的结果，不再通过多个
  独立发射区、出生队列或局部尾流直接拼出条带。
- 桌面端先提供关闭粒子化的连续纹理与网格视图，逐帧对照轮廓、折线、角部翻卷和整体
  加速；整体运动确认后，再让粒子继承同一曲面的坐标、速度、法线和投影密度。

## 2026-08-28 保留 A/B 并先完善桌面交互网站

- 连续布面原型的 A“多点解除”和 B“单一卷边”都保留，不再预先淘汰 B；两种运动都要
  接入同曲面的粒子化，以便直接对比最终视觉，而不是只看完整纹理网格。
- 提供可在桌面端直接播放、拖动时间、切换 A/B 的交互网站；效果确认前不迁移 Android。
- 网站中的完整层与粒子层必须共享材料坐标、释放时序和运动曲面。彩色区域可以增加粒子
  数量表示，但不能形成独立轨迹或单独的动力学系统。

## 2026-08-28 A 改为牵伸后整面平移，不做完整翻面

- A 在开场就应沿消逝方向缓慢牵伸和移动，左上顺风侧的拉伸要先能被感知，不能等到中段
  才突然开始整体位移。
- A 只需要局部区域发生折叠；右下不能在后段整体卷到左上，使整张布发生近似完整翻面。
- 后段应降低局部折叠相对整面的占比，让整张连续粒子面保持大体朝向并直接随主风离场。
- B 继续保留完整卷边行为，作为与 A 不同的对照方案。

## 2026-08-28 开场同步粒子化，后段解除材料坐标锁定

- A 开始向左上牵伸时就必须同步开始粒子化，左上顺风侧应在最早几帧出现可辨认粒群；
  不能先移动完整 Dialog，再延迟生成粒子，也不能继续由右侧或下边缘抢先建立主趋势。
- 已粒子化区域在形成帷幔时可以短暂跟随连续薄面，但后段不能永久保持原材料邻接关系；
  否则所有粒子会机械同步移动，并继续描出被拉伸的 Dialog 外轮廓和按钮排列。
- 后段粒子应继承脱离瞬间的薄面位置、速度和法线，随后在统一主风中产生连续的速度差、
  曲折轨迹和错峰消隐。所有颜色继续共用同一输运公式，彩色区域只增加粒子数量表示。

## 2026-08-28 开场拉伸不得带动 Dialog 整体平移

- A 的开场阶段应保持 Dialog 的贴附主体位置不变，只允许已经离面的区域沿消逝方向做
  适度拉伸。
- 不得为了锁住整体质心而让背风端做等量反向补偿；未脱附区域应继续停留在原位置，拉伸
  来自已脱附区域受风后通过连续布面张力带动相邻区域。
- 真正的整体离场只能在后续主风阶段开始。

## 2026-08-28 末段不做各向扩散，帷幔必须是窄折叠亮带

- 粒子脱离布面后仍应以消逝主方向为绝对主导；可以保留低频、连续且有界的横向曲折，
  但不得随飞行时间持续放大成向四面八方扩散的云团。
- 帷幔密度不能从大面积普通压缩区统一增加。应只选取真实薄面中同时具有明显折曲和投影
  压缩的窄区域，使其形成可辨认的亮带或曲线。
- 帷幔粒子与普通粒子继续共用同一输运公式；折叠身份只允许影响局部采样数量和相干程度，
  不得形成独立发射器、独立颜色轨迹或第二套风场。
- 帷幔区域的真实粒子密度应维持约 `4.2×` 的明显对比，并在脱离布面后保留一段时间，
  不能一进入自由飞行就立即失去亮带形状。

## 2026-08-28 折叠必须由细粒子增密，残余表面不得形成尖角

  单粒子或单独改透明度伪造密度。
- 粒子化过程中剩余的完整 Dialog 必须保持连续、圆滑的布面轮廓；不得出现尖锐半岛、

- 彩色内容继续与中性色共用释放、曲面、速度、寿命、深度和粒径，只通过真实保留率与

## 2026-08-29 留存区域沿主风迁移，粒群不保留矩形包络

- 完整层与粒子层的柔和交界必须保留，但柔化不能再次把释放场变成从整圈边缘均匀向

- 主剥离前沿应主要从飞行反向一侧向飞行方向推进；其他边缘可以有少量同期解除点，
  但只能形成受限的局部扰动，不能各自向中心扩张。向左上消逝时，末段未粒子化区域

- 粒子群必须来自同一张连续薄面并维持整体连贯，但脱离后需要具有连续的流线弯曲、
  顺风速度剪切和错峰消隐，使外包络成为随风变化的有机曲线；不得继续描出仅被拉伸的
  Dialog 矩形轮廓，也不得用逐粒子无关随机散射伪造灵活性。

## 2026-08-29 柔边约束不得因其它视觉调优回退

- 消融边界的柔和性是持续约束，不是一次性修复项；后续调整粒群轮廓、帷幔密度、颜色
  强调或运动速度时，都不得重新引入内部尖嘴、狭长残片或外边缘的直线截断。
- 多个局部早发点只允许产生少量表层粒子，不能各自形成向内扩张的宏观圆形波纹。宏观
  留存面必须始终由一条连续前沿切分，任何两个局部区域相遇时都不得夹住一条细尖白片。
- 柔边应来自同一释放相位的有限宽度过渡、材料尺度平滑和原位接缝粒子；不能通过扩大
  单粒子、整张 Dialog 模糊或把局部孔洞直接清零来掩盖拓扑问题。

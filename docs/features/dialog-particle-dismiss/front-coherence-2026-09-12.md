# 前沿衔接、局部收束与原表面保持

用户在完整画面上指出密度与交接候选仍有明显差异：早期右侧前沿衔接点偏低，右上粒群过散，左侧弯曲不足且下方拖尾过宽，中心原纹理又过早破碎。本轮暂停发布，冻结该候选于 `tuning-0909-gpt6/archive/before-front-coherence/`。

固定钢铁侠 122°、种子 909602，复现约 0.404、0.562、0.574 及相邻时刻；先看完整画面，再用局部测量区分释放、运动与绘制。所有诊断区域仅用于测量，不写入运行时，不引入人脸或素材名称规则。

已确认边缘外推力是右上角外散及下方拖尾过宽的主要来源，单独删除新增随机扰动并不能解决。调整释放时序后，若直接让剥离法线在原控件边缘产生向外的强推力，仍会形成右上方突出的粒群。因此在自由边界附近平滑减弱朝外的剥离力，保留流场、惯性与离屏运动；没有钳制位置或设置碰撞边界。

候选保留原来的连续流场及随机时钟，只修正释放入口：已经沿飞逝方向推进、且接近背向自由边界的前沿稍早接到该边界；内部较晚释放的材料略延后。将这部分修正同时加入流场时钟会产生过早突起，已排除。对所有边界一律提前也会破坏左边缘、上边缘的完整区域，已排除。

绘制保持原有光照，未增加亮边。原表面采用较连贯的渐隐交接，独立随机散开主要在流场可信度低、且粒子已离开源面之后发生。缩小横向展开后适度保留拖尾颗粒，以避免仅靠降低密度掩盖宽度。白底长弹窗验证显示内部延迟需要随面板材质收减，目前继续验证这一点。

整帧消融否决了上述较强候选：对内部流动也延后独立展开、以及过大的内部释放延迟，会改变中段整体覆盖。最终收敛为较小的入口修正（内部最大 0.025 秒，背向边界最多提前 0.065 秒），独立扰动仅在自由边界朝外剥离阶段收减；内部原有卷动节奏保持。白底材质对内部延迟再收减 65%。

固定案例实际渲染确认：右上诊断源区出生中位数从 0.425 提前至 0.391；约 0.574 时右上方明显外散消除，粒子仍连续运动。0.562 时中心原表面覆盖由 0.191 增至 0.298；拖尾可见覆盖宽度由 68 缩至 61 像素，覆盖总量没有减少。顶部及左侧应完整区域在 0.43 的释放比例没有增加。此处数值是同一素材、同一视窗的诊断量，不是视觉相似度。

八个整帧相位的低频外观误差均值从 7.406 降至 7.387；变化较小，不能据此宣称整体完全匹配。三个用户指定问题与邻近帧的连续外观仍作为主要审阅依据。18 个屏幕内近中远输入的速度、位移递增检查已通过，距离不改变出生时序或寿命。

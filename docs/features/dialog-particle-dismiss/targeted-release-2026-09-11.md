# 真实触点输运与局部释放前沿

> 本候选已于 2026-09-11 被用户否定：整体替换了既有轨迹，远近产生过强目标汇聚，部分演示触点超出设备屏幕。本页保留失败分析，不是当前验收结论；未发布到阿里云。

## 纠正上一轮结论

上一版近、中、远顺风行程中位数仅为短边的 0.122/0.146/0.164。数值单调不能证明视觉差异足够。代码只将距离经指数饱和后叠加小幅顺风速度，没有以实际触点参与逐粒子轨迹。这不满足用户本轮明确的触点输运要求。

前沿问题的待验证原因是：共同释放场随风向整体旋转，并在长面板上以固定出生权重平均多个释放时间；两者都可能保留或重新形成贯穿控件的等时线。不能仅增加粒子的运动噪声来修复释放轮廓。

## 新参考观测

- 原片 720×1280、30 fps、11.3 秒。有效消逝片段约在 4.1～6.1 秒，包含手持摄像机运动，不能直接把背景位移当粒子速度。
- 4.20 秒：主要是右上局部起始，左上边和大部分下半部仍完整。
- 4.33～4.47 秒：左下另一个局部区域扩大，与右上粒群分离，中间主体尚完整。
- 4.60～5.13 秒：两片粒群逐渐相连，左侧有局部弧状密集边；右下仍有未释放材料。主方向向上，释放顺序并非一条水平线自上而下扫过。
- 5.27 秒之后：残留材料继续在局部区域解除，早期粒群已向上运动、变稀。以上是图像证据，不声称获知华为内部算法。

## 实施与验收计划

1. 冻结上一版代码、资源、关键缓存。对新参考取稳定区域和归一化片段，提供可逐帧对照。
2. 用真实触点位置和整段动画剩余时间参与输运，保留局部卷动；不使用到点停止、位置夹紧或反弹。
3. 释放采用相互错开的局部区域，限制区域物理尺度。方向影响区域选择和输运，但不把一张跨幅等时线随风向整体转动。
4. 比较相同材料身份的实际速度、路程、目标接近程度与近远画面。检查局部起始、卷动、停滞回归和一秒结束；原速、半速距离矩阵与三素材八方向更新。
5. 桌面确认后同步 Android 共同实现，延续指定双设备验证及默认调试发布流程。

## 本轮实现依据

- [Houdini POP Attract](https://www.sidefx.com/docs/houdini/nodes/dop/popattract.html)明确区分目标位置、力、目标跟随和停止范围；仅有方向并不是逐点寻向。采用目标位置减当前位置构造输运，不采用其停止距离或反向排斥设置。
- [Houdini POP Steer Seek](https://www.sidefx.com/docs/houdini/nodes/dop/popsteerseek.html)提供面向实际目标的转向；与已有流场的速度响应分开处理，保留原大尺度运动和局部旋度。
- [Reynolds Arrival](https://www.red3d.com/cwr/steer/Arrival.html)的到点减速不符合持续消散需求。本实现是有限时长下的目标引导，未声称实现物理引力或严格的到点求解。

初次候选按每片短寿命计算剩余时间，出现细直条，已弃用。当前候选按整段动画剩余时间计算目标速度，逐渐加入引导，并保留约三分之二的原流场速度。每片朝触点附近的小范围移动，在完全淡出前允许继续通过，不夹紧到触点或屏幕边缘；并不承诺每片都在可见期间抵达触点。

释放使用沿控件周界错开的两个或多个局部起始区域，随机改变位置、时间和局部椭圆尺度；长面板增加区域数，尺度以短边为准。相邻前沿平滑相遇，共同释放场只提供小幅形态细节。风向只小幅改变局部时间，不再整体旋转这些区域；新释放时间差反馈到原流场局部时钟，保留解除与输运的衔接。

新的向上参考已用手机上的稳定特征作平面配准，中位重投影误差约 0.36 原片像素。关闭确认框与粒子动画有时间重叠，完整前景由较早帧的上半与确认框消失后的下半合成；这一取材限制明确记录，不将其作为像素级重建真值。固定种子 2 用于展示右上与左下起始的例子，全部素材仍使用同一模型，运行时不读取参考名称或图像来选择参数。

## 速度与显示范围的再核对

第一次完整导出后，在六格视频中仍难分辨远近，未采用该候选。最终将目标速度响应提前到释放后 0.018～0.12 秒，目标速度按整段剩余时间的 0.36 倍计算、下限 0.095 秒；目标项权重 0.84，原引导场仍保留至少约三分之二，并保留额外局部卷动。释放归一化时钟使用 1.45 次幂，局部扩展提前，最后释放时间仍为 0.744 秒。

同一素材、方向、种子下，对相同粒子身份测量可见期间位移及速度。钢铁侠向上，近／中／远位移中位数为短边的 0.286／0.471／0.775，速度中位数为每秒短边的 1.839／3.029／5.099。颜色弹窗左上方向对应位移 0.457／0.677／1.056，速度 2.484／3.652／5.781。三个指定素材、两个方向的六组距离序列均通过远点速度和位移大于近点 1.65 倍的检查；不是只比较流束外轮廓长度。

原截图边框会把远点行程裁掉，因此距离矩阵单独扩大取景范围，并画出真实目标点；每排三个距离保持同一比例。深色空白表示原截图以外区域。扩大取景前后六个检查输入的粒子状态逐项相同；它只改变画面范围，不改变粒子轨迹。普通视频和参考对照保持原取景。

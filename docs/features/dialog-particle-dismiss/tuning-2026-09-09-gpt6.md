# GPT-6 桌面粒子消散调优

## 工作范围

本轮继续在本功能目录维护轻量文档，大文件和实验代码放在 `docs/features/dialog-particle-dismiss/tuning-0909-gpt6/`。不修改 Android 实现，不创建 Git 提交。

## 实施顺序

1. 核对九段原片、三段重点序列和截图分层，重新记录首变、前沿、纹理留存、粒群输运、终点及时间口径。
2. 完成至少 100 个独立网络来源的阅读和价值提取。来源须有正文证据；重复 URL、打不开的网页、只有搜索标题而没有有效内容的结果不计入。
3. 整理运动、释放、材质、密度、合成和节奏模型。区分原片观察、公开资料结论和自主设计假设。
4. 实现可复现的桌面模型，先检视三段重点序列，再应用截图场景与任意方向。
5. 导出全部动画及对比视频；八方向矩阵用于钢铁侠和添加附件。核对画面、时长、末帧、速度标记与导出清单。

## 当前证据边界

- 九段视频文件名中的时间仅用于初始定位；其中有退出确认弹窗、慢放、拍屏、字幕和剪辑，不能直接作为粒子效果的统一时钟。
- 三段重点序列的起碎位置不同，尚不能假设全部从消逝反向侧开始。
- 单张弹窗截图不能提供被遮挡的真实背景；可见区域应保持对应，遮挡区域需明确标记为重建。
- 历史工作区已有 Android、桌面代码及文档修改，本轮在独立实验目录工作并保留既有内容。

# 保留共同流动并扩展形态范围

## 用户纠正与本轮边界

上一候选把新增向上参考当成统一替代形态，又让所有粒子强烈趋近触点，偏离用户意图。该候选已冻结于 `tuning-0909-gpt6/archive/rejected-target-attraction/`，没有发布。当前基线仍是 `archive/before-targeted-release/`，不是被否定的候选。

本轮目标是同一模型保留初版钢铁侠、新增向上钢铁侠、灭霸、科比中的不同形态可能性。触点距离产生适度而可辨认的速度、位移差异，不把粒子收集到一个点。演示触点必须位于素材所示手机屏幕内、弹窗外。

## 联合观测与相关参数

| 参考 | 观测到的主要差异 | 共同模型中相关的输入或参数 |
| --- | --- | --- |
| 初版钢铁侠 | 右下局部释放持续给弯曲粒群供料；左下密集边由上凸转为下凸；大部分左上边较晚解除 | 起点布局、释放先后、与后续流场保持同一局部时钟、已有共同场中的卷动与剪切 |
| 新增向上钢铁侠 | 右上与左下局部起始分离，局部曲边逐渐连接，右下材料较晚残留 | 主方向改变；局部起点的独立程度、位置及延迟改变；无需改成另一套速度模型 |
| 灭霸 | 右侧和中部逐渐解除，多个不等形态的细缕继续流动，左下残留较晚 | 多个起点及延迟、释放区域与共同卷动的相位关系、材质对应的可见粒子密度 |
| 科比 | 左侧局部先扩大成弯曲粒群，随后其他区域解除，主体释放节奏与另两段不同 | 局部起点位置和主次、不同局部时钟，不能只按相近的 128°／130° 方向解释差异 |

参考没有可靠显示每次真实触点坐标，也没有提供内部力场。因此上述对应关系是需要通过反例检验的建模假设，不是从画面唯一反推出的华为算法。用固定演示输入比较时，选择的种子与触点需明确展示；不能把选择过的输入计为新留出集。

## 实现原则

- 保留基线共同速度场、可靠区域、无观测区延拓、卷动与非周期细缕；没有重新拟合或替换共同速度表。
- 共同释放场继续作为基底。局部起点只按连续权重参与，权重由方向与矩形边角的几何关系、一次动画的随机输入共同决定。连贯卷边和更独立的局部区域均可出现，不按素材名称分支。
- 起点沿周界分布，数量随长宽比及随机输入改变，位置、尺度、延迟不固定等距等时。新释放时间仍反馈到原流场局部时钟。
- 去掉 `目标位置减当前位置／剩余时间` 的强汇聚。触点距离只对原速度作有界调整，出生位置到触点的夹角只产生小幅偏转；之后继续采样共同空间流场，不在目标点、控件或屏幕轮廓停靠。
- [Houdini POP Wind](https://www.sidefx.com/docs/houdini/nodes/dop/popwind.html)及[POP Solver](https://www.sidefx.com/docs/houdini/nodes/dop/popsolver)将环境目标速度与阻力响应分开，支持这里保留环境流动、限制触点影响的设计。采用其概念区分，不声称手机效果遵从完整流体物理。

## 屏幕内的距离演示

`touch_rect` 只标记源素材可见设备内、避开系统栏的测试区域，不是运动参数。向上及左上先选区域内的远点，再沿控件中心到该点的射线生成近、中、远三点。根据实际坐标计算方向和边缘外距离；所有点都断言在屏幕内、弹窗外。

颜色弹窗严格沿 135° 会先碰到左边缘，左侧只剩约 16 像素，不能假装有很长的可触摸空间。因此“左上”使用屏幕内左上触点反推的实际角度，视频显示角度及真实像素距离。原钢铁侠素材上方可用背景很窄，其三距离的绝对差别也应较小。

当前在桌面检查共同形态范围与屏幕内距离，验证结果随执行补充。先看形态、卷动和参数交换，再看数值；不能用最低远近比值或全场零停滞单独宣称视觉完成。

## 设备检查中的插值差异

六个常规设备输入及两组局部起点输入通过后，附件的 130°、种子 323 在 0.567 秒出现单颗粒位置差 1.015 像素，超过原有 1 像素门槛；99 分位差为 0.082 像素。该粒子的出生位置、释放时刻、局部时间偏移和随机值完全一致，排除了起点生成错配；仅将桌面速度纹理换成与手机相同的半浮点存储没有改善。正在用相同浮点权重的显式三线性采样区分硬件过滤与积分误差，保持原检查门槛。

控制实验确认：保留场数据与运动规则，只将两端过滤改为 `texelFetch` 后用相同浮点权重插值，最大偏差降至 0.0204 像素，99 分位降至 0.000655 像素。采用这一修复，原检查门槛不变。[OpenGL ES GLSL 规范](https://registry.khronos.org/OpenGL/specs/es/3.2/GLSL_ES_Specification_3.20.html)提供整数纹素读取及高精度浮点的定义；设备差异的具体归因依赖此次控制实验。采样坐标只用于读取场数据，不把粒子位置限制到纹理或屏幕范围。

## 联合审阅方式

新增四个参考示例和三个跨素材矩阵，共 14 个补充视频；原有 128 个视频继续保留。四组输入的方向、种子分别为 122°／909602、90°／489、130°／323、128°／494。它们原样应用到钢铁侠、添加附件、调整颜色。后三个种子经过粗粒度释放位置筛选，是可复现的展示输入，不是图片识别分支，也不是独立留出结果。常规六种子视频继续提供未逐一筛选的变化样本。

原参考无法确认实际触点，因此四参考形态示例只使用共同的默认距离，不给出伪造的参考终点；三距离视频单独使用实际屏幕内坐标。新增向上参考的释放时序、灭霸的细缕密度仍有差异，本轮只据实说明保留和扩展了共同模型的形态范围，不宣称已经精确复现所有参考。

## 重点：卷曲、翻折和流动究竟怎样实现

用户补充要求：交接重点必须包含已经有效的实现机制，不能只告诉新 agent「请保留卷曲」。下面依据当前运行代码及已有隔离实验说明；这描述的是本项目实现，不是对华为内部算法的断言。

### 1. 宏观形态由共同释放表与时变速度表共同承载

不能只复制模拟器目录下的 JSON 或只阅读 `curl()`。仓库根目录 `shared/particle-dismiss/` 中还有关键共同资源：

| 资源 | 当前形状与用途 |
| --- | --- |
| `common-release.f32` | 96×96，源材料各位置进入运动的基础时刻 |
| `common-flow.f16` | 48×64×64×2，时间、Y、X、二维速度；连续三线性采样 |
| `flow-confidence.u8` | 48×64×64，引导有效性，用于调节未充分观测区域的附加流动 |
| `rules.properties` | 上述尺寸、场范围、共同增益、寿命及随机规则 |

读取入口是 `unified_model.py` 的 `RELEASE`、`guidance()`、`flow_confidence()`；消费入口是 `renderer.py` 的 `guided_flow()` 和计算着色器。三维纹理的第三维是时间，不是物理 Z 坐标。

历史上，`analysis/distill_transport.py` 从用户认可的 `archive/observed-approved/` 控制组中提炼了同一归一化坐标系的释放和速度表示，之后又经过场延拓与共同校准。当前正式资源才是接手依据；不要直接重跑早期提炼脚本覆盖后来的修正。它是一份由观测提炼的共同运动先验，所有素材共用，运行时不逐视频读取光流；不能误称为已经独立推导出的通用物理定律。

**已有的宏观弯曲、剪切和不同时刻的流向变化，已有一部分编码在这份时变场里。单靠增加 `curl_gain`，或重新搜索几十个标量，不等于保留了这些信息。** 新模型可以逐步取代这份表示，但须先复现它提供的有效形态，再证明共同规则更接近原片。

### 2. 释放、空间变换与流场时钟保持配合

源位置 `x0` 的释放时间为 `T(x0)`；粒子年龄 `a=t-T(x0)`。出生前保持原位，出生后连续积分。释放梯度经平滑后给出法向 `n≈normalize(∇T)`，指向较晚释放区域。

- `unified_model.py::release_components()` 和 `renderer.py::guided_flow()` 共用方向／长宽比归一化、随机仿射、平滑弯曲与时间变换。
- 速度不是只把向量旋转一下：空间映射记为 `F`、时间变换记为 `τ`，需按 `J_F⁻¹ · v_base(F(p),τ) · dτ/dt` 换回，另含像素尺度与方向变换。只变释放轮廓而不配套变速度，会破坏释放区域与后续卷边之间的关系。
- `learned_release.py::predict()` 在共同释放先验上叠加「同一条件函数在实际起点与标准起点上的输出差」、共同时间校准及空间校准。标准布局差项为零，但仍可能受其它共同校准影响，不等于最终图像被冻结。
- `coupled_transport.py::material_builder()` 用新释放场重算法向，并把释放时序相对原场的偏移保存到 `physical.w`；计算着色器用 `t-physical.w` 采样当地流动阶段。出生年龄与流场时钟是两个不同量，不能合并成全局统一进度。
- 当前 `CoupledRules.warp=False`；该文件的 `fit_coordinates()` 是未启用的配准实验，不是当前翻折的实现。

恢复弧边的历史实验曾发现：随机坐标／时间偏移过大会改变有限控件内参与这段卷边的源材料，导致分支丢失。`variation()` 因此对连贯形态样本收小变化幅度，仍保留其它随机布局。不能只保留速度纹理，却任意重采样起点和坐标后认为效果自然会保留。

### 3. 横向弧边与下方拖尾依赖新生材料短时展开

这是 `rim-flow-2026-09-11.md` 中有隔离实验支持的有效改动。仅调整风、最低顺风速度或阻力响应，当时都没有恢复足够弧度；沿释放边界法线展开则明显改变了所需弧边。

`renderer.py` 的计算着色器以 `peel=-n` 指向已经释放的一侧，处理其顺风分量后，在出生早段加入约为下式的目标速度：

```text
v_peel(a) = span × A_i × adjusted(-n)
            × exp(-a / 0.16) × smoothstep(0.003, 0.028, a)
```

当前 `A_i=1.2141309×(0.10+1.80×peel_response)`，还叠加自由边界收减、静态压缩估计和下节压力修正；这不是可脱离上下文直接复制的单一公式。`peel_response` 与寿命随机量分开，不把强展开和长寿命材料锁在一起。

它的作用是：新解除材料先沿当地边界开放侧展开，再逐渐跟随共同流动；前沿继续推进，不同年龄的材料持续加入。横向弧边会随之弯出，而较早释放的部分仍继续形成下方拖尾。可见的「一条曲线变成两部分轮廓」来自这一连续释放、不同年龄材料运动及覆盖的共同结果，不是将整片控件沿固定轴旋转，也不是画两条轮廓。

因此，只拟合每帧前沿掩码、只调静态曲率，或只保证粒子最终去向，都可能丢掉这个过程。重构时需要同时保留 `T`、`∇T`、出生后短时响应、当地流场阶段、惯性与可见寿命之间的关系。

### 4. 连续输运与附加卷动负责后续流动，不能全局删掉

`renderer.py::COMPUTE` 的目标速度还包括共同引导速度、主方向携带速度、三尺度势场旋度、少量独立分离及边缘展开。`curl()` 的三个空间尺度约为短边的 1.12、0.51、0.23，幅值依次为 1、0.38、0.12；它是附加运动，不是宏观翻折的唯一来源。

基础运动按 `STEP=1/240` 连续积分，速度按 `1-exp(-dt/τ_i)` 接近目标，`τ_i≈0.018～0.054`（内部时间单位）。它保留速度连续性；不能把每帧位置重新设成 `x0+sin(t)` 等独立偏移。真实触点距离的系数 `0.55+0.90×touch_strength` 同时换算出生位置以外的实际位移和速度，采样流场时还原材料坐标，避免单纯加速后反而被带回相似轮廓。

`conditional_material.py` 以释放布局差异计算 `g=1-exp(-(RMS/0.085)²)`；当前引导与两处附加卷动分别乘：

```text
conditional_motion = 1 + g × (motion - 1)
conditional_curl   = 1 + g × curl_balance × (motion - 1)
```

当前 `curl_balance=1`、`motion≈0.47734`。这用于防止更换起点布局后，引导减弱而附加卷动相对过强，造成内部同步回摆。原版标准布局下 `g` 为零，这条比例调节不改变它；但共享输运和材质校准仍可改变原版画面。不要误以为原版已经被所有后续改动自动保护。

### 5. 防止孤立细缕，需要约束局部压缩而保留正常展开

`unified_model.py::peel_compression()` 根据源剥离场的对称速度梯度估计局部压缩，先减轻容易集中到细线的短时剥离。`pressure_grid.py` 再依据当前粒子分布与剥离动量，在局部网格上求单侧压力，向原有每粒速度叠加负压力梯度。

关键是只保留非负压力，并在实际粒子支持区外设零；不是按原控件轮廓截断运动。基础积分为 240 Hz，当前压力每四步更新一次。它保留原有卷动与相对速度，抑制异常内部汇聚。此前对整个场做完整无散度投影同时消除了需要的展开，已损伤正常卷边；不要重复这种替换后只报告细缕减弱。

这不保证所有异常都已解决。仍要用真实最终画面区分正常依附主体的卷动与孤立细流，不能把压力求解通过当作美术验收。

### 6. 当前成片还有共同输运修正及材质交接，不能只复刻基础积分

- `shared_transport.py` 把同一条件函数按方向、尺寸、起点布局等生成 56×56×41 的位移／密度场；空间范围为控件归一化的 -0.38～1.38，时间为 0～1。`flow_steps=5` 用缩放复合积分生成连续空间形变，绘制时在基础粒子位置上采样并叠加。它与基础逐步速度积分是不同层，不能混为同一个 ODE。
- 当前 `canonical_gain=1`，所以这层也参与原版钢铁侠，不能省略。共享条件输运、细分颗粒散布及材质覆盖共同决定最终可见轮廓；检查位置不能只读基础 `state.pos`。
- `surface_transfer.py`、`particle_coverage.py`、`particle_cohorts.py`、`surface_coherence.py`、`particle_fission.py`、`scatter_material.py` 继续处理原表面与颗粒交接、不同年龄材料覆盖、细分和反射／色度。亮边来自这些绘制量、原纹理和运动后的局部材料分布，不能简单等同于物理密度，也不能靠添加一条发光曲线复现。
- `roll_gain`、微片倾斜和小幅绘制深度提供颗粒姿态变化。当前宏观翻折主要发生在二维输运／轮廓层，不是一个已经实现的完整三维涡流或布料翻面模拟。不要把调大微片的旋转角或 Z 偏移当成恢复宏观弧边的办法。

当前实际渲染继承关系由基础到最终为：`Renderer → CoupledRenderer → ConditionalRenderer → SharedTransportRenderer → TransferRenderer → CoverageRenderer → CohortRenderer → CoherenceRenderer → FissionRenderer → ScatterRenderer`。入口在 `analysis/export_shared_candidate.py`；很多着色器通过逐层字符串替换组合，需核对最终生效的着色器与资源，而非只测试基础 `Renderer`。

### 接手时的技术执行顺序

先从上述完整依赖原样复现当前原版钢铁侠，再明确哪个共同环节造成其它序列的差异。初期保留共同时变先验、释放／流场时钟关系及短时剥离响应；优先针对证据明确的共同条件修正做小步实验。若准备替换核心表示，先作为独立候选证明能重现当前认可的连续形变，才进一步拟合原片；对现有输出的拟合只是初始化，最终仍必须直接对照华为。

已做过的全局关闭引导、卷动、剥离、压力，以及只放松运动约束等失败实验在 `material-contrast-2026-09-28.md` 中。可以提出更好的方法，但要清楚自己替换了哪一部分有效机制，不能因为新模型形式更简洁就默认它等价。

## 必须保留的具体行为

先完整播放原版钢铁侠的华为原片和当前模型，分别看原速、半速，再逐帧检查约 0.35～0.65 的动画进度。这里说的是消散阶段进度，不是包含片头停留的播放器秒数。

1. 左中部／左下部的连续粒群边缘随着流动改变曲率和朝向，能从较上凸的弧形转成较下凸的横向弧形；随后能看出横向弧边与向下拖尾这两部分连续轮廓。不能退回只有一条斜向前沿，也不能用固定弧线平移、缩放或淡出来代替翻折。
2. 颗粒应沿这片连续边缘流动、聚散，局部亮边与密度和运动自然衔接。不能用绘制发光线代替，也不能为消除内部摆动，把必要的边缘卷动一起削掉。
3. 卷曲、翻折属于主粒子群的连贯形变；不能产生脱离主体的孤立细缕、交叉窄流、被硬边界截断后停住的曲线。
4. 保留其它正确区域的释放顺序、主方向和轻盈观感。不能通过全局关闭卷曲、抹平流场、强制所有粒子直线或严格单向移动，来获得表面上的稳定。

当前模型不是华为真值。以上描述同时包含用户要求保住的特性和原片中的目标；先实看并记录当前实现达到的程度，不能凭交接文字宣称都已完美实现。参考原片中更准确的曲率、位置、时序和亮度仍需继续改善。

## 共同模型与验收规则

- 所有参考继续共用一套运动、释放、材质规则。差异可以来自尺寸、方向、真实触点、起点数量／位置／时序、随机输入等有物理或交互意义的条件。不得按视频名、人物、场景编号切换专属模型，也不得把逐参考观测场、轮廓、逐粒路径作为运行数据。
- 原片的触点和随机种子不总是已知。测量／推断输入要说明不确定性。固定回归用例的输入，不能为隐藏算法退步而移动起点、重选种子或改变时间映射。
- 同时保留两种对照：**华为原片是最终目标；接手时固定版本是防止已具备效果退步的对照。** 不要每轮仅与上一轮比较，以免误差累积。
- 原版钢铁侠的上述特性是独立通过条件，不是总损失中可以被其它序列收益抵消的低权重一项。即使十二段平均像素误差下降，只要卷曲、翻折或沿边流动明显变差，该候选就不得替换默认版本。也不要为机械地复现旧版错误而拒绝更接近原片的改进。
- 每轮先进行规模合适的实验。涉及运动或释放的重要修改，至少同时看原版钢铁侠、向上钢铁侠和内部起点钢铁侠的完整连续画面；合格候选再检查全部十二段，不必对每个小实验都重新导出所有视频。
- 既看完整手机画面的原速和半速，也看关键帧局部。原版重点包括约 0.33、0.39、0.44、0.48～0.56、0.65 及后段；截图相近不代表连续运动正确。
- 数值可包括多尺度像素差、轮廓曲率与位置、占用／亮度分布、材料释放时序、连续轨迹和共同换向。它们辅助解释视觉结果，不能替代看动画。未经验证的光流不是粒子真值；背景未知区域不能用重建背景冒充原始 RGB 真值。
- 对当前内部粒子共同左右／上下回摆、压缩后突然扩散、颗粒细灰等问题，先做可归因的定位和消融。区分应保留的边缘形变与应减少的内部同步摆动，不要先全局降运动或统一提亮。
- 不限定手调、CMA-ES、可微拟合或其它方法。先验证误差指标、渲染近似和约束是否对应实际观感，再扩大搜索；不要重复已否定实验后只报告训练损失下降。最终还需能移植到 Android，当前桌面研究用的小型条件函数不等于已满足移动端实现要求。

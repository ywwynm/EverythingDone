# 隐藏碰一碰诊断入口，默认关闭日志采集

用户决定暂时结束卓易通兼容性排查，保留本次会话实现，并要求整理后提交；提交前隐藏临时诊断 UI，使用 GONE 而非 INVISIBLE，同时为诊断日志增加总开关。

- `TapDiagnostics.ENABLE_DIAGNOSTICS` 默认 false。设置页、首页／详情接收区域、分享面板的诊断入口统一 GONE，不留下空白占位；从旧状态恢复的诊断对话框也立即关闭。
- 关闭时不创建诊断会话、不查询权限与网络环境、不加载或写入历史、不导出文件；P2P 附加查询、八秒状态快照、重试错误摘要和监听诊断计数一并停止。诊断线程按需创建，已有本地历史继续保留。
- 重新排查时只需在代码中启用总开关并重新构建 debug；正式包始终关闭诊断。普通传输的错误处理及组网策略不依赖此开关。
- 保留本会话加入的接收预建组、NFC 组网方向协商、普通 Wi-Fi 系统确认兼容路径和 ACK 后短等 TCP 关闭的处理。环境识别继续使用原有 HUAWEI／System 条件，不扩大到普通华为设备。

完整 debug 构建与 74 项诊断／协议／传输 JVM 测试通过，无失败或跳过；覆盖真实回环 Socket 的收发、身份拒绝、取消清理及新旧握手兼容。本轮没有连接设备，不把自动化通过等同于卓易通实机稳定。

最新实机证据已确认，明确绑定 P2P IPv4 仍有连接被拒绝。卓易通网络兼容和发送端角色切换路由仍待区分，暂缓进一步试验；此次主要整理诊断能力，不能视为连接故障已经修复。

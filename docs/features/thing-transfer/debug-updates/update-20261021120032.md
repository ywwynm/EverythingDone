## 首页接收入口跟随当前文件夹配色

确认首页碰一碰接收的归属：进入接收时保存当前文件夹 ID，正常接收及退出后继续导入完整文件的路径都将其传给导入器；来件顶层记事和文件夹归入这一位置，内部层级保持。根目录目标为 null。本轮核对现有代码，不改动归属规则。

“接收记事”胶囊现使用当前文件夹的完整 ThingBackground，保留纯色、渐变两端及方向。ThingsActivity 在目录或文件夹外观刷新时同步入口，TapReceiveController 将背景传给共用 TapReceivePull；退出接收后恢复当前文件夹配色。文件夹文字与图标复用 BackgroundUtil.onColor，触摸波纹复用 adaptiveRippleColor，浅色底配深色前景、深色底配浅色前景。根目录继续采用 accent + accent2 渐变、白色文字和白色波纹。

完整 debug 构建和 152 项相关本地测试通过。沿用此前指定的三台测试机，一加 15T 检查浅／深纯色、浅／深渐变、根目录恢复，以及真实按压波纹和进入／退出接收；三星与魅族检查父文件夹、子文件夹及返回根目录。截图已核对，三台原有数据库各表摘要完全一致。本轮没有实际传入记事，也没有执行实体 NFC 互碰。

实现与验证记录位于 docs/features/thing-transfer/folder-receive-style-2026-10-21.md。未创建 Git 提交。

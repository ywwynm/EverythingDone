## 文件夹也能分享和碰一碰传输了

### 从哪里分享

- 选择模式里选中文件夹，菜单里就有「分享」，文件夹和记事可以一起选（只在「正在进行」列表里）。
- 打开一个文件夹之后，右上角菜单的第一项是「分享此文件夹」，卡片从页面里升起，标题和图标用这个文件夹的颜色。
- 分享的都是文件夹时，面板标题是「分享文件夹」；混着记事时仍是「分享记事」。带文件夹时不提供「长截图」。

### 带过去什么

- 带的是列表里看得到的内容：文件夹里正在进行的记事，连同整棵子文件夹；首页开着类型筛选时只带筛选出来的记事，里面没有符合记事的子文件夹不带。
- 文件夹里的先后与置顶保留；收到的文件夹本身不置顶，落在置顶之后。文件夹的颜色和卡片外观（正常 / 大、普通 / 通栏）一起带过去。
- 私密标记不跟着过去；要分享的内容里有私密的记事或文件夹，会先验证身份。
- 对方已经有同名文件夹时新建一个，不合并。

### 碰一碰

- 发送时抬起的是文件夹在首页上的卡片（「大」文件夹带缩略图），接收时颗粒拼成对方首页上的文件夹卡片。
- 收完的提示会说文件夹，例如「已收到 2 个文件夹与 1 条记事」「已收到 1 个文件夹，共 5 条记事」。

### 记事文件

- 带文件夹的记事文件格式升到版本 2，还没更新的完事儿收到会提示升级；只含记事的文件与以前完全相同。
- 导入时以文件夹为单位勾选，可以逐层展开看里面有什么。文件夹里的记事全都与本机重复时默认不勾，并注明「已有相同内容」。

### 已知问题

- 私密文件夹分享前的验证、两台手机真的互碰传文件夹，都还没在真机上看过。
- 手机横屏与平板上抬起的文件夹卡片、平板上的面板宽度还没在真机上看过。
- Android 14 及以下的发送方、四周光尘变成拼卡颗粒的效果时多时少，同上一版。

### 验证情况

三星 SM-S9180 与魅族 20 Infinity（深色）上用模拟收发核对了：接收文件夹的动画，以及数据库里的层级、先后、置顶与外观；选择模式里文件夹与记事一起分享（三星）；「分享此文件夹」与模拟发送的完整过程；记事文件的导入；按类型筛选分享；只含记事的文件仍是版本 1。

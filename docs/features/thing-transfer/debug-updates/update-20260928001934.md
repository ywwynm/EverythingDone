## 分享面板改版：加上「分享记事」标题，悬浮在底部、更矮

### 分享面板

- 最上面加了标题「分享记事」，用这条记事的颜色（纯色或渐变）；选了多条时用应用的强调色。
- 竖屏时面板不再铺满整个宽度，与「调整颜色」面板一样左右和底边都留出空隙、四角圆角；平板上最宽 480dp，居中。
- 「文本与图片」「长截图」「记事文件」的图标缩小，文字与图标挨得更近，整个面板比原来矮一些；按下时图标周围是圆形的波纹。

### 碰一碰

- 等待被碰的波纹落在分享面板上的那一段改用记事的颜色，不再是白面板上看不清的白圈（例如三星横屏时天线正好在面板边上）；落在暗处与卡片上的仍是白色。
- 不支持碰一碰的设备上，抬起的卡片在上方区域居中，不再为并不存在的天线让位、停在偏上的位置。

### 已知问题

- 平板上的面板宽度与手机横屏时的面板还没有在真机上看过。
- Android 14 及以下的发送方、四周光尘变成拼卡颗粒的效果时多时少，同上一版。

### 验证情况

三星 SM-S9180 竖屏上核对了详情页分享、按住分享方式时的波纹、多选分享与不支持碰一碰时的面板；横屏时核对了面板上的波纹颜色（纯色与渐变）。

## 修好两台 OPPO / 一加手机互碰连不上，以及下拉按钮与头部的几处问题

### 碰一碰

- 两台 OPPO / 一加手机之间传过一次之后怎么贴都连不上：原因是贴合时发送方的系统先读到了接收方，触发了系统自己的碰一碰，接收方读不到发送方。现在发送方打开分享界面后只等对方来读、自己不再读卡（Android 15 及以上），Find X9 Ultra 发给一加 15T 实测已能传。
- 发送方的 Wi-Fi Direct 连接被系统占走（系统碰一碰、互传、与手表平板的互联）时，分享面板回到「正在准备…」并自动重新准备，不再出现显示可以碰、实际连不上的情况。

### 首页

- 「接收记事」只在列表已经滑到顶、再往下拉时出现。一路滑回顶部顺势继续下拉，或者先往上推再往回拉，都不会再拉出按钮压住头部。
- 接收时新记事排在置顶之后、列表要先滚过去的，头部随滚动正常收起；退出接收时列表不在顶部，按钮一并收起。

### 已知问题

- Android 14 及以下的手机做发送方、对方是 OPPO / 一加时，仍可能要多贴几次。
- 碰上后约 1 秒才出现颗粒，数据到齐后约 1 秒多才开始拼卡；四周光尘直接变成拼卡颗粒的效果时多时少。

### 验证情况

Find X9 Ultra 与一加 15T 之间实际互碰传输成功；下拉手势的几种情况在 Find X9 Ultra 上逐项验证过。

## 2026-10-10：修复碰一碰批量接收后滚动出现空白卡片

针对一次接收多条记事后，带视频和大量清单项的记事在首页占位却不显示的问题，定位并修复接收卡片的显示恢复遗漏。

原实现只恢复当前挂在列表上的卡片。暂存于 RecyclerView 缓存的卡片没有恢复；滚回时直接复用原视图，不触发重新绑定，于是残留隐藏或完全透明状态。使用生产适配器和实际列表缓存，已在三星复现普通记事、视频长清单及文件夹的相同问题。

`ThingsAdapter` 现在记录接收动画实际隐藏的视图及其 stableId，接收完成、失败或退出时覆盖屏外缓存中的视图，同时恢复可见性和透明度。视图改绑、回收或恢复后立即解除旧归属，避免其它记事或动画被提前显示。`ThingsActivity` 删除只查当前附着 holder 的重复处理，不强制刷新整张列表，不改变传输内容或粒子动画时序。

三星和魅族各 6 项真机回归全部通过，覆盖普通记事、视频与 36 项清单、文件夹、透明快照阶段、回收改绑、同 id 多视图。碰一碰相关 69 项 JVM 测试及构建通过。测试记事仅存在内存；三星 371 条、魅族 180 条现有记事以及数据库其它表的逐行摘要均未改变。

本轮未进行实体 NFC 触碰或复传用户原记事，验证聚焦接收后的列表显示故障。未创建 Git 提交。

## 修复分享时私密记事的标题被截断

### 修复

- 分享文件夹时，抬起的文件夹卡片里如果有已解锁的私密记事，它的标题前有一把开锁图标，标题末尾会被截掉一截，而且没有省略号（例如「7.5晚/7.6凌晨」只显示到「7.6凌」）。现在标题完整显示，放不下时正常出省略号。
- 从详情页分享私密记事时，抬起的记事卡片上的标题也有同样的问题，一并修好。
- 首页通栏的「大」文件夹，缩略图里的私密记事在本次打开过、显示标题时也可能这样被截断，一并修好。

### 已知问题

- 私密文件夹分享前的验证、两台手机真的互碰传文件夹，都还没在真机上看过。
- 手机横屏与平板上抬起的文件夹卡片、平板上的面板宽度还没在真机上看过。
- Android 14 及以下的发送方、四周光尘变成拼卡颗粒的效果时多时少，同上一版。

### 验证情况

原因是这些卡片在显示到屏幕之前先测量，那时标题前的开锁图标还没算进宽度；三星 SM-S9180 上测得标题量出 249 px、实际需要 314 px。三星与魅族显示之后会自动重新量一次，所以在这两台上看不到截断；现在第一次测量就已包含图标（315 / 314、425 / 424、通栏 298 / 297）。三星与魅族上的抬起卡片、详情页分享与首页截图都完整；截图里出问题的那台手机上还需要再看一眼。

## 碰一碰的粒子动画换成第三版

发送和接收的粒子动画按模拟器里定下的第三版重做。两台手机碰一碰时，握手信息里多带了每张卡片的形状（高宽比、是否通栏），旧版的发送方照样能发过来。

### 发送

- 碰上之后，卡片化成颗粒整团滑进天线，末段不再打转。
- 天线处的扩散圈从「可以碰了」一直持续到关闭分享界面，颗粒流进去时圈随之收小；天线处不再有光点。
- 发送完成、「已发送」停留一会儿之后，卡片按打开分享界面时的那段动画重新抬起，不再从天线里流回来。发送失败时仍然流回。

### 接收

- 屏幕四周换成一圈细小的彩色光尘，底下有一层柔光；碰上之后换成对方记事的颜色，随传输进度向内扩散。
- 碰上之后天线处出现扩散圈，颗粒从天线处和四周的光尘里浮现，朝新记事将要落下的位置飘。
- 列表腾出位置之后，颗粒拼成真实的卡片（图片、文字都在），四周的一部分光尘直接变成拼卡的颗粒。
- 光尘、柔光和扩散圈改在 GPU 上画，等待被碰期间不再持续占用处理器，接收时界面掉帧明显减少。

### 已知问题

- 碰上后约 1 秒才开始出现颗粒；数据到齐后约 1 秒多才开始拼卡。
- 四周光尘直接变成拼卡颗粒的效果时有时无，有时几乎看不出来。
- 带图片的记事，传输期间颗粒飘向的位置可能与最终位置略有偏差，拼卡时以真实位置为准。

### 验证情况

三星 SM-S9180 与魅族 20 Infinity 上用「碰一碰模拟」各验证了接收（带图、通栏、普通三条记事）与发送。两台手机之间实际碰一碰还没有测试。

## 增加碰一碰传输诊断，支持卓易通设备直接复制过程日志

用户反馈华为鸿蒙 7 的卓易通能够进入「接收记事」，但碰触 Android 发送方后很快接收失败；发送方仍显示连接进度，随后发送失败。本次先提供两端可直接操作的诊断，收集实体碰触证据后再判断兼容原因。

- 接收按钮下方和发送面板新增「查看／复制传输诊断」，打开后实时更新，可点击「复制全部」。退出接收后再次下拉仍可查看；最多保存三次会话，重新打开应用也能读取。
- 记录版本与型号、运行环境的 NFC／Wi-Fi Direct 支持、开关和权限、NFC 握手状态字、P2P 建组／入组回调与错误码、TCP 连接重试、字节进度、ACK 及具体异常。
- 失败记录在重试后保留，环境信息不会随进度事件淘汰；后台保存并限制记录大小。不记录记事／文件夹内容、原始 APDU、密码或令牌，网络凭据和私人路径脱敏。
- `TapDiagnostics`、`TapDiagnosticBuffer` 和 `TapDiagnosticsDialog` 统一收集与显示；现有收发控制器和 NFC／Wi-Fi Direct 传输层补齐关键阶段记录。仅 debug 包展示入口，传输协议、入组策略及超时不变。

本地构建和 34 项诊断／协议 JVM 测试通过。未连接设备，未代做碰触；卓易通实际失败原因尚未确认。请两台设备都更新后复现一次，分别点击「查看／复制传输诊断」→「复制全部」，提供双方记录。

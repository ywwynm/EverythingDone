## 分享界面转屏不再收起、接收更快、补齐其他语言

### 新增与改进

- 分享界面开着的时候旋转屏幕（或调整分屏），界面不再收起，面板和抬起的卡片按新的方向原地重新排好。碰一碰传输途中转屏时，飞行中的颗粒会直接收回成卡片，传输本身不受影响。
- 手机横屏时，右半边的分享面板改为从状态栏下方开始，状态栏上的时间、信号、电量等图标不再被白色面板盖住。
- 首页的「接收记事」可以用读屏操作打开：读屏焦点停在首页大标题上时，在操作菜单里选「接收记事」，效果与下拉后点按钮相同。
- 接收记事时，从数据到齐到颗粒开始拼成卡片的等待变短：三星上约快 0.4 秒，魅族上提升不明显（原因已查到，等接收动画定稿后再处理）。
- 记事文件与碰一碰的文字补齐了繁体中文（台湾、香港）与德语、西班牙语、法语、意大利语、葡萄牙语、俄语、日语、韩语、印地语。

### 已知问题

- 手机横屏时，「大」文件夹卡片太高，抬起时整叠卡片会缩小到约一半，里面的字偏小，怎么改待定。
- 私密文件夹分享前的验证、两台手机真的互碰传文件夹、平板上的面板与卡片，还没在真机上看过。
- 读屏入口还没有用 TalkBack 实际走过一遍。

### 验证情况

三星 SM-S9180 上横竖来回转过四种分享入口（首页选择模式混选、只选文件夹、文件夹页、详情页），录屏逐帧看过，旋转后的第一帧就是新布局。接收在三星、魅族上各测了多次，三星从约 1.6 秒降到约 1.1–1.3 秒，录屏看过接收画面正常。

# 优化：选择模式下点击大文件夹缩略图的 ripple 落在整张文件夹卡

## 主要改动

- 选择模式下点击大文件夹（缩略图模式）里的预览缩略图，**点击反馈（ripple）现在出现在整张大
  文件夹卡片上**（并带卡片按压动画），与点击文件夹卡片空白区域完全一致；此前 ripple 只出现在被点
  的那个小缩略图上。
  - 做法：选择 / 移动等模式下，预览缩略图卡不再自行响应点击、去掉自身 ripple，让触摸冒泡到外层
    文件夹卡，由文件夹卡统一显示 ripple、按压动画并完成选择 / 反选。普通模式下点缩略图仍是打开
    对应记事 / 进入子文件夹（行为不变）。

（本版同时包含上一版"大文件夹第一个正在做预览图标/文字不显示"的修复。）

## 验证重点

1. 进入选择模式，点击大文件夹里的预览缩略图：ripple 与按压动画在整张文件夹卡上，且选中 / 反选
   该文件夹；与点击文件夹空白区域观感一致。
2. 普通模式下点缩略图仍能打开对应记事 / 进入子文件夹，且 ripple 在缩略图上（不变）。
3. 大文件夹里第一个正在做预览的火箭图标 + “正在做”文字正常显示（上一版修复不回退）。

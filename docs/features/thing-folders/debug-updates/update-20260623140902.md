# 菜单去重与空状态梳理 + 回收站“全部恢复” + 返回键回默认

## 主要改动
- **菜单去重 / 按实际情况显隐**：
  - 文件夹内，内容批量操作只由工具栏承担（全部完成 / 全部恢复 / 全部删除 / 全部永久删除）；overflow 只放结构操作（设私密 / 移动 / 解散 / 永久删除文件夹）。移除了 overflow 里与工具栏重复的“删除文件夹中所有记事”。对某个文件夹“删除其全部记事”改为从上一层长按该文件夹卡片触发。
  - 工具栏的全部完成 / 恢复 / 删除 / 永久删除 / 排序，在当前视图没有可见内容时（如空文件夹、空的某状态视图）自动隐藏。
- **回收站工具栏新增“全部恢复”**：递归把当前范围回收站里的记事恢复到删除前状态（跟随类型筛选）。现在回收站工具栏与已完成视图对称（恢复 + 永久删除）。
- **返回键回默认**：在根目录且筛选不是“正在进行 + 全部类型”时，按返回先回到“正在进行 + 全部类型 + 根目录”，再按返回才退出。因此用返回键退出 app 后再打开，类型筛选不会保留；按 Home 退到后台再打开则仍保留筛选。

## 验证重点
1. 进入某文件夹（已完成视图），不再同时出现“全部删除”和“删除文件夹中所有记事”。
2. 空文件夹 / 空的某状态视图里，不再出现全部完成 / 全部恢复 / 全部删除等工具栏项。
3. 回收站里有“全部恢复”，可一次性恢复当前范围回收站记事。
4. 根目录切到已完成或某类型筛选后，按返回先回到正在进行 + 全部类型 + 根目录，再按返回才退出；返回退出再打开为默认筛选。
5. 按 Home 退到后台再打开，类型筛选仍然保留。

## 修复搜索态长按拖拽和选择模式回归

本次更新修复上一轮搜索模式文件夹支持引入的长按交互问题。

用户反馈：
- 搜索态长按记事并释放进入选择模式后，源记事没有被选中，其他记事也无法选择，但文件夹仍可选择。
- 搜索态长按记事可以拖动，但不能拖到另一个记事上创建文件夹，也不能拖到文件夹上移动进去。
- 搜索态长按文件夹完全不能拖拽移动或加入别的文件夹，而是直接进入选择模式。

诊断结果：
- 搜索态文件夹长按被错误地直接导向选择模式，绕开了原本“长按先拖拽，释放在原处才进入选择模式”的 overlay drag 语义。
- 选择模式点击记事时仍提前校验 `thingIndex`，但该索引只用于普通态打开详情，不应影响选择态切换。
- 拖拽创建/移动文件夹后的管理层方法会直接 `loadThings()`，导致搜索文本和颜色筛选被清空。

主要修改：
- 搜索态正在进行视图下，记事和文件夹长按都先进入 overlay drag；释放在原处时再进入选择模式并选中源项。
- 进入选择模式时按 stable id 再次选中源项、刷新该卡片和 contextual toolbar 计数/菜单。
- 选择模式点击记事不再依赖详情页使用的 `thingIndex`。
- 拖拽创建文件夹、移动记事到文件夹、移动文件夹到文件夹后，按当前搜索文本和颜色重新构建列表；搜索态下使用全量 rebind，避免局部 notify 与过滤后的列表不一致。

验证：
- `:app:assembleDebug` 已通过。
- `git diff --check` 已通过。
- 本次未使用 adb。

# 文件夹纯骨架模型：删除/还原文件夹改为内容操作 + 批量操作跟随类型筛选

## 主要改动
- 文件夹不再有“删除状态”，变成稳定骨架。对文件夹的“删除”现在是「删除文件夹中所有记事」：递归把子树里进行中+已完成的记事移入回收站，文件夹本身不动；删完后它在首页因无匹配记事而消失、在回收站作为含已删记事的文件夹出现、可“恢复文件夹中所有记事”还原。**跟随当前类型筛选**。
- 回收站里对文件夹区分两个操作：
  - 「永久删除文件夹中所有记事」：只永久删除该文件夹回收站里的记事（跟随类型筛选），不影响其它视图里的记事；
  - 「永久删除文件夹」：结构操作，销毁整个容器及其全部内容，会警告“包含当前状态/类型筛选下看不到的内容”。
- 工具栏批量操作（全部完成/全部恢复/全部删除/全部永久删除）与长按文件夹的“…文件夹中所有记事”全部统一为递归、跟随类型筛选、带确认弹窗。有具体类型筛选时弹窗提示“仅作用于当前类型筛选（X），其它类型不受影响”。
- 数据库升级到 v20：会自动把旧的已删文件夹迁移为新模型（其子树记事置为已删除并记录删除前状态，文件夹状态清回正常）。
- 清理：移除了早已不可达的旧文件夹操作弹窗代码与相关文案（删除文件夹/还原文件夹等旧措辞）。

## 验证重点
1. 升级后，旧版里“删除的文件夹”应正确变为“回收站里含已删记事的普通文件夹”，能在回收站看到并恢复。
2. 在某类型筛选下（如习惯）对文件夹执行“删除文件夹中所有记事”，应只删该类型记事；弹窗有“仅作用于当前类型筛选”提示。
3. 删空某文件夹的记事后，该文件夹从首页消失、在回收站出现、可“恢复文件夹中所有记事”。
4. 回收站里：「永久删除文件夹中所有记事」只清掉回收站内容；「永久删除文件夹」销毁整个容器并给出跨状态警告。
5. 各处不再出现“删除文件夹/还原文件夹”这类旧措辞。

# 2026-06-27 - 搜索排除私密与 checklist 存储标记

用户反馈：首页搜索时，私密记事标题前缀和 checklist 的各种内容前缀有可能被纳入搜索范围；这些只是存储标记，不属于真正的记事内容。

诊断后确认，`ThingManager.searchThings(...)` 和相关 DAO 查询曾把 keyword 交给数据库 raw `title/content like` 或旧的条件式剥离逻辑处理，导致私密前缀、checklist 的 SIGNAL、状态位、层级位、控制标记等可能影响搜索结果；文件夹递归计数和缩略图候选也存在同类规则分叉。

本次新增 `ThingSearchHelper` 作为统一搜索匹配入口：私密标题只移除真实的私密前缀；checklist 正文复用 `CheckListHelper.toContentStr(..., "", "")` 转成用户可见纯文本后再匹配。`ThingDAO`、`ThingFolderDAO`、`ThingManager` 和 `Thing.matchSearchRequirement(...)` 都改为走同一套 helper，搜索范围内操作、文件夹结果计数、缩略图和编辑返回后的搜索刷新判断保持一致。

验证：`:app:assembleDebug` 通过；`git diff --check` 通过，仅有仓库既有 LF/CRLF 提示。未使用 adb。

# use-cases 审计修复：回收站可见性 + 确认文案 + 创建刷新

- 修复：删除一个子文件夹后，它里面的记事（本身状态没变、只是因父文件夹被删而进了回收站）在回收站里看不到、也无法恢复。现在回收站会正确显示这些路径文件夹及其内容。
- 修复：在某类型筛选下（如习惯）创建新记事、返回后，虽切回全部类型，但界面上的大文件夹缩略图仍只显示该类型记事、显示不完整。现在创建后会整列刷新，文件夹卡片按全部类型正确显示。
- 删除/解散/永久删除文件夹的确认文案：当子文件夹数或记事数为 0 时，省略对应的“0 个子文件夹/0 件记事”描述。
- Widget：当它指向的文件夹被删除或永久删除后，配置会被持久改写回“全部记事”范围（保留状态/类型/显示模式等），不再一直指向失效文件夹。
- 文档：use-cases.md 已更新到与当前实现一致（回收站为状态分段、完成/恢复为全类型递归、操作入口等）。

验证重点：① 删子文件夹 → 回收站能看到并恢复其内容；② 习惯筛选下建记事返回 → 大文件夹缩略图按全部类型完整显示；③ 删除只含若干记事、无子文件夹的文件夹时，确认文案不出现“0 个子文件夹”。

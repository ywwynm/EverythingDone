# Phase D：删除前状态 + 级联恢复 + 回收站文件夹区分（含数据库迁移）

包含数据库迁移（版本 17→18，新增 state_before_delete 列，仅新增可空列、非破坏性）。

- 记录"删除前状态"：记事进入回收站时记住它之前是正在进行还是已完成。
- 单条/批量从回收站恢复：恢复到删除前状态（已完成的记事恢复后仍是已完成，不再一律变正在进行）。单条恢复必定精确还原。
- 文件夹级联恢复：从回收站恢复一个文件夹时，连带恢复整个子树——嵌套的已删子文件夹、以及子树内被单独删除过的记事，都按各自删除前状态一起恢复。
- 回收站里区分两种文件夹：自身已删除的文件夹（Trashed）其图标带一个删除小标记（×）；只是因为内部有回收站内容才出现的路径容器文件夹（Projection）用普通文件夹图标。

验证重点：① 已完成记事删除后从回收站恢复，应仍是已完成；② 删文件夹后从回收站恢复，子树内容应完整回来；③ 回收站里自身已删的文件夹图标有删除标记。

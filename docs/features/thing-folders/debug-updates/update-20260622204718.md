# 删除/解散文件夹确认计数修正 + 解散语义澄清

修正确认对话框统计，区分删除与解散：

- 删除文件夹（移入回收站，可恢复）：影响计数只统计“未在回收站”的内容（正在进行/已完成的记事 + 未删除的子文件夹）。原本就在回收站里的子项不再被算进“将进入回收站”的数量。
- 解散文件夹：是把文件夹容器本身彻底删除（正在进行/已完成/回收站里都找不到它，不是移入回收站），并把里面所有内容按各自原状态移到上一级目录，包括原本就在回收站里的内容。因此解散的影响计数统计整个子树的全部内容（含已在回收站的）。确认文案也改写说明了这一点。
- 永久删除：仍统计全部（含已在回收站的），因为它确实销毁整个子树。

验证重点：① 文件夹里有一条已在回收站的记事时，删除该文件夹的确认数量不应把它算进去；② 解散该文件夹的确认数量应包含它；③ 解散后该文件夹从所有列表（含回收站）消失，内容按原状态出现在上一级。

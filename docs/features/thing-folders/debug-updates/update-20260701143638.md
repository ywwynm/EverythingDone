# 大文件夹缩略图缓存优化：进出文件夹后返回不再卡顿

之前大文件夹缩略图做了整棵预览树的缓存，但缓存扛不过导航——打开一个文件夹再返回，缓存会被整体清空，
滚回那个大文件夹时又要重新构建，容易"顿一下"。本版改掉了这个"数据重载即清空整个缓存"的做法，改由每个
文件夹的内容签名判定：进出文件夹、打开记事再返回、来回滚动，只要文件夹内容没变就直接复用已缓存的缩略图。

## 主要改动

- 去掉"数据重载即清空整个缩略图缓存"的兜底，改由每文件夹内容签名判定失效——内容真的变了才重建，导航
  返回不再无脑全清。
- 对含提醒、进行中目标（倒计时会随时间变化）的缩略图，把"当前本地日历日"纳入签名：同一天内进出全部命中、
  滚动流畅；跨过本地凌晨 0:00 后首次刷新会重建一次、更新倒计时文本。
- 纯普通记事 / 习惯记事的文件夹不含日历日因子，永远不会因为跨天而失效，命中率无损。

## 验证重点

1. **核心手感**：滚动到有缩略图的大文件夹 → 打开它 → 返回，再滚动经过它，应不再"顿一下"（同一天内命中缓存）。
   反复进出文件夹、打开记事再返回，大文件夹缩略图显示正确、滚动顺滑。
2. **内容正确性**（不能复用出过期内容）：移动记事进出文件夹、改记事内容 / 封面、私密文件夹揭示、外观编辑
   实时预览、进入 / 退出选择模式后，缩略图都应正确反映当前内容。
3. **倒计时刷新**：提醒 / 目标类记事的缩略图倒计时当天显示正确；跨过凌晨 0:00 后再次进入 / 刷新列表，
   "还剩 N 天 / 已逾期 N 天"应更新为新值。
4. **Widget 配置界面**：单一记事 widget 配置界面的记事列表里，大文件夹缩略图行为应与主列表一致。

## 备注

本版是缩略图缓存策略优化，界面外观无变化，重点看两点：滚动手感（进出文件夹返回不再卡）、以及缩略图内容 /
倒计时的正确性。已知次要限制：进行中目标"当天到点从'应于 H:mm 前完成'变'已逾期'"这一步翻转会等到次日凌晨
才在缩略图刷新，点进文件夹看单张卡片始终准确。

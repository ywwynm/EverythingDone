# 完成文件夹中所有记事（递归）

新增“完成文件夹中所有记事”操作：递归完成文件夹及其所有子文件夹里的所有正在进行记事（不受当前类型筛选影响）。

入口：
- 长按文件夹卡片（正在进行）的菜单新增该项。
- 打开文件夹后，工具栏的“全部完成”在文件夹内显示为“完成文件夹中所有记事”，并改为递归处理整个子树。
- 首页右上角的“全部完成”同理，从根目录递归完成整棵树里的所有正在进行记事。

交互：点击先弹确认对话框（显示会完成多少件，标题/按钮用文件夹颜色或 accent 渐变）。若其中含习惯/目标，确认后弹三选项对话框（去掉习惯目标只完成其它 / 继续全部完成 / 取消）——这个三选项对话框现在也适配了文件夹色/accent 渐变（之前是随机色），选择模式下的同款对话框一并适配。

“完成当前筛选下的内容”改为仅在启用了具体类型筛选时才出现，避免与“完成所有记事”重复。

验证重点：① 文件夹卡片菜单/文件夹内工具栏/首页全部完成 三个入口都能递归完成；② 含习惯/目标时弹三选项且配色正确；③ 完成后子文件夹里的记事也变已完成。

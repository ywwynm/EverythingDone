# 大文件夹缩略图缓存补漏：子文件夹计数、提醒/习惯状态及时刷新

接上一版（缩略图缓存改为按内容签名判定、进出文件夹返回不再卡）的正确性补漏。上一版去掉了"数据重载即清空
整个缓存"的兜底后，有两类变化没被内容签名覆盖，可能让缩略图显示旧内容，本版修复。

## 修复内容

- **子文件夹"N 个文件夹 M 项"计数**：大文件夹缩略图里的子文件夹卡显示的计数，此前在更深层（孙及以下）内容
  增减后可能不刷新、显示旧数字。现已纳入判定，深层增减后计数及时更新。
- **提醒 / 目标的状态后缀**：提醒到点（变"已提醒 / 已过期"）、延迟提醒、目标重置改了时间/状态，缩略图里的提醒
  文字现在会及时反映，不再停留在旧文本。
- **习惯的暂停 / 恢复**：习惯暂停或恢复后，缩略图里习惯摘要的"已暂停"标注现在会及时更新。

## 验证重点

1. **子文件夹计数**：在一个大文件夹的某个子文件夹的更深层里增删记事 / 子文件夹，回到外层看该子文件夹缩略图卡
   的"N 个文件夹 M 项"计数是否更新为新值。
2. **提醒状态**：让缩略图里可见的提醒记事到点（或延迟提醒），看提醒文字是否及时变化（如加"已提醒 / 已过期"）。
3. **习惯暂停**：暂停 / 恢复缩略图里可见的习惯记事，看其摘要"已暂停"标注是否及时更新。
4. **回归**：上一版的核心手感与正确性仍在——进出文件夹返回不卡、来回滚动顺滑、移动 / 改内容 / 私密揭示 / 外观
   编辑 / 选择模式切换后缩略图内容正确、提醒/目标倒计时跨天刷新。

## 备注

本版是缩略图缓存的正确性补漏，界面外观无变化。原理：这些变化只改提醒 / 习惯的关联数据、或更深层文件夹内容，
不改记事本身，故此前的内容签名漏判；现已把子文件夹的实际渲染计数、以及提醒 / 习惯的关联派生数据一并纳入缓存
判定。

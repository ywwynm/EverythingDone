## 修复刚打开搜索模式时底层数据为空

本次更新修复点击搜索按钮后、尚未输入搜索文本且颜色仍为默认全部颜色时的特殊搜索态问题。

用户补充的复现条件：
- 只点击搜索按钮，不输入搜索文本，也不筛选颜色。
- 此时长按/拖拽卡片无法放入文件夹或创建文件夹。
- 原地释放进入选择模式后，记事卡片视觉上会变化，但 toolbar 计数不增加，也不出现该记事可用的 contextual menu item。
- 如果先进入一个文件夹再返回，问题会消失。

诊断结果：
- `toggleSearching(false)` 进入搜索态时清空了 `mThings`，但 `mThingListEntries` 仍保留原列表。
- Adapter 渲染的是 `mThingListEntries`，所以用户仍能看到卡片；选择计数、菜单和拖拽投放源记事查找依赖 `mThings`，因此底层行为失效。
- 进入文件夹再返回会重新执行搜索刷新，所以 `mThings` 与 `mThingListEntries` 恢复一致。

主要修改：
- 进入搜索模式时不再清空 `mThings`。
- 改为立刻用当前搜索框文本和颜色调用 `ThingManager.searchThings(...)`。
- 空文本 + 全部颜色会形成真实的当前范围全部结果搜索投影，保证可见卡片和底层数据一致。
- 搜索态开启后立即调用 `handleSearchResults()`，同步 no-result 状态。

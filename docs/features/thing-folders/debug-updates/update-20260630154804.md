# 大文件夹缩略图性能诊断埋点（临时调试版）

为定位"大文件夹缩略图明明已缓存却仍有一点点卡顿"的问题，加入一组临时性能日志。本版不改功能，只新增
诊断埋点，诊断完成后会移除。

## 主要改动

- 在大文件夹缩略图绑定路径加入性能日志，异步写入文件（不占用滑动帧）：
  - 每绑定一次大文件夹缩略图记录一行：文件夹 id、标题、布局（全宽几列 / 普通）、显示与总缩略图数、
    绑定时的滚动状态（静止 / 拖动 / 快速滑动）、**是否命中缓存**（命中 / 首次无缓存 / 签名变化 / 仍挂载未复用）、
    以及签名计算、构建、挂载、measure、总绑定各段耗时。
  - 列表数据刷新（reload）清空缓存时，另记一行。
- 其中 measure 耗时单独测量：缓存命中省掉了重复构建，但系统仍要对这棵较大的内容子树做测量/布局，
  这一项用于判断"缓存命中却仍卡"是否卡在测量/布局环节。

## 怎么取日志

1. 正常使用，重点是**上下滑动到含大文件夹缩略图的位置几次**（尤其缩略图里有封面图/视频或较复杂记事的）。
2. 取日志文件（用文件管理器或电脑）：
   `Android/data/com.ywwynm.everythingdone/files/debug_logs/folder_thumbnail_perf.log`
3. 把该文件发回即可分析。

## 备注

这是临时调试埋点，由开关 `DEBUG_FOLDER_THUMBNAIL_PERF` 控制，定位问题后会连同相关诊断代码一并移除。诊断期
每次绑定会多做一次 measure 用于取数，体感上可能比正式版略卡一点，属正常；日志中的“总绑定耗时”不含这次
诊断 measure，数据准确。

# 修正“（含所有子文件夹）”字样 + 正在进行文件夹内补“删除文件夹中所有记事”

## 主要改动
- 确认弹窗里的“（含所有子文件夹）”改为按实际情况显示:只有当受影响的记事确实落在子文件夹里时才显示，挂在数量后面（如“共8件（含所有子文件夹中的记事）”）。
  - 之前:没有子文件夹的文件夹也带这句；根目录明明有子文件夹却不带。现已修正，根目录与文件夹一致。
- 正在进行视图下，进入一个文件夹后，overflow 菜单首项新增“删除文件夹中所有记事”（与长按该文件夹时一致）。
  - 已完成视图仍由工具栏“全部删除”承担（不重复）；回收站视图 overflow 为“永久删除文件夹”。

## 验证重点
1. 删除/完成/恢复等确认弹窗:没有子文件夹的文件夹不再出现“含所有子文件夹”；根目录或含子文件夹时正确出现该字样。
2. 正在进行视图进入某文件夹 → overflow 首项有“删除文件夹中所有记事”。
3. 已完成视图进入文件夹仍只有工具栏“全部删除”，overflow 不重复出现删除项。

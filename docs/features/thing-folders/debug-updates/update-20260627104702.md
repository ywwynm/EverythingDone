# “移动到文件夹”加入可见移动动画

## 背景

用户反馈：在 ThingsActivity 的记事/文件夹混合列表中，拖拽记事或文件夹到目标文件夹时有加入文件夹的动画；但长按后选择“移动到文件夹”并确认移动时，界面只刷新，没有可见动画。用户进一步补充：多选移动也应尽量保留动画，尤其是目标文件夹和部分源条目可见时，不应因为某些源条目不可见而放弃其它源条目的动画。

## 本次更新

- 新增“移动到文件夹”Dialog 确认后的统一可视化路径，覆盖单个文件夹、单个/多个记事、以及记事+文件夹混合多选。
- 当目标文件夹和一个或多个源条目都在当前屏幕可见时，会为每个可见源条目生成 overlay，并飞入目标文件夹。
- 当目标文件夹不可见、但当前屏幕可见源条目时，源条目走定向移除动画。
- 当源条目和目标文件夹都不在当前屏幕可见区域，或移动后目标文件夹才新进入当前投影时，退回无入场动画的全量刷新，避免错误的局部通知。
- 即使源条目在屏幕外，只要它属于当前混合列表，也会按旧 adapter position 发送 `notifyItemRemoved`，保证 adapter item count 与 RecyclerView 通知一致；目标文件夹可见时再补 `notifyItemChanged` 更新缩略图和计数。
- `ModeManager` 新增不抢先全量刷新的退出当前模式方法，让选择模式可以先隐藏 contextual toolbar，再由移动路径执行定向通知和动画。
- 同步更新 `docs/features/thing-folders/preferences.md`、`decisions.md`、`sessions.md`，记录这次移动动画与通知策略。

## 结构操作确认弹窗补充搜索范围提醒

用户反馈：解散文件夹、永久删除文件夹等影响文件夹结构的操作，确认弹窗的提示正文只说明了状态筛选、类型筛选下看不到的内容，没有说明搜索范围下看不到的内容。

本次修复：
- `ThingsActivity.hiddenScopeClauseForStructural(...)` 在搜索模式下把“搜索范围”纳入结构操作的隐藏范围提示。
- 若同时存在状态筛选、类型筛选和搜索范围，提示会合并成同一句，例如“该操作作用于整个文件夹子树，包含当前状态和类型筛选（X、Y）以及搜索范围下看不到的内容。”
- 新增默认英文、简中、繁中资源短语，覆盖“仅搜索范围”“状态筛选 + 搜索范围”“类型筛选 + 搜索范围”“状态和类型筛选 + 搜索范围”四种组合。
- 同步更新 `selection-batch-actions` 与 `thing-folders` 的决策文档和文案矩阵，明确结构操作是警告式提示：它作用于整个子树，不是仅作用于搜索范围内的记事。

验证：
- `git diff --check` 通过，仅有仓库既有 LF/CRLF 提示。
- `:app:assembleDebug --console=plain --no-configuration-cache` 构建通过。

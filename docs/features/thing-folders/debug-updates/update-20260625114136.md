# 正在做提示：图标与文字协调、矮卡片留白

## 正在做提示的图标与文字大小协调、矮卡片留白调整

- 上一版只把矮卡片里"正在做"蒙层的图标缩小了，右侧文字没有同步缩小，导致图标小、文字偏大、不协调，大文件夹缩略图的迷你卡片里尤其明显。现在图标、文字、图文间距按卡片高度统一等比缩放，始终保持协调。
- 普通记事列表里卡片高度不够时，"正在做"图标上下的间距偏小，现在按卡片高度比例留出更舒适的上下间距。
- 较高的"正在做"卡片（多行内容、带封面等）保持原来的图标与文字大小不变。

测试重点：
- 主页普通列表里只有一行内容的"正在做"记事：图标不再紧贴卡片上下边缘，且图标与"正在做"文字大小协调。
- 大文件夹缩略图里的"正在做"记事：图标和文字一起按迷你卡片大小缩放，不再出现图标小、文字大的不协调。
- 较高的"正在做"卡片外观保持不变。

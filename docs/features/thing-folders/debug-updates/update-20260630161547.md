# 关闭大文件夹缩略图性能诊断日志（真实手感版）

确认缓存复用生效后，关闭上几版的临时性能诊断日志。本版是修复后的真实手感版。

## 主要改动

- 关闭缩略图绑定性能诊断（开关置为关闭）：不再写日志文件，也不再为取数做那次额外的测量。之前诊断版
  每次绑定会多做一次测量、体感偏卡，本版去掉，恢复正常手感。
- 功能不变。此前的修复全部保留：
  - 全宽大文件夹缩略图按实测高度分列（修分列不均）；
  - 按文件夹缓存整棵缩略图树并正确复用（修滑动卡顿，含列表项回收时摘树、私密揭示态入签名、reload 兜底、
    单记事 Widget 配置路径转发）。

## 验证重点

- 主列表：上下滑动到含大文件夹缩略图的位置（尤其有封面图/视频或较复杂记事的），来回滑动，确认是否
  顺畅、不再有明显卡顿。
- 单记事 Widget 配置界面：同样滑动含大文件夹缩略图的列表，确认顺畅。
- 顺带回归：分列是否均匀；切换类型/状态/搜索筛选后缩略图内容是否正确；私密文件夹认证揭示前后是否正确。

## 备注

诊断埋点代码暂时保留（仅关闭开关），以便后续若需要进一步优化测量/布局时可再次开启。日志目录
`debug_logs/folder_thumbnail_perf.log` 不再增长，可自行删除旧文件。

# 修正多选移动 Dialog 默认选中目标

## 背景

用户反馈：在 ThingsActivity 中多选文件夹和记事后打开“移动到文件夹”Dialog，默认选中的目标好像直接是根目录，而不是这些条目真实所在的文件夹。随后进一步确认，不只是记事+文件夹混合选择，多选文件夹也有同样问题。

## 本次更新

- 修正多选文件夹、以及记事+文件夹混合多选时的 Dialog 默认选中目标。
- 新增共同来源文件夹计算：Thing 使用自身 `folderId`，Thing Folder 使用自身 `parentFolderId`。
- 当所有选中源项来自同一个文件夹时，Dialog 默认选中该来源文件夹；来源不一致时，才回退到当前投影文件夹。
- 纯记事多选继续复用同一套共同来源计算，保持原有行为。
- 保留上一版“移动到文件夹”Dialog 的可见源项 overlay 动画与定向移除动画逻辑。

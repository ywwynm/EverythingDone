# 修正完成入口 + 已完成/回收站递归恢复

修正：上一版“完成文件夹中所有记事”加错了地方（一个无调用者的死方法），所以长按文件夹的菜单里看不到。现在已加到选择模式的上下文菜单：选中一个文件夹（正在进行）后，溢出菜单里会有“完成文件夹中所有记事”。

新增对称的递归恢复（选中一个文件夹后的上下文菜单）：
- 已完成里：恢复文件夹中所有记事 → 递归把该文件夹及所有子文件夹里的已完成记事恢复为正在进行。
- 回收站里：对“只是包含回收站内容的路径文件夹”，恢复文件夹中所有记事 → 递归把其中在回收站的记事恢复到删除前状态；对“自身已删除的文件夹”，仍用原来的恢复按钮恢复整个文件夹子树。

都带确认对话框（显示数量、用文件夹色/accent 渐变）。

验证重点：① 长按选中文件夹（正在进行）→ 溢出菜单出现“完成文件夹中所有记事”；② 已完成里选中文件夹 → “恢复文件夹中所有记事”递归生效；③ 回收站里选中一个只含回收站内容的文件夹 → 能递归恢复其内容。

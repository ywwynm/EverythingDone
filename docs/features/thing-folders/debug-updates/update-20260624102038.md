# 无标题可设私密、文件夹颜色信息、移动 Dialog 高度自适应、根标签与 FAB ripple

本次 debug update 包含一组跨界面小迭代：

- 允许把没有标题的记事设为私密：移除详情页返回、列表单选、批量选择三处“标题非空才能设私密”的限制。私密仍以标题前缀编码，无标题即存为空标题的私密记事；批量跳过提示只保留“正在计时”一种情况。
- 打开文件夹后的 overflow 菜单新增“颜色信息”项，复用记事详情页的颜色信息弹窗，展示当前文件夹纯色或渐变背景的颜色名、RGB、Hex、HSL 等信息；正在进行/已完成/回收站三种状态下打开文件夹时均可用。
- 移动到文件夹 Dialog 的文件夹列表改为高度自适应：随行数增长、最多 6 行后封顶滚动，做法参照记事列表小组件配置页；上下分界线沿用该弹窗原有的滑动状态提示逻辑。
- 首页根目录新建记事 FAB 的触摸 ripple 不再预览随机新记事颜色，统一改为偏白（accent+accent2 暖色渐变配白色 ripple 更协调）；文件夹内仍按文件夹颜色自适应偏白或偏黑。
- Drawer、移动到文件夹 Dialog、记事列表小组件配置页的根范围标签改为条件文案：数据库没有任何文件夹时显示“所有记事”，存在任意文件夹（含已在回收站中的）时显示“所有内容”。

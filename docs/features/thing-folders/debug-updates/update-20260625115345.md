## 修复右滑时"正在做"蒙层图标/文字先按旧尺寸闪现再跳变

- 上一版"正在做"蒙层的图标/文字缩放是放在卡片测量回调里做的，导致记事右滑预览出"正在做"蒙层时，先以默认大小（大图标）闪一下，随后才跳变成最终大小。
- 现在改为：只要卡片已经测量出高度（列表项复用、右滑预览等），就直接同步把图标、文字、间距按高度定好，蒙层一出现即是最终大小、不再跳变；只有首次绑定、卡片还没量出高度时才退回原来的延后处理。

测试重点：
- 在普通列表里右滑一条记事触发"正在做"预览蒙层：蒙层里的图标和文字一出现就是正确大小，没有先大后小的跳变。
- 已经在"正在做"的记事、以及大文件夹缩略图里的"正在做"记事：显示仍然正常，图标与文字协调。

## 搜索结果打开文件夹后保留搜索条件

本次更新继续优化首页搜索模式对文件夹的支持。用户反馈：在搜索结果里打开文件夹后，应继续维持搜索模式，并保留搜索框文本筛选和颜色筛选；从文件夹返回上级时也应保持同一组搜索条件。

诊断发现，文件夹导航入口会直接调用 `ThingManager.loadThings()`，导致当前搜索文本和颜色筛选被清空；搜索态的返回键也会优先退出搜索，而不是先返回父文件夹。

主要修改：
- `ThingManager.openFolder()`、`openParentFolder()`、`navigateToFolderPathIndex()`、`openFolderPath()` 支持只更新当前文件夹投影，暂不立即重新加载列表，默认行为保持不变。
- `ThingsActivity` 在搜索态打开文件夹、返回上级、点击文件夹路径段时，会用当前搜索框文本和颜色重新查询当前文件夹范围内的结果。
- 搜索态在非根目录按系统返回键或点左上角导航按钮时，先返回上级文件夹；回到根目录后再退出搜索。
- 左上角导航按钮的 content description 会根据当前搜索投影在“返回上级文件夹”和“离开搜索界面”之间切换。

验证：
- `:app:assembleDebug` 已通过，无 error / warning。
- 本次未使用 adb。

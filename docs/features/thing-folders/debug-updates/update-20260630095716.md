# 修复大文件夹里侧边图文缩略图长按时高度闪动（真因）

## 主要改动

- **修复：大文件夹（缩略图模式）里，一个"图片在左/右、内容列有正文+音频提示+提醒分割线"的侧边图文
  记事缩略图，长按它或别的记事时高度会闪一下，并连带挤动同列其它缩略图（如多级 checklist）的高度。**
  - 根因：侧边图文卡的图片高度 = 内容列实测文本高度。绑定后 `syncSideImageProjectionAfterMeasure`
    会在下一帧（`post`）据实测文本重新结算一次投影并改尺寸。大文件夹缩略图预览在绑定**之后**才用
    `applyFolderThumbnailPreviewScale` 把文字整体缩小，于是初始投影按未缩放文字算、偏大，下一帧的异步
    补算据缩小后的文字算出更矮的高度并改之——长按等触发列表重绑、重建预览时就表现为"高度闪一下"。
    普通列表不缩放文字、该补算本就 no-op，所以只在大文件夹缩略图里出现。
  - 修复：把补算逻辑抽成可同步调用的 `resyncSideImageProjection`，预览在缩放文字之后**同步结算一次**
    侧图投影，使卡片首帧即为最终高度；原有的异步补算届时因投影未变而 no-op。普通列表渲染路径不变。
  - 同列其它缩略图（如多级 checklist）的"连带闪动"是侧图卡改高度引起文件夹卡整体重测的级联，侧图卡
    高度定稿后应一并消失。

## 验证重点

1. 大文件夹（缩略图模式）里放一个侧边图文记事：图片在左或右，内容列同时有正文、音频附件提示、提醒
   （带分割线/图标/文本）。长按该记事、或长按同一文件夹里别的记事进入移动/选择：
   - 该侧图缩略图的**高度不应再闪动**；
   - 同列的其它缩略图（尤其多级 checklist）**高度也不应再被连带挤动**。
2. 普通列表里的侧边图文记事卡片外观、高度不回退（图随文走、底部状态置底等保持原样）。
3. 大文件夹缩略图里的侧图卡静态外观（图片宽高、内容列排版）与修复前一致，只是不再闪动。
4. full-span 与非 full-span 大文件夹、压缩列（masonry 多列）与单列预览都验证一遍。

## 备注

本项与上一版（更新码 202606291603）里那条"拖拽时列表闪动→SGLM gap 修正"的猜测无关，那条已撤回。

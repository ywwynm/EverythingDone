# 修复两个大文件夹（缩略图模式文件夹）相关问题

## 主要改动

1. **选择模式下点击大文件夹缩略图 = 选择 / 反选该文件夹**：此前在首页记事 / 文件夹混合列表进入
   选择模式后，点击大文件夹里的预览缩略图毫无效果（回调在非 NORMAL 模式直接返回）。现改为：选择
   模式下点击缩略图（预览记事或预览子文件夹），等同于点击文件夹卡片空白区域——选择 / 反选这个外层
   文件夹，与空白区域行为完全一致（含外观面板取消、选中计数 / 菜单刷新）。普通模式下点缩略图仍是
   打开对应记事 / 进入子文件夹，不变。

2. **修复全宽置底大文件夹缩略图里"正在做"图标 + 文字整体不显示**：正在做的记事显示在
   SPAN_FULL（占满整行）、独自置底的大文件夹缩略图预览里时，蒙层显示、但火箭图标 + "正在做"文字
   整体不显示（与预览卡高度、与是否有图片均无关）。根因是"正在做"图标 / 文字只通过 setTextSize /
   setCompoundDrawables 在布局之外被设置，仅发出重布局请求；对"宽度一趟定死、之后不再变化"的全宽
   稳定卡，这次重测会被卡片的"尺寸未变就跳过重测蒙层"逻辑吞掉、且不会再有新的测量趟次去兑现，
   于是图文停在零尺寸不渲染。现改为：算好图标 / 文字尺寸后，立即按卡片内容区把蒙层及其居中子 View
   同步测量 + 布局一次，保证图文一定渲染出来。

## 验证重点

1. 首页混合列表进入选择模式，点击大文件夹里的预览缩略图：该外层文件夹被选中 / 反选（与点击卡片
   空白区域一致）；再次点击取消。普通模式下点缩略图仍能打开对应记事 / 进入子文件夹。
2. 把一个正在做的记事放进一个占满整行、位于列表底部的大文件夹：缩略图里该记事应正常显示蒙层 +
   火箭图标 + "正在做"文字。短文字卡、高图片卡都验证一遍。
3. 普通（非全宽）大文件夹、以及右滑开始做事时的正在做蒙层外观不回退。

## 备注

第 2 项此前有两版误判（图片异步加载、卡片高度→缩放归零），均被真机复现推翻；最终定位为
"图文重布局在全宽稳定卡上落不了地"，与缩放无关。详见
`docs/features/doing-thing-organize/decisions.md` 与 `sessions.md` 的更正记录。

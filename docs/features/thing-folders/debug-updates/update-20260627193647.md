# 修复：拖拽大文件夹时缩略图卡片圆角丢失

## 主要改动

- 长按带缩略图的大文件夹进入拖拽（卡片放大）时，文件夹里缩略图预览卡贴边的内容（右上角置顶标识、
  上方/左侧的图片或视频、作为卡片背景的图片或视频）**现在始终保持卡片圆角裁切**，不再在拖拽时显示成
  直角矩形。
  - 原因：拖拽时的悬浮卡片是把卡片"画"成一张图片来做的，而这种软件绘制不会应用圆角裁切（圆角裁切是
    硬件渲染的能力），导致内部缩略图卡片的贴边内容被画成直角。现在在这条软件绘制路径上手动按卡片
    圆角抗锯齿地裁切，使悬浮卡片里的每张缩略图也保持圆角。
- "飞入文件夹"的移动动画同理受益。

## 验证重点

1. 长按带缩略图的大文件夹进入拖拽：文件夹里每张缩略图预览卡的四角始终是圆角——
   - 右上角有置顶标识的；上方有图片/视频的；左侧有图片/视频的；整张是图片/视频背景的，都验证一遍。
2. 拖拽结束后卡片圆角正常（不回退）。
3. 把记事/文件夹拖入另一个文件夹的"飞入"动画里，缩略图也是圆角。

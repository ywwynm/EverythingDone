# 修复大文件夹缩略图缓存的两个正确性问题（私密揭示态 / Widget 配置路径）

接上一版（202606300650 引入的缩略图整树缓存）的 review 修复，修两个缓存正确性盲点。

## 主要改动

- **修复：私密子文件夹在父大文件夹缩略图里的揭示态可能被缓存住、认证失效后仍显示已揭示内容。**
  - 场景：父大文件夹非私密、其中嵌着一个私密子文件夹。本会话认证揭示过该私密子文件夹后，App 切后台
    再回前台会清空会话认证，但首页此时只刷新、不重建列表，导致缓存里"已揭示"的子文件夹预览被继续复用，
    短暂显示出本应重新上锁的内容。
  - 修复：把"子文件夹是否已揭示"纳入缩略图缓存签名（与卡片本身的揭示判定同源）。揭示态一变，缓存即失效
    重建为锁态；认证失效后的刷新路径也能正确恢复上锁。

- **修复：单个记事 Widget 配置界面里的大文件夹缩略图缓存，未走到上一版新增的"列表刷新即失效"兜底。**
  - 原因：Widget 配置界面复用了文件夹卡渲染，但走的是另一条绑定路径，没经过首页列表的那道兜底检查。
  - 修复：把兜底检查移到两条路径都会经过的公共入口，并让 Widget 配置按它自己的数据源判定失效，确保该
    界面的大文件夹缩略图也能在数据变化/认证变化后及时刷新。

## 验证重点

1. **私密子文件夹揭示态（重点）**：
   - 准备：一个**非私密**的大文件夹，里面放一个**私密**子文件夹；进入会话认证揭示该私密子文件夹一次。
   - 把 App 切到后台再回到前台（触发会话认证清空），观察父大文件夹缩略图里那个私密子文件夹的预览：
     **应重新变回上锁态**，不再显示已揭示的标题/内容。
   - 正常进入私密文件夹认证、查看揭示内容，仍应正常。
2. **单个记事 Widget 配置界面**：进入桌面单记事 Widget 的配置，浏览含大文件夹缩略图的文件夹列表；认证
   私密文件夹前后，缩略图显示应正确（锁态/揭示态），不复用错误的旧预览。
3. **回归**：上一版的分列均匀、滑动顺滑、以及编辑/增删/置顶/子文件夹改名改色/习惯打卡后缩略图及时刷新，
   均应保持不变。

## 备注

P1 选择"把揭示态纳入签名"而非"认证代次变化时清空缓存"：签名是所有渲染路径都会实时计算的失效点，既覆盖
"认证失效（揭示→锁）"也覆盖"新增认证（锁→揭示）"，比只在清空时触发的代次更全面，且主列表与 Widget 配置
都能各按自身的揭示语义生效。

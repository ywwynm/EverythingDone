## 移动到文件夹 Dialog 飞入动画目标坐标修正

本次继续修正“移动到文件夹”相关动画：

- 用户反馈：目标文件夹 F 不一定完整可见，飞入动画不能直接使用 F 卡片完整中心点；如果 F 的一部分被 selecting mode 的 contextual actionbar 挡住，也应该按实际可见区域计算。
- `ThingsActivity` 现在会用目标文件夹卡片与当前 `RecyclerView` 可见 viewport 的交集作为飞入目标区域，并扣除 contextual toolbar wrapper（含 statusbar spacer 和 shadow）的垂直遮挡。
- Dialog 移动路径会在退出选择模式前缓存当前 viewport，避免 contextual toolbar 隐藏后重新计算时丢失遮挡信息；多选时仍优先保留所有可见源项飞入目标文件夹的动画。
- 如果目标文件夹在扣除遮挡后完全不可见，则不生成飞入目标，继续走可见源项的定向移除动画或全量刷新兜底。
- 后续确认旧拖拽提交动画不应套用这条 Dialog 坐标规则，旧拖拽路径继续按自身落点语义处理。

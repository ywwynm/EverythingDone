# 修复大文件夹缩略图里"正在做"图标贴边

## 本次改动

- 修复大文件夹缩略图里，若某条记事正在做、且内容只有一行、卡片很矮时，"正在做"蒙层里的图标会紧贴卡片上下边缘、不美观的问题。
- 现在图标按卡片高度自适应：卡片够高时保持原始大小，矮到放不下时自动缩小，保证上下留出间距。主页列表里"一行内容的正在做卡片"也一并受益。

## 测试重点

- 进入一个大文件夹（缩略图模式），让里面某条只有一行内容的记事处于"正在做"，看缩略图里那张迷你卡片的"正在做"图标上下是否有留白、不再贴边。
- 主页列表里把一条只有一行内容的记事设为"正在做"，确认图标也不贴边。
- 内容较多、较高的正在做卡片，图标大小应与之前一致、无变化。
- 文件夹缩略图正常跨度 / 全宽跨度两种都看一下。

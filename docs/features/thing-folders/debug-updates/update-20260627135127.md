## 首页搜索模式补齐文件夹支持

本次优化首页搜索模式对文件夹的支持，并修正搜索结果内选择操作的作用范围：

- 搜索关键词现在会匹配文件夹标题；搜索颜色现在会匹配文件夹自身背景色。
- 搜索结果中长按文件夹可以直接进入选择模式，不再被正在进行视图的拖拽分支挡住。
- 在搜索结果中选择文件夹、记事或二者混合后，完成、恢复、删除、永久删除等影响记事的操作，只作用于当前搜索范围内实际命中的记事。
- 确认弹窗的范围提示已与类型筛选提示合并：同时存在类型筛选和搜索范围时只显示一句合并提示；仅搜索范围时提示“本次操作仅作用于当前搜索范围内的记事，其他不在搜索范围内的记事不受影响”。
- 相关设计记录已同步到 `docs/features/thing-folders/` 与 `docs/features/selection-batch-actions/`。

验证：`:app:assembleDebug --console=plain --no-configuration-cache` 已通过；`git diff --check` 仅有仓库既有 LF/CRLF 提示。

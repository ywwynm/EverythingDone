# 删除 folder-drop 收尾的滚动保护（实测无效，跳动是另一个真因）

## 主要改动

- **删除 `ThingsActivity.rebindHomeListAfterFolderDropModeExit` 的滚动 save/restore**，恢复为 HEAD 的
  简单 `notifyDataSetChanged`。实测结论：加不加这处 save/restore，folder-drop 收尾的"上下跳一下"都照旧，
  说明它并没修好这个跳动——跳动是另一个真因的问题，与滚动位置无关。故移除这处无效改动，保持代码干净。

## 验证重点

- 本版只是去掉一处无效改动，folder-drop 收尾的跳动现象与上一版（202606300313）一致（即仍会跳）；该
  跳动留待后续单独定位真因。
- 之前三处大文件夹缩略图修复（预览数量、侧图高度闪动、媒体背景置底）保持有效、不受影响。

## 备注

folder-drop 收尾跳动的真因尚未定位，已知 SGLM gap 的 save/restore 思路对它无效（与早先拖拽缩略图闪动一样，
是误判方向）。后续如需处理，应另查其真实成因，而非套用滚动位置保护。

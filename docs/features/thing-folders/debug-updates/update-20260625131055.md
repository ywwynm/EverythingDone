# 移动到文件夹弹窗标题/确认按钮按当前文件夹配色

## 移动到文件夹弹窗标题/确认按钮按当前文件夹配色

- 之前多选记事/文件夹点"移动到文件夹"，弹窗的标题和确认按钮颜色是按第一个所选记事/文件夹的颜色取的；现在改为按当前所在文件夹配色，与"完成所选记事"等确认弹窗一致。
- 根目录下用 accent+accent2 渐变，在某个文件夹里就用该文件夹的颜色（纯色或渐变）。

测试重点：
- 根目录下多选记事（或文件夹、或混合）→ 移动到文件夹：弹窗标题与确认按钮为 accent 橙色渐变。
- 进入某个有颜色的文件夹，多选其中的记事 / 子文件夹 → 移动到文件夹：标题与确认按钮用该文件夹的颜色。
- "移动当前文件夹"也一致（用当前文件夹自己的颜色）。

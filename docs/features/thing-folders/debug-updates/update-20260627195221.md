# 修复（第二版）：拖拽大文件夹时缩略图卡片圆角丢失

## 主要改动

- 修正上一版（更新码 202606271137）未生效的问题：拖拽带缩略图的大文件夹时，文件夹里缩略图卡片
  贴边的内容（右上角置顶标识、上方/左侧图片或视频、整张图片/视频背景）**现在才真正保持圆角**。
  - 上一版用的圆角蒙版方式有 bug：只裁了圆角矩形内部、四角没被处理，所以等于没裁。本版改为正确地
    把四角抗锯齿地擦掉，缩略图卡片四角才真正变圆。

## 验证重点

1. 长按带缩略图的大文件夹进入拖拽：文件夹里每张缩略图预览卡四角始终圆角——
   右上角有置顶标识的、上方有图片/视频的、左侧有图片/视频的、整张是图片/视频背景的，都看一遍。
2. 拖拽结束后圆角正常（不回退）。
3. 把记事/文件夹拖入另一个文件夹的"飞入"动画里，缩略图也是圆角。

## 单个记事 Widget 配置顶部栏跟随文件夹配色

用户反馈：单个记事 Widget 配置界面上方的 `statusbar + actionbar` 区域一直使用全局 `accent + accent2` 渐变，打开文件夹后也不会跟随文件夹颜色变化；同时要求全局 accent 渐变对应的文字和图标使用偏白前景色。

本次诊断确认 `BaseThingWidgetConfiguration` 只在初始化时固定给 `view_status_bar` 和 `Toolbar` 应用 `App.defaultAccentBackground`，切换文件夹时只更新标题，没有刷新顶部栏背景、文字颜色、返回图标颜色或系统状态栏图标模式。

本次修改：
- 在 `BaseThingWidgetConfiguration` 中新增顶部 chrome 刷新逻辑，统一设置 `view_status_bar`、`Toolbar` 背景，以及标题、返回图标、overflow/menu 图标颜色。
- 根目录继续使用 `App.defaultAccentBackground`，但前景色固定为 `white_86p`，系统状态栏图标使用浅色模式，避免 accent 渐变被亮度算法误配成偏黑图标。
- 打开文件夹后使用该文件夹的纯色或渐变背景，并按背景代表色通过 `BackgroundUtil.onColor` 自动选择偏白或偏黑前景色；浅色文件夹会切换到深色系统状态栏图标。
- 从文件夹返回上级、进入文件夹、结束 Widget 预览回到选择界面时都会重新应用当前范围的顶部栏配色。

验证：
- 已运行 `:app:assembleDebug --console=plain --no-configuration-cache`，构建成功。
- 已运行 `:app:publishDebugUpdate -PdebugUpdateNotesFile=docs/features/thing-folders/debug-updates/update-20260624213401.md --console=plain --no-configuration-cache`，发布成功，更新码 `202606241334`，远端 `latest.json` 指向 `http://120.25.194.207/everythingdone-updates/debug/latest.json`。

# 2026-06-25 修复"调整裁切"图标亮色模式下颜色偏深

- 亮色模式下"调整裁切"图标比另两个偏深。原因：两个 PNG 图标是纯黑 @ 0x8A alpha（约 54%）绘制，亮色模式仅走 XML `drawableTint`（`#6D6D6D`，SRC_IN 保留各自 alpha），所以呈半透明软灰；而 crop 矢量是全不透明黑，tint 后是实心 `#6D6D6D`，更深。
- 修复：把 `act_adjust_drawer_header` 的 `fillColor` 由 `#FF000000` 改为 `#8A000000`，与两个 PNG 的 alpha 一致；亮色模式 tint 后颜色对齐，暗色模式经 opaque tint 仍然一致。
- 本地已通过 :app:assembleDebug 编译验证；本次未使用 adb。

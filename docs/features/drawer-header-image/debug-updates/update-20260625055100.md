# 2026-06-25 抽屉/统计头图支持选本地图与裁切

- 修复在设置里为抽屉头图选择本地相册图片时误报“不支持添加网络图片”的问题。改用 DetailActivity 的稳健流程：优先引用原图路径，遇到解析不出路径的 content URI 时按 MIME 复制兜底（这正是此前报错的那种情况）。
- 新增头图裁切编辑：可调宽高比（连续滑块，默认 16:9，范围约 1:2 到 2.7:1）、平移与缩放，复用记事卡片外观那套裁切交互。
- 同一张图与同一套裁切同时驱动“抽屉头部”和“统计界面顶部”，两处保持一致取景。
- 设置里“抽屉头部图片”的弹窗改为三项：默认 / 选择图片 / 调整裁切（已设自定义图时才出现“调整裁切”，可直接重新取景而无需重选图）。
- 头图支持动图：选 GIF / 动态 WebP 时，抽屉与统计头图会逐帧裁切并播放；裁切编辑器内只显示单帧。
- 老用户已设的头图升级后观感不变（未调整裁切时按默认 16:9 居中，与此前一致）。
- 本地已通过 :app:assembleDebug 编译验证；本次未使用 adb 连接任何设备。

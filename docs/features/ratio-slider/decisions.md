# RatioSlider 决策

Feature 级决策。全局索引见 `memory/decisions.md`。

## 2026-06-25 - 统一四处比例调节滑条为 RatioSlider

经一次 grill 逐项确认,定下以下设计:

1. **超集共用一套档位**。4 处显示同一套梯子,靠各自 `[min,max]` 过滤显隐,
   而非各自维护一套档位。避免"详情没有 9:16/3:4、卡片没有 3:2/65:24"的不一致。
2. **各处保留自己的 min/max**。卡片继续按几何动态算(真实可达裁切范围,受缩略图
   高度上下限约束),详情/抽屉固定 `[0.5, 65/24]`。不把卡片改成固定范围,以免允许
   做不到的比例或挡掉本可做到的极端比例。
3. **档位成员 = 原并集 + 2:3,不加 24:65**,共 10 档。2:3 是之前漏掉的常用竖图比例;
   24:65 无实际意义。
4. **对数映射**(位置 ∝ ln(ratio)),tick 位置与 seekbar 手感统一。理由:比例是倍数
   关系,对数下互为倒数自动对称、拖动每步等比例;线性下 65:24 会把竖图侧档位挤扁,
   对数把它们摊开。否决了"档位等间距(序数均分)"(动态范围下子集间距会变、自由拖动
   不再等比例)和"保留线性只特判 65:24"(治标不治本)。
5. **组合控件 RatioSlider 收敛**。新建自包含控件内部装 ticks + SeekBar,4 处各放一个,
   把映射/snapping/布局/主题色/拖动锁范围全部封装。否决了"只抽常量+工具函数"(模板
   代码仍重复)与"binder/controller"(不如组合控件彻底)。
6. **动态范围:rangeProvider + 拖动开始锁定 + 显式 refreshRange**。保持现有手感
   (拖动期间不让范围随预览几何抖动);非拖动时由调用点在几何变化后显式刷新。

# 追加及时计时数字字体

本次更新为及时计时数字新增 9 种可直接接入的字体风格：

- Space Grotesk
- Limelight
- Righteous
- Poiret One
- Major Mono Display
- Genos
- Italiana
- Nixie One
- Outfit

实现细节：

- 扩展 `generate_glyph_data.py`，支持只生成指定 style 子集，避免重新生成已有字体资产。
- 使用现有 filled-outline timely 管线生成新的 `app/src/main/assets/timely/*.json` 字形数据。
- 在 `DoingDigitStyleDialogFragment.STYLES` 中加入新增字体，使设置里的「计时数字风格」dialog 可以选择它们。
- 本轮不接入 stencil / Monoton 类字体；这些字体需要先扩展离线管线支持多外轮廓 / 多填充分片。

验证：

- 已运行 `:app:assembleDebug`，编译通过。
- 已运行 `:app:publishDebugUpdate -PdebugUpdateNotesFile=docs/features/timely-digit-typography/debug-updates/update-20260705141512.md`，发布 debug 更新 `202607050615` 成功。

# Timely 计时颜色与录音计时器微调

本次更新继续调整及时数字读数在 DoingActivity 和录音 dialog 中的视觉效果。

- 将整组读数的位置透明度从此前的 96% -> 64% 改为 90% -> 100%，让右侧秒钟变化更醒目；设置里的字体预览同步使用新梯度。
- 无限时长符号 `∞` 不再套位置透明度遮罩，内部字形透明度固定为 100%。
- 录音 dialog 宽度从 280dp 调整为 320dp；录音计时器高度从 44dp 调整为 40dp，并收紧冒号间隔，减少完整 `HH:MM:SS` 顶到边界的问题。
- 录音进行中为 timely 计时器加入整体透明度呼吸；停止、重录和关闭 dialog 时会取消呼吸动画。
- DoingActivity 和录音 dialog 仍保留 h/m/s 的粗细层级、Thing Background 字形色、整组渐变和细轮廓光。

验证：`:app:assembleDebug` 已编译通过；`:app:publishDebugUpdate` 已发布阿里云 debug update `202607050245`。未使用 adb。

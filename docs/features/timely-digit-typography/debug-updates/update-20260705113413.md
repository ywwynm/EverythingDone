# Doing 计时器进场动画修复

本次更新修复 DoingActivity 打开后 timely 计时器抢先直接显示的问题。

- 根因：迁移到单个 `TimelyClockView` 后，读数在 `updateTimeViews()` 中会立即绘出并被设为可见，而 `playEnterAnimations()` 只处理了无限时长分支的淡入。
- 修复：`clock_time_doing` 初始 alpha 改为 0；普通倒计时不再在 `updateTimeViews()` 中直接设为 `alpha=1`。
- 进场动画统一处理普通倒计时和无限时长：普通倒计时淡入到 1.0，无限时长淡入到 0.76。
- 本次没有改动录音 dialog 的宽度、上边距或 alpha 参数。

验证：静态检查确认没有残留的提前 `alpha=1` 路径；`:app:assembleDebug` 已编译通过；`:app:publishDebugUpdate` 已发布阿里云 debug update `202607050334`。未使用 adb。

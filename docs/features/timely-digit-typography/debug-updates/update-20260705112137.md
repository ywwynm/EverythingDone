# 录音计时器顶部留白微调

本次更新调整录音 dialog 内 timely 计时器的位置关系。

- 保留用户改回的 280dp dialog 宽度，以及用户已经调好的录音计时器 alpha 参数。
- 将准备和录音阶段的 `TimelyClockView` 顶部间距从 18dp 增加到 26dp，让计时器不再贴近 dialog 顶部。
- 停止录音后，计时器下移动画仍落到调整前相同的绝对位置：旧位置为 18dp top margin + 72dp translation = 90dp；现在通过 90dp 目标顶部位置动态扣除当前 top margin 计算 translationY。
- 文件名编辑区域的 y 方向动画未改动。

验证：`:app:assembleDebug` 已编译通过；`:app:publishDebugUpdate` 已发布阿里云 debug update `202607050321`。未使用 adb。

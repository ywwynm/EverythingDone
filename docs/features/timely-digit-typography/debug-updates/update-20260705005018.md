# 计时数字：改回粗细分档（尺寸一致），用逐档合成描边加粗

## 用户反馈

- 不要用尺寸区分，必须靠粗细。每种字体都有不同粗细版本，肯定能实现。时/分/秒数字尺寸要保持一致。

## 思路修正

- 撤销上一版的"尺寸阶梯"，时/分/秒**尺寸完全一致**。
- 这个 App **原本**就是用"每档不同的笔画宽度"（时 28 / 分 16 / 秒 8）做层级、效果本就清晰。改成填充后只靠字体自带字重轴，多数字体范围有限、单字重字体（Abril Fatface、Pacifico）根本没有，所以差异变弱。
- 解决：在填充字形上叠加**逐档的合成描边加粗**（`Paint.FILL_AND_STROKE`，描边宽度按字形高度的比例逐档设定：时最粗、秒不加），粗细比例完全由代码控制，对**任何字体（含单字重）**都强烈可辨，且尺寸一致。这就是原有机制搬到新字形上，无需字体自带多字重。

## 本次修改

- `TimelyView` 新增 `setWeightStroke`；`onDraw` 在填充模式下用 `FILL_AND_STROKE` + 逐档描边宽度（时 `0.08`、分 `0.035`、秒 `0`，均为字形高度比例），描边端点/连接设为圆角。撤销尺寸阶梯（`scale` 恒为 1）。
- `DoingActivity` 按 时/分/秒 设置 `weightStroke`，尺寸系数统一为 1。
- 选择器预览 `renderClock` 同步：同尺寸 + 逐档描边加粗，透明度阶梯保留作次要强化。
- 上一版的"按 advance 统一间距、修宽字体相撞"保留不变。

# Timely 计时数字显示记事颜色，并接入录音计时器

本次更新继续优化 timely 计时数字：

- DoingActivity 的倒计时读数改为使用当前 Thing Background 作为主字形色。纯色记事直接显示原色；渐变记事会在当前可见读数组上连续铺设渐变，不再让每个数字各自重复渐变。
- 读数透明度改为从左到右 96% -> 64% 的连续渐变；h/m/s 的层级继续由合成粗细表达。
- 新增复用的 `TimelyClockView`，统一绘制数字、冒号、无限符号、连续渐变、透明度和可读性辅助层。
- 可读性辅助层改为细微轮廓光：使用 64% 宿主反向明暗 + 36% Thing Background 的混色，stroke 宽度为字高 0.018，alpha 为 0.32，并保留 0、4、6、8、9 等数字洞形透明，不做整块 glow。
- 录音 dialog 的计时器从系统 `Chronometer` 迁移到同一套 `TimelyClockView`，固定显示 `HH:MM:SS`，复用用户在设置里选择的 timely 字体风格和实心/空心模式，并使用当前详情记事的 Thing Background 字形色。
- 设置里的字体样式预览仍保持中性深色背景 + 白色字形，避免在没有具体 Thing 的场景里误导颜色来源。

验证：`:app:assembleDebug` 已通过，未使用 adb。

## 设置字体选择器选中态与滚动指示

继续调整设置界面的 timely 字体选择 dialog：

- 选中字体行中的字体名称改为偏白文字，保证在整行 accent + accent2 渐变背景上可读；未选中字体名仍使用提示性文本颜色。
- 打开 dialog 时自动滚动到当前选中的字体；切换实心 / 描边后也会保持当前字体行可见。
- 在实心 / 描边 tab 下方加入顶部滚动指示线，显示 / 隐藏逻辑参考设置应用语言 dialog：列表位于顶部时隐藏，向下滚动后显示。该 dialog 只保留顶部这一条指示线。

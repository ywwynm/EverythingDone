# 录音重录不再重复 animateIn

本次更新调整录音 dialog 的 timely 计时器出现动画。

- `animateIn(0L)` 只保留在 dialog 首次出现时播放，通过 `configureClockView` 阶段的延迟 `mClockIntro` 触发。
- 点击重新录音、从完成态回到准备态时，不再播放 `animateIn`；计时器直接静态复位到 `00:00:00`。
- 重录回准备态时会取消任何待执行的 `mClockIntro` callback，避免重复出现动画。

验证：`:app:assembleDebug` 已编译通过；`:app:publishDebugUpdate` 已发布阿里云 debug update `202607050413`。未使用 adb。

## 设置界面 timely 字体选择器重设计

本次更新重做了设置界面的“Countdown Digit Style / 倒计时数字字体”选择 dialog。

- 实心 / 描边选择改成两个等宽 page tab，视觉上向记事详情提醒时间 dialog 和 Thing Background 编辑器的页签靠拢；选中 tab 使用 accent + accent2 渐变文本，未选中 tab 使用提示色，并保留渐变触摸 ripple。
- 字体列表每一行改为“字体名称在上、`01:29:36` 预览在下”的纵向结构。
- 未选中字体行保持透明背景，触摸时显示 accent + accent2 渐变 ripple；未选中预览数字本身使用 accent + accent2 渐变。
- 当前选中的字体行整行使用 accent + accent2 渐变背景，预览数字改为白色，以便更清楚地区分选中态。
- `TimelyView.renderClock` 增加整组连续渐变预览能力，并统一用左到右 90% -> 100% 的 alpha mask，确保设置预览与 DoingActivity、录音 dialog 的位置透明度规则一致。
- 补充处理了实心 / 描边 tab 快速切换时的渐变文本状态：未选中 tab 通过 `ThingBackground.pure(hintColor)` 清掉 pending shader，避免旧选中态的延迟 shader 回写。

验证：`:app:assembleDebug` 已编译通过。未使用 adb。

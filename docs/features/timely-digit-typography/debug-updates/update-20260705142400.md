# 多外轮廓及时数字字体

本次更新扩展 timely 字形生成管线，并接入此前延后的多外轮廓字体。

新增字体：

- Big Shoulders Stencil
- Sirin Stencil
- Allerta Stencil
- Saira Stencil
- Stardos Stencil
- Monoton

实现细节：

- `generate_glyph_data.py` 不再把次级轮廓限制为最多 2 个。
- 历史字段 `holes` 现在承载所有次级轮廓：真实数字内洞、stencil 缺口、inline 环和分离填充分片。
- 运行时继续使用 `EVEN_ODD` 填充；现有 `TimelyView` / `TimelyClockView` 已支持任意数量的次级轮廓 morph，因此无需改 JSON 顶层结构。
- 更新 `DoingDigitStyleDialogFragment.STYLES`，设置里的「计时数字风格」dialog 现在可以选择这些字体。

验证：

- 已运行 `:app:assembleDebug`，编译通过。
- 已运行 `:app:publishDebugUpdate -PdebugUpdateNotesFile=docs/features/timely-digit-typography/debug-updates/update-20260705142400.md`，发布 debug 更新 `202607050624` 成功。

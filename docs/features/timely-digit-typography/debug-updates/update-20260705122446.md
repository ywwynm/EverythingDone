# TimelyClockView 宽字体自适应

本次更新处理不同 timely 字体字宽不同导致读数可能贴近边缘的问题。

- `TimelyClockView` 绘制时会按 `min(内容高度, 可用宽度 / widthUnits)` 计算实际绘制尺度；宽字体会整体缩小到 view 的可用宽度内，避免溢出或贴边。
- DoingActivity 的 `clock_time_doing` 改为占满父行可用宽度，并在屏幕左右各保留 24dp。
- DoingActivity 动态调整计时器高度时，不再把宽度重置为 `wrap_content`，保持 `match_parent`。
- 录音 dialog 的 `clock_record_audio` 改为占满 dialog 内可用宽度，并在 280dp dialog 内左右各保留 16dp。

验证：`:app:assembleDebug` 已编译通过；`:app:publishDebugUpdate` 已发布阿里云 debug update `202607050425`。未使用 adb。

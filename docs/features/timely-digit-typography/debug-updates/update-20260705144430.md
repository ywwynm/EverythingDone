## 2026-07-05 Stencil 秒钟字距修正

- 用户反馈 Stencil 系列字体中，秒钟部分两位数字的间距会显得偏大。
- 复核 `TimelyClockView` 和 `TimelyView.renderClock` 后确认：当前读数使用统一 tabular advance，秒钟又保持最轻字重，Stencil 的断笔和镂空会放大秒钟两位之间的视觉空隙。
- 本轮在 `TimelyClockView` 中为 Big Shoulders Stencil、Sirin Stencil、Allerta Stencil、Saira Stencil、Stardos Stencil 增加秒钟两位的动态 kerning：只在当前秒钟组合确实有额外空隙时，将秒钟个位向左收紧；宽数字组合保留原位置，避免重叠。
- 同步更新 `TimelyView.renderClock`，让设置页字体选择器中的 `01:29:36` 预览与 DoingActivity、录音 dialog 的实际计时显示保持一致。
- 未使用 adb。

# 计时数字：拉大时/分/秒字重差 + 接入全部风格 + 设置选择器

## 用户反馈

- 时/分/秒的粗细差别太小，几乎看不出——希望能统一调整这个参数。
- 既然可以统一调，就把其它字体也都接进来。

## 本次修改

- **拉大字重阶梯（统一参数）**：离线生成器新增一个统一的字重档位配置 `WT`（时≈900、分≈450、秒≈200）。可变字体按该档位取实例；Poppins 改用 Black/Regular/ExtraLight 三个静态字重（原来是 Bold/Regular/Light，差距太小）；Zilla Slab 用 Bold/Regular/Light；单字重字体（Abril Fatface、DM Serif、Pacifico）无法变字重，仍靠透明度分层。
- **接入 11 种风格**：`generate_glyph_data.py` 改为通用多字体生成器，一次产出全部风格的 `app/src/main/assets/timely/<style>.json`。本次上架 Poppins、Comfortaa、Orbitron、Playfair Display、Abril Fatface、Zilla Slab、Lora、DM Serif Display、JetBrains Mono、Pacifico、Dancing Script。
- **Cormorant Garamond 暂缓**：它默认是旧式数字（高低不齐、带降部），用在计时器上会参差不齐，需要先做等高数字（`lnum`）处理，本次先不上，留作后续。
- **设置里的选择器**：设置页「界面」组新增「计时数字风格」一行；点开是一个对话框——顶部 `实心 / 描边` 切换，下面每种风格一行、用 `01:29:36` 深色底白字实时预览（能看出时/分/秒字重差），点选即生效。选择存入偏好，`DoingActivity` 打开时读取并应用（风格 + 渲染模式）。
- `TimelyView` 新增填充/描边渲染模式与整块时钟预览渲染 `renderClock`。

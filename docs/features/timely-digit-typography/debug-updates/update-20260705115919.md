# 无限呼吸范围与录音首次 animateIn 同步

本次更新调整 timely 计时器的两个动画细节。

- 修复无限时长符号呼吸 alpha 会掉到接近 0 的问题。原因是旧代码用 `1 - 当前 alpha` 计算下一次目标；当当前 alpha 接近 1 时，下一次目标就接近 0。
- 无限时长符号现在进场淡入到 1.0，后续只在 1.0 和 0.75 之间呼吸。
- 录音 dialog 首次准备态的 `animateIn(0L)` 改为延迟 160ms 启动，让 `00:00:00` 的出现动画更接近下方录音波浪动画。
- 如果用户在延迟期间立即开始录音，会取消这次准备态 `animateIn`，避免进入录音态后重复播放。

验证：`:app:assembleDebug` 已编译通过；`:app:publishDebugUpdate` 已发布阿里云 debug update `202607050359`。未使用 adb。

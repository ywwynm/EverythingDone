# 计时数字排版曳光弹：Poppins 填充字形 + 形变

## 用户反馈

- 希望把 Doing 计时界面的数字换成漂亮字体、保留形变动画。经充分调研与讨论，定为"填充轮廓形变"方案（见 ADR-0015）。本次先跑通一种字体（Poppins），发布真机验证。

## 本次修改

- 重写 `timelytextview` 的 `TimelyView`：数字改用真实字体的**填充轮廓**渲染（外轮廓 + 最多两个字怀，`EVEN_ODD` 填充），替换原来的 13 点单线线框。
- 换数字时做**连续形变**：外轮廓与字怀按点线性插值，采用最佳旋转偏移对应（best-offset），缺失的字怀从质心点长出/缩回，保证洞的开合平滑。
- 字形数据由离线管线生成（`tools/generate_glyph_data.py`，`fontTools removeOverlaps` 去重叠 + 等弧长重采样 + 统一视觉盒），打包为 `app/src/main/assets/timely/poppins.json`（Bold/Regular/Light 三字重 × 0–9）。
- `DoingActivity` 给六个数字视图设置**时/分/秒字重阶梯**：时=Bold、分=Regular、秒=Light，叠加原有透明度（86/76/66%）。
- 目前仅 Poppins 一种风格、实心填充；其余 11 种风格、描边模式与设置入口为后续迭代。

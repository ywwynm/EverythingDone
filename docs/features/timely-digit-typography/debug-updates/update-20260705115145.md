# animateIn 双触发修复与录音接入

本次更新继续调整 timely 计时器动画。

- DoingActivity 普通倒计时不再在 `playEnterAnimations()` 中主动调用 `animateIn`；保留 `DoingService` 首次 tick 从 `[-1…-1]` 到当前读数的后一遍 morph。
- `playTimelyAnimation()` 首次触发时会先把 `TimelyClockView` alpha 设为 1，再播放服务触发的数字 morph，避免整个 view 先额外淡入。
- 录音 dialog 初次准备态和重录回准备态使用 `animateIn(0L)`，让 `00:00:00` 也从空形态出现；按下开始录音时仍固定到 0，不重复播放出现动画。
- 录音完成态计时器停止目标顶部从 82dp 改为 80dp；文件名区域停止 translation 保持 24dp。

验证：`:app:assembleDebug` 已编译通过；`:app:publishDebugUpdate` 已发布阿里云 debug update `202607050352`。未使用 adb。

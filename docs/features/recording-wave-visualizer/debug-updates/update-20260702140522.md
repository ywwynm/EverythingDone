## 录音波浪恢复灵动错峰感

- 回退上一版过度收束的波形策略：取消质量门控、严格谱式权重、主形/细纹强分离、空间平滑和顶部 headroom 前置限幅，恢复更自由、更野的多分量波形基底。
- 保留小颤动修复：实时振幅随机仍是连续慢速包络，瞬态仍有门限，避免回到 100ms 采样点跳变。
- 新增每层 / 每分量的个性化响应：录音特征帧先进入历史队列，每个波分量按自己的延迟、attack 和 release 追随不同时间点的目标，声音变化不会让所有浪同时上升或下降。
- 瞬态浪涌改成每层局部触发：不同层拥有独立延迟、强度、尖峰加成和衰减时间，让大声骤起时出现随机先后顺序，而不是全体统一动作。
- 恢复更宽的频率、权重和漂移速度随机范围，高频细纹与多分量干涉重新参与水面变化，以保留随机、灵动、每个浪有个性的感觉。
- 已通过 `:app:assembleDebug` 编译验证，发布后请重点观察波浪是否重新有随机先后、个体差异和更灵动的野性。

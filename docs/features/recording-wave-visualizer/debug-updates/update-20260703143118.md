## 录音波浪动画：修复残余阶梯状折点

这次更新继续优化 `RecordingWaveVisualizer` 中偶发的阶梯状折点。上一版已经明显减少锯齿和卡顿，但在多道浪合并、互相抵消时仍可能看到很轻微的局部下折。

本次诊断发现，生成浪的主位移虽然已经改为连续的 signed sum，但用于估计 trough room 的 `crestSupport` 仍依赖单个浪包当前是 crest 还是 trough。多个浪包互相穿过时，单个浪包跨过零点会让支持量的斜率发生变化，可能在总曲线上留下细小阶梯感。

本次修改：
- `RecordingWaveVisualizer.kt` 中，同层多浪包合并不再按单个浪包正负分组计算支持量，改为使用总 signed sum 的建设性 crest 分量和连续的合并能量 `sqrt(sum(offset^2))` 推导限幅空间。
- 路径重建改为局部单调 cubic 切线，在波峰/波谷附近避免 cubic 控制点过冲，把很小的合并斜率变化放大成折点。
- 降低生成浪尾部硬截断阈值，让浪包边缘更自然地衰减。
- 保持 6 层半透明水面、多浪包合并、强声高浪和现有采样质量；没有通过削弱浪高、降低野性或减少层数来掩盖问题。

验证：
- `:app:assembleDebug --console=plain --no-configuration-cache` 已通过。
- 未使用 adb，未安装到物理设备或模拟器。

# 录音波形可视化 调试发布日志

## 修复对话框限高，波浪加入时间与空间随机性

- 修复录音对话框高度塌陷成只剩水位的问题：根布局改为声明最小宽高（280×320dp，比原 300dp 加高 20dp），上方为计时与文件名预留空间。根因是对话框以 null parent 充气布局，根节点尺寸参数被忽略。
- 浪峰不再一样高：每层水面由主正弦与一条波长不同、反向流动的次谐波叠加，浪峰沿宽度高低不均，且形态随时间持续演化。
- 各层不再同升同降：每次音量采样对每层振幅加 ±35% 随机抖动；各层平滑速度不同（前层快、后层慢）；另有每层独立的慢速呼吸包络与水面基线微漂。
- 数值仍集中在 VoiceVisualizer 顶部常量，可继续按观感微调。

## 录音波浪形状美感优化

- 优化波浪偶尔“不够好看”的问题：不再让所有频段分量同等参与水面轮廓，而是让低频 3 个分量负责主浪形状，高频和 air 分量只做轻量表面细纹。
- 将波形分量权重改为更严格的谱式递减，主形分量占绝大部分能量，减少高频细碎波互相抢轮廓导致的破碎感。
- 每次打开录音仍然会随机生成不同波形，但现在会先做一次轻量质量检查：过密、过碎、细纹占比过高或曲率过高的参数会重新抽取。
- 波峰尖化加入坡度限制：只有足够大的主浪会被尖化，小碎峰不会被一起尖化；实际坡度过高时也会压低尖峰强度。
- 对最终水面采样点做轻量空间平滑，并根据上方可用空间提前限制振幅，减少顶部压扁和局部折皱造成的奇怪形状。
- 已通过 `:app:assembleDebug` 编译验证，发布后请重点观察不同录音开启时的水面轮廓是否更稳定、更漂亮。

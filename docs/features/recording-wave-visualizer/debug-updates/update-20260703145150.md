## 录音波浪动画：按按钮高度重新上调水位

这次更新修正上一版水位上移过于保守的问题。上一版只是把水位略微提高，但复查布局后确认，主录音按钮位于底部 `96dp` 按钮行内，按钮 top 大约在 `284dp`；上一版最前景深色浪的静态水面约在 `288dp`，仍低于按钮 top，因此视觉上只会擦到按钮边缘，不会明显盖过录音按钮。

本次修改：
- `RecordingWaveVisualizer.baseSurfaceY()` 从 `0.772 - waterLevel * 0.218` 调整为 `0.724 - waterLevel * 0.202`。
- 在 `360dp` dialog 中，最前景深色层静态水面约从 `288dp` 抬到 `271dp`，会更明显进入录音按钮区域。
- 同时略微收窄高水位继续上移的范围，避免强声时水面过度靠近上方文本。
- 未修改 dialog 尺寸，仍保持 `280dp * 360dp`；未修改按钮布局。

验证：
- `:app:assembleDebug --console=plain --no-configuration-cache` 已通过。
- 未使用 adb，未安装到物理设备或模拟器。

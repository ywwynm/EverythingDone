## 录音波浪 Fable 内核补全

本次更新继续补齐 Fable 方向里适合 EverythingDone 当前视觉目标的部分。仍然不替换视觉风格，录音 dialog 继续使用 `RecordingWaveVisualizer` 的 6 片半透明填充水面，并保持 `280dp * 360dp`。

主要变化：
- 冲击事件不再在 `receive()` 里即时注入物理波场，而是先进入轻量队列，再由动画帧统一消化，音频事件和水波积分更解耦。
- 补回窗口可见性、聚合可见性和焦点恢复时的帧循环启动/停止，降低锁屏返回或窗口状态变化后动画停住的风险。
- 增加非常轻的 `beatBreath`：当 tempo 置信度足够时，只让宽浪有轻微节拍呼吸，不额外制造尖锐波峰，也不做硬同步节拍。
- 横向流速改为更接近 Fable 的活动度门控：安静或低活动时保持慢速水感，有效声音、快节奏和明显事件出现后再恢复活跃流动。

有意不做：
- 没有引入 Fable 的粒子水花、径向光斑或整体三层视差视觉结构，因为这会改变 EverythingDone 当前 6 层填充水面的视觉身份。

验证：
- `:app:assembleDebug --console=plain --no-configuration-cache` 已通过。

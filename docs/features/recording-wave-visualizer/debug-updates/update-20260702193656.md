# D36 录音波浪水位随音量涨落优化

用户反馈：水位高低也应根据音量大小有一定变化，声音小时水位处于低位，声音大时处于高位；并要求回看之前关于水位的决定。

回看结论：
- D3 原始设计是“音量同时驱动浪高 + 水位”，声音大时水面升高、浪变大。
- D15 因为当时反馈“大声时基础水位匀速上升、带动每个浪整体匀速升高，不好”，把 `REST_FRAC / MAX_FRAC` 收窄到 0.06 左右，水位近固定，主要由浪振幅表达声音。
- D35 已经新增 `intensity` 区分声强，因此可以把水位重新接到声强通道，而不是继续只靠近固定水位。

本次调整：
- `VoiceVisualizer` 新增独立 `levelDrive`，由 `loudness` 与 `intensity` 混合后经曲线驱动水位。
- 水位范围从 `REST_FRAC=0.36 / MAX_FRAC=0.42` 扩为 `REST_FRAC=0.31 / MAX_FRAC=0.49`，声音小更低、声音大更高。
- 水位使用独立上升 / 回落时间常数：上升 `LEVEL_ATTACK_TAU=0.30`，回落 `LEVEL_RELEASE_TAU=0.62`，形成较慢的潮位变化，避免跟每个音节机械跳动。
- 保留 D33 空调风噪抑制、D34 峰高稳定和 D35 的 `intensity` / `pace` 分离。

# 录音主按钮去除 FAB 叠层

本次 debug update 修复上一版录音确认按钮视觉问题，并按用户要求重新实现为单个圆形按钮。

- 用户反馈：上一版正常状态下出现正方形背景，确认状态下图标附近出现多边形残留，效果很差；不应继续使用 FAB，应统一改成圆形按钮。
- 诊断结论：问题来自上一版 “透明 Material FAB + 背后色层” 的叠层方案。底层色块没有被圆形裁剪，所以普通态可能看到方形；Material FAB 自身的内部 shape/ripple 仍参与绘制，所以确认态图标附近会出现多边形/八边形残留。
- 修改 `fragment_record_audio.xml`：删除 `FloatingActionButton` 和背后 `View` 色层，改为单个 56dp 的 `ImageView` 圆形按钮，16dp padding 保持 24dp 图标视觉尺寸。
- 修改 `AudioRecordDialogFragment.kt`：主按钮类型改为 `ImageView`；普通态直接给按钮设置圆形高架面背景；确认态直接给同一个按钮设置当前 `ThingBackground` 的圆形纯色/渐变背景；图标仍通过 `BackgroundUtil.onColor(...)` 根据记事色自适应；ripple 前景按普通态/确认态分别使用 app chrome ripple 或自适应 ripple。
- 本次未改录音采样、波浪响应、水位或动画参数。

## 录音波浪动画：柔化毛刺并上移初始水位

这次更新回应两个真机反馈：
- 波浪偶尔仍会出现一些毛刺。
- 初始水位稍低，最深色前景浪没有盖过录音按钮的高度。

本次诊断认为，水位问题来自 `RecordingWaveVisualizer.baseSurfaceY()` 的静态基座偏低，尤其最前景深色层有向下的 `verticalOffset`，低能量时不够进入按钮所在高度。毛刺问题更像最终路径中少量孤立采样点、物理波场局部高斜率或细小扰动被路径重建放大，而不是需要削弱整套波浪。

本次修改：
- 将 `baseSurfaceY()` 的基座整体上移，让 6 道浪和底层水体一起上移，前景深色水面在低能量/初始状态也更容易盖过录音按钮高度。
- 新增最终路径的孤立尖点柔化，只处理单个采样点相对左右邻居形成局部极值且超过阈值的突起。
- 连续的大浪峰、多层半透明水面、同层多浪包合并和强声高浪仍保留，不通过降低浪高、减少层数或削弱野性来掩盖毛刺。
- 没有修改 dialog 尺寸，仍保持 `280dp * 360dp`。

验证：
- `:app:assembleDebug --console=plain --no-configuration-cache` 已通过。
- 未使用 adb，未安装到物理设备或模拟器。

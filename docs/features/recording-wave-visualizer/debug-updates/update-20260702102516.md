# 录音波形可视化 调试发布日志

## 波浪改为多分量合成，消除"波峰同时等高升起"的程序化感

- 每层水面从"单条正弦 + 谐波、整层共用一个振幅"改为 3 条不同频率 / 速度 / 相位的波分量叠加（准周期干涉）。
- 空间上：多分量干涉使波峰高低天然参差、不再等高，且随时间不断此消彼长。
- 时间上：每个波分量各自独立跟随音量，缓动速度不同（高频细纹快、低频大浪慢），每次采样各分量还有独立随机抖动——一声大声音来时是细纹先冒、大浪后涌、此起彼伏，而不是整条线同一时刻齐刷刷弹起。
- 水位上升改得更柔和一些（缓动放慢），保留"音量大整体上升"的趋势；波浪最大振幅相应上调补偿多分量的相互抵消。

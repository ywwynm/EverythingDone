## D29 录音波浪安静降活跃度与自然水感优化

- 新增音频有效活动度 `activity`，综合持续响度、onset/fast impact 和 spectral flux，区分安静、有效活动和强冲击。
- 安静时门控 rhythm/beat/onset/pulse 与 tempo 历史，减少环境底噪和近静音小波动触发的高频动画。
- 视觉侧按 `activity` 衰减主体驱动、细节驱动、节奏触发、漂移加速和 rhythm contour；强 onset 仍可快速唤醒节奏层。
- 静音微动改为更慢、更低频的独立 idle 波，安静时保留轻微水感，但不再高频翻动。
- 未使用 adb，未连接或安装到物理设备。

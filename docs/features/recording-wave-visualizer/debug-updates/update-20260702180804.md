# D34 录音波浪峰高稳定优化

用户反馈：D33 后安静工位和空调风噪场景已经好一些，但动画里仍能看到部分波峰高度出现抖动式上下变化，影响观感。

本次调整：
- `VoiceVisualizer` 不再恢复逐采样最终 y 值冻结，避免重新引入峰顶锯齿。
- 新增逐层 `ampBoost` 死区平滑，吸收 surge、rhythm 和 rhythmEnergy 的小幅变化，减少已成形波峰被轻微 envelope 推着上下浮动。
- 新增逐层 `crestFactor` 死区平滑，避免峰形尖化强度被很小事件包络持续改写。
- 主体分量的慢速随机包络收敛，细节分量保留更多随机性；低活动状态下两者都会进一步压低。
- 高位波峰区域的细节衰减提前并增强，让峰顶更稳定、圆润。

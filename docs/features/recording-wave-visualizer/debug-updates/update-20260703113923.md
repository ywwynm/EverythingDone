## 录音波浪波谷限幅与细微抖动修正

本次根据真机反馈继续调整 `RecordingWaveVisualizer`：上一版在声音变化较大时，波谷可能直接落到 dialog 底部，视觉上上下差异过大；同时部分波浪会因为音频 drive 的细小变化出现轻微颤动。

主要修正：
- 为 `level`、`waterLevel`、`swell`、`wake`、`pace`、频段权重、pitch、pan、beat/tempo 等输入目标增加死区门控，小幅变化不会反复更新目标值。
- 目标值超过阈值后仍由 visualizer 内部状态通过 `approach()` 连续追赶，避免瞬时 set 式跳变。
- 以每层 `baseSurfaceY + verticalOffset` 作为平均基座水位，对向下波谷做指数软限幅；允许明显波谷，但超过基座水位下方阈值后逐渐收束，避免 trough 撞到 dialog 底部。
- 略微降低物理波场中配对 trough 的向下冲击，并降低高能量整形对向下波谷的额外放大，保留向上波峰的野性和高能量表现。

验证：本地 `:app:assembleDebug --console=plain --no-configuration-cache` 已通过。未使用 adb，未连接或安装到物理设备/模拟器。

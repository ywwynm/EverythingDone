## 录音波浪行进波前修正

本次根据真机反馈继续调整 `RecordingWaveVisualizer`：上一版在声音变化时，波浪会在原地把已有曲线拉成波峰和波谷，看起来像一座座山，而不是自然升起并传播的水波。

主要修正：
- 降低 `level`、`swell`、`wake`、`wildness` 对整条基础正弦波的直接振幅放大，避免声音变化时整条曲线原地变形。
- 新增带生命周期的 traveling surge：当 `level` / `swell` / `presence` / `wake` 上升或 beat pulse 明显时，生成局部行进波前，让波峰从水面局部升起并横向传播。
- traveling surge 在 6 层水面之间带有轻微层间延迟、宽度和强度差异，与已有一维阻尼物理波场共同表现声音事件。
- 保留上一版的目标值死区门控和相对基座水位的向下软限幅，避免回到轻微颤动或波谷撞到底部的问题。

验证：本地 `:app:assembleDebug --console=plain --no-configuration-cache` 已通过。未使用 adb，未连接或安装到物理设备/模拟器。

## 录音波浪自然动力学补强

本次更新继续录音 dialog 的新 `RecordingWaveVisualizer` 调优，不替换 EverythingDone 当前的 6 层填充水面视觉风格，只借 Claude Fable 的自然波浪动力学思路。

主要变化：
- 6 层波浪现在在每次 dialog 生命周期开始时生成小幅实例级差异，包括相位、采样偏移、振幅、速度和细节比例，让各层同源但不完全重合。
- 物理波场脉冲从单个正向扰动改为较宽的 crest/trough 成对速度扰动，并轻量消除整体速度均值，减少整片水面被机械抬起的感觉。
- 略微放慢波场传播、提高短波黏性、加宽脉冲核，让波峰更圆润，保留明显响应但避免尖锐跳动。
- 加密水体和主波填充曲线采样，继续降低半透明填充路径产生的竖向分段或闪烁感。

保持不变：
- 录音 dialog 根布局仍为 `280dp * 360dp`。
- 入口仍统一使用 `RecordingWaveVisualizer`。
- 没有使用 adb，也没有自动安装到设备。

验证：
- `:app:assembleDebug --console=plain --no-configuration-cache` 已通过。

## 录音波浪小颤动修复

- 修复波浪已经升高后，随着音量和频段变化偶尔出现细小颤动的问题。
- 主要原因是此前每 100ms 音频采样时，会给每个波分量重新应用一次即时振幅随机；当波浪幅度已经较大时，这些目标值小跳变会被视觉放大。
- 现在随机性改为每个波分量自己的连续慢速包络，仍保留自然不规则感，但不再在采样点突然换目标。
- 同时给瞬态浪涌增加 0.20 门限和 180ms 冷却，避免微小频谱波动反复触发浪涌；并略微降低高频 / air 频段和整体频段混合权重，让细纹更稳。
- 已通过 `:app:assembleDebug` 编译验证，发布后请重点观察大声说话或环境声变化时，已经升起的浪体是否还会出现不自然小颤动。

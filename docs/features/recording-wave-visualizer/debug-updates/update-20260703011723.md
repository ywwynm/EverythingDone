## 2026-07-03 - 录音波浪动画完整重做

本次 debug update 把 DetailActivity 录音 dialog 里的波浪动画入口切换到全新的 `RecordingWaveVisualizer`，旧的 `VoiceVisualizer` 代码暂时保留在仓库中，但不再作为当前 dialog 的运行入口。dialog 根尺寸保持 `280dp * 360dp`，自定义 View 仍然只使用原有 `match_parent` 区域，不改变对话框尺寸。

实现内容：
- 新增 `RecordingAudioFeatureFrame`、`RecordingWaveDriveFrame`、`RecordingWaveFrameReceiver`、`RecordingAudioAnalyzer` 和 `RecordingWaveVisualizer`。
- 音频特征层重做为多时间尺度分析：RMS / dBFS、adaptive noise floor、fast level、8 个 FFT 频段、spectral centroid / rolloff / flatness、spectral flux、onset、弱 beat/tempo 估计、轻量 YIN pitch 可信度、stereo balance。
- 动画层重做为 6 道主波 + 底部水体 + 局部浪涌 + 表面高光：每次打开录音 dialog 都生成一组新的随机波浪个性；声强优先驱动浪高和局部浪涌，水位只慢速少量变化；高频/音高/节拍只在可信和有意义时增强表面细节。
- 安静或接近环境噪声时，adaptive floor、spectral flatness 和 presence gate 会压低响应，让水体保留轻微自然流动但不剧烈起伏。
- `AudioRecorder` 的实际输出改为新的 `RecordingWaveDriveFrame`，debug 日志也切换为 level / presence / swell / wake / pace / pitch / tempo / noise 等新指标。
- `fragment_record_audio.xml` 只替换 View 类名为 `RecordingWaveVisualizer`，保留根布局 `layout_width="280dp"`、`layout_height="360dp"`、`minWidth="280dp"`、`minHeight="360dp"`。

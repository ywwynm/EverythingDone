# 录音波形可视化 debug 更新

## 本次修复

- 修复连续发出两个“啦”时，部分已上升波峰会突然改变高度、出现生硬颤动的问题。
- 将每层局部浪涌从“延迟结束后直接写入当前值”改为“写入目标值，再由当前值平滑追随”。
- 为每个波分量的目标变化增加轻量单帧限幅，减少 100ms 音频特征刷新带来的局部轮廓突变。
- 保留上一版的随机错峰、每层个性化响应和灵动感，不回到统一平滑的波形。

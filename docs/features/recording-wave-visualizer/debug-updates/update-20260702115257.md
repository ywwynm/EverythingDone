## 录音波浪可视化加入频段与瞬态驱动

- 将录音动画的数据输入从单一分贝值升级为 `VoiceAudioFrame`，包含整体响度、5 个 FFT 频段能量和瞬态浪涌强度。
- `AudioRecorder` 现在基于最近 2048 个 PCM 样本做轻量 FFT：低频、低中频、中频、高频和空气感频段分别可驱动不同尺度的波浪，同时用响度上升和频谱正向变化生成瞬态。
- `VoiceVisualizer` 现在优先接收 `VoiceAudioFrame`：低频推动更宽的大浪，高频推动更快的细纹，瞬态会短时增强浪幅和波峰尖锐度；旧的 `receive(Int)` 分贝入口仍保留为兼容兜底。
- 视觉形态继续向真实水波靠近：在已有波谷压浅基础上增加波峰尖化，并让波分量漂移速度与空间频率建立近似频散关系，权重也改为低频主导、高频递减后叠加少量随机。
- 已通过 `:app:assembleDebug` 编译验证；本次发布供真机观察频段灵敏度、细纹强度和瞬态浪涌是否需要继续微调。

## 录音波浪阶梯式下折锯齿修正

本次继续优化详情页录音 dialog 的 `RecordingWaveVisualizer`。用户反馈仍能看到一种像阶梯一样的锯齿：本来平滑的曲线会突然往下折一下，并询问是否是采样点数不够。

调研后判断：采样点数不足确实会造成 aliasing 和阶梯感，但这类“局部突然下折”更像是几何合成函数本身有斜率突变。`Path` / `Canvas` 只负责绘制给定路径，不能自动修复上游波形函数里的折点。

主要修改：
- 生成浪合成从“每个浪包先拆成 crest / trough 两组再分别非线性限幅”改为“先做连续 signed sum，再只对总和做 crest / trough 软约束”。
- `crestSupport` 现在只用于估计 trough room，不再让单个浪包跨过零点时切换输出公式，减少局部斜率突变。
- 提高水体边界和主浪路径采样密度，降低普通采样 aliasing 对阶梯感的放大。
- 保留前一版的低水位慢流、强浪高度增强和基座水位向下软限幅。

验证：
- `:app:assembleDebug --console=plain --no-configuration-cache` 已通过。

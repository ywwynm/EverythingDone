## 录音波浪果冻感与重新开始失效修复

本次更新修复两个录音波浪反馈问题。

用户反馈：
- 当前波浪对一些很小的音量、频段或节奏参数变化仍然偏敏感，容易产生果冻感；
- 录完音后点击“重新开始”，特别是多次重复“开始 -> 结束 -> 重新开始”后，有时动画只剩水面流动，完全没有波峰波谷响应。

诊断结论：
- 果冻感主要来自 20ms 音频特征更新后，微小输入变化持续进入视觉目标链路；
- 重新开始失效的核心风险在旧录音监听线程没有被彻底收束。旧线程使用全局监听标记和可变 `AudioRecord`，快速重启后可能与新线程争用录音源，导致可视化 analyzer 收不到稳定 PCM。

代码修改：
- `VoiceVisualizer.kt` 增加 `stableInput()` 输入死区，对分量目标、水位、rhythm energy、low/high pulse 过滤小幅变化，保留强音节、明显节拍和频段差异；
- `AudioRecorder.kt` 新增 `restartListening()`，统一处理重新开始流程；
- `AudioRecorder.kt` 新增当前 `RecordingThread` 跟踪、线程私有 stop 标记、旧线程 stop/join、`AudioRecord` 初始化兜底；
- `RecordingThread` 捕获启动时的 raw 文件和 `AudioRecord`，避免旧线程在下一轮 start 后继续读取；
- raw 写入和 wav 转存都改为按真实读取长度写入；
- `AudioRecordDialogFragment.kt` 的重新开始按钮改为调用 `mRecorder.restartListening()`，并清空旧的 `mFileToSave`。

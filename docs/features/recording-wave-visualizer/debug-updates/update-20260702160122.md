## 录音波浪 D26：修复颤动、渐变方向和锁屏恢复

本次更新针对 D25 真机反馈继续优化录音 dialog 的波浪可视化：

- 修复部分波浪在第二个音节或节拍到来时，已经升起的峰值被突然改写、看起来上下颤动的问题。`VoiceVisualizer` 中 rhythm backfill 不再直接写当前视觉值，改为连续目标包络合并；surge/rhythm 的延迟触发也会在当前包络已经接近峰值时保持高度，而不是重新抬峰。
- beat phase 从“收到新节拍相位后立即吸附”改为按帧限速拉近，减少宽轮廓相位瞬移导致的生硬跳变。
- 录音水体使用记事渐变色时，现在会遵循 `ThingBackground.orientation` 的 8 向渐变方向，不再固定为横向渐变。
- 修复打开录音 dialog 后锁屏、再回到应用时动画可能完全停止的问题。`VoiceVisualizer` 现在会在 window 可见性、聚合可见性和窗口焦点恢复时显式重启动画帧循环，并重置上一帧时间。
- 可视化采样从约 25ms 调到 20ms，同时缩小 `AudioRecord.read()` 的读取块，避免采样间隔被系统音频读取 buffer 的阻塞粒度抵消。动画本身仍通过 `postInvalidateOnAnimation()` 跟随系统 vsync。

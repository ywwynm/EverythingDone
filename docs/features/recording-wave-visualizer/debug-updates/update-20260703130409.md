## 录音波浪同层多浪包叠加优化

本次更新继续优化详情页录音 dialog 的 `RecordingWaveVisualizer`。用户反馈有时会看到一个已经升起的波峰在瞬间突然下压，因此本轮重点调整同一层中新旧生成浪之间的相互作用。

诊断后确认，上一版每层只有一个 `GeneratedWave` 槽位；当声音变化触发新浪、且槽位被复用时，同层旧浪可能被直接替换，视觉上就会表现为前一个波峰突然消失或被下压。结合本轮关于水波叠加、干涉、Gerstner/水面生成浪生命周期的调研，新的实现不再让后浪覆盖前浪，而是让同层多个浪包同时存在并按各自生命周期传播。

主要修改：
- `RecordingWaveVisualizer.kt` 中的生成式波浪从“每层 1 个槽位”改为“每层 4 个浪包槽位”，新波优先进入空槽。
- 槽位复用增加可见度约束：只有旧浪已经接近不可见时才允许复用，避免正在升起或仍明显可见的波峰被瞬间替换。
- 同层多个浪包在几何合成阶段叠加，crest 分量可以形成更大的浪，trough 分量经过软上限和 crest 保护，避免新浪的 leading/trailing shoulder 在一两帧内把旧波峰压下去。
- 新浪出生位置会避开把肩部直接压到同层可见 crest 的区域，使后浪对前浪的影响更像连续传播、错峰和干涉，而不是瞬态改写。

验证：
- `:app:assembleDebug --console=plain --no-configuration-cache` 已通过。

# 录音波形可视化 调试发布日志

## 录音动画改为多层水体波浪（首个可测版本）

- 录音对话框的"底座 + 竖直柱子"改成一片由记事颜色填充的水体波浪：4 层半透明正弦波，横向流动、随音量平滑过渡、静音时保留极轻微荡漾。
- 音量同时驱动浪高与水位：声大则水面升高、浪增大；声小则回落变缓（水位有上限，不淹没上方计时文本）。
- 波浪配色取自当前记事颜色：纯色取同色系由浅到深的阶梯，渐变则每层复用整条渐变。
- 重录 / 主按钮 / 取消三个控件浮在水面之上；两个侧边图标加了一层柔和的半透明圆形衬底以保证在彩色水面上的可读性。
- 目前浪高、水位、流速、颜色深浅、层透明度等均为初始值。请在真机上看实际效果后告诉我要调大 / 调小哪些，我再逐项微调。

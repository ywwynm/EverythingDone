## 录音波浪波峰卡顿保质优化

本次继续优化详情页录音 dialog 的 `RecordingWaveVisualizer`。用户反馈声音较大、动画较丰富时，波峰处会出现一些小卡顿，并强调不要降低动画质量。

诊断后判断，问题更可能来自高能量场景下的帧时间峰值：上一版为了消除阶梯锯齿提高了路径采样密度，同时每个采样点会通过三点空间平滑重复计算生成浪；当声音较大、多个 `GeneratedWave` 同时激活时，单帧内 `exp/cos/sin` 计算量明显上升，容易在波峰丰富处表现为小卡顿。

主要修改：
- 不降低层数、浪高、强声响应、生成浪数量或动画丰富度。
- 移除生成浪三点空间平滑的重复 raw 计算；D64 的连续 signed sum 已经承担几何连续性，不再需要每个采样点三次计算同一组浪包。
- 路径从高密度二次中点连接改为三次连续路径重建；采样点数略降，但使用受限切线的 cubic 连接保持曲线平滑并降低每帧计算量。
- `waveWildness()` 改为每帧计算一次并缓存，避免每个采样点重复计算同一视觉状态。

验证：
- `:app:assembleDebug --console=plain --no-configuration-cache` 已通过。

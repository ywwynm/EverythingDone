# 录音波形可视化节奏响应优化

用户反馈：旁边播放比较激情、节奏较快的歌曲时，录音波形动画和歌曲节拍、演唱速度不够贴合，观感偏慢。用户进一步强调希望采用效果最好的方法，而不是只调快几个参数。

本次实现把节奏响应单独做成一条 rhythm-aware 通道，而不是直接加快主水波：

- `VoiceAudioFrame` 新增 `onset`、`beatPulse`、`beatPhase`、`tempoBpm`、`tempoConfidence`、`rhythmEnergy`、`lowPulse`、`highPulse` 等节奏特征。
- `AudioRecorder.VoiceAudioAnalyzer` 在原 RMS + 5 个 FFT 频段基础上新增轻量 rhythm engine：用 loudness rise、spectral flux、低频/高频 flux 计算 onset，维护自适应 onset floor，并用短历史 onset 自相关估计 tempo 和 beat phase。
- 录音可视化采样间隔从 100ms 降到 40ms，提高 onset/beat 的时间分辨率；主体水波仍走已有平滑链路，避免因为采样更快导致主水位和主波形抖动。
- `VoiceVisualizer` 新增 rhythm accent 层：每层独立 rhythm delay、amp、speed 和 phase；beat/onset 触发短促细纹、局部浪花感、轻微振幅/尖峰加成，以及 tempo confidence 足够时的漂移加速。
- 保留 D21-D23 的随机、灵动、每层有个性、二次音节不突跳和波峰圆润化决策；节奏层只负责更快、更跟拍的表面反应，不把整片水波变成同步上下运动。

验证：`:app:assembleDebug` 已通过；`:app:publishDebugUpdate` 已发布，debug code 为 `202607020717`。未使用 adb，未安装物理设备；真实节奏贴合度需要用实际歌曲在 debug 包上继续确认。

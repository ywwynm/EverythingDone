## 2026-07-03 - 顶部平浪、起伏幅度与竖条闪烁优化

本次 debug update 根据真机反馈继续优化新 `RecordingWaveVisualizer` 的渲染质量：

- 修复最上方几乎一直平着的浅浪：此前底部水体用 `drawRect()` 绘制，水体上边界是水平直线。现在改为 `bodySurfaceY()` 低频波形路径，让最上方水体边界也随整体水面起伏。
- 进一步加大波峰和波谷的高度差异：提高主波基础振幅、声音驱动振幅和 wake 振幅，并在最终波高上叠加随 `swell / level` 增强的圆润放大系数。
- 降低竖条滑动闪烁感：主波和水体填充从粗折线改为更密的二次曲线采样，减少半透明填充随相位移动时出现的竖向分段。
- 收敛表面高光：提高触发门槛、降低出现概率、降低 alpha 和移动速度，并把短亮条改得更长、更平，避免像从左往右滑动的竖条。

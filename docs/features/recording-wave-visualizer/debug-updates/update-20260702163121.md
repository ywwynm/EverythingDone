## 录音停止和重新开始按钮卡顿修复

本次更新修复 D27 后出现的 UI 卡顿。

用户反馈：
- 按下停止按钮会卡住约一秒；
- 按下重新开始按钮也会卡住约一秒。

诊断结论：
- D27 为了彻底修复“多次重新开始后动画只剩水流动”的问题，引入了更严格的录音线程收束；
- 但 `AudioRecord.stop()`、`RecordingThread.join(600ms)` 和 raw -> wav 转存仍在 UI 点击回调中同步执行，因此主线程会被阻塞。

代码修改：
- `AudioRecordDialogFragment.kt` 新增后台停止流程：停止按钮点击后立即切到 STOPPED UI，后台执行 `stopListening(true)`、wav 转存和 `startListening()`；
- 新增后台重新开始流程：重新开始按钮点击后立即切到 PREPARED UI，后台删除旧 wav 并执行 `restartListening()`；
- 新增 `mRecorderTransitionInProgress`，后台完成前临时禁用保存、重新开始、取消等相关按钮，避免文件未写完或监听未就绪时继续操作；
- dialog 关闭时的 `AudioRecorder.release()` 和 `audio_raw` 临时目录清理改为后台线程执行，避免关闭时再次卡 UI。

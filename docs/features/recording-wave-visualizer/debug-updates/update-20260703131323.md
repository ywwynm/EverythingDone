## 录音波浪潮位流速与强浪幅度优化

本次继续优化详情页录音 dialog 的 `RecordingWaveVisualizer`。上一版同层多浪包叠加的整体效果更好，但用户反馈仍有三个问题：低水位时波浪流速也应更低；有时会出现矩形锯齿感；声音较大或强节拍场景下仍缺少足够高大的浪。

主要修改：
- 新增潮位流速门控：低水位会降低基础波、肩部波、细节波、漂移波、生成浪出生速度和物理波场注入速度；高水位和强声时才恢复更明显的横向流动。
- 强浪幅度增强：强声、强节拍和高 `wake` 场景会提高 `GeneratedWave` 的 crest room、出生强度上限和前景层振幅，使必要时能出现更高、更大的主峰。
- 减少矩形锯齿：生成浪合成增加小尺度空间平滑，略加大浪包最小宽度，并把同层 crest / trough 的软上限从较快饱和改为更柔和的曲线，降低局部硬折角和平台感。
- 仍保留基座水位的向下软限幅，避免波谷再次撞到 dialog 底部。

验证：
- `:app:assembleDebug --console=plain --no-configuration-cache` 已通过。

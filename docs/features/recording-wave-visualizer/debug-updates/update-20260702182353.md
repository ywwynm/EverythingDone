# D35 录音波浪声强与节奏快慢区分优化

用户反馈：正常音量说话与大声说话、普通音量音乐与大声音乐在动画上差异不够；正常语速与快速说话、慢节奏音乐与快节奏音乐在横向流速和波形变化速度上也差异不够。

调研参考：
- ITU-R BS.1770 loudness 推荐使用加权能量、时间窗和 gating，而不是只看瞬时峰值。
- librosa 的 beat tracking 流程基于 onset strength、tempo correlation 和 beat peak picking，说明 onset envelope 可以作为节奏快通道。
- Essentia RhythmExtractor2013 输出 BPM、beat 位置和 confidence，但整段统计更适合离线音乐；实时录音需要在 BPM 置信度不足时用事件密度补足。
- aubio 同时提供 onset、tempo tracking 和 beat detection，支持把 onset 与 tempo 拆成不同层级的节奏信号。

本次调整：
- `VoiceAudioFrame` 新增 `intensity` 与 `pace` 字段，把“是否有有效声音”的 `activity` 与“多大声 / 多快”分开。
- `AudioRecorder` 新增自适应 loudness contrast，结合绝对 loudness、fast loudness 和相对环境底噪的动态范围，拉开正常音量与大音量。
- `AudioRecorder` 新增事件密度 `pace`，由 onsetScore、fastImpact 和 body flux 的 leaky density 得到；tempo/BPM 置信度足够时再作为音乐节拍慢通道补强。
- `VoiceVisualizer` 使用 `intensity` 放大主体浪高和频段驱动，让大声说话 / 大声音乐更明显变高。
- `VoiceVisualizer` 使用 `pace` 放大横向流速和波形变化速度，让快速说话 / 快节奏音乐明显快于正常语速 / 慢节奏音乐。
- 保留 D33 的空调风噪抑制和 D34 的连续峰高稳定，不恢复逐点 y 冻结。

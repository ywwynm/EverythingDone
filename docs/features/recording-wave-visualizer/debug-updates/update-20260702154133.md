# 录音波形可视化 D25：减少锯齿细纹并降低节奏延迟

用户反馈 D24 有两个问题：水面细纹太多，容易变成整片锯齿；音乐进入高潮时视觉响应仍然偏慢。用户要求采用效果最好的方案，而不是只把几个参数调小。

本次实现做了结构性调整：

- `AudioRecorder` 的可视化采样间隔从约 40ms 降到约 25ms。
- `VoiceAudioAnalyzer` 新增 512-sample fast RMS/rise，作为低延迟 onset/impact 快通道；`onset` 不再只依赖 2048 FFT 窗口和 tempo 置信度。
- `rhythmEnergy` 改为持续能量 + onset 的组合，让音乐高潮段即使没有清晰鼓点，也能更快推高整体波浪强度。
- `highPulse` 增加 onset gate 和视觉缩放，减少高频/air 对几何轮廓的常态驱动。
- `VoiceVisualizer` 移除 D24 的高频 rhythm surface displacement，不再把节奏画成密集小齿。
- rhythm accent 改为宽轮廓脉冲、振幅增强、轻微漂移加速和 event backfill；小延迟事件会直接进入目标并给当前 envelope 一个起始值，减少“现在才开始爬”的观感。
- 主体波形和高频细节分离：前 3 个分量负责主体轮廓，高频分量进入 `DETAIL_BUDGET_*` 限制；rhythm 越强，细节预算越收敛，避免高潮时水面锯齿化。

验证：`:app:assembleDebug` 已通过；`:app:publishDebugUpdate` 已发布，debug code 为 `202607020742`。未使用 adb，未安装物理设备；真实歌曲下的细纹量和高潮响应需要在 debug 包中继续确认。

## 录音波浪去白边与高潮能量修正

本次更新回应真机反馈，继续调优 `RecordingWaveVisualizer`。

主要变化：
- 去掉每层主浪顶部的白色 crest 描边，避免每一道浪都出现白边。
- 高能量场景新增 `wildness` 门控：安静或普通说话时仍然克制，声音丰富、高潮、强节奏或明显事件出现时，主波会进入更大的非线性放大，并产生相对更尖锐的波峰。
- 提高主波振幅和物理波场冲击力度，让波峰和波谷的高度差更明显。
- 降低 pitch / brightness 对主波高度和水位的主导性；水位、整体 `level` 和 `swell` 现在更多跟随 `absoluteLevel`、`relativeLevel`、`fastLevel` 和整体频带能量。
- 降低 `noiseLike` 对高能量人声/高潮段的压制，避免前奏因乐器频段更亮而水位较高、高潮反而下降。

保持不变：
- 录音 dialog 根布局仍为 `280dp * 360dp`。
- 入口仍统一使用 `RecordingWaveVisualizer`。
- 没有使用 adb，也没有自动安装到设备。

验证：
- `:app:assembleDebug --console=plain --no-configuration-cache` 已通过。

## 2026-07-03 - 修复录音 dialog 尺寸回归与波峰过尖

本次 debug update 修复上一版新 `RecordingWaveVisualizer` 带来的两个真机问题：

- 录音 dialog 被撑得过高，顶部计时器文本不再视觉居中。
- 波峰过尖锐，且局部跳动速度太快。

修复内容：
- `RecordingWaveVisualizer` 新增 `onMeasure()`，在 Dialog 的 `WRAP_CONTENT / AT_MOST` 测量链里声明固定固有尺寸 `280dp * 360dp`；在父容器给出精确尺寸时仍按父容器尺寸填满。这样自定义 View 不再把 `FrameLayout` 撑到屏幕可用高度。
- `fragment_record_audio.xml` 继续保持根布局 `layout_width="280dp"`、`layout_height="360dp"`、`minWidth="280dp"`、`minHeight="360dp"`，并把计时器 `layout_gravity` 调整为 `top|center_horizontal`。
- 波浪形态调参：提高局部浪涌触发门槛，放慢 `level / presence / swell / wake / pace / shimmer` 等视觉驱动的 attack，降低横向流速，削弱 crest 线条、高频交叉分量和 turbulence 权重。
- 局部浪涌改为更宽、更慢、更低强度的波包；降低二次浪涌概率，拉长生命周期，减少尖窄峰和快速跳变。

## D33 录音波浪空调风噪抑制

- 针对中央空调持续风噪 / hiss / swish，降低 high / air flux 对 `activity`、onset 和 fast impact 的影响。
- 新增 mid/body flux 作为主要活动证据，优先响应人声、敲击和音乐主体变化。
- 降低 high/air 对 transient 与 high pulse 的权重，避免稳态高频噪声持续触发波浪。
- 视觉侧低活动 body/detail 改为 smooth step 门控，安静时主体更平、细节几乎关闭。
- 进一步降低低活动横向底速、rhythm phase 和 idle 时间底速。
- 保留用户手动设置的水面采样数 `216`。
- 未使用 adb，未连接或安装到物理设备。

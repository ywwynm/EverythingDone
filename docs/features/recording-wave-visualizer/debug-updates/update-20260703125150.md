## 录音波浪野性增强

本次根据真机反馈继续调整 `RecordingWaveVisualizer`：生成式生命周期版本减少了当前波浪原地乱颤，但整体太平淡，波浪野性不足。

主要修正：
- 继续保留“已出生波浪不被后续音频帧改形”的生命周期模型，只增强新波浪的出生参数。
- 降低有效事件和持续音乐 drive 的生成门槛，缩短快节奏场景下的新波浪生成间隔。
- 提高 `GeneratedWave` 的波峰振幅、crest 权重、传播速度、尾浪权重、前肩部和内部 ripple，让新生成的浪更高、更快、更有冲击感。
- 强 beat / 高 pace / 高 strength 时允许一次事件生成主浪和副浪，占用不同槽位形成错峰叠加，提升音乐高潮下的密度和野性。
- 基础水体仍保持低幅、低频、慢速底座；上一版的目标死区、波谷软限幅和生命周期自然 rise/fall 继续保留。

验证：本地 `:app:assembleDebug --console=plain --no-configuration-cache` 已通过。未使用 adb，未连接或安装到物理设备/模拟器。

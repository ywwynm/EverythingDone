# 私密记事/文件夹体验优化（第一批）

本次更新围绕私密记事与私密文件夹的交互、显示与安全做了一轮系统性优化：

- 文案更清楚：长按选择、文件夹内菜单里的"设为私密"现在按所选内容自适应——纯记事显示"设为私密记事"、纯文件夹显示"设为私密文件夹"、混合显示"设为私密项"，不再含糊。未设密码时的提示也改为"请先设置密码"。
- 设私密反馈：把当前文件夹设为私密后，里面的内容不再立刻全变成锁卡片；文件夹名称前会出现一个锁标识，清楚表明"这个文件夹是私密的"。
- 取消更顺手：在详情页取消私密记事不再要求二次验证（能进到详情页本就已通过验证）。
- 修复数据损坏：给私密文件夹设置的卡片外观不再被清空——取消私密后外观可以完整恢复；外观面板经验证后展示文件夹的真实外观供调整。
- 安全堵漏：修复了"位于私密文件夹内、但自身未单独设为私密"的记事，在桌面单一记事小部件、系统通知里明文显示内容的问题；这类记事现在同样隐藏内容、点按需验证。
- 全屏提醒：私密记事在全屏通知上改为只显示标题 + 锁、隐藏内容，且完成 / 开始做 / 延迟等每个操作前都需验证。
- 导出保护：批量"导出到 SD 卡"若包含私密记事，会先要求验证再导出。

（"同一私密文件夹在抽屉、移动对话框、列表之间只需验证一次"的认证体验优化将在后续版本提供。）

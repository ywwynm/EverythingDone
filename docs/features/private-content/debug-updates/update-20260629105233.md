# 修复：已打开的私密文件夹内，右滑记事不再重复验证

之前在已验证打开的私密文件夹里，右滑记事（完成 / 开始做）仍会再次要求验证密码，与"记事已解锁显示"以及"本会话已认证则不再二次验证"的规则不一致。

根因：`needsThingSwipePrivacyAuthentication` 只看 `thing.isPrivate() || isCurrentFolderEffectivelyPrivate()`，没有像列表显示那样加上 `&& !isCurrentFolderPrivacyAuthenticated()` 的豁免。现在右滑鉴权口径与列表显示一致——当前私密文件夹已认证后，里面的记事右滑直接生效，不再重复验证。

# 修复：选图/拍照后私密文件夹的验证状态被误清

在已经验证过的私密文件夹里创建带图片的记事，会发现刚建的记事（明明不是私密的）显示成私密、点击还要验证、返回后整个文件夹的内容都变成上锁——这是个连带 bug。

原因：添加图片要跳到外部相机/图库，那一刻 app 退到后台，程序把它当成"用户离开了"，于是清掉了这个文件夹本次会话的验证状态。但这其实只是"临时去取张图片"。

修复：跳外部相机/图库/选媒体文件之前打上标记，这种"为取结果临时离开"不再清空验证状态，回到 app 即恢复正常（真正切后台离开仍会按原样清空、需要重新验证）。

现在在已验证的私密文件夹里加图片建记事，新记事会正常显示、点击免验证、文件夹路径图标也是开锁状态，返回后其它内容不再被误锁。

# 修复：私密文件夹调成大文件夹时看不到记事缩略图

编辑私密文件夹外观、切换到大文件夹时，预览只显示子文件夹缩略图、看不到记事的缩略图。这是上一批"揭示真实外观"修复遗漏的根因。

- 私密遮蔽是分层的：预览取数里子文件夹和记事走两条独立路径。上次给子文件夹接了"揭示"开关，记事这条路径漏了。
- 记事这条路径在数据层有一道独立的私密拦截：取私密文件夹的直接记事时会被整条丢弃，根本到不了渲染。现在外观编辑揭示该文件夹时放行，按"取消私密后的样子"显示记事。
- 正常浏览、桌面小部件预览不受影响，私密文件夹平时仍是上锁、无预览。

现在揭示私密文件夹时，记事和子文件夹都按取消私密后的样子出现，与大文件夹普通模式一致。

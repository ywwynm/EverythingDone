# 私密内容：本会话认证过后直接显示真实内容

把"访问即信任"从"免再输密码"推进到"直接显示内容"：本会话认证过的私密文件夹、私密记事，在首页列表、大文件夹缩略图等界面直接显示真实内容，不再只是一把锁。

- 认证过的私密文件夹：卡片从摘要恢复成真实外观，大文件夹缩略图显示里面的真实记事和子文件夹。
- 认证过的私密记事：首页卡片直接显示标题和内容，点开也不再要密码。
- 返回详情后列表即时刷新，卡片当场从锁变成内容。

边界保持不变：

- 记事 widget 配置界面是从桌面启动的独立会话，按它自己的认证显示内容，不会把主程序里认证过的私密内容带过去。
- 全屏提醒通知、桌面小部件本身仍维持上锁，需各自就地验证。

未认证的私密文件夹/记事一切照旧上锁。

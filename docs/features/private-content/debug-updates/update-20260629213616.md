# 私密内容评审 9 问题修复

本次修复一批私密记事 / 文件夹的交互与鉴权问题：

1. 拖拽记事到私密文件夹后取消验证，列表不再卡在变灰、不可点的状态，会正常恢复。
2. 已解锁的大文件夹被拖入时，播放的是大文件夹的加入动画（不再误用小文件夹动画）。
3. 拖拽 /“移动到文件夹”把记事移入私密文件夹并验证通过后，该文件夹立即解锁、卡片显示内容，再往里移东西不必重复验证。
4. 切到后台再回到 app，已解锁的私密文件夹会重新上锁——首页卡片、抽屉、“移动到文件夹”对话框三处同步恢复锁状态（对话框开着时切后台也会收起并上锁）。
5. 全屏通知里点完成 / 开始做 / 延迟，只验证一次，不再被要求验证第二次。
6. 取消某条私密记事后，同一次使用里再把它设为私密，会正确上锁（不再残留“已解锁”而直接显示内容）。
7. 从文件夹内取消私密时，若尚未验证身份会先要求验证（堵住未验证直接解除保护的隐患）；并清理了一处无用代码。
8. 完成 / 恢复 / 删除 / 彻底删除私密记事或文件夹时会要求验证——验证时机放在确认框点“确定”之后、真正执行前。

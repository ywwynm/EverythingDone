# Cloud Sync Followups

设计已定但刻意不在一期实现的延后项（2026-07-06 grilling 会话确认）。

## 二期功能

- **SSE 前台实时通道**：App 在前台时接服务端轻信号即拉，两台前台设备秒级互通。Hono 原生支持 SSE，成本不高，一期价值低（同时盯两台设备的场景少）。
- **`doing_records`（计时历史）同步**：统计页数据跨设备一致。追加型数据、量大、价值边际低；协议按新增实体类型 `DOING_RECORD` 平滑扩展即可（uuid 列可与迁移一起预埋或届时再加）。
- **手机号 / 微信登录**：identity 表已为此预留；等拿到短信签名 / 微信开放平台资质后追加，不动已有账号。
- **付费档位**：`users.plan_tier` 字段已预留；个人开发者收款渠道（支付资质、发票）问题解决前不做。
- **pgvector 语义搜索与 AI 功能**：PostgreSQL 预留 pgvector（ADR-0011）；若 AI 管线重到需要 Python 工具链，加挂独立 worker 服务，不动同步 API。
- **CDN 加速附件下载**：用户量/流量上来后在 OSS 前加 CDN，签名 URL 换 CDN 鉴权。
- **Web 端**：无 E2EE 决策（ADR-0012）已为其留路。

## 已知语义微瑕（观察后再定）

- **设私密 × 改正文的并发会出冲突副本**：私密标记是 `PRIVATE_THING_PREFIX` 标题前缀，属内容域。若内测中真实困扰，再考虑把"仅前缀变化"识别为结构域变更。
- **冲突副本无聚合入口**：副本只出现在原文件夹里（标题标记）。若副本频发难发现，考虑加"冲突收件箱"聚合视图。

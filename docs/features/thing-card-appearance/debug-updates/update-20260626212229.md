## 2026-06-26 - 首页外观面板滚动同步 Activity Header

本次 debug update 继续修正首页选择模式里的“调整记事/文件夹外观”面板。

用户在上一版提交后反馈：打开调整记事外观 panel 后，选中卡片的自动滚动基本已经正常，但 Activity Header 的位置有时没有同步更新。Activity Header 的折叠位置依赖首页 RecyclerView 的当前滑动位置，因此外观 panel 引发的程序化滚动也必须触发 Header 重算。

本次调整：

- 已撤销上一版 Git 提交，保留工作区改动后继续修复。
- 为外观面板选中卡片可见性校正增加专用滚动状态。`smoothScrollBy()` 和 holder 缺失时的 `smoothScrollToPosition()` 会被标记为外观面板引发的程序化滚动，RecyclerView `onScrolled()` 会在这类滚动过程中刷新 Activity Header。
- 程序化滚动进入 idle 后会清理状态，并在稳定布局帧再次刷新 Header，避免最终停靠位置和 Header 折叠位置不一致。
- 外观 panel 高度变化导致 RecyclerView bottom padding 改变时，也会在下一次 pre-draw 前刷新 Header，覆盖颜色页/外观页切换和颜色页内部纯色/渐变页切换后的布局时序。
- 仍保留上一版关于长卡片顶部对齐、短卡片最小滚动、复用卡片间距作为顶部留白，以及拖拽进文件夹命中阈值直接使用 `folder_drop_target_inset=16dp` 的修正。

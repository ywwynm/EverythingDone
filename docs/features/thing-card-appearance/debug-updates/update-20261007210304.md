## 2026-10-07：修复外观面板在粒子出现动画结束后闪烁一帧

用户反馈：首页长按有图片附件的普通记事，打开并取消“调整记事外观”，取消选中后滑动列表、换选另一条记事并重开面板，有概率在出现动画结束后整块面板消失一帧；飘散和流体两种样式都有。用户视频在 3.3377 秒清楚记录了这一帧，同时表明视频封面记事也需要覆盖。

- 确认面板本身的尺寸和内部控件没有跳变。旧交接路径先恢复 View 透明度，再等待窗口提交，并在 100 ms 后兜底撤掉粒子层；这不能保证真实面板已经在屏幕上显示。受控延迟窗口绘制后，确实出现粒子已清空、真实面板尚未显示的空档。
- `ThingsActivity` 的外观面板出现、消逝改用已有含阴影的同步交接路径。在支持的系统上，粒子末帧先同步交给静态面板快照，再把快照撤下与真实面板恢复绑定到同一次窗口帧，避免交接空白，同时保留面板阴影。
- 新增 debug 专用回归入口，通过系统界面树和真实系统输入操作；普通应用启动不会启用诊断或额外等待。测试用数据模型明确排除文件夹及其缩略图，未确认外观草稿或修改记事数据。
- 已在通过 Wi-Fi ADB 连接的一加 15T（Android 16）上验证。修复前，延迟窗口绘制的截图断言失败；修复后，飘散和流体均通过图片记事→视频封面记事的同条件截图检查。正常速度下两种样式各完成 4 轮滑动、换选和重开，恢复后的像素采样未再发现面板消失。

本次不依赖用户手动录屏完成回归。原视频没有同步开发日志，修复依据为其明确显示的交接空档，以及真机上已重现并取得前后截图的共同交接缺陷。未创建 Git 提交。

## 2026-06-26 - 首页外观面板离屏选中卡片立即校正

本次 debug update 继续修正首页选择模式里的“调整记事/文件夹外观”面板。

用户反馈：选中记事后打开调整记事外观 panel，切换到调整颜色 panel 的渐变页，再切回调整记事外观 panel；随后手动向下滑动首页列表直到看不到这个记事，再切换到调整颜色 panel，此时不会自动向上滑动。只有用户稍微手动滑动一下列表后，自动向上滑动才会触发。

本次诊断：

- 上一版为了合并多次高度变化，把选中卡片可见性检查挂到了延迟后的 `OnPreDrawListener`。
- 如果切换 panel 时 RecyclerView bottom padding 的目标值没有变化，可能不会触发新的布局/绘制帧。
- 因此检查会一直挂着，直到用户手动滚动 RecyclerView 触发下一次 pre-draw，才开始自动滚动。

本次调整：

- 选中卡片可见性检查不再只等待 pre-draw，而是延迟后主动 `postOnAnimation` 执行。
- 调度检查时会对 RecyclerView 请求下一帧绘制，确保即使 padding 没有变化，也能启动离屏选中卡片的自动滚动。
- 如果下一帧时 RecyclerView 仍在计算布局，则短延迟后重新排一次检查，避免在布局计算中直接触发滚动。

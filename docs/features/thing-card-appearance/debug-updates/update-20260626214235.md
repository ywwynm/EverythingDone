## 2026-06-26 - 首页外观面板 padding 动画与滚动合并

本次 debug update 继续修正首页选择模式里的“调整记事/文件夹外观”面板。

用户反馈上一版仍有三个问题：切换到调整颜色 panel、在颜色 panel 内切换纯色/渐变、再切回外观 panel 时，panel 高度变化会触发 RecyclerView bottom padding 重设，这种由 padding 改变造成的位置变化可能没有动画；有时自动滚动会短时间分成两段；颜色 panel 下方预留 padding 看起来不像 `panelHeight + 16dp`，似乎偏小。

本次调整：

- RecyclerView bottom padding 不再瞬时跳到新值，而是用 160ms 动画过渡，降低 panel 高度变化造成的列表跳动感。
- 选中卡片可见性校正改为 debounce 到布局稳定后执行：panel 高度、颜色页内容高度、纯色/渐变页切换引发的多次空间更新会合并，减少连续两段 `smoothScrollBy()`。
- holder 暂时不存在时，不再直接使用普通 `smoothScrollToPosition()` 再补一次 `smoothScrollBy()`；改用带顶部卡片间距的 `LinearSmoothScroller`，尽量一次滚到接近最终位置。
- panel 打开时 RecyclerView bottom padding 的额外间距从单个 `thing_card_outer_spacing` 改为首页卡片间距，也就是当前 16dp。最终目标为原始 bottom padding + panel 实际高度 + 16dp。
- Activity Header 同步刷新仍保留：外观面板引发的 padding 动画、程序化滚动过程和滚动结束后的稳定布局帧都会刷新 Header。

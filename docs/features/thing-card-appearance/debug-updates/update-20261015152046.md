## 封面附件数量遮罩的不透明度降为约 16%（2026-10-15）

根据用户反馈，将上一版封面左下角／右下角附件数量提示的黑白遮罩从约 26% 不透明度统一降低为约 16%。新增 `black_16p`，将本功能专用的白色资源改为 `white_16p`，Alpha 均为 `0x29`（41/255，约 16.08%）。`BaseThingsAdapter.applyThingCardImageCountColors` 与 `card_thing.xml` 的初始背景同步使用新资源，仍按记事前景明暗切换黑白遮罩。其他使用 `black_26p` 的界面不变。

`:app:assembleDebug` 与本次改动的 `git diff --check` 均通过。用户随后明确要求不必装机验证、直接发布，因此本次没有追加设备界面验证。

# 首页外观面板取消/滚动修复 + 拖拽进文件夹阈值

本次 debug update 修复首页记事列表选择模式下的外观面板与拖拽交互问题：

- 文案：选择单个记事或文件夹后的菜单项改为“调整记事外观”/“调整文件夹外观”，记事外观面板标题同步改为“调整记事外观”。
- 取消行为：外观面板打开时，系统返回键、contextual toolbar 的关闭按钮、面板里的“取消”现在只取消外观草稿并关闭面板，不再直接退出选择模式。
- 滚动行为：外观面板打开、颜色页和外观页切换、面板高度变化时，列表会按当前选中卡片的实际可见区域计算滚动。长卡片优先让顶部贴近列表可见区域顶部；短卡片如果已经完整可见则不再额外滚动。
- 拖拽进文件夹：拖拽移动模式下，创建文件夹/移动到文件夹的 hover 目标改为需要左上角进入目标卡片内缩 16dp 的区域后才触发，避免刚碰到边缘就播放动画。

验证重点：

1. 选择一个很长的记事或文件夹打开外观面板，确认自动滚动稳定对齐顶部。
2. 外观面板打开后切到颜色页再返回，确认卡片不会被 contextual toolbar 遮住，也不会在已完整可见时多滑一下。
3. 点击返回键、contextual toolbar 关闭按钮、面板“取消”，确认只关闭面板且仍停留在选择模式。
4. 拖拽卡片到另一个记事/文件夹边缘，确认刚碰到边缘不会触发建夹/移入文件夹动画，进入更深后才触发。

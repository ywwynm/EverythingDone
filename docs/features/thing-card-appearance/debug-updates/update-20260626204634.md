## 2026-06-26 - 首页外观面板滚动留白与颜色页切换校正

本次 debug update 继续修正首页选择模式里的“调整记事/文件夹外观”面板。

用户在上一版反馈：自动滚动时卡片不要紧贴 contextual actionbar，需要留白；随后进一步指出不应凭空使用 8dp，而应沿用首页记事/文件夹卡片之间的现有间距。同时，打开外观面板后如果切换到更高的颜色面板，或在颜色面板内部切换“纯色/渐变”页，面板高度变化可能挡住原本完整可见的卡片，但列表没有再次滚动；另外实际测试中滚动看起来像瞬移，希望尽量使用 smooth scroll。

本次调整：

- 首页外观面板自动滚动时，卡片顶部与 contextual actionbar 之间的留白改为复用首页相邻卡片之间的实际可视间距。该值由卡片 item margin 推导，当前等价于上下两个 `thing_card_outer_spacing` 相加，不再单独写死 8dp。
- “调整记事/文件夹外观”面板的空间更新统一由 `requestThingCardAppearancePanelSpaceUpdate()` 调度。外观页、颜色页、颜色页内部纯色/渐变切换、panel 自身高度变化，以及颜色页滚动容器/编辑器高度变化，都会重新计算 RecyclerView bottom padding 和选中卡片可见性。
- 空间更新增加当前帧、下一帧、短延迟和最终延迟多次校正，用于覆盖 `animateLayoutChanges` 和颜色页内容测量完成较晚的情况。
- 选中卡片已挂载时，精确校正使用 `smoothScrollBy()`；卡片 holder 暂时不存在时，先用 `smoothScrollToPosition()` 平滑靠近，稍后再按真实 holder 几何用 `smoothScrollBy()` 校正。移除了这一流程里不必要的 `stopScroll()`；如果上一段 smooth scroll 尚未结束，则延后复查，避免多次校正叠加造成突兀或过冲。
- 拖拽创建文件夹/移动到文件夹的左上角命中阈值也改为复用首页相邻卡片之间的实际可视间距，当前等价于 16dp；目标卡片过小时仍按尺寸自动收缩阈值。

- `git diff --check` 通过，仅有仓库既有 LF/CRLF 提示。
- `:app:assembleDebug --console=plain --no-configuration-cache` 已通过。

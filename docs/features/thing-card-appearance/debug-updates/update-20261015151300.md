## 修复浅色记事封面附件数量的遮罩（2026-10-15）

用户反馈：首页带图片／视频封面的记事使用浅色背景时，附件数量文字随记事变为深色，底下的遮罩却仍是黑色，导致难以辨认。

已在 OPPO 现有首页卡片复现并核对相关历史修复。问题位于 `BaseThingsAdapter` 的 `tv_thing_image_attachment_count`：正常绑定和前景刷新都会更新文字，但布局中的 `black_26p` 背景未同步更新。现在统一通过 `applyThingCardImageCountColors` 设置文字与遮罩，深色文字配新增的 `white_26p`，浅色文字保留 `black_26p`，透明度均保持 26%，数量文案、位置和封面播放不变。

`:app:assembleDebug` 已通过，并已在 `3B1629006YC00000` 与 `R5CW20BLNKL` 上覆盖安装验证：浅色渐变卡片的遮罩变白，滚动离屏后返回仍正确；深色卡片的图片／视频数量保持原配色；颜色草稿切为白色、封面调整到宽卡片右侧后，数量文字与遮罩同步变化。测试草稿最后已取消，恢复原有颜色和外观。

## 2026-06-26 - 首页外观面板离屏滚动落点统一

本次 debug update 继续修正首页选择模式里的“调整记事/文件夹外观”面板。

用户反馈：选中记事后打开调整记事外观 panel，切换到调整颜色 panel，向下滑动列表直到记事不可见，再切回调整记事外观 panel；此时会自动向上滑动到记事可见，但记事顶部与 contextual actionbar 的间距不是 16dp，而是稍大一点。随后再切到调整颜色 panel，又会补一小段向上滑动。

本次诊断：

- 当 holder 不在屏幕上时，上一版用 `LinearSmoothScroller` 先粗定位。
- `LinearSmoothScroller` 默认按 decorated top 计算，包含 item margin / decoration。
- 外观面板的精确校正按 `holder.itemView.top` 计算。两个坐标基准不一致，会让粗定位后的卡片顶部多出一点间距。
- 后续切换 panel 再触发精确检查时，才会补上这一小段滚动。

本次调整：

- 外观面板专用 `LinearSmoothScroller` 覆盖 `calculateDyToMakeVisible()`，直接按 `itemView.top == recyclerView.paddingTop + 首页卡片间距` 计算滚动量。
- holder 缺失时的粗定位与 holder 已挂载时的精确 `smoothScrollBy()` 使用同一个 16dp 基准。
- 程序化滚动结束后的精确复查改为下一帧立即执行，避免剩余误差等到下一次 panel 切换才被修正。

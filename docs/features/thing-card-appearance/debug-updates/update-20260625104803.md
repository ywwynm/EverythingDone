# 修复裁切封面视频弹窗里视频溢出预览区

## 本次改动

- 修复「调整记事卡片外观 → 裁切封面视频」弹窗里，视频会溢出预览框、漏到弹窗上方或下方的问题（此前会出现画面布满弹窗上方，或上下各多出半截视频）。
- 视频预览改用强制硬件裁剪，无论怎么平移、缩放，视频都只显示在预览框内。
- 与上次的 HDR、动图播放无关，根因是视频裁切预览用 TextureView（硬件合成层）被撑到完整视频尺寸、必然上下溢出预览框，而弹窗为保留按钮 ripple 关闭了子裁剪，单靠遮挡层与父容器盖不住溢出；图片裁切、按钮 ripple 效果、HDR 全屏预览均不受影响。

## 测试重点

- 打开视频封面记事 → 调整卡片外观 → 裁切封面视频，确认视频只出现在预览框内，弹窗上方 / 下方不再有多余画面。
- 竖屏长视频、横屏视频分别测；打开即看，以及拖动 / 双指缩放到边缘后再看。
- 切换不同裁切比例，确认预览框内裁切正常、四周干净。
- 确认「确定 / 取消」按钮点击的 ripple 仍完整显示。

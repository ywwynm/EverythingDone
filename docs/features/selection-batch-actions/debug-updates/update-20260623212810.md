# 结构性永久删除弹窗正文统一 + 含→包含

修复结构性「永久删除」确认弹窗（单选文件夹 / 多选文件夹 / 多选文件夹+记事）正文不一致的问题：

- 多选文件夹、混合两种情况此前硬编码了固定提醒文本，未真正反映当前状态/类型筛选。现改为与单选文件夹相同，
  用 `appendFilterScopeReminder` 动态生成："包含当前状态筛选（回收站）下看不到的内容"；只有在有类型筛选时
  才追加类型部分（无类型筛选则不显示）。
- 三者正文结构现在一致："将永久删除…，共X个子文件夹、Y件记事，无法恢复。" + 动态提醒。
- 文案统一用「包含」而非「含」（`scope_includes_subfolders` 等）。

验证：`:app:assembleDebug` 已通过。已通过 `:app:publishDebugUpdate` 发布到阿里云，debug update code 为 `202606231328`。

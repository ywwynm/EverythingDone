# 批量动作文案与行为的 9 项修复

1. 多文件夹动作标题不再用单数。多选文件夹时标题/弹窗标题改为「完成/删除/恢复/永久删除所选文件夹中的所有记事」，与正文一致；单选文件夹仍为「…文件夹中所有记事」。
2. 功能修复：正在进行状态下「删除文件夹中所有记事」只删除文件夹中正在进行的记事（不再连带已完成）。已完成状态删已完成、回收站删回收站，各状态各管各的。
3. 多文件夹/混合的确认弹窗在递归到子文件夹时，也会提示「（包含所有子文件夹中的记事）」（此前只有单文件夹提示）。
4. 「回收站中/里/在回收站」统一为「回收站中」。
5. 纯记事确认弹窗句式与其它桶对齐：「将完成所选记事，共 N 件。」。
6. 「选中的」统一为「所选」（标题、结构删除等）。
7. 「解散文件夹」确认正文改为以「将解散该文件夹：…」开头，不再用「彻底删除」字样。
8. 移动到文件夹 Dialog 根节点由「正在进行」改为范围名「全部记事」（与抽屉根目录、词汇表一致）。
9. 批量取消私密的验证弹窗标题随选择自适应（取消私密记事 / 取消私密文件夹 / 取消私密项），与动作标题一致。

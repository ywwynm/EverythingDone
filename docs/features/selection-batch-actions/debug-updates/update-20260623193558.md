# 批量动作文案按选择组合自适应

修复选择模式下批量动作的文案：动作名称随当前选择的组成自适应，分三种情况——

- 全是记事：用记事文案，如「设为私密记事」「完成选中的记事」。
- 全是文件夹（无论一个还是多个）：用文件夹文案，如「设为私密文件夹」「完成文件夹中所有记事」。
- 记事与文件夹混选：用中性文案，如「设为私密项」「完成所选项」。

涉及的动作：完成、删除、恢复、永久删除、设为私密。菜单标签与对应确认弹窗标题统一遵循该规则。
置顶、移动到文件夹、导出、全选等本就类型中立，不受影响；卡片外观为单选，已按记事 / 文件夹区分。

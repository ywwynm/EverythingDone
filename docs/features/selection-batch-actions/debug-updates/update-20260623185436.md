# 多选批量动作支持文件夹与混合选择

这一版让首页选择模式的批量动作全面支持「多文件夹」和「记事 + 文件夹混合」选择（含上一版「撤销改确认弹窗」）：

- 完成 / 删除 / 恢复 / 永久删除：一个动作即可作用于所选记事与所选文件夹——记事走状态变更，文件夹递归处理夹中内容（容器不动，跟随当前类型筛选）。混合或多文件夹时弹一个汇总确认弹窗（显示「共 N 件记事，含所选文件夹中的所有记事」）。
- 移动到文件夹：可一次移动「记事 + 文件夹」到目标文件夹；所选文件夹及其后代会被禁止作为目标，避免移进自身或循环。
- 置顶：可一起置顶 / 取消置顶；只要还有未置顶的项就全部置顶，全部已置顶才取消。
- 设为私密：可一起设为 / 取消私密（含文件夹）；空标题或正在计时的记事会被跳过并提示；取消方向整批只验证一次密码。
- 工具栏每个动作合并为一个入口，文案随选择自适应（纯记事 / 单文件夹 / 混合）。卡片外观、解散文件夹、永久删除文件夹容器仍是单选专属。

可验证场景：长按一个文件夹进入选择模式，再点选若干记事 / 文件夹，观察工具栏动作是否齐全、确认弹窗数量是否正确、置顶 / 私密 / 移动是否对整批生效。

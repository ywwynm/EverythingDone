# 普通模式工具栏文案随范围自适应

把"按选择组合自适应文案"的规则补齐到普通模式工具栏（actionbar）及其确认弹窗：

- 根目录工具栏：维持「全部完成 / 全部恢复 / 全部删除 / 全部永久删除」（作用于全部范围，类型中立）。
- 进入文件夹后工具栏：改为「完成 / 恢复 / 删除 / 永久删除文件夹中所有记事」，对应确认弹窗标题一并随之改为文件夹文案。
- 文件夹内 overflow 的结构操作（解散文件夹 / 设为私密文件夹 / 移动文件夹 / 删除当前文件夹）本就是文件夹文案，未改。

至此，根目录工具栏、文件夹内工具栏、长按文件夹/记事进入的选择模式（根目录与文件夹内）四个入口的动作名称与确认弹窗标题文案统一：全记事用记事文案、全文件夹用文件夹文案、混合用「所选项」、整个范围用「全部」。

验证：`:app:assembleDebug` 已通过。已通过 `:app:publishDebugUpdate` 发布到阿里云，debug update code 为 `202606231201`。

# 确认弹窗正文全面统一

把所有「完成/删除/恢复/永久删除」确认弹窗的正文收敛到同一套模板，消除此前的各种不统一：

统一后的正文格式：`将[动词][范围]的所有[状态]的记事，共 N 件[（包含所有子文件夹中的记事）][，去向]。`

- 范围用词统一：根目录无范围词；文件夹/单选/多选文件夹统一为「所选文件夹」（不再用「该文件夹/整个文件夹」）；混合为「所选项」；纯记事为「所选」。
- 一律带「的」、一律「的所有…的记事」、一律带状态词。
- 状态词统一为「正在进行 / 已完成 / 已删除」；「回收站」不再作为状态用词（提示里的「回收站中的」改为「已删除的」），只在「移入回收站 / 可在回收站恢复」等表示去向时保留。
- 多选/混合的递归现在也会显示「（包含所有子文件夹中的记事）」。
- 解散文件夹正文以「将解散所选文件夹：…」开头。
- 类型/状态筛选提示（appendFilterScopeReminder）里的已删除状态词也由「回收站」改为「已删除」。

实现上把单文件夹、文件夹内工具栏、根目录、多选、混合、纯记事六种入口的正文收敛到同一套带「范围占位符」的字符串，从源头杜绝再次漂移。

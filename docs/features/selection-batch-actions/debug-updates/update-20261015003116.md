## 工具栏全部操作补齐粒子动画（2026-10-15）

用户反馈，普通 ActionBar 右上角的全部完成、全部恢复、全部删除和全部彻底删除没有粒子动画，而多选时已有完整动画。隔离包复现确认：范围操作成功变更数据后直接刷新列表，绕过了多选共用的退场入口。

`ThingsActivity` 将全部完成、已完成恢复、全部删除、回收站恢复及全部彻底删除统一接入 `applyUnionStateChange`。复用现有确认框关闭等待、可见记事／文件夹粒子退场、列表差分及输入恢复；不新增粒子实现，也不模拟全选。保留当前文件夹范围、类型／搜索筛选、正在做记事保护、习惯／目标二次确认和回收站恢复到删除前状态。

已在 OPPO `3B1629006YC00000`、三星 `R5CW20BLNKL`、魅族 `192.168.100.67:40807` 的独立测试包完成共 33 个场景，覆盖五种范围动作、根目录／文件夹、不同滚动位置、飘散／流体、普通淡出和既有多选。修正旧测试脚本的大写样式参数后，额外核对九例实际流体动画。代表性录屏已复核，1496 项 JVM 测试中 0 失败、1 跳过。

所有破坏性测试只使用虚构记事。三台原应用的数据库及日志文件 SHA-256 与测试前一致；独立测试包均已卸载。未创建 Git 提交。

# 选择操作确认弹窗按单选/多选配色

## 选择操作确认弹窗：单选用所选项颜色、多选用当前文件夹色

- 之前移动到文件夹、完成 / 恢复、永久删除等确认弹窗没有正确区分单选和多选：移动弹窗按第一个所选项配色，完成 / 恢复弹窗一律按当前文件夹配色，永久删除按 accent。
- 现在统一规则：单选 1 个记事 / 文件夹时，弹窗标题与确认按钮用该项自身的颜色；多选时用当前所在文件夹的颜色（在根目录就是 accent+accent2 渐变）。

测试重点：
- 单选 1 条记事 → 移动 / 完成 / 恢复 / 删除：弹窗标题与确认按钮是该记事的颜色。
- 单选 1 个文件夹 → 移动 / 永久删除：用该文件夹的颜色。
- 多选（多个记事、多个文件夹、或混合）→ 各操作弹窗用当前所在文件夹颜色；根目录下为 accent 渐变。
- 进入某个有颜色的文件夹后多选再操作：弹窗用该文件夹颜色。

# 统一 Home action 文案与文件夹内容删除语义

本次更新集中修正 Home 列表里批量/范围 action 的文案不统一问题，覆盖普通 actionbar、长按后的 contextual menu、确认 dialog 标题和正文。

- 新增 `HomeActionWordingHelper`，统一生成 action 标题、dialog 标题、dialog 正文和确认按钮文本，避免不同入口各自拼接造成“所选文件夹中的/所选文件夹的/所选项中的”等漂移。
- 状态类内容动作标题补齐当前状态限定，例如“完成所选文件夹中所有正在进行的记事”“删除当前文件夹中所有已完成的记事”；dialog 正文继承同一个 action title。
- dialog 正文里的数量、子文件夹命中提醒、类型筛选提醒、可恢复/不可恢复提醒集中生成；中文数字和单位之间不加空格。
- 中文确认按钮保持现有通用文案“确定”。
- 置顶/设为私密保持短文案：“置顶/取消置顶”“设为私密/取消设为私密”，不再生成“设为私密所选项”这类不自然文本。
- 解散文件夹、永久删除文件夹走结构动作专属模板，和“删除文件夹中记事”的内容动作区分。
- 文件夹内容删除按当前状态执行：正在进行里只删除正在进行的记事，已完成里只删除已完成的记事，回收站里只永久删除已删除的记事，不再跨状态处理。
- 国际化同步补充：默认英文、简中、繁中，以及 de/es/fr/hi/it/ja/ko/pt/ru 增加新的完整模板；状态内容目标短语和结构目标短语分开，避免其他语言的语序、介词或格变化问题。

# 回收站新增结构性"永久删除所选项"；外观/私密/置顶限正在进行

两项调整：

## 1. 回收站新增结构性永久删除（真正删除文件夹）

回收站里选中包含文件夹时，现在有两个区分清楚的删除入口：

- 「永久删除所选项中的记事」（内容操作，右上角图标）：只永久删除回收站里的记事，文件夹容器保留，跟随当前类型筛选。
- 「永久删除所选项」（结构操作，overflow 菜单，新增）：真正删除选中的文件夹本身——连带其整棵子树（所有状态/类型筛选下的子内容），以及选中的记事，不可恢复。

文案随选择自适应：仅单个文件夹时为「永久删除文件夹」；仅多个文件夹时为「永久删除选中的文件夹」；记事+文件夹混合时为「永久删除所选项」。确认弹窗强提示"作用于整个文件夹子树、含当前筛选下看不到的内容、不可恢复"。

## 2. 已完成 / 回收站不再允许外观、私密、置顶

卡片外观、设为私密、置顶仅在"正在进行"状态可用。此前单条记事在回收站里仍能调整卡片外观，现已修正（私密、置顶本就仅正在进行可用）。

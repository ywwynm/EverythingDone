# 混合选择文案消歧：所选项 → 所选项中的记事

修复混合选择（同时选了记事和文件夹）时状态动作的文案歧义。原来显示「永久删除所选项」等，对文件夹其实只
永久删除其中的记事、容器保留，但「所选项」让人误以为会删除文件夹本身（回收站里还另有「永久删除文件夹」
结构操作，更易混淆）。

改动：混合桶的完成 / 删除 / 恢复 / 永久删除，对象由「所选项」改为「所选项中的记事」，明确只作用于记事、
不动文件夹容器。弹窗标题与正文一并更新。

为什么只改这一桶：纯记事文案本就说「选中的记事」、单/多文件夹本就说「文件夹中所有记事」，都清楚；
移动到文件夹 / 置顶 / 设为私密在混合时确实作用于文件夹容器本身（移动容器、置顶容器、容器变私密），
用「项」是准确的，保持不变。

改完四种对象互相平行、都以「记事」收尾：所有记事 / 文件夹中所有记事 / 选中的记事 / 所选项中的记事。

验证：`:app:assembleDebug` 已通过。已通过 `:app:publishDebugUpdate` 发布到阿里云，debug update code 为 `202606231307`。

# 批量/范围动作文案全面统一

按统一规律重排了所有批量/范围动作的文案（标题、弹窗标题、弹窗正文）：

- 动词全程统一：完成 / 删除 / 恢复 / 永久删除（修正选择模式此前的「还原」「彻底删除」）。
- 根目录改为动词在前 + 「所有」：完成所有记事 / 恢复所有记事 / 删除所有记事 / 永久删除所有记事（原「全部完成」等）。
- 同一操作不同入口弹同一个弹窗：长按单个文件夹与进入该文件夹后操作，现在标题与正文完全一致（都走文件夹范围弹窗）。
- 弹窗标题与正文用词一致：不再出现标题「…文件夹中所有记事」而正文「…所选内容」的错位。
- 弹窗正文统一为陈述句（「将…，共N件…。」），并去掉数字与中文之间的空格（共N件，而非共 N 件）。
- 对象用词收敛为 5 种：所有记事 / 文件夹中所有记事（单文件夹或进入后）/ 选中的记事 / 所选文件夹中所有记事（多选文件夹）/ 所选项（混合）。

详见 docs/features/selection-batch-actions/wording-matrix.md。

可验证：对比「长按某文件夹→完成文件夹中所有记事」与「进入该文件夹→完成文件夹中所有记事」，弹窗应一字不差；根目录工具栏应显示「完成所有记事」等；各弹窗正文为陈述句、无数字空格。

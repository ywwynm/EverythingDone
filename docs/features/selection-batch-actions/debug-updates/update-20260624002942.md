# 首页批量操作文案与回收站恢复修正

本次根据 `HomeActionWordingHelper` 生成 action 文案的审查结果，修正除“选择单文件夹与进入文件夹后的 actionbar 文案不完全一致”之外的其它问题。

- 修正纯记事选择在回收站点击“恢复”时的执行路径：现在与文件夹/混合选择一致，会逐条按删除前状态恢复，不再把混合来源的记事统一恢复为正在进行。
- 回收站恢复确认弹窗新增专门正文，明确提示会恢复到删除前状态，避免“恢复所选记事，共 N 件”信息不足。
- 解散或永久删除空文件夹时改用空内容专门正文，不再出现“共无内容”这类不自然表达。
- 同步更新默认英文、简体中文、繁体中文以及现有外语资源中的新文案模板。

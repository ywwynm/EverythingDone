# 批量/范围动作文案矩阵与规律（2026-06-23，已统一并落地）

目的：把"状态 × 类型筛选 × 目录 × UI 位置"下的动作标题、弹窗标题、弹窗正文、行为结果
讲清楚，并提炼成少数几条规律统一应用。

> 状态：第六节的统一方案已全部实现（debug code 202606231256）。下文第二节标题表、第四/五节
> 已更新为落地后的现状；第五节列出的历史不一致均已修复。

## 一、三条独立主线（关键：维度其实是独立的，按规律组合，不是 72 种特例）

1. **动词**——看当前**状态**：
   - 正在进行：完成、删除
   - 已完成：恢复、删除
   - 回收站：恢复、永久删除
   - 状态无关：移动到文件夹、置顶、设为私密（均仅正在进行）、卡片外观（仅单选）
   - 文件夹结构操作：解散文件夹（正在进行）、永久删除文件夹（回收站）

2. **作用对象**——看 **UI 位置 + 选择组成**（决定标题里的"对象"词）：
   | 作用对象 | 出现位置 |
   |---|---|
   | 整个根目录 | 根目录 actionbar |
   | 当前文件夹（已进入） | 文件夹内 actionbar |
   | 选中的记事（无文件夹） | 选择模式·全记事 |
   | 选中的文件夹（无记事，任意数量） | 选择模式·全文件夹 |
   | 选中的记事+文件夹 | 选择模式·混合 |

3. **类型筛选**（全部/单选/多选类型）——**只改"做什么"和"提醒"，不进标题**：
   - 内容操作（作用于某范围/文件夹的内容）**跟随当前类型筛选**：只处理命中类型的记事。
   - 选中的记事本身不再过滤（你选的就是当前可见、已被类型筛选过的）。
   - 有具体类型筛选时，内容操作的弹窗追加提醒"本次仅作用于当前类型筛选（X）的记事…"。

## 二、动作标题 = 动词 × 对象（当前现状）

| 对象 \ 动词 | 完成 | 删除 | 恢复 | 永久删除 |
|---|---|---|---|---|
| 根目录 actionbar | 完成所有记事 | 删除所有记事 | 恢复所有记事 | 永久删除所有记事 |
| 文件夹内 actionbar | 完成文件夹中所有记事 | 删除文件夹中所有记事 | 恢复文件夹中所有记事 | 永久删除文件夹中所有记事 |
| 选择·单文件夹 | 与「文件夹内 actionbar」完全一致（复用同一弹窗，标题+正文一字不差） | ← | ← | ← |
| 选择·全记事 | 完成选中的记事 | 删除选中的记事 | 恢复选中的记事 | 永久删除选中的记事 |
| 选择·多文件夹 | 完成文件夹中所有记事 | 删除文件夹中所有记事 | 恢复文件夹中所有记事 | 永久删除文件夹中所有记事 |
| 选择·混合 | 完成所选项中的记事 | 删除所选项中的记事 | 恢复所选项中的记事 | 永久删除所选项中的记事 |

注：混合桶用「所选项**中的记事**」而非「所选项」，消除"是否会删除文件夹容器"的歧义——这几个状态动作对
文件夹只动其中记事、容器保留。移动 / 置顶 / 设为私密在混合时确实作用于文件夹容器本身，仍用「项」（移动到
文件夹 / 置顶 / 设为私密项）。

弹窗标题 = 与动作标题一致。弹窗正文：根目录 / 文件夹内 / 选择·单文件夹复用既有 scope 文案
（"将…该文件夹/所有正在进行的记事，共N件…。"）；选择·多文件夹用"所选文件夹"文案；混合用"所选项"文案；
纯记事用"选中的记事"文案。全部为陈述句、数字与中文之间无空格。

## 三、行为与结果（动词 × 状态）

| 动词 | 状态 | 行为 | 跟随类型筛选 | 结果 |
|---|---|---|---|---|
| 完成 | 正在进行 | 正在进行→已完成 | 是（内容操作） | 习惯/目标命中时弹三选项（去掉/继续/取消）；完成后从正在进行视图消失 |
| 删除 | 正在进行 | 未删除(进行中+已完成)→回收站，保留原状态 | 是 | 文件夹删除会连带"看不到的已完成"记事；容器不动；可在回收站恢复 |
| 删除 | 已完成 | 已完成→回收站 | 是 | 可在回收站恢复 |
| 恢复 | 已完成 | 已完成→正在进行 | 是 | 回到正在进行视图 |
| 恢复 | 回收站 | 回收站→删除前状态（进行中或已完成） | 是 | 各记事回到删除前状态，不统一变进行中 |
| 永久删除 | 回收站 | 回收站→销毁 | 是 | 不可恢复 |
| 移动到文件夹 | 正在进行 | 改归属（记事改 folderId，文件夹移子树） | 否 | 禁止目标=所选文件夹及其后代；跨私密边界整批一次鉴权 |
| 置顶 | 正在进行 | 切换 location 正负 | 否 | 智能置位：有未置顶就全置顶，全置顶才取消 |
| 设为私密 | 正在进行 | 切换私密 | 否 | 智能置位；置位跳过空标题/计时中并提示；取消整批一次鉴权 |
| 解散文件夹 | 正在进行 | 销毁容器，子项按原状态上移一级 | 否（整棵子树） | 单文件夹专属；不可恢复 |
| 永久删除文件夹 | 回收站 | 销毁整棵子树（含所有状态） | 否（整棵子树） | 单文件夹专属；不可恢复 |

## 四、确认弹窗 = 正文 + 按需提醒

正文（陈述句）："将[动词][对象]，共 N 件记事[（含所有子文件夹中的记事）][，可在回收站恢复/无法恢复]。"

按需追加的提醒：
- **跨子文件夹**：受影响记事确实落在子文件夹时，数量后追加"（含所有子文件夹中的记事）"。
- **类型筛选**（内容操作）：有具体类型筛选时追加"本次仅作用于当前类型筛选（X）的记事，其它类型不受影响。"
- **结构操作跨状态**（解散/永久删除文件夹）：追加"该操作作用于整个文件夹子树，包含当前[状态/类型筛选]下看不到的内容。"

当前不一致：选择模式的弹窗正文是**问句**且格式不同（"完成选中的 N 件记事？" / "完成所选内容，共 N 件记事（含所选文件夹中的所有记事）？"），与文件夹/工具栏的**陈述句**（"将完成…，共 N 件…。"）不统一。

## 六、建议统一方案

**规律一句话**：标题 = 动词 + 对象；动词全程统一为「完成 / 删除 / 恢复 / 永久删除」；对象 5 选 1；类型筛选只改行为与提醒、不进标题；弹窗正文统一为陈述句。

落地动作：
1. 动词统一：把「还原」→「恢复」、「彻底删除」→「永久删除」（改 `act_restore_selected` / `act_delete_selected_forever` 文案，行为不变）。
2. 词序（二选一，需用户拍板）：
   - A 保留「全部完成/全部恢复/全部删除/全部永久删除」（根目录惯用语，仅这一处动词在后）。
   - B 改为「完成全部记事 / …」与其它位置完全平行。
3. 弹窗正文统一为陈述句，统一模板（见第四节正文格式），选择模式也改陈述句；对象词用：全部记事 / 此文件夹中所有记事 / 选中的记事 / 选中文件夹中所有记事 / 所选项。
4. 多文件夹选择的对象词用"选中文件夹中所有记事"（比"文件夹中所有记事"更准确）。

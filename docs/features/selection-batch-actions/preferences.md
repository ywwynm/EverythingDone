# 使用与动画要求

## 2026-10-13：退出后滚动复用与子控件恢复

- 用户反馈：批量动画全部结束后往返滚动，部分图片／视频记事的卡片颜色已恢复，媒体区域仍然变淡。验收不能只停在当前屏幕或卡片根 View。
- 全面检查图片遮罩、媒体背景、计数、私密／清单／提醒等子控件，以及“正在做”蒙层的显示、透明度与复用；既有计时和业务保护规则不变。
- 继续用独立测试包与虚构媒体验证正常绑定、局部绑定、缓存重新挂载和真正回收后的复用，保护用户原数据。

## 2026-10-13：批量移除后的完整转场

- 用户提供两段首页批量完成／恢复／删除／彻底删除视频，要求统一修正状态栏图标提前变色、工具栏与状态栏底色不同步、选择模式退场和未选卡片恢复动画缺失、工具栏阴影叠加、剩余卡片瞬移。
- 顺序应为：先播放被移除项的粒子动画；完整退场后，再动画退出选择模式并让剩余列表项补位。每个阶段都要有完整动画，不得闪烁；动画期间可以暂时禁止操作。
- 验证覆盖根目录／文件夹、不同滚动位置、可见与屏幕外的混合选择，以及全部选中项都不在屏幕内的情况。沿用已有三台 Android 测试授权；既有记事不做破坏性测试。
- 继续保留 SurfaceView、动态背景和既有粒子表现；修复需区分原有选择／列表时序问题与统一 GL 捕获引起的遮挡，不能只验证粒子播放完成回调。

# FableSol HDR Vivid 完整曲线与逐场景动态元数据

用户已确认首个 HDR Vivid 样本在普通 HDR 设备上的 HDR10 基础层回退正常；当前没有可用的
HDR Vivid 终端，因此本轮先完成编码侧的 Tone Mapping 曲线、逐场景统计与时域平滑，并尽量
复用已经验证过的 HDR10+ 分析链路。

本次更新：

- 复用 HDR10+ 的最终线性 BT.2020 GPU 逐帧统计、完整场景判定、直方图和内容感知目标曲线，
  HDR Vivid 侧独立生成符合 T/UWA 005.1 的 Base Parameters 与两段 3Spline。
- Base Parameters 对量化后的参数执行单调性和参考显示端点门禁，并使用
  `base_param_Delta_mode=3`；3Spline 按附录 A.3 的 `U=6`、`N=8` 推荐流程生成。
- 新增 HDR Vivid 场景时间线：硬场景边界立即清空历史，连续内容的软边界在短窗口内平滑，
  降低动态元数据突跳与画面明暗闪动的风险。
- 正式编码不再按编码器回调顺序取元数据，而是按输出视频样本的 PTS 查找对应场景载荷，
  因而兼容启用 B 帧后的样本重排。
- 修正 `variance_maxrgb_pq` 的标准语义：在线性域先计算 P90−P10，再将差值整体转换到 PQ。
- 保留 HEVC Main10、BT.2020/PQ、HDR10 静态元数据、逐视频样本 HDR Vivid SEI 和 MP4
  `cuvv`，不识别 HDR Vivid 的播放端仍可按 HDR10 基础层回退。

验证状态：

- 新增完整载荷位级解析、不同动态范围曲线、硬／软场景边界、时域平滑和乱序 PTS 回归测试。
- 全量 Debug JVM 单元测试共 577 项，0 失败、0 错误、1 项既有跳过。

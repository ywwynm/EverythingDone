# FableSol HDR Vivid 设置入口与 OPPO 真机验收

## 本次更新

- HDR Vivid 现在位于“导出色彩模式”全部选项的最后，排在两种 SDR 模式之后；仍不加入
  `HDR（自动）`，不改变既有自动格式落点。
- 中国大陆显示“国产标准HDR Vivid”，香港／台湾显示“國產標準HDR Vivid”；其它语言／
  地区使用本地化后的“中国标准 HDR Vivid”含义。
- 选中 HDR Vivid 后会显示“参考显示峰值”、快捷参考值和“高光起点”，设置摘要会同时列出
  这些实际参与 Base Curve 创作的参数。
- 13 套 locale 的 HDR Vivid 说明同步更新为当前完整实现：Base Parameters、两段
  3Spline、逐场景统计与时域平滑，不再显示旧的统计信息首版说明。
- 全量 581 项 Debug JVM 测试通过，0 失败、0 错误、1 项既有跳过；
  `:app:assembleDebug` 构建通过。
- 按用户授权，在 OPPO PLZ110 上从“测试音频呀”的音频附件卡片进入 FableSol，使用
  400 nit 参考显示峰值、90% 高光起点、120 fps、HEVC 10-bit 硬件编码与 VBR 成功导出
  HDR Vivid 视频。
- FFmpeg 全量核对 853／853 帧：每帧均有一组 HDR Vivid 动态元数据、Base Parameters
  和两段 3Spline，目标显示峰值反算为 399.72 nit。载荷包含两组稳定场景参数及 29 帧平滑
  过渡，验证默认 5 秒软分段与约 0.24 秒时域平滑生效。
- MP4 的 HEVC sample entry 内只有一个正确的 30 字节 `cuvv`；音视频完整解码无错误，
  PTS 连续且无重复或倒退。该 OPPO 本轮只验证编码导出，不据此声称显示链路已识别
  HDR Vivid。

# FableSol 新增实验性 HDR Vivid 视频导出

用户希望在现有 HDR10+、HDR10、杜比视界 8.4 与 HLG 之外，评估并开始实现国产 HDR 标准
HDR Vivid；由于该格式的 Android API 与封装链路较特殊，本次为其建立独立 feature 目录。

本次更新完成首个可测试竖切：

- 新增显式 `HDR Vivid` 导出选项、稳定标识 `hdr-vivid` 与文件标签 `HDRVivid`；首版不加入
  `HDR（自动）`，避免在终端兼容性尚未验证时改变既有自动落点。
- 采用 BT.2020/PQ、10-bit limited range 与 HEVC Main10 基础层，继续写入 HDR10 静态
  元数据，使不识别 HDR Vivid 的播放端具备按 HDR10 回退的条件。
- 对完整连续场景执行预分析，按 T/UWA 005.1 附录 A 生成 minimum、average、variance 与
  maximum MaxRGB 四项 12-bit PQ 统计，使用 HDR Vivid 1.0 统计信息模式。
- 在每个 HEVC 视频 access unit 的首个 VCL NAL 前注入
  `user_data_registered_itu_t_t35` prefix SEI；兼容 Annex B 和 1／2／4 字节长度前缀输入，
  并执行 emulation prevention。
- `MediaMuxer` 完成后、产物发布前，在 MP4 的 HEVC `VisualSampleEntry` 中补写并回读
  30 字节 `cuvv`。后处理只接受尾置 `moov`，或 `moov` 后有足够相邻 `free` 的布局，不移动
  `mdat`。
- 能力探测不查询不存在的 Android HDR Vivid profile，而是实际编码一帧，验证每个视频样本
  的 SEI 覆盖率以及 `cuvv` 写入／回读结果。
- 已补齐 13 套 locale 的格式说明。

# FableSol HDR Vivid 视频导出偏好

## 2026-07-30 独立功能目录

- HDR Vivid 格式较特殊，应使用独立的
  `docs/features/fablesol-hdr-vivid-export/` 目录，不把专属调研、计划和实现记录继续堆入
  `fablesol-video-export`。
- 仍遵循 FableSol 视频导出的全局偏好：只要平台上存在真实可达的更高规格，就实现并以真实
  码流和终端结果验证，不以“收益可能有限”作为不做的理由。

## 2026-07-30 导出设置与地区名称

- HDR Vivid 放在“导出色彩模式”全部选项的最后，位于两种 SDR 模式之后；仍不加入
  `HDR（自动）`。
- 中国大陆显示名称使用“国产标准HDR Vivid”，中国香港和中国台湾使用对应繁体
  “國產標準HDR Vivid”。
- 其它语言／地区使用本地化后的“中国标准HDR Vivid”含义，避免写成国产标准。
- HDR Vivid 与 HDR10+ 一样需要显式显示“参考显示峰值”和“高光起点”；不能只显示
  “漫反射白”。

# 计划 · FableSol 表达力与视觉质量升级（2026-07-11 定稿）

依据：`research-2026-07-11-quality-upgrade.md`（第一轮）、
`research-2026-07-11-perception-aesthetics.md`（第二轮）、决策 D14~D23（经
2026-07-11 grill 问答逐项确认）。

**工作方式**：所有表达/映射/渲染改动先在 `audioVisualizerSimulatorFable`
（Conda 环境 `everythingdone`）实现并经用户目测认可，再同构移植
EverythingDone/Kotlin 并补差分 fixture（D16/D22）。Android 侧不建测试装置，
真机验收 = 用户视觉感知反馈（D22）。当前重点：**阶段 A（Python）**。

## 红线（每步适用）

- 浪形连续性：已成形的浪只因物理传播/重力/阻尼/边界/新注入能量自然变化；
  包络与记忆只作用于浪的出生处（D12/D17）。
- 不要尖而窄的浪（最小宽度下限、锐度上限、高宽联动）；水位只允许潮位式慢变；
  宁少勿烂——做不好的手法整项砍，不上线降级版（preferences 红线）。
- 注入反克隆纪律（D18）：单事件 ≤3 层、群传播时序、逐层形状独立。
- 单色相纪律：一切高光为主题色染近白，无第二色相、无纯白。
- 静中有动、动中有静（D14 章程）。

## 阶段 A · Python 表达层（六步，每步后交用户目测）

### A1 前端第一批 + 延迟尺子
自适应白化 + SuperFlux 最大值滤波；K 计权 momentary(400ms)/short-term(3s)
响度（44.1kHz 重推双二阶系数，保留自校准与可听度门）；Scheirer–Slaney
speech/music 门控（4Hz 调制能量、flux 方差、pulse metric + 迟滞）。
**延迟测量脚本**：WAV 回放 → onset 时刻 vs 首个可见驱动时刻的分位数报告，
此后每步跑回归（"快触发 <50ms 启动、慢展开"为硬约束）。

### A2 结构改造
双 register（涌浪能量库半衰期默认 6s、可调 4~8s；chop 即时；涌浪水位贡献设
上限并入体积守恒）；波群包络（能量按组进入，浪生于组尾亡于组首，仅作用出生
处）；反克隆注入落地 + rhythm wave 单层化；乐队分层骨架（装饰层 0~1 /
旋律层 2~3 暂用中频 / 织体层 4~6 / 深层 7~8 改 20~40s 长积分 + 永恒慢涌，
不再响应逐帧人声）。验收：普通语音/快语速/音乐三段样本目测 + 延迟回归 +
"无九层克隆"目检。

### A3 前端第二批（语音韵律）
YIN/MPM F0 + voicing/非周期度；4Hz 波动强度 → 呼吸容积通道；因果音节率
（强度包络峰 >2dB 于滚动中值 + ≥4dB 谷 + voiced 门控）→ 语音模式 flow01
融合；prominence 事件（energy×F0 位移×时长 z-score）→ 旋律层峰击（预峰值
提前、峰值不迟到）。旋律层完整化：F0 高度→峰高、F0 漂移→行进方向微调。
验收：目测"语调可读"。

### A4 境状态机
8 锚点：idle / silence / quiet-speech / active-speech / melodic / loud-music /
climax（瞬态）/ settle（尾声）；功能命名，文档注马远题名（镜塘、寒塘清浅、
洞庭风细、湖光潋滟、秋水回波、层波叠浪、云舒浪卷、细浪漂漂）。连续插值 +
迟滞 + 升快降慢；境不是旅程是查询表——平淡语音只驻留 quiet↔active。
三种静默：句中悬停（<~600ms 非终结语调：微抬保持、受束）、句末沉降（前层
~1s、深层 ~3s 级联）、结束尾声（chop ~1s 内死、涌浪 4~8s 沉降）。
验收：平淡语音整段好看 + 各锚点参考帧。

### A5 渲染六手法（逐项独立验收）
1. 闪光带离散化：概率包络（高斯软边、宽度=活动度）+ 闪点原地生灭（150~400ms
   独立包络、大小不一、沿面微拉长、染色近白）。验收：明灭不行驶，无轨道车厢感。
2. 猫爪暗纹：音节触发局部暗色毛细斑块，顺流漂移消散。
3. 沉降尾声呈现（A4 结构的渲染面）。
4. 驻波呼吸（试验标签）：仅 melodic 境缓降墙侧吸收使反射显现；不喜欢即砍。
5. 顶边羽化：低能量时最上层轮廓向背景溶解，能量升高变锐利。
6. 波峰珍珠斑（crest glow + pearl 合并升级）：强度=f(峰高×圆润度×坡向对光)，
   OpticalWaveSet 长波分量咬边界；单侧峰肩、向下慢淡出；斑心染色近白、边缘
   ±6° pearl 色相环；近 0~2 层、圆润峰限定、语音电平同屏 ≤3~4 个。
   验收："贴在峰肩的软鹅卵石光泽"，无盖章椭圆感。

### A6 修饰批 + 张力试验
HNR→清澈度（毛细/veil/闪点锐度）；arousal 复合（F0 IQR+响度动态+音节率）→
境迁移输入；looming（响度导数）→ 波群生长率与新浪前倾；冲击性（包络峰度）→
注入峰形（守红线）。张力=相位：各层推进速度缓慢偏置实现、相干上限 0.6、
持续渐强证据×门控触发、静息回失谐、绝不同步化注入。
验收：目测 + "平淡语音不受影响"回归。

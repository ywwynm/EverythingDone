## 1. 听觉感知全景：水应该听到什么

### 1.1 被典型可视化忽视的高价值维度（按价值/成本排序）

1. **4Hz 音节波动强度（fluctuation strength）**——本轮最重要的单项发现。
   心理声学的"波动强度"感知恰好在 4Hz 达到峰值，而 4Hz 正是人类语音的
   音节率。对宽带包络做一个 2~8Hz 带通即可直接取出"语音的脉搏"。映射到
   水的呼吸/涌动节奏，水面就会"说话"而不是仅仅对音量作出反应。成本极低。
2. **逼近偏差（looming bias）**——人对渐强声音会系统性高估并感知为"正在
   接近"（Neuhoff 1998，先天适应性偏差）。只需响度导数的符号与速率（几乎
   免费），渐强即可表现为浪涌向观者、渐弱表现为退去。几乎没有可视化区分
   "变响"与"变轻"，而感知收益不对称地大。
3. **谐波性/音高强度（voiced vs noisy）= 清澈度轴**——自相关峰高（YIN 顺带
   产出）区分清晰元音（连贯波形）与耳语/擦音/气声（弥散水雾）。给水一条
   与响度正交的"清晰度"维度。
4. **粗糙度（roughness，70Hz 调制）**——区分平滑元音与嘶哑/紧张/喊叫，
   独立于响度；完整 Zwicker 模型贵，30~150Hz 包络调制能量代理是中等成本。
   映射到表面碎裂/起沫。
5. **尖锐度 vs 温暖度**（DIN 45692 标准化；与不愉悦度相关）——双端亮/暖轴：
   高光与水雾 vs 深沉水体。与 centroid 相关，二选一避免重复计入。
6. **纹理颗粒度/密度**（McDermott & Simoncelli 纹理统计）——雨/火/掌声靠
   少量时间平均统计量即可辨认；微事件密度是独立于响度与音高的轴，直接
   对应水面（稀疏水滴 → 密集雨幕）。
7. **冲击性/攻击形态**（包络峰度、上升斜率）——描述 onset 的"种类"：
   敲击式水花 vs 渐入式涨潮 vs 持续水流。对现有 onset 检测是零成本补充。
8. **发声努力（vocal effort）**——喊叫/Lombard 语音的谱倾斜变平、alpha 比
   升高，独立于电平。"被用力推的水"：水花随 effort 而非仅振幅缩放。

排在其后（价值高但成本/场景受限）：groove/律动与节拍层级（需要音乐模式的
拍点模型）、混响/空间感（盲估 RT60 困难）、真源分离（不需要，见 1.3）。

### 1.2 水声为何普遍愉悦——对视觉的启示

水声在恢复性声景研究中始终名列前茅（Alvarsson 2010：同电平下自然水声的
应激恢复更快）。三个会聚的原因，每一个都能反过来指导视觉：

1. **1/f（粉红）涨落结构**（Voss & Clarke 1975）：水声的幅度涨落谱既非白噪
   的"过于随机"也非 1/f² 的"过于相关"。→ **把 1/f 时间结构施加到水的闲置
   运动上**：跨时间尺度的涌中有涌，即使静止也按"水声的统计"运动。这可能
   是可用的最深层跨模态呼应。
3. **宽带、随机、无冲击**（气泡声学：千万个阻尼共振叠加成平滑宽带）：
   → 默认响应保持平滑、宽带、非冲击，把尖锐/粗糙/冲击的表面行为留给真正
   尖锐/粗糙/冲击的输入——水默认停留在"愉悦声学区"，粗糙才有对比度。
4. **低因果不确定性**（Gaver 日常聆听：人听到的是"水在流"这个安全事件，
   不是频谱）：水本身就是可辨识的良性来源——概念自洽。

另一条反例警告：**全表面同相脉动读作低音炮电平表；去相关微闪才读作水**
（低跨带相关是水声纹理的签名）。与 Kawabe 的"空间平滑连贯"要求并不矛盾：
空间上平滑 ≠ 时间上同相。现九层各自独立相位 + 平滑场恰好同时满足两者。

### 1.3 图形/背景（听觉场景分析）

Bregman ASA：人耳本来就把一个人声从房间噪声中分离成独立流。真源分离在
端侧不可行，但**不需要**：谐波性 + 4Hz 音节调制这两个通道天然偏向前景
人声；宽带、低谐波、低波动的能量天然属于背景。→ 前景特征驱动主水波
（近/中层），背景能量只驱动弥散的远层雾感——用现有九层结构低成本近似
图形/背景，无需分离算法。

### 1.4 维度独立性（避免重复计入）

音色 MDS 研究反复得到三条近正交轴：**攻击时间**（时间域）、**频谱质心/
亮度**（谱包络）、**谱不规则度/flux**（谱细节）；语义音色跨语言坍缩为
**光泽（luminance）/ 质感（texture）/ 质量（mass）** 三轴（Zacharakis 2014）。
已知相关：尖锐度≈质心加权版（二选一）；粗糙度与波动强度是同一机制的不同
速率（70Hz vs 4Hz，可按速率分离）；响度会渗入几乎所有量——尽量用电平
归一特征去相关。SenseLab Sound Wheel（AES 2015）可作"是否漏掉感知类别"
的清单校验。

## 2. 水的美学本体：水应该长什么样

### 2.1 自然现象学词汇（每个都自带声音语义）

| 现象 | 视觉形态 | 可承载的声音语义 | 适配度 |
|---|---|---|---|
| **波群/set 包络**（群速=相速一半；单浪在群尾出生、群首消亡） | 几个大浪结伴而来，然后间歇 | 响度不该均匀调制每个浪，应喂给"包络"、由少数浪乘载：一句话成为一个 set，句后停顿是间歇。有机而非合成 | 高 |
| **涌浪+风浪双 register**（全球约 70% 海面两系统叠加） | 长而平滑的缓涌 + 骑在其上的细碎快纹，速度方向都不同 | 涌浪=累积语音能量的长记忆（"记住你的能量片刻"）；风浪=即时音节。停止说话→风浪立刻死、涌浪缓慢衰减=雨后初晴 | 高 |
| **蒲福风级**（水手用了 200 年的"外观分级"） | 0 镜面 → 1 鳞纹无峰 → 2 玻璃质小浪不破 → 3 开始破碎零星白帽 → 4 长浪多白帽 | 输入→外观的现成阶梯；关键细节：**白色破碎从 3 级才开始**——"提高嗓门"的有意义阈值 | 高 |
| **猫爪纹（cat's paws）** | 阵风掠过，一片暗色软边纹理斑块顺风滑行后消散（微面停止反射天空所以变暗） | "声音即风"最字面的化身：一个爆破音/一声笑生成一块暗纹斑块滑过某层并溶解。局部、瞬态、有方向 | 高 |
| **闪光带（glitter path）** | 无数波面对准光源的瞬时闪点组成的光柱；**带宽即粗糙度**：静水窄、动水宽 | 闪点密度/带宽编码活动度——一个永远不像仪表的响度计。静默两三个慢闪点；音乐一条宽闪带 | 高 |
| **泡沫花边衰减** | 破碎后气泡结成花边，大泡先破：粗→细→无，有结构地消逝 | 响度的余像：一声喊留下比它长一两秒的花边，细先溶——记忆可见 | 中 |
| **破碎浪叙事弧** | 羽化→变陡→卷→破→白水→消散；四种破法（崩落/卷破/坍塌/**涌破 surging**——无白水的鼓胀推进） | 完整弧线只留给罕见峰值。语音只用第一幕（羽化后回落）。**涌破是小水体的优雅大声态**：鼓胀的力量，没有飞沫 | 中高 |
| **驻波/clapotis** | 波撞墙反射叠加成驻波：节点静止、腹点上下呼吸；斜射成菱格纹 | **我们的水本来就在带墙的容器里**（物理已有墙反射）：持续乐音=驻波呼吸（共鸣的视觉双关），语音=行波。几乎没人做过 | 高 |
| **风停浪不停** | 风骤停，碎浪随之死，涌浪滑行数小时——光滑表皮下放松的肌肉 | 录音结束态：chop 立即死、swell 数秒沉降。这正是"说完时归于平静" | 高 |
| **镜面/油样静水** | 蒲福 0：几乎不是水，是一张会极缓呼吸的天空 | 录音前 idle：近乎完美的静止 + 一道几乎不可察的慢涌——第一句话可见地"打破一个屏息" | 高 |
| **软性迷恋（恢复性注意）** | — | 动水是"soft fascination"的典范刺激：足够丰富但不索取。约束：复杂度在高输入时应**饱和压缩**而非升级成视觉噪声 | 高（约束） |

### 2.2 绘画 / 动画 / 摄影的手法提取

- **艾伊瓦佐夫斯基《九级浪》：光在浪的内部**。薄透明罩染 + 让白底透出来——
  背光波峰像彩绘玻璃一样发光。水在材质中独有的美是**透射**而非反射；
  九层半透明叠加本身就是他的罩染法。→ 高能温暖输入（歌声/音乐）让波峰
  "接住光"：峰尖用更亮更饱和的主题色变体发光。同时他的风暴里永远留一处
  透光的亮区——**最大输入时也保留一个平静的发光区域，画面永不读作苦难**。
- **透纳：溶解边界**。海天从两块色域开始，然后失去边缘；主题是媒介本身。
  → 低能量时水的顶边不应是硬矢量线——最上层羽化进背景，能量升高才变锐利。
- **莫奈：水是碎色之镜**。倒影作为碎裂色形，表面一动倒影即碎。→ 层内色彩
  连贯度可作"平静度"的通道（小尺寸下直接做倒影有杂乱风险，评级中）。
- **索罗拉：定量供应的有色白**。白从来不是纯白（掺黄粉紫蓝）；浪肩上几笔
  厚亮点完成全部闪耀。→ 高光必须是主题色染过的近白、绝不用 #FFFFFF，
  语音电平下的闪点数量"一只手数得过来"。
- **北斋《神奈川》：工程化的浪**。剪影优先（任何尺寸都可读，因为它是形状
  不是纹理）；双蓝叠印 + 留纸白 = 色彩总量极简；不动的富士山让运动有意义。
  → 同色相分层深浅（即现有层栈）；**一个稳定锚**（水位基准/对话框）让浪
  的运动可读；浪爪只属于风暴叙事，不属于录音陪伴。
- **马远《水图》十二帧**：水的表达全谱系仅靠**线的质量**承载——颤笔=海的
  力量。十二帧各有（线形、节奏、密度、淡出）配方与命名心境，正是音频
  反应参数集需要的模式。见 2.4 的七境量表。
- **留白/计白当黑 + 郭熙"水欲远，尽出之则不远"**：不是每个像素都要有浪。
  波纹线簇聚在能量所在处，其余留呼吸的空白；细节在对话框边缘前淡出，
  水池才显得比盒子大。
- **吉卜力**：《波妞》的浪有动物的时机（迟疑一拍、急切一涌）——不加眼睛，
  借时机，读作"在听"。《千与千寻》海上列车：**平**的海承载全片最深的情绪
  ——ma（间）是刻意放置的空。→ 句间静默要用真正的视觉休止来尊重，不用
  idle 小动作填满；整个动画的情绪支点就是水安静下来的那一刻。
- **新海诚《言叶之庭》：构建的雨**。用手工设计的层（背景雨丝循环、单帧
  前景滴、水花高光、虚化光斑）而非模拟——"抽象一点，就从'雨的机械图像'
  变成'人在雨中看见的东西'"。→ 为整个风格化路线背书：按听者**感受**调每个
  元素，一个重音一粒闪光胜过物理正确的密集水花。
- **《海洋奇缘》：可信优先于真实**。让角色水更接近真水反而"太凶、太躁"，
  最终保持"非自然的平滑圆润"；**情绪强度映射到上升速率而不是叠加抖动**。
  高频表面噪声=威胁编码，平滑=友善编码。
- **迈克尔·肯纳长曝光**：分钟级曝光把海化为发光的雾面 + 一两个深色锚点 +
  巨大的空。时间本身成为主题。→ 深远层可以表现为"长曝光的水"：几乎静态
  的软渐变**平均**近期能量，前层承载瞬时运动——九层字面实现短/长曝光并存。
- **海洋摄影年赛评语**："vibrant colour, technical precision and powerful
  simplicity"——评委在一万五千张里奖励的是削减。峰值时刻只做**一件**美的事。

### 2.3 东方框架（作为九层栈的纪律）

- **墨分五色**：一个主题色相分出焦浓重淡清五档明度即是全部配色——深层浓重、
  中层淡、表层清、高光=染过主题色的纸白。永不引入第二色相。
- **留白**：空是放置的，不是剩下的。静默时大多数层归于静——空本身就是
  静默的可视化，而不是说话状态的调暗版。
- **静中有动 / 动中有静**（宗白华）：静默态保留一个几乎不动的活物（一道
  慢涌、一粒漂移的闪点）——可证明活着的静；喧闹态保留一个静物（稳定的
  水位基准、平静的远层）——保持安详的动。**本项目的总原则候选**。
- **不均齐（fukinsei）**：层相位永不对齐、浪距微不均；真实重力带来的倾斜
  本身就是"侘寂的礼物"，不要在视觉上补偿掉。
- **青海波**：最平静态可含一丝嵌套圆弧的规则韵律（纹样=平安的文化编码），
  能量升高溶解为不规则自然主义——秩序=安宁，自由=能量。（点到即止，中评级）

### 2.4 七境表达量表（马远 × 蒲福交叉校验）

马远《水图》作骨架的评估：**成立，但需编辑**——十二帧不是强度阶梯（有的
按地理/光线分帧），故取子集重排为强度序，逐级对照蒲福保持物理真实，其余
帧降为"修饰语"。

| 境 | 输入域 | 视觉配方（要点） |
|---|---|---|
| **0 镜塘** | 对话框 idle、未录音 | 蒲福 0。九层近静、边界羽化（透纳）、约 8~10s 一道不可察慢涌 + 一两粒慢闪点（静中有动）。重力倾斜是唯一事件 |
| **1 寒塘清浅** | 已就绪、静默/房间底噪 | 稀疏、慢、单根可见的起伏线浮在大片空白上（马远的疏线盘旋；蒲福 1 鳞纹无峰）。前层极淡鱼鳞微纹，需注视才见。可看一分钟不厌（软性迷恋） |
| **2 洞庭风细** | 轻声说话、耳语 | 细软规则的鳞浪向远侧淡出（掩映）；音节生成**猫爪斑块**——局部暗纹顺流漂移溶解。峰玻璃质、永不破碎（蒲福 2）。涌浪 register 开始积累记忆 |
| **3 湖光潋滟** | 活跃说话、对话能量 | 快、轻、不规则的小浪——峰刻意不均匀（乱风；不均齐）；**闪光带开启**：稀疏主题色闪点，密度/带宽跟踪响度（索罗拉的定量白）。重读词上首次出现零星软性峰亮（接近蒲福 3）。能量以 **set 包络**成组到来，不逐音节尖刺 |
| **4 秋水回波** | 持续乐音、旋律音乐、歌唱 | 圆润双勾轮廓的涌成组行进；双 register 显式化：长涌驮着细纹。持续音在对话框墙侧出现**驻波呼吸**（clapotis）——水池在共鸣。峰缘随高度拾取背光辉光（艾伊瓦佐夫斯基/rim light） |
| **5 层波叠浪** | 大声音乐、喊 | 大振幅浪 + "颤笔"式受控微抖（自由噪声仍被禁止：《海洋奇缘》平滑律仍统治底形）。白帽点缀=峰尖的留白亮形（北斋的留纸；蒲福 4~5）。深层加深（浓/焦），亮峰前跳。**场中一区保持较平静**——艾伊瓦佐夫斯基的透光 |
| **6 云舒浪卷** | 瞬态高潮事件（非持续态） | 真峰值（突然的最强音）时：一道浪变陡、前倾、卷起、释放为约 2s 粗→细衰减的泡沫花边。一次一个事件、只在前层（摄影年赛"一件事"）。北斋的戏剧性只允许以这种克制形态出现，无浪爪 |
| **尾声 细浪漂漂** | 录音结束（过渡态） | chop 约 1s 内死（风停）；涌浪 register 约 4~8s 经鱼鳞细纹稀释向空白沉降，闪带收窄成两粒闪点，落回 0/1 境。**这条衰减尾巴是全功能里最该精调的动画**——用户每次录音后都会看到它，它就是情绪签名 |

排除：**黄河逆流**（最暴烈一帧：浑浊原始的对冲咆哮——记事应用错误的情绪；
响度到顶应饱和为层波叠浪的酣畅，不升级为苦难）。

### 2.5 大师会删掉什么

浪爪/飞沫/水滴/生物浪（300dp 宽、对自己的声音——读作威胁或滑稽）；逐帧
神经质（北斋早期浪"密、僵、匀"即死浪；自然自己的平滑——群包络、涌浪记忆
——就是模型：更少但更好的浪）；第二色相与纯白高光；到处闪烁（真实闪带
是窄的，带宽即信息；无处不在的闪烁毁掉闪烁的意义）；展示全部的水（掩映
断脉才远）；填满静默的 idle 小动作；完美规则与对称。

## 3. 音画结合语法：水如何与声音对话

### 3.1 操作性原则（十五条压缩）

1. **地基图纸，不是插画**（费辛格："我的电影不是音乐的插图……音乐是建筑
   地基图"）：水拥有自主模拟，声音只操纵参数（能量、相位、锐度）——现有
   D12 架构正是此原则的现代形态（Magnetosphere 同源）。
2. **结构化的运动才产生情绪**（惠特尼《Digital Harmony》："只有结构化的
   运动产生情绪"；张力在整数比/共振点解决）：**九层作为声部，层间相位关系
   承载张力**——渐强让层相位渐次对齐，乐句高潮多层波峰对齐（视觉协和），
   释放时漂移分开。这是"从仪表到作品"最强的单一手段。
3. **预备：峰值落在拍上，绝不迟到**（迪士尼实践"提前 2~4 帧，绝不迟一帧"；
   心理物理：视觉领先可容忍、音频领先不可容忍）：有拍点预测时提前
   100~200ms 起涌，让峰**正好**落拍；语音不可预测时所有手势峰值相对特征
   平滑极大值偏早一两帧。
4. **因果有截止期**（Michotte 发射效应：延迟 <~50ms 因果印象即时，随延迟
   陡降）：**快触发、慢展开**——每类 onset 响应必须在检测后一帧内（端到端
   <50ms）启动，随后可用一秒展开。攻击要诚实，发展可修辞。
5. **同步点当作终止式来花**（Chion synchresis：少数显著同步点为段落断句，
   点与点之间声画各自独立发展）：**每个语调短语预算约一次全栈同步事件**
   （短语核心重音或每小节第一拍），其余都是单层局部响应。全都同步等于
   没有同步。
6. **重音层级：主重音给主动作**（迪士尼 bar sheet 制度）：把层分配成乐队
   ——一个"旋律层"（中前）拥有音高轮廓与重读；两个前层拥有 onset/爆破音
   （装饰音）；深层只拥有慢包络（arousal、段落）。重读音节强推旋律层、
   弱推邻层、不动深层。
7. **拉班力效：运动性格必须匹配声音性格**（Weight 强/轻 × Time 突然/持续
   × Space 直接/迂回 × Flow 受束/自由 → punch/dab/flick/glide/float/press/
   wring/slash 八种动作）：每类声音事件一个力效预设——上升时间=Time、
   振幅+质量=Weight、空间扩散=Space、阻尼/约束=Flow。
8. **复杂映射造乐器，一对一造推子**（Hunt & Wanderley NIME：一对多/交叉
   耦合映射在表达力上胜过一对一；Fels：但须保留"透明度"）：保留两条透明
   主线（响度→波能量；onset→水花）供任何人秒懂，其余交叉耦合（响度同时
   锐化波峰并加暖光；音高同时微调行进方向；亮度同时加闪点）。骨架可读，
   血肉丰富。
9. **对位胜于平行**（爱森斯坦纵向蒙太奇；克利复调绘画）：语速快时**不**按
   音节抖水——音节密度转为某一层的细闪纹理参数，主涌保持短语速率。两个
   对位声部共享一个结构。
10. **打点与装填**（动画实践"拍上击、拍间备"）：重音之间形成微小的回撤/
    低谷（水在积蓄），波峰花掉低谷攒下的。整体表面"呼吸容积"的胀缩是
    最可读的总参数。
11. **随动：衰减不是死亡**（follow-through + "after-silence"）：短语结束
    永不冻结也永不弹回 idle——能量以错开的时间常数向外/向后层级联
    （前层 ~1s、深层 ~3s 沉降）：水记住这个短语，然后忘记它。
12. **休止是屏住的呼吸**：用韵律区分**句中停顿**（<~600ms、非终结语调：
    表面微抬保持、运动近停但受束——悬停）与**句末静默**（第 11 条的呼气
    沉降，然后进入 4~8s 周期的 idle 呼吸——水的"静默同义词"）。
13. **无动于衷的深层**（Chion anempathetic：无视事件继续行进的声音反而
    强化情绪）：**最深两层永不响应人声**，只承载缓慢永恒的涌。有了这份
    "世界的一部分不在乎"，上层的响应才读作**倾听**这个行为，而不是整个
    世界是一台仪表。可能是"从仪表变成生命"最便宜的单一改动。
14. **纯粹域：所见即所闻**（麦克拉伦 Synchromy；示波器音乐）：保留一个
    特殊状态——持续干净的浊音长音（唱一个音）时，旋律层锁成音高成比例的
    字面驻波。因为只在声音本身如乐音时出现，读作"揭示"而非"读数"。
15. **运动活在帧与帧之间**（麦克拉伦："动画不是会动的画，是被画出来的
    动"）：以速度场而非姿态审核水——所有映射参数在导数域整形（攻击/释放
    包络、按拉班 Time 的斜率限制），让**过渡**而非状态承载表达。

### 3.2 映射语法表（声音事件类 → 视觉手势类）

短语单位 = **语调短语（1~4s）**，不是帧也不是音节（舞蹈音乐性："穿过音乐
跳，不是踩着每一拍跳"）。

| 声音事件 | 视觉手势 | 拉班力效 | 时标/包络 |
|---|---|---|---|
| 持续元音（浊、包络稳） | 行进：宽峰滑过旋律层；波长变长、chop 减少；音高高度→峰高、音高漂移→行进方向 | **Glide**（轻·持续·直接·自由） | 连续；~300ms 斜率限制；无离散事件 |
| 爆破音/尖 onset | 点击：前层固定位置的局部凹坑水花 + 2~3 圈涟漪回声 | **Dab/Flick**；响的爆破→**Punch** | 触发 <50ms；衰减 150~400ms |
| 重读音节（音高+能量重音） | 峰击：旋律层涌至全高、峰值正落重音；邻层迟 60~120ms 跟随 | **Press→Punch** | 预涌提前 100~200ms；随动 400~800ms |
| 上升语调短语（疑问） | 抬升-悬停：水位与倾斜随短语上升，**顶部保持**，不解决 | **Glide 收于 bound** | 上升随短语 0.5~2s；悬停 300~800ms |
| 短语结束+静默 | 呼气-沉降：水位下沉、峰变长、能量前→后层级联、余摆存续、进 idle 呼吸 | **Wring→Float 释放** | 释放 0.5~1s；余韵 1~3s；idle 涌 4~8s 周期 |
| 音乐下拍（节拍置信高） | 韵律浪：拍前低谷、峰正落拍；振幅按节拍层级（下拍>拍>反拍） | **Punch**（经由预备送达） | 锁 tempo；预备 100~200ms；低能量时只响应下拍（同步预算） |
| 段落切换 | 波前+转调：一道行进波前扫过全表面；光照/色彩状态切换并保持——新的视觉"调性" | **Slash** 后进入新稳态 | 手势 0.5~1.5s；状态保持到下一段落 |
| 渐强/arousal 上升 | 对齐-积累：层相位渐次对齐、振幅与峰锐度同长、运动可见地受束（张力）——高潮释放为水花，或中止则消散 | **Press**（强·持续·直接·受束）→释放为自由流 | 随渐强 1~10s；释放 <1s |
| 耳语/气声（高亮度、清音） | 微光：细毛细纹理、无涌；边缘软化、微闪 | **Float**（轻·持续·迂回·自由） | 连续；仅纹理 |
| 粗糙/嘶哑声 | 碎波：中层间刻意相位失谐；峰形碎裂 | **Wring**（强·持续·迂回·受束） | 连续、振幅封顶 |

### 3.3 直译同步（mickey-mousing）的边界

历史结论精确而非一刀切：科普兰批评其"庸俗化"，但琼斯承认"完美的同步可以
有真正的力量"；卡尔黑恩："只有逐音符对应才机械恼人"。存在一条不适谷曲线：
满意度随"有计划的同步点"上升、在"墙到墙全同步"崩塌、只在"声画完全同一"
（纯粹域）恢复。

**直译同步正确的场合**：(1) 事件是点状且因果形的（onset/爆破/下拍——冲击。
每次都直译、即时、<50ms）；(2) 处在结构性终止式（短语高潮、小节第一拍、
段落边界——全栈响应，正因罕见）；(3) 完美可达（做不到一帧内命中瞬态就改
用诠释）；(4) 语域是玩笑（对一声咳嗽眨眼时，直译是笑话的语法）。

**诠释/对位正确的场合**：(1) 信号是连续的（响度轮廓、音高漂移、arousal
→ 映射到**运动质量**，绝不映射到瞬时位置）；(2) 事件密集（>~4 个/秒：
逐个手势糊成抽搐——密度本身转为纹理参数）；(3) 内容是情感（用水**怎么动**
——力效——共情地呈现，而不是更多同步事件）；(4) 是深层（无动于衷原则）。

一行规则集：每短语一次全焊接；主重音给主动作；宁早勿迟；一帧内启动、
一秒内展开；衰减而非死亡；犹豫时让低谷来演。

**为什么大多数可视化显得机械**——公认的病因即惠特尼 1980 年的话：既不
积蓄也不释放张力的运动只产生"情绪的平淡"。**可视化映射的是状态；作品
组织的是张力。** 现有管线（包络、onset、韵律、arousal、段落）恰好是
"组织张力"所需的全部特征集——上面的语法就是花掉它们的方式。

## 4. 综合设计论点（三报告拧成一个骨架）

1. **双 register 时间结构**：涌浪（长记忆，秒级衰减）+ 风浪（即时，音节级）
   + 波群包络（响度以 set 成组进入）。现有 swell/hero 与 DynamicWave 已是
   雏形，需要把"记忆语义"显式化（涌=近期能量积分，chop=瞬时）并加入群包络。
2. **乐队分层**：九层 = 声部。旋律层（中前，音高轮廓+重读）、装饰层（前，
   onset/爆破）、织体层（中，音节密度纹理）、**无动于衷的深两层**（永恒慢涌，
   只随段落/arousal 极缓变化）。取代现在"每层都听全频段"的均质响应。
3. **张力=相位**：渐强/高潮/释放通过层间相位对齐度表达（惠特尼协和）。
   这是现架构完全没有的表达维度，也是"组织张力"的直接实现。
4. **七境状态机**：现有 mood 性格档升级为 2.4 的七境量表（马远×蒲福），
   由（响度包络、4Hz 波动强度、谐波性、粗糙度、speech/music 门控、arousal）
   共同决定境的驻留与迁移；境间过渡即 3.2 的"段落切换"手势。
5. **快触发慢展开**：<50ms 因果启动 + 秒级修辞展开；一切连续量走导数域
   整形（拉班 Time）。第一轮 P1e 的延迟测量因此升级为硬验收项。
6. **休止的语法**：句中悬停 vs 句末呼气沉降 vs 录音结束的"细浪漂漂"尾声
   ——三种静默三种形。衰减尾巴是全功能最重要的单条动画。
7. **单色相多光学**：墨分五色的明度纪律 + 闪光带（带宽=活动度）+ 波峰
   内透光（高能温暖）+ 猫爪暗纹（音节阵风）+ 有色白。全部在一个主题色相
   内完成，不引入第二色相。

## 5. 更新后的讨论问题

1. **总原则确认**："静中有动、动中有静"+"一句话概念"（你的声音是掠过一小
   片真实水面的风）是否定为本功能的美学章程？
2. **七境状态机**：是否采纳为 mood 系统的继任者？境的数量/命名可再议
   （用马远原题有文化纵深，也可另拟）。
3. **乐队分层与无动于衷深层**：深两层不再响应人声（只随段落极缓变化）
   是显著的行为变化——接受吗？
4. **张力=相位**：允许渐强时层间相位趋同（与"层相位永不对齐"的不均齐
   纪律存在受控冲突——对齐只作为张力的临时状态，释放后回到失谐）？
5. **优先序**：第二轮内容建议的最小可感知集是——双 register 记忆语义、
   4Hz 呼吸、快触发慢展开、句末沉降尾声、闪光带。同意以此为 P2 的核心
   重排依据吗？
6. 第一轮遗留：APK 预算（YAMNet +5.7MB）、AGSL 立项、时段底色三问仍待定。

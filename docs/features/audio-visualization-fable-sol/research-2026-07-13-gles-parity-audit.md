# FableSol GLES 迁移问题核验（2026-07-13）

## 结论

用户提供的 A1、B1～B9 清单总体质量很高。A1、B1、B2、B3、B5、B6、B7、B8 的核心判断
全部准确；B4 的抖动覆盖和幅度判断准确，但“不乘 alpha”的后果在当前已经合成为不透明颜色的
水面上不成立；B9 的参数、阈值、空气透视和颜色退化判断准确，但完整椭圆几何不能恢复，因为此前
真机已经确认它会穿出水面。以下修改均以源码对照和回归为依据。

## 逐项核验

| 编号 | 核验 | 证据与处理 |
|---|---|---|
| A1 | 准确，已修复 | `release()` 删除 EBO 后保留旧列数，同尺寸 EGL 重建会跳过索引上传。新增“上传→释放→同列数必须重传”状态回归，并在释放时清零列数和每组索引数。 |
| B1 | 准确，已修复 | `water.vert` 的绝对 `0.90+0.10·ndl` 确实替代了 Canvas 的相对 `b+f-r`。现恢复平坦纵向恒等、迎光候选提亮、背光沿基色→黑轴与远层平方淡出。 |
| B2 | 准确，已修复 | GL 无 `body_light_strength` 消费点。现按 Canvas 的曲率、Fresnel、体积宽度、颜色、alpha 和空气透视生成九层体积光带。 |
| B3 | 准确，已修复 | GL 使用全视口 UV 和两端 RGB。现按每层包围盒上传渐变原点/方向/分母，并上传 start、OKLab 21%、OKLab 56%、end 四停靠点做三段插值。 |
| B4 | 核心准确，已修复 | GL 天空无抖动，水体噪声为 Canvas 两倍。现天空和前景填充使用 Canvas 同常量、同 ±0.5/255 三角噪声，连续 ribbon 不抖；当前目标 alpha 为 1，因此“未乘 alpha”不是实际差异。 |
| B5 | 准确，已修复 | `SRC_ALPHA/ONE_MINUS_SRC_ALPHA` 同时用于 alpha，会使目标 alpha 最低降到 0.75。现改为分离混合：RGB 保持 source-over，alpha 使用 `ZERO/ONE` 保持不透明 framebuffer。 |
| B6 | 准确，已修复 | GL 无 `crest_veil_strength` 消费点。现迁移第 0～2 层 crestVeil 采样、平滑、可变宽度、颜色和 alpha。 |
| B7 | 准确，已修复 | `sky_reflection_strength` 在 GL 光学中未读取。现恢复相对平面 Fresnel 细节项。 |
| B8 | 准确，已修复 | 闪点和流光缺 1/f 调制，且 GL 时间尺度与 Canvas 不同。现统一为 Canvas 的四时间尺度，并分别恢复闪点与流光 pink 增益。 |
| B9 | 大部分准确，已修复可兼容部分 | 恢复闪点 `×1.5`、归一化、0.08/0.015 阈值、空气透视和核心→边缘双色彩晕；继续使用贴合曲面且只向水内展开的弯曲带，不恢复会越出水面的完整椭圆。 |

## 参数回退

- `GLES_SURFACE_ALPHA_SCALE = 1.0`
- `GLES_SURFACE_WIDTH_SCALE = 1.0`
- `GLES_FEATHER_ALPHA_SCALE = 1.0`

这三项回到 Canvas 原值后，白带是否仍异常由修复后的真机画面判断，不再用迁移期间的合成错误反推
光带参数。

# FableSol HDR 前置 SDR 材质去雾基线

## 发布说明

### 本次目标

用户希望 FableSol 的水体更明亮、更晶莹，减少目前水面、波浪与光线偏冷、偏雾、过于柔和的
观感，同时明确要求保留远层偏白、透明和柔化形成的水层景深阶梯，不能让不同层级混在一起。
经逐项裁决，本轮作为 HDR 前的第一阶段，只调整共享 SDR 材质；不启用 HDR 额外亮度，便于把
“材质更通透”与后续“显示峰值更高”分开验收。

### 原因与隔离边界

- 代码审计确认原画面同时叠加九层 `body light`、前五层最宽约 23dp 的 `thin glow`、前三层
  `crest veil`、连续表面带及闪点宽 `analytic halo`，多组低频柔光累计后会降低局部对比。
- 原高光还存在固定 165°/220°/150° 派生目标、约 ±6° 周期色相摆动和约 +3° 固定偏移，
  会让 Thing 身份色之外的冷暖漂移持续出现。
- 本轮锁定 environment top/horizon/bottom、`environment_tint=0.16`、`lighten_far=0.60`、
  九层 alpha、远层 edge feather、`back_shade_gain=0.80`、水面几何、声音映射和倾斜动画。
- “整体更亮”按局部峰值与主观晶亮感解释；不抬高水体基色补偿宽光损失，也不额外压暗阴影。

### 材质与颜色改动

- `FableSolParams` 将 `body_light_strength` 从 0.36 归零，取消九层独立体光；
  `thin_glow_gain` 从 0.55 调为 0.38，`crest_veil_strength` 从 0.32 调为 0.14。
- 新增 `FableSolMaterialPolicy`：连续表面反射最大宽度由约 16.7dp 收至 9.4dp；薄峰透射最大宽度
  由约 23dp 收至 11dp。
- 闪点 `analytic_halo_strength` 从 0.21 调为 0.10，外围几何由核心厚度约 4.2 倍收至 2.25 倍、
  长度比例收至 1.18，`optical.frag` 的解析衰减从 `-4.6` 收紧为 `-6.5`。
- 镜面闪点容量由近层 3/中层 2 调为近层 4/中层 3，最小间距由 46dp 调为 34dp，并覆盖第 0～5
  层；用更多窄片段增加覆盖，不扩宽单个光晕、不把整段浪峰画成白线。
- 新增 `FableSolOpticalColorPolicy`。高光、薄峰透射与轻纱只沿 Thing 身份色到中性白的 OKLab 轴
  改变；移除固定目标色、周期摆色和固定色相偏移。深水/次表面色继续改变明度和彩度，但不再主动
  向蓝色或绿色旋转。
- `FableSolGlOptics` 与 Canvas 故障回退同步使用同一材质宽度、色彩和闪点容量策略；顺流流光仍是
  原有 SDR 运动线索，不获得新的亮度或生命周期行为。

### 本地验证

- 新增并更新材质能量、Thing 色到中性白轴、深度色相、闪点容量、宽光删除与 shader 契约回归。
- 完整 `:app:testDebugUnitTest`：96 项通过，0 失败。
- `environment.frag`、`water.vert/frag`、`optical.vert/frag`、`present.frag` 等 7 个共享 GLSL 已通过
  `glslangValidator` 离线编译。
- `:app:assembleDebug`：通过。
- 本版仍为 RGBA8 SDR，不包含 FP16/scRGB，也不生成任何 `>1.0` HDR excess。
- 未使用 adb、模拟器或物理设备。

### 真机重点确认

- 近、中层水体是否明显减少泛白和宽雾，同时没有变暗、变脏或出现硬描边。
- 远层仍应保持更白、更透明、更柔和的景深阶梯，相邻水层不能混在一起。
- 高光片段应比上一版稍多，但单个闪点外围更窄，不能出现连续白线或发光拖尾。
- 纯色与渐变 Thing 的水体、波峰、透射和流光应保持原身份色，不再周期性偏青、偏蓝或偏暖。
- 声音响应、波形、重力倾斜、准备/录音态淡入淡出、SurfaceView 圆角和控件层级应保持不变。

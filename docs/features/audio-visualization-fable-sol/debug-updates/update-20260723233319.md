## HDR 亮度强度交给你了：滑杆 1.0～7.5，默认档观感不变（D204）

本版只动 HDR 一件事，水体形态、浪形、流速、巨浪与昨天的收顶改动全部原样。

### 改了什么

设置里调参界面的「HDR 高光增强」从开/关复选框换成了强度滑杆：

- **范围 1.0～7.5**，步长 0.05。**1.0 = 完全关闭**（等于旧开关的取消勾选），
  **3.6 = 老的固定档**（默认值，不动滑杆的话这一版和上一版逐帧一致），7.5 = 上限。
- 之前如果关了 HDR，升级后自动迁移为 1.0；开着的迁移为 3.6，都不用重新设。
- 拖动立即生效（录音中、冻结预览里都行），松手才落盘。

### 强度是怎么作用的

滑杆缩放的是每个高光效果**超出参考白的部分**，不是把画面整体乘亮：

- 受控对象：闪点核心、波峰银边太阳段与顶点闪光、水面迎光薄处的背光透射、
  体光肩部。九层之间的强弱比例在任何档位都保持不变，往下拉是所有超白一起
  均匀变淡、到 1.0 精确归零；往上拉同理一起变强。
- SDR 部分（水体颜色、阶梯、阴影）在任何档位都完全不变。
- 实际能亮多少仍受屏幕当刻余量限制：屏幕亮度开得越高，系统给的 HDR 余量越少。
  设了 7.5 不代表一定能到 7.5——中低亮度环境下才能完整兑现，这是显示物理不是 bug。

### 本版看什么

1. **默认不动滑杆时应与上一版无任何区别**。有区别请直接报，那就是回归。
2. **拉到 1.0**：录音时所有超白高光应完全消失，只剩 SDR 画面。
3. **往上拉（比如 5.0～7.5）**：闪点、银边应明显更亮更晶莹。重点看迎光薄处的
   大面积透光会不会开始显得「泛白过曝」——如果高档位下面积发白让你不适，
   告诉我档位数，我单独把透射压一档（点状高光不动）。
4. 可以在不同屏幕亮度下各试一次：高亮度下高档位和默认档可能几乎没区别（余量
   被系统收走了），这是预期行为。

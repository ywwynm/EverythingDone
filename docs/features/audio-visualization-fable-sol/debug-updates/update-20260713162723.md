# FableSol FP16/scRGB HDR 真机验证版

## 发布说明

### 本次目标

用户希望 FableSol 整体更明亮、水体更晶莹，同时减少水面、波浪与光线偏冷、
偏雾和过于柔和的观感。上一个 Debug `202607130749` 已先完成共享 SDR 材质基线，
用户真机确认方向没有问题后，本版只增加第二阶段 HDR 显示峰值，不再改环境、
水体基色、阴影、水层 alpha、远层羽化或波形。

### HDR 输出链路

- `WaveVisualizerFableSolGl` 继续使用已验收的统一 `SurfaceView`；录音状态切换不重建
  surface，Dialog Window 也不切换 color mode。
- API 34+ 只在当前显示器同时报告 HDR 与可用 `hdrSdrRatio` 时尝试 HDR；
  API 26～33 和普通 SDR 屏仍走原 SDR 输出。
- `FableSolEglSession` 要求 `EGL_EXT_pixel_format_float`、`EGL_KHR_gl_colorspace` 和
  `EGL_EXT_gl_colorspace_scrgb_linear`，建立 float component EGL config 与 linear scRGB
  window surface。任一 EGL 能力、context 或 surface 建立失败，立即在同一视图上回退
  RGBA8 SDR。
- HDR 场景在 `GL_RGBA16F` framebuffer 内以线性值合成，再以 linear scRGB 输出；
  若当前 GPU 不能把 RGBA16F 作为 color-renderable target，会取消超白增量并自动回退
  SDR scene target，不让录音水体失效。
- API 35+ 在 RECORDING 且 HDR 链路已就绪时，仅为 FableSol `SurfaceView` 请求最多
  `2.0×` desired HDR headroom。PREPARED/STOPPED 不生成额外亮度。

### 亮度分配与视觉边界

- 录音开始/停止通过 `FableSolHdrTransition` 以 0.36 秒平滑收放 HDR 增益；显示器
  实际 headroom 下降时则立即收紧，不短暂越过当前屏幕上限。
- 镜面闪点核心：近层目标峰值 `1.75～2.0×`，中层递减到 `1.2～1.5×`，
  第 6～8 层回到 SDR。最亮核心趋近中性白，但仍保留轻微 Thing 色倾向，不统一偏青。
- 受光窄浪峰/表面反射：使用约 `1.08～1.4×` 的更广但仍局部的峰值，保留 Thing
  色相；通过几何朝向与峰尖条件控制，不扩宽环绕柔光。
- 薄峰透射：仅最近几层分配约 `1.05～1.2×`，作为晶莹感的小比例辅助。
- 顺流流光、解析光晕、轻纱、阴影、环境和远层始终保持 SDR。不用音量、onset 或
  beat 直接乘 HDR 峰值，也不加入 tone mapping、soft shoulder、全局曝光或全局压暗。
- SDR 路径从源头把可用 headroom 设为 `1.0`，不先生成超白值再压回 SDR，因此上一版
  已确认的材质明暗与远近层级应保持不变。

### 诊断与自动回退

Debug 版会把 HDR 链路状态写入 `debug_logs/fablesol_hdr.log`，包含 HDR 是否激活、
EGL/scRGB 能力或回退原因、录音态开关和显示器 `hdrSdrRatio` 变化。能力不成立时应继续显示
与上一版一致的 SDR 水体，不应出现红屏、空白或闪烁。

### 本地验证

- 新增 HDR 能力、分层峰值、headroom 上升/下降、录音状态过渡、EGL 建链/回退、
  renderer 与光学 eligibility 回归。
- 完整 `:app:testDebugUnitTest`：106 项通过，0 失败。
- `environment`、`water`、`optical` 和 `present` 四组 vertex/fragment 程序通过
  `glslangValidator` 链接。
- `:app:assembleDebug`：通过；APK 已确认包含 `environment.frag`、`water.vert/frag`、
  `optical.vert/frag` 与 `present.frag`。
- `git diff --check`：通过。未使用 adb、模拟器或物理设备。

### 真机重点确认

- 正在录音时，近层闪点核心是否有明确高于普通白色的峰值，水体是否更晶亮，而不是
  整体水面更白。
- 受光浪峰的 HDR 覆盖应比极少闪点稍多，但仍为窄片段，不得变成连续发光白线或宽雾带。
- 第 3～5 层的峰值应比近层低，第 6～8 层仍依靠偏白、透明、柔化区分距离；不同层不能混在一起。
- 最亮核心可以接近中性白，但水面、浪峰、透射与流光不应偏成统一青白或蓝白。
- PREPARED/STOPPED 应与 SDR 基线一致；RECORDING 的 HDR 收放应平滑，无 surface 重建闪烁、
  控件遮挡异常、圆角漏边或弹窗生命周期问题。

# FableSol 去灰蒙蒙：水层改为不透明 + 直接混白

## 本轮更新

用户用纯色记事 AE6060=(174,96,96) 实测：最下层水体 A55659=(165,86,89)，整片"低饱和灰蒙蒙"。
用真实颜色数学逐 band 复现定位到根：**不是掉饱和，是透明度**。半透明水层让环境色（纯白 dialog
背景 / 深主题背景）从底下透上来，把远层从饱满色拖成灰——实测远层饱和度 S 从 ~35 塌到 ~27，明度被
推到 L86 近白。近/中层层数多盖住环境所以干净，远层层数少、透得最厉害。

按用户方向重做（保持九层、远处更白、去掉透明度）：**每层不透明（alpha 全 = 1.0），颜色纯由
lighten_far 直接混白确定**。这样每个 band = 该层纯混白色、无环境透入：近层严格 = 记事色，远层是
干净的偏白记事色，S 不塌。去掉透明度后远层少了"环境透入的白"，把 `lighten_far` 0.6→0.75 补回，
远层 L86→L88（比原来更白且干净）。环境/天空层完全不动，不碰计时器那片。

不透明下逐层（记事 AE6060）：近 L0=(174,96,96)L53 → L2 L62 → L4 L71 → L6 L79 → 远 L8 L88，
S 全程 33-40，平滑九层近→远淡出。

真机看：整片是否干净的玫瑰色渐变、近层是否严格贴记事色、远处白度是否满意（不够白就再提 lighten_far）。

## 实现内容

- `FableSolParams.kt`：`alpha` 层参数从 `[1.0,0.84…0.68]` 改为全 `1.0`（不透明）；
  `lighten_far` 0.6→0.75。
- `FableSolMaterialPolicyTest`：`lighten_far` 断言 0.60→0.75。
- 删除本轮临时诊断测试 `FableSolCompositeDiagnosticTest`。

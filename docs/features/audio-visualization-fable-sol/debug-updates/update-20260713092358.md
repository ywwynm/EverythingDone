# 修复 FableSol GLES 迁移差异并恢复 Canvas 光带参数

## 用户可见变化

- 表面软带宽度、透明度与最远两层羽化亮度恢复 Canvas 原始数值。
- 修复水体整体偏暗、浑浊、渐变记事配色偏移和天空色阶问题。
- 补回体积光带、波冠轻纱、Fresnel 闪点、1/f 呼吸和双色彩晕。
- 修复光学软边在亮背景上发白、透色的问题。
- 修复录音框打开时退后台再返回可能变成红色回退画面且无法恢复的问题。

## 技术说明

- EGL/GL 资源释放时同步失效 EBO 列数缓存，确保同尺寸重建重新上传索引。
- 水体纵向受光恢复 Canvas 的相对 `b+f-r` 与背光基色约束。
- 渐变改用每层包围盒参考系和四个 OKLab 派生停靠点。
- 天空与前景填充恢复 Canvas 强度的三角抖动，连续水体不额外抖动。
- 光学绘制改为 RGB source-over、alpha 保持的分离混合。
- 迁移九层 body light、近三层 crest veil，并补齐闪点/流光细节。
- 73 项单元测试与 Debug 构建通过；APK 已确认包含更新后的共享 GLSL；未使用 adb。

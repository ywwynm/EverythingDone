## 七项水面与音画参数默认值调整

### 用户要求

用户按 Android 设置名称重新指定七项默认值，并要求 Python 蓝本同步：

- 相机仰角：`36°`
- 波背自阴影：`0.84`
- 主浪增强时间：`0.84s`
- 背景小浪强度：`0.54`
- 水位上升预平滑：`0.54s`
- 涨落攻击：`0.36s`
- 响度瞬态加成：`0.21`

### 实现

- Android `FableSolParams.kt` 中的 `surface_view_elev_deg`、`back_shade_gain`、
  `hero_attack_s`、`ambient_gain`、`swell_presmooth_s`、`swell_attack_s` 和
  `relative_loudness_mix` 已更新为上述数值。
- “响度瞬态加成”还有声音分析器的独立初始化入口，因此
  `FableSolPerceptualCalibrator.DEFAULT_RELATIVE_MIX` 也从 `0.20` 更新为 `0.21`，
  `FableSolFrontEndTuning` 与实时分析器由此使用同一默认值。
- Python `src/wavesim/params.py` 与 `src/wavesim/audio/calibration.py` 同步采用完全相同的
  七项默认值。
- 本轮只调整默认值，没有修改参数键、设置分组、取值范围、步长或消费者公式；已有 Android
  SharedPreferences 与 Python JSON 预设仍按原机制覆盖默认值，不强制重置用户配置。

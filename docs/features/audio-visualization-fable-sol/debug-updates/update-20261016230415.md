## 修正卓易通 HDR 海浪区域穿透（2026-10-16）

用户反馈上一版开启 HDR 后，海浪区域变成半透明，能看到弹窗后面的内容；强度 0、画面稳定后正常。本次仅调整卓易通音频海浪输出，作为待设备复验的修正候选。

- PQ 窗口由 RGB10_A2 改为带完整 8 位 alpha 的 RGBA8，保留圆角、内部 FP16 场景和 HDR 高光范围。实际创建时同时检查配置、窗口缓冲通道和 PQ 色彩空间；失败退回 SDR。
- 颜色编码精度从 10 位降到 8 位，最终 PQ 输出增加共通道抖动以抑制色带，白色和灰色不额外引入彩色噪声。准备态继续与弹窗底色混合，区域内部应保持不透明。
- HDR 和 SDR 即使使用同一种像素格式，也显式重建颜色会话，确保强度 0 真正关闭 HDR。保留先提交静止遮盖、目标会话交出首帧后撤盖的流程；补上渲染循环恢复、冻结时补帧及过期状态回调保护。
- 粒子与切换遮盖继续使用显式 sRGB 快照。其它设备的 SDR／scRGB、图片 PQ 和视频导出路径保持。
- debug 构建成功；980 项相关 JVM 测试中 979 项通过，1 项既有按需探针跳过。实际 shader 离屏验证中，48 组原 SDR／scRGB 输出逐像素一致，24 组后景合成的内部 alpha 始终为 1；圆角、中性颜色和快照检查通过。
- 桌面验证不能代替卓易通合成器；本轮未操作设备。请复查海浪后景穿透、HDR 高光、白色按钮和粒子颜色、圆角与色带，以及强度往返 0 档是否闪烁。

## 2026-10-17 11:31:04 卓易通 HDR 黑角：增加三组图层对照

上一版 C／J／K 仍有黑角，新日志已确认 K 的四角窗口缓冲为透明。本次按用户要求增加结构对照，保留 C 的系统暗层与文件导出，不把透明采样当作屏幕问题已修复。

- L「无独立 Surface」：用普通 Canvas 显示静态 SDR 图，完全不创建 SurfaceView／EGL；此项没有 HDR 属于预期。
- M「C＋去阴影」：保留原 PQ 固定图，关闭窗口及 Decor／面板祖先的阴影，日志核对实际 elevation／translationZ。
- N「直接 SurfaceControl」：仅用公开 API 创建 RGBA8、非 opaque 图层，复用原 PQ／EGL 与同一固定图绘制；记录创建、坐标、实际 PQ 输出、首帧、事务提交、透明区域及资源释放。创建失败或超时会明确提示，仍可导出日志。请额外观察左侧原生白圈是否被覆盖。
- 默认进入 C／模式 2，建议按 C→L→M→N 分别记录「圆角正常／仍有黑角」。进入或离开新三项会重新创建窗口，避免旧图层残留影响结论。A～K、原海浪模式及保存到下载／分享日志入口保留。

代码仅位于 debug 测试页和三个诊断辅助类；正式录音、音频附件、设置弹窗、粒子动画、PQ 着色器及其它设备路径不变。构建与 50 项相关 JVM 回归通过，固定图 GL 绘制主体与旧版核对一致；未连接物理设备或模拟器，最终黑角及图层效果仍待卓易通实机复验。

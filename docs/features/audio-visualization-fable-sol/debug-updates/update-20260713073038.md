# 分离校准表面软带与最远两层羽化

## 用户可见变化

- 表面软带比上一版略宽，但明显更加透明。
- 最远两层上方此前几乎未变化的白色羽化带显著淡化。
- 薄峰透光、波背阴影、镜面闪点和顺流流光保持不变。

## 技术说明

- 表面软带宽度由 Canvas 的 52% 回调为 62%，峰值透明度由 48% 降为 34%。
- 最远两层使用独立的 `edge feather` 通道；保持其柔化宽度，将 alpha 缩放到原值的 30%。
- 新增远层羽化实际顶点 alpha 回归，并同步更新表面软带宽度/透明度回归。
- 完整单元测试与 Debug 构建通过；未使用 adb。

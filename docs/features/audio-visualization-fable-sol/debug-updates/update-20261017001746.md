## 卓易通 HDR：记录真实弹窗状态，增加实际海浪合成对照

上一版固定图的 SDR／透明 PQ／不透明 PQ／前置 PQ 都没有穿透，模式 1、2、3 均有黑角；PQ 下普通控件白不如画面内白。用户确认同版实际录音与海浪设置弹窗仍穿透、偏青，因此本版继续补充复现条件，尚未修改正式 HDR 渲染方案。

- 保留原入口：设置 → 音频海浪动画 → 长按“HDR 高光增强”。进入前先记录真实设置弹窗仍在前台时的窗口格式、颜色模式、alpha、暗层及祖先 View 的位置、尺寸、裁剪状态。
- 测试页可切“普通弹窗／实际弹窗结构”。后者使用与实际功能相同的 BaseDialogFragment 和应用暗层；相同固定画面可用于比较窗口结构。
- 增加模式 5“海浪 SDR”和模式 6“海浪 PQ”，直接使用正式海浪渲染器；另有准备态／录音态呈现、冻结／继续开关。不采集音频，不修改持久化设置。
- 日志仍可直接保存到“下载/EverythingDone”或分享 `.txt` 文件，并附带最近的正式海浪 HDR 数值日志。正式日志可能包含此前弹窗，按时间戳区分。

建议在“实际弹窗结构”下依次比较模式 2、6、5，分别记录是否能看到后方文字、白圈是否偏青；若模式 6 复现，再检查冻结后是否仍然出现。无需重复上一版的不透明／前置模式。测试页海浪模式没有右侧固定白圈。

改动限定在 debug 诊断 Activity 和既有卓易通 debug 长按入口。正式 shader、Surface 格式及其它设备路径保持原样。debug 构建与 19 项 HDR 策略回归通过；未连接设备，实屏效果仍待验证。

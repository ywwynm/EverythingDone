## 修正卓易通音频弹窗偏色与 HDR 关闭状态（2026-10-16）

用户在上一版中反馈：录音、音频附件和海浪设置弹窗的粒子动画白底偏青绿色，录音按钮在关闭粒子动画后仍偏色，弹窗外正常；HDR 强度拉到 0 后仍有相同问题。核对确认关闭档只收回了高光，却仍保留 PQ Surface；白色在应用 shader 中的 RGB 则没有偏移，实际合成与截图转换需要分别处理。

- 仅卓易通的屏幕输出从 FP16 PQ 改为图片方案使用的精确 RGB10_A2 PQ，内部线性场景及颜色公式保持。该变更针对浮点 PQ 与普通控件混合的兼容问题，是否消除本机偏色仍需实测。
- 粒子源图和换格式遮盖由海浪渲染器直接生成 sRGB 快照，避免依赖卓易通的 PQ PixelCopy 色彩转换；原有按钮、文字、阴影和粒子轨迹保持。普通设备及其它 SurfaceView 继续原捕获路径。
- HDR 强度 0 现在完整退回 RGBA8／SDR，恢复 1 倍 headroom；主动关闭不再被误判为能力失败，重新打开仍可用，保存 0 后下次打开直接使用 SDR。
- 开关跨越关闭档时，先提交遮盖，再更换格式，目标会话真正交出首帧后撤盖；连续拖动合并到最新强度，防止旧帧或迟到截图抢先覆盖。普通 Android 的原切换顺序保留。
- 圆角沿用原几何；RGB10_A2 只有四档透明度，先量化覆盖率再预乘，防止透明像素残留颜色造成亮边。sRGB 快照保留完整 8 位 alpha，实际屏幕圆角细节仍需检查。
- debug 构建成功；979 项相关 JVM 回归中 978 项通过，1 项既有按需 CPU 性能探针跳过，无失败。实际 GPU 对照包含原 SDR／scRGB 的 48 组逐像素一致、24 组 PQ 公式、8 组中性灰、2 组整数缓冲圆角和 42 组 sRGB 快照颜色。未连接或操作设备；请复查粒子打开／关闭、静止录音按钮、强度 0 和快速往返切换。

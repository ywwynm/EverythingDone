# FableSol Step A：打光法线统一到真连续水面

## 本轮更新

把水面打光的法线从"只跟随二维方向翻滚"改为**来自真正被渲染出来的连续水面**（各层波形轮廓 +
二维方向场），让高光与明暗第一次贴着你看得见的波峰走，而不再与波形错位。同时把九层之间的纵深
过渡由线性改为 Catmull-Rom 平滑，消除层与层交界处可能出现的横向接缝。

这是"光照相干化与 HDR 存在感"计划的第一步（地基），只改打光所依据的水面形状，未改变颜色身份、
波形、音频响应、HDR 峰值或分层景深；SDR/HDR 输出语义不变。真机重点观察：光是否贴着波峰走、
层交界处（纵向每约三行）有无横向亮暗接缝、倾斜与发热是否正常。

## 实现内容

- `FableSolContinuousSurface.sample()`：先合成真渲染面 `worldEta`（各层轮廓 + 二维方向场），
  再从 `worldEta` 求 `slopeX/slopeZ`；此前坡度只来自二维方向场 `eta`，不含各层波形。
- `FableSolContinuousSurface.composeLayerField()`：跨层插值由线性改 Catmull-Rom，锚点行仍精确
  穿过各层自身轮廓（分层语义不变），仅消除层锚点处的坡度跳变。
- 行间 Catmull-Rom 权重按固定 `z01[r]` 在 `init` 预计算，稳态零分配。
- shader、renderer、optical 光学实体均未改动。

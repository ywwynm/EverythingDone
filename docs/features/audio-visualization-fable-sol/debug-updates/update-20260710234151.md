## 发布说明

### 用户反馈

- 打开录音 Dialog 后，即使环境安静，FableSol 水位也会先升高、随后回落。
- `20260710231609.wav` 约第 7 秒的拖鞋拍地声会让多层已形成的浪生硬改形。
- 已形成的浪只能因物理传播、重力、阻尼、边界或新注入能量自然变化；Python 和 Android 必须同步。

### 诊断

- WAV 前 0~3 秒的 PCM 实际约为 −20~−23dBFS，约 70%~90% 的 A 加权能量位于 250Hz 以下，
  约 4.5 秒后才降至 −55dBFS 以下，不是 Analyzer 凭空抬高。
- 应用当前显式关闭 AGC/NS/AEC，仅凭 WAV 无法确定是 HAL/硬件启动暂态还是机械低频。
- 拍击 onset 位于约 6.30、6.76、7.15、7.26 秒。旧 onset 会直接改写全层 HeroWave punch；
  高频模态攻击最低约 61ms，禁用物理注入后仍会重塑既有轮廓。

### 修改

- Android Analyzer 增加采集会话启动预热门：稳定静音或可信非低频内容持续 0.3 秒即可开放，
  最长 4.5 秒；低频暂态不进入视觉校准和 onset。该门不修改保存的 WAV。
- Python 与 Kotlin 同步取消 onset 对 HeroWave 振幅/频段模态的直接改写；快速事件只注入 DynamicWave。
- 历史兼容的 `hero_punch` 增益默认归零，防止旧调用重新激活全屏直接塑形。
- HeroWave 默认攻击由 0.16 秒改为 0.85 秒，各模态最短约 0.72 秒。
- 几何粗糙度使用 1.2 秒慢状态；快速材质变化只影响光学毛细纹与高光。
- 演示模式同样改用物理注入，不再直接触发 HeroWave punch。

### 验证

- 实际 WAV 的 Kotlin 回放中，前 4 秒最大视觉响度为 0、onset 为 0。
- 禁用物理注入时，onset 造成的既有轮廓变化由最高约 0.56dp RMS 降为严格 0。
- 极端频段目标的单帧轮廓变化由约 3.97dp RMS 降至约 0.39dp RMS。

## 已成形浪形稳定调节与两端设置重组

### 用户反馈与诊断

- 用户反馈：已经生成的波浪仍会持续改变轮廓，即使把临时诊断开关全部关闭也没有改善。
- 复查确认临时开关本身曾因音频加载时恢复 checkpoint、替换 `ShapeDiagnostics` 对象而失联；
  修复后，面板始终操作当前模拟实例，并让连续水面引用同一个诊断对象。
- 开关恢复有效后，用户目测确认环境波和二维方向谱是轮廓持续形变的主要来源，但完全关闭二者
  会使画面过于单调。

### 浪形稳定参数

- Python 新增并正式保留 `ambient_shape_stability`、`surface_spectrum_gain`、
  `surface_spectrum_audio_response`、`surface_shape_stability`。
- 环境波稳定度把不同模态的相速连续混合到共同水平输运；斜向浪稳定度以相同思路减少九个
  方向谱模态之间的相对滑动。取值为 `0` 时保持原有色散推进，向 `1` 调节时轮廓更接近整体
  平移，但仍保留波面细节。
- 斜向浪强度只控制二维方向谱几何幅度；斜向浪音乐响应只控制三个音乐能量波段对谱振幅的
  调制，不会关闭微法线、材质或其它水面细节。
- 用户目测选定的正式默认值为：背景小浪强度 `0.42`、小浪强弱变化 `0.27`、
  小浪形状稳定 `0.00`、斜向浪强度 `0.96`、斜向浪音乐响应 `0.25`、
  斜向浪形状稳定 `0.00`。Python 与 Android 已统一使用这组默认值。

### 设置目录与名称

- Python 和 Android 均新增正式“浪形”组；Android 中该组紧跟在“连续水面”之后。
- “浪形”集中 15 项直接影响轮廓的设置，按主浪、背景小浪、斜向浪和边缘组织。原“主浪”
  独立组取消；“连续水面”只保留观察角度；流速、漂移、倾斜和节拍仍属于“环境与流动”。
- 设置名称改为简短的影响导向文本，包括“主浪高度”“主浪宽度”“背景小浪强度”
  “小浪形状稳定”“斜向浪强度”“斜向浪音乐响应”“远浪消散距离”和“边缘反弹柔和”等。
- Android 的 13 套 `strings.xml` 语言资源已同步更新。

### Android 移植

- `FableSolParams.kt` 增加四项正式参数并同步六项默认值。
- `FableSolWaveSets.kt` 与 `FableSolSimulation.kt` 接入环境波共同输运稳定算法。
- `FableSolContinuousSurface.kt` 接入斜向浪强度、音乐响应和共同输运稳定算法。
- `FableSolTuning.kt` 完成“浪形”目录重组，并保证该组直接位于“连续水面”之后。
- 新增目录完整性、默认值、刚性平移、强度/音乐响应和共同输运回归，确保设置项确实影响
  Android 产品计算，而不只是显示在设置界面。

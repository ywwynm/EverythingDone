# FableSol 恢复 lighten_far 混白并清理中远层圆环光斑

根据真机复测，本版撤销上一轮固定 hue 的亮向色域阶梯：它虽然减轻了第二、第三层乳白，却让
水体显得灰暗、发脏，层级分界也不如旧方案。中远层新增的周期扩张/收缩光斑同样过密，影响了
整体观感。

本版完成以下调整：

- 九层主体恢复静态 `lighten_far`：第 0 层保持记事身份色，第 1～8 层在 OKLab 中按深度混向
  白色，最远层最多混白 `86.4%`。纯色与渐变的四个停靠点使用同一公式，不再进行逐色分支、
  固定 hue 色域贴边、相邻 ΔE 重分配或第二/第三层特殊压暗。
- 录音、HDR、mood 和 color breath 不再改变主体色板，避免点击开始录音时第二、第三层整体
  跳亮。界面肩全部关闭，由主体混白阶梯直接承担九层分界，不再产生记事色粗边。
- 离散闪点仅保留最近三层，容量为 `3/2/1`；第 4～9 层不再生成离散光斑。删除闪点的周期尺寸
  呼吸、强度尺寸耦合和解析圆环外晕，连续太阳反射也只保留最近三层，权重为
  `.72/.49/.21`。
- 将折射与 Beer–Lambert 的背景混合上限从 `.049` 收到 `.016`，保留非零折射和体积吸收，
  同时减少它们对第二、第三层主体色的洗灰。18 色离屏消融中，两层跨颜色中位色度保留率约为
  `98.2%/96.0%`，没有出现整体压暗。

验证结果：18 组真实/内置颜色共 648 个渐变停靠点逐码符合静态 `lighten_far` 公式；180 帧动态
回归的闪点数量为 `3/2/1/0/0/0/0/0/0`，第 4～9 层的 `full - no_glint` 图像差严格为零。
Python 149 项 unittest、Android 全量 Debug JVM 测试及 `:app:assembleDebug` 全部通过，两个仓库
的 `git diff --check` 均无错误。未使用 ADB；最终 HDR 运动观感留给 Android 真机验收。

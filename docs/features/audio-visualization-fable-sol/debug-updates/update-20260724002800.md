## 恢复默认按钮现在会一并恢复 HDR 强度（D204 修订）

上一版你反馈的问题：调参界面点「恢复默认」，HDR 强度滑杆不动。本版只修这一件事。

### 为什么会这样

这不是新滑杆引入的 bug——从 HDR 还是开/关复选框的年代起，恢复默认就被刻意设计成
「只重置参数、保留 HDR 设置」。强度化时我沿用了这条老约定。按你的反馈，这条约定废止。

### 现在的行为

- 点「恢复默认」：所有参数回默认值，**HDR 强度同时回默认档 3.6**，滑杆跳回对应
  档位、显示 3.60×，预览立即按默认强度渲染。
- 持久化里的强度记录（含旧版开关的迁移残留）一并清空，下次打开录音界面也是默认档。

### 本版看什么

1. 把 HDR 拉到任意档位（比如 1.0 或 7.5），点恢复默认：滑杆应回 3.6，预览高光
   立即回默认观感。
2. 其余与上一版 `202607231534` 完全相同；那一版的验收点（默认档观感不变、1.0 全关、
   高档位面积透光是否泛白、不同亮度下的余量表现）如果还没看，这一版一起看即可。

出问题回滚上一版 `202607231534`。

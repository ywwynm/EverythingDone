# FableSol Stage 2-1 色相保持高光压缩

## 用户可见变化

- 接近白色的闪点、薄纱和亮带高光不再直接顶到纯白，而是平滑收束。
- 普通记事色、中间亮度水体和低亮饱和颜色保持 Stage 1 原样。
- 本轮不改变散射、微法线、光学实体形状或水体运动。

## 技术说明

- 新增 RGBA8 离屏场景纹理与最终 fullscreen pass。
- 采用 Khronos PBR Neutral 的 `F90=0.04`、`Ks=0.76`、`Kd=0.15` 高光曲线。
- 正确执行 sRGB→linear→tone map→sRGB；线性最大通道不超过 0.76 时严格恒等。
- 新增独立参数 `pbr_neutral_strength=1.0`，可整项关闭。
- 离屏目标尺寸缓存随 EGL/GL 资源释放失效，避免同尺寸重建跳过分配。
- 79 项单元测试与 Debug 构建通过；APK 已确认包含 `tone_map.frag`；未使用 adb。

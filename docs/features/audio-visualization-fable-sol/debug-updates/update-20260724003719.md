## HDR 强度上限提到 9.6（D204 修订二）

按你的要求，HDR 强度滑杆上限从 7.5 提到 **9.6**。本版只动这一件事。

### 具体变化

- 滑杆范围 1.0～9.6，步长 0.05 不变；1.0=关闭、3.6=默认档的语义不变，
  你已保存的强度设置原样有效，不用重设。
- 顶格 9.6 时：闪点核心、银边太阳段的峰值可到参考白的 9.6 倍；迎光薄处的
  背光透射预算也随之增大（约为 7.5 档的 1.32 倍）。
- 实际能亮多少仍受屏幕当刻余量限制：9.6 属于只有低亮度、大余量场景才可能
  完整兑现的档位，高亮度下和低档位几乎无区别，这是显示物理不是 bug。

### 本版看什么

1. 拉到 9.6：低屏幕亮度环境下闪点与银边应比 7.5 更亮更刺一点；重点仍是
   迎光薄处的**大面积透光会不会泛白过曝**——预算比 7.5 档又大了三成，如果
   高档位下面积发白让你不适，告诉我档位数，我单独把透射压一档（点状高光不动）。
2. 默认 3.6 与中低档位应与上一版 `202607231628` 完全一致。

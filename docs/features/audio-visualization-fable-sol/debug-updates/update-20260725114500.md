# FableSol 调参更新 2026-07-25

## 银丝不再断断续续，上边缘的黑点消失

- 定位到银丝"断断续续 + 上边缘偏黑像素"的根因：银丝的亮芯此前正好画在每层水面轮廓那一行像素上，而这一行同时是水体边缘抗锯齿的软过渡中心和层带几何的边界，两者相乘把亮芯削到约四分之一；更糟的是削多少取决于轮廓落在像素中心还是像素边界，实测同一条银丝的逐列亮度因此在 2.5 倍之间来回振荡（第 0 层 0.148↔0.363、第 1 层 0.359↔0.892）。轮廓沿横向缓慢漂移，这个相位周期性扫过一遍，就成了肉眼看到的忽明忽灭；灭掉的那几列露出下方较暗的水体色，紧挨着超白亮段就读作黑点。
- 修复把亮芯整体向水体内侧移出这条过渡带，外侧改为平滑衰减而不再钳在峰值，另外用轮廓法向的真实垂直距离取代原先会随坡度高估 √2 倍的近似，并给窄于一像素的亮芯做像素积分（细线变淡而不是变断）。
- 实测：亮度与像素栅格相位的相关性从 −0.548 降到 −0.154，逐列峰值离散从 5.4 倍收到 3.5 倍；沿线**最亮处只提高约 12%**，中位亮度 +35%——补的是原先的缺口，不是整体提亮。粗细度拉到最小档（0.16dp）时改善最明显，拉到最粗档（2.0dp）时基本不变，因为粗银丝原本就没有这个问题。
- 银丝强度、光晕、峰值亮度、滑动等所有滑杆与默认值都没有改动；若修复后觉得银丝偏亮，可在调参对话框下调"波峰银边强度"。
- 波背暗带、闪点、星芒、九层水体边界与其它特效全部未动。

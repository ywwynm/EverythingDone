# FableSol 第二轮晶莹水体：九层分界、连续海面高光、折射与体积吸收

用户复测上一版后指出：九层边界变弱并偶发记事色粗边；跨层移动光影带有直线马赛克；最近三层
以外缺少闪点和材质变化；原有海面光斑、波光粼粼与局部 HDR 超白响应不足。用户同时提供 10 个
内置色与 8 组真实纯色/渐变，要求浅色不显脏、远层可偏白但不超过 86.4% 等效混白，并要求先在
Python HDR 离屏链调试、解决卡顿，再同步 Android，实机测试由用户完成。

本版完成以下更新：

- 九层主体改为固定 hue 的亮向 OKLCH 色域贴边阶梯，以八条相邻 ΔE 分配层距；第 0 层保持记事
  身份色，最远明度不超过 `L0+0.864×(1-L0)`。录音、mood 与 color breath 不再整体提亮主体。
  界面肩只补 8-bit 量化损失，移除会形成身份色粗描边的宽肩补偿。
- 连续水面改用 GGX/Trowbridge–Reitz、height-correlated Smith、Schlick Fresnel 与逐片元导数
  specular AA；SDR 反射、SSS 和同色阴影分别限能，HDR 只开放局部银泽、背光透射和闪点。
- 连续网格由 25 行提高到 97 行，降低三角形间直线/马赛克；闪点纵深跨度保持为每层三分之一。
  九层均有闪点容量，核心与解析光晕合并为一次 `6～32` 段曲面绘制，中远层微法线、SSS、银泽
  和透射按景深连续衰减，不再在最近三层后硬截止。
- Android 与 Python 均增加独立 `pre-water` 和 `scene` 离屏目标。水体从不可变背景纹理执行
  Snell 屏幕空间折射，并只对透射分瓣应用 Beer–Lambert；相对彩度与感知明度保护浅灰绿、浅粉、
  浅黄等颜色。任一 FP16 目标失败时，两张纹理原子回退到 RGBA8，不改写 EGL 输出颜色空间。
- Python 光学构建缓存精确的 8-bit RGB 色变换，色板改变即失效并设 65,536 色上限；高活动稳态
  保留 23 个闪点和 6 条流光，中位帧耗时为 15.52ms（约 64.4fps），P95 为 18.86ms。

验证结果：18 色 FP16 离屏回归的最弱相邻主体 ΔE 为 0.01365，中位数为 0.01973；全部夹具的
界面肩宽度为零；去掉离散闪点后仍有中位 0.442% 的局部超白覆盖。Python 151 项 unittest、
Android 149 项 JVM 测试和 `:app:assembleDebug` 全部通过，共享 GLSL 已由 ModernGL 实际编译。
未使用 ADB。真机请重点观察快速大浪的折射边缘、准备态/录音态第 1/2 层腹部亮度、浅色阴影
洁净度、九层动态分界和中远层碎光分布。

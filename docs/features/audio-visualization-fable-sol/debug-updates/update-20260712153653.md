# 将 FableSol 连续 2.5D 水面迁移到 Android

## 发布说明

本次把桌面模拟器最新的 FableSol 连续 2.5D 水面完整迁移到 Android：九层改为一张
25 行连续曲面的深度/颜色/声音角色锚点，新增远近方向传播、有限相干波包、Gerstner
X/Z 轨道、三维重力俯仰、纵向法线受光和连续 ribbon 遮挡；保留 ThingBackground
配色、第 0 层身份色、普通 onset 即时响应与完整光学链。新增回归测试，完整单测和
Debug 构建通过，未使用 adb；本版本重点等待真机确认运动方向、接缝、帧率与发热。

### 用户请求

`E:\projects\audioVisualizerSimulatorFable` 完成了一轮更新，用户要求把对应的
FableSol 代码与文档迁移到 Android 主项目。

### 蓝本核对

Android 已包含 2026-07-11 的表达、材质、画外出生和 AGSL 更新。本轮以模拟器最新提交
`be72b42` 之后尚未提交的连续水面工作区为蓝本，迁移范围为：25 行连续曲面、九层 Z 向
锚点、二维方向波谱、有限相干波包、Gerstner X/Z 轨道、前后俯仰惯性、连续 ribbon
遮挡、纵向法线受光和半正弦软带剖面。

### Android 改动

- 新增 `FableSolContinuousSurface.kt`：保留九层各自轮廓和声音角色，只叠加去除深度
  均值后的纵向翻滚；实现方向波谱、深水色散、有限相干波包、随波数增强的耗散、
  X/Z 轨道和欠阻尼俯仰。
- `FableSolSimulation` 接入二维场、前后俯仰、摇晃纵向分量和稀有远浪入口；
  `FableSolFeatureMapper` 仅让 incoming 远浪与段落事件注入纵向波包，普通 onset
  继续保留前景即时响应。
- `WaveVisualizerFableSol` 使用完整三维重力：屏幕内分量控制滚转，法向分量控制俯仰；
  默认把九层吸收到一张 25 行连续曲面，以远到近 ribbon 绘制，第一层作为唯一前景
  剪影。九层固定 alpha、ThingBackground 八向渐变、第 0 层身份色和完整锚线光学链保留。
- 相邻 ribbon 沿深度方向覆盖一个物理像素以抑制白缝；每帧缓存九层配色停靠点，避免
  在 24 条 ribbon 的横向采样中重复做大量 OKLab 转换。
- `FableSolAgsl` 的软带剖面改为连续半正弦，消除内部透明度平台并让两端归零。
- 旧九层完整填充路径保留为 `surface2d_on=0` 的内部回退，Android 默认启用连续路径。

### 测试与状态

- 新增 `FableSolContinuousSurfaceTest`，覆盖默认路径、九层锚点身份、共同横向波去重、
  纵向坡度有限性和俯仰惯性。
- `:app:testDebugUnitTest`：通过。
- `:app:assembleDebug`：通过。
- 未使用 adb、模拟器或物理设备；连续水面的运动、姿态、帧率和发热需由用户通过
  阿里云 Debug 版本真机确认。

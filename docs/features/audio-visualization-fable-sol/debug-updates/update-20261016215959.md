## 卓易通音频海浪启用 PQ HDR 兼容输出（2026-10-16）

用户反馈同一台卓易通设备已能显示图片 HDR，但音频海浪设置仍提示不支持 HDR。本次按授权只为现有卓易通环境增加兼容路径，重点保留圆角和开关连续性，普通设备继续使用原有 SDR／scRGB。

- 设置不再因卓易通缺失 HDR 能力和实时亮度比例的声明而直接禁用；实际创建 PQ、验证颜色空间、RGBA 位深及浮点渲染目标后使用，失败回退 SDR，并更新设置可用状态。
- 使用 FP16 PQ 保留完整圆角透明度，不套用图片的 2 位 alpha 缓冲。继续使用现有线性场景和全部海浪材质，仅在最终输出时做 BT.2020／PQ 转换，内容参考白为 203 尼特。
- 卓易通的 HDR 开关保持同一个 Surface，强度变化用 180 毫秒平滑过渡，关闭时收回超白内容；录音、播放和停止仍使用原有状态过渡，避免开关重建造成黑帧。普通设备的关闭档换格式与首帧遮盖逻辑保持。
- 系统无法报告亮度比例时，不再把默认 1 倍误当成实际屏幕限制；生成内容仍受用户强度上限约束，最终由系统映射。未修改音频分析、海浪模拟、配色或视频导出规则。
- debug 构建成功；583 项 FableSol 回归中 582 项通过，1 项既有按需 CPU 性能探针跳过，无失败。原 SDR／scRGB 的 48 组实际 shader 输出逐像素一致；24 组 PQ 输出与参考计算一致，圆角 alpha 与原输出一致、透明区域没有 RGB 残留。
- 本轮未操作设备。FP16 PQ 与此前图片已验证的 10 位 PQ 配置不同，实际 EGL／合成效果仍待卓易通实测；请重点检查设置预览、深浅配色的圆角、高光强度快速往返关闭档，以及录音／播放启停是否闪烁。

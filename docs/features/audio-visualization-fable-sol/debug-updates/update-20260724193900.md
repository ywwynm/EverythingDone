# FableSol Debug 更新

## 2026-07-24 - 波顶人眼眩光星芒（D206~D209 移植）

FableSol 音乐可视化新增波顶星芒：银丝最亮的镜面焦散点（太阳柱内的波峰
顶点）会绽出人眼眩光形态的星光——近核光轮 + 细针放射芒（竖直主导的黄金
角线表、针尖 λ 色散偏暖、针长随亮度伸缩），与银丝同亮同灭、只在波峰出现。
九层都可出星：触发阈值随银丝层权重等比放宽，远层的星更弱更小，另有远层
衰减指数可调；被更近层浪头挡住的星连同针芒整体消失。SDR 与 HDR 录音态
均可见（SDR 星核饱和到参考白，录音态与 HDR 超白钳制共存）。

实现：CPU 星光轨迹（FableSolStarField，与 Python 模拟器逐式同构：银边辐
亮度场复算、apex 门、簇内伴星四次方压暗、瞬时同步包络 + 0.36s 失锚淡出）
+ present 前眩光 PSF pass（FableSolGlarePass，半分辨率星点注入/弥散/32tap
针芒 gather + 全分辨率显示 cap resolve；FP16 目标，不支持的设备回退
RGBA8）。共享 water/optical 七文件 GLSL 未改动；新增 glare_*.vert/frag
五个眩光专用 shader。调参 Dialog"质感"组新增五项：人眼眩光强度（默认
0.9）、眩光触发亮度（2.8×白）、眩光针芒长度（24dp）、眩光针芒线数（6）、
眩光远层衰减（0.5）；强度归零即完全关闭、输出与旧版逐位一致。参数标定
与 Python 模拟器 2026-07-24 实测定档相同（响段约半数帧有 1~2 颗星、停留
约 1~2 秒随银丝呼吸）。Android assembleDebug + fablesol 测试包全绿。

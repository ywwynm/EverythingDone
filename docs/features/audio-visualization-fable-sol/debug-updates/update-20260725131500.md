# FableSol 调参更新 2026-07-25

## 银丝不再是"一个个小矩形拼起来"，而是一条连续的线

- 上一版修掉了银丝被水体边缘抗锯齿削掉一半、亮度随像素栅格相位振荡的问题。这一版处理你放大后看到的另一个现象：银丝像"一个个小矩形连在一起"。它既不是粗细在变，也不是波浪翻滚遮挡，而是两个采样问题叠加。
- 主因是银丝在法向上的有效宽度只有约 0.63 像素，不足一个采样间隔。银丝中心的位置随波形连续漂移，而屏幕只有整数像素格，于是每一列只点亮 1~2 个像素、亮度逐列跳变，轮廓爬升时整段跳到相邻行——放大看就是一串错位的小方块。现在把抗锯齿的有效宽度压了一个 1 像素下限，同时按能量守恒相应降低峰值：线变得连续，细的观感由亮度而不是由亚像素宽度承担。
- 次因是银丝原先用屏幕导数换算"到水面轮廓的距离"，而屏幕导数在每个网格四边形内是同一个值、四边形之间跳变（网格列宽只有 2 像素左右），银丝的位置与粗细因此被切成一格一格。现在改由顶点携带解析求出的梯度，逐像素连续。
- 实测逐像素粗糙度（相邻像素亮度差的相对量，越小越连续）从 0.172 降到 0.055；亮度与像素栅格相位的相关性从 −0.55 降到 +0.04；关掉滑动调制后沿线亮暗比从 3.4 倍收到 1.9 倍。不支持 MSAA 的设备同样有效。
- 代价：最细档银丝的可见宽度从约 1.2 像素变成约 2.2 像素，峰值亮度降约 14%（总光量不变，只是摊得更宽更柔）。这是"连续"的必要代价——无法既保持亚像素细度又不出现颗粒。粗细滑杆的语义没变，仍可自行调整；粗档（1.2dp 以上）与之前基本一致。
- 银丝的强度、光晕、峰值亮度、滑动等默认值都没有改动，其它特效未动。

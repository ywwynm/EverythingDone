# FableSol Step B：止脏 + 拉对比（打光待在身份色轴上）

## 本轮更新

上一版（Step A）让光贴着波走、更真实，但也暴露出"脏"：一条灰银/灰青的带子和偏灰黑。根因是真法线
放大了水面掠射角对**近白天空色**的反射，而它在 SDR 下被钳住，于是身份色被糊成中性灰（挨着品红就
读成灰青）。

本轮原则：**打光始终待在身份色轴上——要暗往更深的身份色压，要亮靠受光，不糊成近白天空、不掉进黑。**

- 把掠射角的天空反射在 SDR 阶段**压弱**，消除那条灰青灰带；"光贴着波走"的漫反射受光保持不变。真正
  发亮的银色光泽留到后续 HDR 步骤再做。
- **关闭九层平铺体光**（真机开关无感、只会抬中间调压对比）。
- **加强几何深浅散射**：波谷用更深的身份色压暗、浪峰提亮，用几何体积代替平铺体光，把明暗对比拉开。

真机重点观察：灰青带是否消失或明显减弱、波谷是否更深浪峰是否更亮（对比更强、更晶莹）、身份色是否
更干净、整体略微变暗是否可接受（这是有意的，晶亮感来自对比而非整体提亮）。

## 实现内容

- `water.vert` `relativeLongitudinalLight`：掠射天空反射项乘 `skyReflect=0.2` 压弱；保留全强度 N·L
  漫反射与 `0.14*sqrt(darkness)` 保色暗化。
- `FableSolParams`：`body_light_strength 0.36→0`；`depth_scattering_strength 0.21→0.45`。
- 同步更新 3 个写死默认值 / 验证体光的单元测试（`FableSolMaterialPolicyTest`、
  `FableSolDepthScatteringPolicyTest`、`FableSolGlOpticsTest`）。

## 卓易通音频弹窗：继续排查圆角黑色区域

用户确认上一版粒子动画已正常，但圆角仍有黑块。本次保留已恢复的打开／关闭粒子交接及 C 系统暗层，仅继续处理圆角；范围仍限定为卓易通的录音、音频附件与海浪设置弹窗。

排查发现，SurfaceView 后续更新会重设底层圆角，上一版仅提交 SurfaceControl 圆角不能证明最终窗口裁剪正确；旧日志中测试画面未覆盖窗口顶部时也出现黑角，需同时排查窗口外沿。没有新设备日志，暂不断言反射被拒绝或最终合成器的根因。

本版候选：新增 FableSolDialogCornerMask，在 Decor 绘制结束后通过普通 Canvas CLEAR 明确清除圆角外的像素，关闭该窗口的 Decor 轮廓裁剪，并保留轮廓供阴影／粒子快照使用。保留内容根节点裁剪、海浪 shader 圆角、Surface 层级、PQ／SDR 输出及切换遮盖；窗口再次显示时恢复清角策略，移除时清理回调。DialogSystemDim 仅负责在三个兼容弹窗中接入，粒子控制器和首帧／关闭时序均不修改。普通设备不进入该分支。

诊断页升级为第 6 版，保留 A～I、模式 1～6 和日志导出，新增 C→J→K 圆角对照：C 为原裁剪；J 只关闭 Decor 裁剪；K 在 J 上增加显式清角，与新版实际弹窗相同。三项都保持系统暗层 0.6，不主动重建 Surface／EGL。新增“圆角正常”和“仍有黑角”记录按钮。进入页默认 K，可按需比较 C、J、K。

导出增加 window_corner 的安装／尺寸／实际绘制／移除及四角窗口缓冲 alpha，原生圆角跳过原因也会记录。只记录数值，不保存截图或音频；四角 alpha 不代表最终屏幕像素。入口仍为长按海浪设置的“HDR 高光增强”，可保存到下载目录或分享日志文件。

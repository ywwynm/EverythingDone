## 录音：点停止之后，取消和重录立刻就能点

- 修复：录音中点停止后**立刻**点右侧的叉号（或左侧的重录），点不动，要等一会儿才有反应。停止后台要把录音文件写完，此前这段时间里两个按钮虽然正在淡入、看起来可用，实际是被禁用的。
- 现在停止后两个按钮随淡入立即可点；录音器的收尾、重启、释放改为按顺序排队执行，不会互相打架。保存按钮仍要等录音文件写完才可点。
- 顺带修复：录音准备阶段，点到取消按钮所在的位置（那时按钮是完全透明的）会直接关掉对话框。

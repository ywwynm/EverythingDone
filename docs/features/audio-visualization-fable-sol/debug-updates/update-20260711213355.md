# FableSol Debug 更新

## 2026-07-11 - 阶段 C3：层填充逐像素光学（深度吸收 + 焦散）

### 背景

用户真机确认 C1+C2 无问题后圈定 C3。按 A5.5 教训逐项独立参数：
`absorption_gain`（默认 0.35）与 `caustic_gain`（默认 0.5）各自归零即关。
折射视差暂缓——第 0 层不透明（alpha=1.0），本架构中真折射无"透过水看背后"
语义，做出来只能是填充扰动的假折射，待用户看过本轮效果再定。

### 实现

- `FableSolAgsl` 新增 `layerFill` shader：链在既有（已抖动）渐变之上，
  逐像素接收该层轮廓（≤216 列 uniform 数组）求水深。
- **深度吸收**（Beer–Lambert 近似）：随深度乘性衰减、保色相、下限 0.72 不压黑
  ——水体从"竖直渐变的色带"变成"越深越沉的介质"，与薄峰透光（浅处透亮）
  形成同一物理叙事的两端。全九层生效。
- **焦散**：表面下 1.5~36dp 深度包络内的横向拉伸值噪声亮脉（两倍频、
  smoothstep 稀疏化阈值 0.60~0.94、峰值强度 0.14），相位随该层流速累积漂移
  （光脉跟着水走）、随时间缓慢演化。近三层限定、随层深衰减。
- 焦散色从本层色派生（mix 向白 0.5），无新色相；uniform 缓冲复用零分配。

### 验证

- `:app:testDebugUnitTest`、`:app:assembleDebug` 均 BUILD SUCCESSFUL；未使用 adb。
- 真机验收点：① 水体是否读作"有深度的介质"（上亮下沉）；② 浪下光脉是否柔和、
  梦幻、跟随水流，而非贴屏噪点；③ `caustic_gain`/`absorption_gain` 分别归零对比；
  ④ 帧率发热无退化。若整体画面与上一版一致说明 shader 回退触发，需回报。

# 纠正实体识别并修复镜面闪点高光越出曲面

## 用户纠正

用户提供第二张截图，确认 `202607121525` 后亮白长斜高光仍明显位于波面外侧，并质疑此前是否
一直在讨论同一个对象。重新核对后确认：不是同一个对象，前两轮修错了通道。

## 根因

- 前两轮修改的是 `streak`：低 alpha、按寿命持续随背景流平移的顺流流光。
- 截图目标实际是 `glint`：最高 alpha 约 0.92、偏白、长度更长、跟随受光峰并呼吸的镜面闪点。
- glint 仍使用以中心切线为轴的完整直椭圆，因此既有一半短轴位于空气侧，长轴两端也可能穿过
  弯曲波峰。
- 珍珠斑更宽、更块状；水体网格接缝不会作为独立高光随受光峰移动。

## 修复

- 为 glint 增加独立顶点范围，诊断和回归不再与 streak 混用。
- 保留受光峰检测、跨帧身份、位置攻击/释放、尺寸跟随与呼吸明暗。
- glint 几何由完整直椭圆改为 10 段曲面软带：上边逐段采样当前波峰，下边只向水体内部展开。
- 镜面闪点使用比顺流流光更窄的亮芯、更长的软出区，减少锐利平直白线感。
- 固定光学顶点容量由 1024 提升为 1536，以容纳两类曲面带；仍无稳态扩容。
- streak、珍珠、猫爪和层间遮挡顺序保持不变。

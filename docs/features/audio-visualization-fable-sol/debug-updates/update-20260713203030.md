# FableSol Step C 修复：银泽由"朝太阳门控"改为"朝太阳加成"（让 HDR 光泽真正出现）

## 本轮更新

上一版（Step C v1）在真机上**完全看不到 HDR 光泽**，只剩灰青。原因是几何算得出来：平缓水面的
反射方向大多指向观察者一侧，而太阳在画面深处高处，两者几乎垂直——我把"朝太阳"当成了光泽的**开关**，
于是平缓水面几乎没有满足条件的朝向，银泽整片被掐灭。

本轮把"朝太阳"从**开关**改成**加成**：掠射的波面本来就该反射明亮的天空（广域出现），朝太阳一侧只是
更亮的加分，而不是"不朝太阳就没有"。于是所有能看见反射的受光陡波面都会出现发亮的银泽，朝太阳一侧最强；
仍只在 HDR 屏 + 录音态出现，SDR 逐字节不变。近层峰值略提到约 1.6× 以确保可见。

真机重点观察：受光陡波面现在**能不能看到明显发亮的银泽**（先确认看得到，再谈强弱）、是否只在录音态、
远层是否仍克制、暗色记事上是否也有、以及会不会太强/太亮需要回调。

## 实现内容

- `water.frag` `grazingSheenExcess()`：`sunLobe = pow(sunCos, 2~6)`（门控）改为
  `sunBoost = 1.0 + 1.4*pow(sunCos,3)`（全域基线 1、朝太阳最高约 2.4）；
  `grazing = clamp(fresnel*sunBoost, 0, 1)`；峰值 `mix(1.40→1.6, 1.0, smoothstep(0,0.62,depth01))`，
  超白差量 `grazing*max(peak-1,0)`（天然不超过 `uHdrHeadroom`）。
- 门控/进入条件、SDR 逐字节不变、近中性白+一丝身份色、不接音频，均不变。

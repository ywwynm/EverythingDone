# FableSol Debug 更新

## 2026-07-11 - 根治连续“你好”时既有 Hero 浪突然上抬

### 用户反馈

连续说“你好你好你好”时，偶尔有一条已经可见的浪突然向上变形。用户要求在修复前详细核对
Python 与 Android 文档，避免破坏 FableSol 已有六模态 Hero、旋律层和重音事件设计。

### 诊断

确定性差分排除了 `Prominence`、张力相干和注入渐入。两套初始状态、流速、物理时间相同且不接收
离散事件的 Simulation，仅逐帧响度、频段和音高不同，可见轮廓仍在 0.2 秒内分叉最高约
`0.541dp RMS`；关闭 `hero_gain` 后差异归零。根因是全局 `heroBandTargetDp` 重新缩放已经显示的
解析波，而非新浪注入。

### 修复

- 保留每层六模态 `HeroWave`、低/中/高频段身份、A3 音高/境映射与 `Prominence` 旋律层事件。
- Python/Android 每层新增三频段空间能量包络；声音目标只写入上游画外出生区。
- 包络以 `FLOW_DIR × (1.5|flow| + 0.45×wave_speed)` 平流进入画面；可见区既有 Hero 不再被
  下一帧声音全局缩放。
- `HeroWave.sample()` 改为逐点读取包络场，同时保留色散传播、可见区零均值与受限 Gerstner 聚峰。
- 新增双向回归：传播到达前可见轮廓不得分叉；到达后不同声音必须产生可测差异。

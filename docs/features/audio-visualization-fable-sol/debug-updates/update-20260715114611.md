## 2026-07-15 - FableSol 删除层内斜短光点与 continuous sheen

### 用户反馈

上一轮已经移除扩缩光带，但各层水体内部又出现大量斜短光点。用户确认它们不是位于水体边缘的
glint，并要求直接删除，不再用其它点状或带状方案替代。

### 诊断与修复

- `full/no_glint/water_only` 动态消融确认，斜点来自用于替代旧光带的稳定微面片 continuous
  sheen；它们在关闭 glint 和其它 optical 实体后仍然存在。
- 从共享 `water.frag`/`water.vert` 完整删除固定微面片、连续 GGX/Smith 太阳反射、SDR 有界
  反射、continuous HDR sheen excess 及配套暗面。
- Android 与 Python 同步删除对应 uniform 上传、逐层 coverage/峰值策略，以及两个不再生效的
  Python 调参项。
- 保留边缘 glint 的数量与 HDR 峰值，以及 surface reflection/streak、折射、Beer–Lambert、
  SSS 和 HDR transmission；预滤波坡度继续供折射与透射使用。
- HDR transmission 使用不随微法线分块的 `V·H` Fresnel，避免以另一种层内噪点重新出现。

### 验证

- 129 BPM、适中水位动态三联画中，`full/no_glint/water_only` 均无层内斜点、扩缩光带或环状
  替代物。
- 18 色 FP16 回归的完整效果峰值仍为 `2.629/2.934/3.314× reference white`
  （最小/中位/最大），说明边缘 glint 与其它独立 optical HDR 峰值未被削弱；`water_only`
  不超过 `1.000×`。
- Python 160 项 unittest 与 Android 140 项 Debug JVM 测试全部通过。
- 640×840 FP16 基准中，GPU 不读回约 `81.35fps`，FP16 读回约 `57.22fps`，没有性能回退。
- 未使用 ADB；Android 真机 HDR 动态观感交由用户最终验收。

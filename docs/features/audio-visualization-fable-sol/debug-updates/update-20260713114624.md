# FableSol Stage 2-3 解析镜面抗锯齿

## 用户可见变化

- 双色深度散射轻量强度从 0.22 微调为 0.21，其他散射规则不变。
- 倾斜或水面运动时，短毛细波驱动的镜面闪点应更稳定，减少采样跳变造成的闪烁。
- 保留闪点原有数量上限、跨帧跟踪、颜色、亮度能量和曲面内侧几何。

## 技术说明

- 按实际水面列足迹带限每波不足 2～4 个样本的毛细波分量。
- 把未解析坡度方差卷积回闪点坡度高斯宽度，并做积分能量归一。
- 把未解析曲率以统计 RMS 补回，避免抗锯齿导致闪点整体消失。
- 只有镜面闪点使用过滤坡度；体积光等其他光学效果仍使用原始毛细坡度。
- `specular_aa_strength` 为独立开关，设为 0 可逐值恢复旧路径。

# 把浪面灰黑阴影改为记事色混黑

## 发布说明

用户真机发现浪面经常出现难看的灰黑阴影，希望暗部保持更深的记事颜色。本次把波背
自阴影和猫爪暗纹统一改为由当前层记事颜色在 OKLab 中混合黑色生成：波背混黑 18%，
猫爪暗纹混黑 24%。不再混入固定蓝黑色，也不再额外冷偏；阴影形状、透明度和出现条件
不变。红、绿、蓝、黄、紫代表色回归、完整 38 项单测和 Debug 构建通过，未使用 adb。

### 诊断

- 猫爪暗纹原来把所有记事颜色混入固定 `#080C16`，在频繁 onset 下反复出现，直接产生
  脱离记事色的蓝黑/灰黑斑块。
- 波背自阴影原来先对层色做固定 OKLab 降明度，再按 `−hue_temp_deg` 冷偏；部分浅色或
  低彩度记事会因此偏灰，且结果不等于“当前记事色混黑”。
- 纵向法线受光和深度吸收均从当前水体基色计算，没有使用固定灰黑色，本轮不改其几何
  或光照强度，避免扩大修改范围。

### 修复与验证

- 新增 `FableSolShadowColorPolicy`，集中管理显式阴影色。
- 波背阴影：当前层颜色在 OKLab 中混黑 18%，取消额外冷偏。
- 猫爪暗纹：当前层颜色在 OKLab 中混黑 24%，删除固定蓝黑 `#080C16`。
- 先以旧公式运行颜色语义测试，红/绿/蓝/黄/紫两组共 10 个断言全部失败；应用新策略后
  全部通过。
- `:app:testDebugUnitTest`：38 项通过，0 失败。
- `:app:assembleDebug`：通过。
- 未使用 adb、模拟器或物理设备。

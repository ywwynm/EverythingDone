# FableSol：加深一律改为"更深的记事色"（保彩度、不发黑发脏）

## 本轮更新

你反馈水体混杂的灰黑色让画面变脏、近层的黑尤其明显。定位到两处"加深"其实是在**掉彩度**（发黑），
而不是"更深的记事色"：

1. 水体深浅散射的深色，是从**已经混白的层色**派生的——把乳白压暗就成了灰；
2. 波背阴影是**向黑混合**的——同时压暗和掉彩度，这就是近层"黑"的主要来源。

本轮把两处都改成"**只压明度、保住色相与彩度**"，得到的暗部是"更深的记事色"而不是黑/灰：

- 深浅散射的深色/浅色改从**未混白的身份色**派生，中远层加深不再发灰；
- 波背阴影改用 `darkenOklab`（只降明度、保彩度），并略微减浅，近层的暗部变成有色的深记事色。

光泽本轮**先保持不变**（没有调更亮）——因为你最新的反馈是"黑更明显"，而调亮光泽会加大对比、让暗部
更扎眼；先单独确认"黑→深色"这一步是否对了，下一版再谈提亮光泽。

真机重点观察：近层与中远层的暗部现在是不是"更深的记事色"（有色、不发黑不发脏）、整体是否更干净、
对比是否舒服。

## 实现内容

- `FableSolGlRenderer.buildColors`：`deep`/`subsurface` 改从未混白的 `base` 身份渐变派生
  （`base.start` / `base.end` 及其 OKLab 中间停靠点），不再从 `mixOklab(base, WHITE, lighten)` 派生。
- `FableSolShadowColorPolicy.backShade`：由 `mixOklab(base, black, 0.18)` 改为
  `darkenOklab(base, 0.10)`（只降 OKLab 明度、保色相彩度）；随层深衰减不变。
- 同步更新 `FableSolShadowColorPolicyTest`。
- `water.frag` 掠射光泽峰值保持 1.6（本轮不提亮）。

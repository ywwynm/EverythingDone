# 恢复准备态的额外透明度（淡入淡出交互）

## 现象

排查“水体透明+闪烁”（实为渲染 Paint.alpha 泄漏，已由拆分 fillPaint/bandPaint 修复）时，
一并把可视化 View 的整体 alpha 临时改成全程 1.0，丢掉了“未开始录音时水体淡”的交互。恢复它。

## 本次改动

- fragment_record_audio.xml：可视化 View 初始 alpha 由 1.0 改回 0.16（准备态淡）。
- 三态透明度恢复为：准备态 0.16（xml 初始）→ 录音态 1.0（preparedToRecording 升起）
  → 停止态 0.16（recordingToStopped 淡回，突出文件名编辑）。recordingToStopped 本就保持
  Opus 的 0.16（之前想改成 1.0 的编辑因格式错误未生效），无需再动。

该淡入淡出与之前的“透明+闪烁”无关——后者是共用 Paint 时高光带 alpha 泄漏到层渐变填充所致，
已修复；故可放心恢复此交互。

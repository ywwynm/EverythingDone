# FableSol Debug 更新

## 2026-07-11 - 修复焦散悬浮感与偶发颜色闪烁

### 用户反馈

① 焦散光丝读作"从 z 轴悬浮在浪前面的一片羽毛"，效果差；② 水面/波浪颜色
偶尔闪烁一下。

### 诊断与修复

- **焦散悬浮**：噪声纵坐标此前用屏幕 y——浪在动、光纹钉在屏幕上，于是读作
  贴在浪前的贴片。改为**水深锚定**（v = 深度 d，光纹随浪升降），并补上真实
  焦散的成因结构：亮度受**上方浪峰聚焦调制**（轮廓曲率场编码进数据纹理 b
  通道，峰下聚亮 0.30+0.70·crest、谷下散淡），阈值再稀疏（0.60→0.64）。
- **偶发闪烁**：轮廓数据位图池按帧复用存在跨帧竞争——UI 线程写第 N+1 帧位图
  时 RenderThread 可能仍在渲染引用同一位图的第 N 帧显示列表（位图内容不做
  快照）。位图池改为**三帧轮换**，跨帧不再触碰在飞位图。

### 验证

`:app:testDebugUnitTest`、`:app:assembleDebug` BUILD SUCCESSFUL；未使用 adb。
真机验收：① 光丝是否"在水里"随浪起伏、峰下更亮；② 闪烁是否消失（多录几段
观察）；若光丝观感仍差，按宁少勿烂砍除焦散（caustic_gain 归零即关）。

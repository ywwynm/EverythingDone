# FableSol 将远层混白收至 0.864

## 本轮更新

### 用户反馈

用户在 `lighten_far=0.96` 对照版后要求改为 `0.864`。

### 本轮实现

- Android 与 Python 的默认 `lighten_far` 从 `0.96` 调整为 `0.864`。
- 静态九层基础混白步进由上一版每层约 `12%` 收到约 `10.8%`；仍高于原 `0.60` 基线的
  `7.5%`，在层间分明度与远层身份色之间取中间值。
- 第 0 层仍严格保持 Thing 原色；动态 mood 与色彩呼吸的计算及 `0～1` 钳位不变。
- D87 同色正向坡面光、九层 alpha、环境色、表面反射、闪点、HDR 银泽、SSS、薄峰透射和
  水面几何均未修改。
- Python 继续保持 320dp 宽度。

### 验证结果

- Android FableSol 相关 105 项单元测试通过。
- Python 99 项 `unittest` 全部通过。
- `:app:assembleDebug` 构建通过。
- 未使用 ADB，也未操作物理设备或模拟器。

### 真机观察重点

- 层间区分是否仍明显优于 `0.60` 基线；
- 最远两层是否比 `0.96` 版保留更多身份色；
- 坡面立体感与干净水体效果是否保持。

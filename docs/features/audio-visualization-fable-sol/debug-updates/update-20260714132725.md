# Step D/E：HDR 背光透射与连续太阳碎光

## 更新内容

- 真实水面新增 HDR 背光透射：复用现有朝阳 SSS 掩码，以 `(1-Fresnel)` 与银泽反射共享能量预算；近层目标峰值为 `1.45× reference white`，随深度归回 SDR，并受设备实时 headroom 和录音态 HDR 增益封顶。
- 透射颜色从当前水层身份色派生，不混灰、不改色相；SDR 的 SSS 公式与输出保持不变。原独立透射带仅保留 `1.08/1.06/1.04/1.02/1.0…` 的弱肩部，避免重复提亮。
- 镜面闪点改用跨整个连续水面的统一候选池和总出生额度，出生位置偏向固定太阳方位形成的近宽远窄路径；路径外仍有 `0.12` 概率底，不会变成常亮光柱。
- 闪点沿真实相邻深度行方向轻微展开，近层最大 `2.6dp`、远层最大 `1.3dp`；闪点数量、单点亮度、attack/release、软退场、HDR 峰值和音频映射均未改变。
- Python ModernGL/QPainter 已同构同步，画布继续保持 `320dp/640px`；Android 生产路径仍使用 GLES。
- 数值回归确认：`1.45` 透射峰值会产生纯正向 HDR 超白差量，`1.0/1.45` 两档的 SDR 输出逐字节一致；全局出生池可跨至少两层组织闪点，且出生权重明显高于路径外概率底。
- Android 强制重跑 118 项单元测试全部通过，Debug 构建成功；Python `compileall` 与 111 项 unittest 全部通过，共享 shader 已由 ModernGL 实际编译。未使用 ADB。
- 真机重点观察：背光薄峰是否出现小面积、保身份色的透射亮边；闪点是否形成松散连续的太阳碎光路径，同时仍保持稀疏、自然淡入淡出且无逐层错位感。

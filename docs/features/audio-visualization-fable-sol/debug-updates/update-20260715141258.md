## FableSol 放大波浪精细化与帧率优化

### 用户反馈与诊断

用户反馈，放大观察波浪时 Python 与 Android 都有像素颗粒和折线感，其中 Python 更明显；同时要求在画面
效果一致或更好的前提下继续提高渲染帧率。现有 `N_POINTS=216` 并不是屏幕上的 216 个最终像素采样，而是包含
画外余量、海绵边界和注入区域的完整物理网格，屏幕内通常只显示其中约 96～126 点。直接增加物理点数会改变
`DX_DP`、CFL 稳定条件、传播速度和已经验收的波形，因此本次保持 216 点物理模拟不变，把物理网格与显示重建
网格明确分离。

### 代码改动

- 新增 `FableSolCubicResampler.kt`，并在 `FableSolSimulation`、`FableSolGlRenderer` 中把显示侧横向网格从
  最多 120 列改为固定 196 列。高度与横向坡度采用 Hermite C1 重建，轨道与纵深坡度采用 Catmull–Rom C1
  重建；轨道达到 ±10dp 钳制边界时同步清零导数，防止边缘假峰。
- 更新共享 `water.vert`、`optical.vert` 与 `water.frag`：新增 `uRasterScale`，让几何按实体像素映射而材质仍
  在既有设计空间计算；加入限制在一个实体像素内的解析边缘 coverage，以不透明、线性域的邻层颜色合成消除
  放大后的台阶、环境白泄漏、粗身份色边和 SDR 暗边。没有新增层内光点、光带或界面肩，也没有修改既定 glint
  数量、生命周期和 HDR 峰值合同。
- `FableSolGlMeshLayout` 的七次坡度平滑改用双缓冲交替，只在最后复制一次；渲染器缓存静态 Thing 材质和环境
  uniform，稳定运行后每 129 帧抽检一次 GL 错误。水体改用不透明绘制，独立 optical 实体继续使用预乘混合。
- Android 保留适合移动端 tile GPU 的双目标极简环境绘制，没有照搬桌面 GPU 上更快、但可能迫使手机 FP16
  attachment resolve 和外存往返的 framebuffer copy。
- Python 同步实现 196 列 C1 重建和原生 DPR 渲染；普通 GL、HDR Composer、D3D11/scRGB swapchain 均按
  `logical size × devicePixelRatio` 创建目标。录像仍输出 640×840，但直接复用原生 DPI 场景并由 GPU 在线性域
  缩小、撤销 scRGB scale、编码 RGBA8，开始录制不再让窗口退回低分辨率。
- Python 还删除了无人消费的 `micro_x/micro_z`，把二维相位三角函数拆成可分离一维运算，缓存重建权重，使用
  无复制 VBO 上传，并让坡度平滑使用双缓冲；这些优化用于抵消更高显示精度的成本。

### 视觉与性能验证

- 相对 640 列轮廓参考，196 列在正常帧的误差为 `p95≤0.035px、max≤0.117px`；强波压力帧为
  `p95≤0.186px、p99≤0.350px、max≤0.521px`。继续增加到 216 显示列的边际收益不足以抵消成本。
- 18 组内置/真实 Thing 颜色与渐变的 FP16 离屏回归中，HDR 峰值中位数约为
  `1.710× reference white`；相邻层渲染色差中位数约为 `0.0419`。浅灰绿色有一处约 `0.0195`，接近既有
  `0.02` 观察线，未为单一颜色增加会污染全局规则的特殊分支。
- Python `build_gl_frame` 中位耗时从约 4.26ms 降至约 3.33～3.55ms。960×1260、1.5 DPR 的完整 HDR 链为
  `p50 14.54ms、p95 15.24ms、p99 16.19ms`；加入 GPU 录像取帧后为
  `p50 15.30ms、p95 16.47ms、p99 17.32ms`，P95 约等于 60.71 FPS。原 CPU 录像取帧约 65～78ms 的瓶颈
  已消除。
- Python 164 项测试通过；Android 完整 `gradlew test` 通过；`git diff --check` 通过。

### 真机验收重点

本轮没有使用 ADB。请使用中高能量音乐，分别在深蓝和浅灰绿 Thing 上放大观察九条边界：不应再有明显折线
颗粒、浅色虚线、粗身份色边或一像素暗脏边；开始录音前后，既有 glint 数量、逐层 HDR 峰值和主体色阶应保持
一致。Android 帧率仍需在目标设备上分别记录准备态和 HDR 录音态的 `p50/p95/p99` 与掉帧情况。

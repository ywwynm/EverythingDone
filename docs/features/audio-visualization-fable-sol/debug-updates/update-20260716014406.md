## FableSol 远景连续小波峰修复

### 用户反馈与诊断

最远两层水体偶尔会在局部连续出现多个小波峰，聚集后形成锯齿观感。固定静默输入即可稳定复现，说明它不是音乐频率或节奏带来的设计效果。单变量消融确认，根因是最远两层环境波基准波长过短，经过远景透视压缩后，短波峰会挤在一起。

### 代码改动

- 将最远两层环境波基准波长从 `84/72dp` 调整为 `120/132dp`，保留环境波的流动、音乐响应、振幅和宽缓主浪。
- 不改变水体配色、HDR/SDR 亮度、光学特效、4× MSAA/RGSS 抗锯齿路径或采样数量。
- 仅替换两个默认波长，不增加每帧计算量。

### 验证

- 20 秒静默扫描中，倒数第二层的局部高频峰谷差由 `0.504dp` 降至 `0.305dp`，最远层由 `1.375dp` 降至 `0.213dp`。
- Python 174 项测试全部通过；Android 完整 `:app:testDebugUnitTest` 通过。
- 未使用 ADB；真机最终动态观感由用户验收。

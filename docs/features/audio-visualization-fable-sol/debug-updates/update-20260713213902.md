# FableSol 诊断：关闭背光坡压暗（红框暗斑）

## 本轮更新

从你圈红框的截图看，暗斑都在波形的**背光肩部**。此时水体内部只剩 `relativeLongitudinalLight`
（Step A 的"光贴波走"）在打明暗，所以暗斑=它给背光坡压的暗；这也解释了"之前没这个问题"——
Step A 把法线变陡后这个压暗才明显。

本轮只关它的**背光坡压暗**那一支（受光坡提亮仍保留）。真机对照红框：

- 暗斑**消失/变干净** → 就是背光压暗，下一版把它重做成"干净的深身份色阴影"，再把之前诊断关掉的
  `depth_scattering / micro_normal / back_shade` 逐步、干净地加回来；
- **还在** → 是受光侧提亮太狠把周围衬脏了，转去收提亮。

## 实现内容

- `water.vert` `relativeLongitudinalLight`：背光坡返回改为 `mix(base, base*(1-blackMix), 0.0)`
  （即返回 base，不再额外压暗背光坡）；受光坡提亮分支不变。

# FableSol Debug 更新

## 2026-07-24 - 星芒长度-强度耦合 + 宽晕去格点（D212）

星芒参差立体化：每道芒的长度因子现在同时作为**振幅权重**——长芒亮而长、
短芒暗而短（更强的衍射结构本就同时更亮且更长，可见长度 ∝ √振幅 的同一
支配律）。"眩光芒长参差"范围放宽到 0~4：高参差档呈现电影感的"一道修长
主刃 + 弱芒陪衬"，配合星芒慢旋即"长刃在转"的画面。

梦幻宽晕的"小方格/雪花"伪影修复：那不是物理现象，而是宽晕模糊 tap 间距
（σ/2）超过源平滑尺度、二维梳齿织出的格点阵被 ~18× 增益放大所致。模糊核
从 7 权重（±6 tap）加密到 13 权重（±12 tap）、宽晕间距收到 σ/4——覆盖仍
是 ±3σ，格点间隔压到源尺度以下，光晕恢复物理应有的光滑。Android
assembleDebug + fablesol 测试包全绿，与 Python 模拟器同步定档。

## 2026-10-17 — 卓易通海浪 HDR 前景控件层级验证版

用户确认上一版 `202610170418` 仍在 HDR 出现后丢失计时、按钮和进度条，圆角正常；关闭粒子动画无改善。保守修改窗口透明区域提示没有解决问题，本轮改查自有 PQ 图层与原生窗口的前后关系。

核对 Android 36 实现发现，根附着接口把图层挂在 Bounds 中间容器内，局部 `setLayer(-1)` 没有明确保证图层在窗口缓冲下面；系统 SurfaceView 使用另一套相对窗口排序。该差异是本轮候选依据，尚不能据此宣称已确认卓易通内部根因。

仅卓易通的录音、音频附件和海浪设置弹窗增加 `FableSolWindowUnderlay`：由全透明 SDR SurfaceView 提供窗口下层容器，自有 PQ 海浪通过公开父子挂载继承其顺序。SurfaceView 自身不输出 PQ；保持原海浪渲染、圆角 shader、C 系统暗层及旧缓冲到新缓冲的 HDR 交接。容器重建会重新挂载图层并更新粒子生产者代次，失效回调不再冒充同一生产者恢复完成。

透明容器显式排除粒子截图和恢复等待，不额外生成空白图像。普通 Android 设备继续原 SurfaceView 路径，不创建此容器，也不改变现有 HDR、海浪或粒子效果。

保留原日志导出入口：长按海浪设置中的“HDR 高光增强”进入对照页，导出文件。`production_direct_log` 继续记录窗口控件像素采样，并补充容器代次、挂载策略、首次窗口透明绘制及逐条 debug 版本号。日志只采状态和像素数量，不保存窗口截图或控件文字。

本地构建及 451 项相关 JVM 回归通过；未连接设备，不能以单元测试代替卓易通屏幕验收。请先关闭粒子检查控件是否在 HDR 出现后仍完整，再核对圆角、粒子开关、HDR 0 与非 0 切换、点外及返回关闭。若仍异常，请复现后导出日志，以区分窗口中缺少控件像素与最终图层遮挡。

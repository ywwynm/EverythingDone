## 卓易通音频弹窗接入 C 系统暗层

用户在 A～I 对照中确认 C 有效，要求接入实际录音、音频附件及海浪设置弹窗，仅在卓易通启用，保留日志导出并检查粒子动画、关闭和 HDR 切换连续性。

- 三个弹窗通过 `BaseDialogFragment` 显式选择兼容路径，复用既有 API 34+／HUAWEI／System 环境判据。全程采用系统 dim=0.6，不再为该弹窗创建应用暗层；其它设备和其它弹窗继续原逻辑。
- 新增 `DialogSystemDim`、`DialogDimDismissGate` 和独立粒子承载 `ParticleSystemDimHost`。出现按粒子进度渐入；关闭先等快照和粒子首帧接管，隐藏真实内容及独立 Surface，再淡出系统暗层，归零并提交后移除窗口。快速关闭、重复回调、创建失败和宿主销毁分别处理，保留原来的重叠弹窗行为。
- 原窗口保留期间，音频附件在内容退出时暂停，取消录音提前收尾并防止重复结束服务；保存、导出仍走原流程。
- 暗层策略不随 HDR 强度来回切换。HDR 关闭继续真正退出 PQ，保留既有快照遮盖和目标会话首帧交接；本次不改海浪 shader、PQ 颜色公式、圆角及普通 Android 的 scRGB 输出。
- 保留长按海浪设置“HDR 高光增强”进入的 A～I 对照与文件导出，诊断修订号为 4。导出新增真实弹窗的 `production_dialog_dim_log`，同时保留 `production_hdr_log`，可关联出现、粒子接管、暗层归零、窗口移除与 HDR 会话。只附带数值日志，不采集音频、记事正文或截图。

验证：本地 debug 构建通过，45 项暗层门闩、粒子时序、捕获、Surface 恢复和 HDR 策略测试通过，无失败或跳过；变更范围核对通过。未连接设备或模拟器，实际穿透、偏色、黑角及过渡观感仍由用户验证。C 对照此前消除了穿透，但轻微偏色与黑角尚未结案，不能将其视为所有 HDR 合成问题已经修复。

建议覆盖录音准备／录制／停止、音频播放／暂停、海浪设置 HDR 关闭↔非零强度、粒子开启／关闭和快速连续关闭；有异常时导出同一次操作后的日志。

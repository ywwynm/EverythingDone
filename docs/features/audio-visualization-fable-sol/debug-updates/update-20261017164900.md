## 卓易通海浪：减少计时与控件更新等待，补充计时分段日志

根据第二份性能日志，上版异步回收已有效：持续录音时 HDR／SDR 海浪分别约每秒提交 58／59 帧，控件约 34／36 次新帧，前景替换已降到不足 0.5 ms，未发生同步回退。用户也观察到 ripple 和控件移动改善，但计时数字形变仍明显不连续。现有前景平均间隔约 28～30 ms，部分间隔约 50～60 ms；这些是应用提交数据，不能等同屏幕实测 FPS。

本版仅优化卓易通 Direct 合成调度：FableSolForegroundMailbox 合并尚未使用的前景，FableSolGlRenderThread 在最终合成前读取最新控件帧；UI 就绪时，FableSolGlRenderer 可以复用已有海浪画面单独合成控件，减少等待完整海浪重绘的时间。正在被 GPU 使用的缓冲仍按原完成信号安全回收，未增加捕获缓冲数量。

TimelyClockView 新增默认关闭的诊断接口，仅 debug／卓易通启用。日志分别记录数字形变的更新、实际绘制及最终提交间隔和延迟，并排除每秒之间正常静止的时间；每个捕获帧携带真实绘制版本。海浪完整绘制、控件单独合成和总提交次数分开统计，便于确认收益及新增合成成本。原日志导出入口保留。

保持字形、动画时长、海浪画质和共享 shader，继续使用已确认的同缓冲前景、圆角、C 系统暗层与粒子交接；普通设备不启用新调度。构建及 485 项相关回归通过，其中 11 项为前景所有权和计时版本的新测试；18 项桌面 GPU 画面检查通过。这些验证不能代替卓易通实机的流畅度和闪烁检查。

请优先录音 15～20 秒，观察每秒计时数字形变、开始／停止和按钮 ripple，再长按海浪设置的“HDR 高光增强”，从原入口导出日志。方便时再对比 HDR 关闭、附件进度拖动及暂停，并检查粒子、HDR 切换和关闭重开。实际改善幅度仍待本版日志确认。

# FableSol 诊断：关闭波背阴影（back_shade dl=0）

## 本轮更新

这是一个**诊断版**，用于隔离"暗部发脏"的来源：把波背阴影强度改为 0（`BACK_DARKEN_L=0`），其它一律不动
（深浅散射从身份色派生、掠射光泽 1.6、青灰天空反射等全部保持上一版）。

真机对照上一版判断：

- 如果暗部**变干净了** → 脏来自波背阴影，下一版给它换更好的做法；
- 如果**还是脏** → 脏来自别处（深浅散射的深色下拉、背光坡的亮度差压暗、或那道青灰天空反射），
  下一版逐个关闭定位。

注：那道**青灰色是独立的 SDR 天空反射**（`skyReflect=0.2`），本轮及上一轮都未改动，与暗部诊断无关，
稍后单独处理。

## 实现内容

- `FableSolShadowColorPolicy.BACK_DARKEN_L`：`0.10 → 0.0`（波背阴影关闭）。

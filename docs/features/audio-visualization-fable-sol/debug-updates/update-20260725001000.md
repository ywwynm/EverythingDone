# FableSol Debug 更新

## 2026-07-25 - 调参对话框按特效分组（D215）

设置里的海浪动画调参对话框重新分组：原"质感"大组（15 项混排）拆成四个
独立特效组——**水体透光**（厚度透光强度/透光派生提亮/水体透光强度，后者
自"外观"组移入）、**银丝**（强度/粗细/光晕/峰值亮度/滑动）、**星芒**
（强度/梦幻光晕/触发亮度/针芒长度/针芒线数/芒长参差/远层衰减）、**闪点**
（数量）。"眩光"命名统一改为"星芒"，组内参数标签去掉重复前缀（如
"眩光针芒长度"→"针芒长度"）。参数键与已存的调参值不变，仅界面组织与
文案调整；13 种语言同步。Android assembleDebug + fablesol 测试包全绿。

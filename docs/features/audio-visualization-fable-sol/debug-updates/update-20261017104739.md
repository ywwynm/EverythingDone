## 卓易通音频弹窗：修正粒子交接并补充圆角裁剪候选

用户提供录屏反馈：C 系统暗层接入实际弹窗后，打开录音时先露出整块背景，再播放凝聚；点外部或返回关闭时没有可见粒子，圆角外还有黑块。逐帧核对确认了背景提前露出与关闭后仅暗层淡出的现象。本轮仅调整卓易通的录音、音频附件和海浪设置兼容路径。

- BaseDialogFragment / ParticleDialogVisibility：在首次显示前隐藏窗口与内容，同时恢复 window alpha=0，避免仅隐藏 decor 时独立 Surface 或背景提前出现；动画完成后沿用现有 Surface 恢复交接。
- DialogSystemDim：首次创建即声明透明窗口。粒子首帧接管后共同隐藏窗口和内容，保留 C 系统暗层渐退；不再在交接时改变焦点属性。关闭、快速重复操作与宿主销毁仍受现有门闩保护。
- ParticleDismissController / ParticleSystemDimHost：承载窗口布局返回后再创建粒子 Surface；明确透明背景。抓图／准备失败使用独立回调，不再伪造粒子首帧与覆盖层就绪而突然隐藏面板。
- FableSolWindowSurfaceClip：尝试将整个弹窗的圆角同步施加给独立 Surface 容器。设置预览沿用窗口轮廓，保留其底部平直拼接。原生圆角方法不是公开 SDK，仅作卓易通兼容探测；系统拒绝时保留现有显示并记录，不绕过系统限制。黑角是否消除仍需实机验证。
- 保留长按“HDR 高光增强”的对照入口与文件导出，诊断修订号为 5。新增粒子开关判定、宿主布局、抓图结果和九点 alpha、GL 首帧、会话失败／结束以及原生圆角请求／拒绝日志。不会保存截图、录音或记事正文。

本地 debug 构建与 50 项相关 JVM 测试通过，无失败或跳过；包含圆角坐标、设置预览底边、缩放与无效布局，以及既有捕获、暗层、Surface 恢复、PQ／SDR 策略。未连接任何设备。JVM 无法验证卓易通的最终合成，不能把构建通过等同于实际观感已修复。普通设备渲染与粒子行为、海浪 shader、PQ 编码和 HDR 关闭档保持原路径。

请重点复测三个弹窗打开时是否提前出现背景，点外部／返回是否正常消散，圆角是否仍有黑块，以及 HDR 开关是否连续。若仍异常，在同一次操作后长按“HDR 高光增强”进入对照页导出日志。

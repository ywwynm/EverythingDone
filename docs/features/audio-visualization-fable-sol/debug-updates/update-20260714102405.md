# FableSol 增强九层水体分明度

## 本轮更新

### 用户反馈

用户希望各层水体更加分明，要求把 `lighten_far` 调到 `0.96` 进行真机对照。

### 本轮实现

- Android `FableSolParams` 的默认 `lighten_far` 从 `0.60` 提到 `0.96`。
- Python 模拟器同步把 `lighten_far` 默认值设为 `0.96`，继续保持 320dp 宽度。
- 静态九层的基础混白步进由每层约 `7.5%` 提高到约 `12%`；第 0 层仍严格保持 Thing 原色，
  中远层通过更大的混白阶梯拉开视觉层次。
- 只改变该参数。D87 同色正向坡面光、水体 alpha、环境色、表面反射、闪点、HDR 银泽、SSS、
  薄峰透射与水面几何均保持不变。
- 动态混白仍钳在 `0～1`；最远层叠加 mood 或色彩呼吸后可能更早到达纯白，这是本版需要观察的
  预期副作用。

### 验证结果

- Android FableSol 相关 105 项单元测试通过。
- Python 99 项 `unittest` 全部通过。
- `:app:assembleDebug` 构建通过。
- 未使用 ADB，也未操作物理设备或模拟器。

### 真机观察重点

- 第 1～6 层边界是否比上一版更容易分辨；
- 第 7～8 层是否仍保留足够身份色，而不是过早接近纯白；
- 上一版恢复的轻微坡面立体感及干净水体效果是否保持。

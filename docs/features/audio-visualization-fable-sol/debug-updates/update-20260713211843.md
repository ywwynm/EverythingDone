# FableSol 诊断：关闭 depth_scattering（隔离暗部发脏）

## 本轮更新

灰青光斑已确认是 SDR 天空反射、已清除。暗部仍脏，继续隔离：本轮把 `depth_scattering_strength` 关到 0，
其它不动（`skyReflect=0`、`back_shade=0` 保持）。

`depth_scattering` 是把暗部朝 `L×0.70` 深色下拉的主要"加深/对比"手段（Step B 从 0.21 提到过 0.45），
嫌疑最大。真机对照：

- 关掉后暗部**变干净**（哪怕整体变平、对比变弱）→ 就是它把暗部压得又深又闷，下一版用**更浅的深色 +
  更小强度**重做，让暗部是"通透的深记事色"而不是闷；
- **还脏** → 不是它，下一刀去关 `relativeLongitudinalLight` 的漫反射压暗 / 微法线的明暗调制。

注：这是诊断版，暂时没有深浅体积对比，属预期。

## 实现内容

- `FableSolParams`：`depth_scattering_strength 0.45 → 0.0`（诊断隔离）。
- 同步更新 `FableSolDepthScatteringPolicyTest`。

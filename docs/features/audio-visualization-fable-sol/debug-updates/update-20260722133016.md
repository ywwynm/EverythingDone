## 巨浪不再顶画面、平顶变平、流速有惯性、高响度水位降下来（D178）

你上一版报的四个问题全部处理了。前两个是同一个根子，后两个各自独立。

### 一、触发巨浪时整幅画面瞬间上下平移

**是真 bug，而且上一版是我放大的。** 画面合成时每层要减掉自己的「直流分量」（整层
216 列的均值）。巨浪虽然出生在画外 560dp 处，但它宽 960dp，侧翼会盖住网格最右侧
84 列——**触发那一帧，这块突然多出最高 112dp 的内容，层均值瞬间跳变，整幅画面跟着
平移**，离场时反向跳回。

上一版之前跳 6.97dp，上一版之后跳 15.64dp（420dp 画面上的 3.7%），所以你现在才看得
这么明显。

修法是把巨浪的贡献从「直流分量」里剔除——它是一个局部隆起，不是整层的水位。这里有
两个坑，都踩过了：巨浪对均值的影响不只是它自己的高度，还包括它把背景压掉的那部分；
而这个均值有**两个**消费点（画面合成、深度基准高度），只改一个位移只从 29.4dp 降到
23.2dp。现在两端都收敛成一个统一取值口，触发和离场应当**完全没有位移**。

### 二、巨浪顶部不平

你的判断对了——不是巨浪自己的问题，是别的东西加在它上面。

巨浪冠部本来会把底下的普通浪压到 12%，但这个压制**只作用于锚层细节，从没盖住方向场
和轨道位移**——它们是在锚层之后才合成的。于是平顶上一直浮着 9 个方向模态（约 14dp）、
波包（每个 2~8dp）和 ±10dp 的轨道位移，合计约画面高的 5%，正是你看到的起伏。

现在压制覆盖到这两项了。平顶应当明显更平。

你说的「已生成的浪完全不再变化」我**没有做**：这些场是水面细碎质感的全部来源，全关
掉水面会退化成纯波方程的光滑曲面，很可能显得像塑料。先看这次修完够不够；如果还要，
我做成开关而不是直接删。

### 三、流速停得太急

弹簧的加速和减速用的是同一个 0.18 秒半衰期。物理上不对——推动水体时驱动力大、响应
本就该快；撤掉驱动后只剩粘性耗散，必须慢得多。现在减速改成 **1.80 秒**（十倍），
加速仍是 0.18 秒。半衰期切换时速度是连续的，不会引入新的突变。

### 四、高响度时水位太高

**先纠正一个前提**：水位和七境档位其实没有直接关系，档位只拉层间距。水位只由响度
决定（`160 × 响度`），你感觉「PEAK/CLIMAX 水位高」实际是那时响度高。

满响度时最前层静水面 96+160 = 256dp，叠上 144dp 的巨浪就是 400dp，420dp 的容器几乎
被顶满——正是你截图里的样子。按你的要求改成满响度落在 216dp，走的是软饱和而不是
钳位：

| 响度 | 改前 | 改后 |
|---|---|---|
| 0.10 | 16.0 | 15.9 |
| 0.25 | 40.0 | 39.1 |
| 0.50 | 80.0 | 73.2 |
| 0.75 | 120.0 | 100.1 |
| 1.00 | 160.0 | **120.0** |

**安静和中低响度几乎没动**（低端斜率与改前完全一致），只压高端。用钳位的话高响度会
整段贴在同一高度、彻底分不出大小声。

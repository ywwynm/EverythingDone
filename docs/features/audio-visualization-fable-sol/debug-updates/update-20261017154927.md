## 卓易通音频弹窗：海浪与控件动画性能取证

- 用户已确认上一版 202610170712 的圆角、前景控件和 HDR 显示正常，但海浪、按钮 ripple 和控件移动仍感觉帧率不足。本版先记录可分析的性能数据，保持现有 C 系统暗层、自管 PQ、同缓冲前景及粒子交接，尚不宣称卡顿已解决。
- 仅 debug 且使用卓易通 Direct 方案的录音、音频附件和海浪设置弹窗自动启动性能会话。普通设备不启用新探针；未修改 shader、图层配置、画质、帧率上限、缓冲同步或捕获频率。
- 新增 FableSolCompositionPerformance 和有界统计器，按弹窗记录主线程排队、输入分发、原窗口绘制／GPU／deadline、GC、CPU、热状态、刷新率及 HDR／粒子／冻结状态。特别区分海浪提交频率与控件新帧频率、控件帧年龄和最近捕获输入到对应 swap 的延迟。
- 为 ForegroundCapture／Texture 及 GlRenderThread 增加分段计时，覆盖 display-list 记录、HWUI 提交与完成、fence、主线程／GL 排队、缓冲归还、原有 glFinish 等待、EGLImage 导入、海浪物理／网格／绘制与 swap；已有启动 alpha 诊断采样单列耗时。
- 逐帧只采集有界数值，每两秒在工作线程汇总均值、p50／p95／p99、最大值、长耗时数量与有限示例；不逐帧写盘、不新增 GPU 等待或截图。关闭和导出补齐剩余统计。swap 仅代表应用提交，监测回调丢失也不等于屏幕掉帧。
- 保留原文件日志导出。长按海浪设置的“HDR 高光增强”进入诊断页后，导出／分享文件会同时包含新的性能日志、上一份轮转日志和既有帧性能日志；无需连接电脑。建议在出现卡顿的弹窗连续操作约 15 秒，比较 HDR 开启和强度为 0，并在备注中写明场景及操作顺序。
- 最终本地构建及 462 项相关回归通过，包括 6 项新增统计测试。未操作设备、未提交 Git；真实卓易通瓶颈和改善幅度需根据用户导出继续分析。

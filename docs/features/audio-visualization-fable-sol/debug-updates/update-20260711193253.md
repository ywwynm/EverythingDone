# FableSol 表达与材质升级迁移到 Android

用户说明 `E:\projects\audioVisualizerSimulatorFable` 刚完成一轮更新，Android 侧已经迁移了一部分，
要求继续完成；并再次明确本任务是所有 `FableSol` 前缀/后缀实现的延续，不涉及旧
`RecordingWaveVisualizer` 路线。

本次先对照模拟器 `docs/porting-notes.md`、Python 当前工作区改动、Android 功能文档与 Kotlin
未提交改动确认断点。Android 已有 A2～A6 映射/物理以及 A5、B1、视觉批次 2 的大部分代码，
但 `FableSolFeatureFrame`、`FableSolEvent` 和 `FableSolRealtimeAnalyzer` 尚未迁移 A1/A3/A6，
导致 Mapper 引用的 `hnr01`、`fluct4hz01`、`pitchRel01`、`Prominence` 等符号无法编译。

本次完成：

- 新增 `FableSolAudioFrontEnd.kt`，同构实现 44.1kHz K 计权频响、滑动均值/方差环与 4Hz
  包络带通；Analyzer 保留 A 计权安全门，感知响度改走 K 计权 400ms/3s 窗。
- `FableSolRealtimeAnalyzer.kt` 接入白化 SuperFlux、music gate、4Hz 波动强度、YIN/浊音度、
  相对音高、音节率、`Prominence`、HNR、arousal、looming 与 impulse，并保留 Android 独有的
  采集启动低频暂态保护。
- 扩展 `FableSolFeatureFrame.kt` 的所有 A1/A3/A6 字段和事件出生特征；
  `WaveVisualizerFableSol.kt` 分发 `Prominence`；`FableSolRng.kt` 补齐 Kotlin 随机整数接口。
- 延续并验证已有部分迁移：双 register、乐队角色分层、反克隆注入、境连续权重、持久闪点/
  珍珠斑、猫爪、表面带、薄峰透光、流光条纹、轨道微摆、波背自阴影、空气透视、冷暖微偏、
  1/f 慢调制和 A6 张力试验。接触阴影保持移除，未恢复已否决的 A5.5。
- 新增 `FableSolExpressionUpgradeTest.kt`，覆盖 K 计权 44.1kHz 响应、F0/音节率、HNR、A6
  有限值与张力升降。

验证结果：模拟器 A1～A6/视觉相关 7 个测试文件共 42 项通过；Android 完整
`:app:testDebugUnitTest` 与 `:app:assembleDebug` 通过。未使用 adb，未安装到物理设备或模拟器，
未创建 Git commit。发布后需真机重点目测材质稳定性、立体感、阴影/空气透视的克制度，以及
HNR、looming 与“张力=相位”的主观效果。

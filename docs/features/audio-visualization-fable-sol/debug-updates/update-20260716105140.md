# FableSol 中远层水面曲线 C1 平滑修复

## 更新内容

**用户反馈与复现**

- 用户指出上一版仍会在中远层轮廓出现连续小冒尖、轻台阶和不平滑折点，并指定
  `HOYO-MiX - 银花玉鉴逐人来 Where Tender Night Embraceth Thee.flac` 作为复现音乐。
- 先用 Python 正式实时分析链从 0 秒回放并换成蓝色配色制作 mask；经用户逐项校正后，只把 14.0 秒左上区域的两条
  独立轮廓和 112.0 秒上方中间轮廓作为正样本，层间正常交叉及其它误标区域均不作为缺陷。
- 最终几何区段为 14.0 秒 `L6 x=-150..-35dp`、同帧 `L3 x=-25..+5dp`，以及
  112.0 秒 `L7 x=+65..+150dp`。

**定因与修复**

- 单变量消融排除了声音高频、`AmbientSet`、`HeroWave`、`DynamicWave`、196 列重建与 MSAA。
- 根因是 `orbit_z` 使锚层跨越九层均值的分段线性节点；节点左右斜率不连续，把原本平滑的纵向水体轨道投影成小尖峰。
- 新增 `FableSolDepthBaseline`，用保持形状的 Fritsch–Carlson/PCHIP 三次 Hermite 插值替换线性深度基线。它严格命中
  九个层锚点、在节点处保持 C1，且对单调输入不超调。
- GLES 的 `FableSolGlRenderer` 与 Canvas fallback 的 `WaveVisualizerFableSol` 共用同一零分配实现；完整保留 packet
  高度与 `orbit_x/orbit_z`、音乐驱动、HDR/SDR 策略、196 列、4x MSAA、shader 和既有光学效果。
- 撤回上一版基于错误静默全层指标而把 L7/L8 `ambient_len_dp` 改成 `120/132dp` 的修改，恢复原设计
  `84/72dp`；真实问题由 C1 深度剖面修复，不再靠改变远层宽浪构图掩盖。

**验证**

- 指定音乐在最终 Python 同构代码下的三个正样本空间 jerk 为
  `0.000797 / 0.001322 / 0.000936dp⁻²`，均低于 `0.00145dp⁻²` 合同；三个用户否定区段也全部通过。
- 新增 Android 回归覆盖节点命中、C1、PCHIP 参考值、单调不超调，以及合成 `orbit_z` 跨节点时的同一 jerk 合同；
  测试同时证明旧线性插值会失败。
- Python 177 项测试、Android 完整 `:app:testDebugUnitTest`、两端 diff check 均通过；未使用 ADB。
- Android 每帧只增加 8 个差分、9 个切线及既有 19,012 顶点上的无分配 Hermite 求值，不增加顶点、上传、shader
  或 GPU pass。

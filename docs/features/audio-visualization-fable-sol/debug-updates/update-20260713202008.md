# FableSol Step C：掠射 Fresnel 天空反射进 HDR（发亮的银泽）

## 本轮更新

之前 Step B 把水面掠射角的天空反射在 SDR 阶段压弱，避免它糊成灰带；本轮把这块反射**在 HDR 里提成
发亮的银色光泽**——受光的陡波面在录音时会出现明显高于普通白的镜面银泽，这正是"高光太酷了"里那种
存在感，但它是大面积、柔和、贴着波面的，而不是零星闪点。

物理与克制：光泽 = 掠射角 Fresnel（越掠射越强）× 朝太阳集中（统一的"带太阳天空"，近处瓣紧、远处瓣宽，
自带空气透视）× 随水层深度衰减的峰值（近层最亮约 1.4×、远层归到普通白，避免远处过曝、保留景深）。
颜色近中性白、只带一丝身份色（强反射光本就趋白）。**只有在支持 HDR 的屏幕、且正在录音时**才出现；
SDR 屏幕或非录音态逐字节不变，几何、身份色、音频响应都不改，也不与声音直接挂钩。

本版是第一步、只做宏观波面的大面积柔光泽，暂不接微法线细碎闪烁与窄闪点瓣（后续单独做）。

真机重点观察：受光陡波面是否出现发亮的银泽、是否只在录音态出现、远层是否仍克制不过曝、暗色记事上
是否也能看到、太阳一侧的方向是否正确、以及弹窗文字/按钮是否被 HDR 影响。

## 实现内容

- `water.frag`：新增 `grazingSheenExcess()` 与 `uHdrGain`/`uHdrHeadroom` uniform。掠射 Fresnel
  `f0=0.020373`、`pow(1-NdV,5)`；朝太阳反射瓣 `reflect(-viewDir,normal)·lightDir`，瓣指数
  `mix(6,2,depth01)`；峰值 `min(mix(1.40,1.0,smoothstep(0,0.62,depth01)), uHdrHeadroom)`。仅当
  `uSceneLinear && vFrontFill==0 && uHdrGain>0 && uHdrHeadroom>1` 时叠加超白差量 `max(peak-1,0)`。
- `FableSolGlRenderer`：把 `hdrGain`/`hdrHeadroom` 也喂给水面 program。
- 新增守卫测试 `waterGrazingSheenAddsSuperWhiteOnlyInSceneLinear`。

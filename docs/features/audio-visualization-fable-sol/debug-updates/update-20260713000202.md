# GLES 表面软带真机感知补偿

## 用户可见变化

- 收窄录音画面中沿多层波峰连续出现的表面软带。
- 降低表面软带的白亮程度，使其更接近旧 Canvas 版本。
- 薄峰透光、波背阴影、远层羽化、镜面闪点和顺流流光保持不变。

## 技术说明

- GLES 与 Canvas 的带宽、颜色、基础透明度和半正弦剖面已经一致，但真机混合后仍存在感知差异。
- 仅对 GLES 表面软带应用 68% 峰值透明度、72% 几何宽度的独立补偿。
- 新增真实光学网格回归，分别锁定亮度与宽度补偿，防止其他轮廓效果被连带修改。
- 完整单元测试与 Debug 构建通过；未使用 adb。

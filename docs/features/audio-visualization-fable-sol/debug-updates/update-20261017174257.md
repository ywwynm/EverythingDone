## 卓易通海浪：继续改善计时提交，控制诊断日志体积

本次分析新版性能导出。持续 60 Hz 录音中，计时形变更新平均约每 16 ms 一次、绘制约每 17 ms 一次，但新计时画面提交仍约每 30 ms 一次；字形绘制本身平均只需约 0.43 ms。上一版优化主要减少等待：在报告 60 Hz 的片段中，捕获到提交从约 39 ms 降至约 18 ms。旧版没有计时专用指标，无法直接比较其更新和绘制阶段的改善幅度；应用提交率也不等于屏幕实测 FPS。

本版仅调整卓易通前景回收：FableSolGpuRetirement 与 FableSolForegroundTexture 在控件最后一次被 GPU 采样后记录完成标记，替换时复用最新标记，减少等待下一轮无关海浪任务的时间。重复使用会更新标记，创建或查询失败仍保守回退；三缓冲、HDR 切换、关闭收尾与已确认的颜色、圆角和粒子方案保持。海浪 shader、字形和动画时长未改。

保留计时更新／绘制／提交日志，增加实际捕获的计时版本、捕获间隔、捕获内外绘制次数，以及新回收标记的成本与复用次数，便于区分下一步瓶颈。

用户反馈导出文件已达约 8.14 MB。已修正重复累积：生产日志不再被每次导出附加回长期记录，而是合并到独立导出副本；本功能测试事件限制为 512 KiB，生产日志继续轮转。首次使用新 debug 版本时自动清理旧版的本功能诊断，同版本重启保留新测试数据。原导出页增加“清空并重新记录”，可以手动开始下一轮测试；其它功能日志及已保存、分享的导出文件保留。

构建及 497 项相关回归通过，包括 6 项最后使用回收测试和 6 项日志清理／导出测试。原回收策略在“旧前景已完成、新海浪尚未完成”的测试中先复现了不必要等待，修复后通过；这些验证不能代替卓易通实机的性能及转场检查。

安装后请重新打开录音弹窗，录音约 15～20 秒，观察计时形变和按钮动画，然后从原入口导出日志。要做新的独立对照时，可先点“清空并重新记录”，再返回实际弹窗测试；不要在完成测试、尚未导出时清空。本版实际改善幅度仍待新日志确认。

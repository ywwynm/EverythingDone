# FableSol Stage 2-4 四项持续质感优化

## 用户可见变化

- 水面的整体环境波幅、稀有波包和新生闪点增加缓慢的 1/f 呼吸，节奏不再完全机械重复。
- 水面增加沿主流向梳理的细微法线纹理；远层高频自动衰减，减少倾斜和运动时的闪烁。
- 朝向日照的近层薄浪峰增加同色透光，方向收束较强，不跟随瞬态音频忽明忽暗。
- 镜面闪点亮芯周围增加数学衰减光晕，光晕仍严格位于水体内侧。

## 技术说明

- 1/f 呼吸只调制持续环境运动和实体新生率，不重塑已形成的音频主浪，不删除已有闪点。
- 微法线采用三倍频解析导数值噪声，按远近行采样足迹复用镜面抗锯齿强度带限。
- 朝阳 SSS 使用固定日照、视角、深度和 `crestPinch`，方向瓣指数为 6，禁止接入音频瞬态。
- 解析光晕先于原双色闪点核心绘制，不使用模糊纹理。
- 四项均有独立强度参数，设为 0 可分别关闭。

## 语速传感器与录音域巨浪泛化修复（2026-07-23 第二版）

- 语速改用包络调制率（2~9Hz 归一化自相关，响度/AGC 无关）：快速连说与快速重复单字不再被读成慢速——快速·正常声约 165dp/s、快速·小声约 150dp/s（小声略慢是"响度为辅"的既定语义），慢速与正常整句读数不变。
- 录音（翻录）域巨浪改为"编曲到达重音"（D200）：hook/副歌/尾奏等编曲大节点给巨浪，同一首歌多次录音的落点彼此一致（实测两版 Lose 全录音大地标 ±3.6s 对齐、开场 hook 完全一致），不再出现"每次录巨浪都不一样"的漂移；银花录音命中 2:23 真高潮。原声母带的巨浪行为逐点不变（Lose 四处、银花 2:23、全部母带有巨浪、rap 段无）。
- 说话场景不受影响：五档水位、潮位缓退、"安静→偏大声/大声"两级巨浪与快速段快流速全部保持。
- 验收契约升级为跨会话一致性（12 轨官方验收全绿），两端全量测试通过。

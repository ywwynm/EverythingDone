## 卓易通音频弹窗：黑角复发后的媒体子窗口候选

- 用户复验上一版：计时、按钮和进度条已恢复，但完整弹窗在 HDR 开启和关闭时都有黑角，粒子动画图像正常。本轮继续排查圆角，保留日志导出并发布 debug 供实机验证。
- 调查确认：透明 SDR SurfaceView 虽能提供正确的前后顺序，仍与黑角复发相关；直接停止提交其缓冲可能阻塞系统同步重绘，不继续使用该容器。历史单独清角、去阴影也未通过。
- 仅卓易通的录音、音频附件和海浪设置弹窗改用公开 TYPE_APPLICATION_MEDIA 子窗口承载现有 PQ 图层。FableSolWindowUnderlay 不再创建 SurfaceView；子窗口附着于原 Dialog，位于其后方，不接收触摸／焦点，不增加暗层或悬浮窗权限。原 Dialog 继续显示原生控件，C 系统暗层保持。
- WaveVisualizerFableSolDirect 按子窗口实际位置和 Surface 内边距定位海浪；保持圆角 shader、HDR 强度 0 的真实 SDR 输出、旧／新缓冲就绪后交接，以及原粒子快照和恢复。关闭、后台和异常路径释放子窗口，首帧超时明确记录并降级。
- 保留长按海浪设置“HDR 高光增强”的诊断入口及文件导出。production_direct_log 新增媒体窗口创建、就绪、位置、尺寸、代次和释放信息，继续记录前景控件窗口采样；普通设备仍使用原 SurfaceView。
- 本地构建及 451 项相关 JVM 回归通过，0 失败／错误／跳过。原 GL 渲染线程、普通设备 SurfaceView、C 暗层和粒子恢复实现未改。本轮未连接设备，最终窗口合成仍需实机确认。
- 请复测实际三个弹窗的 SDR／HDR 圆角、计时／按钮／进度条、点外／返回关闭、粒子开关、HDR 连续切换及切后台恢复。如仍异常，复现后从原诊断入口导出文件，以核对当前版本的生产日志。

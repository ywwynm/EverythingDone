# 九层水体材质存在度与闪点质感增强

## 更新内容

- 近三层继续承担主要视觉效果，同时把弱化版本有序延伸到中远层：连续坡面明暗、微法线、SDR SSS、局部表面反射、保色波背阴影、薄峰透射、解析光晕、波峰薄雾与顺流银线均改用明确的逐层曲线；第 3～7 层不再突然失去材质，第 8 层干净退出局部与 HDR 效果。
- 镜面闪点容量调整为 `4/4/3/3/2/2/1/1/0`，所有层未匹配的真实受光坡面峰进入同一个候选池，再按太阳反射路径、逐层软配额和当前占用统一选择。Android GLES、Android Canvas 回退、Python ModernGL 与 QPainter 均使用同一组织方式；闪点仍自然攻击、释放和退场，不生成固定保底亮点。
- 闪点沿水面方向逐层缩短，并沿连续水面的真实深度轴向水体内部展开；核心与解析光晕共享 `12～32` 段、目标段长不超过 `3.2dp` 的曲率自适应边界，消除大尺寸亮斑的矩形拼接、错缝和粗糙边缘，同时保留完整几何，不允许因顶点容量不足静默截断。
- 闪点核心最大 alpha 精确设为 `0.9129`；解析光晕使用更低的发射阈值，让第 6～7 层通过软门自然退隐。HDR mode 3 与 SDR 核心共用同一时间 visibility，避免闪点在 HDR 设备上提前突消。
- HDR 内容 headroom 上限提高到 `3.6× reference white`。闪点核心、局部反射带、连续银泽和背光透射分别使用独立逐层峰值，保持“闪点最亮、反射带次之、连续银泽更柔”的主次；第 7～8 层连续银泽与透射回到 SDR。
- 共享水面 shader 把静态逐层曲线移到顶点采样并插值；远层权重为零时跳过无效微法线与 HDR 计算。六组静态 uniform 只在程序初始化时上传一次，deep/subsurface 身份色按 RGB 缓存，避免逐帧重复推导和 JNI/driver 调用。
- Python 自适应边界评分、曲面四边形装配和表面带宽度改为等价的批量 NumPy 计算，不减少效果、采样点或细分质量。高活动基准中 CPU 网格中位耗时由 `26.114ms` 降至 `11.484ms`，ModernGL 含同步读回由 `26.862ms` 降至 `12.114ms`；优化前后最大光学顶点数均为 `9,972/64,000`。
- Android 与 Python 的全部逐层策略数组新增跨仓逐项一致性回归；另覆盖全局闪点池、远层真实候选、自然退场、HDR eligibility、核心/光晕共享细分、shader 实际编译和顶点预算。Android 全量单元测试与 Debug APK 构建通过，Python 115 项 unittest 全部通过，`git diff --check` 通过；未使用 ADB。
- Python 画布宽度保持不变，仍为 `320dp×420dp`（`640×840px`）。
- 真机重点观察：第 3～7 层是否能读出连续但逐层减弱的材质；第 7 层闪点是否足够稀有；闪点、局部反射与连续银泽的 HDR 亮度主次是否自然；运动中是否仍有矩形拼片、边缘错缝或突然消失。

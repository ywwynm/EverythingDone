# 修掉上一版带出来的两处闪烁

## 两处闪烁的根因与修法

上一版（`202609151529`）修好了录音弹窗的两件事，但各带出一个一瞬间的闪烁。这一版把两个都
修掉，两台设备实测。

**闪烁一（魅族）：关闭录音弹窗时，弹窗一瞬间变成直角、整屏亮度掉一下。** 逐帧录屏定位到
**连续两帧**：这两帧里海浪那一层被裁成 974×1357 的一块（弹窗本身是 1086×1470），内容位置
一个像素没动、只是可见区域被裁小，四角因此是直的；差异严格落在弹窗的包围盒之内，弹窗之外
的页面逐像素相同——所以**不是暗层交接乱序**，暗层全程正常。弹窗自己的控件（录音按钮）也
还在原位，被裁的只有海浪那一层。

根因是**用第二个 `HardwareRenderer` 去画活着的视图树**。Android 15 起 `SurfaceView` 的裁剪
由 RenderThread 驱动：它那条 Surface 的位置与裁剪来自「这一帧把它的显示节点画到了哪里」，
由框架逐帧上报。离屏抓图一旦把同一个显示节点再画一遍，上报的就是**离屏那一帧**的边界，
而这个边界被应用到了**真实的** Surface 上；真实窗口下一帧上报正确边界后又自己恢复，所以
只闪两帧。这解释了为什么上一版之前没有：那时这类弹窗只走窗口复制，根本不做离屏重录。

修法：**弹窗里有可见的独立 Surface 时，离屏那一步改用软件绘制**，不经过显示节点，也就不会
触发那条上报。这类弹窗只有录音与音频附件播放两个，它们的圆角来自窗口背景而不是子控件轮廓，
软件绘制不受影响；Surface 的透明洞由框架记下，软件画布同样支持。顺带把消散的首选路径统一
成「一律先离屏，窗口复制只作回退」：窗口复制在这台设备上对这两类弹窗本来就取不到数据，先
试它只是白等。**出现动画不跟着改**——它的末帧要与随后揭开的真实弹窗逐像素相同，窗口缓冲
是那条契约最直接的来源。另外把盖在真实弹窗上的那张交接图也按弹窗圆角裁了一刀：圆角遮罩此前
在材料线程上做，盖回去的那一份是没裁角的，只是恰好四角透明才没出事。

实测（魅族，每格 2 次、逐帧录屏）：修前点外部关闭有整屏亮度 −9.5 灰阶的单帧跳变、角块偏离
参照 120；修后**四次全部没有**，最大跳变 3.7（全都是消散本身的渐变），角块最大偏离 8.5。
四次全部正常开播（54~61 帧）。抓图耗时从上一版的 1.07 秒降到 **59 毫秒**。合成出来的图与
同一时刻的系统截屏逐通道绝对差均值 0.17、97.6~95.8% 的像素差不超过 2，四角透明；相隔几十秒
的两张合成图，上部控件区完全相同而水体区有变化——水体确实是 Surface 的真实像素合成回来的。

**闪烁二（OPPO 平板）：设置里把 HDR 强度改到 0，预览瞬间闪一下。** 这是上一版新加的「跨过
关闭档就换缓冲格式、整条重建渲染会话」。换格式的那一刻旧缓冲作废，新会话交出第一帧之前
合成器手上没有内容，于是有一两帧空白。

修法是**先显后撤**：换格式之前先把当前这一帧复制下来盖在预览上，换完等新会话**在这条
Surface 上**真正交出第一帧才撤掉遮盖层（不是等宿主窗口画了一帧——那证明不了这条 Surface
有内容），并附 900 毫秒兜底。抓图万一失败也照常改设置，只是那一次没有遮盖。

实测：OPPO 上三次来回切换，遮盖层停留 46.4 / 35.9 / 37.2 毫秒，全部由「新会话首帧」撤下，
一次都没有走到兜底。魅族上同样三次，停留 72.2 / 60.3 毫秒，并且逐帧录屏 796 帧里
**没有一帧空白**（预览区亮度 159.5~163.3、标准差 89.2~90.5，全程平稳）。录音弹窗本身是新建
的 Surface，不经过这条路，没有改动。

回归：魅族上「添加附件弹窗、调整颜色面板 × 返回键 / 点外部 / 取消 / 确认 + 弹窗到弹窗」
**8/8 全部开播**，路径与帧数与上一版同档；**OPPO 首次跑录音弹窗的关闭，4/4 全部开播**
（62 帧、p90 16.7 毫秒），这是消散那一项第一次有第二台设备的回归。单测 1036 项：1034 通过、
1 跳过、1 项既有的 `FableSolCurveFairnessTest` 失败与本改动无关。华为 MatePad Pro 13.2
本轮不在线。

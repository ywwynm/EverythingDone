# FableSol 基础层去灰浊：抬高远层 alpha

## 本轮更新

关掉受光坡提亮后"脏削减很多、基础层仍稍有点脏"，定位到根因：水体合成的起点背景是
`environmentAt`，其中 84% 是深色 app 背景；远层被 `lighten_far` 混白成乳白，alpha 又低到
0.357，于是 64% 的深背景透过乳白远层 → 灰浊。且这只发生在远端 band（近/中层被 layer0 的
alpha=1.0 覆盖，不受影响）。

本轮把远层 alpha 阶梯从 1.0→0.357 抬到 1.0→0.68（深背景透出 64%→32%），只清理远端灰浊、
不动近中水体，仍保留单调下降的景深半透。受光坡提亮仍关着，保持基础层信号干净。真机看远方水面：

- 远方变干净/不再发灰 → 就是远层透深背景造成的，确诊。下一版把受光坡提亮**封顶**恢复，
  再逐个干净地加回 `depth_scattering / micro_normal / back_shade`；
- 还发灰 → 不是远层 alpha，转查颜色派生（乳白量 lighten_far 或身份色合成）。

## 实现内容

- `FableSolParams.kt` `alpha` 层参数：`[1.0, 196/255 … 91/255]`（1.0→0.357）改为
  `[1.0, 0.84, 0.80, 0.77, 0.75, 0.73, 0.71, 0.695, 0.68]`（1.0→0.68）。

# FableSol 调参更新 2026-07-25（四）

## 银丝强度归零后星芒不再一起消失

- 此前把「银丝」组的「波峰银丝强度」拉到 0，银丝隐去的同时星芒也整体消失；「银丝峰值亮度」落到最低的 1.0× 时同样如此。原因是星芒的触发光源由波峰银丝的亮度场推算，这两项到底之后亮度场恒为基准值，没有任何位置能越过起晕阈值。
- 现在星芒的触发亮度场固定按银丝的标定档（强度 1.0、峰值 3.6×）推算，不再跟随这两个滑杆。银丝与星芒是两个独立特效，银丝滑杆此后只决定银丝自身是否可见；星芒的有无由「星芒」组的「星芒强度」单独掌管，它归零仍然是关闭星芒的唯一开关。
- 星芒与银丝的节奏同步保持不变：起落仍由音频活跃度、亮结滑动与波峰演化驱动，「银丝滑动」滑杆也继续对星芒生效。
- 默认参数下画面与性能与上一版完全一致，逐位不变。

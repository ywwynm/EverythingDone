# FableSol 清理近中层大范围阴影

## 本轮更新

### 用户反馈与诊断

用户在 Android FableSol 中持续观察到单层水体内部存在较大范围、可感知的灰暗阴影；此前把
`skyReflect`、`depth_scattering_strength`、`micro_normal_strength` 和波背阴影分别归零，都只能
缓解，无法彻底消除。先在 Python 模拟器同步当前 Android 效果并做固定恒色帧逐项消融，第一轮只
禁止纵向负向受光、限制正向抬亮后，用户继续指出近中层仍有阴影。

进一步按 X 方向取样确认有三个宽域来源：

- `depth_scattering` 会让第 1/2/4/5 层整体降低约 12/15/11/7 个亮度单位；
- 纵向长波受光会形成最高约 4 个亮度单位的宽域抬亮，使相邻基色被感知为暗区；
- 旧 `surface_strip` 在没有波峰时也保留 `1.2dp` 基础宽度，中层可形成约 11 个亮度单位的
  宽域抬亮，同样会制造邻区阴影错觉。

前景青灰色高亮是 `water.frag` 的 HDR 掠射银泽，不属于本次问题，继续保留。

### 本轮实现

- `FableSolParams.kt`：把正式默认 `depth_scattering_strength` 设为 `0`；deep/subsurface 派生
  结构仍保留作独立诊断，不再进入默认填充色。
- `water.vert`：`relativeLongitudinalLight()` 改为严格返回基色。纵向 Z 坡度继续参与连续水面
  几何和局部片元光学，但不再压暗或宽域抬亮整片水层；删除因此失效的 `uHorizonColor` 上传。
- `FableSolLightColorPolicy.kt`：Canvas 回退使用相同的填充色恒等纪律。
- `FableSolMaterialPolicy.kt`、`FableSolGlOptics.kt`：表面反射带改为迎光与波峰双门控。无波峰或
  非迎光位置宽度为 0，近层最大约 `3dp`；HDR eligibility 同样只覆盖局部波峰。
- 保留波背阴影、薄峰透射、波冠轻纱、镜面闪点、流光和 `water.frag` HDR 掠射银泽。
- 收口此前诊断实验遗留的断言：`micro_normal_strength=0.16`、`lighten_far=0.60` 与当前正式
  实现一致。

### 验证

- Android FableSol 相关 105 项单元测试通过。
- Python 共享 shader/ModernGL 6 项测试通过，实际完成 OpenGL 3.3 编译与离屏渲染。
- `:app:assembleDebug` 构建通过。

### 真机观察重点

- 近层和中层内部是否不再出现横跨较大 X 范围的灰暗块；
- 局部波峰反射是否仍清晰，但不再形成连续宽亮带；
- HDR 青灰银泽是否仍存在且位置合理；
- 九层远近混白、局部闪点、薄峰透射和整体流动感是否保持。

# FableSol 恢复干净的坡面立体感

## 本轮更新

### 用户反馈与取舍

上一版为消除单层水体里的大范围脏阴影，关闭了纵向长波对整片填充色的调制。阴影得到控制后，
用户确认水体基色变成逐层平色，缺少“光贴波走”的逐坡明暗，整体显得过平。本轮只恢复轻量的
正向坡面光，不恢复任何压暗分支。

### 本轮实现

- `water.vert` 只取 `max(fullNdl - referenceNdl, 0)`；背光坡面严格返回原基色。
- 正向光按原基色 RGB 同比例相乘，不混天空色、不计算 Fresnel 候选色、不使用 `blackMix`，
  因此不会直接产生灰黑或偏色阴影。
- 相对增益响应为 `0.12`，近层封顶 `1.5%`；深度权重从近层 `1.0` 平滑降至远层 `0.45`，
  避免远层混白水体被过度强调。
- Android GL 与 Canvas 回退使用相同数学规则；Python ModernGL/QPainter 同步该规则，继续保持
  既有 320dp 宽度。
- 上一版的干净水体约束继续保留：深度散射默认关闭，表面反射带仍由迎光与波峰双门控，其它
  闪点、银泽、SSS、薄峰透射等局部光学不变。

### 数值验证

固定 640×840 帧关闭其它光学后，最终共享 shader 相对平色基线有 37,527 个像素发生正向变化，
所有抽样层的最小亮度差均为 `0.00`，没有任何压暗。第 1/2/4/5/7 层的 61px 横向宽域亮度跨度
分别约为 `1.49/1.50/1.54/1.76/1.02` 个单位；足以摆脱逐层平色，又显著低于旧方案近层约
4 个单位的宽域变化。

### 验证结果

- Android FableSol 相关 105 项单元测试通过。
- Python 99 项 `unittest` 全部通过，其中 ModernGL 测试实际编译共享 GLSL 并完成离屏渲染。
- `:app:assembleDebug` 构建通过。
- 未使用 ADB，也未操作物理设备或模拟器。

### 真机观察重点

- 近中层是否恢复轻微、连续的逐坡体积感，而不是整层平色；
- 原先较大范围的灰暗块是否仍未复发；
- 波峰闪点、HDR 银泽、SSS 与薄峰透射是否保持原有局部性。

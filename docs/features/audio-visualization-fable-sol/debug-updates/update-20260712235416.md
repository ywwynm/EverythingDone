# 修复 GLES 表面边带比 Canvas 过厚过白

## 用户反馈

用户截图指出，迁入 GLES 的多层白色边带明显比此前 Canvas 版本更厚或更白，要求仔细区分厚度、
颜色或二者共同影响。

## 差异诊断

- 连续覆盖 0～6 层轮廓的主要效果是表面软带，不是镜面闪点或薄峰透光。
- GLES 与 Canvas 的几何宽度公式完全一致：迎光坡、曲率、深度缩放和 density 均未放大。
- 环境地平色、层高光色、OKLab 混合比例 0.42 与基础 alpha 也一致。
- Canvas/AGSL 的带内覆盖率为 `0.66×sin(πr)`：峰值 0.66、两端归零、积分约 0.420。
- GLES 旧剖面在 14%～72% 相对深度维持接近 1.0 的平台。峰值高约 52%，积分光量也更大，
  因而同样几何同时呈现“更白”和“可见厚度更大”。

## 修复

- 表面软带、薄峰透光、波背阴影和远层羽化统一恢复 Canvas 半正弦剖面。
- 顶点 alpha 乘峰值 0.66；片元覆盖率使用归一化 `sin(πr)`。
- 几何宽度和颜色保持不变，避免同时调三个变量后无法判断来源。

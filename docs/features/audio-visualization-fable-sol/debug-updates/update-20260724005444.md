## 银丝粗细下限放宽到 0.16dp（步长同调 0.04）

按你的要求，「银丝粗细」滑杆下限从 0.3dp 放宽到 **0.16dp**。本版只动这一件事。

### 具体变化

- 范围 0.16～2.0dp；步长从 0.05 改为 0.04，这样默认值 0.60 和上限 2.00 仍然
  精确落在滑杆档位上（0.05 步长配 0.16 起点会让 0.60 取不到）。
- 你已保存的粗细值不受影响。
- 渲染侧说明：银丝是半高斯亮脊，着色器里有 0.5 物理像素的最细采样保护。
  0.16dp 档在常见屏幕密度下各层都会落在这个保护线上——效果是「最细且不断裂」，
  比 0.3dp 更淡更纤细，但不会真的细到亚像素或断成虚线。

### 本版看什么

1. 把银丝粗细拉到 0.16：银丝应明显比 0.3 档更纤细清淡，但仍是连续的线，
   不应出现珠化、断裂或闪烁加剧。
2. 默认 0.60 与其它档位、以及 HDR 等其余一切应与上一版 `202607231637` 一致。

出问题回滚上一版 `202607231637`。

## 卓易通音频海浪兼容收尾：保留最新版并隐藏调试入口

用户确认当前流畅度可以接受，并在比较历史版本后明确选择保留最新版，隐藏调试入口并提交。当前方案保留 C 系统暗层、N 直接 PQ 图层和原生控件同缓冲合成，包含异步 GPU 回收、三缓冲、最新前景补捕获、纹理复用及 90 Hz 请求。仅 API 34 及以上且命中既有卓易通环境判据启用，普通设备渲染与海浪共用计算保持。

本版通过 FableSolTuning.DEBUG_CONTROLS_ENABLED=false 隐藏海浪设置中 HDR 行的长按对照入口、调试设置组及性能面板。即使旧版本保存了 HUD 开启偏好，也不再显示。debug 清单同时禁用 FableSolHdrCompositionActivity，诊断、日志采集和文件导出代码保留供后续专门启用。HDR 强度、正式海浪参数和音视频导出设置照常可用。

本次不回退或继续调整性能。历史同状态比较中，计时提交均值约 20.82 ms 的旧版略好于当前约 21.24 ms，当前缓冲占用较低；两者处于相近水平，非受控记录不能证明哪个版本整体最优。90 Hz 请求仍不能阻止停止触摸后回到 60 Hz，不宣称已经稳定高刷。

本地构建通过；144 个套件共 1099 项检查中，1098 项通过，1 项默认关闭的 CPU 性能基准按设计跳过，零失败／错误。修正一条仍按旧无参函数签名定位渲染源码的检查，没有修改渲染实现。编译字节码与合并清单确认入口和 HUD 已关闭。未操作实际设备。

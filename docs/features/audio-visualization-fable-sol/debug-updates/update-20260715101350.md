# FableSol 恢复逐层特效并重做晶莹光影

本次更新保留已确认的静态 `lighten_far` 九层主体色板和零界面肩，恢复此前确定的逐层闪点数量、
出现率、长度、强度及 HDR 峰值。第 0～2 层仍承担主视觉，第 3～7 层恢复逐层稀疏的水面事件，
第 8 层退出离散闪点；不再因为清理圆环而把中远层材质响应整体关闭。

闪点改为贴住真实水面、出生后尺寸固定、向水内单调衰减的实心短光迹，删除解析 halo、周期扩张/
收缩和大块低频椭圆银斑。连续高光和保色暗面由同一法线、太阳方向与遮蔽关系驱动；暗面只从当前
水色降低曝光，不混黑、灰，也不整体乘暗最终 HDR。小面积银白 HDR 核心与保 Thing 身份色的 SDR
肩部独立控制，恢复峰值时不会同步扩大乳白覆盖。

折射与 Beer–Lambert 现在从未包含当前层的背景颜色开始计算，当前层 alpha 只应用一次；同时修复
体光 HDR 资格未传入、第 8 层只暗不亮、反射取错身份色和光学 HDR excess 被 alpha 二次衰减等
问题。Android GLES/Canvas 与 Python ModernGL/QPainter 已同步。

18 色 PNG 明确是 8-bit SDR 颜色与形状预览；HDR 验收改为读取 FP16 线性 scRGB 原值，并输出
`1.0/1.08/1.16/1.29/1.6/2.0× reference white` 分档伪彩图。完整效果峰值中位为 `2.934×`，
去闪点后仍为 `1.898×`。Python 158 项测试、约 63fps 的 FP16 读回基准、Android 139 项 JVM
测试和 Debug 构建均通过；未使用 ADB。请在真机重点观察中远层稀疏光迹、浅色暗面洁净度、录音
前后第 1/2 层主体稳定性，以及系统 tone mapping 下的小面积超白晶莹感。

# FableSol HDR 薄峰透射轻量收窄版

## 发布说明

### 本次目标

用户在 Debug `202607130840` 的“保留 HDR、恢复宽材质”版本上，单独要求薄峰透射
再收窄一些。本版将薄峰透射最大厚度由约 `23dp` 调整为 `18dp`，保持强度、
颜色、HDR 超白峰值与其它材质不变，便于直接判断几何宽度。

### 唯一视觉改动

- `FableSolMaterialPolicy.thinGlowThicknessDp()` 由
  `(3.0 + 20.0 * signal) * sqrt(signal)` 改为
  `(3.0 + 15.0 * signal) * sqrt(signal)`。
- 满强度透射的最大厚度从约 `23dp` 降为 `18dp`；低强度端仍保留相同的
  `3dp` 基础项和 `sqrt(signal)` 展开曲线，避免变成突然出现的硬线。
- Canvas 诊断回退与 GLES 主路径继续共用该策略，不会在两条路径中呈现不同厚度。

### 保持不变

- `thin_glow_gain=0.55`、透射颜色、4～14dp 绝对海拔门、上凸曲率门、
  HDR eligibility、第 0～4 层范围和分层 HDR 峰值不变。
- 表面反射保持近层最大约 `16.7dp`；解析光晕保持 `0.21/1.38×/4.2×`；
  `body_light_strength=0.36`。
- FP16/linear scRGB、实时 headroom、录音态 HDR 过渡、自动 SDR 回退、Thing 色轴、
  environment、远层景深、阴影、波形、音频映射和顺流流光均不变。

### 本地验证

- 更新薄峰透射最大厚度的精确回归，同时保留表面反射与材质强度约束。
- 完整 `:app:testDebugUnitTest`：106 项通过，0 失败。
- `environment`、`water`、`optical` 与 `present` 四组 GLES 程序通过
  `glslangValidator` 链接。
- `:app:assembleDebug` 和 `git diff --check` 通过。
- 未使用 adb、模拟器或物理设备。

### 真机重点确认

- 薄峰透射是否比 `23dp` 版更精细，但仍有足够的透射亮感，没有变成窄硬白线。
- 透射的亮度、Thing 色倾向与 HDR 峰值应与上版一致；只应看到厚度减少。
- 表面反射、外围光晕、`body light` 和远层景深应与 Debug `202607130840` 一致。

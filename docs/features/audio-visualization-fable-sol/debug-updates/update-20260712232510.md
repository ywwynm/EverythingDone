# 根据截图把顺流流光改为贴合波峰的弯曲软带

## 用户反馈与纠正

用户提供截图，明确指出右下方跨过波峰的长斜锐利高光。它确实是顺流流光，但上一轮只修了短轴
越界：流光仍是中心点切线上的直线，无法贴合整段弯曲波峰，两端仍可能穿到空气侧。

## 诊断闭环

- 若只是短轴越界，水体内侧半椭圆应已消除问题；截图证明长轴端点仍会越过曲线。
- 新回归直接读取真实流光顶点，并对每个顶点比较对应横坐标上的水面高度。
- `202607121517` 的直线半椭圆稳定违反 `vertexY >= contourY(vertexX)`，确认根因是中心切线近似。
- 层间网格裂缝不会作为实体持续顺流移动；镜面闪点也不会形成这种稳定平移的长直斜带。

## 修复

- 每条流光由直线椭圆改为 10 段曲面软带。
- 每段上边逐点采样当前波峰轮廓，下边只向水体内部展开，因此整条流光随波峰曲率弯曲。
- 片元着色器分别软化长度两端、水面入口和水内下缘，避免新的硬裁切亮边。
- 顶点缓冲仍为固定容量；闪点、珍珠、猫爪和层间遮挡顺序不变。

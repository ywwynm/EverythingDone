## 卓易通音频 HDR：增加固定画面合成诊断

前一版 RGBA8 PQ 在卓易通设备上仍有海浪区域穿透和白色偏青。用户提供五张 HDR／SDR 系统截图；原文件确认第 1、3、4 张含 ISO 增益图与 APP8 Vivid。白色按钮的数据基本中性，但第 1 张在华为图库重显时仍略偏青、第 4 张较正常，因此不能只归因于弹窗多图层，也不能再仅靠改位深宣称修好。

本版新增仅 debug、且仅命中卓易通判据时可进入的固定画面对照。入口：设置 → 音频海浪动画 → 长按“HDR 高光增强”。依次比较 SDR、透明 PQ、不透明 PQ、前置 PQ，画面保持一致，左圈是普通控件白、右圈是同一 PQ 画面内的白。每种模式可记录正常／偏色／穿透／两者都有，也可填写具体区域。模式 3 的方形黑角、模式 4 左侧白圈被遮住，是有意设置的试验条件。

`FableSolHdrCompositionActivity` 复用现有 EGL 与 `present.frag`，记录请求格式、验证后的输出空间、GL 像素、分类的 PixelCopy 样本、View／窗口 alpha 和用户观感。日志即时落盘，可“保存日志到下载”或“分享日志文件”，无需 ADB；默认保存为下载/EverythingDone 中的 `.txt` 文件。窗口／Surface 复制结果不是最终面板测量，不能仅凭日志判定屏幕无偏色。

正式海浪、图片 HDR、粒子动画和其它设备的渲染保持原方案。本版用于定位尚未解决的兼容问题，不宣称已修复穿透或偏色。原图只在本地读取，保留了可复核的分析脚本与元数据结果，没有改写或上传截图。

最终 debug 构建成功；相关 980 项 JVM 回归中 979 项通过、1 项既有按需探针跳过，无失败。未连接或操作物理设备／模拟器，固定画面的实际表现仍需用户在卓易通验证。

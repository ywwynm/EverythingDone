## 卓易通海浪：复用前景导入资源，补齐刷新率诊断

撤回消费等待后的日志显示，同为 60 Hz 的录音片段中，计时捕获间隔从 22.92 ms 改善至 16.67 ms，提交从 22.88 ms 改善至 20.73 ms；海浪从 53.45 至 54.57 次提交／秒，没有变慢。录音输入与系统负载并非严格受控，应用提交率也不等于屏幕显示帧率。

本版进一步减少卓易通前景每次创建、销毁 EGLImage 和 GL 纹理的成本：三个硬件缓冲复用各自导入资源，每次新内容仍重绑；GPU 最后使用完成之前不能归还或复用，尺寸改变、关闭和 HDR／SDR 上下文切换按原安全顺序收尾。明确的重绑错误会记录，并在本上下文退回逐次导入。原导入／销毁成本约 0.7 ms，实际收益仍需日志验证。

用户指出卓易通支持 90 Hz，而面板支持 120 Hz。原日志确实出现 90→60→90 Hz，应用当时仍请求 120 Hz，没有主动锁 60。本版补充窗口刷新率／模式请求、可用模式、省电状态和距上次触摸的时间，以分析系统何时降档；不修改刷新率策略。

仅调整卓易通前景路径和 debug 诊断，保持普通设备效果、共用海浪计算、shader、GL 帧循环、捕获节奏、圆角、原生控件合成、粒子和 HDR 切换方案。涉及非卓易通设备的后续优化仍会先确认。

构建及 531 项相关 JVM 回归通过，新增日志字段后重新构建通过。保留日志导出、按版本清理和手动“清空并重新记录”。可录音约 30 秒，中途轻触界面，再导出日志，联合检查缓存命中／耗时、计时提交间隔、海浪耗时及刷新率变化；同时复验圆角、计时、按钮和 HDR 切换。

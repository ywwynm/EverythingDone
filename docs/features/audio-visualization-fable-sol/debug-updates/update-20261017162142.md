## 卓易通海浪：优化计时与控件的前景更新

根据导出的性能日志，持续录音时 HDR 海浪约每秒提交 43 帧，但计时和按钮等控件只有约 17 次新帧；SDR 分别约 48 和 20。控件本身绘制很快，主要瓶颈是前景更换时约 8～10 ms 的 GPU 同步等待，以及双缓冲长期占用。这里记录的是应用提交率，不能等同屏幕实测 FPS。

本版仅调整卓易通的同缓冲前景：使用 GPU 完成信号异步回收旧纹理和硬件缓冲，正常更新不再逐次执行 glFinish；捕获池增加一个缓冲，改善海浪与控件的周转。海浪暂停时仍会回收，HDR／SDR 切换和关闭保留完整收尾；同步能力失效或超时会保守回退，防止过早重用缓冲。

保留已确认的颜色、圆角、系统暗层、粒子交接及普通设备路径。海浪还有约 11～13 ms 的网格构建开销，本轮不调整画质或算法，先根据新日志确认解除同步阻塞的实际收益。保留原日志导出，增加异步回收耗时、积压和回退指标。

构建及 474 项相关回归通过，其中 12 项覆盖资源回收和切换生命周期。尚未在卓易通实机验证本版的流畅度；请重点对比 HDR／SDR 录音计时、按钮 ripple、附件进度拖动，同时检查暂停、粒子、HDR 切换与关闭重开。长按海浪设置的“HDR 高光增强”，从原入口导出日志即可。

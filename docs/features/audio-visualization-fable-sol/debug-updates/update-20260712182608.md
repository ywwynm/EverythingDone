## 发布说明

本次优化 FableSol 手机前后俯仰，移除 `±55°` 输入硬截断及更早出现的透视平台。用户澄清此前所说的 Z 轴旋转实际是前后俯仰，并确认 55° 不是必须限制，希望完整角度范围内继续响应。

### 诊断结论

- 旧实现先在 `WaveVisualizerFableSol.setContainerGravity()` 将传感器俯仰截为 `±55°`。
- `FableSolSimulation.setPitch()` 与连续曲面内部再次执行相同限幅，输入超过 55° 后水体惯性目标完全不变。
- 渲染观察角以 `38°` 为基准硬限制为 `14°~68°`，因此静态纵深实际在前俯 `+30°`、后仰 `−24°` 时便进入平台，比 55° 更早。
- 欠阻尼弹簧本身不会造成目标回退，但需要确认新目标下初始响应方向正确。

### 本次改动

- 新增 `FableSolPitchPolicy`，集中管理完整手机俯仰、水体惯性角和渲染观察角。
- `pitchDeg` 现在保留完整 `−90°~90°` 手机输入，不再在 55° 截断。
- 新增 `motionPitchDeg`，用归一化 `atan` 曲线将完整输入平滑压缩到原有安全幅度 `±55°`；普通角度响应较快，越接近 `±90°` 变化越缓。
- 观察角改用另一条响应更快的归一化 `atan` 曲线，在完整输入上连续映射到原安全范围 `14°~68°`，消除前俯 `+30°`、后仰 `−24°` 后的硬平台。
- 连续曲面的欠阻尼惯性使用 `motionPitchDeg`，纵深透视使用完整 `pitchDeg` 经策略映射，避免一个限幅同时截断两条通道。
- 55° 仍只是水体惯性的最大输出幅度；手机到达 90° 时才渐近到该值，不再是输入临界点。

### 映射示例

- 手机前俯 `55°/70°/90°`：水体惯性目标约 `44.0°/49.7°/55.0°`。
- 手机前俯 `55°/70°/90°`：观察角约 `65.4°/66.8°/68.0°`。
- 后仰侧同样连续、单调地到达 `−90°` 端点。

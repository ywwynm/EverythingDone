# FableSol Debug 更新

## 2026-07-11 - C 阶段返工：轮廓数据改纹理采样（修复 AGSL 红屏回退）

### 诊断

上一诊断版真机天空为红色 = C3 层填充 shader 编译失败；根因是 AGSL（GLSL ES 1.0
fragment 语义）不允许 uniform float 数组的动态索引——C2 软带 shader 同样中招、
自 C1+C2 版起一直静默回退（诊断色按优先级只报第一项）。C1 抖动无数组，应存活。

### 返工

- 两个 shader 的轮廓数组换成 `uniform shader data`：top/th 归一化后编码进
  RGBA_F16 216×1 位图（r=top01、g=th01，半浮点精度 ≈0.3px），shader 在纹素
  中心 eval 两点后手动线性插值——纹理采样是动态索引的合法等价物。
- 位图从帧内递增的池中取用（首帧按需创建，之后零分配）：显示列表不快照位图
  内容，同帧复用同一张会串数据。
- 诊断天空色（红/橙/紫）与 C3 夸张档（absorption 0.80 / caustic 1.0）保留，
  供同一信号复验；确认后回优雅档并移除诊断。

### 验证

`:app:testDebugUnitTest`、`:app:assembleDebug` BUILD SUCCESSFUL；未使用 adb。
真机复验：天空应恢复正常且明显可见 C2 软带 + C3 深沉水体与浪下光丝；
若仍红/橙/紫，回报对应颜色。

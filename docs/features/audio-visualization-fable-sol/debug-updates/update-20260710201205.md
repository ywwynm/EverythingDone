# 修复水体透明与透明度闪烁（Paint.alpha 泄漏）

## 现象

Android 上水体基本一直透明，且透明度随音频每帧闪烁，与 Python 版（始终不透明）不一致。

## 根因

渲染只复用了**一个** `Paint`。Android 规则：Paint 设了 Shader 时，绘制会用 **Paint 当前 alpha 调制
Shader 输出**；而 `setColor(argb)` 会顺带把 Paint 的 alpha 设成该颜色的 alpha。高光带
（`drawVariableBand` 等）`setColor` 把 alpha 改成了很小的值，绘制下一层水面渐变时没有复位，于是
该层填充被这个小 alpha 乘了一遍——本该不透明的近层水面主体也被压成半透明，透出后面很浅的天空，
看着就像"水是透明的"。且这个泄漏的 alpha 来自高光强度、随波动每帧变化，导致逐帧闪烁。
QPainter 没有"画笔全局 alpha 再乘 brush"的机制，故 Python 不受影响。

## 修复

拆成两个 Paint 隔离 alpha：

- `fillPaint`：专管**渐变填充**（环境天空 / 九层水面 / 单侧透光 fade 带），alpha 恒 255，
  透明度全部走渐变 stop，不再被泄漏的 alpha 二次调制。
- `bandPaint`：管**纯色高光带**（`setColor` 自带 alpha，自洽）。

附带保留上一步的 View alpha 由 0.16 → 1.0（录音停止态同样保持不透明），对齐 Python 的不透明观感、
并避免整视图走离屏半透明合成。

# FableSol 调参更新 2026-07-25

## 修复银丝与星芒引入的严重掉帧

- 定因：银丝的法向距离场每帧对 97×196 网格做 18816 次 sqrt 库调用，在 debug 版的 ART 运行时上逐次穿越慢速通道，四个计算线程在同一把运行时锁上排队（真机 simpleperf：GL 线程 37.5%、行 worker 47% 的采样落在 art::Mutex 上）——单这一段就吃掉约 11.25ms，是近几版从 120fps 掉到 50 左右的主因。
- 修复一：切向与法向只依赖（层带, 列），改为按带预计算一次（sqrt 从每帧 18816 次降到 1568 次），行循环内部不再有任何库调用。测试平板实测该段 11.25ms → 0.49ms（约 21 倍）；输出逐位不变，并新增 196×97 伪随机几何的逐位对拍测试锁定等价性。
- 修复二：星芒扫描先算 apex，低于起晕门限的列提前跳过噪声、朝向与对齐计算（这些列的输出本来就精确为 0，与完整计算逐位一致）；测试平板实测 1.23ms → 0.35ms。
- 性能 HUD 第五行新增 rim（银丝距离场）与 star（星芒扫描）两个分段读数，optics 现在只统计光学实体构建本身。本版没有任何视觉改动。

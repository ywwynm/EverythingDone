## 卓易通 HDR：逐项对照暗层、背景和圆角合成

上一版实际弹窗中的固定 PQ 与海浪 PQ 都出现偏色、穿透，海浪 SDR 正常，冻结 PQ 后也没有改善。本版继续隔离窗口合成条件，正式音频弹窗的渲染方案暂不调整。

- 原入口不变：设置 → 音频海浪动画 → 长按“HDR 高光增强”。现在默认进入“实际弹窗结构”和模式 2（固定 PQ）。
- 新增 A～I 对照：A 原始配置；B 无暗层；C 相同 0.6 浓度的系统暗层；D 透明窗口背景；E 透明面板背景；F 关闭窗口裁剪；G 关闭面板裁剪；H 同时关闭两处裁剪；I 固定图不绘制圆角。
- 每项从 A 的配置出发，不叠加上一次改动。同一模式切换窗口条件时不主动重建 Surface 或 EGL。换背景时保留窗口格式、padding 和原轮廓来源，避免混入额外变化。
- 先在模式 2 依次选择 A～I，等“已生效”后点击“正常／偏色／穿透／两者都有”。有改善的 A～H 项再切模式 6 验证真实海浪。I 仅用于固定图，从 I 切海浪会明确恢复 A；准备态、冻结和模式 5 的 SDR 对照仍可使用。
- 观感按钮、备注和日志导出常驻底部。日志保存每次配置、实际暗层覆盖、背景、裁剪、几何与 Surface 会话；过期采样与未就绪反馈单独标记，可保存到“下载/EverythingDone”或分享 txt 文件。
- DialogDimLayer 只增加 debug 诊断接口，不改变正式弹窗、普通 Android 设备或已保存参数；不采集音频，不导出记事正文或屏幕图像。

本机 debug 构建及 22 项 HDR／暗层回归通过。本版用于设备对照与候选方案验证，尚不能认定偏色、穿透或黑角已经修复。

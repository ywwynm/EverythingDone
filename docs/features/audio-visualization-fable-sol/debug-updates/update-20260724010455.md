## 出厂默认调整：HDR 强度默认拉满 9.6、银丝粗细默认 0.28dp（D204 修订三）

按你的要求改两个出厂默认值，机制本身没有任何变化。

### 改了什么

- **HDR 强度默认 3.6 → 9.6（=上限）**。滑杆出厂位置在最右端；1.0=关闭、
  3.6=老标定档的含义都不变，想要老观感把滑杆拉回 3.6 即可。
- **银丝粗细默认 0.6 → 0.28dp**（新栅格第 3 格），银丝出厂观感更纤细。
- 这两项只影响「没有手动设置过」的情况。**你之前拖过滑杆的话，存的值继续生效**——
  想吃到新默认，在调参界面点一次「恢复默认」。

### 本版看什么

1. 点一次「恢复默认」后确认：HDR 滑杆在最右（9.6）、银丝粗细显示 0.28。
2. 默认档观感：低/中屏幕亮度下录音时高光应明显比 3.6 档亮且更晶莹；重点仍是
   迎光薄处大面积透光是否泛白过曝（9.6 档预算最大），不适就报档位数。
3. 银丝 0.28dp 应比原默认 0.6 明显纤细但连续不断裂。

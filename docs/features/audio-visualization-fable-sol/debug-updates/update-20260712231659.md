# 修复 GLES 顺流流光滑出波峰

## 用户反馈

用户指出，顺着水流移动、沿波面切线倾斜的流光有时会有一部分滑到波峰轮廓外侧。

## 诊断

- 当前流光使用以波面切线为长轴的完整对称椭圆，局部法向坐标固定包含 `-1` 和 `+1`。
- 这意味着一半网格位于水体外侧；原有 1.4～2.4dp 水内偏移小于部分流光半厚度，无法在宽流光
  和陡坡上可靠遮住外露部分。
- 层间绘制顺序没有错误；问题发生在流光自身相对其波峰轮廓的几何边界。

## 修复

- 流光网格改为局部法向 `0～1` 的水体内侧半椭圆，长轴仍与波面切线一致。
- 移除依赖固定 dp 的中心偏移，几何直接以当前采样轮廓为边界。
- 光学顶点新增单侧标记；片元着色器在轮廓后的 0～14% 厚度内从透明软入，避免裁切形成硬亮边。
- 闪点、珍珠、猫爪及层间遮挡顺序保持不变。

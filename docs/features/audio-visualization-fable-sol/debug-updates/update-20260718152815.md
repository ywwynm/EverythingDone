## 海浪动画：移除 17 项归零无感的表面光学参数与对应功能

- 依据模拟器逐项归零 A/B 目测裁决：镜面高光强度、高光提亮、波峰透光
  强度、透光纵深、波冠轻纱、毛细闪光、薄峰透光（deprecated）、表面
  流光、轨道摆幅、波背自阴影、空气透视压缩、1/f 慢调制、微法线带限、
  全局 1/f 呼吸、风梳微法线、朝阳次表面散射（含收束）共 17 项参数
  全部设为 0 或最小后画面无可感变化，参数与其功能代码、渲染代码整体
  移除；
- 调参 Dialog 的"外观"组同步移除上述 17 个条目，界面更精简；
- 共享 GLSL（水面顶点/片元、光学片元）删除对应 uniform、varying 与
  分支，Python 模拟器与 Android 同步瘦身，逐帧渲染与几何生成成本
  略降；
- 保留项不受影响：厚度透光、波峰银边（银丝）、天空反射、水体透光、
  界面肩、宏观受光/背坡遮挡、HDR 透射与闪点骨架（试验期数量仍为
  0）均维持既有观感。

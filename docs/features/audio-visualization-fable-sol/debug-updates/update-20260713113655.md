# FableSol Stage 2-2 双色深度散射

## 用户可见变化

- 水体在同一记事色系内增加轻微的深水色与薄峰透色，增强深浅体积。
- 浪峰透色只跟随远近视角、浪峰收拢和固定光向，不受音频瞬态直接闪烁。
- 保持上一版的高光亮度、现有光学效果、波形和运动不变。

## 技术说明

- 新增 `FableSolDepthScatteringPolicy`，在 OKLab/OKLCH 语义下派生 deep/subsurface 色板。
- deep/subsurface 色相偏移分别限制在 8°/4°，超出 sRGB 时保持色相压缩彩度。
- GLES 水面顶点新增 Gerstner 横向收拢量，`water.vert` 以独立强度 0.22 做轻量混合。
- 未新增离屏渲染 pass。

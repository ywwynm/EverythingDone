# FableSol SurfaceView 迁移预览

## 发布说明

### 本次目标

Android 官方能力表将 SurfaceView 标为完整 HDR 支持，而 TextureView 仅在 Android T+ 提供有限
HDR 支持。用户确认将 FableSol 改为 SurfaceView，并要求先发布一个 Debug 版本，单独检查容器
迁移是否破坏现有录音界面。本版尚未启用 HDR 额外亮度，也没有调整水体、波浪、光线颜色或
雾感参数。

### 容器与生命周期改动

- `WaveVisualizerFableSolGl` 从 TextureView/`SurfaceTextureListener` 改为
  SurfaceView/`SurfaceHolder.Callback`，API 26+ 统一走同一个容器，不保留双路径。
- `FableSolEglSession` 直接接收 SurfaceView 提供的 `Surface`；surface 创建、尺寸变化、销毁、
  窗口可见性与前后台切换继续由独立 `FableSolGles` 线程管理。
- SurfaceView 保持在宿主窗口下方，不使用 `setZOrderOnTop(true)`，因此录音时钟、文件名输入框、
  主操作按钮与取消/重录按钮仍应正常覆盖在水面上方。

### 淡入淡出与圆角兼容

- Android 14 以前 SurfaceView 不可靠支持 `0 < View alpha < 1`。本版移除 XML 与
  `ViewPropertyAnimator` 对可视化 Host 的直接 alpha，改用独立 presentation alpha。
- 新增 RGBA8 scene framebuffer 与共享 `present.frag` 最终合成 pass；现有水体先按原样绘制，
  最终 pass 再完成准备/停止态 `0.16`、录音态 `1.0` 及其动画过渡。
- 同一个最终 pass 输出 16dp 透明圆角与预乘 alpha，避免 SurfaceView 绕过父 View outline 后
  在 Dialog 四角露出矩形底色。
- GLES 失败时的旧 Canvas 诊断回退仍保留普通 View alpha，不影响现有红色故障提示路径。

### 本地验证

- 完整 `:app:testDebugUnitTest`：91 项通过，0 失败。
- `present.frag` 已通过 `glslangValidator` 离线编译。
- `:app:assembleDebug`：通过。
- Debug APK 已确认包含 `assets/fablesol/glsl/present.frag`。
- 未使用 adb、模拟器或物理设备。

### 真机重点确认

- 打开录音 Dialog 时水面正常显示，没有黑屏、全透明、纯红天空或首次黑帧。
- 四个圆角外没有矩形水面或底色泄漏，浅色与深色模式都应检查。
- 准备态水面较淡；开始录音时平滑增强到完整强度；停止时平滑回到较淡状态，不能突然跳变。
- 时钟、文件名与全部按钮始终位于水面上方，不能被 SurfaceView 遮挡。
- 关闭后重新打开、切到后台再回来时不出现冻结、闪烁、错位或红屏。
- 说话与倾斜响应、九层水体结构、现有颜色和光学效果应与迁移前一致。

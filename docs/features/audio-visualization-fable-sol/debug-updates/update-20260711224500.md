## 2026-07-11 - 画外出生保证补丁：中心网格上限（防静默丢包）

Python 回植时新增回归测试暴露一处边界缺陷（双端同修）：出生点只向外推时，
超远的瞄准点可能整体落到网格之外，包被静默丢弃（表达丢失）。补丁：出生
中心钳制在网格上限内（`min(max(|raw|, need), gridCap)`），外侧尾巴允许被
网格截断——发生在海绵深处，不可见且被吸收。画外全支撑保证不变。

Python 蓝本已同构回植整套画外出生硬保证并新增 4 项回归
（tests/test_offscreen_birth.py：中心瞄准外推、共鸣档不塌缩、宽包收窄、
锁步可见区不受非行波改形+波确实入画）；Python 全量 59 项、Android
`:app:testDebugUnitTest` 与 `:app:assembleDebug` 均绿；未使用 adb。

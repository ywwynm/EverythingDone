# FableSol：关闭 SDR 天空反射（清灰青光斑 + 暗部洗脏）

## 本轮更新

定位到**灰青光斑**和**暗部发脏**的共同强嫌疑：`relativeLongitudinalLight` 里那道 SDR 天空反射
（`skyReflect × Fresnel × 近白偏冷天空色`）。它反射的是近白/偏冷的环境天空 → 在受光面上就是一片/一斑
灰青，叠在水体上又把身份色和暗部洗脏。

关键判断：**Step C 之后，水面真正的"好反射"已经由 HDR 掠射银泽接管**，这道 SDR 老反射是冗余的、
而且发脏。本轮直接把它关到 0，只保留 N·L 漫反射的"光贴着波走"。

真机对照：灰青光斑是否消失、暗部是否变干净。

- 若两者都好了 → 就是这道 SDR 天空反射，确认清理；
- 若暗部仍有残留脏 → 下一刀去关 `depth_scattering` 的深色下拉或 `blackMix`，继续定位。

注：`back_shade` 继续保持关闭（dl=0，你的诊断进行中）。非 HDR 屏此刻没有镜面高光（老反射已关、
HDR 银泽是 HDR 专属），后续用"SDR 钳位版光泽"单独补上（见计划里非 HDR 屏的处理）。

## 实现内容

- `water.vert` `relativeLongitudinalLight`：`skyReflect 0.2 → 0.0`（保留 N·L 漫反射与保色暗化）。

## 验证

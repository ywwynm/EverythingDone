## 发布说明

### 用户反馈

- 完全倒置手机时，FableSol 的水面和波浪没有像原 Opus 版本一样转到录音 Dialog 顶部。
- 核对打开录音 Dialog 时是否禁止宿主 Activity 自动旋转，并保持与 Opus 一致。

### 诊断

- 以“180° 重力输入必须得到 ±180° 渲染角”建立单元测试复现。
- 旧实现将输入限制到 `[-90°, 90°]`，完全倒置因此稳定变成侧向 90°。
- 现有水体填充闭合端在 180° 时已经越过 Dialog 顶部约 80dp，绘制范围不是根因。
- 对比 Opus→FableSol 迁移前后代码，`AudioRecordDialogFragment` 的方向锁定、恢复及重力屏幕坐标换算均未改变。

### 修改

- `FableSolSimulation.setTilt()` 支持完整 360° 重力方向。
- 179°↔−179° 跨界时选择最近等价角，避免反向旋转 358°。
- 墙面过渡按水面偏离水平面的角度计算，0° 和 180° 均视为水平水面。
- 保留录音 Dialog 打开时的 `SCREEN_ORIENTATION_LOCKED`，关闭后恢复原 `requestedOrientation`。
- `FableSolContainerGeometryTest` 新增完全倒置和跨 ±180° 连续旋转回归用例。

## 巨浪的顶变宽、来得更早：轮廓拆成平顶 + 侧翼（D177）

本版只动巨浪一个东西的形状，其余所有浪、所有参数、录音链路都没碰。

### 为什么改

上一轮反馈是「巨浪有点尖，还需要更宽、波峰更圆润宽平」，并怀疑宽度的算法与人眼
感知不一致。量下来确实如此，而且比反馈说的更极端。

`WIDTH_DP = 840` 是**支撑全宽**——轮廓恰好落回水位的两点之间的距离。按等高线切开：

| 等高线 | 全宽 |
|---|---|
| 90% 浪高 | **207dp** |
| 50% 浪高 | 420dp |
| 3% 浪高 | 708dp |

把「边坡」定义成斜率超过峰值一半的区间，得到顶部平坦区只有 193dp，和 90% 等高线的
207dp 互相印证。**而 dialog 只有 276dp 宽——浪顶比画面还窄四分之一。** 所以浪峰经过
时，画面里必然同时装下峰顶和两侧下坡，看上去就是一个尖。840 这个数字买到的是两条
各 300dp 的长坡，不是一个宽顶。

时间上也一样：全程 2.82 秒里，峰顶在画面内只有 0.70 秒，真正「宽平」的观感只有
0.52 秒，前后各有 1.08 秒是单调的斜坡。

### 为什么不是换个曲线就完事

试过把它换成普通波包用的 Hann 窗——统一口径后 Hann 反而**更尖**（顶宽占支撑宽
20.5%，quintic 是 24.7%），而且要达到同样的顶宽需要更大的支撑，入场从 1.08 秒
涨到 1.72 秒。

根因不是曲线选错了：任何单尺度的窗函数，顶宽都是支撑宽的一个**固定倍数**，所以
「想要更宽的顶」必然等价于「整体放大」，坡和入场时间必然跟着涨。这是自由度不够。

因此轮廓改成**平顶 + 两侧过渡带**：顶宽和坡宽变成两个独立参数。平顶设为 0 时，
曲线逐点退回今天的形状，所以这是加了一个自由度，不是换了一套东西。

### 效果

| 指标 | 改前 | 改后 |
|---|---|---|
| 浪顶宽度（90% 浪高） | 193~207dp | **327dp**（盖住整个画面） |
| 浪峰入画时间 | 1.08s | **0.91s** |
| 侧翼最陡斜率 | 32.7° | 32.7°（一点没动） |
| 浪高上限 | 201.6dp | 201.6dp（一点没动） |
| 整体过场时间 | 2.82s | 2.79s |

入场那 0.17 秒来自另一处：侧翼最外侧 66dp 的高度不到 4.3dp（画面高的 1%），肉眼
看不见，但过去它整段都要先移出画面外才算「出生」。现在出生和离场都只按能看见的
部分算。

### 本版在真机上要看什么

**主要看巨浪**：

- 浪峰经过时是不是**明显比以前宽平**了——这是本版唯一的目的。以前是「升上来、
  尖一下、落下去」，现在中间应该有一段真正的平台。
- 入场只快了 0.17 秒，**大概率感觉不出来**，不用刻意找。真正该看的是宽度。
- 巨浪刚要进画面时，屏幕右缘会有一小段极低的抬起（约 3.6dp，画面高的 0.9%）。
  理论上看不见；**如果你能看出来右边缘有个小鼓包，请告诉我**，说明那 66dp 裁多了。

**其次看会不会发死**：平顶经过期间，巨浪底下的普通浪被压到只剩 12%（这是一直以来
的设定，没改）。以前高位只持续 0.52 秒，现在是 0.83 秒。如果这段时间画面显得
**太安静、像一块匀速平移的水台**，那就是压得过头了，我准备了两条改法，等你确认
再动。

**其它浪不该有任何变化**：普通波群、装饰点击、水位、流速、颜色、光学全部没碰。
如果发现它们也变了，那是回归，请直接说。

## 海浪动画：波浪曲线单纯化（消除轮廓上的叠加小波与生硬转折）

- 依据真机目测反馈：表面光学纹理精简后，水面轮廓上"长曲线中间叠加
  小曲线"与"峰形生硬转折"变得直接可感。三处收敛（模拟器截图对照
  定档）：
  - 连续水面方向谱的高频三模态（102/78/58dp）振幅约减半——消除叠在
    长浪上的短波碎纹；
  - Gerstner 峰聚拢陡峭度减半（谱模态与波包同步）——原先满档的峰
    锐化是生硬转折的主要来源，峰形恢复圆润；
  - 短波方向扩散收窄——减少斜向交叉波的干涉图样；
- 第一层大浪的起伏活力与远浪滚来的叙事保持不变，整体曲线回归单纯
  连贯的长波形态。

# FableSol 近处去脏：纵向受光改为封顶高光、背光坡不再压暗

## 本轮更新

远处灰浊上一版已解决（远层 alpha 抬升）。近处水体的脏定位到 `relativeLongitudinalLight` 的
**背光坡压暗**支（`base*(1-blackMix)`）：它的 `depthScale=(1-depth01)²` 和 `nearShadingWeight`
两个权重都把压暗**堆在近层**，最该晶莹的地方被压得最暗 → 近水发脏。

按"封顶高光、不要阴影"的方向重做：背光坡一律不压暗；受光坡只取 candidate 比 base 亮的差量，
按 base 比例**封顶**（`base*0.15`，保色、不冲白——冲白正是之前把旁边水色衬脏的原因）。景深交给
水层阶梯 + `lighten_far`，不再靠纵向阴影。近处因此是"纯身份色 + 受光坡温和高光"，晶莹且有光贴波走。

真机看近处水体：

- 近处干净、不再有发暗脏块，受光坡有淡高光起伏 → 达标。下一版可按需微调封顶幅度（当前 0.15）或
  给中远景补一点点景深阴影；
- 若近处高光太弱/太强 → 只调 `base*0.15` 的系数即可。

## 实现内容

- `water.vert` `relativeLongitudinalLight`：删除亮度分支 + `0.14*sqrt(darkness)*depthScale`
  压暗，改为 `lift = min(max(candidate - base, 0.0), base * 0.15); return base + lift *
  nearShadingWeight(depth01)`。顶部 candidate 计算、`skyReflect=0`、`linearSky` 引用逐字不变，
  uniform 存活性与上一版一致。
- `FableSolGlShaderParityTest`：该契约原钉 GL 与 Canvas 回退的 blackMix 阴影一致；GL 主路径现
  有意分歧，改为守卫封顶高光结构 + 断言旧压暗（`sqrt(darkness)`）已移除。测试重命名。
- Canvas 回退（`FableSolLightColorPolicy` / `WaveVisualizerFableSol`）暂不动，记为后续对齐项。

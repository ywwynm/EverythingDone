# FableSol 调参更新 2026-07-25

## 最近层星芒优先：近层更易起星，快浪不再吃亏

- 修正星芒的层间分布：此前第 0 层（最近层）出星概率常低于第 1、2 层。现在触发阈值加入近层起晕偏置（近层银丝视角更大，更低亮度即可起晕），第 0 层的越阈要求降低 60%，第 1、2 层也比之前更宽松但与第 0 层拉开差距，远层不变——最近层的星芒稳定居首。
- 星芒的起振、稳定与位置跟随改为按波速折算成恒定空间距离：最近层波速最快（216dp/s），此前星还没亮满波峰就滑出了太阳柱，现在快层包络相应缩短，不再吃亏。
- 三段测试素材、按响度分九桶实测：8 桶第 0 层星帧数居首。整体星芒会比之前更活跃；若嫌密集可在调参对话框把"星芒触发阈值"拉高，层序不受影响。
- 银丝本身的亮度与外观完全不变；星芒与银丝高亮仍是同一系统、同步涨落。

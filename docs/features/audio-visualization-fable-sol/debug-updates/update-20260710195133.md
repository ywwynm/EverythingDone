# 接入 FableSol 音频可视化（首个可运行版本）

## 背景

把桌面模拟器 `audioVisualizerSimulatorFable`（PySide6 + numpy）的**实时分析 → 九层水体
物理 → 渲染**一比一移植进录音对话框，替换原有的 Opus 可视化（Opus 代码保留）。物理与高光
一比一复刻原版；配色改接记事 `ThingBackground`（纯色 + 渐变，渐变方向沿用记事 8 向）。

## 本次改动

- 新建包 `views/recording/fablesol/`，逐模块移植：
  - 常量/参数：`FableSolSpec`、`FableSolParams`（默认值硬编码）
  - 数据/工具：`FableSolFeatureFrame`/`FableSolEvent`、`FableSolColor`（OKLab/HLS）、
    `FableSolMath`（gradient/interp/卷积/percentile 等）、`FableSolRng`、`FableSolSpeed`、`FableSolFft`
  - 物理：`FableSolDynamicWave`（波方程）、`FableSolWaveSets`（环境波/主浪/光学毛细波）、
    `FableSolSimulation`（九层浅水 + 倾斜/体积守恒水位/反弹壁/节拍锁相/性格档/晃动）、`FableSolFeatureMapper`
  - 实时音频链：`FableSolRingStat`、`FableSolBeatTracker`、`FableSolNoveltyDetector`、`FableSolRealtimeAnalyzer`
  - 渲染：`WaveVisualizerFableSol`（环境天空 + 九层水面 Catmull-Rom + 镜面/菲涅尔/透光/波冠轻纱高光），
    vsync 帧循环 drain 音频队列 → mapper → simulation → 渲染
- `AudioRecorder` 增 `linkFableSol`：采集线程把单声道 16-bit PCM 转 float 直接 feed 分析器，
  产出 frames/events 分发（与 20ms 采样间隔解耦）。采样率复用现有 44100Hz。
- 录音对话框（`AudioRecordDialogFragment` + `fragment_record_audio.xml`）可视化换成 `WaveVisualizerFableSol`；
  对话框高度 360→420dp 对齐 Fable 逻辑坐标 HEIGHT_DP（宽度随 TimelyClockView 自适应，不改）。

## 需在真机重点验证

- **视觉/物理**：九层水面层次、主浪/环境波起伏、注入浪滚动、镜面高光与波峰透光是否接近原版观感。
- **配色**：纯色记事与渐变记事（含 8 向）下的水体颜色与渐变方向是否正确、与主题一致。
- **性能**：九层 × 216 点物理（120Hz 子步）+ 每层高光渲染较重，注意中低端机是否掉帧。
- **重力倾斜**：手机倾斜时水面汇聚方向、回荡是否自然；`setContainerGravity` 的倾角符号可能需按真机校准。

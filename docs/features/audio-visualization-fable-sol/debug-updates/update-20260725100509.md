# FableSol 调参更新 2026-07-25

## 星芒亮度随 HDR 强度与银丝同步，最亮可达 9.6

- 修复星芒亮度被钉在 3.6 标定档的问题：HDR 录制时星芒出射亮度现在乘以与银丝超白相同的强度缩放，HDR 强度 9.6 满增益下最亮星核与银丝最亮处一同达到 9.6 倍参考白。
- 这也是此前把针芒长度从 96dp 拉到 129dp 看不出差异的根因：亮度不够时针芒尾端早已暗于一个显示台阶。修复后最亮星的可见针芒约 132dp，129dp 上限真正生效。
- 星芒的出现频率、位置、主从关系与 SDR 观感完全不变；HDR 强度调到 3.6 及以下时画面与之前逐位一致。
- 上一版（202607250152）已将针芒长度上限放宽到 129dp，本版在此基础上补齐亮度同步。

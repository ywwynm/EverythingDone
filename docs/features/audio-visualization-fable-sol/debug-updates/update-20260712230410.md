- 闪点是否少量、持久、贴着受光浪面，不是一帧一换的闪烁噪点。

- 流光是否顺流缓慢漂移，猫爪是否是软入软出的暗纹。
- 近层水体是否正确遮挡远层实体，持续播放和倾斜是否仍保持流畅。

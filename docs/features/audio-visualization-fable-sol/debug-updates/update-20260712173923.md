# 让阴影混黑量随水体层级递减

## 发布说明

用户指出固定混黑比例仍会让远层阴影过重：远层水体已经被空气透视提亮，同样比例的黑色
反而更显眼。本次让波背阴影和猫爪暗纹的混黑量统一随 `depth01` 递减；近层保持原黑度，
越远越浅，最低保留基础黑度的 35%。完整 39 项单测及 Debug 构建通过，未使用 adb。

### 修复

- 有效混黑比例统一为：`基础比例 × max(0.35, 1 − 0.85×depth01)`。
- 波背阴影：第 0 层保持 18%；当前最远参与的第 5 层约降至 8.4%。
- 猫爪暗纹：第 0 层保持 24%；当前最远参与的第 2 层约降至 18.9%。
- 只改变阴影颜色，不重复修改既有层 alpha、空气透视、阴影几何或出现条件。

### 验证

- 先把 `depth01=0/0.25/0.625/1.0` 的红、绿、蓝、黄、紫颜色纳入回归；固定比例实现
  稳定失败。
- 应用深度衰减后，所有输出均精确等于当前层颜色按动态比例混黑，且越远混黑越少。
- `:app:testDebugUnitTest`：39 项通过，0 失败。
- `:app:assembleDebug`：通过。
- 未使用 adb、模拟器或物理设备。

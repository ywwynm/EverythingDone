## 发布说明

本次修正 FableSol 水面中由纵向法线光照产生的灰黑暗部。用户在前两轮阴影颜色调整后进一步确认，主要问题并非波背或猫爪显式阴影，而是与光线相关。

### 诊断结论

问题定位到 `WaveVisualizerFableSol.applyLongitudinalLight()`。旧实现分别计算完整三维法线与参考二维法线的受光结果，再逐 RGB 通道执行 `base + fullLight - referenceLight`。当纵向法线带来负向光照差时，天空反射色及各通道差值会把水体暗部推离当前记事颜色，形成不自然的灰黑区域。

### 本次改动

- 新增 `FableSolLightColorPolicy`，集中约束纵向光照的颜色输出。
- 正向受光、高光和更亮的天空反射候选色保持原样，不降低亮部表现。
- 负向光照不再直接采用逐通道相减结果，而是提取其相对暗度，将颜色约束为当前层记事颜色混合黑色，保持主题色身份。
- 近处负向光照的最大混黑量为 14%，并随相对暗度的平方根变化。
- 混黑量按 `max(0.05,(1-depth)²)` 随水体层深快速衰减，远方的黑色很淡。
- 法线、Fresnel、透射、天空反射、光照几何和正向受光强度均未改变。
- 此前波背与猫爪阴影的主题色混黑策略继续保留。

# FableSol 加入局部保色坡面阴影

## 本轮更新

### 用户反馈与目标

在此前“干净水体”与 D87 正向坡面光的基础上，恢复少量随波形变化的明暗转折，减少水体过平的观感；
同时避免重新出现近中层大范围灰暗、远层脏污或整层曝光下降。

### 实现内容

- 新增默认参数 `macro_shadow_luma_cap=0.018`，表示阴影造成的最终线性亮度损失上限。
- 保留 D87 的同色正向坡面提亮；背坡只在宏观法线相对参考法线的负向 `N·L` 足够强时生效。
- 使用 `0.08～0.18` 坡度门、`0.35～0.70` 深度退出和 crest 局部门控；远层完全退出，宽缓坡只保留
  很弱的底权重。
- 阴影颜色只朝未混白 Thing 身份色派生的 `deepColor` 移动，并按最终 linear RGB 亮度损失反解
  混色量；不混黑、不使用微法线暗纹、不整体压暗环境或水体底色。
- GLES 共享 `water.vert` 与 Canvas 回退使用同一规则；Canvas 逐顶点路径没有新增临时数组分配。
- Python ModernGL 改为直接复用 Android 共享阴影函数，避免重复注入；QPainter 保持同构。

### 保持不变

- `lighten_far=0.864`；
- Python 320dp 宽度；
- `depth_scattering_strength=0`、微法线、HDR、SSS、闪点、表面反射及其它局部光学参数；
- 水面物理、层序、颜色呼吸和音频映射。

### 验证结果

- Android FableSol 全量单元测试在 `--rerun-tasks` 强制重编译下通过。
- Python 104 项 `unittest` 全部通过。
- ModernGL 已实际编译并渲染新的 Android 共享 shader。
- `:app:assembleDebug` 构建通过。
- 未使用 ADB，未操作物理设备或模拟器。

### 真机观察重点

- 近中层坡面是否恢复适量、平滑的立体转折；
- 阴影是否随波移动，而不是形成固定的大块灰斑；
- 远层和宽缓坡是否继续保持干净；
- 若强度仍不足，后续优先小幅提高亮度上限，不扩大阴影范围。

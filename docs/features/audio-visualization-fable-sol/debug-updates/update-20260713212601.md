# FableSol 诊断：关闭微法线（隔离"暗部混杂灰黑颗粒"）

## 本轮更新

已确认清掉的：灰青光斑（SDR 天空反射）。已排除的：back_shade、depth_scattering（关掉后暗部仍脏，
说明脏不是这些"保色加深"）。

本轮关**微法线**（`micro_normal_strength = 0`）。它给水面叠 ±18% 的细密明暗噪点，在暗部会表现为
一层细碎的黑点/脏纹理，跨近远都有——最符合你一直说的"混杂着灰黑色"。其它保持（`skyReflect=0`、
`back_shade=0`、`depth_scattering=0`）。

真机对照：暗部那种"混杂的灰黑/脏纹理"是否消失。

- 消失了 → 就是微法线的噪点，下一版把它的强度、暗部足迹和带限重做（暗部收敛、亮部保留细节）；
- 还脏 → 我基本把水体内部的东西都关过一遍了，剩下就是基础层色/合成本身。到那一步，**麻烦你发一张
  当前的截图**，我直接看着定位，比继续盲关快很多。

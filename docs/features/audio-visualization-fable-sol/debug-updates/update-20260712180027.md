# 让远层阴影黑色接近消失

## 发布说明

用户进一步明确“远方的黑色要很淡很淡”。上一版线性深度衰减仍强制保留 35% 的基础
黑度，本次改为平方衰减 `max(0.05, (1−depth01)²)`：近层保持原阴影，中远层迅速变淡，
最远端波背实际只混黑约 0.9%。完整 39 项单测及 Debug 构建通过，未使用 adb。

### 黑度变化

- 波背基础黑度 18%：第 0 层 18%，第 2 层约 10.1%，第 5 层约 2.5%，最远端约 0.9%。
- 猫爪基础黑度 24%：第 0 层 24%，最远参与的第 2 层约 13.5%。
- 5% 是“基础黑度的保留比例”，不是直接混黑 5%；因此远端不会留下明显黑斑。
- 阴影仍由当前层记事颜色混黑生成，不恢复固定灰黑/蓝黑或额外冷偏。

### 验证

- 先把红、绿、蓝、黄、紫代表色的深度期望改为平方衰减，旧线性策略稳定失败。
- 应用新曲线后，0/0.25/0.625/1.0 四档深度的颜色回归全部通过。
- `:app:testDebugUnitTest`：39 项通过，0 失败。
- `:app:assembleDebug`：通过。
- 未使用 adb、模拟器或物理设备。

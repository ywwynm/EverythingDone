# FableSol HDR 上恢复去雾前宽材质对照版

## 发布说明

### 本次目标

用户真机确认 Debug `202607130828` 已成功进入 HDR，但希望在现有 HDR 基础上，把
表面反射、薄峰透射和闪点外围光晕恢复到第一阶段去雾收紧前，并重新加回
`body light` 进行观感对照。本版只恢复这四项共享材质，不回退 HDR 管线、颜色归一、
水层景深或自动 SDR 回退。

### 恢复的材质

- `body_light_strength`：由 `0.0` 恢复为去雾前的 `0.36`，重新生成九层体积光带。
- 表面反射：带宽公式恢复为
  `(2.2 + (10.5 + 4.0 * crest) * facing) * (1 - 0.45 * depth)`，近层最大约
  `16.7dp`，而不是收紧版的 `9.4dp`。
- 薄峰透射：厚度恢复为 `(3.0 + 20.0 * signal) * sqrt(signal)`，最大约
  `23dp`；`thin_glow_gain` 由 `0.38` 恢复 `0.55`。
- 闪点外围解析光晕：`analytic_halo_strength` 由 `0.10` 恢复 `0.21`；长度恢复为
  核心的 `1.38×`、厚度 `4.2×`、alpha 系数 `0.24`；`optical.frag` 恢复
  `exp2(-4.6*r²)` 衰减与 `0.82` 边界软出。

### 明确保留的边界

- FP16/linear scRGB、`GL_RGBA16F` scene framebuffer、实时 `hdrSdrRatio`、API 35+
  desired headroom、0.36 秒录音态 HDR 过渡和逐环节 SDR 回退全部保留。
- 近、中、远层的 HDR 峰值阶梯不变；第 6～8 层仍不产生明显超白峰值。
- 恢复的 `body light` 与 analytic halo 仍为 SDR 材质，HDR eligibility 固定为零，
  不会变成九层超白体光或 HDR 大光晕。
- 表面反射和薄峰透射继续使用现有朝向/峰尖 eligibility 和分层峰值，只恢复其
  材质宽度与 SDR 基础能量。
- `pearl_shift_deg=0`、`hue_temp_deg=0` 和 Thing 色到中性白的高光色轴保持；
  不恢复固定青/蓝派生色、周期色相摆动或偏冷高光。
- `crest_veil_strength=0.14`、镜面闪点数量、environment、`lighten_far`、九层
  alpha、远层羽化、阴影、波形、声音映射和顺流流光保持不变。

- 表面反射与薄峰透射恢复后，水体是否更充盈、晶亮，宽光是否回带可接受的柔和感。

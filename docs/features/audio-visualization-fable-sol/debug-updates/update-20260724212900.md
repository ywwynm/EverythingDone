## 2026-07-24 - 星芒主刃偏水平 + 逐星差异（D213）

星芒针表整体旋转 90°：主刃（最长针芒）改为**偏水平**起始。针芒重构为
**逐星解析精灵**——每颗星携带自己的针表，朝向偏移（±26°，保持偏水平
基调）、转动速度与相位、参差程度、针芒长度都由出生时的种子决定、终生
稳定且星与星互不相同（物理：不同视场方向的光穿过泪膜/晶状体的不同区域，
星芒图案本就各不相同——同时看两盏路灯的星芒确实不一样）。针芒改为全
分辨率解析求值，细线质量不再受半分辨率采样限制。

强度/梦幻光晕/触发亮度/针长/线数/参差/远层衰减七滑杆语义不变；参差与
呼吸、慢旋在逐星差异之上继续生效。Android assembleDebug + fablesol
测试包全绿，与 Python 模拟器同步定档。

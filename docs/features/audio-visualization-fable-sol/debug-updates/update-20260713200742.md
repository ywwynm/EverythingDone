# FableSol Step B 补丁：远处灰黑修复（打光随水层混白而衰减）

## 本轮更新

上一版（Step B）灰青带好转，但**中远处波背的灰黑更严重**。根因已确认：远层水色是被有意混白的
（水层景深阶梯），而水体的深色（deep）是从**已经混白的层色**派生的——所以**给乳白的远层加深，只会
变成灰**（白 + 黑 = 灰，而不是更深的身份色）。上一版加大了加深量，远处灰黑因此更重。

本轮修复：让**加深与打光随水层变白而逐渐减弱**。饱和的近层保留全额明暗对比和"光贴着波走"；乳白的
远层几乎不再被加深，交给景深阶梯保持干净、柔和。

真机重点观察：中远处的灰黑是否消失、近层对比是否仍在、近到远的过渡是否自然。

## 实现内容

- `water.vert` 新增 `nearShadingWeight(depth01) = mix(1.0, 0.15, smoothstep(0.15, 0.70, depth01))`。
- `depthScattering` 的强度乘 `nearShadingWeight(depth01)`；`relativeLongitudinalLight` 的最终输出对
  `base` 按 `nearShadingWeight(depth01)` 混合（亮、暗两支都衰减）。
- 未改几何、身份色派生、HDR、光学实体；shader 契约关键串保留。

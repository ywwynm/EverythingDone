## 水体质感提升：银丝细化与逆流滑动

- 银丝更纤细（亮芯 0.6dp），层级递减更分明：近层最清晰，越远越细越淡，
  最远层仅余隐约痕迹；
- 新增"逆流滑动"视差：银丝上的亮段以恒定速度沿波脊向右缓行，与波浪的
  左滚形成两层运动（物理来源：深水波群速为相速一半，镜面亮区随波群走、
  相对波峰恒向后滑移）；暂停时随画面一同静止；
- 修复滑动调制在部分 GPU 上完全失效的问题（着色器噪声大参数精度），
  亮段明暗现在在所有设备上一致可见；
- 银丝峰值亮度维持闪点核心同档（录音态 HDR 下太阳对准段最高 3.6 倍
  参考白，近层最亮），非录音态严格不越参考白；
- 覆盖全部记事配色；闪点仍处评审期关闭状态，由银丝承接其表达。

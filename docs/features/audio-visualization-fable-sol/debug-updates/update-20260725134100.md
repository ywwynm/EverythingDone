# FableSol 调参更新 2026-07-25

## 打开录音对话框的屏上渲染性能面板

- 录音对话框顶部现在叠一块半透明的等宽文字面板，实时显示渲染性能读数：实际帧率与 GL 帧间隔（含 p95）、面板刷新率与系统实际服务速率、vsync 周期与派发丢帧率、GL 线程的分段耗时（物理 / 建帧 / 绘制 / 提交），以及建帧内部的采样、顶点、坡度、配色、光学各段和物理步数的分位数。
- 只有 debug 版会出现，release 版整段代码会被编译期移除。面板本身的统计与格式化都在独立线程上做，不占 GL 线程；性能日志文件的记录行为与之前一致。
- 这一版没有任何视觉或功能改动，只是把原先默认关闭的屏上读数打开，省去为了看一次帧率而拉设备日志。看完可以再关掉。

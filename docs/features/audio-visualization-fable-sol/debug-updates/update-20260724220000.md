# FableSol Debug 更新

## 2026-07-24 - 星芒性能优化（D214）

针对星芒引入后的渲染耗时回归与偶发卡顿（Python 模拟器实测星系统每帧
+1.52ms，尖峰帧与星数相关）：

- 星光轨迹的波顶辐亮度扫描加**太阳柱窗口裁剪**——apex 门在柱窗外精确为
  零，只扫窗内列（近层省 ~45%、远层省 ~70%，锚点结果逐位不变）；
- 消除逐帧分配与重分配：星点/针芒 VBO 首帧定容、逐帧 SubData（逐帧
  glBufferData 重分配是部分驱动的偶发卡顿源）；逐星图案改零分配推导；
  轨迹整理改手写移除 + 小容量插入排序（去 lambda/装箱垃圾）；
- 模糊 tap 数按 σ 收敛（近核弥散 ±4、宽晕 ±12，原一律 ±12）；
- **眩光 program 预编译**移到表面初始化（原首颗星出现的那一帧才编译
  5 个 program——正是"偶然一次大卡顿"的来源）。

Python 端同构优化（另含九层合批）后实测：星系统每帧开销 1.52→0.86ms、
尖峰帧回落，星的出现频率/数量/形态逐位不变；pytest 362 项全绿。Android
assembleDebug + fablesol 测试包（50 类）全绿。视觉无任何变化。

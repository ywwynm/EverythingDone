## 海浪动画调参界面二轮打磨

- 预览区贴顶满宽、去掉标题，底部两角与参数区无缝衔接；
- 预览取景整体上移，最近一层水体的波谷不再被下边缘遮挡；
- 预览右上角新增两个按钮：暂停/继续（冻结当前画面），以及切换水体
  颜色——颜色从你创建过的记事背景、内置十色与主题渐变中随机选取，
  切换时新颜色的波浪从右侧涌入、逐渐融合替代，界面上的强调色元素
  （分组标题、滑杆、勾选框、按钮）同步渐变跟随；
- HDR 开关行的勾选框与触摸反馈改为与设置界面一致的渐变样式，
  确定按钮采用标准强调色；
- "质感提升（试验）"分组更名为"质感"，调节项间距增大，底部新增
  滚动指示分隔线。

## FableSol：实时感知、可持续七境与巨浪演出重构

- 重构实时感知标定：动画改用固定声学域的响度 `W`、速度 `K`、强度 `I`、能量/上升、四类音乐运动和 grade 证据，不再让曲内自适应响度或旧诊断刻度造成同类高潮水位、流速和状态大幅漂移；
- 手机录音使用固定 capture 档与母带域对齐，原始 A 计权静音门继续读取未补偿 PCM，避免增益补偿把底噪误当内容；本版不打包可选神经人声模型，只使用低成本实时 DSP 人声/音节运动；
- 七境改为严格因果的软时长解码。`LIFT` 与 `CLIMAX` 都可随证据持续，不再有 4.5 秒演出上限；快速女声 solo 可以保持高流速而不被错误等同于最高境地；
- 巨浪改为 `PEAK` / `CLIMAX` 中可重复出现的乐句重音：取消每个高潮最多两道的配额，统一使用 14 秒全局冷却；Section、Drop、段内急剧到达和强新奇度都必须同时通过当前音乐运动、水位、速度和强度门，不使用歌名或时间戳硬编码；
- 巨浪物理实体固定为第 0 层 840dp × 144dp 的完整 C2 宽峰，从画外按当前真实流速自然通过；没有特殊演出计时、冻结、拉长或途中变形；
- 所有九层、97 条深度行统一采用 C2 B-spline fairing、六阶软限幅、逐行单调 X 修复与 Hermite 重建；Hero 出生前沿同步改为 C2。GLES 主路径与 Canvas 回退均移除二次 Catmull-Rom 过冲，减少尖角、尖凹、阶梯和波顶分叉；
- 音频 hop 在渲染端逐个按权威音频时间消费，并把 Onset、Section、Drop、Prominence 稳定交织回相邻 hop，避免 60/120Hz 显示帧率吞掉 0.2 秒确认窗；水位、流速、浪幅、层距、银边和闪点容量由同一连续状态通道驱动；
- 保留原有 GLES、FP16/scRGB HDR、4× MSAA、scene-linear、120Hz 固定物理与逐像素材质。行并行器改为常驻 worker 和可复用同步状态，移除每帧数千个短命任务/同步对象，不降低网格、物理频率或视觉质量；
- 新增“音画耦合”调参组（表达幅度、状态灵敏度、过渡速度），声音分析组新增“响度瞬态加成”；默认值与 Python 蓝本一致，13 种语言资源已同步；
- 真实音频回归：Lose My Mind 在约 53.133s、69.617s、139.900s、158.800s 命中四处目标巨浪；录音版在覆盖到的对应高潮 54.083s 命中；《银花玉鉴逐人来》在 143.267s 命中，约 32 秒没有短促 CLIMAX。Python 281 项测试 + 23 个子测试、Android 193 项 JVM 测试全部通过，Debug APK 组装成功。

# 移除珍珠/猫爪并迁移四类 GLES 表面效果

## 用户要求

移除珍珠斑、猫爪暗纹；继续 Stage 1 的表面软带、薄峰透光、波背阴影和远层羽化。

## 删除项

- GLES 与 Canvas 回退均不再绘制珍珠斑和猫爪暗纹。
- 删除珍珠跨帧跟踪列表与生成逻辑。
- 删除 `FableSolFeatureMapper` 的猫爪事件入口。
- 删除 `FableSolSimulation` 五槽阵风数组、生成 API、顺流推进和寿命剔除。
- 删除已无调用的猫爪阴影颜色策略及回归。
- 镜面闪点与顺流流光保留。

## GLES 表面效果

- **表面软带**：0～6 层；迎光坡更宽、背坡更窄，曲率控制波峰开合，并混合环境地平色。
- **薄峰透光**：0～4 层；保留高出均线 4～14dp 的绝对海拔门与上凸薄度，使用偏青透射色。
- **波背阴影**：0～5 层；背光坡×脊线邻近，颜色从当前层记事色向黑混合并随深度减弱。
- **远层羽化**：7～8 层；按 `calm01` 把轮廓软溶到环境地平色。
- 前三项沿轮廓只向水体内侧展开；羽化按溶解语义跨轮廓两侧。
- 全部效果复用 `FableSolGlOptics` 的预分配曲面带，按层穿插绘制；固定容量 20000 顶点，无帧内扩容。

# FableSol Stage 1 首个 OpenGL ES 纵向切片

## 发布说明

### 本次目标

真机日志已确认 Canvas 水体的 CPU `onDraw` 中位数约 32.8ms，GPU 只有约 4ms，无法满足
稳定 60fps。本次正式进入 Stage 1，以一条可运行纵向切片先验证 TextureView + EGL ES 3.0
独立渲染线程、共享 GLSL、连续水面基础几何与真实音频/重力链路。

### 架构改动

- 新增仓库级 `shared/fablesol/glsl/`；Android 通过 assets 直接加载，后续 Python moderngl
  读取同一份文件，不再双端复制 shader。
- 新增透明 `WaveVisualizerFableSolGl` TextureView、`FableSolEglSession`、独立
  `FableSolGles` HandlerThread 和 latest-frame 合并；UI 线程只投递 60Hz 时间戳。
- Simulation、音频 frame/event 消费、latest-value 重力、25×最多 120 列连续水面构建、
  VBO/EBO 上传、绘制和 swap 全部移出 UI 线程。
- GL 性能日志新增 `glFrame drain/physics/build/draw/swap` P50/P95/P99；EGL 或 GLSL
  失败会写 `[DEBUG-FABLESOL-GL]` 并降级为静态 Thing 色。

### 当前视觉覆盖

首批 shader 已实现环境天空、连续 2.5D 网格、九层颜色 alpha 合成、Thing 纯色/八向渐变、
纵向坡度受光、Fresnel、抖动和近层深水填充。录音 Dialog 已实际切换到该 GL 路径。

持久闪点、珍珠、流光、猫爪暗纹、表面软带、薄峰透光、波背阴影和远层羽化尚未迁移，
因此本版视觉会比 Canvas 基线简洁；旧 Canvas 类仍保留作源码对照，待 GL 一比一验收并观察
一个发布周期后再删除。

### 验证

- 新增连续网格索引布局测试，覆盖八个深度组、顶点边界与索引范围。
- 完整 `:app:testDebugUnitTest`：通过。
- `:app:assembleDebug`：通过。
- APK 已确认包含四份 `assets/fablesol/glsl/*`。
- 未使用 adb、模拟器或物理设备。

### 真机重点确认

- 水面是否正常显示，而非静态底色、黑屏或全透明；日志不得出现 `[DEBUG-FABLESOL-GL]`。
- Dialog 圆角、整体 alpha、出入场动画和上层文字/按钮是否正常。
- 说话和倾斜是否驱动水体；基础九层颜色、渐变方向和远近结构是否正确。
- 回传 `fablesol_frame_perf.log`，重点看 `glFrame` 五段分位数与 Window total/GPU。

# FableSol Debug 更新

## 2026-07-11 - 根治浪包突然隆起/鼓包 + 移除焦散

### 用户反馈

① 焦散两轮修形后仍不好看，裁决删除；② 长期顽疾：波浪形状偶发突变——波峰
侧面突然鼓起、平水面突然升起几十 dp 的浪包、浪包突然回落，频繁且幅度大；
用户确认与水位高低无关（水位目测不变）。

### 根因（本次定位）

注入浪包是 Hann 窗（支撑 = 全宽 width），出生点本应在画外，但存在两个越界机制：

1. **主因**：`injectLayer` 的 `uLimit` 向内钳位在共鸣档塌缩——melodic/loud 状态
   使 `resonance01→1`、`wallBlend≥0.35>0.3`，画外余量从 140dp 塌缩到 **12dp**，
   此后每一次注入（音头/波群/重音/远浪）都被拽到可见边缘，半个包体
   （48~140dp）直接压进画面，120ms 渐入内隆起可达几十 dp。这解释了"频繁、
   幅度大、与声音活跃相关、改别处永远治不好"。
2. **次因**：各注入路径的随机项（jitter σ=0.26~0.32·width、pan ±0.08·span、
   frac 0.30~0.65）的统计尾部本就能越过画外边界；A6 的 looming/冲击性把包宽
   最多放大 1.3 倍后越界更频繁。

物理核验：共鸣档墙外 `cScale=0.65`，画外出生的包**可以穿墙进入**（墙区海绵
适度吸收，与共鸣语义一致），故向内钳位并非物理必需。

### 修复

`injectLayer` 对显式出生点改为**画外全支撑硬保证**：need = 可见半宽 + 半包宽
+ 8dp，出生点只向外推（|u| ≥ need）、绝不向内拉；need 超出网格容量时先收窄
包宽保持支撑完全画外，仍放不下则丢弃该包。浪从此只能以行波形式进入画面
（D12/D17 语义的最后一块）。同时整体移除焦散（shader/参数/相位/聚焦场）。

### 验证

`:app:testDebugUnitTest`（含浪形连续性与传播回归）、`:app:assembleDebug`
BUILD SUCCESSFUL；未使用 adb。真机验收：正常/响亮/音乐场景长时间观察，
可见区内不应再出现任何非行波进入的突发隆起或回落。

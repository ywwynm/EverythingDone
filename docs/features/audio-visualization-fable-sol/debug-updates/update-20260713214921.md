# FableSol 诊断：关闭受光坡提亮（红框暗斑）

## 本轮更新

背光坡压暗关掉后红框暗斑仍在，排除它。水体内部只剩 `relativeLongitudinalLight` 的**受光坡提亮**。
怀疑 Step A 的陡法线让受光坡提亮冲到接近白（发白亮带），把旁边正常水色**衬得又暗又脏**——暗块的根
在旁边"太亮"。

本轮关**受光坡提亮**（背光压暗恢复，使两支分支不同、避免着色器把 uniform 优化掉；candidate 仍用于判据）。
真机对照红框：

- 干净了/水面均匀 → 受光提亮冲太狠衬脏。下一版给提亮**封顶**（受光带只到浅色、不冲白），再把诊断关掉的
  项干净加回；
- 还在 → 不是任何打光效果，是基础层色/合成本身，转钻 `buildColors` 代码。

## 实现内容

- `water.vert` `relativeLongitudinalLight`：受光坡分支改为 `return base`（关闭提亮）；背光坡压暗恢复。

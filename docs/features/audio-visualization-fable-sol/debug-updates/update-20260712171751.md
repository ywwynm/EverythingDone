# 优化连续水面倾斜手机时的专项卡顿

## 发布说明

用户复测确认正常播放流畅，主要卡顿发生在倾斜手机期间。诊断发现倾斜会把连续水面的
渲染列数从水平 110 列扩大到最高 190 列，同时边界阻尼剖面在 120Hz 物理子步中约
114Hz 重建。本次把连续渲染固定为最多 120 个等距插值列，并把边界剖面更新限制为
30Hz；安全采样窗首尾、完整 216 点物理网格、120Hz 波方程和传感器手感保持不变。
36 项单测及 Debug 构建通过，未使用 adb；需真机重点复测倾斜过程的流畅度。

### 复现与诊断

- 宽 276dp 时，投影安全窗口原始列数为：`0°=110`、`30°=172`、`45°=186`、
  `60°=190`、`90°=160`。25 行网格、逐顶点颜色和九层光学均随列数增长，最高
  比水平姿态多约 73% 工作量。
- 固定姿态与连续倾斜的同条件 1200 帧物理基准显示，倾斜路径额外开销在重复运行中约
  7%～47%；加入边界重建计数后确认，持续倾斜 2 秒会执行 227 次 `rebuildBc()`。
- `rebuildBc()` 每次重新计算 9×216 个边界阻尼、波速、黏滞和滞后剖面，并调用大量
  `exp`；缓存失效来自 `span`、`wallBlend`、`tiltAgit` 每个物理子步持续变化。

### 修复

- 新增连续渲染列预算：原始列数不超过 120 时全部保留，超过时在安全窗口完整首尾之间
  等距插值为 120 列。首尾位置由共享纯逻辑函数计算并有回归测试，避免优化重新引入
  两侧空白。
- 连续曲面的轨道、轮廓、坡度和波冠轻纱均按相同源索引与分数线性插值；物理模拟继续
  使用完整 216 点网格，25 行纵深和九层角色不变。
- 边界阻尼剖面最多 30Hz 重建，最大滞后 33ms；波方程仍以 120Hz 更新，倾斜激励和
  三维重力传感器输入不降频、不增加低通。
- 同一倾斜物理基准中，优化后相对固定姿态的额外开销降至约 12%。

### 验证

- 新增渲染列预算回归：各姿态实际列数为 `110/120/120/120/120`，最大差不超过 10；
  插值首尾严格等于安全窗口首尾。
- 新增边界剖面频率回归：连续倾斜 2 秒重建次数必须处于 30～65 次，不得回到约 227 次。
- 原有多宽度、多滚转角远行覆盖回归继续通过。
- `:app:testDebugUnitTest`：36 项通过，0 失败。
- `:app:assembleDebug`：通过。
- 临时倾斜计时探针已删除；未使用 adb、模拟器或物理设备。

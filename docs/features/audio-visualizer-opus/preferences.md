# 偏好 — 录音波浪可视化（Opus 版）

## 2026-07-06 - 倒置触底后应有侧壁爬升和大波浪，不应只是整块弹簧回弹

用户反馈：水坠落到新底部后，当前反应太弱，像弹簧一样弹一下就结束。更符合直觉的表现应包括部分水爬到两侧壁上、撞底后被挤压生成较大的波浪、随后回落和反射回荡。

偏好：触底后的主要反馈应来自水体内部的动量和自由面大形变，而不是整摊水作为刚体反弹。允许夸张一些的侧壁 run-up、中心凹陷、两侧大浪和回荡；仍不新增泡沫、粒子雨或可见边框。

## 2026-07-06 - 斜向倒置下坠不应在触底前翻转或闪烁，应保留每层自由下落

用户反馈：如果先倾斜手机再翻转，水体沿 dialog 斜对角坠落时，初始高度仍像按未倾斜状态设置，快触底时水面会瞬间翻转并闪烁几次。用户判断：不应该在触底前翻转；应让每一层水自由下落，触底后自然跳动和恢复。

偏好：斜向下坠阶段必须保留触发前的几何高度和层级，不能在接近底部时提前混回新重力水面。触底前只做自由落体；触底后再通过冲击、爬墙、回荡逐步恢复正常状态。

## 2026-07-06 - 倒置下坠接近落地时不能突然涨满，水片左右不能露出斜切面

用户反馈：当前版本在水下坠到接近新底部时，水位会突然升高到几乎占满 dialog，下一帧又变回正常水位；下坠过程中在轻微倾斜时，水体左右侧可能没有占满 dialog 宽度，露出非常平整的斜切面。

偏好：空中阶段必须始终是有限厚度的水片，不能在落地前一帧临时切回近似“无限深”的正常填充；真正触底后才恢复正常水位。水片左右边缘不应在可见区域内形成直线切口，应延展到 dialog 裁剪区外，让用户看到的是水体被容器裁掉，而不是水片自身的平整侧边。

## 2026-07-06 - 倒置下坠开始时必须保留原 6 层水的层级

用户反馈：当前版本下坠开始时仍会看到瞬间层级反转，且水的高度被缩减。倒置触发后，不能马上按新重力重排 6 层水，也不能只保留前景波浪线。

偏好：倒置下坠的空中阶段应保留原本 6 层水的层级、位置关系和可见高度；只有真正坠落到 dialog 边缘、发生触底/铺展之后，层级才能自然恢复到新重力下的正常结构。换句话说，空中落体是“原来的 6 层水一起掉下去”，不是“触发瞬间先把层级重算/反转再掉下去”。

## 2026-07-06 - 倒置下坠前沿必须继承翻转前的自由液面

用户指出：当前版本在确定下落的一瞬间，像是把之前的波浪状态重置，先把水的顶部波浪面和非常平的底面颠倒，再用那个平底去算下坠，而不是用原本的顶部，也就是倒置后的新底部去算下坠。

偏好：直接倒置时，翻转前可见的自由液面波浪应成为下坠阶段朝向新底部的前沿。下坠不能重新从一个新求解的平边开始，也不能让波浪面在触发瞬间消失或换边。允许后续过程中逐步变形、拉伸和铺展，但起点必须继承旧自由液面的形状和相位。

## 2026-07-06 - 倒置下坠不能像果冻块，水体必须在空中变形

用户反馈当前 debug 版的倒置下坠“像一块果冻掉下去”，不像水；问题集中在整块形状被直接翻转/平移、下坠时底部完全平齐。后续实现不能再把整摊水当作刚体水带处理。

偏好：仍然不回到可见粒子雨，但整摊水在空中下坠时必须表现出流体特征：下缘不平、前沿有下坠凸起和拉伸，边缘可轻微收缩/铺展，触底后有凹陷、向两侧铺开和回荡。核心判断标准是“这是一摊水在落下”，不是“一个保持形状的软块在弹跳”。

## 2026-07-06 - 倒置时要看到整摊水从空中落到新底部

用户重新强调：直接把手机颠倒时，原本的 dialog 顶部应成为新的物理底部，水不能只是瞬间贴到新底部，而应表现为整摊水从空中落下、到达新底部并带来一点砸底回荡。

约束：这次只做整摊水的短暂自由落体，不回到此前被否定的水团粒子；不新增泡沫、水滴、可见边框或其它装饰层。音频仍是核心，水量仍守恒，普通小角度倾斜仍只走现有 Phase 1 晃动。

## 2026-07-06 - 倾斜动画要真物理：多次衰减回荡 + 空中坠落回弹；可为真实水破 D4

用户要继续把倾斜动画做得更符合真实物理，明确两个诉求：① 安静时晃动应像真水一样**多次衰减回荡**（每次更低），而不是弹两三次就平；② 倒置/大幅倾斜时水应**从空中坠落到新底部、砸底还会回弹**。回荡手感选**甲（清爽活水、5~8 次）**，坠落触发选 **A（大幅快倾才掉水、日常小倾斜不掉）**。

**关键放宽**：用户主动同意为此**细化 D4**——物理驱动的真实水元素（受重力下落的水团、砸底飞溅、Worthington 回弹）**不算装饰**，允许；但必须**是水不是碎屑**（少量较大柔边水团、记事本色，非喷雾/彩纸）。

**Why**：用户觉得"该回弹却没回弹""该坠落却瞬移"很违和；真物理感来自水本身的动力学（速度/动量/重力），不是贴特效。

**How to apply**：给自由液面加速度场（晃动/回荡）+ 受限弹道水团（坠落/回弹），但**音频永远是核心、永远是运动学浪包不进流体**（守 D5/D18/D34）；静止时这些全休眠、音频动画一字不变。未来可能把整套动画扩展到首页（常驻面），所以要模块化、性能可控。见 [decisions.md](decisions.md) D48/D49。

## 2026-07-06 - 倾斜交互要像可玩的容器，而不是轻微的物理反馈

用户确认：录音 dialog 的倾斜交互应更像一个可玩的容器。手机或平板倾斜时，水体应能明显向一侧堆积、带着惯性回摆，并在快速摆动时产生可感知的晃水和浪包，而不是只让水线做很轻微的角度变化。

约束：这个玩法仍然必须长在 Opus 的水体和波浪本身里。不要为倾斜另加独立装饰图层、水滴、泡沫、闪点或高光；容器感应主要来自基准水面倾斜、层间水体偏移、浪包方向和惯性响应。它也不应遮蔽录音 dialog 的核心信息和控制区域。

## 2026-07-06 - 倾斜强度偏夸张，接近玩具水槽

用户选择：容器感应比“明显但受控”更夸张一些。倾斜时水体可以有更大的左右堆积、更强的惯性回摆和更容易被触发的晃水浪包，整体观感应接近“拿在手里可以玩的水槽”，而不是只做真实物理的克制反馈。

约束：夸张不等于失控。仍需保留录音 dialog 的信息可读性，并避免水体频繁完全盖住计时器、文件名或底部控制；夸张程度应主要通过斜率、回弹、浪包和层间错位表达，而不是新增装饰元素。

## 2026-07-06 - 前后倾斜也要参与，但不做 3D 透视容器

用户确认：除了左右倾斜，设备前后倾斜也应参与录音水体的容器玩法。前后倾斜不应强行画成俯仰透视水面，而应转化为水体涌动强度、回弹和晃水浪包，让用户向前/向后扣动设备时能感觉水被推了一下。

方向偏好：左右倾斜是主玩法，负责水面斜率和左右堆积；前后倾斜是辅助玩法，负责强化惯性、浪包和水体涌动。整体仍保持 2D 侧剖水体的表达，不升级成 3D 容器。

## 2026-07-06 - 录音 dialog 可见时就能玩倾斜容器

用户确认：倾斜容器玩法不应只在正在录音时启用，而应在录音 dialog 可见期间一直可用。未开始录音、正在录音、录音结束后的预览/停止状态里，用户都可以通过倾斜手机或平板晃动水体。

含义：倾斜是录音容器本身的交互状态，音频只是另一个驱动通道。无声音或未录音时，水体仍应能响应设备姿态；真正录音时，再把音频驱动的离散波浪叠加到同一水体里。

## 2026-07-06 - 倾斜和音频是同一片水的两套驱动，音频仍是核心

用户确认：倾斜浪包和音频浪包应叠加到同一片水里，但 Opus 的核心身份仍然是声音驱动的离散、分层、可数波浪。倾斜负责水面基准斜率、整体涌动、惯性回弹和额外晃水浪包；音频继续负责主要的波浪数量、大小、分层和节奏。

实现偏好：用户晃动设备时，倾斜可以明显改变水体姿态和增加 slosh，但不应长期压过音频表达。两套驱动同时强时，通过软限幅和能量分配避免水体失控。

## 2026-07-06 - 要有隐形容器的撞壁、爬墙和反弹，但不新增可见边框

用户确认：倾斜容器要有撞壁感、爬墙感和反弹感。当前录音 dialog 的左右边界可被视为隐形容器壁；快速倾斜或反向晃动时，水体应从边缘反弹出晃水浪包，高侧也可以明显爬升。

约束：不要为了容器感新增可见玻璃边框、刻度、水滴、泡沫或其他装饰元素。容器边界应通过水体运动、软限幅、边缘浪包和层间错位被感知，而不是通过新的 UI 外观被看见。

## 2026-07-06 - 倾斜姿态最好支持完整方向，包括屏幕完全倒置

用户提出：倾斜玩法最好支持所有方向，包括设备屏幕完全颠倒。姿态映射不能只按固定竖屏处理，也不能在倒置时左右/前后手感反掉。

偏好：竖屏、横屏、反向竖屏、反向横屏都应有一致的“真实重力”手感。水体应始终响应设备相对重力的方向，并按当前屏幕旋转归一化为 dialog 内的左右主轴与前后辅助轴。

## 2026-07-06 - 完全倒置时按新的重力底部倒灌，而不是只在顶部做反弹

用户确认：设备完全倒置时，原本的 dialog 顶部就相当于新的物理底部。水体应整摊倒灌到这个新的底部，根据物理规律产生一定反弹，然后在新的底部继续正常的水体和波浪动画。

含义：倒置不是一个短暂特效，也不是只让水爬到顶部后退回原底部；水体的“底部”应跟随重力方向重新定义。只要设备保持倒置，水体就应稳定地停留在原顶部一侧，并继续接受音频浪包与倾斜晃水驱动。

## 2026-07-06 - 旋转和倒置时水量守恒，音频只调节总体水位

用户确认：设备旋转、倾斜和完全倒置时，水量应保持守恒。当前有多少水，改变姿态后仍是同一摊水，只是按照新的重力方向重新分布；不能因为翻转或晃动凭空增减水量。

含义：音频响度仍然可以像现在一样调节总体水位，但这是水量变化的唯一主通道。姿态输入负责水面角度、倒灌、撞壁、反弹和 slosh，不直接改变总体水量。

## 2026-07-06 - 重力方向要完整 360 度连续跟随，不做四向或八向吸附

用户确认：任意角度倾斜时，水体应完整连续地跟随真实重力方向。设备从竖屏、横屏到倒置的过程中，自由液面、填充方向、倒灌和撞壁都应平滑变化，而不是在接近 45 度或某个方向阈值时突然吸附到上下左右或八个固定方向。

含义：实现应使用连续重力向量驱动容器模型，而不是用离散屏幕方向枚举切换水体状态。屏幕旋转只用于把传感器坐标归一化到 dialog 坐标系，水体内部仍按连续角度响应。

## 2026-07-06 - 倒置时 UI 保持现有布局，不为可读性做特殊处理

用户确认：录音 dialog 的 UI 保持现有布局即可，不需要为了倒置或大角度倾斜做特殊可读性处理。水体可以按物理方向倒灌、经过计时器、文件名和底部控制背后；如果用户需要操作 UI，可以把设备转回原来的正常方向。

含义：实现不需要让按钮、文字或布局跟随水体重排，也不需要专门为倒置时的可读性增加遮罩、前景保护或交互补偿。水体玩法优先保持物理一致性。

## 2026-07-06 - 录音 dialog 打开期间临时禁用 Activity 屏幕旋转

用户确认：为了实现完整 360 度容器物理，录音 dialog 打开期间应临时禁用系统屏幕旋转，防止 `Activity` 整体方向变化。设备旋转角度应通过传感器等其它手段监测，并只驱动 `WaveVisualizerOpus` 内部的水体方向。

含义：屏幕 UI 坐标系在 dialog 生命周期内保持稳定，水体自己的重力向量在这个固定坐标系内连续旋转。退出录音 dialog 后，应恢复原本的屏幕方向策略。

## 2026-07-06 - 接近平放时保留最近稳定方向，并缓慢回默认底部

用户确认：设备接近平放、重力在 dialog 平面内的投影很小时，不应继续放大传感器微小噪声来决定水体方向。此时应保留最近一次稳定的重力方向，并逐渐回到当前 UI 的默认底部，同时仍允许晃动产生 slosh。

含义：平放是姿态方向的退化区。实现应有投影强度阈值、方向保持和缓慢回落策略，避免水面在平放附近乱跳或高速旋转。

## 2026-07-06 - 音频波浪跟随自由液面坐标系

用户确认：音频波浪也应遵循物理规律，跟随当前自由液面坐标系。水面在哪里，音频浪包就沿那条自由液面的切线传播；填充方向沿重力方向。手机横放或倒置后，音频波浪应在新的自由液面上继续正常动画。

含义：音频波浪不能固定为屏幕横向。倾斜、旋转、倒置后，音频驱动仍是 Opus 核心，但其波浪传播和绘制坐标应进入同一套重力相对的水体坐标系。

## 2026-07-06 - 倾斜容器功能一口气做完整版本

用户确认：不分阶段交付，直接实现完整玩具水槽式 360 度物理容器，包括方向锁定、传感器姿态、面积守恒、倒置倒灌、自由液面坐标系、音频波浪跟随、撞壁、爬墙、反弹和 slosh 强化。实现前需要先做网络调研，选择最优落地方式。

## 2026-07-04 - 不要竖直方向明暗变化，避免底部显脏

用户确认：此前 Opus 版为模拟水体体积感加入的 y 方向明暗变化需要撤掉，因为最下方的压暗会让水体看起来脏。后续录音水体颜色应主要表达记事本色、记事渐变方向与层间远近关系；不要再用顶部提亮、底部压暗的竖直渐变或第二遍光照覆盖来制造体积感。

## 2026-07-04 - 渐变记事的水体底色必须完整跟随记事渐变方向

用户确认：录音 dialog 里的水体、波浪在记事颜色为渐变时，底色渐变不能固定横向，也不能只根据左右语义反转颜色；必须与 `ThingBackground.orientation` 的 8 向方向一模一样，包括上下与四个对角方向。竖向明暗覆盖曾作为第二遍体积明暗保留，但已在后续反馈中撤销；无论是否有覆盖，底色方向都必须独立保持正确。

## 2026-07-03 - 北极星：最高视觉质量，靠"音频×水面完美融合"，不靠加装饰元素
用户强调 Opus 版的目标是**最高的视觉质量**，且有两条硬约束：

1. **不偷懒复用现成方案。** 不得为省事直接套用项目现有 v1/v2 的实现；Opus 整套（音频层
   与视觉层）都全新构建，每个设计选择服务于最终质量。
2. **质量不靠加新元素。** 不通过水滴、光晕、高光斑、泡沫、粒子等叠加装饰来"显得丰富"；视觉
   丰富度必须来自**声音对水面/波浪形态与运动的深度塑造**——让水体本身表达声音的强弱、音色、
   音高与节奏变化。追求的是"音频与水面的完美融合"，而不是水面 + 一层特效。

**How to apply:** 设计与实现时，若想通过增加一个可见"元素/图层"来提升观感，先停下——正确的做法
是让该表现从水的运动、波的形态、层次与配色里长出来。评审标准是"这看起来像被声音塑形的水"，
而不是"这看起来热闹"。据此，Opus 版不设独立的表面高光/泡点/光晕生命层（与 v1 D43 / v2 D54
允许轻量表面生命层的口径不同）。

## 2026-07-03 - 主要通过"波浪"（离散、分层、可数）反映声音，不是通过连续水面纹理
用户进一步澄清并强调：不是想通过**水面**（一片连续起伏表面的纹理/疏密）来反映音频的特点与
变化，而是**主要通过一道道"波浪"来反映**。表达声音的核心机制是**"不同层级、不同数量的波浪"**
——声音一变，浪的数量、大小、分布在哪些层就随之变化。用户经验：如果只是一片水面，观感很平淡、
动画很无聊；**过度模拟现实也会很无趣**。

**Why:** 离散、可辨认、有个性的"浪"是这套动画的表现单元与趣味来源（也是 v2 受喜爱的原因）；
连续表面纹理 / 物理仿真式的写实水面缺乏动画趣味。

**How to apply:** 视觉核心是**被艺术化、被声音驱动的、有表现力的离散波浪群**，不是物理仿真。
声音的响度/音色/音高/节奏应主要映射为"生成多少道浪、多大、在哪些层、以什么方式运动"。物理
（Gerstner 形、色散定波长速度、传播）只用到"让它看起来自然"为止，不为写实而写实。这**收窄了
D1**：弹簧水线从"核心传播介质"降级为至多轻量点缀；离散、可数、分层的波浪重新成为主角，方向
上更接近 v2 的生成式波浪，但要在更干净/更轻/更连续的基础上重做，并把"数量与分层随声音变化"
这条表现轴推得比 v2 更足。参见 [decisions.md](decisions.md) D5。

## 2026-07-03 - 主体水体必须是纯记事本色（满明度满不透明），不能偏暗偏脏
用户反馈：完全激活动画时，主要水体（在高度上盖住录音按钮那部分，约等于最前方那层）有时偏暗
偏脏。要求主体水体的明度和透明度都为 1，完全等于记事颜色。

**Why:** 多层压暗 + 半透明叠加在主体区域 composite 后会变浑，破坏记事的颜色身份。

**How to apply:** 主体水体（最前/最近层）永远用纯本色、满明度满不透明，作为颜色身份锚点；景深只
在其上/更远的波浪层用明度 + 透明度阶梯表现，且倾向更亮更透（大气透视）而非更暗；体积感以提亮
波峰为主、压暗波谷为辅且很克制。见 [decisions.md](decisions.md) D12。

## 2026-07-04 - 响度要"半绝对"：大声真的比小声汹涌，且不被环境底噪激活
用户诉求：正常/小声说话跟大声放歌动画差别不大、甚至前者更显著，很奇怪。要的是**同场录音内保留
大小声/高低/快慢的真实差异**（大声=大动画），同时环境底噪（空调）自动减掉、不激活。grill 中的取舍
选择：**半绝对**（非完全绝对、非纯自适应）、**最小机制**（不建历史缓冲）、**信号门控零点**、**强区分**
（S 曲线）、**分步**（先软件半绝对 + 尝试关采集端 AGC/NS，录音保存暂不动）。

**Why:** 未校准手机拿不到绝对 SPL（差设备相关常数，跨机误差大），纯自适应归一化又会把每种声音拉满、
抹平大小声——半绝对（自适应零点 + 固定尺子）是唯一同时满足"大小声区分 + 抗环境底噪"的路。

**How to apply:** 响度永远用"自适应零点 + 固定 dB 尺子"，**不要回到"floor+peak 都自适应"**（那会重新
抹平大小声）。视觉审美（大声更突出）优先于"感知响度线性/sones"（后者反而压缩大声）。录音文件音量问题
真机验证后再单独、谨慎处理，**不要贸然改录音保存落盘链路**。见 [decisions.md](decisions.md) D21。

## 2026-07-04 - 曾试做波峰高光（方案C），真机不满意已撤回，D4 恢复
北极星第 2 条定"不加装饰元素、不设独立高光/泡点/光晕图层"。2026-07-04 用户曾主动要求给波峰加接近白的高光让它
更像自然水，据此临时放宽 D4 试做了**方案C（斜率镜面着色 + 少量 sun-glitter 闪点）**。真机两版均不理想（首版规则
碎斑成"尺子刻度"，修正版连续 sheen + 闪点仍不自然），用户决定**撤回全部高光**。

**结论：D4 恢复生效**——不设独立的表面高光/泡点/光晕层。侧剖水面的镜面高光投入产出低、难达自然波光感，暂不
再尝试（除非将来上逐像素 shader；受 minSdk 26 限制）。见 [decisions.md](decisions.md) D26/D27。水体的"明暗体积感"
仍由 D24/D25 的竖直深度着色承担（那是水体自身着色、非独立高光层，保留）。

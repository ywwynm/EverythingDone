# 偏好 — 录音波浪可视化（Opus 版）

## 2026-07-03 - 北极星：最高视觉质量，靠"音频×水面完美融合"，不靠加装饰元素
用户强调 Opus 版的目标是**最高的视觉质量**，且有两条硬约束：

1. **不偷懒复用现成方案。** 不得为省事直接套用项目现有 v1/v2/Fable 的实现；Opus 整套（音频层
   与视觉层）都全新构建，每个设计选择服务于最终质量。
2. **质量不靠加新元素。** 不通过水滴、光晕、高光斑、泡沫、粒子等叠加装饰来"显得丰富"；视觉
   丰富度必须来自**声音对水面/波浪形态与运动的深度塑造**——让水体本身表达声音的强弱、音色、
   音高与节奏变化。追求的是"音频与水面的完美融合"，而不是水面 + 一层特效。

**How to apply:** 设计与实现时，若想通过增加一个可见"元素/图层"来提升观感，先停下——正确的做法
是让该表现从水的运动、波的形态、层次与配色里长出来。评审标准是"这看起来像被声音塑形的水"，
而不是"这看起来热闹"。据此，Opus 版不设独立的表面高光/泡点/光晕生命层（与 v1 D43 / v2 D54
允许轻量表面生命层的口径不同）。

## 2026-07-03 - 主要通过"波浪"（离散、分层、可数）反映声音，不是通过连续水面纹理
用户进一步澄清并强调：不是想通过**水面**（一片连续起伏表面的纹理/疏密）来反映音频的特点与
变化，而是**主要通过一道道"波浪"来反映**。表达声音的核心机制是**"不同层级、不同数量的波浪"**
——声音一变，浪的数量、大小、分布在哪些层就随之变化。用户经验：如果只是一片水面，观感很平淡、
动画很无聊；**过度模拟现实也会很无趣**。

**Why:** 离散、可辨认、有个性的"浪"是这套动画的表现单元与趣味来源（也是 v2 受喜爱的原因）；
连续表面纹理 / 物理仿真式的写实水面缺乏动画趣味。

**How to apply:** 视觉核心是**被艺术化、被声音驱动的、有表现力的离散波浪群**，不是物理仿真。
声音的响度/音色/音高/节奏应主要映射为"生成多少道浪、多大、在哪些层、以什么方式运动"。物理
（Gerstner 形、色散定波长速度、传播）只用到"让它看起来自然"为止，不为写实而写实。这**收窄了
D1**：弹簧水线从"核心传播介质"降级为至多轻量点缀；离散、可数、分层的波浪重新成为主角，方向
上更接近 v2 的生成式波浪，但要在更干净/更轻/更连续的基础上重做，并把"数量与分层随声音变化"
这条表现轴推得比 v2 更足。参见 [decisions.md](decisions.md) D5。

## 2026-07-03 - 主体水体必须是纯记事本色（满明度满不透明），不能偏暗偏脏
用户反馈：完全激活动画时，主要水体（在高度上盖住录音按钮那部分，约等于最前方那层）有时偏暗
偏脏。要求主体水体的明度和透明度都为 1，完全等于记事颜色。

**Why:** 多层压暗 + 半透明叠加在主体区域 composite 后会变浑，破坏记事的颜色身份。

**How to apply:** 主体水体（最前/最近层）永远用纯本色、满明度满不透明，作为颜色身份锚点；景深只
在其上/更远的波浪层用明度 + 透明度阶梯表现，且倾向更亮更透（大气透视）而非更暗；体积感以提亮
波峰为主、压暗波谷为辅且很克制。见 [decisions.md](decisions.md) D12。

## 2026-07-04 - 响度要"半绝对"：大声真的比小声汹涌，且不被环境底噪激活
用户诉求：正常/小声说话跟大声放歌动画差别不大、甚至前者更显著，很奇怪。要的是**同场录音内保留
大小声/高低/快慢的真实差异**（大声=大动画），同时环境底噪（空调）自动减掉、不激活。grill 中的取舍
选择：**半绝对**（非完全绝对、非纯自适应）、**最小机制**（不建历史缓冲）、**信号门控零点**、**强区分**
（S 曲线）、**分步**（先软件半绝对 + 尝试关采集端 AGC/NS，录音保存暂不动）。

**Why:** 未校准手机拿不到绝对 SPL（差设备相关常数，跨机误差大），纯自适应归一化又会把每种声音拉满、
抹平大小声——半绝对（自适应零点 + 固定尺子）是唯一同时满足"大小声区分 + 抗环境底噪"的路。

**How to apply:** 响度永远用"自适应零点 + 固定 dB 尺子"，**不要回到"floor+peak 都自适应"**（那会重新
抹平大小声）。视觉审美（大声更突出）优先于"感知响度线性/sones"（后者反而压缩大声）。录音文件音量问题
真机验证后再单独、谨慎处理，**不要贸然改录音保存落盘链路**。见 [decisions.md](decisions.md) D21。

## 2026-07-04 - 曾试做波峰高光（方案C），真机不满意已撤回，D4 恢复
北极星第 2 条定"不加装饰元素、不设独立高光/泡点/光晕图层"。2026-07-04 用户曾主动要求给波峰加接近白的高光让它
更像自然水，据此临时放宽 D4 试做了**方案C（斜率镜面着色 + 少量 sun-glitter 闪点）**。真机两版均不理想（首版规则
碎斑成"尺子刻度"，修正版连续 sheen + 闪点仍不自然），用户决定**撤回全部高光**。

**结论：D4 恢复生效**——不设独立的表面高光/泡点/光晕层。侧剖水面的镜面高光投入产出低、难达自然波光感，暂不
再尝试（除非将来上逐像素 shader；受 minSdk 26 限制）。见 [decisions.md](decisions.md) D26/D27。水体的"明暗体积感"
仍由 D24/D25 的竖直深度着色承担（那是水体自身着色、非独立高光层，保留）。

# Opus 录音波浪：y 方向明暗着色扩展到渐变记事 + 深水压暗（D24）

## 本次更新

上一版（D23）的水体竖直体积感只影响了纯色记事、且只提亮。本次扩展到两类记事，并加上深水压暗，更好模拟自然水的上亮下暗：

- **纯色记事**：波峰稍提亮、主体大段保持记事本色、最下方深水区稍压暗（同色系明暗，不发灰、颜色身份不变）。
- **渐变记事**：底色的横向渐变方向完全保留，在其上叠一层竖直明暗——波峰提亮、中段透明保留底色与渐变方向、深水压暗。
- 明暗都取偏克制的强度（"稍微"），主体中段仍是记事颜色。

## 验证

真机重点看：

1. **渐变记事**是否既保留了记事的渐变方向，又有了竖直方向的体积感（波峰亮、深水暗）。
2. **纯色记事**的深水压暗是否自然、主体是否仍纯净不脏。
3. 明暗强度是否合适（偏弱/偏重都可调 `CREST_LIGHTEN_*`/`DEEP_DARKEN_*`（纯色）、`OVERLAY_LIGHT_ALPHA`/`OVERLAY_DARK_ALPHA`（渐变））。
4. 深水压暗的起始位置是否合适（`SHADE_NEUTRAL_LO` 调整本色带到深水的过渡）。
5. 此前各项（K 加权大小声、SuperFlux、流向、层次、帧稳定性）是否一切照旧。

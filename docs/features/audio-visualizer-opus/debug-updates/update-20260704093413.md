# Opus：频段进水面 + onset 语义分型 + 浪列 + floor 门控多证据（GPT 建议 3/1/2/4）

## 本次更新

对 GPT 提的 6 条优化做技术评审后，采纳并实现价值最高的 4 条（⑤⑥核心已做/低价值，略）。

### ③ floor 门控多证据（修 D21 弱点，最优先）
D21 的 `signalGate = max(tonal, pitchConfidence)` 有个洞：**响亮、宽频、无明确音高的音乐**（摇滚/电子）
会因 flatness 高、无基频被误判成稳态噪声，floor 慢升把它吸收、**吞掉高潮**。改为**四证据 OR**：
`max(音调, 音高, flux 起伏, dB 快速上升)`——空调稳态四证据全低→被吸收；音乐即便宽频也有持续 flux/
起伏→冻结 floor。新增 `mPrevDbFs` 算帧间上升。

### ① 频段进入水面（偏置，非硬频段轨道）
`bassWeight`/`trebleWeight`/`noiseLike` 此前完全没被 visualizer 消费。现按"物理参数偏置"叠加在层/亮度上
（吸取 D14 教训，不做"某频段→某层"硬轨道）：
- **bass 高** → 浪更长（`BASS_WL`）、更宽（`BASS_WIDTH`）、更慢（`BASS_SPEED`）、更长寿（`BASS_LIFETIME`）；
- **treble 高** → 更短（`TREBLE_WL`）、更快（`TREBLE_SPEED`）；
- **noiseLike 高** → 抑制 sustain 细浪生成（`NOISE_SUSTAIN_SUPPRESS`）+ 压小浪幅（`NOISE_AMP_SUPPRESS`），
  空调/摩擦不激活细浪（与 D21 零点抑制形成双保险）。
- visualizer 平滑 `mBass`/`mTreble`/`mNoise`。

### ② onset 语义分型
用现有特征（`pitchConfidence`/`noiseLike`）给 onset 分型，不引 Essentia 全套：
- **percussive**（无音高、宽频冲击，如鼓/辅音）→ 更偏前层、大 skew 前冲；
- **tonal**（有音高，如元音/旋律）→ 拉向中层、小 skew 平滑起伏；
- **noisy**（高噪）→ 浪幅压小。

### ④ 浪列
节奏强（`pace≥0.5` 且 `onset≥0.45`）时，一次生成 **2–4 个共享方向/速度/尺度的浪包**，在上游按波长
错峰排开、依次进入 →"节奏在推动水面"，比单个随机浪包更有推进感。容量不足先回收将逝浪、仍不足退单浪。

**未做**：⑤ octave-jump guard / 三帧 median（pitch 核心"只影响新浪、confidence 低退亮度"已实现，八度错
只微调波长、影响小）；⑥ 浪包尾谷（centripetal Catmull-Rom 早已在用，尾谷有露按钮风险、收益小）。

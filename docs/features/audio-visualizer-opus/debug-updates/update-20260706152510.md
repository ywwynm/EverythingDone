# 倾斜物理升级 Phase 1：自由液面速度场（晃动多次回荡 + 浪包平流 + 静止门控）

本次 debug 版本是"倾斜动画更符合物理"（D48/D49，C-可见方案）的 **Phase 1**。目标：解决安静时晃动"只弹两三次就平"，让水面像真水一样多次衰减回荡；同时保证静止时音频动画一字不变。**Phase 2（水团空中坠落 + 回弹）尚未做**，本版倒置/大倾斜时水仍是"沿容器重新分布"、没有空中坠落。

## 本次实现（Phase 1）

- **自由液面速度场取代旧的能量池晃动**：给水面加真实动力学——1D 交错网格浅水（形变 η + 切向流速 u，48 点，6 层共享、按视差缩放）。倾斜/前后倾把能量注入流速，浅水动力学自发产生晃动、爬墙、壁面反射、**多次衰减回荡**。
- **回荡手感 = 甲**：低阻尼，静止环境下可见约 5~8 次逐次变低的回荡（不再两三下就平）。
- **频率绑容器宽**：容器越宽晃动越慢越大气（为将来扩展到首页更大的面自动适配）。
- **音频浪包被晃动流速平流（③）**：倾斜时音频浪会"骑着"晃动的水面一起涌，更连贯。
- **静止门控（④）**：设备静止、晃动能量衰竭后，速度场清零休眠、直接走原静态路径 → **静止时的音频波浪与加倾斜前完全一致**。
- 音频分析链路、浪包生成、面积守恒填充均未动；速度场只被容器姿态驱动，绝不吃音频。

## 已验证

- 本地 `:app:assembleDebug` 通过。
- 未使用 adb，未连接物理设备或模拟器。

## 需要重点观察（真机）

- **回荡次数与手感**：安静环境下倾一下手机再放住，水面是否像真水一样来回荡好几次、每次更低、最后平静（目标 5~8 次）。太少/太多可调阻尼 `SLOSH_DAMP`。
- **晃动幅度**：倾斜时水面起伏/爬墙的幅度是否合适。太小/太大调 `SLOSH_TILT_GAIN`（主振幅旋钮）或 `SLOSH_RENDER_GAIN`。
- **静止零回归**：设备完全不动时，音频波浪动画是否和加倾斜前一模一样（应当是）。
- **平流是否自然**：倾斜时音频浪随水面涌动是否连贯、有没有被"甩飞"。异常调 `SLOSH_ADVECT_GAIN`。
- **倾斜方向**：左右倾斜时水往低侧堆的方向对不对（若反了，`SLOSH_TILT_GAIN` 取负即可翻）。
- **前后倾（z）**：前后扣动设备时水面是否有涌动响应。
- 性能：常规倾斜时帧率是否稳定。

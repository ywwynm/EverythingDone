# Opus 波浪：六层角色分工（近层平静·偶爆发，远层细密·频繁）以求任意时刻都能看清所有层

## 本次更新

反馈：仍看不清 6 层，最近最深色的前景层容易挡住后面。用户提出一个（正确的）设计洞察——**层级越近，
波峰极值越高但平均值稍低；层级越远，波峰极值越低但出现频率越高**，从而任意时刻都能看到所有层级。

据此把六层做**角色分工**（layer 0=最远/最浅，layer 5=最近/前景/最深）：

| 维度 | 近层(前景) | 远层 | 常量 |
|---|---|---|---|
| 基础波场平均振幅 | **低 0.48**（平时平静、不挡后层） | **高 1.3**（持续起伏） | `mLayerAmp` 反向 |
| 波峰极值(净空) | **满 1.0**（偶尔冲很高） | **压 0.5**（冲不高） | `mLayerCeilFrac` 拉大 |
| 波峰密度 | 疏(×0.72，大而少) | **密(×1.5，细而多)** | `CYCLES_*_SCALE` |
| 事件浪包幅度 | **大 1.25** | 小 0.5 | `mLayerPacketAmp` 反向 |
| 事件浪包频率 | 稀(强击才落) | **频(弱/持续声偏落)** | `LAYER_SPAWN_W_*` |
| 浪包波长 | 长宽(大而疏) | 短窄(细密) | `wl` 随层反向 |

**关键转变**：前景不再靠"基础波高"刷存在感（那会抬高其平均水位、持续挡住后层），改为**平时平静的深色
主体 + 偶尔一记又大又高的事件浪爆发**（极值靠 onset 强击落前景、净空满、包幅大，但稀疏）。远层则是
**幅度小、密度高、频繁**的细浪，靠更高的基线偏移持续露在前景之上。落层用 strength 在 BACK/FRONT 两套
权重间插值：弱声/持续声偏远层（远层频繁），强击偏前景（近层偶尔大浪）。

于是任意时刻：远层总在细密起伏(可见)、前景是平静深色主体(不挡)、偶尔前景爆发大浪(高光) → 6 层都在、
内容丰富。

## 验证

- `:app:assembleDebug` 通过；`:app:publishDebugUpdate` 发布（debug code **202607031612**）。
- 真机验证：
  1. 是否**任意时刻都能看到 6 层**（尤其安静/中等音量时，远层细密浪是否持续露在前景之上、不被盖死）；
  2. 前景是否**平时平静、偶尔一记大浪**（大声/重音时前景才冲高），而非持续高企挡住后层；
  3. 远层是否**细密频繁**、近层是否**大而疏**；整体单向流动、浪尖不拍平是否保持。

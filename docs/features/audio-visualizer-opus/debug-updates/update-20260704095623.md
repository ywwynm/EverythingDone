# Opus：远层波浪圆润化 + 说话快慢的流速差异拉大

## 本次更新

两处真机反馈。

### 1. 远层"面筋"感 → 圆润
根因：远层是"波峰密（`CYCLES_FAR_SCALE=1.5`）+ 振幅大（`mLayerAmp=1.3`）+ 净空低（被 tanh 强压）"，短陡
的密波经净空压缩容易失真；再加 `RENDER_N=112` 采样点对密波**采样不足**，Catmull-Rom 重建就出不规则的
面筋状。改：
- **`RENDER_N` 112 → 176**（采样密度，主力——密波足够采样才圆润）；
- **`CYCLES_FAR_SCALE` 1.5 → 1.35**（远层波别太短陡，仍比近层密）；
- **`mLayerAmp` 远层 1.3 → 1.12**（收敛过大的振幅，别撞净空被 tanh 压变形）。
- 保留"远层细密"的角色，但每层都圆润。

### 2. 说话快慢差异不够 → 流速差异拉大
根因：① 分析器 `pace` 被 `presence` 二次压低、值域偏窄；② `FLOW_BASE=1.1` 太大，把 pace 的加成稀释了。改：
- 分析器 **`pace` 让 eventDensity 直接主导**（`eventDensity * smoothStep(0.05,0.30,presence)`，只用 presence
  做"有声"门控，不再二次压低 → 值域更宽、快慢分明）；
- **`FLOW_BASE` 1.1 → 0.6、`FLOW_PACE` 1.0 → 2.0、`FLOW_DRIVE` 0.7 → 0.5**（静息慢、快时大幅加速）；
- 浪包速度的 pace 系数 **(0.7+0.6·pace) → (0.5+1.2·pace)**（spawnWave 与浪列同步）。
- 效果：说慢真慢、说快明显更快，流速快慢差异拉大。

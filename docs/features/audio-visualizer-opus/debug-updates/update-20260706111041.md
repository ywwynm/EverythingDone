# 修正录音水体初始方向反转

本次 debug 版本修复上一版 360 度倾斜容器的初始方向判断问题。

## 问题

用户反馈：录音 dialog 刚打开时，水体方向判断错了，直接翻转 180 度跑到顶部，看起来像陀螺仪或方向数据读反。

## 诊断

检查后确认，问题不在传感器数据本身，而在 `AudioRecordDialogFragment.dispatchGravityToVisualizer()` 的 UI 坐标映射中。正常竖直方向下，传感器 y 分量应让水体停在当前 dialog 底部；旧实现又对 y 轴额外取反，导致 `WaveVisualizerOpus` 把顶部解释为新的底部。

## 修复

- 移除 `dispatchGravityToVisualizer()` 中多余的 y 轴取反。
- 保留录音 dialog 打开时的方向锁定和 0/90/180/270 度旋转映射。
- 360 度水体容器、面积守恒、倒置倒灌、音频波浪跟随自由液面等逻辑保持不变。

## 验证

- 本地 `:app:assembleDebug` 通过。
- 未使用 adb，未连接物理设备或模拟器。

## 观察重点

- 正常竖直打开录音 dialog 时，水体应停在底部，不再直接跑到顶部。
- 倾斜、横放、倒置时仍应按真实重力方向重新分布水体。

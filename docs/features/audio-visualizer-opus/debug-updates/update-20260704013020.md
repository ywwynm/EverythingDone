# Opus 响度：半绝对重构（大声真的比小声汹涌）+ MIC 关 AGC/NS + 空调底噪不再激活

## 本次更新

针对"正常/小声说话跟大声放歌动画差别不大、甚至前者更显著"。经一轮 grill + 6 份 web 调研（声学
dBFS/SPL、心理声学、自适应 metering、Android MIC/AGC），定位到**双重元凶**并重构：

### 1. 软件核心：半绝对响度（零风险主力）
- **根因**：旧 `relativeLevel` 把噪声底 `floor` 和峰值 `peak` **都自适应**、把每种声音都拉满量程 →
  抹平大小声；`absoluteLevel`（无自适应底的旁路）又把持续空调底噪抬起来。
- **改为**：只重构响度一路（`pace`/`pitch` 本就是绝对刻度，不动）：
  - **零点** = 信号门控自适应底：快降跟随环境变静；仅在"稳态噪声态"（无音高/宽频）慢升吸收新底噪；
    **有信号（说话/音乐）时冻结上升** → 零点=纯环境底噪，不被持续大声污染。
  - **尺子** = 固定 `RANGE_DB=45`（零点上方 45dB 算满，≈单人声动态；正常说话~44%、喊叫封顶）+
    `DEADZONE_DB=5`（死区滤环境波动）。
  - **曲线** = `contrast()` S 曲线（强区分：大声明显更汹涌）。
  - 新 `semiAbsLevel` 取代 `relativeLevel`/`absoluteLevel`，驱动 `loudness`/`intensity`/水位/浪高；
    **`absoluteLevel` 与 D20 的 `absAssist` 一并退役**（新零点自带减空调）。

### 2. 采集端：MIC 也尝试关 AGC/NS（修 AudioRecorder.kt 逻辑漏洞）
- 原 `if (!PREFER_MIC) disablePreprocessing(...)` → MIC 模式从不关 AGC，硬件实时压动态（小声抬、大声压）。
- 现无论哪种源都调 `disablePreprocessing`，关 **AGC + NS**（NS 削小声/高频动态），AEC 顺手；
  `create → getEnabled 读默认态 → setEnabled(false) → 复核`，DEBUG 打 log（`preproc=AGC[...]NS[...]`）
  便于真机判断各机型能否关。定制 ROM 硬件层可能关不掉（返回成功却无效），此时靠半绝对兜底。

### 3. 不动
- `pace`/`pitch` 不改；录音保存链路暂不动（分步：真机若发现录音明显变小/闷再单独加"保存前增益归一"）。

## 验证

- `:app:assembleDebug` 通过；`:app:publishDebugUpdate` 发布（debug code **202607031730**）。
- 真机验证：
  1. **大声放歌 vs 正常/小声说话，动画是否明显拉开**（大声更汹涌、小声更收敛）——核心目标；
  2. 只有空调底噪时是否仍不激活；
  3. `adb logcat | grep AudioRecord` 看 `preproc=` 报告，判断本机 AGC/NS 能否关掉；
  4. 若正常说话偏弱/大声不够猛，调 `RANGE_DB`(45)、`DEADZONE_DB`(5) 或 S 曲线陡度。

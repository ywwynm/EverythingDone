# 录音波浪可视化 debug 更新 - 2026-07-06 17:27

本次更新为倒置容器物理的“小范围重启”版本：当录音 dialog 可见、设备被直接颠倒或接近 180 度快速重定向时，原本在旧底部的一整摊水会被保留在空中，然后沿新的重力方向自由下坠到新的底部。

实现边界：
- 不恢复此前被否定的粒子、水滴或独立水团方案。
- 6 层水体共用同一个下坠位移，作为整摊水一起移动。
- 触底后有短暂反弹，并把冲击注入现有浅水速度场，产生砸底后的回荡。
- 水量仍由原有面积守恒逻辑控制，音频只调节总体水位和自由液面波浪。
- 普通小角度倾斜继续走原 Phase 1 晃动，不触发空中下坠。

本地验证：
- `:app:assembleDebug` 已通过。
- 未使用 adb，未连接真机或模拟器。

# 修复晃动模态错误：改为 1 阶摇摆（不再中间汇聚撞击 / 拉面筋 / 荡几十次 / 六层机械齐动）

修复上一版（202607060737）猛地倾斜时的观感问题：水从两边向中间汇聚撞击又分开、像拉面筋、荡几十次、6 层水面几乎无差别显得机械。

## 根因

**倾斜激励的空间 profile 用反了**：给切向流速注入的是**反对称** profile（左半向左、右半向右）→ 水向两侧外涌、在中间汇聚撞击 = **2 阶驻波**。真实的倾斜应是**整摊水一起被推向低侧**（均匀流速），在反射壁堆积成"一侧高一侧低"的 **1 阶摇摆**。

- "中间汇聚撞击 / 拉面筋"：就是这个 2 阶对称驻波。
- "荡几十次"：2 阶及更高模态频率更高 → 同样衰减时间内看到的次数多几倍（1 阶基础模态本应约 5~6 次）。
- "6 层机械齐动"：晃动是一整套共享场、几乎齐动，盖过各层音频波差异。

## 修复

- **倾斜激励改均匀 profile**（去掉反对称因子）→ 整摊水朝低侧摇摆的 1 阶晃动，回荡次数回到 5~6 次。
- **前后倾(z)增益压低**（24→12）：z 是对称模态（会带汇聚感），降低它让倾斜摇摆为主、z 只作辅助。
- **6 层加水平微错位**（±3% 宽）：破除齐动的机械感，近似各层惯性/相位差。

## 已验证

- 本地 `:app:assembleDebug` 通过。
- 未使用 adb，未连接物理设备或模拟器。

## 需要重点观察（真机）

- **摇摆而非汇聚**：猛地倾一下，水面应是"整体涌向低侧、再摇回来"的来回摇摆，不再从两边汇聚中间撞击。
- **回荡次数**：应回到约 5~6 次衰减后平静（不再几十次）。太多/太少调 `SLOSH_DAMP`。
- **层次感**：6 层晃动是否不再完全齐动、有一点错落。仍太齐可加大 `mLayerSloshShift`。
- **幅度**：均匀注入比之前更"高效"，晃动可能偏大；太大调 `SLOSH_TILT_GAIN`（现 40）。

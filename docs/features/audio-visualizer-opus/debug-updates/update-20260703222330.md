# Opus 波浪：修"没有横向流动、原地升降"

## 本次更新

反馈：波浪出现后只在原地升高、下落，没有流动感。诊断：基础波场每个分量的漂移速度设得太小
（换算相速仅约 5% 宽度/秒，几乎看不出移动），本质是驻波——声音一来只是在原地把振幅顶大再落下；
事件浪包虽会走，但被这个"原地脉动"的基础波场盖住。

修法：

- **基础波场明确横向流动**：drift 改为 `flowDir·k·velMag`（velMag 为相速 xNorm/s，长波稍快），
  **同层各分量同向流动**（清晰的滚动感），不同层不同流向（景深）。
- **流速随声音变速**：新增变速流动相位——安静缓流、有声/快节奏更快（该快则快、该慢则慢）。
- 事件浪包提高基础流速（即使 pace≈0 也明显滚动）。

## 验证

- `:app:assembleDebug` 通过；`:app:publishDebugUpdate` 发布（debug code **202607031424**）。
- 真机验证：水面是否有明显的横向流动/滚动感（不再原地升降）；说话/快歌时流速是否更快、安静时
  缓；峰谷、丰富度、连续性是否仍保持上一版的改善。

# Opus 波浪：整体单向流动（消驻波干涉）+ 浪包横穿移出 + 动态层间偏移（丰富层次）

## 本次更新

针对两个反馈：①6 层看着像 4 层，深色前景仍盖住浅色后层，层次不够丰富；②波浪像在 dialog 宽度内
左右晃动、分叉、合并，缺流动感——希望浪升起后真的朝一个方向移动、移出屏幕。

**问题②根因（流动感）**：基础波场的横向运动此前是**层间随机对冲**（有的层向左、有的向右）+ 同层三个
波分量**相速差过大**（0.14~0.34，差 2.4 倍）。多列不同速甚至反向的波叠加，数学上就是**驻波干涉**——
波峰在原地上下起伏、此消彼长，看着就是"分叉/合并/左右晃"，而非整体平移。事件浪包寿命又只有约 1 秒，
还没横穿就消退了。

- 改为**全场统一主流向**（`mFlowDir`，整片水面朝同一方向流），杜绝层间对冲；
- 各分量**相速收窄接近**（`FLOW_VEL_BASE=0.24` + 温和色散 `0.3`，相速差压到约 1.5 倍、长波略快主导），
  抑制驻波干涉 → 呈现"一列波持续推进"的整体流动；整体流速提高（`FLOW_BASE` 0.75→1.1、`FLOW_DRIVE`
  0.5→0.7）；
- **事件浪包**：寿命 0.95→2.1s（足够横穿并移出屏幕）、大概率顺主流向（`PACKET_FLOW_ALIGN=0.78`）、
  从屏外一侧出生横穿到屏外另一侧、快升后落（升起后保持满幅横穿大部分行程、接近移出才衰减）；
  并发上限 18→26 以容纳更长寿命。

**问题①根因（层次）**：后层净空阶梯压得太狠（后层净空仅前景的 0.55），后层波峰太矮、几乎永远高不过
不透明的深色前景；层间基线偏移又只有 9dp（远小于波峰），层几乎贴在一起。

- **放宽后层净空**（`mLayerCeilFrac` 0.55→0.74 起步、逼近前景 1.0）→ 后层波峰能与前景**交错露出**
  （前景仍净空最大、恒主导，后层不会大幅盖过）；
- **层间基线偏移随音量动态伸缩**：基础梯度加大到 20dp，乘 `offsetScale`（安静 0.35、响时 +1.0×drive）
  → 安静时各层贴合成一片平静水面（不成"梯田"），响时层间展开、6 层充分错开、后层从前景之上清晰露出。

## 验证

- `:app:assembleDebug` 通过；`:app:publishDebugUpdate` 发布（debug code **202607031556**）。
- 真机验证：
  1. 是否有明显的**整体单向流动**——浪升起后朝一个方向移动、横穿、移出屏幕（不再原地晃动/分叉/合并）；
  2. 响时是否能看清**6 层**、后层不再被深色前景盖死；安静时是否仍是平静一片、不成梯田；
  3. 前景是否仍主导、后层不会大幅窜高盖过；浪尖不拍平；水位涨落保持。

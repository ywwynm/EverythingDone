# Opus 波浪：层间差调到 9.6dp + 抑制空调稳态底噪（不再"底噪比音乐还激烈"）

## 本次更新

两处反馈：①层间基线差 9.5dp → 想要 9.6dp；②房间只有空调底噪时，动画甚至比激昂音乐还剧烈。

### 1. 层间基线差 9.5 → 9.6dp

`mLayerOffset` 相邻梯度 13.2 → **12dp**、`OFFSET_BASE_SCALE` 0.72 → **0.8**，相邻层基线差 = 12×0.8 =
**9.6dp**（跨度 60dp，数字更整齐）。护栏安全性照旧（响时最远层波峰上限仍在计时器护栏之下更靠下处）。

### 2. 抑制空调稳态底噪（WaveAudioAnalyzerOpus）

**根因**：分析器有两条响度路径——
- `relativeLevel`：**有自适应噪声底**（`mFloorDb` 快降慢升），稳态空调噪声被其吸收 → 稳态 `≈0`。这条路径
  本能正确忽略空调。
- `absoluteLevel = (dbFs+72)/50`：**纯绝对阈值、无任何噪声底**。空调 -50dBFS → `≈0.44`，持续不衰减。

`mapToDrive` 里 presence/loudness/intensity 都用 `max(relativeLevel, absoluteLevel)` 或含 `absoluteLevel`
加权，于是即便 `relativeLevel` 把空调压到 0，`absoluteLevel` 旁路仍持续把它抬到 0.44、喂给水位/基础波场/
sustain。这是之前为治"说话没波浪"降敏时的副作用。

**修法**：让有自适应底的 `relativeLevel` 主导，`absoluteLevel` 降为**辅助**，且辅助力度随**音调性**缩放：
`absAssist = ABS_ASSIST(0.5) × (NOISE_FLOOR_ASSIST(0.28) + (1-0.28)×max(tonal, voiced))`。
- 空调（稳态宽频、无音高，flatness 高→tonal≈0、voiced≈0）：absAssist ≈ 0.5×0.28 = 0.14，且乘 absoluteLevel
  0.44 ≈ 0.06 → presence 稳态≈0.04，几乎不激活；
- 真实语音/音乐：`relativeLevel` 本就高、主导，且 tonal/voiced 高→absAssist 接近满值，**不受影响**。

presence、loudness、intensity 三处一并用 absAssist 缩放 absoluteLevel/fastLevel；relativeLevel 权重相应提高。

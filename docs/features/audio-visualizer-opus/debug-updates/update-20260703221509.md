# Opus 波浪：结构性重构——始终起伏的基础波场 + 有峰有谷 + 真正滚动

## 本次更新（针对 5 条真机反馈的结构性修复）

上一版暴露的是模型缺陷（非调参能解决），本次重构 `WaveVisualizerOpus` 的水面组成：

- **引入"基础波场"（解决 P1 全平 / P5 没有波谷 / P4 不够丰富）**：水面不再是"正高斯波峰叠在会
  上抬的平基线上"（只有峰、无谷、安静全平）。改为**一层始终存在、会横向漂移、有峰有谷的多分量
  行波基础波场**：每层 3 个分量（长/中/短）各自波长、漂移速度、相位、权重（实例级随机，每次
  打开略不同），场值 ∈ [-1,1] → 天然有峰有谷。振幅随声音涨落，**安静也保留 floor 轻微起伏（绝不
  变平线）**，声音大时汹涌。离散事件浪包叠加其上做野性响应。
- **有峰有谷 + 峰尖谷平（P5）**：叠加后做 Gerstner 不对称整形——峰轻度尖化、谷压浅且软限深度
  （最深约基线下 18dp，不露按钮），s=0 处 C1 连续。波谷会真实下陷，但不夸张。
- **浪真正"滚过来"而非"拔地而起"（P3）**：上一版波包传播速度设得太小（几乎不动，所以原地长
  起来）。本次色散速度常数大幅提高，并让浪从上游边一侧出生横滚过水面；生命周期升起更平缓
  （riseFrac 0.28–0.42）。
- **降低"流动的锯齿"（P2）**：去掉产生线性插值棱角的弹簧层（其"活水"职责由基础波场承担），
  水面采样密度 72→112，Catmull-Rom 之上更平滑。
- **让浪成为主要表现、削弱基础水位占比（P4）**：水位涨幅收窄（range 0.22→0.10），浪的振幅
  （基础波场 + 事件浪）成为响度的主要表达；上方软限护住计时文本。

## 仍另案

- 录音回放偏小/偏闷：去 AGC 代价 + 远场手机录音；近场人声更好；保存文件音质改善另行谨慎处理。

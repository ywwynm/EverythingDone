# Opus 波浪：修"说话没有波浪"（灵敏度 + 采集回退）

## 本次更新

针对反馈"我在那说话，一点波浪都没有"，修两处根因：

- **采集源回退链**：采集源改为依次尝试 `UNPROCESSED → VOICE_RECOGNITION → MIC`，直到某个真正
  `STATE_INITIALIZED`。此前若设备"报告支持 UNPROCESSED 但实际初始化失败"，会没有录音线程、分析器
  收不到数据、驱动帧恒为 SILENCE、水面全平永不生成浪。现在保证一定有可用采集源（DEBUG 日志会打印
  实际选中的源）。
- **放开灵敏度（去 AGC 后信号变低导致门控过严）**：
  - 分析器：presence 改为主要由"相对电平（超出近期噪声底的部分）"驱动，去掉"相对电平×音色×噪声"
    三重门控（音色/浊音仅温和加权、下限 0.6，绝不把有声压成零）；loudness/intensity 不再乘 presence
    二次压低；持续驱动 sustain 更慷慨；dB 窗口整体下移（−72..−22）、自适应 peak 起点贴近 floor 让
    相对电平即时敏感；安静判定门槛下调。
  - 可视化：大幅下调生成门槛（onset 0.28→0.12、sustain 0.24→0.10）、只在近乎全静音时才 block；
    持续驱动生成更密；浪幅上限 34→42dp、初生浪幅下限抬高，确保可见；帧循环判定改为"attached 且有
    尺寸"，避免可见性判定抖动导致动画停摆。

预期：说话/放音乐时应能明显看到成群的浪按数量/大小/分层随声音变化。若现在偏"过敏/过多"，属预期，
再往回收比"没反应"好调。

## 已知另案（不在本次改）

- 录完音回放偏小、偏闷：是去掉 AGC/NS 的代价（AGC 本会顶高音量）叠加手机单麦录远场外放音乐本身
  就偏小偏闷；近场人声备忘会明显更好。保存文件的响度归一化/音质改善属动用户数据的改动，另行谨慎处理。

- 真机验证：说话/放歌是否明显出浪；安静（仅空调）是否平缓；数量/大小/分层是否随音量/音色/节奏变化。

# Opus 波浪：层次均衡（前后层各有存在感，后层不突兀高过前景）

## 本次更新

上一版为根治"后层特别高"把所有分量都共享了，导致每层形状完全一样、后层被前景全遮住、只剩一道
浓色（太统一）。本次取两版的**均衡**：

- **主长波 comp0 全层共享**（维持宏观协调，前景大体领先、后层不会整体乱冒高过前景）；
- **中/短波 comp1/comp2 每层独立**（各层有自己的局部起伏、互相错开 → 后层能在前景之间露出、有
  存在感），但独立分量占比有限，后层只能小幅高过前景、不会"特别高"。
- **事件浪包偏前景但不过度**（放松 front-bias）+ **后层浪幅压小但仍可见**（0.6→1.1）→ 后层也有小
  事件浪露出，同时不出现后层突兀高峰。
- 层偏移适度回调（后层稍高一点、更有存在感）。

  自然协调；流动、峰谷、水位涨落是否保持。若还偏某一边（后层还是太弱 / 又偶尔冒高），告诉我往哪
  收，这个均衡点可以继续微调（独立分量权重、层偏移、浪包 front-bias 三个旋钮）。

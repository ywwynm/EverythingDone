# Opus：流向固定为右往左（修方向约定 bug）+ 快慢再提

## 本次更新

### 1. 流向修正（含一个真正的方向约定 bug）
用户反馈近层常从左往右流，觉得录音应绝大多数从右往左。排查发现**方向约定不一致的 bug**：
- 基础波场 `sin(k·x + drift·t)`：`drift>0` → 波形向 -x 移动 = **从右往左**；
- 事件浪包 `center = origin + dir·speed·age`：`dir>0` → center 向 +x = **从左往右**；
- 两者约定相反，而浪包直接用 `mFlowDir` 作 dir，导致**基础水面与浪包主流向对着流**；加上 `mFlowDir`
  每次随机正负，就出现"近层（浪包主导）从左往右"。

改：
- **主流向固定为从右往左**（`mFlowDir = 1f`，不再随机）；
- **统一浪包 dir 约定**：`dir = if (rand<ALIGN) -mFlowDir else mFlowDir`（主向 dir<0，与 drift>0 视觉同向）；
- **丰富度（少数反向）**：基础波场少数层反向（`LAYER_REVERSE_PROB=0.18`，平均~1 层左往右）+ 少量浪包
  反向（`PACKET_FLOW_ALIGN` 0.78→0.85，即 15% 浪包左往右）。

### 2. 快慢再提
- `FLOW_BASE` 0.6→**0.5**、`FLOW_PACE` 2.0→**2.8**（静息更慢、快时更快）；
- 浪包速度 pace 系数 (0.5+1.2·pace)→**(0.4+1.7·pace)**（spawnWave 与浪列同步）。

- `:app:assembleDebug` 通过；`:app:publishDebugUpdate` 发布（debug code **202607040220**）。
- 真机验证：
  1. **绝大多数波浪从右往左流**，只有个别层/个别浪偶尔从左往右（丰富度）；
  2. **说快 vs 说慢的流速差异是否够大**（还不够的话 `FLOW_PACE` 可继续提）；
  3. 远层圆润、半绝对大小声、频段、浪列等是否保持。

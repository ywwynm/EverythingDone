# Opus 录音波浪：撤回波峰白色高光，回到无高光版本（D27）

## 本次更新

波峰白色高光(方案C:斜率镜面着色 + 闪点)两版真机效果都不理想(首版像"尺子刻度",修正版仍不自然),已**整套撤回**,水面回到没有白色高光的版本(即之前的 202607040529)。

保留的:此前所有其它改动都在——K 加权响度、SuperFlux、分桶 + 相量递推、去机械感,以及竖直深度明暗着色(波峰提亮 / 深水压暗,那是水体自身着色、不是高光层)。

## 验证

真机确认:

1. 波峰上**不再有白色高光/闪点**,水面干净。
2. 竖直明暗(体积感)、大小声、流向、层次、帧稳定性等其余表现是否一切照旧。

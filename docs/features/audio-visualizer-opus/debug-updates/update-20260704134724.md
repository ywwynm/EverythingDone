# Opus 录音波浪：波峰高光（斜率镜面着色 + 少量闪点，方案C，D26）

## 本次更新

给波峰加了接近白的高光,让水面更像自然水。做法贴近物理、刻意避免"白边":

- **斜率镜面着色**:高光按**波面朝向(斜率/法线)**出现在迎光的波峰坡面上(Blinn-Phong specular),是软的、向下羽化的近白光,不是沿轮廓的一条线。
- **碎斑 + 闪烁**:高光被高频碎斑打散成斑块,并随波浪与相位缓慢明灭移动,像阳光洒在水面的波光,而非固定描边。
- **少量闪点(sun-glitter)**:最前一层的波峰尖上,偶尔出现几个柔和的近白光斑点缀(数量封顶、克制)。
- **能量门控**:只有声音够大、浪够高时才出现;安静水面不闪。只作用前景 1–2 层,近白非纯白。

## 验证

真机重点看:

1. 高光是否**自然、像被光打亮的波峰/波光**,而**不是一条白边或描边**。
2. 闪点是否克制、不像"贴钻/闪闪发光",数量/大小/亮度是否合适。
3. 安静时是否确实不出现高光;有声/大声时是否恰当增强。
4. 整体是否发白/发脏(若有,可调低强度或改用 SCREEN 混合)。
5. 高能量场景**帧是否仍稳**(前景多两遍绘制)。

可调:`SPEC_SHININESS`/`SPEC_LIGHT_X`(高光集中度与选面)、`HILIGHT_MAX_ALPHA`/`HILIGHT_BAND_DP`(带强度/宽度)、`SPARKLE_*`(碎斑疏密/移动)、`GLINT_*`(闪点数/阈值/大小/亮度)、`HILIGHT_ENERGY_*`(门控)。

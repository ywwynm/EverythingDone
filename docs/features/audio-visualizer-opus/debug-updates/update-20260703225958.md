# Opus 波浪：根治"浅色浪比深色浪高" + 加大水位涨幅

## 本次更新

- **根治"浅色后层浪比深色前景浪高"**：上一版只共享了主长波，但每层的中/短波分量仍独立相位，
  某时刻后层叠成峰、前景在谷就冒高；加上事件浪包随机落层，一道强浪落后层就"特别高"。本次：
  - **6 层共享同一整套基础波场形状**（同波长/相位/漂移/权重），层与层只按振幅倍率缩放——前景振幅
    最大 → 前景在每个位置都 ≥ 后层，后层基础波**恒不会超过前景**；层次靠振幅/偏移/配色 + 波谷处
    露出更浅的后层体现。
  - **事件浪包偏向前景层生成**（front-biased）+ **后层浪幅大幅压小**（每层包幅 0.42→1.14，后层仅
    约 0.4×）→ 野性高峰主要落前景，后层只作小点缀，不再出现后层特别高的浪。
- **加大基础水位涨幅**：WATER_RANGE 0.10→0.15，水位随音量的涨落更明显。

  处看到、有层次；基础水位涨落是否更明显；流动、峰谷、丰富度、连续性是否保持。

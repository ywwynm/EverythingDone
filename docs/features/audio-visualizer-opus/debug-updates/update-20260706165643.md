## 根因

上版做成了离散水滴粒子（spawn 一堆小圆在空中下落），完全不是"水体整体下坠"。删除全部粒子代码。

## 本次实现（②，重做）

- **整摊水体重力下坠**：快速大幅重定向（倒置/急倾，重力旋转 >约180°/s）时，把**整摊水沿 -重力方向"托"到空中**——水体渲染成一条**有限厚度的水带、下方露出空气**（不再是填到底）。
- **自由落体 + 落地反弹**：停手后水带在重力下自由落体，砸到新底部**反弹几次**（bouncing ball，每次更低）归位。6 层一起动。
- **水量守恒**：水带厚度 = 原填充深度，托起的是"同一摊水"（不凭空增减）。
- **静止/常态零影响**：不快速重定向时托举高度=0，水体完全等于原来的填充（音频波浪一字不变）。

## 需要重点观察（真机）

- **整体下坠**：倒置或快速大幅倾斜手机，是否**整摊 6 层水**从空中（旧位置一侧）落向新底部、下方能看到空气缝，而不是几个粒子。
- **反弹**：水砸到新底部后是否**反弹几次**、每次更低后停住。
- **倒置**：直接颠倒手机，水是否倒灌到新底部（原顶部）并反弹。
- **下落快慢/托举高度**：调 `DROP_GRAVITY`（现 3200）/`DROP_HEIGHT_GAIN`。
- **反弹次数**：调 `DROP_RESTITUTION`（现 0.5）。
- **不误触发/不"悬停"**：日常小倾斜不该下坠；快速倾斜过程中水被托在空中、停手才落——若过程中"悬停"感太重，调 `DROP_COOLDOWN`/`DROP_GATE`。
- **静止零回归**：不动时音频波浪与之前一致。

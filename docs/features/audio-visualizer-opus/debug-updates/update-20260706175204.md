# 录音波浪可视化 debug 更新 - 2026-07-06 17:52

本次更新修正倒置下坠瞬间的“波浪面被重置/换边”问题。

问题：
- 上一版虽然把空中下坠改成了变形水片，但下坠前沿仍然从翻转后的新重力水面推导。
- 直接倒置时，看起来像先把波浪面和平底颠倒，再用平底去下坠，而不是让翻转前的自由液面成为新的下坠前沿。

改动：
- 普通状态下持续缓存最后一帧前景自由液面。
- 倒置触发时，在重力切到新方向之前复制这条旧自由液面快照。
- 空中下坠阶段优先用该快照沿新重力方向推进，并叠加变形；接近落地时再淡出到新重力下的面积守恒水面。
- 180 度翻转时会自动反向匹配切向采样顺序，避免左右接反。
- 首次触底后清除旧快照，后续反弹交给新重力水面和 slosh 场。

本地验证：
- `:app:assembleDebug` 已通过。
- 静态检查确认 `triggerWaterDrop` 会先捕获旧自由液面快照。
- 数值检查确认 180 度翻转时快照采样顺序会反向，且下坠起点使用旧自由液面、落地前淡出。
- 未使用 adb，未连接真机或模拟器。

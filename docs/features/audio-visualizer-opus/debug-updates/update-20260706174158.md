# 录音波浪可视化 debug 更新 - 2026-07-06 17:41

本次更新修正倒置下坠的“果冻块”观感。

问题：
- 上一版把整摊水作为刚体水带下坠，空中阶段下边缘与上边缘平行。
- 结果看起来像一块保持形状的软块，而不是一摊水在落下。

改动：
- 下坠阶段改为连续的“变形水片”：上边界仍保留音频波浪和自由液面，下边界改为独立的下坠前沿。
- 前沿会随下落进度、速度和层间相位产生不规则凸起、拉伸、边缘收缩和波纹，不再保持平齐。
- 触底时增加即时水面凹陷和侧向铺展，再叠加原有 Phase 1 回荡。
- 不新增可见粒子、水滴、泡沫或边框；音频仍是核心。

本地验证：
- `:app:assembleDebug` 已通过。
- 数值抽样确认下坠前沿不再是平行直边。
- 未使用 adb，未连接真机或模拟器。

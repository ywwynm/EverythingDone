# 录音波浪可视化 debug 更新 - 2026-07-06 18:32

本次更新修正倒置坠落触底后的物理反馈，以及斜向坠落时的高度/翻面问题。

调研结论：
- 真实水体撞底/撞壁后，主要表现不是整摊水刚体反弹，而是冲击压力、侧向挤压、壁面爬升、回落、反射波和次级波。
- 局部破碎、气泡和飞溅常发生在冲击之后，但当前 Canvas 方案仍用大尺度自由面和浅水速度场近似，不新增粒子雨或泡沫层。

改动：
- 取消整摊水作为刚体弹簧反弹的主反馈；触底后停止全局落体。
- 把触底速度更强地注入浅水速度场，形成中心凹陷、两侧壁爬升和更大的回荡波。
- 斜向坠落时，水片厚度使用触发前缓存的姿态厚度，避免按未倾斜/新重力口径重算。
- 触底前快照权重保持为 1，不再在快接触新底部时提前淡出/翻到新重力水面。
- 触底后通过短暂 settle blend 自然恢复到新重力下的正常层级。

本地验证：
- `:app:assembleDebug` 已通过。
- 静态检查确认旧刚体反弹常量已移除。
- 冲击动量和高度注入强度约提升到上一版的 1.9 倍。
- 触底前快照权重保持为 1。
- 未使用 adb，未连接真机或模拟器。

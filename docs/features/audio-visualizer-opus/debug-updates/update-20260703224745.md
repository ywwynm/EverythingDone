# Opus 波浪：收小层间高度差 + 修浪高突变

## 本次更新

采集维持 MIC（用户已定）。两处优化：

- **收小层间高度差（前景占主导、后层不再偶尔更高）**：根因除偏移/振幅外，更本质是**每层基础
  波场相位独立随机**——某时刻后层正在波峰、前景正在波谷，后层就显得更高。改为：**所有层共享同一
  道"主长波"分量**（长波尺度上同起同落），前景振幅最大→前景最高，层间只在细节上差异；并收紧
  每层振幅倍率区间（0.68–1.16→0.82–1.10）、进一步减小层偏移。
- **修"浪升起后高度突变、像被 set"**：根因是并发浪满(14)时新浪生成会**硬删一道浪**，若那道浪
  当时仍明显，其贡献瞬间消失=高度突变。改为**只回收已很淡（生命周期包络<0.14、接近消亡）的浪，
  否则本次不生成**，绝不硬删可见浪；并发上限 14→18；绘制按索引遍历减少分配抖动。

## 验证

- `:app:assembleDebug` 通过；`:app:publishDebugUpdate` 发布（debug code **202607031448**）。
- 真机验证：后层是否不再偶尔比前景高、层间高度差是否更协调；浪升起后是否不再出现突兀的高度
  跳变（更像连续动画过渡）；流动、峰谷、丰富度是否保持。

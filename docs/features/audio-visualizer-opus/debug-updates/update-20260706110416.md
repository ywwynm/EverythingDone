# 录音水体 360 度倾斜容器 debug 更新

本次 debug 版本用于验证录音 dialog 中 Opus 水体可视化的新容器玩法。

## 用户诉求

用户希望录音 dialog 里的水和波浪不仅响应音频，还能在手机或平板倾斜时像一个可玩的容器：水体随重力方向倾斜、倒灌、撞壁、爬墙和反弹。完全倒置时，原本的 dialog 顶部应成为新的物理底部，水体倒灌过去并继续正常动画。

## 本次实现

- 录音 dialog 打开期间临时锁定宿主 Activity 方向，防止系统旋转导致整体 UI 重建；退出 dialog 后恢复原方向策略。
- 接入 `TYPE_GRAVITY` 传感器，缺失时用加速度计兜底，只在 dialog 可见期间监听。
- 将 `WaveVisualizerOpus` 从固定屏幕底部填充，重构为连续 360 度重力容器。
- 水量按面积守恒处理：音频只调节总体水位，设备旋转和倾斜只重新分布同一摊水。
- 音频波浪、基础波场和倾斜 slosh 浪包都跟随当前自由液面坐标系传播。
- 完全倒置、横放、斜角时，水体按当前重力方向重新定义底部和自由液面。
- 接近平放时保留最近稳定方向，并缓慢回到当前 UI 默认底部，避免传感器噪声导致水面乱转。
- 新增偏夸张的玩具水槽感：快速旋转、前后扣动和反向晃动会触发撞壁/反弹式 slosh 浪包。

## 调研与取舍

本次调研重点修正为动画模型本身。结论是采用重力相对的 1D height-field / shallow-water 自由液面，加面积守恒几何裁剪；不采用 VOF/Navier-Stokes 或 SPH/PBF 粒子流体。这样能在 Android `Canvas` 自定义 View 中保持 O(N) 绘制成本，同时满足倒置、守恒、撞壁和音频波浪跟随。

## 已验证

- 本地 `:app:assembleDebug` 已通过。
- 未使用 adb，未连接物理设备或模拟器。

## 需要重点观察

- 竖屏、横屏、倒置、斜角和接近平放时，水体底部方向是否符合真实重力。
- 完全倒置时水是否稳定倒灌到原顶部，并在新底部继续正常动画。
- 玩具水槽强度是否足够夸张，是否需要继续调 `SLOSH_*`、`GRAVITY_FOLLOW_TAU`、`CREST_CONTAINER_FRAC` 等参数。
- 音频波浪是否仍然是主角，没有被倾斜 slosh 长期抢走表现。
- dialog 退出后 Activity 方向策略是否恢复正常。

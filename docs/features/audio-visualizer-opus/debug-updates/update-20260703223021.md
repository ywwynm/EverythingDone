# Opus 波浪：让前景主体浪占主导 + 略减横向波峰数

## 本次更新

反馈：后面浅色（更淡、更透）的浪反而升得比前面最浓的主体浪还高；横向波峰数量稍多。

- **前景/主体浪占主导**：根因是后层基线偏移过大（后层被抬高 16dp）+ 前后振幅未区分，导致后层
  站得高、显得更猛。改为**大幅缩小层偏移**（16→5dp 递减到 0）+ **给每层加振幅倍率、前景/主体
  层最大（1.16×）后层递减（最低 0.68×）**，让最浓的前景浪明显占主导（后层作次要景深）。
- **略减横向波峰数**：基础波场空间频率（尤其短纹分量）下调（cycles 区间与短纹权重都略降），
  横向波峰数量少一点点。

## 验证

- `:app:assembleDebug` 通过；`:app:publishDebugUpdate` 发布（debug code **202607031431**）。
- 真机验证：最浓的前景主体浪是否明显占主导（不再被后层浅浪盖过）；横向波峰数是否更舒服；流动、
  峰谷、丰富度是否保持。

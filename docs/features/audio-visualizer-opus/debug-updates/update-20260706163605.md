# 倾斜物理 Phase 2：弹道水团（空中坠落 + Worthington 回弹 + 空中水量守恒）

倾斜物理升级（D48/D49，C-可见）的 **Phase 2**，建在 Phase 1 的自由液面速度场之上。目标：**倒置/快速大幅倾斜时，水从空中坠落到新底部、砸底溅起并回弹**。

## 本次实现（②⑤）

- **剥离触发（A）**：只在**快速大幅重定向**（重力方向旋转速率超阈，约 >180°/s，倒置/急倾）时，从"高处空中"剥离出少量水团；日常小幅/慢速倾斜不掉水。
- **弹道下落**：水团沿**真实重力向量**加速下落（倒置时就落向新底部）。
- **外观**：少量（单拨 1~4 个、最多 14）**较大柔边水团**，染成记事本色（内实外柔的径向精灵，不是喷雾/硬点，守 D48"是水不是碎屑"）。
- **砸底 = 两层回弹**：① 往速度场注入局部凹陷（crater）→ 复用 Phase 1 动力学转成外扩涟漪 + 水面回荡；② 水团自身 **Worthington 回弹**（恢复系数 0.45，再弹 1~2 次、每次更小更低）后并入水面。
- **空中水量守恒（⑤）**：水团在空中时从水位如实扣除（水面下降），落地加回（放大让下降可见）。
- 只在快速重定向时出现，静止/常态无水团、不碰音频波浪身份（守 D34）。

## 已验证

- 本地 `:app:assembleDebug` 通过。
- 未使用 adb，未连接物理设备或模拟器。

## 需要重点观察（真机）

- **倒置坠落**：把手机倒过来（或快速大幅倾斜），是否有水团从空中落向新底部、砸出水花。
- **回弹**：水团砸到水面后是否自己反弹一两次（每次更低）+ 水面被砸出涟漪回荡。
- **是水不是碎屑**：水团是否像"一坨水"（较大、柔边、本色），而非喷雾/彩纸。太碎/太多调 `BLOB_RADIUS_DP`/`BLOB_COUNT_GAIN`/`PEEL_GATE`。
- **坠落快慢**：太慢/太快调 `BLOB_GRAVITY`（现 2600 px/s²）。
- **水位下降**：水团在空中时水面是否可见地降一点、落地回涨。太夸张/不明显调 `BLOB_CONSERVE_AMPLIFY`。
- **不误触发**：日常小幅倾斜、说话时不该掉水（应当不掉）。误触发调高 `PEEL_GATE`。
- 幅度/尺度是估的起点，可能偏大或偏小，按上述旋钮真机调。

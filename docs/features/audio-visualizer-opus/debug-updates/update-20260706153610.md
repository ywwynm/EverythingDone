# 修复 Phase 1 开场狂涌 / 无数尖锐波峰

修复上一版（202607060726，倾斜物理 Phase 1）的严重回归：**打开 dialog 后水面流动极快、形成无数尖锐波峰**。

## 根因

速度场求解本身稳定（交错网格 leapfrog，G·HH<1），问题在**激励注入**，三坑叠加：

1. **开场收敛喷冲量（主因）**：初始假设重力为 `(0,1)`，打开 dialog 时若手机不完全竖直，`mStableGravity` 从 `(0,1)` 收敛到真实方向的每帧旋转增量 `dθ` 累加成一次性巨大冲量灌进速度场 → 瞬间狂涌。
2. **传感器噪声持续注入**：休眠门槛太低，手持微噪声让激励每帧都超阈值 → 速度场永不休眠、每帧被踢 → 累积成极快流动。
3. **前后倾(z)激励用了阶跃 profile**（中间 ±1 突变）→ 注入高频成分 → 无数尖锐波峰。

外加主增益 `SLOSH_TILT_GAIN` 对"按帧累积式"注入而言大了约 10 倍。

## 修复

- **重力状态锚定到首个真实读数**：首次可信读数时把重力/稳定方向/prev 全部 snap 到真实方向，消除开场收敛冲量。
- **激励死区 + clamp**：低于阈值的姿态变化视作噪声、不注入（速度场得以正常休眠）；单帧注入设上限，避免一次大动作灌爆。
- **z 激励改平滑 2 阶模 profile**（`cos(2π·faceNorm)`，零均值、无高频尖峰）。
- **速度场安全 clamp**：形变/流速加硬上限，防极端输入下爆冲甩飞浪包。
- **增益回到合理量级**（`SLOSH_TILT_GAIN` 350→40 等），休眠门槛提高。
- **View 分离时复位**晃动状态，避免复用残留。

## 已验证

- 本地 `:app:assembleDebug` 通过。
- 未使用 adb，未连接物理设备或模拟器。

## 需要重点观察（真机）

- **开场正常**：打开 dialog（手机任意角度静止）后，水面应平稳、不再狂涌或满屏尖峰。
- **静止零回归**：不动时音频波浪应与加倾斜前完全一致（速度场休眠）。
- **倾斜回荡**：主动倾一下再放住，水面应来回衰减荡几次（甲）后平静；幅度太小/太大调 `SLOSH_TILT_GAIN`。
- **慢倾是否被死区吃掉**：若很慢地倾斜没反应，调低 `TILT_DEADZONE`。

## 2026-07-06 修复恒定声音下录音波浪水位回落

- 修复录音 dialog 的 Opus 音频可视化中，持续播放同样大小声音时水位逐渐下降的问题。
- `WaveAudioAnalyzerOpus` 的自适应底噪门控新增内容保留判断：当输入明显高于当前底噪，或 K 加权绝对电平达到真实内容区间时，冻结底噪上升，避免稳定声音被慢慢当成新底噪。
- 修正开场 seed：如果打开录音 dialog 时声音已经存在，会给 floor 留出更大的响度余量，避免第一帧内容被 5dB 死区吃掉。
- 新增 `WaveAudioAnalyzerOpusTest`，覆盖“先有背景再出现恒定宽频内容”和“开场即有恒定内容”两个回归场景；本地单测与 `:app:assembleDebug` 已通过。未使用 adb。

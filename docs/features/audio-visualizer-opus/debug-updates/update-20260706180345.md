# 录音波浪可视化 debug 更新 - 2026-07-06 18:03

本次更新修正倒置下坠开始瞬间的 6 层层级反转和水体高度缩减。

问题：
- 上一版只缓存了前景自由液面，后面 5 层仍会在倒置触发后立即按新重力重新求解。
- 空中下坠阶段的背面仍来自新重力下的层偏移，导致开始下坠时能看到层级反转，水体高度也会被压缩。

改动：
- 普通状态下缓存 6 层各自的自由液面，而不是只缓存前景层。
- 倒置触发时复制完整 6 层快照。
- 空中阶段每一层都优先用自己的旧快照生成前沿和背面，保持原本层级和可见高度。
- 接近触底时才逐步淡出旧层级，第一次触底后清除快照，让层级自然恢复到新重力下的正常结构。

本地验证：
- `:app:assembleDebug` 已通过。
- 静态检查确认快照读写都带 `layer` 维度。
- 数值检查确认 180 度翻转时快照采样会反向，空中起点快照权重为 1，落地前淡出为 0。
- 未使用 adb，未连接真机或模拟器。

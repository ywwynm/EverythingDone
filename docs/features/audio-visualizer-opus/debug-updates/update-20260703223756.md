# Opus 波浪：采集切回 MIC（对比用）

## 本次更新

按要求把录音采集切回原始 `MIC` 供对比。新增编译期开关 `AudioRecorder.PREFER_MIC`：

- `PREFER_MIC = true`（本次）：采集源 `MIC`，**保留默认 AGC/NS**（还原原始录音体验，录音更响更清），
  不做采集源回退/关音效。代价：AGC 压平动态、NS 抹频谱细节，可视化对"音量强弱/音色"的区分会变弱。
- `PREFER_MIC = false`：`UNPROCESSED`（回退 `VOICE_RECOGNITION`）+ 关 AGC/NS/AEC（特征最好、
  录音偏小偏闷）。

采集仍为单声道（channels=1），与音质对比无关（多数手机 stereo 只是复制单声道）。可视化逻辑不变。

## 验证

- `:app:assembleDebug` 通过；`:app:publishDebugUpdate` 发布（debug code **202607031438**）。
- 真机对比：MIC 下保存的录音是否明显更响更清（不再偏小偏闷）；同时可视化对说话强弱/音色的区分
  是否变弱（AGC 压平动态所致）。据此决定最终采集方案。

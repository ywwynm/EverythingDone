# Opus 波浪：修降落慢 / 前景层不触发 / 安静态初始瞬变

## 本次更新（针对三条真机反馈）

- **问题1 降落慢**：说完一个词后浪上升 OK，但回落偏慢。原因是浪包生命周期偏长 + 持续驱动
  sustain 释放慢，词结束后仍继续生成、旧浪也要约 1 秒才消，拖出长尾。
  → 生命周期 base 1.15s→0.8s、回落起点前移（fallStart 0.48–0.66→0.40–0.54）、pace 对时长的
  延展收窄；sustain 释放 analyzer 0.45s→0.22s、visualizer 0.45→0.22。词结束后水面回落明显更快。
- **问题2 最前两层几乎不触发、前景水面一直平**：此前"音色→落层"做得太硬（bass→后层、treble→前层），
  而录进来的信号偏闷、几乎没 treble，导致前景层被饿死，只剩弹簧活水那道极矮的左右滑动。
  → 改为**浪跨全部 6 层均匀分布，确保前景/主体层也持续有浪**；音色（亮暗）改为影响"波的整体
  粗细"而非决定落哪层；前景短浪也保持可见高度；并调低弹簧活水幅度与滑动感。主体水面的上边界
  现在会明显起伏。
- **问题3 安静环境打开后水面先涨后落、且最终态与初始态不同**：这是自适应噪声底的初始收敛瞬变
  ——底噪起点比实际环境低，开场几秒"什么都显得响"，等底噪爬到空调声电平才归于平静。
  → **用开场首帧实际环境电平锚定自适应底/峰**（每次开始/重新监听都会重新锚定），消除这个瞬变，
  打开即稳定、且稳定态一致。

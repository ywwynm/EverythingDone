# Opus 波浪：大胆加大层间基线差异 —— 绝对平静时也清晰可见每一层

## 本次更新

反馈：前景仍盖住后面。用户要求先**大胆加大每层的基础水位高度差异**，让绝对平静时也能清晰看到每个层级。

根因：安静时 `offsetScale = OFFSET_BASE_SCALE = 0.35`，层间基线偏移 = 相邻梯度 4dp × 0.35 = **仅 1.4dp**，
而平静时 floor 波动就有约 3.5dp，层与层必然糊在一起、看不出分层。

大胆调整（层间偏移约放大 6.8 倍）：

- `mLayerOffset` 基础梯度 `[20,16,12,8,4,0]` → `[66,52.8,39.6,26.4,13.2,0]`（相邻 4→13.2dp，跨度 20→66dp）；
- `OFFSET_BASE_SCALE` 0.35 → **0.72**（绝对平静时相邻层基线差约 **9.5dp**，远大于 floor 波动 → 清晰可分）；
- `OFFSET_DRIVE_SCALE` 1.0 → 0.35（层间偏移改为以 base 为主、较稳定；响时再略展开）。

于是绝对平静时能看到 6 条明显错开、层层叠起的水线（由深到浅、半透明叠加成透视水面），而非糊成一片。

护栏安全性核对：响时最远层基线上移到约 139dp（距顶），其净空阶梯下波峰上限约 105dp，仍在计时器护栏
（72dp）之下更靠下的位置，不会顶到计时器。

## 验证

- `:app:assembleDebug` 通过；`:app:publishDebugUpdate` 发布（debug code **202607031623**）。
- 真机验证：
  1. **绝对平静**（不出声）时是否能清晰数出 6 层错开的水线；
  2. 说话/出声时前景是否不再盖死后层、层次是否分明；
  3. 层间差异是否"大得合适"——若仍不够/或过头（顶到计时器、显得像生硬梯田），告知往哪调
     （`OFFSET_BASE_SCALE`、`mLayerOffset` 跨度两个旋钮）。

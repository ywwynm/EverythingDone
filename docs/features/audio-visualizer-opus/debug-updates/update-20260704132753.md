# Opus 录音波浪：竖直明暗改用平滑曲线，消除分段分界线（D25）

## 本次更新

上一版的竖直明暗着色是分段的（提亮段 / 本色段 / 压暗段），转折处有时能隐约看到分界线。本次改为一条自然平滑、不分段的明暗曲线：

- 明暗沿高度用平滑包络（smoothstep）定义，转折处与本色段无缝衔接，不再有斜率突变造成的隐约分界线。
- 用足够密的采样让整条曲线平滑连续，观感像自然渐变。
- 结构不变（顶亮—中段本色—底暗），此前调好的强度和位置都沿用。

## 验证

真机重点看：

1. 竖直明暗过渡是否**自然连续、看不到任何分界线**（纯色记事、渐变记事都看）。
2. 波峰提亮、深水压暗的整体观感是否仍在、强弱是否合适。
3. 渐变记事的横向渐变方向是否仍保留。
4. 其它（K 加权大小声、流向、层次、帧稳定性等）是否一切照旧。

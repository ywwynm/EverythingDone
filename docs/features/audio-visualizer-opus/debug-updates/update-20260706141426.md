# 竖直静止复原原音频波浪的峰高与谷深（D47）

本次 debug 版本用于验证：录音 dialog 在设备竖直静止时，音频波浪是否回到加入 360 度倾斜容器之前调好的观感。

## 背景

上一次"保持静止尺度"修正（202607060336）只处理了自由液面采样范围的 margin，并确认静止时 slosh 会衰减。进一步核对倾斜容器重构后的 `drawWater` 发现，竖直静止时波形整形仍有三处与原版不同：波形去均值、波谷限深变深（约 18dp→32dp）、波峰净空变小（前景大浪峰顶从距顶约 72dp 被削到约 115dp，损失约 40dp 爆发力）。

## 本次修复（D47）

- **波峰净空、波谷限深改回原口径**：参照从固定对角线 `diag` 改为"容器沿重力轴的实际深度 `vSpan`"配计时保护线。竖直静止时精确等于旧的以屏幕高度为尺度的口径——前景大浪恢复能冲到距顶约 72dp 的爆发力，波谷回到基线下约 18dp、重新护住底部录音按钮；倾斜时按容器在重力方向的真实深度自适应（比固定对角线更正确）。
- **去均值保留**：它是水量守恒的结构性前提（一旦倾斜，波形非零均值会让水量随浪增减而变），因此静止时仍保留；"响度→水位"的慢潮不受影响。这是静止时与原版唯一有意保留的差异。
- 只改渲染层的上下限幅，未触动音频分析链路、浪包生成与守恒填充。

## 验证

- 本地 `:app:assembleDebug` 通过。
- 未使用 adb，未连接物理设备或模拟器。

## 观察重点

- 设备**竖直静止**时，前景偶尔的大浪是否恢复了原来的高度和爆发力，波谷是否不再露出录音按钮，整体是否接近加倾斜容器前的动画。
- 说话/放歌时，"浪多"不再把整片水面顶高（去均值效果）是否可接受；"响度越大水位越高"的慢潮是否仍清晰。
- 设备**倾斜**时，波峰高度和波谷深度按容器真实深度自适应后是否仍然合理、不撞顶不露底。

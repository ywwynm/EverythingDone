# Opus：水位对响度的响应更戏剧（大小声的水位差更显著）

## 本次更新

用户希望"声音大小在水位高低的体现更显著、像节奏那样有戏剧性"。水位此前对响度的响应偏温和（幅度小
+ 曲线平）。三管齐下：

- **幅度加大**：`WATER_RANGE_FRAC` 0.15 → **0.22**（visualizer）。静息水位不变，大声时水位升得更高 →
  大小声的水位差从 0.15h 拉到 0.22h。
- **响应曲线更陡**：`waterTarget` 加 `WATER_DRAMA=1.2` 对比放大，并让 intensity（已过 S 曲线）主导
  （`0.4·loud + 0.6·intensity`）→ 大声更快顶到高位、小声压得更低。
- **涨得更快**：`WATER_ATTACK` 0.32 → **0.26**（大声时水位更快冲起来，更有戏剧张力）；release 仍慢
  （潮落的韵味保留）。

（用户自己微调过的其它参数保留未动。）

## 验证

- `:app:assembleDebug` 通过；`:app:publishDebugUpdate` 发布（debug code **202607040255**）。
- 真机验证：
  1. **大声 vs 小声的水位高低差是否明显拉大、更有戏剧性**（像节奏那样）；
  2. 大声时水位**是否会顶到计时器**（若顶，回调 `WATER_RANGE_FRAC`）；
  3. 流向（右往左）、快慢、远层圆润、大小声浪高等是否保持。

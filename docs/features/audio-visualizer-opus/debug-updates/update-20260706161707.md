# 晃动改注入 1 阶本征模（消除长时间颤动）+ 加大 6 层错落

修复上一版（202607060802）：倾斜后水面仍长时间处于低幅颤动（与音频无关）；6 层错落感不够。

## 根因

上版倾斜激励用"均匀"速度注入，方向对（1 阶摇摆），但**均匀 profile 会激发一串奇次谐波**（3、5 阶…）。主摇摆之外，这些高频谐波持续颤动很久 → "一直颤动一段时间"。

## 修复

- **倾斜激励改注入 1 阶速度本征模 `sin(π·u)`**（两壁为 0、中间最大）：只激发基础摇摆模态、几乎不带高次谐波 → 摇完就干净地停，不再长时间颤动。
- **加大阻尼** `SLOSH_DAMP` 0.9965→0.995：约 3~4 次干净摇摆后平静。
- **提高倾斜死区** `TILT_DEADZONE` 0.004→0.006：更好地拒绝手抖带来的持续微激励。
- **加大 6 层错落**：层间晃动振幅大幅错开（有的层晃得多、有的少，少的露出各自音频纹理）+ 水平错位 ±3%→±9%。

## 已验证

- 本地 `:app:assembleDebug` 通过。
- 未使用 adb，未连接物理设备或模拟器。

## 需要重点观察（真机）

- **摇完就停**：倾一下再放住，水面做几次干净摇摆后应**平静下来**，不再长时间低幅颤动。
- **回荡次数**：约 3~4 次。想多/少调 `SLOSH_DAMP`（大→少）。
- **6 层错落**：各层晃动幅度/位置是否明显不同、不再齐动。还不够可再调 `mLayerSloshAmp`/`mLayerSloshShift`。
- **手持是否还颤**：握着不刻意动时，若还有轻微颤动，可再调大 `TILT_DEADZONE`。
- 幅度：`sin` 本征模比均匀略弱 + 阻尼加大，幅度可能偏小；太小调 `SLOSH_TILT_GAIN`（现 40）。

## 撤销录音水体竖直明暗变化

本次更新撤销 Opus 录音波浪可视化中此前加入的 y 方向明暗着色。

用户反馈：竖直方向的明暗变化会让水体最下方显得脏。此前实现里，纯色记事使用了从顶部提亮到下方压暗的竖向同色系 `LinearGradient`；渐变记事在保留底色渐变之外，又额外绘制第二遍竖向白/黑中性光照覆盖。现在这些竖直明暗逻辑已全部移除。

当前效果：

- 纯色记事：每层直接使用记事本色或按层间远近轻微提亮后的纯色，不再沿 y 方向压暗底部。
- 渐变记事：每层底色继续完整沿用 `ThingBackground.orientation` 的 8 向渐变方向，不再叠加竖向明暗覆盖。
- 波浪形态、音频驱动、层间远近关系和上一版修正的渐变方向逻辑保持不变。

验证：已运行 `:app:assembleDebug --console=plain --no-configuration-cache`，编译通过。

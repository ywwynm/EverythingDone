# Opus 录音波浪：水体体积感 + K 加权响度 + 抗颤音 onset + 提速去机械感（D23）

## 本次更新

v5 之后经第二轮联网调研，落地五条优化（详见 decisions.md D23）：

- **水体体积感（着色）**：纯色记事的每层水面改用竖直深度渐变——波峰区提亮、静息水线以下保持纯本色，做出"上受光、下深沉"的体积感（只提亮不压暗，主体颜色身份不变）。渐变记事仍保持记事本身的横向渐变方向。
- **响度改用 K 加权（BS.1770）**：从测量源头压低低频空调隆隆声、抬升人声/音乐所在的中高频，让"大声更汹涌"更贴近人耳感知，也进一步抑制环境底噪激活。
- **抗颤音 onset（SuperFlux）**：唱歌、弦乐等带颤音的声音不再被误判成一串虚假节拍浪，onset 更干净。
- **性能提速**：浪包按层分桶 + 基础波场相量递推，去掉大量重复计算，声音丰富/高能量时的帧稳定性更好（画面丰富度不变）。
- **去机械感**：基础波场的形状随时间缓慢有机演变，弱化纯正弦的规律感；不改变流向与流速。

## 验证

真机重点复核（本轮改动 K 加权最可能影响此前调好的标定）：

1. **大小声戏剧性**是否保持或更好；空调等稳态底噪是否仍不激活（若变弱/被激活，回调 `RANGE_DB` / `DEADZONE_DB` / floor 门控）。
2. **纯色记事**水面是否有了竖直体积感、主体是否仍纯净不脏（`CREST_LIGHTEN_MAIN`/`CREST_LIGHTEN_FAR` 可调，主体想绝对纯净可把 `CREST_LIGHTEN_MAIN` 设 0）；**渐变记事**是否仍按记事渐变方向。
3. **唱歌/弦乐**的浪是否更干净、不再一串虚假浪（`SUPERFLUX_MAXFILTER_BINS` 可调）。
4. **去机械感**是否自然，有没有引入不想要的形状抖动或"左右晃动"（`WOBBLE_AMP` / `WOBBLE_K_*` 可调）。
5. 声音较大、动画丰富时**帧是否更稳**（分桶 + 相量递推的目的），流向、快慢、远层圆润、层次等是否一切照旧。

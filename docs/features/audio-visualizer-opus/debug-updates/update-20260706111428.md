# 修正录音水体左右倾斜方向反转

本次 debug 版本修复上一版 360 度倾斜容器中左右方向反向的问题。

## 问题

用户反馈：设备向左侧倾斜时，水体应该堆积到左侧，但实际堆到了右侧。

## 诊断

上一版已经修正了上下方向的初始 180 度反转；本次反馈说明水体半平面和 y 方向已基本成立，剩余问题集中在 `AudioRecordDialogFragment.dispatchGravityToVisualizer()` 的 UI 水平轴映射上。Android gravity/accelerometer 的 x 分量在当前锁定 UI 坐标下与容器希望的“左侧为负、右侧为正”的物理方向相反，因此左右堆积被镜像。

## 修复

- 在传入 `WaveVisualizerOpus` 前只翻转 `screenX`。
- 保持 `screenY` 不变，避免回退上一次“初始直接跑到顶部”的修复。
- 360 度水体容器、倒置倒灌、面积守恒、音频波浪跟随自由液面等逻辑保持不变。

## 验证

- 本地 `:app:assembleDebug` 通过。
- 未使用 adb，未连接物理设备或模拟器。

## 观察重点

- 设备向左倾斜时，水体应堆积到左侧。
- 设备向右倾斜时，水体应堆积到右侧。
- 正常竖直打开时，水体仍应停在底部，不应重新跑到顶部。

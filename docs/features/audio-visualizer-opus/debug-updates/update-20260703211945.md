# 录音波浪可视化换用全新 Opus 方案（首轮）

## 本次更新

- 录音对话框的声音可视化整体替换为全新设计的 **Opus 波浪方案**（类名带 Opus 后缀，v1/v2/Fable 旧方案代码全部保留未删）。核心 = **离散艺术化波浪群 + 轻弹簧水线底**，声音塑造的是一群会传播的浪的数量/大小/分层，而非一片写实水面纹理：
  - 一道"浪"= 非对称高斯波峰（迎风面更陡，峰尖谷平天然成形）沿色散速度横向传播，按 rise→travel→decay 生命周期自然演化，出生后不被后续音频改写；
  - 6 层深度视差：后层大而慢的长浪、前层小而快的短浪（尺度倾向，非硬频段轨道）；浪按尺度/音色落层；
  - 声音→波浪群：响度→浪的数量+高度+水位；音色（低音↔明亮）→浪的大小分布与落在哪些层；音高→主导波长；onset/节奏→催生主浪+副浪；语速→生成率与传播/流速；
  - 主体水体用纯记事本色（满明度满不透明），上层波浪更亮更透表现景深，静息水面即盖住录音按钮；
  - 底层轻弹簧水线做浪间细微涟漪与"活水"，静默也不死平；
  - 水面轮廓用 centripetal Catmull-Rom 重建，从根上无阶梯/无过冲/无自交。
- **录音采集改根**（解决"录音抓不到精细声音特征"）：采集源从 `MIC` 改为 `UNPROCESSED`（设备不支持时回退 `VOICE_RECOGNITION`），并显式关闭 AGC/噪声抑制/回声消除，改单声道采集（WAV 头同步改 mono）。这能拿回被 AGC 压平的动态与被降噪抹掉的频谱细节。**注意：保存的语音备忘也会随之更自然、动态更真，但安静环境可能更"生"、偏小声、噪声更明显。**
- 全新 Opus 音频分析器：预加重 + FFT + 5 宏频段自适应归一 + 逐 bin 自适应白化做 onset + 归一化谱质心（亮暗）+ 谱平坦度门控（抑制稳态空调风噪）+ 事件密度（速度感）+ YIN 音高。

## 验证

- `:app:assembleDebug` 构建通过；`:app:publishDebugUpdate` 发布本更新（debug code **202607031321**）。
- 待真机目视验证与调参：
  - 录音时旁边放音乐/说话，观察"浪的数量、大小、落在哪些层"是否随音量、音色、节奏明显变化且自然；
  - 安静（含空调风噪）时是否平缓轻柔、只余活水微动；强声/快歌是否够野够快；
  - 主体水体颜色是否始终是纯记事本色、不偏暗偏脏；水位是否盖住录音按钮且不糊住计时；
  - 曲线是否连续无阶梯/无毛刺、无帧峰卡顿；对话框保持 280×360dp；锁屏返回动画自动恢复；
  - 保存的语音备忘音质是否可接受（如偏小声，后续可对写盘那份加响度归一化）。

# 保持静止状态下的原音频波浪尺度

本次 debug 版本用于降低 360 度倾斜容器在设备相对静止时对原 Opus 音频波浪动画的影响。

## 问题

用户询问：当陀螺仪/重力数据相对静止时，当前方案会不会影响原本的音频波浪动画效果。

## 检查结论

静止传感器不会持续注入 slosh：`mSloshEnergy` 只来自重力方向变化量和 z 方向变化量，设备静止后会衰减，不会不断生成倾斜浪包。

但检查发现上一版为了旋转时覆盖容器边角，把自由液面采样范围额外加了 margin。这样在设备竖直静止时，基础波和音频浪包会以大于屏幕宽度的范围作为尺度，导致原本的波形横向变宽、频率略变低。

## 修复

- 自由液面采样范围改回当前矩形在自由液面切线方向上的真实投影跨度。
- 竖直静止时 `uSpan == width`，基础波频率、音频浪包宽度和速度回到以屏幕宽度为尺度的原始口径。
- 保留连续 360 度重力方向、面积守恒、倒置倒灌和 slosh 逻辑。

## 验证

- 本地 `:app:assembleDebug` 通过。
- 未使用 adb，未连接物理设备或模拟器。

## 观察重点

- 设备竖直静止时，录音水波应更接近加入倾斜容器前的原本动画尺度。
- 设备静止但保持倾斜时，应只有水体基准方向变化，不应持续冒出新的 slosh 浪包。
- 旋转、横放、倒置时仍应保持水体完整覆盖容器。

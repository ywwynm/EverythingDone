# Debug 更新日志

## 2026-07-06 启发式降低开窗外界环境声的水位响应

- 修复上一版中“安静房间打开窗户后，外界声音传入也会造成很高水位”的问题。
- `WaveAudioAnalyzerOpus` 现在拆分两类判断：`mFloorDb` 的保护门控仍可防止稳定真实声音被底噪吞掉；视觉水位驱动新增更严格的 `visualContentScore`，主要依赖音调性、音高置信、onset 强度和事件密度。
- 缺少结构证据的宽频稳态环境声现在只保留低响应，不再单纯因为 K 加权绝对电平较高就把 `waterLevel` 顶高。
- 更新 `WaveAudioAnalyzerOpusTest`：稳定内容改用音调夹具，新增宽频环境声低水位回归测试。单测已通过。未使用 adb。

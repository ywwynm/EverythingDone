# 录音波浪可视化 debug 更新 - 2026-07-06 18:12

本次更新修正倒置下坠后段的两个几何问题。

问题：
- 水片接近新底部时会突然涨高到几乎占满 dialog，下一帧又恢复正常水位。
- 设备有轻微倾斜时，空中水体左右侧可能没有铺满 dialog 宽度，露出平整的斜切面。

改动：
- 空中水片始终使用有限水厚 `dropDepth`，不再在空中阶段插值回正常填充使用的 `diag * 2` 深度。
- 正常的无限深闭合只在落地/恢复普通水面后使用。
- 空中水片左右两端增加切向 overscan，把路径闭合边推出 dialog 裁剪区外，避免可见斜切边。
- 保留上一版的 6 层快照和层级保持逻辑。

本地验证：
- `:app:assembleDebug` 已通过。
- 静态检查确认空中路径只传入 `dropDepth`，普通路径才使用 `diag * 2`。
- 数值检查确认旧逻辑在 `dropAir=0.03` 时厚度约 888px，新逻辑保持约 118px。
- 未使用 adb，未连接真机或模拟器。

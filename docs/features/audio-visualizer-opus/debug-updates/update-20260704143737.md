## 录音水体渐变方向修正

本次更新修正录音 dialog 的 Opus 波浪可视化在渐变记事下的底色方向。

此前 `WaveVisualizerOpus` 虽然接收了当前记事的 `ThingBackground`，但渐变水体底色固定使用横向 `LinearGradient(0,0,w,0)`，只在部分右向语义下交换起止色，因此上下方向和四个对角方向不会与记事背景完全一致。

现在每一层水体/波浪的底色都会构造对应的 `ThingBackground.gradient(...)`，再交给 `BackgroundUtil.createLinearGradient(...)` 生成 shader，完整沿用项目统一的 8 向 `ThingBackground.orientation` 映射。也就是说，`L_R`、`R_L`、`T_B`、`B_T` 以及四个对角方向都会与记事渐变方向一致。

竖向明暗覆盖逻辑保留不变：它仍然作为第二遍中性光照叠加，用于提供上亮下暗的体积感，但不再替代或改变记事渐变底色方向。

验证：已运行 `:app:assembleDebug --console=plain --no-configuration-cache`，编译通过。

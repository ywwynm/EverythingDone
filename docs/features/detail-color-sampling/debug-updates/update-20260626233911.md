# 从世界取色图标地球与 Material 滴管细化

## 用户反馈

- 上一版图标已经接近方向，但地球内部仍不像真实地球。
- 地球内部需要更像大洲轮廓，最好有欧亚大陆的感觉。
- 滴管应使用 Android 官方 Material 的滴管图标。

## 本次修改

- 重新绘制 `app/src/main/res/drawable/ic_pick_from_world.xml`。
- 地球内部从经纬线改为块状陆地轮廓，优先表现欧亚大陆和相邻陆地区域。
- 继续保留地球右下角缺口，避免滴管与地球轮廓、陆地块叠压。
- 滴管改用 Google Material Icons 仓库中的 `colorize` 24dp 官方路径，缩放后放入地球右下缺口。

## 验证

- 已运行 `E:\projects\EverythingDone\gradlew.bat :app:assembleDebug --console=plain`，构建通过。
- 已运行 `:app:publishDebugUpdate -PdebugUpdateNotesFile=docs/features/detail-color-sampling/debug-updates/update-20260626233911.md`，发布 debug 更新 `202606261539` 成功。

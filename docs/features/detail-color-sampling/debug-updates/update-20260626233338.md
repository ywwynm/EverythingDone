# 从世界取色图标缺口重设计

## 用户反馈

- 上一版“地球 + 滴管”图标中，地球线条和滴管线条叠在一起，视觉上不清晰。
- 希望继续使用“地球 + 滴管”的方向，但滴管放在地球右下角，地球右下角需要空缺一部分给滴管线条。

## 本次修改

- 重新绘制 `app/src/main/res/drawable/ic_pick_from_world.xml`。
- 地球外圈、经线、纬线都在右下象限提前截断，形成明确缺口。
- 滴管移动到地球右下角的缺口区域和外侧，避免与地球线条叠压。
- 保持现有 `ColorAreaView` tint 逻辑不变，运行时仍跟随当前颜色着色。

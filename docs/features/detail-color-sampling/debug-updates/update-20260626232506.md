# 详情颜色调整入口与从世界取色图标

## 用户需求

- 记事详情界面右上角颜色入口原显示“改变颜色”，需要改为“调整颜色”。
- 打开的颜色调整面板标题原显示“选择颜色”，需要改为“调整颜色”，并完成已有语言资源的国际化同步。
- 面板内“从世界取色”入口的图标语义不够贴合，需要替换成更符合“从世界取色”的图标。

## 本次修改

- 更新 `act_change_background` 与 `act_select_color` 字符串资源：默认英文、简体中文、繁体中文（香港/台湾）、德语、西班牙语、法语、印地语、意大利语、日语、韩语、葡萄牙语、俄语都统一为“调整颜色”语义。
- 修正资源复用边界：`act_select_color` 仍保留“选择颜色”语义供搜索菜单使用，新增 `act_adjust_color` 专门给详情颜色面板和卡片外观颜色页使用；`act_change_background` 继续用于详情页右上角入口并显示“调整颜色”。
- 替换 `app/src/main/res/drawable/ic_pick_from_world.xml`：从相机轮廓改为“地球 + 滴管”的线性图标，继续由 `ColorAreaView` 按当前颜色 tint。
- 记录了详情取色 feature 的偏好与会话文档，并把新文档加入全局轻量索引。

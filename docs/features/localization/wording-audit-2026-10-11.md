## 结论与范围

存在明确错译、产品概念混淆、英语结构残留和生硬表达。上一轮新增模板也出现了 `completed`、中文“笔记”及句内语法遗漏。资源键齐全和格式化通过，不能说明翻译质量已合格。

- 全量解析主应用 13 套语言配置的字符串、数组和复数资源，以 1,597 个简体中文可翻译资源为基准。
- 对全部语言交叉检查核心类型、状态、操作、统计、无障碍描述和近期动态模板；全量搜索英语残留、损坏占位和繁体词表，定向核对设置说明及帮助中的高风险句子。
- 结合代码、布局、菜单中的直接引用判断影响，复读上一轮三机保存的格式化样例。本轮没有重新操作设备。
- 依据为简体中文、`CONTEXT.md`、本功能偏好和术语决定，没有调用外部翻译服务。
- 这是代理的语义审查，不能替代逐句母语审校；未列出的句子不表示已达到母语质量。没有修改应用资源、业务代码或发布版本。

[逐条证据清单](wording-audit-evidence-2026-10-11.json) 收录 **30 组问题或建议，涉及 101 个资源键、333 个不重复的语言条目**。其中包含 16 条旧资源残留和 4 条表达建议，也包含长资源中的局部句子；不能将 333 理解为 333 个已证实正在展示的功能错误。数组和复数条目分别记录，父资源键数另行去重。

## 明确错误及建议

以下“九种外语”指德、西、法、印地、意、日、韩、葡、俄语。

| 编号 | 问题与示例 | 范围和建议 |
|---|---|---|
| W01 | 英语新模板写 `completed %2$s`、`%1$d items completed` | 三个习惯模板、清单计数和部分帮助句子；完成动作、状态统一为 `finish / finished` |
| W05 | 已停用变成 `Discapacitado`、`障害者`、`장애인`、`विकलांग` 等描述残障的词；俄语 `Неполноценный` 表示缺陷、不健全 | 西、印地、日、韩、俄；`disabled` 和自动开始设置数组均需修正 |
| W06–W07 | 置顶变成 `Klebriges Ding`、`cosa pegajosa`、`ベタベタしたもの` 等“黏性的东西” | 九种外语；覆盖置顶操作、卡片描述、快捷方式和空结果提示，不能只改一个键 |
| W08 | 常驻通知的记事变成“进行中的事情” | 九种外语的 `ongoing_thing`；锁屏说明另含 `thing\'s` 等残留。必须与未完成状态、正在做计时分开 |
| W09–W10 | 恢复习惯提醒出现韩语 `이력서`（简历）；各语种混入 `habit\'s`、`hábito\'s`、`習慣\'`；养成按钮出现 `I\'he`、`J\'\'ai`、`私\'` | 暂停和恢复涉及九种外语，养成按钮涉及八种；需重写完整句子，不是只删反斜杠 |
| W11 | “已完成，点击取消完成”被写成“已完成，点击完成” | 西、法、印地、日、葡的 `cd_checklist_finished_item_clickable`；无障碍操作提示方向相反 |
| W12 | 完成次数、完成次数 / 总次数、最长连续完成次数被译成时间或结束时刻 | 九种外语的三个统计标签；如日语 `終了時間 / 合計時間`，对应数值实际是次数 |
| W13 | 习惯养成率变成英语 `Nurturance Rate`、德语护理率、西语育儿率、葡语营养率、俄语照护水平 | 英语及七种外语；应表示养成习惯的比例，与 `develop a habit` 对应 |
| W14 | 目标详情返回按钮中的 Goal 变成德语 `Tor`、西/意/葡语 `Gol` | 此处是个人目标，不是球门、进球；葡语目标空态还有 `gols` |
| W15–W16 | 清单项变成日语 `完成品 / 未完成品`、韩语 `완제품`；返回描述出现“问题是这条笔记”类句式 | 清单制成品错义涉及日、韩，返回描述明显错义涉及韩、俄 |
| W17–W18 | 德语进行中是 `Unterwegs`（在路上）；日语已提醒是 `思い出した`（想起来了），韩语是“使人想起”的原形 | 分别应表达记事状态和通知已发出，不能描述用户的记忆行为 |
| W19–W20 | 打开地图从英文 `Visit` 译成访问；支持开发者在七种语言里成为“支持工程师”一类名词 | 地址操作应明确打开地图；支持入口应使用动词，前者也需修正英文 |
| W21–W22 | 自动保存说明残留 `Thing`、断裂撇号；自动提醒漏掉“先设置时间，再在创建后经过该时间提醒”，英文把 Note 写成 Record | 自动保存涉及八种外语；自动提醒涉及英语及九种外语。重写时保留功能限制 |
| W23 | 印地语统计出现 `__ईडीएनएल__`；西语提醒提示含 `Una cosa__La alarma` | 四条有当前引用的损坏文本，资源编译不会报错 |

建议译法示例：

- 已停用：西语 `Desactivado`、日语 `無効`、韩语 `사용 안 함`、俄语 `Отключено`。
- 置顶：德语 `Anheften`、西语 `Fijar`、法语 `Épingler`、日语 `上部に固定`、韩语 `상단에 고정`；其他语言同样表达固定在顶部。
- 日语已完成清单项的点击描述：`完了済みの項目。タップして未完了に戻します`，明确取消完成。
- 英语清单计数：`%1$d item finished` / `%1$d items finished`；习惯完成说明和分享也用 `finished`。

## 产品术语按概念统一

| 概念 | 应保留的边界 | 当前问题 |
|---|---|---|
| 记事 / Thing | 包括记录、提醒、习惯、目标的总称 | W04：八种外语早期主类型和抽屉名称与较新的文件夹、传输文案不同 |
| 记录 / Note | Thing 的一种类型，不等于所有记事 | W02：简、台、港的空态、新分享和编辑标题使用“笔记 / 筆記”，主类型名却是“记录 / 記錄” |
| 非中文 Note | 同一类型在菜单、分享、帮助中保持可识别的一致名称 | W03：德语 `Hinweis` 对新模板 `Notiz`，法语 `Remarque` 对 `Note`；日语 `注記`、韩语 `참고`、俄语 `Примечание` 也与新页面不同 |
| 完成 / 已完成 | 英语动作和状态使用 `finish / finished` | W01：新动态模板和帮助仍有 `complete / completed`；不是所有含 completion 的词都应替换 |
| 正在进行 / Underway | 尚未完成的记事状态 | 不能译成正在计时、在路上或常驻通知 |
| 正在做 / Doing | 当前正在做的一件事，关联计时 | 停止做事不等于删除、取消记事或标记完成 |
| 常驻通知 / Ongoing | 在通知栏展示记事的属性 | W08：不能按普通英语 ongoing 译成进行中 |
| 养成习惯 | 整个习惯达到养成状态，与完成这一次分开 | 英语已有 `develop a habit`；新模板 `formed this habit` 可归回既有表达 |
| 还原、恢复提醒、取消完成 | 根据当前操作分别判断 | `restore`、`resume`、取消完成不是同一动作，不能机械统一 |

2026-09-28 的 Thing 约定仍是审查依据：德语 Ding、西语 cosa、法语 élément、意语 elemento、葡语 item、俄语 запись、日语 メモ、韩语 항목、印地语 चीज़。原决定注明这些词未经用户或母语者审校，词表不是质量认证。

日语需先处理类型层级：新文案把 Thing 和 Note 都叫作 `メモ`，旧资源又有 `もの / 注記 / 記録`。实施时应为总称和类型选定可区分的表达，再同步帮助及入口。俄语帮助把 Note 称作 `Запись`，而较新的 Thing 总称也是 `запись`，存在类似风险。

不应机械替换的语境：

- `completion rate` 是自然的统计名词，不应因为动词统一为 finish 就强行改成 `finish rate`。
- `Export complete`、下载和编码完成描述的是技术流程。
- 图案锁的 `Done`、`Release finger when done` 不属于完成记事。
- 产品名 `EverythingDone`、品牌呼应，以及目标分享中的 `achieved this goal` 不自动判错。

## 直译和语气问题

这里判断可见表达及中文语义偏差，不能凭文本断定使用了哪种模型或翻译工具。

**W24：英语及德、意、韩、葡、俄目标空态添加了共同度假、晒太阳。** 中文是“恭喜您完成了所有的目标！别累着了，先给自己放个假吧！”，英语却写成 `I think we can have a holiday together. Let\'s go to enjoy sunshine~`。这显得刻意亲密，也偏离原文。可改为 `You've finished all your goals! Take a break—you've earned it.`，保留恭喜和休息的语气。

**W25：印地语帮助有普通产品词的英语残留。** 完成率说明含 `notes formula`、`Habits`、`completion`、`rate`；权限说明也使用整组英文名词。应与本语言菜单名称一致，Android、EverythingDone 等专名除外。

**W29：新俄语动态文案语气像数据说明。** 分享使用 `Продолжительность моих усилий: …; выполнено …`（我的努力持续时间……；已完成……）；月周期逐项重复 `число: 1, число: 11, число: 21`。原文是日常分享及日期说明，建议改为自然完整句或简洁列表，并检查词形。本组是润色建议，不当作事实错译。

中文已有的鼓励语气应保留，例如“艰难却美好的经历”“很高兴看到一个更好的您”。不能为了去除所谓“AI 味”删掉原文已有含义。

## XML 以外的动态语法

**W27：西、意、葡语的时间介词固定为复数。**

| 语言 | 当前模板在 1:00 的组合 | 应有形式 |
|---|---|---|
| 西语 | `a las 1:00` | `a la 1:00` |
| 意语 | `alle 1:00` | `all’1:00` |
| 葡语 | `às 1:00` | `à 1:00` |

四种周期模板均受影响。`LocalizedText.recurrence()` 先拼时间列表，再套固定介词；每天同时有 `1:00` 和 `17:08` 时，应按每个时刻生成合适的短语，再组合列表，或采用经审校的完整句式。不能简单将所有复数介词改为单数。保留用户要求的 24 小时制。

**W28：德语独立数量短语不自动获得句内变格。** `duration()` 的 `2 Tage` 被放入 `Überfällig seit: …`、`Sie haben dieses Ziel in … erreicht`，此句法需要 `2 Tagen`。优先改写成不要求该格变化的自然表达；若保留原句，则需要按上下文格式化。

这两组根据资源和调用构造边界场景，尚未在本轮设备上重新执行。上一轮样例主要是 `6:30`、`17:08` 和独立时长，通过的 4,403 项检查没有证明句内语法正确。

## 全面恢复中文原文和各语言列表标点

用户指出此前只恢复数量文案仍不充分，要求检查本次全部中文修改：中文原文是翻译基准，除明确统一的产品术语外，不得擅自润色。英文原来使用标点的列举不能改成 and；所有语言的首页、文件夹卡片、小组件、附件计数，以及文件夹操作说明，都保留标点连接。

本版对照本地化改造前版本，检查全部 4,338 个既有中文资源。发现的 74 处变化中，65 处恢复原文，保留 3 处“记录／記錄”术语统一，以及此前确认的 6 处繁体文件夹操作参数和含义补齐。新增的必要翻译继续保留。

同时逐项检查动态代码，恢复中文的日期和时段、周期描述、延时和频率单位、目标状态、时长和百分号空格、习惯及目标庆祝文字、分享正文和“分享该……”标题、“最后更新于”“习惯养成于”、统计说明、导出目录及 zip 文件提示。中文延时页恢复原单位表达，去掉此前新增的重复说明。外语单复数和语法修复继续有效，保持 24 小时制和随应用语言调整的日期输入顺序。

英文周期列表、习惯分享及庆祝文案恢复逗号。13 种语言的计数和操作范围使用各场景既有的逗号、顿号或中点，不再使用 and 及对应连词。

资源完整性、中文固定基线与术语检查已通过。最终包将在此前授权的 OPPO、三星、魅族三台设备核验：比较旧中文格式化实现，检查全部语言的计数标点，并确认界面、数据库和语言设置。完整记录见 docs/features/localization/chinese-original-and-punctuation-2026-10-11.md。本版未创建 Git 提交。

## 2026-10-11：恢复中文首页与附件数量原有格式

用户指出首页“X个文件夹，Y件记事”被改成“X个文件夹和Y件记事”，并要求保留中文内容。检查确认是本地化改造把 ICU 列表连接方式套用于中文；附件计数同时误改了空格、视频量词和逗号。

`LocalizedText.folderCount` 在中文下重新使用原有计数资源，覆盖首页、文件夹卡片与小组件；`AttachmentHelper` 恢复原有逗号加空格，三套中文的附件复数资源恢复“2 张图片, 1 个视频”“2 段音频”等原样；`ThingsActivity` 的文件夹操作范围恢复顿号。外语复数及语法修复保留，24 小时制和日期顺序策略不变。

增加中文原样回归断言，并在原 OPPO、三星、魅族各做一轮合并验证。详见 `docs/features/localization/chinese-count-format-restoration-2026-10-11.md`。未创建 Git 提交。

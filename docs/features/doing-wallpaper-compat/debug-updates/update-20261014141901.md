## 修复选图成功却误报网络文件

用户在华为卓易通中选择本地图片时，看到“无法添加网络文件”，但随后能进入裁切并正常显示图片，因此询问是否与 HEIC 后缀有关。

排查确认 `SettingsActivity.onActivityResult()` 在调用 `super` 分发新式选图回调后，还继续执行旧式通用路径校验。对不提供直接文件路径、但可以通过授权 URI 读取的图片，新回调成功导入，旧逻辑却显示网络文件错误。这个分支发生在后缀检查之前。

修复前使用普通 PNG，经真实图片菜单和 ActivityResult 分发，在三星 `R5CW20BLNKL` 复现了相同现象，证明该误报不依赖 HEIC。修复仅让剩余旧式路径校验接收铃声选择请求，保留新回调及已存在的抽屉图片、备份、记事导入处理。

此前回归直接调用 `onImagePicked()`，遗漏了结果分发层。本轮已改为从真实菜单启动选择器，由测试返回本地 PNG URI，并记录是否出现错误提示。修复前回归失败，修复后同一用例及后续裁切保存、旋转、取消等检查全部通过，本地 debug 构建通过。设备测试恢复原配置，没有修改真实记事。

本次未在卓易通实机复测用户的原始 HEIC 文件，不新增权限、格式转换或平台专用逻辑。按默认流程发布阿里云 debug，未创建 Git 提交。

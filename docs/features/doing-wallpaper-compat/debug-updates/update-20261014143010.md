## 手机横屏将操作按钮移至右侧

用户反馈手机横屏时，中间记事卡片可占据的区域过矮，要求将三个按钮移到界面右侧竖排，为卡片腾出高度；平板保持原布局。

`activity_doing.xml` 将原有按钮组调整为内容区域的同级视图，`DoingActivity` 按实际窗口方向和应用现有 `sw600dp` 平板判定切换排列。只有手机横屏使用右侧竖排，计时和卡片在左侧剩余区域居中；竖屏和平板使用底部横排。右侧按钮避开系统栏与屏幕挖孔，卡片下边界改为窗口安全底边，不再被按钮上沿限制。

调整布局时复用原有三个按钮、计时控件和粒子场景，未重建计时页面，也未修改粒子运动或数字变形实现。横竖屏转换后重新计算卡片宽度及高度上限。

本地 `:app:assembleDebug` 通过，三台授权设备各完成一轮合并回归：三星 `R5CW20BLNKL` 横屏长卡片可用高度增加 89.1dp，魅族 `192.168.100.67:40807` 增加 89.4dp；平板 `9018f404` 保持底部横排。三台均通过按钮完整可见与无重叠检查、横屏真实触摸加五分钟、竖→横→竖计时持续及滑动粒子显示／回拉恢复，截图已复核。测试采用虚构记事，恢复原背景及系统方向设置。

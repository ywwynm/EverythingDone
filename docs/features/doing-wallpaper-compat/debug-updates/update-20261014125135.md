## 裁切横竖屏选项卡改为应用现有样式

用户反馈初版选项卡的形态和外观不符合应用风格，要求参考改变记事颜色面板中的纯色／渐变切换、提醒时间对话框和计时数字风格对话框。

对照这些控件后，`DoingBackgroundSettingsController` 将 Material 默认选项卡改为 44dp 高、15sp 的等宽文字选项。选中项加粗并使用完整强调色渐变，未选中项使用提示色，去掉下划线；点击反馈复用现有 `GradientRippleDrawable` 胶囊形波纹。

横竖屏独立裁切、切换时保留未确认取景和确认／取消行为保持原有逻辑。本次修改仅涉及裁切对话框的选项卡及对应 debug 回归探针，没有修改正在做事页面的粒子动画或计时文本动画实现。

本地 `:app:assembleDebug` 通过。三星 `R5CW20BLNKL` 与平板 `9018f404` 的设置专项回归通过，覆盖 72dp 设置行、默认菜单、图片导入、两套固定比例与独立保存、调整项显隐、对话框旋转和取消保留原配置；截图复核手机横竖屏及平板外观。测试结束后恢复背景和系统方向设置。本次没有重复运行上一版已完成的三设备粒子及计时字形专项检查。

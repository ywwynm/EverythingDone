## 修复旧版 Android 打开正在做事界面时崩溃

用户提供华为 `PCE-W30` 平板的崩溃日志，系统报告 Android 12／API 31。异常发生于 `DoingActivity.initBackground()` 调用 `setWallpaperTouchEventsEnabled(false)`：该系统方法从 API 34 才提供，原代码却从 API 30 即调用，导致旧系统抛出 `NoSuchMethodError`。Git 历史确认该问题早于本次自选背景功能。

按用户要求，将版本判断改为 `Build.VERSION_CODES.UPSIDE_DOWN_CAKE`（API 34），旧系统直接跳过该项壁纸触摸转发设置。应用代码仅修改这一处条件。

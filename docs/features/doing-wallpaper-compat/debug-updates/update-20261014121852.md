## 正在做事界面自选背景与横竖屏裁切

用户最初反馈鸿蒙卓易通中的 DoingActivity 背景全黑。核对源码与官方资料后，确认当前采用系统壁纸窗口，没有找到经验证可用于普通 APK 自动读取鸿蒙宿主壁纸的公开方案。用户随后选择自选图片方案，并明确要求允许横竖屏切换、不影响滑动卡片粒子与计时文字动画。

设置的“正在做事”分组新增“正在做事界面背景”，采用与“抽屉头部图片”相同的 72dp 两行形式，下行显示默认背景或图片路径。点击提供“默认背景”“选择图片”，有可读图片时额外显示“调整裁切”。

裁切复用现有对话框和编辑控件，新增竖屏／横屏选项卡，按屏幕比例固定裁切框，分别保存取景中心与缩放。取消调整保留原裁切；新图成功导入后立即生效。图片导入与预览解码在后台进行，不申请新增存储权限。新增文案覆盖现有语言资源。

DoingActivity 现在遵循系统横竖屏设置，旋转时保留计时服务、计时控件和粒子场景，只重算背景及卡片布局。自选图片位于原深色蒙版下方，沿用既有整页粒子呈现。修复旋回竖屏后卡片高度仍受横屏限制，以及三星系统栏回调把横屏居中间距恢复成竖屏值的问题。未修改粒子运动、着色器或计时数字变形算法。

验证：16 项相关单测及 debug 构建通过；三星 R5CW20BLNKL、平板 9018f404、魅族 192.168.100.67:40807 的设置、双方向裁切、旋转居中、倒计时连续和滑动粒子检查通过，每台 792 组计时字形逐像素对照通过。测试使用虚构记事，恢复背景及方向设置，没有写入真实记事。

默认背景仍依赖系统／卓易通的壁纸窗口支持。本次自选背景验证在三台原生 Android 设备上完成，尚无卓易通实机验收结论。

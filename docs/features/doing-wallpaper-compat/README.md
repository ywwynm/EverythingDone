# 正在做事界面背景与壁纸兼容性

研究 DoingActivity 的桌面壁纸兼容性，并提供自选图片及横竖屏独立裁切。

- 用户现象（2026-10-14）：普通 Android 环境可显示当前桌面背景，鸿蒙卓易通内显示为黑色。
- 当前阶段：已实现自选背景、固定屏幕比例的双方向裁切，以及遵循系统设置的横竖屏切换。默认背景继续使用系统壁纸窗口；未宣称解决卓易通宿主壁纸的自动获取。
- 实施及验证：[2026-10-14 实现记录](implementation-2026-10-14.md)。
- 初版发布后按用户反馈修正横竖屏选项卡：采用与颜色面板、计时数字风格对话框一致的文字选中态及胶囊形波纹，去掉下划线。
- 后续移除裁切提示行，统一取消／确定按钮的胶囊形波纹，路径文本与抽屉头图一样允许换行。
- 修复新式选图结果被旧式逻辑重复校验造成的“无法添加网络文件”误报；普通 PNG 可复现，修复前失败、修复后通过，不依赖 HEIC 后缀。
- 手机横屏时三个操作按钮右侧竖排，为长卡片增加约 89dp 可用高度；计时、记事卡片和滑动提示相对整页水平居中。平板及竖屏保持底部横排，三机居中、旋转、计时与粒子回归通过。
- 最新已发布阿里云 debug `202610140651`，并安装到三台授权设备；远端元数据、发布说明和下载 APK 哈希核验一致。

## 2026-10-10 修复详情页单图片、视频横屏时的默认比例

- 用户反馈：只有一个图片或视频附件、尚未确认外观设置时，缩略图可能显得过宽；打开外观设置直接确认后才恢复默认比例。本轮全面检查手机、平板、横竖屏以及不同形状的源图片和视频。
- 根因是未设置外观的旧横屏尺寸分支使用“高度＝页宽÷3”，生成 `3:1`；外观编辑器及已确认外观使用 `4:3`。平板真实复现为 `2520×840` → `2520×1890`，与图片本身的比例无关；手机横屏同样受影响。
- `AttachmentHelper.calculateImageSize()` 现在优先处理单媒体，从 `DetailAttachmentMediaAppearance` 读取与编辑器相同的默认比例，统一使用 `4:3`。不需要进入外观设置再确认；已保存的自定义比例、裁剪，以及多附件网格继续按原有规则显示，默认展示不自动写入外观数据。
- 新增 debug 专用 `DetailMediaGeometryProbe` 回归入口和运行脚本，验证实际 Adapter 与真实详情界面，而非只检查模型常量。
- OPD2515、SM-S9180、MEIZU 20 Inf 三台授权设备各验证横竖屏下横图、竖图、方图、超宽图和视频，共 30 个真实界面场景全部通过。确认前后尺寸一致；已保存比例、附件增减及重排的配置矩阵检查通过。测试临时记事已清理，系统旋转状态已恢复。
- Debug 构建通过；外观来源映射、附件动图生命周期相关 16 项单测通过；差异格式检查通过。未创建 Git 提交。

## 同一附件上的 GIF 等标识与图标按钮统一颜色（2026-10-15）

根据用户反馈，详情页图片/视频附件上的 GIF、HDR、动态照片、空间照片、视频播放标识及外观、删除按钮，现在以同一附件为单位统一选择半透明黑色或白色，避免各元素分别选色显得杂乱。不同附件仍根据各自内容判断。

综合各元素下方的静态封面内容，每个元素等权，保留现有透明度和 HDR/GIF 镂空样式。文字与普通图形仍使用各自的参考对比度；极端明暗分区下，部分元素的局部对比度可能降低。

`DetailMediaOverlayColors` 改为缓存和应用附件共同颜色，通过 `MediaOverlayContrast.chooseGroups()` 汇总判断；异步出现的标识先继承当前颜色，再与其他元素一起更新。继续复用静态小图和后台评分，裁剪、比例、封面选帧变化后刷新，播放帧变化不触发重新取样。

37 项 JVM 回归通过，包括顶部按钮共同配色回归。在 `3B1629006YC00000`、`R5CW20BLNKL` 合并验证横竖屏，共 140 项检查通过，覆盖新增标识、明暗分区、裁剪及撤销/重做、多附件复用和重排、缓存、选帧及真实播放稳定性。8 条已有记事保持不变，32 条临时记事已清理，系统旋转设置已恢复。

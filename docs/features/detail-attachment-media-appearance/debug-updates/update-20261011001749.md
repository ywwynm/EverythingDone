## 修复附件外观首次比例拖动，并支持内容滚动

用户反馈第一张图片/视频附件的外观弹窗首次打开后，显示比例滑条无法拖动，关闭重开才正常。排查确认：异步预览加载前，递归保存控件状态的同时禁用父控件，父级 RatioSlider 会同步禁用内部 SeekBar，导致错误保存了子控件的临时禁用状态。DetailActivity 现先完整保存原状态，再统一禁用，加载完成后正确恢复首次拖动。

三机扩展验证另发现横屏部分多附件图片和视频弹窗超过屏幕高度，滑条和确认按钮被截掉。用户要求一并修复，参考设置中“更改应用语言”的弹窗：标题和取消/确认固定，宽度、预览、视频选帧和比例位于中间滚动区域；顶部/底部的分割线分别提示该方向还有内容，内容完整可见时都隐藏。切换“正常/宽”导致比例行显隐时，滚动边界和分割线同步更新。

中间区域根据窗口剩余高度收缩，保留原有预览尺寸规则与媒体裁剪手势；独立裁剪滚动内容，防止预览或滑条绘制到标题与按钮区域。加载中仍可取消，确认需等待预览就绪。

验证：OPD2515 平板、SM-S9180 与 MEIZU 20 Inf 手机的横竖屏，图片/视频、单媒体/多媒体首项、首次加载/缓存重开，共 48 次比例真实拖动、48 次裁剪手势通过；18 个溢出窗口的真实纵向滚动、顶部/中间/底部指示线、固定区可见性及比例行显隐检查通过。取消不保存外观、确认保留所选比例。19 项相关单测及构建通过，实机截图复核边界裁剪；测试记事已清理，系统旋转已恢复。

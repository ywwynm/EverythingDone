# 同一附件上的标识与图标统一配色

状态：实现与本轮回归完成，debug `202610150857` 已发布、校验并安装到两台指定设备，用户已确认提交本轮改动。

## 范围与方案

用户要求解决同一附件内各标识和按钮分别为黑白两色带来的杂乱。以单个附件为单位，将 GIF、HDR、动态照片、空间照片、视频播放标识和外观/删除按钮的局部样点等权汇总，统一选择一种半透明黑白颜色。

- 保留图形自身的透明度、HDR/GIF 镂空以及现有记事色触摸波纹。
- 文字和图形仍使用各自的参考对比度；元素大小和采样数量不改变该元素的总体权重。
- 静态封面、裁剪、比例、视频选帧与可见元素改变时更新，播放帧变化不重新计算。
- 新出现的标识先继承附件当前配色，后台结果同次应用；跨附件各自判断。
- 延续有界静态小图、图形点集与颜色缓存以及后台评分，保持原有性能约束。

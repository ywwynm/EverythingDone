## 渐变 ripple 反馈微调：移动到文件夹 dialog 根目录上色

### 主要改动
- 移动到文件夹 dialog 选中最上方「全部 / 根目录」时，标题、确定按钮文字颜色与确定按钮触摸 ripple 都改为 accent+accent2 渐变。
- 该 dialog 不再理会外部传入的记事 / 文件夹颜色，完全按自身逻辑上色：选中文件夹 → 该文件夹色；选中根目录 → accent 渐变。`setAccentBackground` 保留为兼容空实现；列表 overscroll 光晕色也改为 accent。

### 验证重点
1. 移动到文件夹 dialog 选中根目录「全部」：标题、确定文字、确定 ripple 是否均为 accent 渐变。
2. 选中具体文件夹：仍为该文件夹色（实时切换）。

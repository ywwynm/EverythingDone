## 渐变 ripple 反馈微调（第三批，3 条）

### 主要改动
1. 设置界面右侧 checkbox 的 accent 触摸 ripple 偏小，已增大：圆形半径固定为 20dp、圆心向控件中心收敛、贴近系统原生尺寸（波纹可画到 checkbox 自身范围之外）。
2. 记事列表 widget 配置界面：标题、确定按钮（文字 + 触摸 ripple）、透明度滑条、「顶部栏同时透明」与「采用简单的记事视图」两个 checkbox（勾选填充色 + checkbox 自身 ripple）及其所在 item 的触摸 ripple，全部随文件夹列表区域所选的文件夹（或根目录 accent 渐变）实时着色。
3. Drawer、移动到文件夹 dialog、记事列表 widget 配置三处的文件夹列表区域配色，统一按 Drawer：
   - 选中行：实色填充（文件夹纯色 / 渐变）+ 按明暗自适应的波纹；文件夹 icon / 名称 / 展开箭头改用满不透明的对比色。
   - 未选中行：文件夹自身颜色的触摸波纹；名称 / 「全部」icon / 展开箭头统一为抽屉项前景色（比之前略深）。
   - widget 选中行此前是文件夹色的半透明版 + 渐变文字，现与 Drawer 一致（实色 + 对比色）。

### 验证重点
1. 设置界面各 checkbox 按下：accent 渐变圆形 ripple 是否比之前略大、居中。
2. widget 配置：在文件夹列表里切换不同文件夹 / 根目录，标题、确定按钮文字与其 ripple、滑条、两个 checkbox（含勾选色与按下 ripple）、两个 checkbox 整行按下 ripple 是否都实时变为该文件夹色（根目录为 accent 渐变）。
3. 对比 Drawer、移动到文件夹 dialog、widget 配置三处文件夹列表：选中 / 未选中态的文件夹 icon 色、文字色、行按下 ripple 色、展开按钮色与其 ripple 色是否观感一致。

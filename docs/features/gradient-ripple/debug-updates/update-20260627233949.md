# 渐变 ripple 反馈修复（第一批）

## 主要改动
- Drawer：文件夹 item 被选中时，右侧展开/收缩按钮的 ripple 改为按文件夹明暗自适应；未选中仍为文件夹颜色。
- 首页顶栏图标：去掉系统自带的那层 ripple，只保留我们按文件夹色 / 自适应的那层（之前是两层叠加）。
- 调整外观 panel：调整颜色 icon、下方“确定”按钮、“封面图片”右侧来源按钮、“调整颜色”左侧返回按钮，触摸 ripple 改为记事/文件夹色；调整颜色 panel 里随机、取色按钮的 ripple 改为当前编辑颜色。
- 设置界面：item 右侧 checkbox 的圆形 ripple 改为 accent+accent2 渐变。
- 选中态用的“偏白”自适应波纹整体调深一些（更明显，alpha 16% → 25%）。

## 验证重点
1. Drawer 选中某文件夹后，其展开按钮 ripple 是否随该文件夹明暗自适应（亮→偏黑、暗→偏白）。
2. 首页顶栏各图标按下是否只剩一层 ripple（不再与系统层叠加）。
3. 外观 / 颜色 panel：调整颜色 icon、确定、封面来源、颜色页返回、随机、取色按钮的 ripple 颜色。
4. 设置界面 checkbox 圆形 ripple 是否为 accent 渐变。
5. 各处选中态“偏白”波纹是否比上一版更明显、深浅是否合适。

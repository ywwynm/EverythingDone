## 渐变 ripple 内部重构：文件夹列表配色集中

### 主要改动
- 新增 `ColorConstants.FolderList`，把三处文件夹列表区域（Drawer、移动到文件夹 dialog、记事列表 widget 配置）相对固定的配色集中到一处（未选中前景、不可选目标色、选中对比前景、选中展开箭头满不透明色、选中自适应波纹色），三处统一引用，以后改一处即可同步。
- 纯重构，行为不变；本版另含此前手动微调的 ripple 数值。

### 验证重点
1. 对比 Drawer、移动到文件夹 dialog、记事列表 widget 配置三处的文件夹列表：选中 / 未选中态的图标色、文字色、行按下 ripple 色、展开按钮色与其 ripple 色是否仍一致、无回退。
2. ripple 整体手感（含 checkbox）按手动调整后的数值复查。

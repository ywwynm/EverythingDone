# 渐变 ripple 动画优化

## 主要改动
- 优化未选中态渐变水波纹的手感：按下瞬间锁定水波纹圆心，手指再滑动时波纹不再跟着滑。
- 半径扩散一旦开始就一定铺满整个控件；松手或滑动取消时只做淡出、不再半路打断，避免「波纹还没填满就消失」。
- 整体加快：水波纹颜色快速浮现、扩散更迅速，更接近系统原生 ripple 的响应速度。

## 验证重点
1. 在未选中的状态段 / 类型图标 / 重复页圆按钮 / 月末药丸上按下后往旁边滑动：波纹圆心应保持在按下处不跟手；即便滑动被列表/抽屉滚动取消，波纹也应铺满后淡出，而不是半路消失。
2. 快速点一下：应能看到颜色明显浮现并铺开。
3. 对比系统其他按钮 ripple 的快慢，确认速度是否接近。
4. 波纹浓度（PEAK_ALPHA = 0.36）是否仍合适。

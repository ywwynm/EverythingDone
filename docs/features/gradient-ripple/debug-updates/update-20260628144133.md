## 显眼提醒界面：类型标题渐变 + 按钮记事色 ripple

### 主要改动
- NoticeableNotificationActivity（显眼提醒 / 习惯提醒弹窗）顶部「记事类型」文字改为按记事颜色上色：渐变记事用渐变（与左侧类型图标一致），纯色记事用其颜色；后面「• 时间」仍为灰色。
- 右上角关闭按钮、记事卡片下方的 action 按钮（完成 / 开始做事 / 延迟提醒等）触摸 ripple 由中性灰改为记事颜色（圆形；渐变记事则渐变波纹）。

### 验证重点
1. 触发一个提醒 / 习惯的显眼通知：标题类型文字颜色是否跟随记事颜色（渐变记事呈渐变、与类型图标一致），「• 时间」是否仍为灰色。
2. 按下关闭按钮、各 action 按钮：触摸波纹是否为记事颜色（圆形铺满），渐变记事是否为渐变波纹。

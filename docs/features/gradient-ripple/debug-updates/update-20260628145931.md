## 记事列表 widget 配置：类型 icon 适配亮/暗色模式

### 主要改动
- widget 配置界面里「记事类型选择」的 5 个 icon，未选中态原本恒为黑色（暗色模式下几乎不可见），改为主题自适应颜色（亮色偏黑、暗色偏白）并满不透明，与 Drawer 里的类型 icon 适配一致。选中态外观不变。

### 验证重点
1. 暗色模式下打开记事列表 widget 配置：5 个类型 icon（全部 / 记录 / 提醒 / 习惯 / 目标）未选中时是否清晰可见（偏白），不再是黑乎乎看不清。
2. 亮色模式下未选中 icon 仍为偏黑、清晰。
3. 选中某个类型时，该 icon 仍为记事范围颜色（与之前一致）。

## 根目录展开/收缩按钮：Drawer + 记事列表 widget 配置

### 主要改动
- Drawer（抽屉）与记事列表 widget 配置界面的「全部 / 根目录」行，右侧补上展开/收缩按钮，行为与移动到文件夹 dialog 一致：收起即隐藏整棵文件夹树，展开即铺开顶层文件夹（带旋转 + 行展开/收起动画）。
- Drawer 里在根目录有顶层文件夹时才显示该按钮；导航进入某个文件夹会自动展开根目录以保证它可见；根目录收起时抽屉选中态回退到「全部」（与折叠父文件夹时高亮最近可见祖先一致）。

### 验证重点
1. Drawer：根目录「全部 / 全部内容」右侧出现展开/收缩按钮；点击可整体收起 / 展开所有顶层文件夹，动画顺畅；收起后再进入某文件夹（如点首页文件夹缩略图）能自动展开并定位。
2. 记事列表 widget 配置：根目录行右侧同样有展开/收缩按钮，点击收起 / 展开顶层文件夹；列表高度、滚动分隔线随之更新。
3. 三处（Drawer、移动到文件夹 dialog、widget 配置）根目录展开/收缩按钮的外观与手感是否一致。

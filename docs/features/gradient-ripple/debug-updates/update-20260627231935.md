# 渐变 ripple 扩展（第一批：首页生态 + 设置）

## 主要改动
- Drawer：状态/类型筛选选中态触摸 ripple 改为按文件夹明暗自适应（亮→偏黑、暗→偏白，根目录 / accent 渐变→偏白）；文件夹及设置/帮助/关于等 item 未选中→文件夹色（根目录 accent 渐变）波纹，选中→整行铺该颜色 + 自适应波纹 + 文字/图标转对比色；文件夹展开/收缩按钮→文件夹色波纹。
- 首页顶栏：汉堡 / overflow / 搜索返回 / 选色等图标按钮触摸 ripple 改为文件夹色（根目录 accent 渐变）；选择模式下按文件夹明暗自适应。（overflow 下拉菜单项仍为系统默认）
- 首页与单记事 widget 配置页：大文件夹（缩略图卡片）触摸 ripple 改为该文件夹颜色。
- 调整外观 panel：卡片宽度、文件夹大小、图片/视频位置胶囊，未选中→记事/文件夹色波纹、选中→自适应；调整颜色 panel 的纯色/渐变切换按钮→记事/文件夹色波纹。
- 设置界面：各设置项触摸 ripple 改为 accent+accent2 渐变；点击抽屉头部图片弹出的对话框各项也改为 accent 渐变。

## 验证重点
1. Drawer：根目录与进入彩色文件夹后，分别看状态/类型选中态、各 item（含设置/帮助/关于）未选中与选中、文件夹展开按钮的 ripple 颜色与对比度。**注意选中 item 现在整行会铺上该文件夹颜色**，看是否符合预期。
2. 首页顶栏图标按下 ripple 颜色；进入选择模式后图标 ripple 是否随文件夹明暗自适应。
3. 大文件夹卡片按下 ripple 是否为该文件夹颜色（其它外观模式文件夹不变）。
4. 外观 / 颜色 panel 各胶囊与纯色/渐变切换按钮的 ripple。
5. 设置界面各项、抽屉头部图片对话框各项 ripple 是否为 accent 渐变。
6. 整体浓度、深色 / 夜间模式下是否合适。

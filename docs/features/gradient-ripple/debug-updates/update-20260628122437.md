## 渐变 ripple 反馈修复（第六批，4 条）

### 主要改动
1. 帮助界面顶栏右上角「反馈」菜单图标改为偏白（顶栏背景为 accent 渐变）；关于界面顶栏标题文字改为 accent+accent2 渐变（与图标统一；关于顶栏是浅色 surface，故用渐变而非偏白）。
2. 设置 / 帮助界面顶栏图标按钮的触摸 ripple 改为偏白（accent 自适应）。
3. 移动到文件夹 dialog：
   - 选中某个文件夹后，标题、确定按钮的文字颜色实时变为该文件夹的颜色（纯色 / 渐变），确定按钮触摸 ripple 颜色也随之更新。
   - 选中行的背景由「文件夹颜色的半透明版」改为「文件夹实色」（与 Drawer 一致）；选中行的文件夹 icon、名称、右侧展开/收缩按钮改用对比色（onColor），ripple 按其明暗自适应。
4. 抽屉头部图片的触摸 ripple 改为 accent+accent2 渐变。

（内部：重新提取 BackgroundUtil.applyToolbarIconRipples 公共方法，供设置/帮助/关于复用。）

### 验证重点
1. 帮助顶栏反馈图标是否偏白；关于顶栏标题是否 accent 渐变。
2. 设置/帮助顶栏图标按下 ripple 是否偏白。
3. 移动到文件夹：选不同文件夹时，标题/确定文字与确定 ripple 是否实时变成该文件夹色；选中行背景是否为实色、icon/名称/展开箭头是否清晰对比色（与 Drawer 选中项观感一致）。
4. 抽屉头部图片按下是否 accent 渐变 ripple。

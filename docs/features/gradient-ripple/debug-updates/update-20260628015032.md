## 渐变 ripple 反馈修复（第四批，7 条）

### 主要改动
1. 记事详情顶栏图标（返回 + 各菜单项 + overflow）触摸 ripple 改为按记事颜色明暗自适应（浅底偏黑、深底偏白），居中、固定半径，去掉系统自带那层。
2. 音频附件卡片上的播放/暂停、删除、信息三按钮 ripple 改为铺满按钮的矩形（不再是圆形）。
3. 调整图片外观 dialog 的「确定」按钮：文字与触摸 ripple 都改为记事颜色（支持纯色 / 渐变）。
4. 调整视频外观 dialog：播放/暂停、停止按钮 ripple 改为记事颜色（矩形）；「确定」按钮文字与 ripple 同改为记事颜色（纯色 / 渐变）。首页调整记事卡片 panel 里裁切封面视频的 dialog，播放/暂停、停止按钮同样改为记事/封面颜色 ripple。
5. 移动到文件夹 dialog：选中行右侧展开/收缩图标不再发虚——源 PNG ic_dropdown 仅 ~54% alpha，改用 opaqueTintDrawable 重映射 alpha 为满不透明（SRC_IN/ATOP 提不上去）。
6. 搜索取色「全部颜色」item 未选中时的 accent 渐变 ripple（之前因点击瞬间被销毁而看不到，见第 7 条）。
7. 【核心】GradientRippleDrawable 触摸动画完整播放：之前快速点击时淡入还没到满就被淡出截断、加上框架的 jumpToCurrentState 会瞬间复位，导致「一点就消失」。现在淡入未结束就松手会先记下、等淡入铺满再淡出（绝不半路截断）；jumpToCurrentState 不再打断正在进行的淡出；列表重绑（notifyDataSetChanged）时复用同一波纹实例、不丢动画。

### 验证重点
1. 详情顶栏：浅色记事用偏黑波纹、深色记事用偏白波纹，居中。
2. 音频三按钮：矩形波纹铺满按钮。
3. 图片 / 视频外观 dialog：确定按钮文字与波纹是记事色（渐变记事应为渐变）；视频的播放/暂停、停止有记事色波纹；首页封面视频裁切 dialog 同。
4. 移动到文件夹：选中行展开箭头是否够实。
5. 搜索「全部颜色」未选中按下是否有 accent 渐变波纹。
6. 全局：随便点哪儿，波纹都应「铺满 + 淡出」完整播放完，而不是一点就没。

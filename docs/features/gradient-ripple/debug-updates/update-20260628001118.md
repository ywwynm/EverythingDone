## 渐变 ripple 反馈修复（第三批）

### 主要改动
- 顶栏图标 ripple 居中：圆心由「触摸点」改为「控件中心」（GradientRippleDrawable 新增 centered 模式），点到图标边缘也不再偏置；半径由 20dp 提到 22dp，更贴合 action item 的可点区域。普通模式与选择模式统一处理。
- 选择模式顶栏的自适应波纹改用 GradientRippleDrawable（居中、固定半径，透明度沿用 adaptiveRippleColor 自带值），与普通模式同款手感。
- Drawer 选中文件夹的展开/收缩图标真正变为满不透明：源 PNG（ic_dropdown）本身只有约 54% alpha，setColorFilter 的 SRC_ATOP 会保留这层透明度提不上去，改用 DisplayUtil.opaqueTintDrawable 把 alpha 重映射为满不透明的对比色；未选中仍沿用源图自带的淡化。

### 验证重点
1. 首页顶栏（普通 / 选择 / 搜索三种模式）各图标按下：波纹是否居中于图标、大小是否与可点区域更贴合、导航按钮与菜单项是否一致。
2. Drawer 选中某个有子文件夹的文件夹：右侧展开箭头是否变为满不透明的清晰对比色（白底深色 / 深底白色），不再发虚；未选中文件夹箭头仍带淡化。

## 渐变 ripple 反馈修复（第五批，8 条）

### 主要改动
1. 首页调整记事外观 panel：「封面图片」来源 popup 里每个选项的触摸 ripple 改为当前记事/封面颜色。
2. 首页外观 panel：左下角「裁切封面」按钮触摸 ripple 改为记事色（胶囊）；裁切封面图片 dialog 的确定按钮 ripple 改为记事色；裁切封面视频 dialog 的播放/暂停、停止按钮 ripple 改回圆形（记事色），确定按钮 ripple 记事色。
3. 记事详情「调整图片/视频外观」dialog：取消/确定按钮的内边距、间距、确定按钮到边缘距离改为与其它 dialog 一致；确定按钮 ripple 由矩形改为胶囊（与其它 dialog 一致）；视频的播放/暂停、停止按钮 ripple 改为圆形。（顺带：所有 dialog 的「确定」类按钮 ripple 统一为胶囊形。）
4. 记事详情分享 dialog：「文本与图片 / 长截图」两个选项的图标本身带透明度，改用 opaque 着色（不再用 SRC_IN 保留半透明），图标变实。
5. 关于界面：顶栏导航/菜单/overflow 图标用 accent+accent2 渐变着色（opaque，源 PNG 带透明度也不用 SRC_IN）+ accent 渐变触摸 ripple；版本文本也改为 accent 渐变（标题等原本已是渐变）。
6. 首页根目录顶栏图标：亮色模式也改为 accent+accent2 渐变着色（此前仅暗色模式是渐变、亮色是深灰）。
7. 设置 / 帮助界面顶栏：背景是 accent+accent2 渐变，标题文字与返回图标由偏黑改为偏白。
8. 首页创建记事 FAB、统计界面分享 FAB、关于界面支持开发者 FAB、记事详情开始做圆形按钮：背景是 accent+accent2（按深色处理），图标由偏黑改为偏白。

### 验证重点
1. 外观 panel 封面来源 popup 选项、裁切按钮、裁切图片/视频 dialog（确定 + 视频播放/停止圆形）。
2. 详情图片/视频外观 dialog：取消/确定的间距与边距是否与普通 dialog 一致；确定 ripple 是否胶囊形。
3. 分享 dialog 两个选项图标是否变实（不发虚）。
4. 关于界面顶栏图标/文本是否 accent 渐变、按下是否 accent 渐变 ripple。
5. 首页根目录亮色模式顶栏图标是否 accent 渐变。
6. 设置/帮助顶栏文字、返回图标是否偏白。
7. 四个 FAB / 圆形按钮图标是否偏白。

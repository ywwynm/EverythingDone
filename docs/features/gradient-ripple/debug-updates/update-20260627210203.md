# 渐变 ripple 触摸反馈（未选中态）

## 主要改动
- 抽屉里「切换记事状态」的分段控件、「选择记事类型」的 5 个图标，在未选中状态下按下时，水波纹改为按当前范围着色的渐变：在「全部记事」根范围用 accent→accent2 渐变，进入文件夹后用文件夹自身的颜色（纯色或渐变）。
- 记事详情页设置提醒时间的「重复」页，每星期 / 每个月 / 每年下的圆形按钮，以及「月末」药丸按钮，在未选中状态下按下时，水波纹改为当前记事的颜色（纯色或渐变）。
- 这些水波纹本身就是渐变色（从手指按下点向外扩散），而非过去的单色；已选中的控件保持原有的淡色水波纹不变。

## 验证重点
1. 抽屉根范围（全部记事）：按住未选中的状态段、未选中的类型图标 → 水波纹是 accent→accent2 渐变。
2. 进入彩色文件夹后再开抽屉：未选中控件的水波纹变成文件夹颜色（纯色文件夹 = 纯色波纹，渐变文件夹 = 渐变波纹）。
3. 详情 → 提醒 → 重复 → 每星期 / 每个月 / 每年：按住未选中的圆形按钮、以及「月末」药丸 → 水波纹是当前记事颜色（记事为渐变时波纹也渐变）。
4. 选中态控件按下时水波纹仍为淡色；未选中控件静止时外观不变。
5. 重点看波纹浓度是否合适（本次 PEAK_ALPHA = 0.36），浅色 / 深色 / 夜间下是否过浓或过淡。
6. 快速点击、滚动列表时无残影。

## 渐变 ripple 扩展（条6–14：Detail / 各 dialog / widget / 搜索）

### 主要改动
- 条6 分享对话框（TwoOptionsDialog）：两个 item 的触摸 ripple 改为当前记事颜色。
- 条7 提醒相关全套：
  - 快速提醒 popupwindow、自定义提醒 dialog 里「一段时间之后 / 重复」单位按钮弹出的 popup，每项 ripple → 记事色（DateTimePicker 列表项）。
  - 三个 tab（某个时刻 / 一段时间之后 / 重复）ripple → 记事色（胶囊形）。
  - 「分钟/小时/天/星期/月/年」「天/星期/月/年」单位按钮 ripple → 记事色。
  - 「每天」下「新的提醒时刻」按钮、每条右侧叉号 ripple → 记事色。
  - 右上角全选/取消全选按钮 ripple → 记事色。
  - 每星期/月/年圆形按钮、月末胶囊：选中态 ripple 改为按记事色明暗自适应。
  - 确定按钮 ripple → 与确定文字同源的记事色。
- 条8 添加附件 dialog：每个 item ripple → 记事色。
- 条9 音频附件卡片 + 播放/暂停、删除、信息三按钮 ripple → 记事色（卡片随圆角、按钮圆形）。
- 条10 图片/视频附件容器、编辑外观/删除按钮 ripple → 记事色；外观 dialog 里宽度两个胶囊：未选中→记事色，选中→自适应。
- 条11 各 dialog 确定按钮 ripple = 确定文字颜色（Alert / ThreeActionsAlert / Chooser / ColorInfo / AttachmentInfo / HabitRecord / HabitDetail / LongText / ThingFolderName / 背景编辑 BottomSheet / PatternLock / DebugUpdate 等）；带 radioButton 的 dialog 每个选项 ripple = 确定按钮颜色。
- 条12 移动到文件夹 dialog：选中行背景改为「目标文件夹自身颜色」（之前错误地用被移动项颜色）；未选中行 + 展开/收缩按钮 ripple → 目标文件夹色；选中行 ripple → 按其明暗自适应（参考 Drawer）。
- 条13 记事列表 widget 配置：上方文件夹区参考 Drawer/条12（按各文件夹色，选中自适应，展开按钮同）；类型 icon 参考条1；状态/显示模式胶囊未选中→所选范围文件夹色、选中→自适应、根目录→偏白；「顶部栏同时透明」「采用简单的记事视图」item ripple → accent 渐变。切换范围文件夹时这些 ripple 颜色会随之刷新。
- 条14 搜索取色 dialog「全部颜色」item：未选中 ripple → accent 渐变；选中保持现状（无 ripple）。

注：记事详情顶栏 overflow 下拉菜单项的 ripple 按用户要求暂缓。

### 验证重点
1. 详情页：分享、添加附件、音频/图片/视频附件、提醒 dialog 全套（含快速提醒 popup、各单位 popup、重复页圆按钮/月末胶囊选中态、全选、确定）逐一按下，ripple 是否为记事色 / 选中态自适应。
2. 各类 dialog 的「确定」按钮按下，ripple 是否与确定文字同色；单选 dialog 每个选项 ripple 是否为确定色。
3. 移动到文件夹：每个文件夹行、其展开按钮按下 ripple 是否为该文件夹自身颜色；选中行是否铺其色且 ripple 自适应。
4. widget 配置：切到不同文件夹后，类型 icon / 状态 / 显示模式胶囊的 ripple 颜色是否跟随该文件夹；根目录是否为 accent / 偏白。
5. 搜索取色「全部颜色」未选中按下是否为 accent 渐变 ripple。

## 渐变 ripple 反馈修复（第二批）

### 主要改动
- 顶栏图标 ripple 尺寸：改为固定半径（20dp），与系统原生那层一致；导航按钮（汉堡 / 关闭 / 返回）不再被自身更大的控件尺寸撑大，与右侧菜单项波纹大小统一。
- Drawer：被选中文件夹 item 右侧的展开 / 收缩图标改用满不透明的对比色，更清晰；未选中时仍沿用淡化前景色。
- 选中态「偏白」自适应波纹 alpha 由 25% 调到 36%（在 BackgroundUtil.adaptiveRippleColor 调整）。

### 验证重点
1. 首页顶栏：普通模式各图标、选择模式各图标按下，ripple 大小是否与系统原生一致、不再偏大。
2. 最左侧导航按钮（普通=汉堡、选择=关闭、搜索=返回）的 ripple 是否与右侧菜单项一样大，不再更大。
3. Drawer：选中某个有子文件夹的文件夹后，右侧展开箭头是否为满不透明（不再发虚）；未选中文件夹的箭头仍带淡化。
4. 各处选中态「偏白」波纹是否比上一版更明显。

## 阴影相关（2026-09-16）

上一轮记在这里的两条（回位没有阴影、快照阴影比系统画的「紧」）**都随方案更换而作废**：现在
阴影由真实卡片产生、只调强度，不再经过离屏渲染，回位那条路也一并修好了。剩下这些：

- **倒放回位没在真机上复现过**：六条「留下」分支共用 `ThingSwipeReturn`，代码走的是与消散完全
  相同的机制（`shadowOnly` + 同一条曲线），但触发条件要构造特定记事（习惯打卡失败、隐私认证
  取消等），这一轮没做。
- **阴影不跟着粒子碎开，而是整体平滑变淡**：这是当前方案的取舍（换来「与静止时逐像素同源」
  和「粒子不变粗」）。若将来要让阴影也碎，得回到「把阴影抓进快照」那条路，注意
  [[offscreen-shadow-needs-enablez]] 记下的两个坑。
- **`ParticleShadowCaster` 目前只有 `InterceptTouchCardView` 实现**：别的卡片类型（如果以后有）
  拿不到这个接口会退回「整块隐藏」，阴影仍会跳变。

## 阴影相关（2026-09-17 撤回后的状态）

围绕 elevation 阴影的全部改动已按用户要求撤回，代码回到 `88e570bb`。撤回后仍然存在的、**独立于
粒子动画**的既有行为，若以后要处理请单独开：

- **粒子接管时阴影随 `view.alpha = 0` 一起消失，回拖取消时一次性出现。** 这是最初报的问题，
  未解决。十轮里试过的路线与各自的死因见 [decisions.md](decisions.md)，不要从头再试一遍。
- **滑动松手回位后卡片总高度停在 12dp 而非静止的 8dp**：按压反馈压低的 `cardElevation` 在手势
  被 `ItemTouchHelper` 接管后不会还原（卡片收不到 `ACTION_UP`），而
  `keepActiveTouchItemAboveSiblings` 按 `maxSiblingZ + 偏移 − elevation` 反推 translationZ 又把
  差额补回来。**滑动档也有这个现象**，与粒子无关，可以独立修（改动只在 `ThingsActivity`）。
- **`bakeAncestorAlpha` 读容器透明度的时机**：原本在捕获回调里读，而宿主在粒子接管那一帧已把
  正在做事界面的列表还原成 1，「绘制过程中就地构造会话」那条路因此没把 0.84 乘进快照。改动只有
  三行（挪到会话构造时读），与阴影无关。

## 2026-09-16 滑走后留在列表里的卡片，回位动画（第三次，真机实测）

- 前两版按推断改时序都不成立（藏 2.4 秒 / 卡片直接不见），已撤回。这一轮先在 OPD2515 上加
  探针量实际时序与卡片状态，再动手。
- 测到的关键事实：滑走后卡片停在 `tx = -RecyclerView.width`；`notifyItemChanged` 约 25 ms
  换上另一张 View，默认换位动画其实一直存在，只是卡片走完约 75% 才进屏，只剩几十毫秒可见；

  从一个卡片身位外滑回（256 ms），粒子档倒放消散。接管失败则默认动画照旧兜底。

## 2026-09-16 粒子接管时 elevation 阴影消失（评估）

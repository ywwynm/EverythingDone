## 卡片粒子与回聚全过程保持 FAB 在上方

用户实测上一版 SurfaceView 方案中，原本被 FAB 遮住的卡片会在交接快照和粒子播放时反过来盖住按钮。本次按确认的方案，保持起滑、消散、回弹和回聚全过程的前后关系。

Android 14 及以上继续使用每窗共享 SurfaceView。新增 `ParticleFabSurface`：FAB 留在原 View 树接收点击、布局及动画，临时绘制层位于粒子 Surface 之上，与原按钮同步交接；保留真实阴影、位置、缩放和透明度。按钮内容使用可复用的小位图，避免系统波纹在第二个硬件 renderer 中自主出帧并阻塞 RenderThread；阴影仍由 HWUI 生成。静止按钮只绘制一帧，变化时更新，不读回 GPU 像素。旧系统的 TextureView 兼容路径保持正常 FAB 层级。

魅族 `392QBFED2226B` 的带 FAB 虚构卡片验证通过：短滑保持与回弹、完成后回聚、FAB 移动及缩放、接管期间实际点击及波纹、仅点按预热、动画中退出清理。自动录屏检查能在旧版复现遮挡，在新版通过；兼容 Texture 路径也已同包验证。实际点击时消散与回聚均提交到末帧，完成回调恰好一次；退出后无临时图层残留。

完整 JVM 检查 1044 通过、1 跳过。关闭录屏和 PixelCopy 的单次性能样本未出现此前波纹导致的秒级阻塞；尚未做其它系统与设备、长期功耗及多卡片压力测试。不读写现有记事、不修改偏好，未创建 Git 提交。

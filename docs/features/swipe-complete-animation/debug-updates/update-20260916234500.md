## 阴影还回去这一下摊成四帧（20260916234500）

你说得对：绑消散进度的话，快速滑动时进度会一帧跳过整段曲线，阴影就成了突变——那个方案的漏洞
是实的，所以不换路线，阴影继续跟着快照一起碎（这样它和粒子天然同步，手滑多快都一样）。

只剩交接那一帧。上一版把「Surface 抹平」与「阴影还给卡片」的间隔从 34 ms 压到 0–7 ms，但它仍
可能落在帧边界两侧——那一帧屏幕上一层阴影都没有，随后**一步跳回满值**，约 15 个灰阶，看起来
就是闪一下。

这一版不再去磨「同帧」（跨两个 Surface 做不到），改成把这一下**摊成四帧渐入**：每帧不到 4 个
灰阶，低于能看出来的程度。渐入期间阴影整体偏淡一点，但这段只有 64 ms，而且是连续变化，不会
出现某一帧的台阶。

请再看一眼。如果还能看出来，我的判断是只剩一条路能做到真正的零交接：**让粒子 Surface 的最后
一帧就不画阴影那一圈**（GL 侧按卡片本体的范围把阴影圈的格子丢掉），这样卡片可以从头到尾保留
自己的阴影、根本不需要「按住再还回去」。那要动 shader 与材料层，我会先说清楚影响面再做。

本版已验：`:app:assembleDebug` 通过，单测全过。设备上的动画档位保持你设的「粒子」，没有改动。

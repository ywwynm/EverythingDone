# 滑动完成从触摸位置开始消逝

## 本次更新

- 首页和 DoingActivity 在启用粒子动画时，将其中一个消逝起点固定到手指最初按下的位置，其余起点继续随机。手指移动后起点仍留在原卡片上，粒子按原来的滑动方向飞出。
- `ParticleSwipeAnimator` 为每次手势保存独立触点，并扣除裁切与阴影外扩偏移；`ParticleReleaseOrigin` 将触点传入共同材料模型，避免顶栏遮挡或设备密度造成起点错位。
- 触点附近在早期开始消逝，短滑回弹和回拖继续反向播放同一份材料。没有触点的菜单移除、弹窗及其它出现动画沿用原释放规则。
- 沿用设置中的粒径、流场细节等参数，不增加逐帧计算工作。
- 本地构建与 39 项相关 JVM 测试通过。魅族和三星各 4 个虚构卡片场景通过，覆盖上下触点、顶栏与半透明阴影、回弹、回拖、右滑完成及回聚；JNI 与 Kotlin 释放场对照一致，设备偏好未改变。

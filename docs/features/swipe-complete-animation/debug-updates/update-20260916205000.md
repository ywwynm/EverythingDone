## 阴影改成随进度做动画：不再瞬间消失，也不再瞬间出现（20260916205000）

按你的新思路做了：**阴影仍由真实卡片产生，只让它的强度随进度平滑退场／入场**。上一版「把阴影
烤进快照」的整套东西（取景框外扩、离屏嵌套节点、光源参数读取）已全部回滚。

做法的关键是一条平台事实：**阴影绘制只看卡片 RenderNode 的 alpha、z 与 outline，与 display
list 里有没有内容无关。** 所以粒子接管时不再用 `alpha = 0` 整块隐藏（那会把落在卡片矩形之外、
由列表绘制的阴影一起干掉），而是让卡片「只投影、不画内容」：内容一概不画、alpha 留在 1，
阴影就还原样留在原位，再按进度把 `elevation` 降下去。

配套两处：

- **粒子档下卡片不再跟手平移。** 它此时只剩一层留在原位的阴影，跟着手指走会与原位消散的粒子
  错开。右滑「开始做事」本来就是这个行为，现在左滑的粒子档也一样（滑动档仍跟手，没动）。
- **粒子档下不再抬 Z。** 原来为了让滑动中的卡片盖住兄弟卡片会按 `elevation` 反推 `translationZ`，
  那会把动画刚降下去的 elevation 又补回来，阴影就淡不下去；而此时卡片内容不可见，也不需要盖
  在别的卡片上。

强度曲线跟的是「还有多少内容留在卡片原位」，取值量自粒子模型的释放场而不是试出来的
（`ParticleCardShadowFade`：衰减区间 0.05→0.65，单测拿同一份 `releaseField` 做逐点对照）。

**倒放回位这一版也一起修了**：`appearContent` 新增一个「怎么把内容藏起来」的回调，卡片这条路
传「只投影」而不是整块透明，阴影从完全散开那一端按同一条曲线长回来。

### 实测（OPPO 平板，逐点量阴影深度）

| | 静止 | 接管瞬间 | 消散中 | 更深 | 松手回弹后 |
|---|---:|---:|---:|---:|---:|
| 下缘阴影 | 9.5 | **9.5** | 5.5 | 4.4 | **9.5** |
| 左缘阴影 | 14.9 | **14.8** | 10.2 | 7.9 | **14.9** |
| 右缘阴影 | 12.5 | **12.4** | 7.6 | 6.1 | **12.5** |

单位是灰阶（与确定无阴影的背景比）。三条都对上了：**接管瞬间与静止时一致**（不再跳变）、
三个方向按同一比例衰减（阴影形状保持不变，就是真实阴影在变弱）、回弹后逐项回到原值。

另外确认了两件事：卡片区域内部没有被阴影压暗（不透明遮挡体的剔除生效，接管帧 161.1 vs 静止
161.0）；滑动档没被改坏（卡片照旧跟手平移到屏外，松手后与静止逐像素相同）。

比上一版好的地方：阴影与静止时逐像素同源，没有「离屏画的阴影比系统画的紧」那个问题；取景框
不外扩，粒子不会变粗。代价是**阴影不跟着粒子碎开，而是整体平滑变淡**——你的目标是消除跳变，
这个取舍应该成立，但观感请你定。

# 滑动完成记事动画调试更新

## 首页右滑开始做事不再带着卡片右移

首页记事列表右滑一条记事是「开始做事」。此前这个手势有两层反馈同时发生：卡片跟着手指往右平移，卡片上那层写着开始做事的蒙层按滑动距离淡入。用户认为平移是多余的，蒙层的出现与透明度变化已经足够表达手势进度，本版去掉卡片的位移，只保留蒙层。

改动只有一处：滑动状态且横向位移为正时，传给框架绘制回调的位移改成 0，框架自己记的位移一个字不动。动手之前先反编译了 recyclerview 1.4.0 的 ItemTouchHelper 核实一件事——松手之后的回弹与完成动画，起点取自按下位置加手指累计位移再减去卡片左边界，与卡片当前的平移量无关，只有在没有横向滑动标志时才会去读卡片的平移量。因此蒙层在松手后仍然按真实手指位移继续走：没到阈值就从当前浓度平滑淡出，过了阈值就补满再进入开始做事。这一点值得单独记一笔，因为本功能此前有一条相反的结论，那条结论约束的是粒子那一侧——粒子完成时要靠框架把真实卡片停在屏外，两者不冲突。

未改动的范围：左滑完成记事（滑动与粒子两档都没动）、长按拖拽重排与拖入文件夹、选择模式，以及正在做事界面。做事界面是另一套回调、另一个动画器实例，左右滑都是完成记事，跟手位移保留。共同粒子模型、着色器与任何已认可的视觉参数均未触及。

本版没有上真机，请重点复看五项：其一，慢速右滑时蒙层浓度是否跟手、卡片是否真的一动不动；其二，滑到一半松手，蒙层是否平滑淡出而不是瞬间消失；其三，滑过阈值松手是否正常进入开始做事界面，中途蒙层有没有闪一下；其四，对当前正在做的那条记事右滑，仍应只给出提示而没有别的变化；其五，左滑完成（两档）与长按拖拽建夹是否确实不受影响，平板多列布局一并确认。本轮未提交 Git。

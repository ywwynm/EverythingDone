## 卡片阴影随粒子共同消散与回聚

上一版让原位的完整阴影独立淡出，用户指出短距离滑动后仍能看到卡片轮廓。这一版将原生阴影加入卡片快照，与卡片本体使用同一粒子材料，消散区域下方不再保留完整投影。

`ParticleCardSnapshot` 与 `ParticleHardwareSnapshot` 捕获真实轮廓、正常高度和窗口光源。修正 Outline 默认透明的问题，并按 HWUI 后端与窗口缓冲方向对齐 OPPO 横屏投影。阴影外圈增加材料预算，保持原有本体粒径。

卡片手势及 `ThingSwipeReturn` 改用同一窗口内的 TextureView，与真实卡片在同一帧交接，消除阴影叠深和空帧。普通弹窗沿用共享 Surface。快速甩动确认完成后，补全过程不再退回已经提交的较早进度，避免阴影短暂重新加深。

OPPO 已用虚构卡片覆盖短滑停住、回弹、快速松手、跨原点反拖、快甩完成和完成后回聚。小卡片与宽卡片的静止前后阴影一致，最终各场景回位交接采样差为 0 灰阶。完整 JVM 检查 1044 通过、1 跳过，差异格式检查通过。

测试页面不读写已有记事或动画偏好。魅族 `392QBFED2226B` 目前离线，尚未验证；API 26–28 仍使用不含外圈原生阴影的软件内容快照。本次未创建 Git 提交。

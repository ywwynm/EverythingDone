## 阴影交接：等 Surface 真的抹平那一刻，不再等固定时长（20260916230000）

你说「阴影突然变深一下」，我把交接的时序逐点打了时间戳，结果和我们俩猜的都不一样——**不是
两层叠加**，而是中间空出了一段一层阴影都没有的窗口，阴影从 0 跳到满值，看起来就是突然变深。

上一版实测的时序：

```
handoff-start    +0ms    卡片内容恢复，阴影按成透明
after-release   +11ms    粒子层从 View 层撤掉
surface-cleared +17ms    GL 线程把粒子 Surface 抹成全透明
shadow-back     +51ms    阴影还给卡片        ← 这中间 34ms 屏幕上没有任何阴影
```

问题在那个固定的 34ms：它是我按「两帧应该够」估的。早一点会与 Surface 上的阴影叠成两层，
晚一点就空出这段窗口——**估不出来，得等事件**。

这一版给 `ParticleWindowSurface` 加了一个「抹平之后」的钩子（`runAfterCleared`）：GL 线程在
把 Surface 抹成全透明的那一帧之后通知主线程，阴影紧跟着还回去。`needsWork()` 一并把这个队列
算进去，免得 GL 线程在还有待办时先休眠；钩子不来时仍有 200ms 兜底。

改完实测两次，`cleared` 与 `back` 的间隔是 **7ms 和 0ms**（上一版是 34ms），也就是无阴影的窗口
被压到一帧以内。

请再看一眼滑动松手前后。如果还能看出变化，麻烦再分一次方向：是**阴影比原来深**（那就还有叠加
源，我继续找），还是**闪一下但深浅最终一样**（那就是剩下的一帧，属于跨 Surface 交接的理论下限，
我会换思路而不是继续磨这一帧）。

本版已验：`:app:assembleDebug` 通过，单测全过；真机上逐点量过交接时序。设备上的动画档位保持
你设的「粒子」，没有改动。

# 滑动完成记事动画调试更新

## 修正回位动画：不再等列表归还卡片

用户在上一版实测：习惯「下个周期前都无法打卡」与私密记事左滑后取消验权两处，卡片都是藏两秒多之后才出现。两秒多正是兜底超时的时长，说明回位动画从来没有开始过。

上一版的前提写错了。当时认为滑走回调必定早于列表归还卡片，于是要求两条消息都到齐才开始播回位。实际上列表对成功滑走的卡片是把它挂进待清理队列，归还的时机并不跟着滑走走：卡片留在列表里、手指又没有再碰列表时，归还可以迟到很久。上一版还有一处自伤——把这六处的变更通知改成带附加标记之后，原本「另建一个视图持有者、新卡片在原位以透明度由零到一出现」这条让卡片回来的路也一并没有了，于是卡片一直停在屏外，直到兜底把它放回来。

本版三处改动。其一，回位由业务判定单独触发，不再等归还：业务侧一确认卡片留下就把它藏起来并排期播放。其二，归还只剩两件事：早到就先藏起来，别让卡片在业务判定之前先露一帧；晚到就把刚被复位掉的透明度压回去。其三，归还迟到落在回位动画中间时，列表收尾里那几项复位一项都不能做——取消动画会直接打断滑动回位，把透明度写回不透明会让真实卡片盖住正在聚拢的粒子，为此新增了「回位是否正在播」的查询供收尾跳过。带附加标记的变更通知保留：回位动画自己负责把位移与透明度摆正，不再需要靠另建持有者把卡片变回来。

时序闸门的本地检查同步改成新语义，并把这两处实测记进测试说明，共八项。共同粒子模型、着色器、时长、密度与任何已认可的视觉参数均未改动。构建通过，本地检查 1036 项，唯一失败是既有的 FableSol 曲线那一项，与本轮无关。

本版仍未上真机。请把上一版报的两处再走一遍——习惯「下个周期前都无法打卡」、私密记事左滑后取消验权，卡片应当立刻开始回位而不是先消失两秒多；另外四条分支（非记事条目、大于通知目标的类型、右滑开始做事、完成后记事仍留在当前列表）也请各走一遍。两档分别试：滑动档从卡片飞走的那一侧滑回并淡入，粒子档粒子从同一侧重新聚成卡片，右滑无论哪档都只滑回来。再确认拖动排序与滑到一半松手不会被误接管，以及习惯打卡后的记录、目标的状态显示照常刷新。本轮未提交 Git。

# 滑动完成记事动画调试更新

## header 记事与占位卡不再可滑

上一版去掉了首页右滑开始做事时卡片的跟手平移之后，用户报告 header 记事「现在也能右滑」。查证后确认：能滑是既有行为，不是上一版引入的。列表把 header 记事和普通记事包成同一种条目，而放行滑动的判定只看是不是记事条目，header 因此一直拿得到左右滑标志；每一项又都用同一份卡片布局，「开始做事」的蒙层在 header 上同样存在，右滑时照样淡入。松手之后才被业务侧按位置 0 原样退回，也就是滑了等于没滑。以前这个手势的主视觉是卡片跟着手指平移，蒙层混在里面并不显眼；平移去掉之后，开始做事的图标与文字成了 header 上唯一的反馈，看起来就像 header 支持开始做事了。

本版让这个手势自始至终不成立，而不是只把蒙层藏掉。后者只管右滑那一半，左滑的平移与粒子消散仍然会播，而且「滑得动但什么都不会发生」本身就是错的。新增的放行判定与业务侧的几处早退对齐：列表位置 0 的 header 记事、非记事条目、以及各类空列表占位卡都不再拿得到滑动标志。顺带修掉一处既有问题：粒子档下左滑 header 会完整播一遍粒子消散再把卡片复位。欢迎卡不在此列，那几张本来就能滑动完成，行为不变。

普通记事的左滑完成（滑动与粒子两档）、右滑开始做事、长按拖拽重排与拖入文件夹、选择模式、正在做事界面均未改动。上一版的滑走回位动画也未改动，它真正服务的隐私认证取消、习惯已暂停、右滑开始做事这几条路径照旧。共同粒子模型与任何已认可的视觉参数均未触及。

本版没有上真机，请重点复看四项：其一，header 记事左滑右滑都应毫无反应，卡片不动、不出现任何蒙层、粒子档下也不播粒子；其二，普通记事的左滑完成与右滑开始做事是否与上一版一致；其三，各类空列表的占位卡（暂无正在进行、暂无已完成、回收站为空等）滑动是否也没有反应；其四，欢迎卡是否仍能左滑完成。本轮未提交 Git。

# 滑动完成记事动画调试更新

## 正在做事界面接入滑动完成动画，粒子不再固定向左

用户报告正在做事界面左右滑动完成记事时，动画没有继承设置里的档位；档位选「粒子」时应当和首页记事列表左滑一样播粒子。排查确认该界面完全没有接这条路：首页的五处入口（向动画器喂触点、按下那一刻预热快照、在卡片被移动之前把粒子画进去、把完成动作推迟到消散播完、手势结束收尾）一处都没有，只有原本的整体淡出，因此档位设成粒子也没有任何变化。本版把五处全部接上。

该界面左右滑都是完成记事，而滑动粒子此前只为左滑写死，随方向变号的有四处：进度取位移的负值、消散的虚拟触点放在卡片左外侧、完成之后把卡片停在左侧屏外、右移一律按「方向不对」取消预热。本版新增 ParticleSwipeDirection，把变号的算式集中成纯函数并用 5 项单测逐项定死；符号写反在设备上表现为粒子朝反方向飞或者进度永远是零，能在本地定死的不靠设备逐个方向试。ParticleSwipeAnimator 新增右滑开关，打开时预热不再因右移取消，方向由第一次越过触摸阈值的横向位移决定——这比列表的滑动判定更早，消散方向赶得上在建动画层之前定下来。快照捕获与建动画层因此拆开：定向之前只留快照，定向之后才按方向建层；首页仍在捕获回调里直接建层，起步时延不变。同一次手势里划过原点换方向时，只要还没有粒子上屏就允许改向并重建动画层，已经上屏就锁定，不让屏幕上正在飞的粒子突然掉头。首页右滑是「开始做事」，那边的右滑开关保持关闭。

做事期间记事卡片所在列表常驻 0.84 浓度，而粒子画在窗口那一个共享表面上、拿不到这个值，直接播会在接管的那一帧整体提亮约两成。本版把各级容器的透明度之积烤进快照（首页各级容器都不透明，是空操作），同时在粒子接管期间把列表这一层还原成不透明，准备期在卡片原位补画的内容与粒子层因此都恰好是原来的浓度。顺带修掉一处既有问题：滑到一半松手回弹时位移归零，原来的算式给出完全不透明，列表会一直停在比进入时更亮的浓度上，现在手势结束恢复常驻浓度。

设置项文案改为「滑动完成记事动画风格」。英文原本是 Swipe-to-complete animation style，而项目里完成记事一律用 finish，这是唯一一处 complete，改为 Swipe-to-finish animation style。中文简繁、日文、韩文原本写的是左滑、左スワイプ、왼쪽 스와이프，去掉方向限定。德、西、法、印地、意、葡、俄七种原本就不带方向，未改动。资源名与设置键不动，键一改会把所有人已选的档位重置。

共同粒子模型、着色器、时长、密度与任何已认可的视觉参数均未改动。构建通过，单测 1028 项，唯一失败是既有的 FableSol 曲线那一项，与本轮无关。

本版没有上真机，请重点复看四项：其一，粒子表面使用置顶层序，而做事界面的窗口带显示壁纸标志且为半透明格式，这个组合本项目此前没有跑过，是最大的未知项；其二，左右两个方向的粒子是否各自朝手指滑走的那一侧飞出；其三，粒子接管处的浓度有没有跳变，该改动按 0.84 推算，没有实测像素；其四，甩动、滑到一半松手回弹、同一次手势里滑过原点换方向这三条路径。设置界面请确认文案与各语言显示正常。本轮未提交 Git。

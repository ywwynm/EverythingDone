# 滑动消逝关联触摸起点

## 范围与实现约束

- 首页与 DoingActivity 已共用 `ParticleSwipeAnimator`；首页左滑完成，DoingActivity 左右滑均完成。
- `warm` 在按下时已取得屏幕触点。本次将触点保存在各自会话中，避免上一张卡片回弹时被下一次触摸覆盖。
- 按快照原点、裁切偏移与阴影扩展边界换算归一化触点；不直接替换控制飞出方向的 `virtualTouch`。
- 在 `ParticleReleaseTopology` 的局部起点中固定一个到触点，其余仍按原随机种子生成。Kotlin 与 JNI 共用相同输入；没有触点的菜单移除、弹窗和出现动画继续使用原规则。
- 沿用当前粒径、流场与其它设置；不增加逐帧工作。短滑回弹、手指回拖继续反向播放同一份材料。
- 固定起点使用零局部延迟；有触点时局部扩散权重下限为 0.90，避免原来的随机细节场把触点推迟到中段。其余起点的数量、位置、延迟与随机形状均不变。此项仅改变消逝时序，不改粒子设置或飞出方向。

## 已完成的本地验证

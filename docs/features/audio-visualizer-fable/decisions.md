# 录音海浪可视化（Fable 方案）· 设计决策

记事详情界面录音对话框内、以海浪为主题的实时声音可视化重设计。类名以
Fable 结尾以区分现有方案（recording-wave-visualizer，本轮按用户要求未读取
其代码与文档，完全从头设计）。

## 2026-07-03（设计访谈）

- **D1 音频特征来源**：不改动录音管线。`AudioRecorder` 本就以 44.1kHz
  立体声 16-bit PCM 采集（AudioRecord→WAV），在其采集线程为新方案增设
  独立分析器旁路，直接消费原始 PCM 字节，提取三类特征：响度
  （RMS→dB）、基频（自相关类算法，真实音调）、语速（能量包络起音率）。
  现有 `RecordingAudioAnalyzer` / `RecordingWaveDriveFrame` 分发链保持原样。
- **D2 文档归置**：本轮新文档写入 `docs/features/audio-visualizer-fable/`
  （用户指定沿用该目录；经查目录原为空，故直接使用标准文件名）。
- **D3 层配色**：每层水体使用 Thing Background 本色——PURE 原色、
  GRADIENT 整条横向铺满 View 宽度并按层复用——仅以透明度阶梯表现远近
  （近层约 0.92，逐层递减至最远约 0.16）。已同步修订 CONTEXT.md 中
  Voice Waveform 的三处取色描述（原"同色系深浅阶梯"规则作废）。
- **D4 技术栈与接入**：Kotlin 自定义 View + Canvas + Choreographer 帧循环
  （AGP 9.2.1 内置 Kotlin；minSdk 26 排除 AGSL 作为基线）。接入方式：在
  `fragment_record_audio.xml` 与 `AudioRecordDialogFragment` 中把
  `RecordingWaveVisualizer` 替换为新 View，旧类全部保留不删。宿主契约
  维持不变：View 铺满 280×360dp 对话框、绘制在控件之下，宿主控制整体
  alpha（空闲 0.16 / 录音 1.0 / 停止 0.16），颜色经
  `setThingBackground(ThingBackground)` 传入。
- **D5 水位边界与动力学**：静息水位约 100dp（恒盖 56dp 主按钮，其顶缘
  距底约 76dp）；静音下限约 84dp——任何时候不露出按钮；持续大声的平均
  水位上限约 200dp（对话框高度 55%），巨浪峰值可短暂冲至约 260dp。水位
  跟随响度采用攻快释慢（攻击 τ≈0.12s、释放 τ≈0.9s）。波形峰高谷浅不对
  称，波谷钳制在水位下方小范围内（需求 9）。
- **D6 声音→波场映射**：波场 = 常在低幅环境涌浪 + 声音波包线性叠加
  （静音时水面不僵止；新浪从右侧注入向左传播，与既有浪叠加融合而非改写，
  需求 7）。响度→波包振幅与水位；音调→波包波长（约 80Hz→长波长圆缓
  涌浪、≥400Hz→短波长细碎密浪，对数映射；检不出基频用中性波长）；语速
  （起音率）→波包生成速率（慢说约 0.6–1.2s 一浪、快说约 0.15–0.3s 一浪）；
  行进速度由深水色散关系 ω=√(g·k) 决定（长浪快短浪慢），不随语速变。
- **D7 巨浪触发与呈现**：双通道触发——突发响度跃升（喊叫、拍手）立即
  触发；持续大声（高响度维持 2s 以上）期间每 6–10s 周期性触发；冷却
  4–8s 随机；同屏至多一个，仅发生在最近 1–2 层。呈现序列：局部陡度在包
  络窗内增大→波峰前倾变尖→唇口按对数螺线（或旋转椭圆）卷曲倒卷→尖端
  按抛物线在重力下落下→触水生成扇形水滴粒子与泡沫、落点注入短波长次级
  波包与水面融合；整段约 0.8–1.5 个波周期。

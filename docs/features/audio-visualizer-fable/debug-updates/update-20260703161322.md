# 录音海浪可视化更换为 Fable 海洋新方案

## 本次更新

- 录音对话框的声音可视化整体替换为重新设计的海洋方案（类名带 Fable 后缀，旧方案代码保留未删）：
  - 7 层记事本色、透明度阶梯分远近的实心水浪，各层波长/相位/节奏独立，带波群呼吸与慢速换代；
  - 音量→水位（初始即盖过录音按钮且恒不露出，攻快释慢）；音调→新浪波长（低音长涌浪、高音细碎浪）；语速→新浪生成密度；新浪一律从屏幕右侧入画、按群速行进并与已有浪线性叠加自然融合；
  - 突发巨响或持续大声触发倒卷巨浪：对数螺线卷头、射流受重力下落、水滴溅落转泡沫并在落点激起次级波回融水面；
  - 波速遵循深水色散关系（长浪快、短浪慢），波谷经软钳制贴近水位不深陷；
  - Choreographer 帧循环、onDraw 零分配、中点贝塞尔平滑，适配设备最高刷新率。
- 修复自定义 View 在 Dialog 的 WRAP_CONTENT/AT_MOST 测量链下默认吃满可用高度、把根 FrameLayout 撑大的问题：新 View 非 EXACTLY 模式只上报固有最小尺寸，录音对话框保持 280×360dp。

## 验证

- `:app:assembleDebug` 构建通过；`:app:publishDebugUpdate` 发布本更新。
- 待真机验证：对话框尺寸保持 280×360dp；水位/波长/浪密度对音量/音调/语速的响应；巨浪触发、倒卷与溅落回融；各层灵动不齐步；曲线平滑与高刷流畅度。

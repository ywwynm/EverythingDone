## 详情页下拉接收更新，修正退出文案并补齐全部语言

用户要求详情页点击“退出接收”后的入口显示“接收并更新记事”，覆盖所有受支持语言，并加入类似首页的下拉展示操作。

三星实机在修正前复现了退出瞬间显示“接收记事”。原因是共用控件 TapReceivePull 固定恢复首页文案。现在首页和详情页分别配置入口文字，详情页首次下拉与退出动画均使用“接收并更新记事”，现有 13 个语言／地区全部补齐。

DetailActivity 在界面就绪时安装接收控件。先将详情滚动到顶部，再下拉即可展开入口，点击后进入原有接收流程；小幅下拉回弹，上滑收起，退出接收后自动复位。键盘、清单移动、分享及裁剪期间不开始下拉。TapDetailReceiveController 将原有媒体让位逻辑延伸至下拉阶段，图片和视频顶部完整显示，底部避开固定操作栏。

122 项相关本地测试、完整资源检查通过；三星、OPPO、魅族三台指定设备各 13 组专项通过，覆盖真实触摸手势、退出瞬间文案、13 种语言资源的控件显示、图片／视频完整性、内容更新及撤销／重做。画面检查通过。三星与 OPPO 的原有各表摘要一致；魅族首次安装测试期间一条习惯的两项提醒运行状态发生校正，记事内容及完成记录未变，补测各表摘要完全一致。具体触发者未采样到，详细差异保留在验证记录，不回写过期提醒。

测试仅建立并清理临时记事；传输回调为模拟，不代表完成实体 NFC 互碰验证。实现和证据见 docs/features/thing-transfer-update/pull-entry-2026-10-19.md。代码与文档保留在工作区，未创建 Git 提交。

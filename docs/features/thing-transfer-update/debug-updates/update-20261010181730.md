# 详情接收界面与设置选择调整

## 2026-10-10：按首版反馈统一接收界面

用户要求详情“碰一碰以更新记事”复用首页的页面下移、四周粒子和接收进度；菜单项紧接分享；提醒和习惯选择框按标题、说明、整行单行动作排列，必须选择一个方案，不提供取消。

详情直接复用 `TapReceivePull` 的按钮、提示与位移曲线，关闭首页专用下拉手势；`TapReceiveStageView` 覆盖整个屏幕内容区域及导航栏安全区。等待、百分比和退出按钮沿用首页样式，进度文字按记事前景色保持可读。内容继续由新粒子直接覆盖，完成或退出后页面复位。

`menu_detail_underway`、两份习惯菜单和已完成菜单在分享项后声明新入口。`TapUpdateSettingsDialog` 使用统一标题和正文间距，说明集中在动作上方，“保留当前设置”“采用收到的设置”各占一整行；禁止返回和外部点击取消。离开应用等生命周期中断不触发设置选择，也不会写入尚未应用的来件。

真机检查后修正下移内容压住底部操作栏、视频封面进入顶部提示区的问题，退出时恢复原裁切边界。普通记事快速传入时等待进场位移结束再捕获画面，避免新旧内容位置不同。

构建与 69 项碰一碰相关 JVM 测试通过；三星与魅族最终各 13 组检查通过，包括设置两种选择、私密及完成状态、视频与清单、撤销／重做、历史附件、无效来件、取消、快速来件、强制设置选择及生命周期中断。三星原有 371 条、魅族原有 180 条记事及其它数据库表前后一致，临时数据已清理。

新版录屏已逐帧核对，传输回调由测试模拟，记事文件、页面、事务与粒子使用实际实现；本轮未进行实体 NFC／Wi-Fi Direct 双机触碰。未创建 Git 提交。

# 修复接收进场裁切顶部附件

## 2026-10-10：图片和视频整体下移

用户反馈上一版详情进入接收状态时，顶部图片类附件被裁掉一部分。原因是普通正文原本已留出顶栏间距，图片详情却从屏幕顶端开始；之前只移动了接收控件的高度，再用额外顶部裁切避免重叠，实际删掉了图片顶部。

`TapDetailReceiveController` 现在根据列表原位置补齐缺少的顶栏间距，与接收控件一起平滑让位；保留附件原顶部边界和原尺寸，只限制底部可见范围，避免压住固定操作栏。退出时复位，有图／无图互换后按新布局捕获更新画面。

在生产详情测试中增加静态图片和视频的连续进出专项，检查顶部完整、尺寸不变、接收控件不重叠、退出位置和裁切恢复。三星修复前四次均裁掉 335 px；修复后两机四次均为 0。三星附件高度保持 1080 px，魅族保持 1026 px。

构建通过，两机原更新流程各 13 组回归通过，包括有图／无图互换、设置选择、粒子覆盖、撤销重做、快速来件和取消。三星原有 371 条、魅族原有 180 条记事及其它数据库表前后一致，测试数据已清理。新版真机画面已核对；收包回调为模拟，未进行实体双机触碰。未创建 Git 提交。

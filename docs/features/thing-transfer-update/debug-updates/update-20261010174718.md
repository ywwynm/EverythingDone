## 2026-10-10：详情页新增碰一碰更新记事

用户要求在记事详情溢出菜单加入“碰一碰以更新记事”，从另一台设备的现有分享入口接收内容后直接更新当前记事，并支持粒子动画、撤销和重做。

逐项确认后，更新标题、正文／清单、附件、背景与外观；保留本机身份、文件夹、置顶位置、私密设置、整条记事完成状态及原完成时间。只接受一条独立记事，多条或文件夹提示后继续等待。有提醒或习惯时提供选择：保留当前设置和打卡记录，或采用收到的设置并让习惯从零开始。重做复用本次选择，历史仅在当前详情编辑期间有效。

`TapDetailReceiveController` 复用传输和粒子渲染；按用户最终要求保留旧画面，新内容粒子直接覆盖，不为旧内容另播退场。`ThingFileUpdate` 以同一数据库事务替换内容与提醒相关行，完整保存打卡记录供撤销恢复，并重新分配记录主键防止与其它习惯冲突。`DetailActivity` 接入菜单、设置选择和完整编辑动作；`App` 在历史存活期间保留旧附件，关闭详情后按使用情况回收。

真机录屏发现视频封面比布局晚完成，已改为等待可见附件加载后再生成粒子；冻结画面也覆盖导航栏安全区。长清单替换成短正文时，新背景覆盖全部旧内容。取消、状态冲突、退出后迟到的文件均不修改目标；提交成功后的界面异常不会误删生效的附件。

验证：应用构建及 1419 项现有 JVM 测试通过；三星和魅族各 10 组业务检查通过，另完成附件生命周期专项与录屏逐帧检查。只创建并清理临时记事，三星原有 371 条、魅族原有 180 条记事及其余数据库表前后完全一致。本次使用真实详情与粒子渲染、真实记事文件和模拟传输回调，未执行实体 NFC／Wi-Fi Direct 双机互碰。没有创建 Git 提交。

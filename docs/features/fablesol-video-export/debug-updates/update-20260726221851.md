# HDR 能力门控、播放结束态恢复与双层水波图标

## 本次更新

- 导出视频图标改成两层高低错落的真实水面轮廓：底层水线横贯画框，上层从中间偏左出现，
  两层不再等高或机械平行。
- “导出 HDR 视频”开关现在会在后台执行一帧真实编码探测，验证 10-bit HDR 编码器、
  BT.2020/HLG EGL surface、FP16 场景和最终输出格式。设备无法完成整条 HDR 链时，开关会
  取消选中并置灰。
- HDR 请求的降级顺序改为 HDR 120fps → HDR 60fps → SDR 120fps → SDR 60fps，避免设备
  支持 60fps HDR 时却提前得到 120fps SDR。
- 修复音频自然播放结束后，拖动进度条再点击播放没有反应的问题；现在会从所选位置重建并
  继续播放，进度不会被准备回调重置到开头。
- 主播放/暂停图标增大到 32dp，外层 56dp touch ripple 保持不变。

## 验证

- 完整 JVM 单元测试：298 项，0 失败，1 跳过。
- debug APK 构建成功。
- 未使用 adb；三星设备上的最终 HDR 判定与播放体验请安装本版后实测。

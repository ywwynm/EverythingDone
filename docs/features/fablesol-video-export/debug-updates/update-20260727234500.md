# FableSol 视频导出：修正推导文字与能力报告

## 2026-07-27 说明文字改为按当前编码器解析；能力报告列出全部可用组合

**「自动」的落点现在按当前选择的编码器解析。** 此前把编码器钉成 AV1 之后，格式选项已经正确
地只保留 HDR10 与 HLG，下方说明却仍显示「当前为 HDR10+」，而 AV1 编不出该格式。原因是那段
文字使用的是编码器同样取自动时的结论，不含用户当前的编码器约束。格式说明、设置摘要，以及
漫反射白与高光起点两根滑杆的显隐，全部改用带编码器约束的结果。

**体积估算与提示语改用实际可达的帧率。** 设置中的帧率是上限，当前组合达不到时导出会自行降级；
此前估算仍按上限计算，会与产物给出两个互相矛盾的数字。现在帧率与编码器在同一次解析中得出。

**能力报告列出每种格式全部可用的编码器。** 此前只显示第一个落点，因此 HLG 明明 HEVC 与 AV1
两条路都成立，报告里只写了 HEVC。现在逐编码器列出各自能达到的最高帧率，例如
「HLG（HEVC 120 fps、AV1 120 fps）」；自动选择一项也补上具体落点。

**修正编码器被意外取消的问题。** 冲突迁移此前取「第一个成立的选项，与当前不同就迁移」，会在
已经选定 AV1、随后切换到 AV1 同样支持的格式时把编码器甩回「自动」。现在仅在当前选项确实不
成立时才迁移。

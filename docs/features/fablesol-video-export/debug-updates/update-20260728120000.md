# 背景暗、没有动态感——根子在漫反射白钉得太低

## 不是曲线的问题

你说的对，我上一版的解释也没说到点子上。真正的原因是：**我们把水体和白卡片钉在了 203 尼特。**

PQ 是**绝对**亮度曲线——我们写 203，正确的显示设备就渲染成 203 尼特，一分不多。203 这个数
出自广播标准，是给暗室里的监视器定的；而你的手机在高亮度下显示普通 SDR 白大概在 500 到 800
尼特。所以我们的 HDR 产物，背景比这台手机平时的白**还要暗**。这从第一帧就定死了，曲线救不了
——它只管膝点以上的东西。

杜比视界躲开了这一点：它走杜比自己的显示管线，基层又是 HLG（相对亮度，跟着屏幕自己的参考白
走），所以一开始就是亮的。

**而这也正好解释了"没有动态感"。** 背景坐在 203 尼特，一块能到 1000 尼特的屏幕还剩五倍余量，
它根本不需要在背景和高光之间做取舍——两个都放得下，所以什么都不动。**杜比视界之所以有动态感，
恰恰是因为它的背景坐得够高，高到屏幕不得不取舍。** 我们的画面是静的，不是曲线不对，是整体
压得太低，从来没逼出过取舍。

## 所以加了一档可调的「漫反射白」

设置里新增这一项，200 到 800 尼特，**默认 400**。它决定水体与白卡片的绝对亮度，高光峰值 =
这个值 × HDR 强度。水体与高光的**相对**关系不变，整个画面一起上移。

这一档**只在选了 PQ 系格式时才出现**——HDR10、HDR10+、杜比视界 8.1。HLG 和杜比视界 8.4 是
相对亮度，压根没有绝对锚点可调，摆出来只会让人以为它有用。

按 400 算：满强度峰值 3840 尼特，一块 1000 尼特的屏幕装不下，**必须**在背景和高光之间取舍
——这时上一版加的那条曲线才真正开始起作用，背景会随高光让位。这就是你在杜比视界上看到的
那个表现。

## 请这样调

从默认的 400 开始，两台机器各导一段有明显星芒的：

- 背景够不够亮？不够就往上推（600 接近手机 SDR 白的量级）。
- 高光涌上来时，背景有没有"让开"的感觉？没有就说明还不够高，屏幕仍然绰绰有余。
- 往上推之后留意水体亮度会不会跟着内容起伏得太明显——那是让位过头了，往回收一点。

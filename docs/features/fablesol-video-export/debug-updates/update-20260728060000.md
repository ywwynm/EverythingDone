# 你看到的正是动态色调映射；顺带把设置与完成提示改了

## 杜比视界那个表现，是真的"更聪明"

你描述的——**一开始白色卡片背景更亮，等银丝星芒出现之后背景反而暗下去衬托高光**——那就是
逐场景动态元数据在起作用。每一段画面它都告诉显示设备"这一段最亮的东西有多亮、亮度怎么分布"，
显示设备据此重新分配它有限的亮度预算：没有高光时就把背景放亮，高光一来就把背景让出来。

值得说清楚的是，**我们现在给 HDR10+ 的动态元数据里没有这一层**。ST 2094-40 允许附带一条
色调映射曲线，我当时选择不写——因为我们没有任何艺术调整要表达，编一条曲线出来不诚实。但你
这个观察说明：**那条曲线正是产生上述效果的东西**。而它其实是能诚实地算出来的——我们每一帧
都量了峰值、平均和分布，从这些实测数据推一条曲线，不是编，是从测量结果导出的意图。

所以现在的局面是：HDR10+ 的**余量**更大（PQ 满量程 vs HLG 约 3.77 倍），杜比视界 8.4 的
**显示端适配**更成熟。要两头都占，就得给 HDR10+ 补上那条曲线。这件事我想先跟你确认再做，
因为它会改变产物在各种屏幕上的观感，属于"调子"的范畴。

## 设置：HDR 开关并进格式选择

原来的"导出 HDR 视频"开关删掉了——它和下面的格式选择说的是同一件事，摆两处只会让人问
"关掉开关但选了 HDR10 会怎样"。现在只有一处：**「导出 HDR 视频格式」**，第一项就是「关闭」。
设备一种 HDR 格式都编不出来时，列表里就只剩「关闭」，也不用再额外解释开关为什么是灰的。

底部那行推导结果现在会写明**最终落到哪种格式**，比如"视频大小随画面复杂度变化 · 120 fps ·
HDR10+"。那一大堆编码器清单挪到了这行之后——它是排查用的细节，不该挡在结论前面。

## 导出产物：名字和完成提示都带上格式

- 文件名加了格式后缀，例如 `FableSol_1753...._HDR10Plus.mp4`；
- 完成对话框与通知除了格式，还多了**实际码率**。

码率这一项以前在恒定质量档下是给不出来的——那个档位里码率只是个提示。但产物落盘之后，
用文件大小除以时长就是**真实**码率，这才是你真正想知道的那个数。所以现在两种模式下都有。

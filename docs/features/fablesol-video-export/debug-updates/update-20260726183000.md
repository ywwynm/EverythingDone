# 音频附件对话框：计时器控件宽度改为跟随字体

## 进度条与导出图标按数字真实宽度对齐

之前一直在算"控件宽度减数字宽度再折半"，绕了远路。计时器控件本身就知道当前字体下数字的
真实宽度（字距 × 位数 × 高度），只是布局里把它写成了铺满父容器——测量时这个固有宽度会被
丢掉、控件被拉满，数字只好在里面居中，于是控件边界就不等于数字边界了。

现在把计时器改成按内容自适应宽度：控件边界从此就是数字边界，进度条左缘和导出图标右缘
直接贴着它对齐，不再需要任何推算。窄字体、宽字体都自动跟随，因为固有宽度本来就是按当前
字体的字距算出来的。

对话框整体宽度不受影响——它本来就是由计时器的固有宽度撑出来的。

调试版里加了一行对齐日志（`FableSolExportAlign`），万一还有偏差可以直接看到控件边界、
数字边界与父容器宽度这三组数。

# 海浪动画视频导出：按钮尺寸、对齐与配色修正

## 四处修正：FAB 尺寸、时钟内容对齐、进度对话框配色、设置档位标签

**录音对话框的按钮尺寸**

重录和取消现在真的比确认和导出小一圈了。之前它们写的是 wrap_content，而图标素材本身就是
40dp，加上 8dp 内边距正好也是 56dp——和两个 FAB 一模一样大。现在给了它们 40dp 的固定尺寸，
图标缩到 24dp，圆盘明显比 56dp 的确认和导出小。

**音频附件对话框的对齐**

进度条和导出图标现在对齐的是计时器**实际显示数字的区域**，不是它的布局区域。计时器的
宽度由布局给定，数字却是按自己的固有宽度居中画的，两者之间空着一段——按布局边界对齐，
看起来自然就是没对齐。现在按数字的真实左右缘计算，并且导出图标本身也重画了一版，
左右严格对称（之前左边留 4.5、右边留 1.5，本身就是歪的）。

**导出进度对话框**

配色和边距都补上了：进度条、按钮文字和触摸水波纹跟随当前记事的颜色，标题、正文、按钮行
的边距全部改用应用统一的对话框尺寸，与其它对话框一致。

**设置里的档位标签**

60 fps / 120 fps、恒定质量 / 恒定码率这两组标签现在：

- 有触摸水波纹，和面板里其它控件同一套渐变波纹；
- 跟着动画颜色一起变——在调参面板里换色时会同步刷新；
- 选中状态的文字颜色按底色明暗自动取偏黑或偏白，不再是固定颜色（浅色强调色上固定白字
  是读不出来的）。

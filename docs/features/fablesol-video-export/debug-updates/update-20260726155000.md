# 海浪动画视频导出：阴影裁切、对齐失效与配色补齐

## 四处修正：FAB 阴影、时钟内容对齐、进度对话框样式、档位标签文字

**录音按钮的阴影被裁掉**

按钮行是 wrap_content，而 FAB 的高程阴影画在自身边界之外。之前重录和取消一直占位，
阴影还有地方落；改成"停止后才出现"以后，准备状态下整行只剩一个 56dp 的按钮，四周的阴影
就被父容器裁掉了。现在按钮行和对话框根节点都关掉了子视图裁剪。

**音频附件对话框的对齐还是没生效**

原因是改布局的时机不对：之前是在布局回调里同步修改边距，而在布局遍历进行中调用的重新
布局请求会被系统丢弃，等于一次也没生效——所以看到的一直是布局文件里的原始值。现在改到
下一帧再应用。同时把进度条的左右内边距归零，轨道左右缘直接等于控件边缘，对齐计算不再
依赖控件样式给了多少内边距（滑块超出的部分靠关掉裁剪来显示）。

**导出进度对话框**

标题现在跟随记事颜色了，整体结构和边距改为参照应用里其它对话框：根节点上下内边距
18dp / 12dp，标题 20dp 起、18sp 加粗，动作行走统一尺寸。完成状态复用同一套控件，
所以配色和边距一并生效。

**设置里的档位标签**

选中项的文字颜色现在切换时也会自适应了。之前只在打开对话框时对：渐变强调色会在文字画笔上
留一个渐变着色器，直接改文字颜色盖不住它，所以切换选中状态后文字还是渐变色。现在选中项
走和普通文字同一条纯色路径，那条路径会先把着色器清掉。

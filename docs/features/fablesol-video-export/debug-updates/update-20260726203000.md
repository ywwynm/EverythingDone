## 本次修正

### 完成态显示实际产物信息

导出完成 Dialog 不再只显示 HDR/SDR 与帧率，现改为四行结果：

1. 导出完成；
2. 规格：HDR/SDR、实际帧率；
3. 视频大小：成功提交后的实际文件大小；
4. 位置：最终公共相册路径与文件名。

`FableSolExportSink` 在 `commit()` 完成后读取最终大小。API 29+ 优先查询
`MediaStore.Video.Media.SIZE`，取不到时再读取文件描述符的 `statSize`；旧系统读取最终文件
长度。位置优先使用真实路径，分区存储不提供路径时回落到
`Movies/EverythingDone/文件名`。数据随 `FableSolVideoExportBus.State.Done` 传递，Dialog
不根据码率估算大小。

### 恢复分享与添加附件两个操作

视频成功时已经默认提交到系统相册，因此移除上一版冗余的「保存到相册」入口。完成态不再
另开三行 Dialog，而是回到导出 Dialog 自身的两个横向按钮：

- 分享；
- 添加到附件。

两个按钮不区分主次，文字及触摸涟漪都使用当前记事的完整 `ThingBackground`，纯色与渐变
均可正确显示。上一版为 `ThreeActionsAlertDialogFragment` 增加的自定义第三操作扩展已经
完全撤销。

13 套语言的四行完成文案已同步。源码反馈回路、`:app:testDebugUnitTest` 与
`:app:assembleDebug` 均通过，未使用 adb。

# 勾选框统一改用强调色描边与自适应对号

## 本次更新

**未选中的勾选框改用完整强调色描边，不再是中性灰。** 描边保留渐变的起止色与方向，且为完全
不透明——2dp 宽的描边一旦降低透明度就会显得发虚。选中态仍是完整渐变填充。

**选中态中间的对号颜色改为按填充色自适应。** 此前固定为白色，在明黄一类浅色强调色上几乎
看不出来；现在按填充色的明暗取偏黑或偏白。该修改对应用中所有勾选框生效。

**上述外观已统一应用于三处**：音频海浪动画设置中新增的「保留录音过程中可能的画面倾斜」、
同一面板底部的「屏上性能面板」（调试构建可见），以及设置界面的全部十三个勾选框。这三处的
整行触摸涟漪与勾选框自身的圆形涟漪同样使用完整渐变，并随强调色变化实时更新。

音频海浪动画设置面板中的三种勾选行原本各有一份实现，现合并为同一份，行高、内边距与涟漪
行为完全一致。

请确认三处勾选框在选中与未选中两种状态下的描边、对号和涟漪，以及切换记事颜色后未选中状态
是否仍保持渐变描边。

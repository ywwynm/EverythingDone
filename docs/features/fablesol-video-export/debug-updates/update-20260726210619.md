# 导出完成通知与海浪图标优化

## 用户反馈

1. 导出完成后的系统通知需要与完成 Dialog 展示相同信息，包括 HDR/SDR、实际帧率、
   实际视频大小和保存位置。
2. 导出海浪视频图标保留画框，但内部海浪不能再像尖锐山峰。

## 分析与修改

- `FableSolVideoExportService` 原先为通知单独拼接规格摘要，只包含 HDR/SDR 和帧率；
  完成 Dialog 则读取 `FableSolVideoExportBus.State.Done` 中的大小和位置，因此两处数据源
  与文案存在分叉。
- 现在 Service 先构造并发布唯一的 `Done` 状态，通知随后直接读取该状态，并复用 Dialog
  的 `fablesol_export_dialog_done` 四行文案；通知查看、分享所用 URI 也改为来自同一状态。
- `act_fablesol_export_video.xml` 保留原有圆角视频画框，把内部 2.5dp 高振幅实心波带改为
  1.8dp 圆头描边的低振幅开放贝塞尔水波。
- `FableSolExportPipelineSourceTest` 新增完成信息同源和图标结构回归约束。

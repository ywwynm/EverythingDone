# 视频导出：第三轮评审后的修复

## 又修掉八处问题，其中三处是会直接导致导出失败的

**Android 8/9 上根本写不出文件。** 导出想写进公共的影片目录，但这需要一个写入权限，而本应用
从来没有在运行时向你申请过它——全新安装的旧系统设备上，导出会直接失败。现在没有该权限时
改写应用自己的影片目录，同样能被相册扫描到，也不用弹权限框。

**Android 14 上的 HDR 被静默关掉了。** 上一版新加的 HDR 能力检查用了一个 Android 15 才有的
标志，Android 14 上一律返回"不支持"，于是所有 HDR 编码方案都被筛掉、悄悄降成了 SDR。现在
只在 Android 15 及以上才用这个标志，更早的系统靠实际尝试来判断。

**连续导出仍可能被上一个任务停掉。** 上一版把"要不要收尾"的判断放进了锁里，但**执行**还在锁
外：判断完到真正收尾之间如果来了新任务，旧任务照样会释放新任务的唤醒锁、并停掉整个服务。
现在唤醒锁改为每个任务各持各的，停止服务也改用带编号的方式——期间来了新任务，这次停止请求
会被系统直接驳回。

**两个导出排队时会串。** 之前进度对话框认不出是哪个任务：第二个导出排队时会显示第一个的
进度，第一个完成后还会给出它的分享按钮——你以为在分享第二个，实际是第一个。现在每个导出
有自己的编号，对话框只认自己那一个，排队中显示"准备中"。

**提交失败仍报成功。** 让产物在相册里可见这一步如果失败，视频会一直处于未完成状态、相册里
看不到，界面却报导出成功。现在这一步是成功流程的一部分，失败就如实报失败并清理。

**播放和导出的开头不一致。** 上一版让导出跳过了防麦克风杂音的那道门，但文件播放路径没跟上，
同一个文件在这两个地方的开头表现会不一样。现在统一：只要输入是文件，两边都不走那道门。

**降级尝试会泄漏图形资源。** 尝试某一档时若编码器启动失败，已经建好的图形上下文没有被释放，
连试几档会越攒越多。已修。

**系统超时会被显示成"已取消"。** 后台处理达到系统时限时，最终提示会被随后的"已取消"覆盖，
让人以为是自己点了取消。现在会明确显示是达到了系统时限。

另外补了一个自动化检查，把"120fps 每帧正好推进一个物理步、60fps 正好两个"钉死，防止以后
有人改回上一版那个会导致顿挫的写法。

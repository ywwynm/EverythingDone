# 海浪动画视频导出：交互与设置修正

## 按钮布局、进度对话框与导出设置的一轮修正

**录音对话框**

录音按钮重新居中了。准备与录音状态下整行只有它一个，重录、导出、取消三个按钮要等停止
录音之后才出现——之前它们虽然透明但一直占着位置，加进导出按钮后就把录音按钮挤偏了。
导出按钮现在和确认按钮一样大，两者都比重录和取消大一圈。

**音频附件对话框**

进度条左端和上方计时器左端对齐了，导出图标的右端也和计时器右端对齐（对齐的是图标本身，
不是按钮的点击区域）。导出图标的颜色和按下时的水波纹改为跟随对话框背景，之前错误地跟随
了记事颜色——这枚按钮属于界面本身，不属于记事。

**导出过程**

点导出后会先弹出一个进度对话框，里面有进度条和剩余时间，下方是「取消」与「在后台运行」。
点「在后台运行」只是关掉这个对话框——导出**全程都在后台跑**，通知栏也一直有通知，这一点
从头到尾没变过，对话框只是让过程更直观。

如果导出结束时这个对话框还开着，它会就地变成完成状态，可以直接「分享」或者「添加为附件」。
通知也改了：标题现在是「导出音频海浪动画视频」，进行中带取消按钮，完成后带分享按钮。

**设置**

设置里的「音频海浪动画参数调节」改名为「音频海浪动画设置」。

视频导出这一组改了不少：

- 帧率和码率模式改成明确的二选一：60 fps / 120 fps，恒定质量 / 恒定码率。
- 选恒定质量时显示「质量参数（CQ）」的实际取值和本机的可选区间，并隐藏目标码率；
  选恒定码率时反过来。设备不支持恒定质量的话，这两项都不出现。
- 新增「导出 HDR 视频」开关。要真的导出 HDR，需要这个开关打开、HDR 强度不在关闭档、
  且设备有对应的编码能力，三个条件同时满足。
- 底部的推导行加了「约」字，并且**恒定质量模式下不再给体积估算**。

关于之前那个体积数字离谱的问题：公式本身没错，问题在于默认走的是恒定质量模式，那个模式下
码率设置只是给编码器的提示，实际体积由画面复杂度决定（实测大约每分钟二十几 MB，而不是
面板说的 180 MB）。所以恒定质量模式下现在改成显示「体积随画面复杂度变化」，只有切到恒定
码率模式才给具体数字。

另外说明一下命名：Android 的质量参数既不是 x264 的 CRF、也不是编码器内部的 QP，而是各家
厂商自己映射的一段区间，只保证数值越大质量越好。所以界面上按原值显示并标出区间，标签写
「质量参数（CQ）」而不是 CRF 或 QP——叫后两个名字容易让人照搬 x264 的经验值，反而会调错。

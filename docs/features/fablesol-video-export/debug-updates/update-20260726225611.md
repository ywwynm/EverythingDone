# Material 导出图标与 HDR 探测缓存

## 本次更新

- 导出视频图标不再使用海浪，改为 Google Material Symbols Outlined 的
  `video_frame_save`。保留官方播放三角和保存箭头，把顶部中央、左侧中央的取景框缺口补齐，
  使上边框和左边框连续完整；播放 Dialog 仍使用当前记事的完整颜色或渐变。
- 确认此前 HDR 实编码虽然运行在后台线程，但每次打开“音频海浪动画设置”都会立即重新创建
  视频/AAC 编码器、10-bit HLG EGL、最大尺寸 FP16 场景缓冲并编译整套水体 renderer，
  会与 Dialog 首帧和实时预览争用 GPU、codec 与内存带宽。
- HDR 能力结果现在按探测实现版本、App 版本、Android API 和系统 build 持久化。成功结果在
  签名不变时长期复用；失败结果缓存 24 小时，避免临时资源占用导致永久误判，也不再每次
  打开都真实编码。进程内缓存可立即恢复。
- 首次未缓存的解析延后到 Dialog 首帧之后，并在后台低优先级线程运行。实际探测继续验证正式
  HDR 视频编码器、RGB10_A2 BT.2020/HLG EGL、AAC/MP4 封装及最终输出格式，但不再编译整套
  水体 shader 或分配完整场景 renderer；正式导出仍会验证实际 FP16 scene targets。
- CQ 质量范围的 codec 枚举结果（包括“不支持”）增加进程缓存，重复打开设置时不再同步
  枚举。
- HDR 导出不可用时，标签追加与顶部 HDR 高光增强相同的本地化“设备不支持”提示；标签保持
  enabled 文本色并使用相同的 `0.5` alpha，不再叠加系统 disabled 色和整行 `0.38` alpha。

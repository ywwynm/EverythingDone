# 说明行跟着选项走；恢复默认不再为了恒定质量降帧率

## 本次更新

两处都是你昨天在真机上看设置页时提出的。

**一、没有这个选项，就不再显示它的说明。**

恒定质量下「复杂帧质量保护」那一行本身是隐藏的（这项保护只作用于目标码率），但它下面那行说明
仍然写着，界面上留着一段没有归属的文字。现在这行说明与选项本身共用同一个判据，一起隐藏。

顺便把这一组的**全部十一行说明**核对了一遍，只有上面这一处有问题：色调映射方式、视频位深、
HLG 信号范围、漫反射白、参考显示峰值、高光起点这六行早就按条件收起；高复杂度编码、启用 B 帧
编码、关键帧间隔三行的选项始终显示，说明随之常显；编码模式那一行是**置灰而不是隐藏**，所以
它的说明也该常显，只是文案在两种模式与「无精确规格」之间切换。

导出完成信息一侧本来就是对的：它写的是**本次真的向编码器申请了什么**，恒定质量下不会声称
启用了这项保护。

**二、「恢复默认」不再为了保住恒定质量而降帧率。**

此前如果本机在 120 fps 下没有恒定质量通路，点「恢复默认」会退到 **60 fps 的恒定质量**——拿一项
真实的规格损失，换了一项本可无损替代的偏好：恒定质量编不出来时，把目标码率调高同样能提升
画质。根因是设置页在修正不成立的组合时只考虑格式、编码器、帧率三条轴，编码模式被当成了不可
更改的前提。

现在编码模式也参与修正，而且**第一个让步**；帧率**最后让步**。完整的让步顺序是：

```text
编码模式 → 编码器族 → 输出格式 → 帧率
```

同一个改动还修掉了一处方向相反的旧权重：设置页原先宁可降帧率也要保住输出格式，与既定的
「帧率固定 → 保持格式与位深 → 再换编码器族」正好相反，而那份顺序本来就要求设置页与导出过程
中的建议规格共用。所以现在同一台设备上，帧率的优先级高于 HDR 格式，格式高于编码器族，编码
模式排在最后。

正式导出期间的严格性没有放松：编码模式仍是公开规格之一，导出开始后不会被静默换掉；上面说的
只是设置页在当前组合不成立时如何收敛到一个确实可用的组合。

**请确认**：在 120 fps 下没有恒定质量通路的那台设备上点「恢复默认」，帧率应停在 120 fps 而
编码模式落到「目标码率」；以及恒定质量下「复杂帧质量保护」那段说明确实不见了。

全量单元测试 78 个套件、544 例、0 失败、1 例按既有条件跳过；本轮未安装到设备，未生成新样片。

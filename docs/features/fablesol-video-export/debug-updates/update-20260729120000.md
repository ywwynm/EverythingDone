# 倾斜选项改为勾选框；未选中描边同样使用渐变

## 本次更新

**「保留录音过程中可能的画面倾斜」改为勾选框。** 音频海浪动画设置「视频导出」组的第一项
原为「保留 / 忽略」两个档位胶囊，现改为整行可点的勾选框，默认开启。胶囊适合若干并列的
档位，而这一项是一个是非开关，用两个胶囊表达等于把二值伪装成多选。

**该勾选框在两种状态下都跟随记事的强调色。** 选中态为完整渐变填充加白色对号；未选中态
不再使用中性灰描边，而是用同一条完整渐变描边并整体降低透明度，因此换色时仍能看出渐变
方向。整行触摸涟漪与勾选框自身的圆形涟漪同样使用完整渐变，换色动画的每一档都会更新。
未选中态使用渐变是该入口专属的行为，应用中其余勾选框的外观不变。

关闭该项后，导出不再读取录音时记录的重力轨迹，画面按竖直渲染，与本功能之前没有轨迹的
历史录音走同一条路径。它只对本应用录制的音频有意义：只有这些录音的文件中带有重力轨迹。

**深色模式下导出的卡片同样为深色**（上一版起）。画框底色、卡片底色与计时时钟的深色适配
现在同源，均按应用实际生效的深浅色判定，不再出现画框已变深而卡片仍为白色的情况。

深色与浅色两种模式下的产物外观，以及勾选框在两种状态下的着色，请在真机上确认。

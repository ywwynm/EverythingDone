# 音频附件对话框：对齐换挂载点 + 上边距加大

## 进度条与导出图标对齐计时器数字

上一版里两者其实都还停在布局文件写死的位置上——那段按数字真实边缘计算的对齐代码**一次
都没跑起来**，导出图标看着接近对齐只是因为它多了 8dp 内边距，凑巧落在差不多的位置。

原来的做法是挂在计时器自己的布局回调上、再延到下一帧应用。这个对话框的宽度是由内容撑出来
的，测量要反复好几轮，单次回调很容易落在还没定型的那一轮上，于是就再也没有机会修正。现在
改成挂在整棵视图树的全局布局回调上，每次布局都重新核对一次，位置稳定后自然不再改动。

同时把布局文件里的基线边距也校正成 24dp（与计时器一致），这样即使运行时计算没能生效，
初始位置也是对的。

进度条和导出图标的上边距各加大了 10dp。

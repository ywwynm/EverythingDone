
# 重写设置中的 HDR 文案

## 文风

去掉第一人称、口语表述与破折号，改为客观陈述。原文案中如"我们的峰值是算出来的""最亮的一段
不用压""代价是……就看不出区别了""要分享给别人就选 8.1"等写法均已重写。

## 一并修正的两处过期内容

**HDR10 的说明写死了 203 尼特。** 漫反射白已经是可调参数，峰值应表述为由漫反射白与 HDR 强度
共同决定，而非引用一个固定数值。

**HDR10+ 的说明仍称「膝点」。** 该术语已改名为「高光起点」，说明文字未同步。

## 一处真实缺陷

Profile 5 的说明中使用了 Markdown 粗体标记。Android 的字符串资源不解析 Markdown，星号会原样
显示给用户。已去除。

## 国际化

十三种语言全部重写，不是仅改中文。法语与意大利语中的撇号按 Android 资源规则转义；简体与
繁体分别使用各自惯用的技术术语。

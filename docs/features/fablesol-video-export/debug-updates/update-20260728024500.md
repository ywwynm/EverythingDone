# FableSol 视频导出：修复导出完成时闪退；编码器说明写明落点

## 2026-07-28 修复完成通知导致的闪退；编码器说明补齐落点与取舍

**修复导出完成后闪退。** 华为平板（EMUI，Android 12）上视频已经写完并入库，进程却在发送完成
通知这一步崩溃：通知栏的分享按钮由 `Intent.createChooser` 携带媒体 URI 构建，而
`PendingIntent.getActivity` 会在构建时立即执行一次 URI 授权，该设备拒绝授权并抛出
`SecurityException`。授权被拒的原因位于厂商实现，无法从应用侧改变；但产物本身完好，通知也
完好，因此现在授权失败时仅省略分享按钮。打开产物的跳转与通知发送同样各自兜底。对话框中的
分享不受影响。

**编码器胶囊下方的说明改为随选择变化。** 此前是一段固定文字，选「自动」时看不出这台机器上
究竟挑中了哪个编码器，也看不出是硬件编码还是软件编码。现在这段说明写三件事：该档位的特点
（HEVC、AV1、H.264 各有独立描述，与 HDR 格式说明形式一致）、当前实际使用的编码器并标明硬件
或软件、以及灰色选项的含义。该结论随输出格式与帧率变化，三条轴任一变更后都会重新解析。

**推导文字的版式调整。** 结论行改为加粗，并与其后的推导过程之间空一行；推导过程与设备能力
报告之间不再留额外间距，两者连成一段完整报告。

# 导出可关闭手机倾斜；深色模式下导出深色卡片

## 本次更新

**导出时可以不加入手机倾斜。** 音频海浪动画设置的「视频导出」组新增第一行「录音时的手机
倾斜」，可选「保留」或「忽略」，默认保留。选择忽略后，导出不再读取录音时记录的重力轨迹，
画面按竖直渲染，与本功能之前没有轨迹的历史录音走同一条路径。倾斜属于画面内容而非编码
参数，因此排在该组最前。该选项只对本应用录制的音频有意义：只有这些录音的文件中带有重力
轨迹，导入的音频本来就没有倾斜可言。

**深色模式下导出的卡片同样为深色。** 此前即使应用处于深色模式，导出视频也只有外侧画框是
深色，中间的卡片恒为白色。原因不在取色逻辑，而在于取色所依据的 Context：卡片底色取自主题
的 `colorBackground`，屏幕上这份主题来自对话框，会随深浅色切换；而导出运行在前台服务中，
拿到的是应用级 Context，它使用平台默认的浅色主题，其 `colorBackground` 与夜间资源无关，
同时它的界面模式配置也读不到应用自身的深色设置。画框恰好绕开了主题，所以只有画框变深。

现新增导出专用的外观解析：先按应用**实际生效**的深浅色钉住界面模式，再套用对话框主题，
导出全程只使用这一个 Context。画框底色、卡片底色与计时时钟的深色适配三者从此同源，不会
再各判各的。一并修正一处原有的不一致：当应用固定为浅色而系统处于深色时，画框此前会被
判成深色，与界面相反。

深色与浅色两种模式下的产物外观请在真机上确认。

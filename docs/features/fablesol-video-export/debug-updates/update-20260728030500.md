# FableSol 视频导出：不再接受产出为空的编码器

## 2026-07-28 补上「必须真的产出视频样本」这道门

华为平板上每一档 HEVC 都导出成 0 字节文件，SDR 与 HDR、60 与 120 fps 皆然，只有 H.264 有数据。
原因是此前的验证判据不完整。

`INFO_OUTPUT_FORMAT_CHANGED` 一到达即可向封装器登记轨道并启动封装，此后即便编码器一个实际
样本都不产出，收尾流程依然会正常走到流结束并成功返回。能力探测与正式导出都以此为准，于是
一个不报错也不产出的编码器被判为「验证通过」，产物是空文件。

该机的具体成因：带 `EGL_RECORDABLE_ANDROID` 的 10 位窗口 config 数量为 0。该属性决定缓冲
是否带视频编码器用途位，缺少时编码器无法消费这些缓冲。而 SDR 通路的首选档位是 HEVC Main10，
同样使用 10 位表面，因此关闭 HDR 也无法回避；H.264 属于 8 位档位，走另一条 config，不受影响。

**现在以实际写入的视频样本数作为硬性门禁**，能力探测与正式导出两处都验；样本计数正常但落盘
仍为空时，发布前再核对一次文件大小。任一不通过即判该候选失败，由降级阶梯换下一档，因此该机
会自动落到 H.264，而不是产出空文件。

能力探测契约版本升至 10，旧结论作废并重新验证。

# FableSol 视频导出：记录 10 位表面编码能力位

## 2026-07-28 补记平台自身的 10 位表面编码回答；收敛无效重试

三星 Z Fold4 上的枚举结果已经确定：该机共有 4 个 10 位窗口 EGL config，**带
`EGL_RECORDABLE_ANDROID` 的为 0 个**。因此上一版的枚举修复对该机不起作用，
`eglChooseConfig` 此前的匹配结果是准确的。结合编码器不支持 P010 字节缓冲输入这一点，
该机的硬件 HEVC 编码器在公开接口上没有任何可用的 10 位输入通路，HDR 只能由软件 AV1 承担。

**新增「10-bit 表面编码能力」一节**，直接列出编码器自身的回答：是否接受
`COLOR_Format32bitABGR2101010` 输入，以及 `hdr-editing` 与 `hlg-editing` 两个能力位。这一节
仅作记录，判定仍然只认真实编码结果。

**重试收敛。** 同一编码器族内只重试一次：第一个候选重试后仍失败即说明不是「编码器当时被
占用」，继续逐个重试只会拖长探测时间。

**失败原因中的换行统一压平**，避免报告版式被撑散。

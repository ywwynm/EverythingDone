# FableSol 自动漫反射白按屏幕能力与 HDR 强度自适应

## 用户需求与分析结论

用户在比较 HDR10+、Dolby Vision 8.4、HDR10 与 HLG 样片后，要求修改此前“屏幕峰值四分之一”
的自动漫反射白：不能把建议值 350 尼特写成常量，而要根据每台设备的屏幕亮度能力、当前
HDR 峰值强度等参数自适应，并在 FableSol 设置 Dialog 下方的规格/编码信息中说明计算方法。

此前对 200/500/800 尼特 HDR10+ 样片的 FFmpeg 逐像素分析确认，800 尼特样片的基础颜色比例
基本正确；偏白、偏亮、偏浅主要来自高绝对白锚、高帧平均亮度与约 7680 尼特母版峰值共同
触发显示端亮度和色容积映射。旧公式在约 2000 尼特屏幕上给出 500 尼特白锚，默认 9.6 强度
下母版峰值仍达 4800 尼特，而且没有考虑最大帧平均亮度能力。

## 实现

- `FableSolExportDisplayLuminance` 同时读取并校验 Android
  `desiredMaxLuminance` 与 `desiredMaxAverageLuminance`。
- 自动公式改为：

  ```text
  raw = min(屏幕峰值 × 1.75 ÷ HDR 强度, 最大帧平均亮度, 400)  // 仅列入可用约束
  autoWhite = floor(clamp(raw, 200, 400)÷25)×25
  ```

  缺一项屏幕能力时忽略该约束；两项都不可用时回退 400 尼特。默认 9.6 强度、2000 尼特
  屏幕会算得 350 尼特，350 是该输入组合的计算结果，不是固定值。
- 自动档随 HDR 强度滑杆实时重算漫反射白滑杆、漫反射白结果和母版峰值；用户手动拖动
  漫反射白后不再自动改写，点击“恢复默认”才重新进入自动档。
- PQ 格式的规格/编码推导文字补充完整公式；手动档明确说明当前为手动值。设备诊断增加
  屏幕峰值、最大帧平均亮度、HDR 强度、自动结果与安全回退标记。
- 13 套语言资源同步新增自动公式和手动状态说明。

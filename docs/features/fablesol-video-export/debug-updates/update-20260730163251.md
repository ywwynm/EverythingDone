# FableSol 视频导出评审修复批次

## 2026-07-30 - 导出全链路评审修复：失败处理、HDR 元数据、编码器兼容与设置页说明

本次更新落地 D62～D184 全量实现评审的 29 项修复与 7 项裁定，覆盖导出失败处理、HDR
元数据正确性、编码器兼容阶梯与设置页说明。

**失败处理与重试**

- 导出失败 Dialog 与失败通知新增「调整导出设置」操作：一键打开 FableSol 设置并定位到
  视频导出组；环境性失败（空间不足等）不显示该入口。
- HDR10+ 场景亮度接近参考显示峰值 10 倍的可行组合不再被误判失败；参考峰值确实不可行时，
  给出专门的失败类别与两个可操作数值（实测场景峰值、最低可行参考峰值），同格式其余规格
  一并判定，不再逐个确认、重复全片预分析。
- 「无完整输出规格」的正式说明现在直达失败提示，不再被通用内部错误文案替换。
- 编码器初始化被拒时的自动退让：申请 B 帧被拒改以 0 B 帧重试；无探测结论回退的纯恒定
  质量被拒改以恒定质量加码率提示重试——均为同规格内部重试，不打扰确认流程。

**HDR 元数据与画质**

- HLG 扩展信号范围的回环验证与正式导出使用同一码控形态，验证结论按完整签名缓存；瞬时
  失败（临时文件、编码超时）不再永久锁定名义范围。
- FP16 呈现中间面不可用时，HLG 自动增强在首帧前降为名义范围并如实标注，完成信息不再
  错报「扩展信号范围」。
- HDR10/HDR10+ 静态元数据：亮度统计的 16 位量化改上取整，MaxCLL/MaxFALL 恢复严格上界；
  正式产物封装后追加诊断性核对，容器元数据与预期不一致时在完成信息如实说明。
- HDR10+ 动态元数据 SEI 逐样本计数：覆盖率进设备诊断，覆盖不完整时完成信息如实说明；
  统计通路新增已知图自检，异常时回退备用通路。
- 完成信息新增膝点可行域调整说明与高亮像素比例未计算说明。

**SDR 与渲染**

- 蓝噪声抖动资源异常时正确回退到三角哈希，不再产生全帧亮度偏置。
- 动态映射统计通路（含着色器编译）任一环节失败均从第 1 帧改用稳定映射并如实标注；
  设置页探测到通路不可用时置灰并说明原因。

**设置页与说明**

- B 帧不适用时按具体原因说明：系统低于 Android 10、AV1、H.264 Baseline 三种情形分别
  给出正式文案；Android 8～9 恒以低延迟约束阻止编码器自行产生 B 帧。
- HLG／杜比视界 8.4 的信号范围设置新增本机预计落点（已验证扩展／将用名义／首次短验证）；
  杜比视界 8.4 明确说明该设置只作用于 HLG 兼容基层，不是开关杜比动态元数据。
- 高复杂度编码增加探测兼容阶梯：编码器拒绝最高档时省略该键、以厂商默认继续原格式；
  复杂帧质量保护开启时 Level 码率定档加入保守余量，产物声明不再可能被码率上浮击穿。
- 首次打开设置页会整份重探一次编码能力矩阵（探测契约升级，属预期现象）；低帧率结论只
  承袭同一编码器实现的高帧率结论，实现不同（例如硬件仅支持 60 fps）时单独实测。

全部改动经 FableSol 76 个 JVM 测试套件 545 例强制重跑验证，0 失败。13 套语言文案同步。

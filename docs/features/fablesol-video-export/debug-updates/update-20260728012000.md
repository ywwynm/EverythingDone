# FableSol 视频导出：10 位表面改为枚举 EGL config；报告支持复制

## 2026-07-28 定位到 EGL_RECORDABLE_ANDROID；设备能力报告可长按复制

三星 Z Fold4 上 SDR 通路通过验证的是 **HEVC Main SDR**，即 8 位那一档；10 位的
HEVC Main10 SDR 同样失败。结合「10-bit 窗口配置：RGB10_A2」这一行可以定位：该机上带
`EGL_RECORDABLE_ANDROID` 的 10 位 config 没有取到，程序退到了不带该属性的一档，随后所有
10 位编码一律以编码器「已被释放」告终。

`EGL_RECORDABLE_ANDROID` 决定分配出来的缓冲带不带视频编码器用途位。缺少该属性时，交给
`MediaCodec` 输入表面的缓冲编码器无法消费。此前代码将其视为「给驱动的提示」并直接降档，
判断有误。

**config 选择改为在匹配落空后自行枚举。** 该属性属于厂商扩展，部分驱动不将其纳入
`eglChooseConfig` 的匹配条件，却可以通过 `eglGetConfigAttrib` 正常读取。现在匹配不到时会
枚举全部 config 逐项核对，因此有机会取到此前拿不到的那一档。

**能力报告新增 10 位 config 的清点**：共有几个 10 位窗口 config、其中几个带 recordable。
这两个数直接决定 10 位编码在该设备上是否成立。

**设备能力报告支持复制。** 长按「视频大小随画面复杂度变化」那一段或下方的设备能力信息，
即可一次复制两段全文。

能力探测契约版本升至 9，旧缓存作废并重新验证。

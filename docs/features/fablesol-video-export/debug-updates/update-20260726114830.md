# FableSol 可视化视频导出

## 新功能：把音频附件导出成一段 FableSol 水体视频

音频附件现在可以导出成一段视频：画面是这段音频的 FableSol 水体，带计时时钟和圆角卡片，
自带这段音频的声音，设备支持时是 HDR。

**两个入口**

- 录音停止后，对号按钮右侧多了一个「保存并导出视频」按钮：先照常保存录音，再立刻导出。
- 点音频附件卡片进入播放对话框后，进度条右侧的图标按钮同样可以导出。

两处出来的产物完全一致——构图与从哪个入口触发无关。设备不支持 GLES 时两个按钮都不出现。

**产物**

- 落在系统相册的 `Movies/EverythingDone/`，不会自动挂成记事的附件。
- 画面是水体卡片加一圈留边，留边底色跟随深浅色模式，卡片带投影和一条发丝描边。
- 优先 120fps（与水体物理的 1/120 步长正好 1:1），编码器不支持则 60fps。
- 优先 HEVC Main10 + HLG；不支持就依次退到 AV1、10-bit SDR、8-bit HEVC、H.264，
  落到 8-bit 时自动重新启用抖动防色带。
- HDR 亮度取你在波浪调参里设的 HDR 强度，**不取导出时屏幕的实际余量**——文件里存的是
  作者意图的亮度，还原交给播放端。因此屏幕不是 HDR 的设备也能导出 HDR 视频。
- 波浪调参里 HDR 强度拉到最低（关闭）时，导出走 FableSol 自己的 SDR 渲染，而不是把 HDR
  结果压回 SDR。

**导出过程**

导出跑在前台服务里，通知栏显示档位、进度和实时更新的剩余时间，随时可取消。可以退出
对话框、切后台、锁屏，导出照跑完。同时只跑一个，第二次点击排队。

时长没有上限，所以要有心理准备：120fps 下**每秒音频约需 1 秒渲染**，一分钟录音约一分钟，
二十分钟录音可能跑二十几分钟（还会因为发热降频更久）。体积按默认码率约 180 MB/分钟。
剩余空间不够会在开始前直接报错。

**录音侧的变化**

录音时会顺手把设备的倾斜记进 WAV 自己的一个自定义数据块（约 36 KB/分钟，正常播放器
完全无感），导出时用它复现录音当时水体的倾斜。**本次更新之前录的音频没有这条数据，
导出时水体按竖直渲染**，其余表现不变。

**新增设置**

波浪调参对话框末尾新增「视频导出」分组：帧率上限、恒定质量、质量档、目标码率、
关键帧间隔，并实时显示当前设置下的 MB/分钟与耗时倍率。「恢复默认」会一并重置它们。

**已知未完成**

真机验收尚未进行；码率与质量档的默认值还是推测值，需要用大面积缓变的深色渐变记事实测
校准。HLG 在 SDR 参考白之上只有约 3.77 倍余量，而 HDR 强度上限是 9.6，超出部分目前用
软肩压缩承接，观感需要你在真机上确认。

# FableSol 视频导出：编码器可选，修复 HDR 默认被关闭

## 2026-07-27 编码器成为可选项；HDR 默认不再被误关

**HDR 默认被关闭的问题已修复。** 设置页此前在探测不到可用 HDR 格式时，会把「这台设备编不出
HDR」这个能力结论写进用户偏好，而该写入不可逆：偏好一旦为关闭，之后即便探测重新通过，界面
仍会停在「关闭」并再写一次。三星 Z Fold4 上设备能编 HDR10 与 HLG，默认却是关闭，正是这条
路径造成的。现在能力探测只影响当次显示，不再写入任何偏好。

**新增「视频编码器」选项：自动 / HEVC / AV1 / H.264。** 选项按本机实测的可行组合置灰：选择
任一 HDR 格式后 H.264 不可用（HDR 阶梯中没有 AVC），选择杜比视界后只有 HEVC 可用，当前组合
编不出 120fps 时该档同样置灰。变更其中一项导致另一项不再成立时，后者自动迁到可行取值。

**自动档不再使用软件编码器。** 导出画布接近两百万像素，软件编码与硬件编码的耗时相差一到两个
数量级。此前候选收集完全不区分软硬件，Z Fold4 上一次 120fps 的 HDR 导出因此静默落到了 AOSP
软件 AV1 编码器的 60fps 上。软件实现仍可显式选择，界面与完成信息会标明「软件编码」。

**能力探测改为按用户实际使用的编码模式验证。** 此前固定使用恒定码率，而设置中「编码模式」默认
为恒定质量，两者下发的编码参数并不相同，会出现设置页显示可用、正式导出全档失败的情况。

**能力信息现在写明落点。** 诊断首行改为逐格式列出实际使用的编码器与帧率，例如
「HDR10（AV1，60 fps，软件编码）」，并新增 SDR 通路一行。导出完成对话框、通知与设置页推导
文字统一改为「输出格式 · 编码器」。

SDR 编码阶梯补入 AV1；此前 AV1 只存在于 HDR 阶梯，关闭 HDR 之后无法选择该编码器。

# FableSol 视频导出严格规格、HDR 稳定性与 AV1 画质修复

## 本次更新

本次更新完成视频导出规格约束、运行时失败确认、HDR 全格式实机验收及软件 AV1 画质修复。

- **60 fps／120 fps 现在是严格输出规格。** 色彩模式、编码器族、位深和帧率基于同一组完整
  可行组合解析，设置摘要、选中状态、置灰状态与实际产物保持一致。选择 120 fps 后不会再借用
  仅支持 60 fps 的 HDR10／AV1 结论，正式导出也不会自动改为 60 fps。
- **任何公开规格变化均需用户确认。** 输出格式、编码器族、位深、硬件／软件编码类型或帧率
  任一变化都不会静默重试。前台 Dialog 和后台通知会正式、完整地列出失败规格、分类原因及
  建议规格；只有用户确认后才使用建议规格。点击后台确认通知正文与“使用建议规格”操作执行
  同一幂等命令。
- **同规格内部重试保留必要说明。** 仅具体编码器组件或 P010／Surface 输入通路变化时可自动
  重试；已有可见处理进度时，Dialog 会持续显示完整失败规格、正式失败原因和当前规格。成功或
  最终失败时仍保留最近一次规格调整说明。
- **HDR10+ 采用完整场景统计。** 7 秒动画不再把每帧视为独立场景，而是预分析完整场景后只
  生成一份 ST 2094-40 动态载荷并逐帧重复。曲线横轴使用场景 V8，失效时回退场景 MaxSCL；
  不再使用母版峰值横轴补偿。OPPO 实测的 203／350 尼特样片均为 853 帧、1 份唯一载荷，
  高光活跃时水体亮度没有下降。
- **完成 HDR 全格式 OPPO 实机复核。** HDR10+、HDR10、HLG 扩展／名义范围、杜比视界 8.4
  均完整解码，未检出频繁明暗变化；水体色彩连续，星芒高光保留。另完成 SDR 原生 10-bit／
  8-bit、稳定／动态保留高光映射及 B 帧组合复核。
- **修复 AOSP 软件 AV1 的 HDR 渐变量化块。** OPPO 的 `c2.android.av1.encoder` 在最高
  恒定质量档仍会明显破坏橙色水体渐变；目标码率 VBR 对照未改善，因此没有改变用户编码模式
  或静默切换 HEVC。现在仅在软件 AV1、HDR、最高 CQ 且编码器声明 QP bounds 时申请 QP 上限
  8。复测码率约 1.15 Mbps，明显块状量化消失，仍保持 AV1 Main 10、60 fps、BT.2020/PQ。
- **设置页现在能识别 AV1 的恒定质量能力。** 当前画布只有 AV1 编码器支持 CQ 时，“编码模式”
  行也会正常显示。第二档实际使用 VBR，名称由“恒定码率”统一修正为“目标码率”；完成全部
  13 套语言的正式国际化，实际 CBR 后备结果仍单独明确标注。

已在 OPPO PLZ110 上使用真实音频附件完成导出、FFmpeg／FFprobe 逐帧分析及系统播放器同帧
截图复核。完整 JVM 回归为 78 个套件、539 例测试、0 失败、0 错误、1 例跳过。

# 2026-06-24 DoingActivity 单卡居中修复

- 修复正在做 Thing 从通知栏、记事列表小组件或单一记事小组件打开 `DoingActivity` 时，含图片/视频的卡片偶发贴到屏幕最左侧的问题。
- 根因是 `DoingActivity` 先安装了底部 inset scroll padding 监听，再设置用于居中唯一卡片的 `RecyclerView` 左右 padding。后续系统重新分发 window insets 时，监听会按最初记录的 `0` 左右 padding 覆盖当前 padding。
- 现在 `DoingActivity` 会先通过 `initRecyclerView()` 写入卡片居中 padding，再安装底部 inset 监听；后续 inset 更新只会追加底部安全区，不会清掉左右居中 padding。
- 本地已通过 `:app:assembleDebug` 编译验证，并已发布 debug update `202606241507`；本次未使用 adb。

# Widget 背景媒体比例、单个 Widget 文件夹筛选、详情单媒体默认比例修正

## 用户反馈

- 记事卡片外观为“宽度正常 + 图片/视频作为背景”时，在记事列表 Widget 中会被严重上下拉伸；改成“宽”后正常，其它图片位置也正常。
- 单个记事 Widget 的配置界面会显示完全为空的文件夹，应隐藏。
- 详情页只有一幅图片/视频时，默认实际占整行显示，但自定义外观默认比例仍是 `1:1`；应区分默认行为和用户确认过的设置：单媒体默认满宽 `4:3`，增加第二个媒体后未确认设置的默认行为回退到普通网格 `1:1`，用户确认后才持久化。

## 诊断与修改

- 修正 `AppWidgetHelper.kt`：列表 Widget 网格模式下，普通宽度卡片现在按 slot 实际宽度计算媒体背景、顶部/底部缩略图和 side media 的目标尺寸；全宽卡片继续按整行宽度投影，避免普通宽度媒体背景 bitmap 按整行宽度生成后被半宽/三分之一宽 slot 纵向压缩。
- 修正 `BaseThingWidgetConfiguration.kt`：单个记事 Widget 配置页的文件夹卡片改用 `ThingFolderDAO.getFolderEntriesForWidgetProjection(...)`，只显示当前可选择投影中有正在进行记事内容的文件夹。
- 修正 `DetailAttachmentMediaAppearance.kt`：`grid` 默认比例保持 `1:1`，`fullSpan` 默认比例改为 `4:3`。单媒体的自动满宽仍只是展示默认；只有用户打开外观设置并确认后，当前 full-span 比例才写入 `Detail Attachment Media Appearance`。
- 更新对应 feature 决策文档，记录单媒体默认与用户设置分离、单个记事 Widget 隐藏空文件夹、列表 Widget 网格 slot 宽度投影规则。

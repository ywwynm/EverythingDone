# 2026-06-24 DoingActivity 单卡媒体背景宽度修复

- 修复普通宽度、图片/视频作为背景的正在做记事，从通知、记事列表小组件、单一记事小组件进入 `DoingActivity` 时卡片显示异常过宽的问题。
- 本次排查确认不是入口 Intent 缺少宽度数据，而是媒体背景/遮罩层在根 `CardView` 为 `wrap_content` 时使用 `MATCH_PARENT` 参与测量，并且旧逻辑使用异常的 `CardView.width` 加载背景 bitmap。
- 现在媒体背景、遮罩层和背景 bitmap 都使用卡片内容目标宽度；普通宽度记事会按普通单卡宽度显示，宽卡仍按宽卡目标宽度显示。
- 本地已通过 `:app:assembleDebug` 编译验证；未使用 adb，未做设备视觉验证。

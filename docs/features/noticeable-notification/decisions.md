# 实现决策

## 2026-10-13 — 通知完整显示两种宽度的清单

`NoticeableNotificationActivity` 的适配器覆盖 `getThingCardChecklistMaxItemCount()`，普通与宽卡片均返回不限数量。替换只影响普通宽度的 `setChecklistMaxItemCount(-1)`，不修改首页或其它界面的显示数量策略。

历史依据：2026-05-30 的 `03ccb4894` 引入宽卡片固定 12 项分支，通知原有的不限数量设置没有覆盖该分支。

## 2026-10-13 — 有限高度优先保留标题与操作栏

通知列表保持 `wrap_content` 并增加纵向权重。内容较短时窗口随内容收缩；窗口高度不足时由 `LinearLayout` 收缩列表，保留固定标题与操作栏，列表内部正常滚动。保留现有宽度 1.2 倍的列表高度上限，不改变粒子动画或其它弹窗。

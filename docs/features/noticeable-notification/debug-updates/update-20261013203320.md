## 修复更突出的记事提醒通知中宽清单滚动与横屏按钮显示

用户反馈通知弹窗中的记事似乎不能上下滑动，并要求覆盖图片／视频各封面位置、特殊比例、音频和清单等情况。

排查发现两处具体问题：宽卡片仍使用固定 12 项清单上限，通知原有的“不限数量”设置没有生效，后续清单未进入滚动区域；横屏高度不足时，列表占满窗口，把底部完成、开始做事、延迟等操作按钮挤到窗口外。

`NoticeableNotificationActivity` 现在对普通和宽卡片统一完整展示清单；`activity_noticeable_notification.xml` 让列表在高度不足时收缩，为标题与操作栏保留空间。首页卡片数量设置与通知粒子动画保持原有行为。

OPPO OPD2515、三星 SM-S9180、魅族 20 Infinity 各 39 场景、共 117 项真实窗口回归全部通过。覆盖普通／宽清单、图片和视频的上／下／左／右／背景封面、宽高比 0.129／6.9、音频及组合附件、横屏和短内容；同时验证从封面区域起手拖动。60 项清单可滑到最后一项，横屏操作栏完整可见，普通竖屏与短内容尺寸不变。测试仅使用虚构记事，结束后已清理。

特殊封面比例未复现独立的手势失效；本次修复针对已取得实测证据的两处问题。

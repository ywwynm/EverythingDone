## 支持选择点击记事通知后的打开界面

按本次需求，在设置页“更突出的记事提醒通知”下方增加“点击记事通知后打开”。沿用现有选择对话框，可选择“记事详情”或“更突出的记事通知”；确认后立即保存并更新右侧文字，取消不修改，默认保持打开详情。新增文字覆盖应用全部 13 套语言，沿用各语言的记事术语。

`SettingsActivity` 和 `activity_settings.xml` 接入新设置；`ThingNotificationClick` 为通知正文生成独立 PendingIntent 身份，在 `AuthenticationActivity` 中按点击时的最新设置打开目标。已生成通知也能跟随之后修改的设置。通知操作按钮、小组件、快捷方式和正在做事入口继续沿用原流程。

通知弹窗复用 `NoticeableNotificationActivity` 的共用对话框与粒子进入动画。开启进入粒子动画时正常播放，关闭时直接显示。定时习惯通知保留本次提醒 ID 和时间；自动提醒与常驻记事通知也支持新选项。关闭弹窗不移除常驻通知，普通记事和通用习惯支持对应动作；私密正文继续遮蔽，查看和操作继续走现有身份验证。

本地构建与全语言资源检查通过。一加 15T、三星 S23 Ultra、魅族 20 Infinity 各 11 项、共 33 项合并验证通过，覆盖用户指定四个连接入口；一加的 USB `3B1629006YC00000` 与无线 `192.168.100.184:36007` 属于同一设备。验证包含设置确认／取消／持久化、默认详情、已有通知切换、实际通知栏点击、进入粒子开关、习惯参数、常驻通知保留、私密遮蔽及过期通知退出。原业务数据摘要一致，临时记事已清理，测试设置已恢复。

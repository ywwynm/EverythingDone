# 临时原型：连续布面与同曲面粒子化

问题：参考动画的整体运动是否应先建模为一张保持拓扑连通、逐步解除平面约束并受风卷起的
薄面，再把粒子化作为同一薄面的材质转换？

本原型已经接入粒子化，两个变体通过 `?variant=A|B` 切换：

- A：贴附主体先保持原位，已脱附边缘向左上局部牵伸，中段仅保留局部折叠，后段保持朝向随风离场；
- B：单一圆柱式剥离前沿，强调一条卷边；

用户确认 A、B 的整体运动都值得保留，因此两者现在使用各自连续曲面和同一套粒子材质
转换。A 使用 24×15 动态约束网格；B 使用单一连续翻卷前沿。释放面积均按参考完整表面
面积拟合：
`t=0.32/0.47/0.55/0.62/0.70` 的离面比例约为
`41%/70%/87%/98%/100%`。

A 的未粒子化像素层在开场继续贴附于原平面；已经脱附的连续材料区域由 PBD 风力和相邻
约束产生局部牵伸，不再对整张 Dialog 施加仿射平移或为了锁质心而让背风端反向补偿。
左上出口同时进入最早粒子化窗口，因此不会再出现完整 Dialog 先动、左上粒子延迟，或
右侧和下边缘先建立主趋势的问题。B 仍保留原平面贴附作为完整翻卷对照。

A 的粒子先从同一材料坐标对应的三维曲面采样位置、速度、法线和投影压缩，并短暂贴随薄面
形成帷幔；到每颗粒子的局部脱离时刻后，不再按材料坐标贴回当前网格，而是继承脱离状态，
进入统一主风。顺风速度差继续增长以解除 Dialog 轮廓，横向和法向扰动则改为有界、低频
且材料邻域连续的场，不再随飞行年龄向四周发散。彩色内容只增加同公式轨迹的采样数量。
后段寿命按粒子属性错开，避免重新形成 Dialog 外轮廓或同步淡出。

帷幔身份在粒子脱离瞬间由邻域法线曲率和视线投影压缩共同决定，而不是继续使用覆盖大面积
网格的普通屏幕压缩。约 `5%` 的材料点属于窄折叠脊；它们不使用独立轨迹，只生成更多同色
真实粒子，并在统一主风中保留局部相干响应。`t=0.55/0.70/0.78` 的折叠脊/普通区域
密度约为 `4.1×/4.7×/4.1×`，因此中段能形成连续高亮曲线并延续到自由飞行阶段。

A 的后段不是把动态网格压平成矩形，而是逐步匹配到保持正面朝向的低频弯曲薄面；薄面上
只保留一个局部褶皱并沿主风加速。关键帧指标为：顺风平均位移在
`t=0.15/0.25/0.55/0.70` 分别约为 `-0.00008/0.0018/0.12/0.53`，反面比例为
`0%/0.3%/6%/0%`。开场均值接近零来自贴附主体不动，而不是背风端反向补偿；左上脱附区
仍在局部延展。作为对照，B 在 `t=0.65` 的反面比例仍约为 `38%`。

诊断指标中，`t=0.03/0.06/0.10` 的左上基础粒子数约为 `10/73/153`；材料坐标与屏幕
位置的锁形相关度在 `t=0.70/0.78/0.82` 约为 `0.76/0.69/0.66`，旧版同期接近
`1.00`。`t=0.82` 的横向飞行量/顺风飞行量由约 `0.25` 降至 `0.067`，且没有反向

## 当前生产物理模型与真机截图一致性模式

旧 A/B 页面保留为设计过程记录；当前生产实现已经改为统一的连续布面模型。释放时间由
方向风压、低频材料阻力、内部附着脊以及有限宽度的反向压力／剪切和顺风角张力共同构成
一张连续材料相位；不再要求沿单一轴严格单调，也不再计算到四条边的最近距离或对多个
边缘波前取最小值。顺风角、上边缘和左边缘的提前解除直接进入同一相位并连续汇入主体，
不会各自向中心扩张成第二张宏观波前。所有已释放区域均与外部连通。布面通过 PBD 结构、
剪切和弱弯曲约束保持整体，
风力按相对速度计算升力与阻力。粒子从布面当前的位置、速度、法线和折叠密度脱离，折叠
密度来自剥离前沿张力、曲率、压缩应变与屏幕投影压缩，不再由参考帧密度贴图指定。

开场表层预脱落现由随主风旋转的顺风角和两个侧角宽瓣组成，强度不同；顺风角粒子会更早
离面并沿主风做有限牵伸，但仍贴附的 Dialog 不平移。早发纤维的自由输运年龄受到布面
张力限制，并在主前沿接管后平滑退场，避免中段形成脱离整体的远端条带。

直接读取 `ParticleDismissRenderer.kt` 中 canonical GLSL 预渲染的 Android 基准；右侧

## 2026-08-30 开场自由边与真机证据

当前 canonical 模型把左上顺风角及其相邻上、左自由边纳入同一连续释放相位，影响只存在
于有限材料边界层；完整层和粒子层因此同步产生真实缺口，深入内部后仍由唯一主前沿接管。
早发纤维越过 `0.20 s` 后继续受同一主风输运，不再冻结。网页导航中的“开场边缘放大
对比”展示 `t=0.10/0.16/0.216/0.24/0.32` 的参考、桌面和 R5 真机原始帧；“真机 1 秒
原速片段”与三列视频也已更新到同一最终 APK。

## 2026-08-30 方向性连续释放拓扑

对参考视频按材料坐标统计首次失去完整表面的时刻后，最近外边缘距离只能解释约三成空间
变化；去除主风趋势后，参考仍只在一至两条边出现大范围向内领先，并非四条边同时向中心
推进。参考留存区域的质心还会随阶段迁移，最后材料不固定在几何中心。因此生产模型改为
单张方向性相位场：内部附着脊延迟局部解除，风压和剪切从若干有限区域同期开始，低频材料
阻力使等时线弯曲。该场在最终平滑前保留原始数值，避免大量高阻力点被截成同一个末时刻。

完整层、贴附接缝粒子、连续输运粒群和高密折叠脊分别使用同一 release phase 的不同年龄
窗口。`seamFront` 只连接完整层和粒子层，`front` 维持整体输运，`densityFront` 生成窄而
明亮的真实细粒折叠脊；三者不再共享一个宽窗口。最终桌面与 Android 仍使用同一 Kotlin／
GLSL 公式，网页的参考、桌面和真机视频均按真实 `1.000 s` 归一化。
